# Commerce leads से छोड़ी हुई कार्ट वापस पाएँ { #recover-abandoned-carts-with-commerce-leads }

जिन खरीदारों ने आपके ऑनलाइन स्टोर से बिना पेमेंट किए कार्ट छोड़ दी, उन सबको यहाँ देखें। हर खरीदार को WhatsApp पर रिमाइंडर भेजें, जिसमें उसकी कार्ट का लिंक हो। आख़िर में आपको हफ़्ते की वापस मिली कार्ट की गिनती और वापस आई रकम दिखेगी। अपनी पहली कार्ट पर आज़माने के लिए 10 मिनट रखें।

## शुरू करने से पहले { #before-you-start }

- **Connect** → **Store Connections** में आपका Shopify या WooCommerce स्टोर कनेक्ट होना चाहिए। जब तक नहीं है, स्क्रीन पर **No store connected** लिखा आता है।
- आपका WhatsApp नंबर कनेक्ट होना चाहिए। देखें [अपना WhatsApp नंबर कनेक्ट करें](../whatsapp/connect-whatsapp-number.md)।
- आपके पास CRM लीड्स का एक्सेस होना चाहिए। कॉमर्स लीड भी आम लीड ही है। फ़र्क़ बस इतना है कि उसका सोर्स कोई स्टोर होता है।

## स्क्रीन पर क्या दिखता है { #what-the-screen-shows }

| टाइल | क्या गिनती है |
| --- | --- |
| **Abandoned Carts** | पिछले 7 दिनों में छोड़ी गई कार्ट। |
| **Potential Revenue** | इन सब कार्ट की कुल कीमत, अगर हर कार्ट वापस मिल जाए। |
| **Recovered This Week** | इस हफ़्ते जो कार्ट बिक्री बन गईं, और उनसे वापस आई रकम। |
| **Recovery Rate** | कितनी कार्ट WhatsApp रिमाइंडर से वापस मिलीं, उसका हिस्सा। जिस हफ़्ते कोई कार्ट नहीं होती, उस हफ़्ते यहाँ **—** दिखता है। |

## स्टेप { #steps }

### Commerce Leads स्क्रीन खोलें { #open-the-commerce-leads-screen }

1. लेफ़्ट रेल में **Home** खोलें। **Workspace** में **Abandoned Carts** कार्ड ढूँढें।
2. **Work the carts** पर क्लिक करें। **Commerce Leads** स्क्रीन खुलेगी। उसके नीचे लिखा होता है: **Abandoned carts from your WooCommerce/Shopify store — recover them on WhatsApp**।

आप इसे **Sales reports** से भी खोल सकते हैं। **Ctrl K** दबाएँ (Mac पर **⌘K**) और **Sales reports** लिखें। उसे चुनें, फिर ऊपर की **Commerce Leads** पट्टी पर क्लिक करें। इस पट्टी में छोड़ी हुई कार्ट, संभावित रेवेन्यू और आज की रिकवरी दिखती है।

कोई कार्ट न हो, तो स्क्रीन पर **No abandoned carts yet** लिखा आता है। खरीदार बिना चेकआउट किए जाते हैं, तो उनकी कार्ट अपने-आप यहाँ आ जाती है।

### कार्ट देखें { #read-a-cart }

1. लिस्ट में खरीदार को ढूँढें। हर लाइन में ये सब दिखता है: खरीदार, स्टोर का प्लेटफ़ॉर्म, कार्ट की कीमत, प्रायोरिटी और कार्ट छोड़े कितना समय हुआ।
2. उस लाइन पर क्लिक करें। खरीदार की विंडो खुलेगी। उसमें 3 टैब हैं: **Overview**, **Cart** और **Notes & Activities**।
3. कार्ट के प्रोडक्ट देखने के लिए **Cart** खोलें।
4. इस खरीदार की कार्ट खोलने वाला लिंक कॉपी करने के लिए **Copy resume-cart link** पर क्लिक करें। **Resume-cart link copied** मैसेज आएगा।

### एक खरीदार को रिमाइंडर भेजें { #send-one-reminder }

1. उसकी लाइन में **Nudge** पर क्लिक करें।
2. WhatsApp खुलेगा और उसमें यह मैसेज पहले से लिखा मिलेगा: **Hi! You left something in your cart — here's your link to finish up:** और खरीदार का लिंक।
3. WhatsApp में भेजें दबाएँ। Ohanvi में **Recovery message to …** मैसेज आएगा।

कार्ट में फ़ोन नंबर न हो, तो **No phone number on this cart to nudge.** मैसेज आता है। WhatsApp न खुले, तो **Couldn't open WhatsApp.** दिखता है।

### सबको रिमाइंडर भेजें { #send-reminders-to-everyone }

1. ऊपर **Recover all** पर क्लिक करें। कोई कार्ट खुली न हो, तो यह बटन दबता नहीं।
2. WhatsApp का ब्रॉडकास्ट कंपोज़र खुलेगा। वहाँ अपनी ऑडियंस चुनें और एक Approved Template चुनें। देखें [Broadcast कैंपेन भेजें](../whatsapp/send-broadcast-campaign.md)।

### कार्ट एक्सपोर्ट करें { #export-the-carts }

1. **Export** पर क्लिक करें।
2. Ohanvi स्टोर लीड्स की Excel फ़ाइल डाउनलोड कर देगा। **Exported.** मैसेज आएगा।

### कार्ट पर बाकी लीड की तरह काम करें { #work-a-cart-like-any-other-lead }

1. कॉल या नोट लिखने के लिए कार्ट का **Notes & Activities** टैब खोलें।
2. ग्रिड व्यू में उसकी लाइन पर **Move Status** और **Convert** वैसे ही इस्तेमाल करें, जैसे बाकी लीड्स पर करते हैं। देखें [लीड्स पर काम करें](leads.md)।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No store connected** | कोई Shopify या WooCommerce स्टोर कनेक्ट नहीं है। | **Connect** → **Store Connections** में एक स्टोर कनेक्ट करें। |
| **No abandoned carts yet** | आपका स्टोर कनेक्ट है, पर अभी तक किसी ने कार्ट नहीं छोड़ी। | थोड़ा इंतज़ार करें। खरीदारों के कार्ट छोड़ते ही वह यहाँ दिखने लगती है। |
| **Couldn't load commerce leads** | लिस्ट लोड नहीं हुई। | पेज रीफ़्रेश करें और देखें कि स्टोर कनेक्शन ठीक चल रहा है। |
| **No phone number on this cart to nudge.** | खरीदार ने फ़ोन नंबर नहीं दिया। | कार्ट खोलें और उसके ईमेल पर मैसेज भेजें। |
