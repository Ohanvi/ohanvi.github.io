# Ohanvi में साइन इन करें { #sign-in-to-ohanvi }

अपने वर्कस्पेस में आप तीन तरह से साइन इन कर सकते हैं: यूज़रनेम और पासवर्ड से, Google अकाउंट से, या ईमेल पर आए कोड से। साइन इन के बाद **Home** खुलता है। वहाँ आपको सेटअप चेकलिस्ट और आज के आँकड़े दिखते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका Ohanvi अकाउंट बना हो। अगर नहीं बना, तो पहले [Ohanvi पर साइन अप करें](sign-up.md)।
- आपको अपना **username** (या ईमेल) और **password** पता हो। या फिर आप अपने अकाउंट वाले ईमेल का इनबॉक्स खोल सकें।

## स्टेप { #steps }

### यूज़रनेम और पासवर्ड से साइन इन करें { #sign-in-with-username-and-password }

1. [app.ohanvi.com](https://app.ohanvi.com) पर जाएँ।
2. **Username or email** में अपना यूज़रनेम लिखें, या वह ईमेल जिससे आपने साइन अप किया था।
3. **Enter your password** में अपना पासवर्ड लिखें। पासवर्ड देखने या छिपाने के लिए आँख के आइकन पर क्लिक करें।

    ![यूज़रनेम और पासवर्ड भरा हुआ Ohanvi लॉगिन फ़ॉर्म](assets/screenshots/sign-in-1-form-filled.png)

4. **Log In** पर क्लिक करें। Ohanvi **Home** खोल देता है।

    ![साइन इन के बाद का Home पेज, जिसमें Set up in 5 steps चेकलिस्ट है](assets/screenshots/sign-in-2-home.png)

### Google से साइन इन करें { #sign-in-with-google }

1. लॉगिन पेज पर **Continue with Google** पर क्लिक करें। **Sign in with Google** विंडो खुलती है।

    ![ईमेल या फ़ोन माँगती Sign in with Google विंडो](assets/screenshots/sign-in-5-google-popup.png)

2. वही Google अकाउंट चुनकर साइन इन करें, जिसका ईमेल आपके Ohanvi अकाउंट वाला है। Ohanvi **Home** खोल देता है।

!!! note "ध्यान दें"
    **Continue with Google** से सिर्फ़ पहले से बने अकाउंट में साइन इन होता है। Google से नया अकाउंट बनाना हो, तो साइन-अप फ़ॉर्म पर **Sign up with Google** इस्तेमाल करें। देखें [Ohanvi पर साइन अप करें](sign-up.md)।

### ईमेल कोड से साइन इन करें { #sign-in-with-an-email-code }

पासवर्ड याद न हो, तो यह तरीका आज़माएँ।

1. लॉगिन पेज पर **Login with email code** पर क्लिक करें। **Log in with email code** स्क्रीन खुलती है।
2. **Enter your email** में अपने अकाउंट वाला ईमेल लिखें। फिर **Send code** पर क्लिक करें।

    ![ईमेल बॉक्स और Send code बटन वाली Log in with email code स्क्रीन](assets/screenshots/sign-in-4-email-code.png)

3. अपना ईमेल खोलें और 6 अंकों का कोड कॉपी करें। उसे डालें और **Verify** पर क्लिक करें। कोड 10 मिनट तक चलता है।

पासवर्ड वाले लॉगिन फ़ॉर्म पर वापस जाना हो, तो **Back to password login** पर क्लिक करें। अगर आप **Send code** पर क्लिक कर चुके हैं, तो उसकी जगह **Use a different email** पर क्लिक करें।

### साइन आउट करें { #sign-out }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें।
2. **Sign out** पर क्लिक करें। **Logged out successfully** मैसेज आता है और लॉगिन पेज खुल जाता है।

    ![Settings, Current usage और Sign out वाला प्रोफ़ाइल मेन्यू](assets/screenshots/sign-in-3-profile-menu.png)
