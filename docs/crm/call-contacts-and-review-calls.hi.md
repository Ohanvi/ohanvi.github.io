# संपर्कों को कॉल करें और अपनी कॉल की समीक्षा करें { #call-contacts-and-review-your-calls }

**All contacts** स्क्रीन से किसी संपर्क को कॉल करें और दर्ज करें कि क्या हुआ। अंत में हर कॉल का एक नतीजा और वैकल्पिक फ़ॉलो-अप तारीख होगी, और आपकी टीम उसे संपर्क की हिस्ट्री में देख सकेगी। हर कॉल की पूरी समीक्षा में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आपको बाएँ रेल में **Contacts** दिखता हो और उसके पैनल में **All contacts** हो। देखें [संपर्क प्रबंधित करें](manage-contacts.md)।
- संपर्क के पास **Phone** या **Mobile** नंबर हो।
- **WhatsApp Call** के लिए आपका व्हाट्सऐप नंबर कनेक्ट हो। देखें [व्हाट्सऐप कॉलिंग का इस्तेमाल करें](../whatsapp/whatsapp-calling.md)।

## कॉल करने के तरीके { #ways-to-call }

| बटन | यह क्या करता है |
| --- | --- |
| **Call Now** | आप जिस डिवाइस पर हैं उसी से कॉल शुरू करता है। Ohanvi पर लौटने पर समीक्षा विंडो खुलती है। |
| **Call on Mobile — send this number to your phone** | नंबर आपके फ़ोन पर भेजता है ताकि आप वहाँ से डायल कर सकें। सिर्फ़ कंप्यूटर पर दिखता है। |
| **WhatsApp Call** | संपर्क को व्हाट्सऐप कॉल शुरू करता है। |

## चरण { #steps }

### किसी संपर्क को कॉल करें { #call-a-contact }

1. बाएँ रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. सूची में संपर्क पर क्लिक करें।
3. रिकॉर्ड हेडर में **More actions** (**…** बटन) पर क्लिक करें।
4. **Call Now** पर क्लिक करें। आपका डिवाइस कॉल शुरू करता है।
5. संपर्क से बात करें। कॉल खत्म होने पर Ohanvi पर लौट आएँ। **Call Review** विंडो अपने आप खुल जाती है।

फ़ोन पर पंक्ति में यही बटन दिखते हैं। पंक्ति पर फ़ोन बटन पर टैप करें।

### नंबर अपने फ़ोन पर भेजें { #send-the-number-to-your-phone }

1. संपर्क चुनें, फिर **More actions** पर क्लिक करें।
2. **Call on Mobile — send this number to your phone** पर क्लिक करें।
3. अपने फ़ोन पर मैसेज खोलें और नंबर डायल करें।

यह बटन फ़ोन पर छिपा रहता है, क्योंकि डायलर पहले से आपके हाथ में है।

### कॉल की समीक्षा करें { #review-a-call }

**Call Review — contact name** विंडो बताती है कि कॉल कितनी देर चली।

1. **Call Outcome** के नीचे एक चुनें। आप अपना भी लिख सकते हैं। बॉक्स पर **Select or type an outcome** लिखा होता है। नतीजा ज़रूरी है।
2. पहले से मौजूद नतीजों में से चुनें:
    - **Interested**
    - **Interested but Busy**
    - **Not Interested**
    - **Call Back**
    - **Call Tomorrow**
    - **Call in Two Days**
    - **No Answer**
    - **Invalid Number**
    - **Left Organization**
    - **Already Used Other Vendor**
3. बॉक्स के नीचे का सुझाव देखें। Ohanvi कॉल की लंबाई से नतीजे का अंदाज़ा लगाता है। बहुत छोटी कॉल पर **Invalid Number** सुझाता है। छोटी कॉल पर **Not Interested** सुझाता है। लंबी कॉल पर **Interested** सुझाता है। आप इसे बदल सकते हैं।
4. अपना लिखा नतीजा बाद में दोबारा इस्तेमाल करना हो, तो **Save "your text" as a reusable option** पर क्लिक करें।
5. अगर आपने **Already Used Other Vendor** चुना है, तो **Vendor Name** में नाम लिखें। बॉक्स पर **Which vendor is the contact using?** लिखा होता है। यह ज़रूरी है।
6. **Remarks** में कॉल के बारे में नोट लिखें। बॉक्स पर **Notes about the call…** लिखा होता है। बोलकर लिखने के लिए माइक्रोफ़ोन (**Dictate remarks (voice to text)**) पर क्लिक करें।
7. **Follow-up Date** सेट करें:
    - **Call Tomorrow** और **Call in Two Days** तारीख अपने आप भर देते हैं। **Follow-up scheduled for …** वाली पंक्ति इसकी पुष्टि करती है।
    - **Call Back** के लिए आपको **Select a date** पर क्लिक करके तारीख चुननी होती है।
8. **Save** पर क्लिक करें। कॉल संपर्क के **Calls** और **Activity** टैब में दिखती है।

!!! note "ध्यान दें"
    **Call Outcome** ज़रूरी है। खाली होने पर विंडो में **Please select or type a call outcome.** दिखता है। **Call Back** के लिए तारीख न हो तो **Please pick a follow-up date for Call Back.** दिखता है।

### समीक्षा के दौरान संपर्क की जानकारी सुधारें { #fix-the-contacts-details-during-the-review }

1. समीक्षा विंडो में **Update contact details** पर क्लिक करें।
2. प्रॉम्प्ट पढ़ें। यह नतीजे के हिसाब से बदलता है:
    - **Update the contact details they shared:** ज़्यादातर नतीजों के लिए।
    - **Wrong number? Enter the correct one:** **Invalid Number** के लिए।
    - **They left — add the alternate details they gave you:** **Left Organization** के लिए।
3. **Mobile**, **Phone**, **Email** या **Designation** बदलें।
4. **Invalid Number** के लिए, अगर आप इस नंबर पर दोबारा कभी कॉल नहीं करना चाहते, तो **Mark as invalid — set Do Not Call** पर टिक करें।
5. **Save** पर क्लिक करें।

### आखिरी संपर्क को दोबारा कॉल करें { #call-the-last-contact-again }

1. **All contacts** स्क्रीन पर ऊपर की बार में **Last Called** आइकन पर क्लिक करें।
2. नाम, नंबर और कॉल का समय देखें, जैसे **Called 2 hours ago**।
3. उसी संपर्क को डायल करने के लिए **Call Again** पर क्लिक करें, या **Close** पर क्लिक करें।

अगर आपने इस डिवाइस से अभी तक किसी को कॉल नहीं की है, तो **No calls placed from this device yet** मैसेज दिखता है।

### जिन संपर्कों को कॉल कर चुके हैं उन्हें छिपाएँ { #hide-contacts-you-have-already-called }

1. ऊपर की बार में फ़िल्टर आइकन पर क्लिक करें। इसका टूलटिप **Hide called contacts (already completed calls)** है।
2. अब सूची में सिर्फ़ वे संपर्क दिखते हैं जिनकी कॉल पूरी नहीं हुई।
3. उसी आइकन पर दोबारा क्लिक करें। अब इसका टूलटिप **Show all contacts** है।

### अपने फ़ॉलो-अप देखें { #see-your-follow-ups }

1. ऊपर की बार में घंटी आइकन पर क्लिक करें। इसका टूलटिप **Follow-ups Due** है।
2. **Overdue**, **Upcoming** या **All** चुनें। हर एक के साथ उसकी गिनती दिखती है, जैसे **Overdue (3)**।
3. हर पंक्ति पढ़ें। उसमें फ़ॉलो-अप, उसका मालिक और वह संपर्क दिखता है जिससे वह जुड़ा है।
4. दोबारा लोड करने के लिए **Refresh** पर क्लिक करें, या बाहर निकलने के लिए **Close** पर।

कुछ बाकी न हो तो सूची में **No follow-ups in this view.** लिखा होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| कॉल के बाद **Call Review** नहीं खुलता | आप Ohanvi टैब या ऐप पर वापस नहीं लौटे। | Ohanvi पर वापस जाएँ। लौटने पर विंडो खुल जाती है। |
| **Could not save the call review. Please retry.** | सेव सर्वर तक नहीं पहुँचा। | अपना कनेक्शन जाँचें और **Save** पर दोबारा क्लिक करें। |
| **Could not update the contact details. Please retry.** | आपने जो जानकारी बदली वह सेव नहीं हुई। | **Save** पर दोबारा क्लिक करें। |
| **Please enter the vendor name.** | आपने नाम लिखे बिना **Already Used Other Vendor** चुना। | **Vendor Name** में वेंडर का नाम लिखें। |
| **Call on Mobile** नहीं दिख रहा | आप फ़ोन पर हैं। | **Call Now** इस्तेमाल करें। |
