# कैंपेन { #campaign }

कैंपेन से एक मंज़ूर Template मैसेज एक साथ कई लोगों को जाता है। आप उसे अभी भेज सकते हैं या बाद के लिए शेड्यूल कर सकते हैं। यह भी देख सकते हैं कि मैसेज किस-किसको मिला।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।

![Campaign स्क्रीन। इसमें कैंपेन की लिस्ट है और चुने हुए कैंपेन की रिपोर्ट है](../../assets/screenshots/whatsapp-campaign-0-overview.png)

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [ब्रॉडकास्ट कैंपेन भेजें](../send-broadcast-campaign.md) | जब आप कॉन्टैक्ट्स के किसी ग्रुप को मैसेज भेजना चाहें। |
| [कई WhatsApp नंबर चलाएँ](../run-multiple-whatsapp-numbers.md) | जब आप कैंपेन अपने Default नंबर की जगह किसी दूसरे नंबर से भेजना चाहें। |
| [कैंपेन रिपोर्ट पढ़ें](../read-campaign-report.md) | जब आप देखना चाहें कि कितने मैसेज डिलीवर हुए, पढ़े गए और फ़ेल हुए। |

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट होना चाहिए। देखें [अपना WhatsApp नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस होना चाहिए। अगर यह स्क्रीन न दिखे, तो अपने एडमिन से पूछें।
