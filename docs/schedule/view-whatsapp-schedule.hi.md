# अपने शेड्यूल किए WhatsApp मैसेज देखें { #see-your-scheduled-whatsapp-messages }

**WhatsApp** व्यू में WhatsApp पर शेड्यूल की गई हर चीज़ एक कैलेंडर या लिस्ट में मिलती है: ब्रॉडकास्ट, अकेले मैसेज, जवाब, कार्ट रिमाइंडर और अपॉइंटमेंट रिमाइंडर। यहाँ से आप इनमें से किसी को भी चेक कर सकते हैं, उसका समय बदल सकते हैं या उसे रोक सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। न दिखे तो अपने एडमिन से कहें।
- WhatsApp में कुछ शेड्यूल किया हुआ होना चाहिए, जैसे कोई ब्रॉडकास्ट। पढ़ें: [ब्रॉडकास्ट कैंपेन भेजें](../whatsapp/send-broadcast-campaign.md)।

## स्टेप { #steps }

### WhatsApp शेड्यूल खोलें { #open-the-whatsapp-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें और **WhatsApp** चुनें। पेज का टाइटल **WhatsApp schedule** होता है।
2. पेज इस महीने के **Calendar** व्यू में खुलता है। यहाँ चैनल चिप नहीं दिखते, क्योंकि पेज पहले से सिर्फ़ WhatsApp का है।
3. किसी दिन पर क्लिक करें और उसके आइटम देखें। आइटम दिन के नीचे समय के हिसाब से देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। दाईं ओर उसकी जानकारी खुल जाती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर टाइप का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि आइटम किस तरह का है।

| प्रकार | यह क्या है |
| --- | --- |
| **Broadcast** | कॉन्टैक्ट के एक ग्रुप को भेजा जाने वाला कैंपेन। |
| **Message** | किसी एक व्यक्ति को भेजने के लिए शेड्यूल किया गया एक मैसेज। |
| **Reply** | किसी ग्राहक को भेजने के लिए शेड्यूल किया गया जवाब। |
| **Cart nudge** | छोड़ी हुई कार्ट का रिमाइंडर। |
| **Appointment reminder** | बुकिंग से पहले जाने वाला रिमाइंडर। यह आपके अपॉइंटमेंट रिमाइंडर के नियमों से अपने-आप बनता है। |
| **Bot step timeout** | चैटबॉट का वह स्टेप जो जवाब का इंतज़ार करता है। जवाब न आए तो वह चैट को आगे बढ़ा देता है। |

**Audience / with** लाइन में वह फ़ोन नंबर दिखता है जिस पर मैसेज जाएगा।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Scheduled** | अपने समय का इंतज़ार कर रहा है। |
| **Live** | अभी भेजा जा रहा है। |
| **Sent** | भेजा जा चुका है। |
| **Paused** | WhatsApp **Scheduler** में रोक कर रखा गया है। |
| **Failed** | मैसेज जा नहीं पाया। |
| **Cancelled** | कैंसिल हो गया। उसका रिकॉर्ड बना रहता है। |

### किसी आइटम में बदलाव करें { #change-an-item }

1. नई तारीख़ और समय चुनने के लिए **Reschedule** पर क्लिक करें। पढ़ें: [शेड्यूल किया आइटम रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।
2. WhatsApp **Scheduler** खोलने के लिए **Edit** पर क्लिक करें। पढ़ें: [शेड्यूल किए मैसेज और डिलीवरी लॉग देखें](../whatsapp/scheduler-and-delivery-logs.md)।
3. उसे रोकने के लिए **Cancel** पर क्लिक करें। शेड्यूल किया हुआ जॉब रुक जाता है और WhatsApp **Scheduler** से हट जाता है।
4. उसे WhatsApp से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छोटा करें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने हैं तो **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in WhatsApp** चुनें। Ohanvi WhatsApp **Scheduler** खोल देता है। आइटम आप वहीं बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | कोई भी WhatsApp आइटम ओनर या स्टेटस फ़िल्टर से मेल नहीं खा रहा। | **Everyone's schedule** और **Any status** चुनें। |
| कोई आइटम **Failed** है | मैसेज जा नहीं पाया, जैसे Template Approved नहीं था। | वजह देखने के लिए आइटम को WhatsApp **Scheduler** में खोलें, फिर उसे दोबारा भेजें। |
| बार-बार चलने वाला ब्रॉडकास्ट सिर्फ़ एक बार दिखता है | कैलेंडर में अगला मैसेज ही दिखता है। | पूरी सीरीज़ देखने के लिए **Recurring** खोलें। |
| **Could not reschedule.** | नया समय मंज़ूर नहीं हुआ। | कोई दूसरा समय चुनें। |
