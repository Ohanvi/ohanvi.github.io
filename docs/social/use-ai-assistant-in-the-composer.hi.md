# कंपोज़र में AI असिस्टेंट का इस्तेमाल करें { #use-the-ai-assistant-in-the-composer }

**AI Assistant** आपकी पोस्ट के लिए कैप्शन लिखता है और इमेज खोजता है। जब तक आप वापस न जाएँ, यह **Create Post** विंडो के प्रीव्यू वाले हिस्से की जगह ले लेता है। इसके बाद आप कैप्शन दोबारा लिखवा सकते हैं या इमेज बदल सकते हैं। इसमें करीब 3 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपने **Create Post** विंडो खोली हो और कम से कम एक चैनल चुना हो। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।
- आपको पता हो कि पोस्ट किस बारे में है, या आप किसी ट्रेंडिंग विषय से शुरू करना चाहते हों।

## चरण { #steps }

### असिस्टेंट खोलें { #open-the-assistant }

1. **Create Post** में सबसे ऊपर **AI Assistant** पर क्लिक करें। लेबल बदलकर **Close AI Assistant** हो जाता है।
2. **Writing for …** वाली लाइन पढ़ें। उसमें आपके चुने हुए चैनलों के नाम होते हैं। असिस्टेंट उनमें से सबसे सख़्त सीमा वाले के हिसाब से लिखता है।
3. असिस्टेंट से बाहर निकलने के लिए पीछे के तीर (**Back to preview**) पर क्लिक करें।

### पोस्ट का ब्योरा दें { #describe-the-post }

1. **What should this post be about?** के नीचे अपना विषय लिखें। जैसे: `Diwali sale on ethnic wear`।
2. अगर कंपोज़र में पहले से कैप्शन है, तो इस बॉक्स में **Write something new** लिखा होता है।
3. अगर इमेज नहीं चाहिए, तो **Caption only, no image** पर टिक करें।
4. **Generate post** पर क्लिक करें। बटन पर **Generating…** लिखा होता है और पैनल में **Writing your caption and finding an image…** दिखता है।
5. पूरा होने पर कैप्शन और इमेज कंपोज़र में दिखते हैं।

### ट्रेंडिंग विषय से शुरू करें { #start-from-a-trending-topic }

1. **Or start from what's trending** के नीचे दाईं ओर की सूची में से कोई विषय क्षेत्र चुनें।
2. किसी टॉपिक चिप पर क्लिक करें। असिस्टेंट ज़्यादा से ज़्यादा 20 टॉपिक दिखाता है।
3. **Generate post** पर क्लिक करें।
4. अगर टॉपिक बॉक्स में पहले से टेक्स्ट है, तो चिप की जगह आपका अपना टेक्स्ट इस्तेमाल होता है।

अगर पैनल में **Trending topics aren't available right now — type your own above.** लिखा आए, तो अपना विषय लिखें। जिस विषय क्षेत्र में कुछ ट्रेंड नहीं कर रहा, उसके लिए यह लिखा आता है **No trending topics for this area right now — try another, or type your own above.**

### कैप्शन दोबारा लिखवाएँ { #rewrite-the-caption }

1. कैप्शन बनने के बाद **Refine your caption** खोजें।
2. किसी एक बटन पर क्लिक करें:
    - **Rephrase** वही बात नए शब्दों में कहता है।
    - **Shorten to N** उसे आपके चैनलों की सबसे सख़्त सीमा में फ़िट कर देता है। `N` वही सीमा है।
    - **Expand** उसे लंबा करता है।
    - **More casual** उसे दोस्ताना बनाता है।
    - **More formal** उसे ज़्यादा पेशेवर बनाता है।
3. काम होते समय बटन पर स्पिनर दिखता है। कंपोज़र का कैप्शन बदल जाता है।

### इमेज बदलें { #swap-the-image }

1. **Image** के नीचे **Search words, e.g. diwali lights** में शब्द बदलें। शुरू में वे वही शब्द होते हैं जो AI ने चुने थे।
2. **Change image** पर क्लिक करें। खोजते समय उस पर **Finding…** लिखा होता है।
3. नई इमेज पुरानी की जगह ले लेती है। कैप्शन नहीं बदलता।

### पोस्ट पूरी करें { #finish-the-post }

1. हर चैनल पर पोस्ट कैसी दिखेगी यह देखने के लिए पीछे के तीर (**Back to preview**) पर क्लिक करें।
2. **Publish Now**, **Save Draft** या **Schedule** पर क्लिक करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Generate post** ग्रे है | टॉपिक बॉक्स खाली है और कोई ट्रेंड नहीं चुना गया। | कोई विषय लिखें, या किसी ट्रेंड चिप पर क्लिक करें। |
| असिस्टेंट लाल रंग में एरर दिखाता है | AI काम पूरा नहीं कर सका। | **Generate post** पर दोबारा क्लिक करें, या अपना विषय छोटा करें। |
| **Change image** को सही इमेज नहीं मिलती | खोज के शब्द बहुत सामान्य हैं। | ज़्यादा ख़ास शब्द लिखें, फिर **Change image** पर दोबारा क्लिक करें। |
| कैप्शन किसी चैनल के लिए बहुत लंबा है | असिस्टेंट सबसे सख़्त सीमा के हिसाब से लिखता है, पर आपने उसे एडिट कर दिया। | **Shorten to N** पर क्लिक करें। |
