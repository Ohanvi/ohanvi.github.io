# लीड्स के साथ काम करें { #work-with-leads }

लीड वह संभावित ग्राहक है जिसे आप अभी परख रहे हैं। इस पेज में बताया गया है कि लीड कैसे जोड़ें, उन्हें अलग-अलग स्टेटस में कैसे ले जाएँ, और अच्छी लीड को संपर्क में कैसे बदलें। आखिर में कन्वर्ट की गई लीड एक संपर्क रिकॉर्ड बन जाती है, और आपने चुना हो तो उसके साथ अकाउंट और डील भी बनती है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Contacts** दिखे और उसके पैनल में **Leads** हो। अगर नहीं दिखता, तो अपने एडमिन से अपने रोल को CRM लीड्स का एक्सेस देने को कहें। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।
- लीड पर **Lead Source** इस्तेमाल करने के लिए, CRM में सोर्स पहले से बने हों। देखें [CRM का ओवरव्यू](../crm/index.md)।
- छोटी विंडो या फ़ोन पर **Leads** में यहाँ बताए गए ट्राइएज व्यू की जगह एक सादा ग्रिड दिखता है।

## चरण { #steps }

### अपनी लीड्स खोलें { #open-your-leads }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **Leads** चुनें।

    ![Leads स्क्रीन, जिसमें Open, Closed और All टैब, लीड की सूची और Convert बटन के साथ लीड का ब्योरा दिख रहा है (नाम और संपर्क जानकारी धुँधली की गई है)](../assets/screenshots/crm-contacts-2-leads.png)

2. बाईं ओर की सूची में गिनती के साथ 3 टैब हैं: **Open**, **Closed** और **All**। **Open** में वे लीड दिखती हैं जो **NEW**, **CONTACTED**, **QUALIFIED** या **WORKING** हैं और अभी कन्वर्ट नहीं हुई हैं।
3. किसी लीड पर क्लिक करें। दाईं ओर उसका ब्योरा खुलता है, स्टेटस और स्कोर के साथ।

अगर अभी कोई लीड नहीं है, तो **No leads yet** और **Add lead** बटन दिखता है।

### लीड जोड़ें { #add-a-lead }

1. **Add lead** पर क्लिक करें। **Add Lead** फ़ॉर्म खुलता है।
2. **First Name** लिखें। सिर्फ़ यही फ़ील्ड ज़रूरी है।
3. जो जानकारी आपके पास है वह भरें: **Last Name**, **Company**, **Designation**, **Email**, **Phone**, **Mobile** और **Website**।
4. **Lead Source** और **Rating** चुनें: **HOT**, **WARM** या **COLD**।
5. अगर आपके पास हों, तो **Industry**, **Annual Revenue**, **Employees** और पते की फ़ील्ड भरें।
6. अगर व्यक्ति ने ईमेल न भेजने को कहा है, तो **Email Opt-out** पर टिक करें।
7. **Submit** पर क्लिक करें। संदेश **Lead created** दिखता है।

### लीड का स्कोर पढ़ें { #read-a-leads-score }

लीड का स्कोर एक संख्या के रूप में दिखता है। **Why this score** के नीचे Ohanvi बताता है कि स्कोर में क्या-क्या जुड़ा, जैसे:

- **Rated hot** या **Rated warm**
- **Gave an email address**, **Gave a phone number**, **Named their company**, **Has a website**
- **Turnover above ₹1 Cr**, **100 or more staff**
- **Qualified** या **Contacted**

छूटी हुई जानकारी भी सूची में आती है, जैसे **No email address** या **No phone number**। उन्हें भरने से स्कोर बढ़ता है।

### लीड को दूसरे स्टेटस में ले जाएँ { #move-a-lead-to-another-status }

1. लीड चुनें और **More actions** (**…** बटन) पर क्लिक करें, फिर **Move Status** चुनें।
2. **Move "…" to** में **NEW**, **CONTACTED**, **QUALIFIED**, **UNQUALIFIED** या **LOST** चुनें। संदेश **Lead status updated** दिखता है।

लीड **CONVERTED** तभी बनती है जब उसे कन्वर्ट किया जाए, स्टेटस बदलने से नहीं।

### लीड को संपर्क में बदलें { #convert-a-lead-into-a-contact }

1. लीड चुनें। **Before you convert** के नीचे डुप्लिकेट जाँच का नतीजा देखें:
    - **No matching contact** — कन्वर्ट करने पर नया व्यक्ति बनता है।
    - **… is already a contact** — दूसरा संपर्क बनाने के बजाय लीड को उसी संपर्क से जोड़ें।
    - **Duplicate check unavailable** — संपर्क सूची लोड नहीं हुई। थोड़ा रुकें और लीड फिर से चुनें।
2. **Convert** पर क्लिक करें। **Convert Lead** डायलॉग खुलता है।
3. **Create a new contact** चुनें, या मैच मिलने पर **Link the existing contact — …** चुनें।
4. लीड की कंपनी से अकाउंट बनाने के लिए **Create account "…"** पर टिक करें। अगर लीड में कंपनी नहीं है, तो यह **Create account (lead has no company)** दिखाता है।
5. डील खोलने के लिए **Create deal in default pipeline** पर टिक करें। **Deal Name (optional)** लिखें।
6. **Convert** पर क्लिक करें।

!!! warning "कन्वर्ट करना एकतरफ़ा है"
    लीड संपर्क बन सकती है, संपर्क वापस लीड नहीं बनता। लीड अपनी हिस्ट्री के साथ रखी जाती है और **CONVERTED** चिह्नित हो जाती है। उसे फिर एडिट नहीं किया जा सकता और उसका स्टेटस नहीं बदला जा सकता।

### डुप्लिकेट लीड्स मर्ज करें { #merge-duplicate-leads }

1. जिस लीड को हटाना है उसे चुनें, फिर **More actions** → **Merge into…** पर क्लिक करें। **Merge "…" into…** डायलॉग खुलता है।
2. **Surviving record** में वह लीड चुनें जिसे रखना है।
3. **Merge** पर क्लिक करें।

!!! warning "मर्ज को वापस नहीं किया जा सकता"
    बचने वाली लीड की खाली फ़ील्ड दूसरी लीड से भर दी जाती हैं। दूसरी लीड के नोट्स, गतिविधियाँ और सदस्यताएँ इसमें आ जाती हैं, और फिर दूसरी लीड डिलीट हो जाती है।

### नोट्स और गतिविधियाँ दर्ज करें { #log-notes-and-activities }

1. लीड चुनें, फिर **More actions** → **Notes & Activities** पर क्लिक करें।
2. लीड के लिए नोट या गतिविधि जोड़ें। नोट्स और गतिविधियों के बारे में [CRM का ओवरव्यू](../crm/index.md) देखें।

### छोड़ी गई कार्ट पर फ़ॉलो-अप करें { #follow-up-on-abandoned-carts }

जो खरीदार आपके Shopify या WooCommerce स्टोर से बिना भुगतान किए चले जाते हैं, वे कॉमर्स लीड के रूप में आते हैं। उनकी अपनी स्क्रीन और चरण हैं। देखें [Commerce leads से छोड़ी गई कार्ट वापस पाएँ](recover-abandoned-carts.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Lead is already converted.** | लीड पहले ही कन्वर्ट हो चुकी है। | जो संपर्क वह बनी थी, उसे **All contacts** में खोलें। |
| **Lead is converted and can no longer change status.** | कन्वर्ट की गई लीड फ़्रीज़ हो जाती हैं। | इसके बजाय संपर्क, अकाउंट या डील के साथ काम करें। |
| **Lead has no company — cannot create an account from it.** | जिस लीड में कंपनी नहीं है, उस पर **Create account** पर टिक किया गया। | टिक हटाएँ, या पहले लीड में **Company** जोड़ें। |
| **Duplicate check unavailable** | संपर्क सूची अभी लोड नहीं हुई थी। | कन्वर्ट करने से पहले कुछ सेकंड रुकें और लीड फिर से चुनें। |
| कॉमर्स लीड्स की स्क्रीन खाली है | कोई स्टोर कनेक्ट नहीं है, या अभी तक कोई कार्ट छोड़ी नहीं गई। | **Connect** → **Store Connections** में स्टोर कनेक्ट करें। खरीदारों के जाते ही कार्ट दिखने लगती हैं। |
