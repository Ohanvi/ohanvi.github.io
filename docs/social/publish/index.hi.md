# पब्लिश करें { #publish }

Publish में पोस्ट बनती हैं और संभाली जाती हैं। यहाँ आप पोस्ट लिख सकते हैं, उसे शेड्यूल कर सकते हैं और चेक करवाने के लिए भेज सकते हैं। पोस्ट जाने के बाद उसे ट्रैक भी कर सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।

| [सोशल पोस्ट बनाएँ और पब्लिश करें](../create-social-post.md) | आप पोस्ट लिखकर भेजना चाहते हैं। |
| [कंपोज़र में AI असिस्टेंट का इस्तेमाल करें](../use-ai-assistant-in-the-composer.md) | आप चाहते हैं कि AI कैप्शन लिखे या इमेज ढूँढे। |

| [Publish के फ़िल्टर, ओवरव्यू और पोस्ट की डिटेल इस्तेमाल करें](../use-publish-filters-and-extras.md) | आप फ़िल्टर लगाना, लिंक कॉपी करना या देखना चाहते हैं कि कौन-सा चैनल फ़ेल हुआ। |
