# इनबॉक्स { #inbox }

इनबॉक्स वह जगह है जहाँ आपकी टीम ग्राहकों से चैट करती है। आप जवाब दे सकते हैं, चैट असाइन कर सकते हैं, उन्हें बोर्ड पर आगे बढ़ा सकते हैं, स्टोर के ऑर्डर संभाल सकते हैं और कॉल कर सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Inbox** चुनें।

![All, Requesting और Active टैब और चैट सूची के साथ इनबॉक्स](../../assets/screenshots/whatsapp-inbox-1-tabs.png)

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट हो। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस हो। अगर यह नहीं दिखती, तो अपने एडमिन से पूछें।
