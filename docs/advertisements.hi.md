# विज्ञापन कैंपेन की योजना बनाएँ और उसकी समीक्षा करें { #plan-and-review-an-advertisement-campaign }

कैंपेन के नोट्स बनाएँ, क्रिएटिव जोड़ें, बजट तय करें और कैंपेन के प्रदर्शन पर नज़र रखें।

## चरण { #steps }

1. **Advertisements** खोलें।
2. **New campaign** चुनें।
3. उद्देश्य, टारगेट ऑडियंस, तारीख़ें और बजट जोड़ें।
4. क्रिएटिव अपलोड करें या कैंपेन की सामग्री के लिंक पेस्ट करें।
5. कैंपेन को लीड कैप्चर या रिपोर्टिंग वर्कफ़्लो से जोड़ें।
6. खर्च, लीड, कन्वर्ज़न रेट और कैंपेन के नोट्स देखें।

## समझाने वाले मेट्रिक { #metrics-to-explain }

| मेट्रिक | मतलब |
| --- | --- |
| खर्च | कैंपेन के बजट में से इस्तेमाल हुई रकम। |
| लीड | कैंपेन से मिले संपर्कों की संख्या। |
| प्रति लीड लागत | खर्च को लीड की संख्या से भाग देने पर मिलने वाली रकम। |
| कन्वर्ज़न रेट | वे लीड जो जवाब, बुकिंग, ऑर्डर या ग्राहक में बदल गईं। |
