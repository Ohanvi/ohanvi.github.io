# प्रोडक्ट्स जोड़ें { #add-products }

आप जो चीज़ें बेचते हैं, उन्हें CRM में जोड़ें। इसके बाद Deal में प्रोडक्ट लाइनें लग सकती हैं। Deal की रकम इन सभी लाइनों का जोड़ होती है। एक प्रोडक्ट जोड़ने में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आप एडमिन हों। CRM सेटिंग्स सिर्फ़ एडमिन देख सकते हैं।
- आपको हर प्रोडक्ट का कोड, नाम और कीमत पता हो।

## स्टेप { #steps }

### Products खोलें { #open-products }

1. नीचे बाएँ कोने में अपने नाम के शुरुआती अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **CRM** चुनें, फिर **Products** पर क्लिक करें।

चाहें तो **Ctrl K** (Mac पर **⌘K**) दबाएँ, **Products** लिखें और उसे चुन लें।

### प्रोडक्ट जोड़ें { #add-a-product }

1. **Add** पर क्लिक करें। **Add Products** फ़ॉर्म खुल जाता है।
2. **Code** लिखें। हर प्रोडक्ट का कोड अलग होना चाहिए।
3. **Name** लिखें।
4. **Unit Price** लिखें।
5. **Currency** देख लें। यहाँ पहले से **INR** भरा होता है।
6. **Active** पर टिक लगा रहने दें। तभी Deal में यह प्रोडक्ट चुना जा सकेगा।
7. **Submit** पर क्लिक करें। **Product created** मैसेज दिखता है।

**Code** और **Name** दोनों भरना ज़रूरी है।

### Deal में प्रोडक्ट इस्तेमाल करें { #use-a-product-on-a-deal }

1. कोई Deal खोलें। इसके लिए देखें [Deal बनाएँ और मैनेज करें](manage-deals.md)।
2. प्रोडक्ट लाइन जोड़ें और प्रोडक्ट चुनें।
3. Deal की रकम अपने आप उसकी सभी लाइनों का जोड़ बन जाती है।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Product code '…' already exists.** | यह कोड किसी दूसरे प्रोडक्ट में पहले से है। | इस प्रोडक्ट के लिए कोई अलग **Code** लिखें। |
| Deal में प्रोडक्ट नहीं दिख रहा | **Active** पर टिक नहीं लगा था। | प्रोडक्ट को एडिट करें और **Active** पर टिक लगाएँ। |
| CRM सेटिंग्स में **Products** नहीं दिख रहा | आप एडमिन नहीं हैं। | अपने एडमिन से कहें। |
