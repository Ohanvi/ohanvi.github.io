# बुक होने वाली सर्विस जोड़ें { #add-bookable-services }

सर्विस वह चीज़ है जो ग्राहक बुक करता है, जैसे हेयरकट, कंसल्टेशन या प्रोडक्ट डेमो। हर सर्विस की एक अवधि होती है और उसके बाद वैकल्पिक अंतराल। अंत में आपके पास सर्विस की एक सूची होगी जिसे प्रोवाइडर, क्लास और आपका व्हाट्सऐप बुकिंग बॉट इस्तेमाल कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको बाएँ रेल में **Appts** दिखता हो। न दिखे तो अपने एडमिन से कहें कि आपके रोल को Appointments का एक्सेस दें। देखें [सेटिंग्स](../settings/index.md)।
- आपको पता हो कि हर सर्विस में कितना समय लगता है और बुकिंग के बीच कितना ब्रेक चाहिए।

## चरण { #steps }

### सर्विस जोड़ें { #add-a-service }

पेज के सबटाइटल में लिखा है **What a customer can book, and how long each one takes.** अगर अभी कोई सर्विस नहीं है, तो पेज पर **No services yet** और **Add one to start taking bookings.** दिखता है। शुरू करने के लिए वहीं **Add service** पर क्लिक करें।

1. बाएँ रेल में **Appts** खोलें, फिर **Services** चुनें। **Services** पेज खुलता है।
2. **Add service** पर क्लिक करें। **Add service** डायलॉग खुलता है।

    ![Add service डायलॉग, जिसमें Name, Duration, Buffer, Price और Active स्विच हैं](../assets/screenshots/appointments-add-service-1-dialog.png)

3. **Name** में सर्विस का वह नाम लिखें जो ग्राहकों को दिखेगा, जैसे `Haircut`।
4. **Duration (minutes)** में लिखें कि सर्विस कितनी देर चलती है। यह `30` से शुरू होता है।
5. **Buffer (minutes)** में वह ब्रेक लिखें जो हर बुकिंग के बाद खाली रखना है, जैसे `10`। ब्रेक न चाहिए तो `0` रहने दें।
6. **Price** में कीमत रुपयों में लिखें। यह फ़ील्ड वैकल्पिक है।
7. **Active** को चालू रहने दें ताकि ग्राहक इसे बुक कर सकें।
8. **Add service** पर क्लिक करें। **Saved** मैसेज दिखता है और सर्विस अपनी अवधि, बफ़र और कीमत के साथ सूची में आ जाती है, जैसे **30 min · +10 min buffer · ₹500**।

### सर्विस एडिट करें { #edit-a-service }

1. **Services** पेज पर सर्विस के पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit service** डायलॉग खुलता है।
2. जो फ़ील्ड बदलनी हों, बदलें।
3. कुछ समय के लिए सर्विस देना बंद करना हो, तो **Active** बंद कर दें। सर्विस पर **Inactive** बैज दिखता है।
4. **Save service** पर क्लिक करें।

### सर्विस डिलीट करें { #delete-a-service }

!!! warning "ग्राहक इसे बुक नहीं कर पाएँगे"
    डिलीट की गई सर्विस बुकिंग के लिए नहीं दिखती। अगर आप इसे दोबारा देने वाले हैं, तो डिलीट करने के बजाय **Active** बंद कर दें।

1. सर्विस के बिन आइकन (**Delete**) पर क्लिक करें। **Delete "Service name"?** डायलॉग खुलता है।
2. **Delete** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Add service** पर क्लिक करने से डायलॉग बंद हो जाता है पर कुछ जुड़ता नहीं | **Name** खाली था। | **Add service** दोबारा खोलें और नाम लिखें। |
| **Save failed** | सर्वर ने सर्विस नहीं ली, जैसे अवधि न होने की वजह से। | **Name** और **Duration (minutes)** जाँचें, फिर दोबारा कोशिश करें। |
| नई सर्विस के लिए ग्राहकों को कोई खाली समय नहीं दिखता | कोई प्रोवाइडर यह सर्विस नहीं देता, या काम के घंटे तय नहीं हैं। | प्रोवाइडर जोड़ें। देखें [प्रोवाइडर और काम के घंटे जोड़ें](add-providers.md)। |
| अवधि 30 मिनट सेव हो गई | **Duration (minutes)** में ऐसा टेक्स्ट था जो संख्या नहीं है। | सर्विस एडिट करें और सिर्फ़ अंक लिखें। |
