# टास्क नोटिफ़िकेशन पढ़ें { #read-task-notifications }

नोटिफ़िकेशन बेल सारे अलर्ट एक पैनल में इकट्ठा दिखाती है। इसके **Tasks** टैब में आपके टास्क के बदलाव तीन लिस्ट में मिलते हैं: **Created by me**, **New created** और **Watcher**। बेल पर लाल बिंदु हो, तो मतलब है कि कुछ अलर्ट आपने अभी पढ़े नहीं हैं।

## शुरू करने से पहले { #before-you-start }

- दाईं ओर की रेल में **Tasks** आइकन दिखना चाहिए। टास्क एक्सेस न हो, तो **Tasks** टैब नहीं दिखता।
- आपने कम से कम 1 टास्क बनाया हो, या किसी टास्क को वॉच करते हों। देखें [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](collaborate-on-tasks.md)।

## स्टेप { #steps }

### नोटिफ़िकेशन पैनल खोलें { #open-the-notifications-panel }

1. दाईं ओर की रेल में बेल ढूँढें।
2. उस पर छोटा लाल बिंदु देखें। बिंदु का मतलब है कि टास्क के कुछ अलर्ट आपने पढ़े नहीं हैं।
3. बेल पर क्लिक करें। **Notifications** पैनल खुल जाएगा।
4. बंद करने के लिए क्रॉस पर क्लिक करें, जिसकी टूलटिप **Close** है। या पैनल के बाहर क्लिक करें।

### General और Tasks के बीच बदलें { #switch-between-general-and-tasks }

1. टाइटल के नीचे दो टैब दिखते हैं: **General** और **Tasks**।
2. दूसरे मॉड्यूल के अलर्ट देखने के लिए **General** पर क्लिक करें।
3. टास्क के अलर्ट देखने के लिए **Tasks** पर क्लिक करें। टैब के पास का नंबर बताता है कि कितने अलर्ट अनपढ़े हैं।

### टास्क की लिस्ट पढ़ें { #read-the-task-lists }

1. **Tasks** टैब में तीन टैब दिखेंगे: **Created by me**, **New created** और **Watcher**।
2. आपके रिपोर्ट किए टास्क के बदलाव देखने के लिए **Created by me** पर क्लिक करें।
3. अभी-अभी बने टास्क देखने के लिए **New created** पर क्लिक करें।
4. जिन टास्क को आप वॉच करते हैं, उनके बदलाव देखने के लिए **Watcher** पर क्लिक करें। देखें [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](collaborate-on-tasks.md)।
5. हर पंक्ति पढ़ें। जो अलर्ट आपने नहीं पढ़ा, उस पर बिंदु दिखता है।
6. अगर कोई लिस्ट खाली है, तो उसमें **No notifications here** लिखा दिखता है।

### जो लिस्ट लोड नहीं हुई, उसे दोबारा लोड करें { #reload-a-list-that-failed }

1. अगर किसी लिस्ट में एरर दिखे, तो **Retry** बटन ढूँढें।
2. **Retry** पर क्लिक करें। लिस्ट फिर से लोड हो जाएगी।

### चुनें कि अलर्ट आप तक कैसे पहुँचें { #choose-how-alerts-reach-you }

1. टास्क अलर्ट चालू या बंद करने के लिए **Settings** खोलें।
2. [नोटिफ़िकेशन आप तक कैसे पहुँचें, यह चुनें](../settings/notification-preferences.md) के स्टेप फ़ॉलो करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Tasks** टैब नहीं दिख रहा। | आपके रोल को टास्क एक्सेस नहीं मिला है। | अपने एडमिन से पूछें। देखें [टीम के मेंबर, रोल और अनुमतियाँ संभालें](../settings/roles-and-permissions.md)। |
| **No notifications here** | उस लिस्ट में अभी कोई बदलाव नहीं हुआ है। | कोई टास्क वॉच करें, या एक टास्क बनाएँ। |
| **Failed to load notifications** | लिस्ट लोड नहीं हो पाई। | **Retry** पर क्लिक करें। |
| बेल पर लाल बिंदु बना रहता है। | कुछ अलर्ट अभी अनपढ़े हैं। | हर लिस्ट खोलें और पंक्तियाँ पढ़ें। [VERIFY: how alerts are marked as read] |
