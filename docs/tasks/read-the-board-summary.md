# Read the board Summary

The **Summary** view shows how your project is doing without opening every task. Read four counts from the last 7 days, then see charts by status, priority, type and person. Click a card or a bar to jump to the matching tasks.

## Before you start

- You can open the task board. See [Set up a task project](set-up-task-project.md).
- The project has at least 1 task. An empty project shows empty charts.

## What the Summary shows

| Section | What it tells you |
| --- | --- |
| Four count cards | How many tasks were completed, updated and created in the last 7 days, and how many are due soon. |
| **Status overview** | A donut chart of every task by status, with the total in the middle. |
| **Recent activity** | The latest tasks that were created or updated, with who did it and when. |
| **Priority breakdown** | A bar for each priority, from **Highest** to **Lowest**. |
| **Types of work** | How many tasks of each type the project holds. |
| **Team workload** | How many tasks each person has, including **Unassigned**. |
| **Epic progress** | How far each epic has got. |

## Steps

### Open the Summary

1. Click **Tasks** in the right-hand rail.
2. Click **Board**. The full task board opens.
3. In the view switcher at the top, click **Summary**.
4. To load the latest numbers, reopen the view. On a touch screen, pull the page down.

### Read the four count cards

1. Look at the row of cards at the top of the page.
2. Read **completed**, **updated** and **created**. Each card ends with **in the last 7 days**.
3. Read **due soon**. It ends with **in the next 7 days**. [VERIFY: the **due soon** number may always read 0]
4. Click a card. The **List** view opens already filtered to the tasks behind that number.

### Read the Status overview

1. Find **Status overview**. Its line reads **Get a snapshot of the status of your work items.**
2. Read the number under **Total work items**. It is every task in the project.
3. Match each slice to its status name. Done, closed and resolved slices are green. To do and open slices are grey. In progress and in dev slices are dark. Other statuses get their own colours.
4. If the chart reads **No data**, the project has no tasks yet.

### Read Recent activity

1. Find **Recent activity** next to the **Status overview**.
2. Read each row. It shows the task key, the title, its status and the assignee. A task with no assignee reads **Unassigned**.
3. Read the line under the title. It says **created this work item** or **updated this work item**, who did it, and when.
4. Read the time. It reads **just now**, then minutes (**5m ago**), hours (**3h ago**), days (**2d ago**) and weeks (**1w ago**). Older changes show a date.
5. Click a row to open that task.
6. If nothing changed lately, the panel reads **No recent activity**.

### Read the Priority breakdown

1. Find **Priority breakdown**. Its line reads **Get a holistic view of how work is being prioritized.**
2. Read the five bars: **Highest**, **High**, **Medium**, **Low** and **Lowest**.
3. Click **How to manage priorities for spaces** to open the help link.

### Read Types of work

1. Find **Types of work**. Its line reads **Get a breakdown of work items by their types.**
2. Read the count for each type, such as story, task, epic and sub-task.
3. Click a type. The **List** view opens showing only that type.
4. Click **View all items** to see every type.

### Read Team workload

1. Find **Team workload**. Its line reads **Monitor the capacity of your team.**
2. Read the **Work distribution** bars. Each bar shows one person's share of all tasks.
3. Find **Unassigned** to see tasks that have no owner.
4. Click a person's name. The **List** view opens showing only their tasks.

### Read Epic progress

1. Find **Epic progress**. Its line reads **See how your epics are progressing at a glance.**
2. Read the bar for each epic. A project with no epics shows no bars.
3. Click an epic. The board is filtered to it and shows **Filtered by epic**.

!!! tip "Find the owner of a problem fast"
    Click **Unassigned** under **Team workload** to list tasks nobody owns. Then assign them from the **List** view.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| The charts are empty. | The project has no tasks, or it is still loading. | Create a task, or reopen the view to reload. See [Create and assign tasks](create-and-assign-tasks.md). |
| **Epic progress** shows no bars. | The project has no epics. | Create a task of type epic, then add tasks under it. |
| A card opens a **List** with fewer rows than its number. | The **List** applies the filters you set on the board too. | Clear the filters on the board toolbar. See [Find, filter and view tasks](find-and-filter-tasks.md). |
| **No recent activity** | Nothing changed in the project recently. | Create or update a task. |
