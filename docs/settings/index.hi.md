# सेटिंग्स { #settings }

सेटिंग्स में आपका अपना अकाउंट, आपकी टीम और हर मॉड्यूल की कॉन्फ़िगरेशन मिलती है। आपको क्या दिखेगा, यह आपके रोल पर निर्भर करता है। टीम, बिलिंग और इन्वाइट की सेटिंग्स सिर्फ़ **Super Admin** के लिए हैं।

## यह कहाँ मिलेगा { #where-to-find-it }

सेटिंग्स लेफ़्ट रेल में नहीं है। स्क्रीन के नीचे-बाएँ कोने में अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** पर क्लिक करें।

सेटिंग्स स्क्रीन में ये दिखते हैं:

| ग्रुप | रो |
| --- | --- |
| आपका नाम और ईमेल | **Team & access** · **Billing & credits** · **Preferences** · **Developer** |
| **Workspace** | **Security**, **Integrations** |
| **Modules** | **WhatsApp**, **CRM**, **Email Marketing**, **Appointments** (सिर्फ़ वही मॉड्यूल जो आपके वर्कस्पेस में हैं) |

इसी प्रोफ़ाइल मेन्यू में **My Account** (अपने नाम पर क्लिक करें), **Switch role** (जब आपके पास 1 से ज़्यादा रोल हों), **Current usage** और **Sign out** भी हैं।

## शुरू करने से पहले { #before-you-start }

- आप साइन इन हों। देखें [Ohanvi में साइन इन करें](../sign-in.md)।
- टीम, बिलिंग और इन्वाइट की सेटिंग्स के लिए आपका रोल **Super Admin** हो।
