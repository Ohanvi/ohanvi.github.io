# List व्यू का इस्तेमाल करें { #use-the-list-view }

**List** व्यू आपके टास्क को टेबल में दिखाता है, हर टास्क की एक पंक्ति। टेबल छोड़े बिना टास्क जोड़ें, पंक्ति को वहीं एडिट करें, और एक कार्रवाई से कई पंक्तियाँ अपडेट करें। **Summary** व्यू के कार्ड भी यहीं खुलते हैं।

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल सकते हैं। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- प्रोजेक्ट में कम से कम 1 टास्क है, या आप पहला टास्क जोड़ने के लिए **Create** का इस्तेमाल करेंगे।

## List में क्या दिखता है { #what-the-list-shows }

| कॉलम | इसमें क्या रहता है |
| --- | --- |
| **Work** | टाइप आइकन, टास्क की की और शीर्षक। |
| **Assignee** | टास्क का ओनर, या **Unassigned**। |
| **Reporter** | जिसने उसे बनाया। |
| **Priority** | **Highest**, **High**, **Medium**, **Low** या **Lowest**। |
| **Status** | बोर्ड का वह कॉलम जिसमें टास्क है। |
| **Resolution** | टास्क के हल होने तक **Unresolved**। |
| **Created** | टास्क बनने की तारीख। |
| **Updated** | आख़िरी बदलाव की तारीख। |
| **Due date** | उसके पूरा होने की तारीख। |

## चरण { #steps }

### List खोलें { #open-the-list }

1. दाईं रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. व्यू स्विचर में **List** पर क्लिक करें।
3. अगर टेबल में **No tasks found** लिखा है, तो फ़िल्टर हटाएँ या कोई टास्क जोड़ें।

### List से टास्क जोड़ें { #add-a-task-from-the-list }

1. टेबल के नीचे **Create** पर क्लिक करें। एक पंक्ति खुलती है।
2. टाइप बटन पर क्लिक करें, जिसका टूलटिप **Select work type** है, और टाइप चुनें। डिफ़ॉल्ट स्टोरी है।
3. **What needs to be done?** में शीर्षक लिखें।
4. वैकल्पिक: व्यक्ति वाले बटन से असाइनी चुनें।
5. Enter दबाएँ, या **Create** पर क्लिक करें। टास्क टेबल में जुड़ जाता है।
6. बिना जोड़े पंक्ति बंद करने के लिए **Cancel** पर क्लिक करें।

### शीर्षक वहीं एडिट करें { #edit-a-title-in-place }

1. किसी पंक्ति के **Work** सेल पर क्लिक करें। शीर्षक टेक्स्ट बॉक्स बन जाता है।
2. नया शीर्षक लिखें।
3. सेव करने के लिए सही के निशान पर, या रद्द करने के लिए क्रॉस पर क्लिक करें।

### स्टेटस या असाइनी वहीं बदलें { #change-a-status-or-an-assignee-in-place }

1. किसी पंक्ति के **Status** सेल पर क्लिक करें, फिर नया स्टेटस चुनें।
2. **Assignee** सेल पर क्लिक करें, फिर कोई व्यक्ति चुनें।
3. बदलाव तुरंत सेव हो जाता है। अगर वह फ़ेल हो, तो सूची में **Error updating status** या **Error updating assignee** दिखता है।

### कॉलम खिसकाएँ, उनकी चौड़ाई बदलें या क्रम बदलें { #move-resize-or-reorder-columns }

1. कॉलम की चौड़ाई बदलने के लिए उसके हेडर का किनारा खींचें।
2. कॉलम को खिसकाने के लिए उसका हेडर बग़ल की ओर खींचें।
3. हेडर पंक्ति के अंत का कॉलम आइकन सिर्फ़ एक निशान है। इससे दिखाने या छिपाने वाले कॉलमों की सूची नहीं खुलती।

### पंक्तियाँ चुनें { #select-rows }

1. किसी पंक्ति को चुनने के लिए उसके शुरू का बॉक्स टिक करें।
2. और पंक्तियाँ जोड़ने के लिए उन्हें भी टिक करें। टेबल के नीचे एक गहरे रंग की बार दिखती है।
3. बार में लिखी संख्या पढ़ें। वह बताती है कि कितनी पंक्तियाँ चुनी हैं, उसके बाद **selected**।
4. हर पंक्ति चुनने के लिए बार में **Select all** पर क्लिक करें।
5. चुनाव हटाने के लिए बार के दाएँ सिरे पर क्रॉस पर क्लिक करें।

### कई टास्क की प्रायोरिटी बदलें { #change-the-priority-of-many-tasks }

1. पंक्तियाँ चुनें।
2. बार में **Set priority** पर क्लिक करें। एक विंडो खुलती है।
3. **HIGHEST**, **HIGH**, **MEDIUM**, **LOW** या **LOWEST** पर क्लिक करें।
4. संदेश **Updated 3 work item(s).** दिखता है, आपकी संख्या के साथ।
5. अगर वह फ़ेल हो, तो संदेश **Bulk action failed.** होता है।

### कई टास्क का स्टेटस बदलें { #change-the-status-of-many-tasks }

1. पंक्तियाँ चुनें।
2. बार में **Change status** पर क्लिक करें। आपके बोर्ड के कॉलम के साथ एक विंडो खुलती है।
3. जो स्टेटस चाहिए उस पर क्लिक करें।
4. संदेश **Updated N work item(s).** दिखता है।

!!! note "एक साथ डिलीट नहीं"
    बार में डिलीट बटन नहीं है। कई टास्क पूरे करने के लिए उनका स्टेटस किसी पूरा हुए कॉलम पर कर दें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No tasks found** | प्रोजेक्ट खाली है, या फ़िल्टर हर टास्क को छिपा रहे हैं। | फ़िल्टर हटाएँ, या **Create** पर क्लिक करें। |
| **Error creating ticket inline** | नया टास्क सेव नहीं हुआ। | शीर्षक जाँचें और दोबारा कोशिश करें। |
| **Bulk action failed.** | बदलाव स्वीकार नहीं हुआ। | कम पंक्तियाँ चुनें, या उन्हें एक-एक करके बदलें। |
| **Error updating summary** | नया शीर्षक सेव नहीं हुआ। | शीर्षक फिर से एडिट करें। |
| गहरे रंग की बार नहीं दिखती। | कोई पंक्ति चुनी नहीं है। | किसी पंक्ति को टिक करें। |
