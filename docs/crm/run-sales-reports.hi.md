# सेल्स रिपोर्ट निकालें { #run-the-sales-reports }

अपने फ़नल, पाइपलाइन, जीत और हार, लीड के सोर्स, एक्टिविटी, कैंपेन के रिटर्न या कोटा की रिपोर्ट निकालें। आख़िर में आपके पास एक फ़ाइल होगी, जिसे आप शेयर कर सकते हैं। एक रिपोर्ट में करीब 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपके पास CRM रिपोर्ट का एक्सेस होना चाहिए। न हो, तो अपने एडमिन से कहें।
- **Sales reports** **CRM** पैनल की लिस्ट में नहीं मिलता। इसे सर्च बॉक्स से खोलें।

## स्टेप { #steps }

### Sales reports खोलें { #open-sales-reports }

1. **Ctrl K** दबाएँ (Mac पर **⌘K**), या ऊपर सर्च बॉक्स पर क्लिक करें।
2. **Sales reports** टाइप करें।
3. **Sales reports** चुनें। स्क्रीन खुल जाएगी।

### रिपोर्ट चुनें { #pick-a-report }

1. इन 7 रिपोर्ट में से किसी एक पर क्लिक करें:
    - **Sales Funnel**
    - **Pipeline Value**
    - **Win / Loss**
    - **Lead Sources**
    - **Activity Productivity**
    - **Campaign ROI**
    - **Forecast vs Quota**
2. रिपोर्ट लोड होने तक रुकें।

### तारीख की सीमा चुनें { #choose-the-period }

1. तारीख की सीमा वाले बटन पर क्लिक करें।
2. जितने समय की रिपोर्ट चाहिए, वह चुनें। रिपोर्ट दोबारा लोड होगी।

रिपोर्ट में **Nothing in this period** दिखे, तो तारीख की सीमा बढ़ा दें।

### रिपोर्ट डाउनलोड करें { #download-the-report }

1. स्प्रेडशीट चाहिए, तो **Export Excel** पर क्लिक करें।
2. प्रिंट करने या भेजने के लिए डॉक्यूमेंट चाहिए, तो **Export PDF** पर क्लिक करें।

### Commerce Leads पट्टी देखें { #check-the-commerce-strip }

1. **Sales reports** के सबसे ऊपर **Commerce Leads** पट्टी ढूँढें।
2. छोड़ी हुई कार्ट देखने के लिए उस पर क्लिक करें। देखें [Commerce leads से छोड़ी हुई कार्ट वापस पाएँ](recover-abandoned-carts.md)।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| सर्च में **Sales reports** नहीं दिखता | आपके रोल को CRM रिपोर्ट का एक्सेस नहीं मिला है। | अपने एडमिन से कहें। |
| **Nothing in this period** | इस तारीख की सीमा में कोई डेटा नहीं है। | तारीख की सीमा बढ़ाएँ। |
| **Forecast vs Quota** में पूरी टीम का हिसाब दिखता है | रिपोर्ट अभी ओनर के हिसाब से फ़िल्टर नहीं हो पाती। | **Dashboard** पर **Won by owner** से मिलाकर देखें। |
