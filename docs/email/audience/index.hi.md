# ऑडियंस { #audience }

ऑडियंस में दो टैब हैं। कॉन्टैक्ट के लिए **Emails** टैब और लिस्ट व सेगमेंट के लिए **Email Groups** टैब।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Email** खोलें, फिर **Audience** चुनें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [कॉन्टैक्ट, लिस्ट और सेगमेंट जोड़ें](../manage-email-contacts.md) | जब आप लोगों को जोड़ रहे हों। |
| [कॉन्टैक्ट खोजें, टैग करें और एक्सपोर्ट करें](../find-tag-and-export-contacts.md) | जब आपको फ़िल्टर, लेबल या एक्सपोर्ट चाहिए। |
| [ईमेल ग्रुप का इस्तेमाल करें](../use-email-groups.md) | जब आप लिस्ट और नियम वाले सेगमेंट संभालते हों। |

## शुरू करने से पहले { #before-you-start }

- जिन लोगों को आप जोड़ रहे हैं, उन्हें ईमेल भेजने की अनुमति आपके पास होनी चाहिए।
