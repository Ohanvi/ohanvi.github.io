# टीम के मेंबर, रोल और अनुमतियाँ मैनेज करें { #manage-team-members-roles-and-permissions }

अपने वर्कस्पेस में टीम के मेंबर जोड़ें, हर किसी को सही रोल दें, और बाद में ज़रूरत पड़ने पर उन्हें एडिट करें या हटाएँ। आख़िर में आपकी टीम का हर व्यक्ति अपने अकाउंट से साइन इन करेगा और सिर्फ़ वही देखेगा जो उसका रोल उसे देखने देता है।

## शुरू करने से पहले { #before-you-start }

- आप वर्कस्पेस के मालिक हों या कोई दूसरे **Super Admin** हों। टीम स्क्रीन पर **Add**, **Invite teammate** और **Edit** सिर्फ़ एडमिन को दिखते हैं।
- आपके प्लान में एक सीट खाली हो। सारी सीटें भर जाने पर **Add** और **Invite teammate** नहीं दिखते। सीटें बढ़ाने के लिए देखें [Ohanvi में क्रेडिट और बिलिंग](../credits-and-billing.md) और [बिलिंग सेक्शन](../billing/index.md)।
- आपके पास हर साथी का नाम, ईमेल और मोबाइल नंबर हो।

## Ohanvi में रोल { #roles-in-ohanvi }

हर व्यक्ति का ठीक 1 रोल होता है। रोल से तय होता है कि वह हर मॉड्यूल में क्या कर सकता है।

| रोल | क्या कर सकता है |
| --- | --- |
| **Super Admin** | पूरा एक्सेस, टीम और बिलिंग भी। |
| **Manager** | डिलीट छोड़कर सब कुछ। |
| **Executive** | रोज़ का काम। डिलीट, अप्रूव या कैंसल नहीं कर सकता। |

अनुमतियाँ रोल से मिलती हैं। आप किसी एक व्यक्ति के लिए अलग-अलग काम चालू या बंद नहीं कर सकते। किसी की अनुमतियाँ बदलनी हों, तो उसका रोल बदल दें।

जिसने वर्कस्पेस बनाया है, वह अकाउंट का मालिक है। उसका रोल नहीं बदल सकते और उसका अकाउंट डिलीट नहीं कर सकते।

## स्टेप { #steps }

### टीम की लिस्ट खोलें { #open-the-team-list }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. Settings की लिस्ट में सबसे ऊपर अपने नाम पर क्लिक करें।
3. **Team & access** के नीचे **App User** पर क्लिक करें। **App User Management** लिस्ट खुल जाएगी।

लिस्ट में हर व्यक्ति के आगे **Status**, **Name**, **Username**, **Role**, **Email** और **Phone Number** दिखते हैं।

### टीम का साथी जोड़ें { #add-a-teammate }

यह तरीका तब चुनें जब आप साथी का यूज़रनेम और पहला पासवर्ड खुद तय करना चाहते हों। अगर साथी को खुद साइन अप करने देना है, तो [लिंक भेजकर जोड़ें](invite-teammates.md)।

1. **Add** पर क्लिक करें। **Add teammate** विंडो खुलेगी।
2. **User Details** के नीचे **Name**, **Username**, **Email** और **Phone Number** भरें।
3. **Username** के नीचे **Username available** दिखने तक रुकें। **Username already taken** दिखे, तो कोई दूसरा यूज़रनेम आज़माएँ।
4. **User Type** को **Standard** ही रहने दें। **Generic** सिर्फ़ ऐसे बाहरी यूज़र के लिए चुनें जिसे गिने-चुने कामों की छोटी लिस्ट चाहिए।
5. पहला **Password** लिखें। बॉक्स के नीचे की चेकलिस्ट का हर नियम पूरा होना चाहिए।
6. **Role** के नीचे **Super Admin**, **Manager** या **Executive** पर क्लिक करें।
7. अगर आपने **Executive** चुना है, तो **Reports To** → **Manager (optional)** में चुनें कि वह किसे रिपोर्ट करेगा। इसमें सिर्फ़ Manager और Super Admin दिखते हैं।
8. **Add teammate** पर क्लिक करें। **<Name> added to your team.** मैसेज दिखेगा।
9. यूज़रनेम और पासवर्ड अपने साथी को दे दें। वह बाद में **My Account** में जाकर पासवर्ड बदल सकता है।

### साथी की जानकारी या रोल बदलें { #change-a-teammates-details-or-role }

1. **App User Management** लिस्ट में उस व्यक्ति की रो में पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit teammate** विंडो खुलेगी।
2. उसकी जानकारी बदलें, या **Role** के नीचे नया रोल चुनें।
3. पासवर्ड रीसेट करना हो, तो **Password** में नया पासवर्ड लिखें। मौजूदा पासवर्ड रखना हो, तो इसे खाली छोड़ दें।
4. **Save** पर क्लिक करें। **<Name> updated.** मैसेज दिखेगा।

अकाउंट बन जाने के बाद **Username** नहीं बदला जा सकता।

### प्लान डाउनग्रेड के बाद साथी को वापस जोड़ें { #bring-back-a-teammate-after-a-plan-downgrade }

प्लान डाउनग्रेड करने पर अगर सीटें लोगों से कम पड़ जाएँ, तो कुछ अकाउंट बंद हो जाते हैं। उनकी रो में सीट का आइकन दिखता है। उस पर माउस ले जाने पर **Deactivated by a plan downgrade — no free seat.** लिखा आता है।

1. कोई सीट खाली करें, या अपने प्लान में सीटें जोड़ें।
2. उसकी रो में पेंसिल आइकन (**Edit**) पर क्लिक करें, फिर **Save** पर क्लिक करें। अकाउंट फिर से चालू हो जाएगा।

### साथी को हटाएँ { #remove-a-teammate }

!!! warning "साथी का एक्सेस तुरंत बंद हो जाता है"
    हटाया गया साथी साइन इन नहीं कर पाएगा। उसका पुराना काम Ohanvi में बना रहता है।

1. उस व्यक्ति की रो में **Delete** पर क्लिक करें। पक्का करने के लिए एक मैसेज आएगा।
2. पक्का करने के लिए **Delete** पर क्लिक करें।

### User Groups से साथियों का ग्रुप बनाएँ { #group-teammates-with-user-groups }

Super Admin को **Team & access** के नीचे **User Group** भी दिखता है। यूज़र ग्रुप में वे लोग होते हैं जिनका रोल एक जैसा है।

1. **Team & access** के नीचे **User Group** पर क्लिक करें। **User Group Management** लिस्ट खुलेगी।
2. ग्रुप में कौन-कौन है, यह देखने के लिए **Users Count** देखें, या ग्रुप खोलें।
3. सदस्य बदलने के लिए ग्रुप एडिट करें, फिर **App Users** में नाम जोड़ें या हटाएँ।
4. सेव पर क्लिक करें [VERIFY: exact save button label in the grid form]।

हो सके तो रोल **App User** से ही बदलें। ग्रुप हाथ से एडिट करने पर लोग एक रोल से दूसरे रोल में जा सकते हैं।

### अपने ही रोल बदलें { #switch-between-your-own-roles }

अगर आपके पास 1 से ज़्यादा रोल हैं, तो नीचे बाएँ अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Switch role** पर क्लिक करें और रोल चुनें। ऐप दोबारा लोड होगा और उसमें उसी रोल का एक्सेस मिलेगा।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Add** और **Invite teammate** नहीं दिख रहे | आप Super Admin नहीं हैं, या आपके प्लान की सारी सीटें भर गई हैं। | वर्कस्पेस के मालिक से कहें, या [बिलिंग सेक्शन](../billing/index.md) में सीटें जोड़ें। |
| **Cannot reactivate: the tenant's plan has no free seats (…). Upgrade the plan or add seats first.** | सारी सीटें इस्तेमाल में हैं। | किसी को हटाएँ या सीटें जोड़ें, फिर दोबारा कोशिश करें। |
| **Email … already exists with user: …** | किसी और चालू यूज़र के पास यही ईमेल है। | इस साथी के लिए दूसरा ईमेल डालें। |
| **Mobile number … already exists with user: …** | किसी और यूज़र के पास यही मोबाइल नंबर है। | दूसरा नंबर डालें। |
| **Delete** ग्रे है और **This account can't be deleted** दिखता है | यह अकाउंट का मालिक है। | मालिक का अकाउंट हटाया नहीं जा सकता। |
| **This is the account owner — their role can’t be changed.** | आपने मालिक का अकाउंट खोला है। | मालिक की जगह दूसरे साथियों के रोल बदलें। |
