# Schedule a class

A class is one instructor, one time, and several people booked in, such as a yoga batch or a coaching session. Unlike a one-to-one appointment, many customers share the same slot. At the end you will have classes on your weekly list, each showing how many places are taken.

## Before you start

- You can see **Appts** in the left rail. If you cannot see **Classes**, ask your admin for Appointments classes access.
- You have a service for the class, for example `Morning Yoga`. See [Add bookable services](add-services.md).
- To assign an instructor, you have added them as a provider. See [Add providers and working hours](add-providers.md).

## Steps

### Schedule a class

1. Open **Appts** in the left rail, then select **Classes**. The **Classes** page opens on this week.
2. Click **Schedule a class**. The **Schedule a class** dialog opens.
3. In **Class**, choose the service.
4. In **Instructor**, choose a provider, or leave **Not assigned**.
5. Click the **Starts** box. Pick the date, then the time. It starts at 7:00 AM tomorrow.
6. In **Lasts**, choose the length: 30, 45, 60, 75, 90 or 120 minutes.
7. In **Places**, type how many people can join. It starts at `20`.
8. Click **Schedule class**. The message **Saved** appears and the class is listed.

### Check how full a class is

1. On the **Classes** page, use **Previous week** and **Next week** to move between weeks.
2. Each class shows places taken out of the total, for example **12/20**. The badge turns amber when 2 or fewer places are left, and shows **Full** when none are left.
3. Click the list icon (**Who is booked**) to see each booked customer's phone number and status. The icon appears once at least 1 place is taken.

### Edit a class

1. Click the pencil icon (**Edit**) on the class. The **Edit class** dialog opens.
2. Change the instructor, time, length or places.
3. Click **Save class**.

You cannot lower **Places** below the number already booked. The hint under **Places** shows how many are booked, for example **5 already booked — cannot go below that**.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **Add a service first — a class is a service booked by several people.** | No services exist. | Add one on **Appts** → **Services**. See [Add bookable services](add-services.md). |
| **Required** under **Class** | No service was chosen. | Choose a service in **Class**. |
| **At least 1** under **Places** | **Places** is empty, 0 or not a number. | Type a number of 1 or more. |
| **At least 5 are already booked** under **Places** | You tried to set fewer places than the people already booked. | Keep **Places** at or above the booked count. |
| **No classes in this week** | Nothing is scheduled in the week shown. | Click **Next week**, or click **Schedule a class**. |
| **Could not save the class** | The server refused the class, for example because the end time was not after the start. | Check **Starts** and **Lasts**, then try again. |
