# डिलीट किए गए आइटम वापस लाएँ { #restore-deleted-items }

अपने डिलीट किए व्हाट्सऐप आइटम वापस लाने के लिए **Manage** में **Recycle Bin** खोलें। आख़िर में आइटम अपनी स्क्रीन में उन्हीं ब्योरे, ग्रुप और सेटिंग्स के साथ लौट आता है जो पहले थीं। वापस लाने में करीब 1 मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आपका रोल व्हाट्सऐप **Manage** खोल सकता हो। न खुले तो अपने एडमिन से पूछें। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](../settings/roles-and-permissions.md)।
- आपको पता हो कि आपने किस तरह का आइटम डिलीट किया था, जैसे संपर्क या टेम्प्लेट।

## रीसायकल बिन में क्या रहता है { #what-the-recycle-bin-holds }

बिन डिलीट किए आइटम को प्रकार के हिसाब से समूहों में रखता है। हर प्रकार दिखाता है कि उसमें कितने आइटम हैं।

| प्रकार | इसमें क्या रहता है |
| --- | --- |
| **Contacts** | आपके डिलीट किए संपर्क। वापस लाया गया संपर्क उन ग्रुप में लौट जाता है जिनमें वह था। |
| **Contact Groups** | संपर्कों के ग्रुप। |
| **Broadcasts** | ब्रॉडकास्ट कैंपेन। |
| **Templates** | मैसेज टेम्प्लेट। |
| **Chatbot Flows** | चैटबॉट फ़्लो। |
| **Scheduled Messages** | बाद में भेजने के लिए सेट किए संदेश। |
| **Canned Replies** | सेव किए हुए त्वरित जवाब। |
| **Tags** | संपर्क के टैग। |
| **Custom Attributes** | संपर्कों के कस्टम फ़ील्ड। |
| **Custom Events** | वे इवेंट जो आपके सिस्टम फ़्लो शुरू करने के लिए भेजते हैं। |
| **Catalog Products** | आपके व्हाट्सऐप कैटलॉग के प्रोडक्ट। |
| **Integrations** | कनेक्ट की हुई सेवाएँ। |

जिस प्रकार में कुछ डिलीट नहीं हुआ, वह नहीं दिखता।

## चरण { #steps }

### डिलीट किया हुआ आइटम खोजें { #find-a-deleted-item }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें।
2. **Recycle Bin** चुनें। हेडर बताता है कि आपके कितने डिलीट रिकॉर्ड हैं। उसमें यह भी लिखा है **Restoring puts one back exactly as it was — same details, same groups, same settings.**

    ![Recycle Bin, जिसमें डिलीट रिकॉर्ड की गिनती, Contacts की सूची और हर पंक्ति पर Restore बटन दिख रहा है](../assets/screenshots/whatsapp-recycle-bin-1-list.png)

3. उसकी सूची खोलने के लिए किसी प्रकार पर क्लिक करें, जैसे **Contacts**। सूची बंद करने के लिए उस पर फिर क्लिक करें।
4. हर पंक्ति पढ़ें। उसमें नाम, छोटा विवरण, और तारीख व समय के साथ **Deleted** दिखता है। अगर पता हो, तो यह भी दिखता है कि किसने डिलीट किया, **by** और एक नाम के रूप में।
5. अगर सूची लंबी है, तो उसके अंत में **Showing the N most recently deleted of M.** लिखा होता है। पुराने आइटम सूची में नहीं दिखते। [LIMIT]

अगर कुछ डिलीट नहीं हुआ, तो स्क्रीन पर **The recycle bin is empty — nothing has been deleted.** लिखा होता है।

### एक आइटम वापस लाएँ { #restore-one-item }

1. वह प्रकार खोलें जिसमें आइटम है।
2. उसकी पंक्ति के दाएँ सिरे पर **Restore** पर क्लिक करें।
3. जो संदेश दिखे उसे पढ़ें। उसमें **Restored.** या सर्वर का कोई संदेश लिखा होता है।
4. यह जाँचने के लिए कि आइटम लौट आया है, उसकी अपनी स्क्रीन खोलें। संपर्क के लिए **Contact** खोलें।

### कई आइटम वापस लाएँ { #restore-several-items }

1. वह प्रकार खोलें जिसमें आइटम हैं।
2. हर पंक्ति की शुरुआत के चेकबॉक्स पर टिक लगाएँ।
3. सूची के ऊपर की गिनती पढ़ें, जैसे **3 selected**।
4. **Restore selected** पर क्लिक करें। काम होने तक बटन पर स्पिनर दिखता है।
5. जो संदेश दिखे उसे पढ़ें। सूची दोबारा लोड होती है और वापस लाए गए आइटम बिन से गायब हो जाते हैं।

आप एक बार में एक ही प्रकार के आइटम पर टिक लगा सकते हैं। सूची दोबारा लोड होने पर टिक हट जाते हैं।

!!! note "संपर्क या फ़्लो वापस लाना"
    **Contact** वापस लाने पर उसके ग्रुप के लिंक भी वापस आ जाते हैं। **Chatbot Flow** वापस लाने पर वे हिस्से भी लौट आते हैं जो उसके साथ डिलीट हुए थे।

### रीसायकल बिन दोबारा लोड करें { #reload-the-recycle-bin }

1. ऊपर दाईं ओर **Refresh** आइकन पर क्लिक करें।
2. अगर बिन लोड नहीं होता, तो स्क्रीन पर **Could not load deleted records.** दिखता है। फिर से **Refresh** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not restore the selected records.** | सर्वर ने रीस्टोर नामंज़ूर किया, जैसे आइटम अब इस्तेमाल के लायक नहीं रहा। | संदेश पढ़ें। कारण ठीक करें, फिर दोबारा कोशिश करें। |
| **Restore failed.** | अनुरोध सर्वर तक नहीं पहुँचा। | अपना इंटरनेट कनेक्शन जाँचें, **Refresh** पर क्लिक करें, फिर दोबारा कोशिश करें। |
| जो आइटम आपको चाहिए वह सूची में नहीं है | वह दिखाए गए ताज़ा आइटम से पुराना है, या उसे व्हाट्सऐप मॉड्यूल से कभी डिलीट ही नहीं किया गया था। | सही प्रकार के नीचे देखें। **Showing … most recently deleted** वाली लाइन जाँचें। |
| संपर्क वापस आया पर उस ग्रुप में नहीं है जो आप सोचते हैं | संपर्क उन्हीं ग्रुप में लौटता है जिनमें वह डिलीट होते समय था। | उसे दोबारा ग्रुप में जोड़ें। देखें [व्हाट्सऐप संपर्क प्रबंधित करें](manage-whatsapp-contacts.md)। |
