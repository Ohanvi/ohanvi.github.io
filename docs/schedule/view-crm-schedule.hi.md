# अपनी शेड्यूल की गई CRM गतिविधियाँ देखें { #see-your-scheduled-crm-activities }

CRM में प्लान की गई हर गतिविधि को एक कैलेंडर या सूची में देखने के लिए **CRM** व्यू इस्तेमाल करें। आख़िर में आप जान सकते हैं कि आपकी टीम को क्या और कब करना है, और किसी भी गतिविधि को आगे-पीछे कर सकते हैं या रद्द कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Schedule** दिखता हो। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल के पास होता है। न दिखे तो अपने एडमिन से पूछें।
- CRM में तारीख और समय वाली गतिविधियाँ मौजूद हों। देखें [गतिविधियाँ और नोट्स लॉग करें](../crm/log-activities-and-notes.md)।

## चरण { #steps }

### CRM शेड्यूल खोलें { #open-the-crm-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **CRM** चुनें। पेज का टाइटल **CRM schedule** होता है।
2. पेज मौजूदा महीने के **Calendar** व्यू में खुलता है। चैनल चिप्स छिपे रहते हैं, क्योंकि पेज पहले से सिर्फ़ CRM तक सीमित है।
3. किसी दिन पर क्लिक करके उसके आइटम देखें। दिन के हेडिंग के नीचे समय के हिसाब से देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर प्रकार का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि आइटम किस तरह का है।

| प्रकार | यह क्या है |
| --- | --- |
| **Task** | करने वाला काम। जिन टास्क का कोई और प्रकार नहीं होता, वे **Task** दिखते हैं। |
| **Call** | प्लान की गई फ़ोन कॉल। |
| **Meeting** | प्लान की गई मीटिंग। |
| **Email** | प्लान किया गया ईमेल फ़ॉलो-अप। |
| **Whatsapp** | प्लान किया गया व्हाट्सऐप फ़ॉलो-अप। |
| **Whatsapp call** | प्लान की गई व्हाट्सऐप कॉल। |

**Audience / with** लाइन उस लीड, संपर्क या डील का नाम दिखाती है जिससे गतिविधि जुड़ी है।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Scheduled** | प्लान की गई, अभी शुरू नहीं हुई। |
| **Live** | चल रही है। |
| **Sent** | पूरी हो गई। |
| **Cancelled** | रद्द कर दी गई। रिकॉर्ड बना रहता है। |

### किसी आइटम को बदलें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।
2. CRM गतिविधियों की स्क्रीन खोलने के लिए **Edit** पर क्लिक करें। देखें [गतिविधियाँ और नोट्स लॉग करें](../crm/log-activities-and-notes.md)।
3. उसे रद्द करने के लिए **Cancel** पर क्लिक करें। गतिविधि का स्टेटस रद्द हो जाता है।
4. उसे CRM से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को सीमित करें { #narrow-the-view }

1. **Everyone's schedule** पर क्लिक करें और सिर्फ़ अपने आइटम देखने के लिए **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in CRM** चुनें। Ohanvi CRM गतिविधियों की स्क्रीन खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | किसी CRM गतिविधि पर तारीख और समय नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | CRM में गतिविधि को देय समय दें। **Any status** चुनें। |
| पूरी हो चुकी गतिविधि **Sent** दिखती है | शेड्यूल पूरी हुई गतिविधि को **Sent** के रूप में दिखाता है। | कुछ करने की ज़रूरत नहीं। |
| **Could not cancel.** | गतिविधि पहले ही पूरी या रद्द हो चुकी है, या आपका रोल CRM में उसे नहीं बदल सकता। | स्टेटस जाँचें। CRM एक्सेस के लिए अपने एडमिन से कहें। |
