# पोस्ट Template इस्तेमाल करें { #use-post-templates }

जो पोस्ट टेक्स्ट आप बार-बार इस्तेमाल करते हैं, उसे Template के रूप में सेव कर लें। फिर एक क्लिक में उसे कंपोज़र में खोल सकते हैं। आप तैयार लाइब्रेरी देख सकते हैं या खाली जगह वाले अपने Template खुद लिख सकते हैं। चाहें तो AI से किसी टॉपिक या ट्रेंड पर Template का ड्राफ़्ट भी बनवा सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखना चाहिए, और उसके पैनल में **Templates** भी।
- Template से पब्लिश करने के लिए कम से कम एक नेटवर्क कनेक्ट होना चाहिए। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।

## स्टेप { #steps }

### Template ढूँढें { #find-a-template }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Templates** चुनें।
2. बाईं तरफ़ से कोई एक व्यू चुनें:
    - **Discover**: तैयार लाइब्रेरी। इसमें **Recommended for you** और **More templates** होते हैं।
    - **My Templates**: आपके बनाए Template।
    - **AI Generated**: AI के बनाए ड्राफ़्ट Template।
    - **Saved**: वे Template जिन पर आपने दिल का आइकन दबाया है।
    - **Recently Used**: वे Template जो आपने कंपोज़र में खोले हैं।
3. **CATEGORIES** के नीचे **All Templates** या कोई कैटेगरी चुनें, जैसे **Marketing**, **Announcement**, **Event**, **Review** या **General**।
4. **Filter by platform** के नीचे कोई नेटवर्क चुनें, तो सिर्फ़ उसी के Template दिखेंगे। सारे नेटवर्क के लिए **All platforms** चुनें।

### Template इस्तेमाल करें { #use-a-template }

1. Template कार्ड पर **Use Template** पर क्लिक करें। **Create Post** विंडो Template के टेक्स्ट और इमेज के साथ खुलेगी।
2. हर `[bracketed]` खाली जगह की जगह अपने शब्द लिखें।
3. अपने नेटवर्क चुनें और पोस्ट पब्लिश या शेड्यूल करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

कंपोज़र के अंदर से भी Template चुन सकते हैं। ऊपर **Templates** पर क्लिक करें, फिर **Start from a template** में से कोई एक चुनें।

### Template बनाएँ { #create-a-template }

1. **Create Template** पर क्लिक करें। **New Template** विंडो खुलेगी।
2. **Template Name** में नाम लिखें।
3. **Category** में कैटेगरी चुनें।
4. चाहें तो **Thumbnail** के नीचे **Add image** पर क्लिक करें। इमेज 500 KB से कम की होनी चाहिए।
5. **Content** में पोस्ट का टेक्स्ट लिखें। किसी भी शब्द को `[brackets]` में लिखने से वह खाली जगह बन जाता है। जैसे `It helps [Target Audience] save time.`
6. **Platforms** के नीचे चुनें कि Template कहाँ इस्तेमाल हो सकता है।
7. **Live Preview** देखें, फिर **Save Template** पर क्लिक करें। **Template saved.** मैसेज आएगा।

यह फ़ॉर्म AI से भरवाना हो, तो विंडो के ऊपर **Draft with AI** पर क्लिक करें और बताएँ कि पोस्ट किस बारे में है।

### AI से Template बनवाएँ { #generate-a-template-with-ai }

1. **Generate with AI** पर क्लिक करें। **Generate a template** विंडो खुलेगी।
2. **Trending in** के नीचे कोई ट्रेंडिंग टॉपिक चुनें। या **Or write your own topic** के नीचे अपना टॉपिक लिखें, जैसे `Independence Day sale`।
3. **Generate** पर क्लिक करें। Ohanvi कैप्शन लिखता है और इमेज ढूँढता है। इसमें एक मिनट तक लग सकता है।
4. **Review your template** में **Template name**, **Category**, **Content** और **Platforms** देख लें। जो बदलना हो, बदल दें।
5. **Save template** पर क्लिक करें। **Saved "…" to your templates** मैसेज आएगा। उसे कंपोज़र में खोलने के लिए **Use now** पर क्लिक करें।

### Template सेव करें और दोबारा ढूँढें { #save-a-template-and-find-it-again }

1. Template कार्ड पर प्रीव्यू के ऊपर दाईं तरफ़ दिल के आइकन पर क्लिक करें। दिल भरा हुआ दिखे, तो Template सेव हो गया।
2. सेव हटाना हो, तो दिल पर दोबारा क्लिक करें।
3. जिन Template पर आपने दिल दबाया है, उन्हें देखने के लिए **Templates** खोलें और **Saved** चुनें।
4. जो Template आपने कंपोज़र में खोले थे, उन्हें देखने के लिए **Recently Used** चुनें।
5. कार्ड की किसी लाइन में उसके सारे Template देखने के लिए **View all** पर क्लिक करें।

!!! note "ध्यान दें"
    सेव किए हुए और हाल में इस्तेमाल किए Template सिर्फ़ मौजूदा सेशन तक रहते हैं।

### अपना Template एडिट या डिलीट करें { #edit-or-delete-your-template }

1. आपके बनाए Template पर **More** (⋯) मेनू पर क्लिक करें।
2. बदलाव करना हो, तो **Edit** पर क्लिक करें। हटाना हो, तो **Delete** पर क्लिक करें। **Delete** करने पर **Delete template?** विंडो में कन्फ़र्म करें।

आप सिर्फ़ अपने बनाए Template ही एडिट या डिलीट कर सकते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Image too large — pick one under 500 KB.** | थंबनेल की साइज़ लिमिट से बड़ा है। | इमेज को कंप्रेस करें और दोबारा जोड़ें। |
| **Name is required** या **Description is required** | **Template Name** या **Content** खाली है। | दोनों फ़ील्ड भरें। |
| **No templates match here** | आपकी कैटेगरी, प्लेटफ़ॉर्म या सर्च फ़िल्टर की वजह से कोई Template नहीं दिख रहा। | **All Templates** और **All platforms** चुनें। |
| **Trending topics aren't available right now — type your own below.** | ट्रेंड फ़ीड से कुछ नहीं आया। | अपना टॉपिक खुद लिखें। |
| **Could not generate a caption right now. Please try again.** | AI की रिक्वेस्ट फ़ेल हो गई। | थोड़ी देर रुकें और **Generate** पर फिर से क्लिक करें। |
