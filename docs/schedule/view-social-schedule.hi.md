# अपनी शेड्यूल की हुई सोशल पोस्ट देखें { #see-your-scheduled-social-posts }

हर शेड्यूल की हुई पोस्ट को एक ही कैलेंडर या सूची में देखने के लिए **Social** व्यू इस्तेमाल करें। अंत में आप देख सकेंगे कि हर नेटवर्क पर हर पोस्ट कब लाइव होगी, और उसे आगे-पीछे या बंद कर सकेंगे।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Schedule** दिखता है। डिफ़ॉल्ट रूप से यह केवल वर्कस्पेस के Super Admin रोल के पास होता है। न दिखे तो अपने एडमिन से पूछें।
- पोस्ट का एक शेड्यूल किया हुआ समय हो। देखें [पोस्ट शेड्यूल करें और कतार प्रबंधित करें](../social/schedule-social-posts.md)।

## चरण { #steps }

### Social शेड्यूल खोलें { #open-the-social-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Social** चुनें। पेज के टाइटल में **Social schedule** लिखा होता है।
2. पेज मौजूदा महीने के **Calendar** व्यू में खुलता है। चैनल चिप छिपे रहते हैं, क्योंकि पेज पहले से ही Social तक सीमित है।
3. किसी दिन के आइटम देखने के लिए उस दिन पर क्लिक करें। उन्हें दिन के शीर्षकों के नीचे समय के क्रम में देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसकी जानकारी दाईं ओर खुलती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### जानें कि हर टाइप का क्या मतलब है { #read-what-each-type-means }

**Type** दिखाता है कि आइटम किस तरह का है।

| टाइप | यह क्या है |
| --- | --- |
| **Post** | किसी कनेक्टेड अकाउंट पर पब्लिश होने के लिए शेड्यूल की गई सोशल पोस्ट। |

**Audience / with** लाइन उस सोशल नेटवर्क को दिखाती है जहाँ पोस्ट जाएगी, जैसे Instagram।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | पोस्ट समय के साथ ड्राफ़्ट के रूप में सेव है। |
| **Scheduled** | पोस्ट **Scheduled** या **Queued** है और अपने समय का इंतज़ार कर रही है। |
| **Live** | पोस्ट अभी पब्लिश हो रही है। |
| **Sent** | पोस्ट पब्लिश हो चुकी है, या केवल कुछ नेटवर्क पर पब्लिश हुई है। |
| **Failed** | पब्लिश नहीं हो पाई। |
| **Cancelled** | रद्द कर दी गई। यह पब्लिश नहीं होती। |

### आइटम बदलें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [शेड्यूल किया हुआ आइटम रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।
2. Social की **Publish** स्क्रीन खोलने के लिए **Edit** पर क्लिक करें। देखें [पोस्ट शेड्यूल करें और कतार प्रबंधित करें](../social/schedule-social-posts.md)।
3. रद्द करने के लिए **Cancel** पर क्लिक करें। शेड्यूल की हुई पोस्ट रद्द हो जाती है और पब्लिश नहीं होती।
4. Social से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छोटा करें { #narrow-the-view }

1. केवल अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in Social** चुनें। Ohanvi Social की **Publish** स्क्रीन खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | किसी पोस्ट का शेड्यूल किया हुआ समय नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | Social **Publish** में कोई पोस्ट शेड्यूल करें। |
| कोई पोस्ट **Sent** दिखती है लेकिन एक नेटवर्क पर नहीं है | पोस्ट केवल कुछ नेटवर्क पर पब्लिश हुई थी। | किस नेटवर्क पर फ़ेल हुई, यह देखने के लिए पोस्ट को Social **Publish** में खोलें। |
| **Could not cancel.** | पोस्ट पहले ही पब्लिश हो चुकी है या आपका रोल उसे बदल नहीं सकता। | स्टेटस जाँचें। अपने एडमिन से Social का एक्सेस माँगें। |
