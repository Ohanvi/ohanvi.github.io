# ड्राफ़्ट खोजें और पूरे करें { #find-and-finish-drafts }

जो आइटम सेव हैं पर भेजने के लिए तैयार नहीं हैं, उन्हें **Drafts** व्यू में ढूँढें। इस गाइड के बाद आप हर ड्राफ़्ट ढूँढ पाएँगे और उसे उसके अपने मॉड्यूल में खोल पाएँगे। फिर आप उसे पूरा करेंगे या हटा देंगे।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। न दिखे तो अपने एडमिन से पूछें।
- आपने Email या Social में तारीख और समय के साथ कोई ड्राफ़्ट सेव किया हो। जिस ड्राफ़्ट में तारीख और समय नहीं है, वह Schedule में नहीं दिखता।

## स्टेप { #steps }

### Drafts खोलें { #open-drafts }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Drafts** चुनें। पेज का टाइटल **Drafts** होता है और पेज **List** व्यू में खुलता है।
2. लिस्ट देखें। हर लाइन में टाइटल, चैनल और एक **Draft** पिल दिखती है।
3. किसी लाइन पर क्लिक करें। उसकी जानकारी दाईं तरफ़ खुल जाती है।

### जानें कि ड्राफ़्ट कहाँ से आते हैं { #know-where-drafts-come-from }

| चैनल | ड्राफ़्ट में क्या दिखता है |
| --- | --- |
| **Email** | ऐसा कैंपेन जो **Draft**, **Pending review** या **Rejected** है और जिसका शेड्यूल का समय तय है। |
| **Social** | ऐसी पोस्ट जो शेड्यूल के समय के साथ ड्राफ़्ट में सेव है। |

WhatsApp, CRM और Appointments के आइटम कभी ड्राफ़्ट नहीं होते। वे बनते ही **Scheduled** हो जाते हैं।

### ड्राफ़्ट पूरा करें { #finish-a-draft }

1. ड्राफ़्ट पर क्लिक करें।
2. **Edit** पर क्लिक करें। **Opening Email…** या **Opening Social…** मैसेज आता है।
3. Ohanvi ड्राफ़्ट वाला मॉड्यूल खोल देता है। वहाँ ड्राफ़्ट ढूँढें और उसे पूरा करें। ज़रूरत हो तो ये गाइड देखें: [ईमेल कैंपेन भेजें](../email/send-email-campaign.md) या [पोस्ट शेड्यूल करें और क्यू मैनेज करें](../social/schedule-social-posts.md)।
4. वापस **Drafts** में आएँ। पूरा हो चुका आइटम **Upcoming** में चला जाता है।

### ड्राफ़्ट हटाएँ { #remove-a-draft }

1. ड्राफ़्ट पर क्लिक करें।
2. रिकॉर्ड रखकर उसे रोकना हो, तो **Cancel** पर क्लिक करें। उसके मॉड्यूल से पूरा हटाना हो, तो **Delete** पर क्लिक करें। ज़्यादा जानकारी के लिए देखें [शेड्यूल किए आइटम को रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।

### लिस्ट छोटी करें { #narrow-the-list }

1. सिर्फ़ **Email** या **Social** के ड्राफ़्ट देखने के लिए किसी चैनल चिप पर क्लिक करें।
2. सिर्फ़ अपने ड्राफ़्ट देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | कोई ड्राफ़्ट नहीं है, या किसी ड्राफ़्ट में तारीख और समय नहीं है। | ड्राफ़्ट को उसके मॉड्यूल में खोलें और शेड्यूल का समय डालें। |
| **Rejected** ईमेल कैंपेन ड्राफ़्ट में दिख रहा है | **Rejected** कैंपेन भी ड्राफ़्ट के साथ ही दिखते हैं। | उसे **Edit** से खोलें, जिस वजह से रिजेक्ट हुआ उसे ठीक करें और दोबारा रिव्यू के लिए भेजें। |
| ड्राफ़्ट **Upcoming** में नहीं है | **Upcoming** में सिर्फ़ **Scheduled** और **Live** आइटम दिखते हैं। | पहले ड्राफ़्ट पूरा करें। |
