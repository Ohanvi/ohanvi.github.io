# अपनी Google Business Profile प्रबंधित करें { #manage-your-google-business-profile }

अपनी Google लिस्टिंग को अपडेट रखें और Ohanvi छोड़े बिना रिव्यू का जवाब दें। आप अपने बिज़नेस का नाम, संपर्क की जानकारी, पता, श्रेणियाँ और खुलने का समय एडिट कर सकते हैं, बुकिंग या ऑर्डर के लिंक जोड़ सकते हैं, और रिव्यू का सार्वजनिक जवाब दे सकते हैं।

## शुरू करने से पहले { #before-you-start }

- Google Business कनेक्ट है, कम से कम एक लोकेशन के साथ। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
- आपको लेफ़्ट रेल में **Social** दिखता है, और उसके पैनल में **Business Info**। अगर नहीं दिखता, तो अपने एडमिन से कहें कि आपके रोल को एक्सेस दें। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।

अपनी Google लिस्टिंग पर पोस्ट करने के लिए कंपोज़र इस्तेमाल करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## चरण { #steps }

### अपनी बिज़नेस जानकारी एडिट करें { #edit-your-business-info }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Business Info** चुनें।
2. अगर आप एक से ज़्यादा लिस्टिंग संभालते हैं, तो **Location** में उसे चुनें।
3. **Profile** में **Business name**, **Description**, **Phone number** और **Website** एडिट करें। फ़ोन नंबर देश के कोड के साथ लिखें, जैसे `+911234567890`।
4. **Address** में **Address line**, **City / locality**, **State / region** और **Postal code** एडिट करें।
5. **Categories** में **Primary category** एडिट करें। **Additional categories** में हर श्रेणी को कॉमा से अलग करें।
6. **Regular hours** में हर दिन को **Open** या **Closed** पर सेट करें, और खुलने व बंद होने का समय लिखें।
7. **Save changes** पर क्लिक करें। **Business info saved.** संदेश दिखता है।

Google कुछ बदलावों को लाइव होने से पहले जाँचता है। तब तक पेज पर दिखता है **Your last edit is still pending review by Google — the values shown may not be live yet.**

Business name अधिकतम 300 अक्षरों का हो सकता है। Description अधिकतम 750 अक्षरों की हो सकती है।

### बुकिंग या ऑर्डर का लिंक जोड़ें { #add-a-booking-or-order-link }

यह भाग तभी दिखता है जब आपका वर्कस्पेस इसे सपोर्ट करता है।

1. **Booking / order links** में **Add link** पर क्लिक करें। **Add booking / order link** विंडो खुलती है।
2. **Action type** में लिंक का प्रकार लिखें, जैसे `BOOK`।
3. **URL** में लिंक पेस्ट करें।
4. **Add** पर क्लिक करें। **Link added** संदेश दिखता है।

लिंक हटाने के लिए उसके बगल वाले डिलीट आइकन पर क्लिक करें।

### अपनी लिस्टिंग वेरिफ़ाई करें { #verify-your-listing }

1. **Business Info** पर ऊपर की **Verification** लाइन देखें।
2. अगर लिस्टिंग वेरिफ़ाइड नहीं है, तो **Start verification** पर क्लिक करें।
3. **Method** में `PHONE_CALL` रहने दें, या Google आपकी लिस्टिंग के लिए जो दूसरा तरीका देता है वह लिखें।
4. **Start** पर क्लिक करें। **Verification started — check for a PIN** संदेश दिखता है। Google PIN उसी तरीके से भेजता है जो आपने चुना।

### Google रिव्यू का जवाब दें { #reply-to-google-reviews }

रिव्यू का अपना अलग पेज है। देखें [Google रिव्यू का जवाब दें](reply-to-google-reviews.md)। उसमें फ़िल्टर, जवाब, फ़्लैग और नोट्स शामिल हैं।
