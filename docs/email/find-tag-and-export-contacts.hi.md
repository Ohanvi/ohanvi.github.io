# संपर्क खोजें, टैग करें और एक्सपोर्ट करें { #find-tag-and-export-contacts }

Audience में **Emails** टैब आपके सभी ईमेल संपर्कों की सूची दिखाता है। इसकी मदद से लोगों को खोजें, टैग करें, उनका स्टेटस बदलें और अपनी ऑडियंस एक्सपोर्ट करें। आखिर में आपके संपर्कों पर लेबल लग जाते हैं, ताकि आप उन्हें टारगेट कर सकें।

## शुरू करने से पहले { #before-you-start }

- आपको **Email** पैनल में **Audience** दिखता है। न दिखे तो अपने एडमिन से पूछें।
- आपके पास संपर्क हैं। देखें [संपर्क, लिस्ट और सेगमेंट जोड़ें](manage-email-contacts.md)।

## चरण { #steps }

### संपर्क खोजें { #find-contacts }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Audience** चुनें।
2. **Emails** टैब खोलें।
3. **All Contacts**, **Subscribed Contacts** और **Unsubscribed Contacts** के बीच बदलने के लिए **All**, **Subscribed** या **Unsubscribed** पर क्लिक करें।
4. फ़िल्टर से सूची छोटी करें: **Status**, **Filter by Owner**, **Filter by Tags** और **Active in last N days** (Last 7, 30 या 90 days, या **Any time**)।
5. हर फ़िल्टर हटाने के लिए **Clear all** पर क्लिक करें।

### संपर्कों को टैग करें { #tag-contacts }

1. किसी संपर्क के टैग खोलकर **Manage tags** पर जाएँ। **Add or remove tags** के नीचे **Search or create a tag** में लिखें।
2. नया टैग बनाने के लिए **Create** पर क्लिक करें। पुराना टैग दोबारा इस्तेमाल करने के लिए **Popular tags** में से चुनें।
3. **Add tags** या **Remove tags** पर क्लिक करें।
4. कई लोगों को टैग करने के लिए उनके पते **Bulk Tag by Email** में पेस्ट करें, या **Upload File** इस्तेमाल करें। पूछे जाने पर टैग का नाम दें: **What should we name this tag?**
5. या **Manage audience** पर क्लिक करें, फिर **Bulk select & actions** चुनें। **Select All** इस्तेमाल करें, फिर **Tag Contacts** या **Delete Selected Contacts** चुनें।

### संपर्क का स्टेटस बदलें { #change-a-contacts-status }

1. पंक्ति पर **More actions** मेन्यू पर क्लिक करें।
2. उन्हें फिर से **Subscribed** करने के लिए **Reactivate** चुनें, या मार्केटिंग ईमेल रोकने के लिए **Unsubscribe** चुनें।
3. उन्हें किसी लिस्ट में जोड़ने के लिए **Copy to List** चुनें।

### अपनी ऑडियंस एक्सपोर्ट करें { #export-your-audience }

1. **Export** पर क्लिक करें। **Export Contacts** डायलॉग खुलता है।
2. **Export Type**, **File Name**, **Format** और **Fields to Include** सेट करें।
3. वैकल्पिक: **Filters** और **Date Range** सेट करें। फिर एक्सपोर्ट करें।

### Manage audience के अंदर के दूसरे टूल { #other-tools-under-manage-audience }

1. **Import history**, **Export audience**, **Find duplicates**, **Copy to list** और **Bulk select & actions** खोलने के लिए **Manage audience** पर क्लिक करें।

### डेटा अनुरोध संभालें { #handle-a-data-request }

1. उस व्यक्ति के पास जो भी डेटा है, उसे एक्सपोर्ट करने के लिए पंक्ति पर **GDPR Data Export** पर क्लिक करें।
2. उनका डेटा मिटाने के लिए **GDPR Erase** पर क्लिक करें। इसे वापस नहीं किया जा सकता।
3. डेटा अनुरोध के बिना संपर्क हटाने के लिए **Delete Contact** पर क्लिक करें।

!!! warning "चेतावनी"
    **GDPR Erase** हमेशा के लिए होता है। अगर आपको रिकॉर्ड की ज़रूरत पड़ सकती है, तो पहले एक्सपोर्ट कर लें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| कोई संपर्क नहीं दिख रहा। | कोई फ़िल्टर उसे छिपा रहा है। | **Clear all** पर क्लिक करें। |
| बल्क टैग में कुछ पंक्तियाँ छूट गईं। | वह पता **Contacts** में नहीं है। | पहले संपर्क जोड़ें, फिर दोबारा टैग करें। |
| बाउंस के लिए **Reactivate** कुछ नहीं करता। | हार्ड बाउंस और शिकायतें हमेशा के लिए होती हैं। | देखें [सप्रेशन लिस्ट से पते ब्लॉक करें](use-the-suppression-list.md)। |
