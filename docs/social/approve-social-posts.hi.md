# पब्लिश करने से पहले पोस्ट रिव्यू करवाएँ { #review-posts-before-they-publish }

ड्राफ़्ट लाइव होने से पहले अपने किसी साथी को रिव्यू के लिए भेजें। रिव्यू करने वाला उसे मंज़ूर करता है या बदलाव माँगता है। मंज़ूर होने के बाद आप उसे शेड्यूल या पब्लिश कर सकते हैं। रिव्यू करवाना ज़रूरी नहीं है। जो ड्राफ़्ट आपने सबमिट ही नहीं किया, उसे सीधे पब्लिश कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखता हो, और उसके पैनल में **Publish** हो।
- पोस्ट ड्राफ़्ट के रूप में सेव हो। [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md) देखें।
- पोस्ट मंज़ूर करने के लिए आपके रोल को सोशल पोस्ट मंज़ूर करने का एक्सेस चाहिए। **Approve** पर एरर आए, तो अपने एडमिन से कहें। [सेटिंग्स का ओवरव्यू](../settings/index.md) देखें।

## स्टेप { #steps }

### ड्राफ़्ट को रिव्यू के लिए भेजें { #submit-a-draft-for-review }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. **Drafts** टैब पर क्लिक करें।
3. पोस्ट पर **Submit** पर क्लिक करें। **Post submitted for approval.** मैसेज दिखेगा।

पोस्ट **Approvals** टैब में चली जाती है और उसका स्टेटस **Pending approval** होता है। आपके वर्कस्पेस के एडमिन को **Approval requested** नोटिफ़िकेशन मिलता है।

### पोस्ट मंज़ूर करें { #approve-a-post }

1. **Social** → **Publish** खोलें, फिर **Approvals** टैब पर क्लिक करें।
2. पोस्ट पढ़ें। कार्ड पर **Submitted by** के आगे भेजने वाले का नाम दिखता है।
3. **Approve** पर क्लिक करें। **Post approved — it can now be scheduled.** मैसेज दिखेगा।

पोस्ट बनाने वाले को **Post approved** नोटिफ़िकेशन मिलता है। अब वह पोस्ट को शेड्यूल या पब्लिश कर सकता है।

### बदलाव माँगें { #request-changes }

1. **Approvals** टैब में पोस्ट पर **Request Changes** पर क्लिक करें। **Request changes?** विंडो खुलेगी।
2. **What needs changing?** में अपनी राय लिखें। यह लिखना ज़रूरी नहीं है।
3. **Request Changes** पर क्लिक करें। **Changes requested — the post went back to the creator.** मैसेज दिखेगा।

### बदलाव के बाद दोबारा भेजें { #resubmit-after-changes }

1. **Drafts** टैब में **Changes requested** लिखी पोस्ट ढूँढें। रिव्यू करने वाले का नोट उसके नीचे दिखता है।
2. **Edit** आइकन पर क्लिक करें, बदलाव करें और **Save Changes** पर क्लिक करें।
3. **Resubmit** पर क्लिक करें।

!!! note "ध्यान दें"
    मंज़ूर होने के बाद पोस्ट में कोई बदलाव करेंगे, तो वह दोबारा **Pending approval** में चली जाएगी। पब्लिश करने से पहले उसका फिर से रिव्यू होना ज़रूरी है।

## मंज़ूरी के स्टेटस { #approval-statuses }

| स्टेटस | मतलब |
| --- | --- |
| **Pending approval** | रिव्यू करने वाले का इंतज़ार है। अभी इसे शेड्यूल या पब्लिश नहीं कर सकते। |
| **Approved** | रिव्यू करने वाले ने मंज़ूरी दे दी है। अब आप इसे शेड्यूल या पब्लिश कर सकते हैं। |
| **Changes requested** | रिव्यू करने वाले ने इसे वापस भेज दिया है। इसे एडिट करें और **Resubmit** पर क्लिक करें। |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **You cannot approve your own post** | पोस्ट बनाने वाला अपनी ही पोस्ट मंज़ूर नहीं कर सकता। | किसी और साथी से मंज़ूर करवाएँ। |
| **Post is awaiting approval and cannot be published until approved** | पोस्ट का रिव्यू अभी बाकी है। | मंज़ूरी का इंतज़ार करें, या रिव्यू करने वाले से कहें। |
| **Changes were requested; edit and resubmit for approval before publishing** | रिव्यू करने वाले ने बदलाव माँगे हैं। | पोस्ट एडिट करें, फिर **Resubmit** पर क्लिक करें। |
| **Only draft posts can be submitted for approval; current status is …** | पोस्ट पहले ही शेड्यूल हो चुकी है या भेजी जा चुकी है। | रिव्यू के लिए सिर्फ़ ड्राफ़्ट भेजे जा सकते हैं। |
