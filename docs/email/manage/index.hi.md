# प्रबंधन { #manage }

Manage वह हब है जहाँ से आपके ईमेल भेजने की सारी व्यवस्था संभलती है।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [शेड्यूलर](../use-the-email-scheduler.md) | आप कैलेंडर पर ईमेल भेजने की योजना बनाते हैं। |
| [बिज़नेस की छुट्टियाँ (Business Holidays)](../manage-business-holidays.md) | आपको कुछ दिनों में कोई ईमेल नहीं भेजना है। |
| [भेजने वाले की पहचान (Sender Identities)](../set-up-sender-identity.md) | आप भेजने वाले का पता सेट करते हैं। |
| [ईमेल भेजने वाला सर्वर (Email Sending Server)](../connect-email-provider.md) | आप अपना प्रोवाइडर कनेक्ट करते हैं। |
| [भेजने के लॉग (Send Logs)](../read-send-logs.md) | आप हर प्राप्तकर्ता की जाँच करते हैं। |
| [सप्रेशन लिस्ट (Suppression List)](../use-the-suppression-list.md) | आप कुछ पते ब्लॉक करते हैं। |
| [विषय (Topics)](../manage-email-topics.md) | आप ईमेल को विषय के हिसाब से समूह में रखते हैं। |

## शुरू करने से पहले { #before-you-start }

- ऐसा एडमिन रोल जो **Manage** देख सकता हो।
