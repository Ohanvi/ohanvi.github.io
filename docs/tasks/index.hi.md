# टास्क { #tasks }

टास्क Ohanvi का बना-बनाया टास्क बोर्ड है। प्रोजेक्ट बनाएँ, काम के हर चरण के लिए कॉलम जोड़ें, और टीम की प्रगति के साथ टास्क को उनके बीच खिसकाएँ।

## कहाँ मिलेगा { #where-to-find-it }

टास्क **दाईं ओर** की रेल में है, नोटिफ़िकेशन बेल और **Help** के बगल में, लेफ़्ट रेल में नहीं।

- **Tasks** पैनल खोलने के लिए **Tasks** पर क्लिक करें। उसमें **Today**, **Assigned to me** और **Created by me** टैब हैं, और **Create** और **Board** बटन।
- पूरा टास्क बोर्ड खोलने के लिए **Board** पर क्लिक करें। उसका टूलबार **Summary**, **Timeline**, **Backlog**, **Board** और **List** व्यू के बीच बदलता है।

## शुरू करने से पहले { #before-you-start }

- आपके रोल के पास Task एक्सेस है। इसके बिना **Tasks** आइकन छिपा रहता है।
- आपके वर्कस्पेस में कम से कम 1 बोर्ड कॉलम वाला टास्क प्रोजेक्ट है। नया प्रोजेक्ट बिना किसी कॉलम के शुरू होता है, देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- जिन सदस्यों को आप काम सौंपना चाहते हैं वे प्रोजेक्ट के सदस्य हैं। असाइनी की सूची में सिर्फ़ प्रोजेक्ट के सदस्य दिखते हैं।
