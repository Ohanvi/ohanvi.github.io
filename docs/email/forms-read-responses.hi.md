# फ़ॉर्म के जवाब पढ़ें { #read-form-responses }

फ़ॉर्म के अंदर **Responses** टैब उसके जवाब दिखाता है। इसका इस्तेमाल रुझान देखने और अलग-अलग जवाब पढ़ने के लिए करें।

## शुरू करने से पहले { #before-you-start }

- आपके फ़ॉर्म पर कम से कम 1 जवाब आ चुका हो।

## चरण { #steps }

1. लेफ़्ट रेल में **Forms** खोलें, फिर **Forms** चुनें।
2. फ़ॉर्म खोलें और **Responses** टैब चुनें। टैब में जवाबों की गिनती दिखती है।
3. सारांश पढ़ें। उसमें हर सवाल **Question N of M** के रूप में दिखता है। रेटिंग वाले सवालों में **Average x of max** दिखता है। NPS में स्कोर दिखता है।
4. एक बार में 1 रिस्पॉन्स पढ़ने के लिए **Individual** खोलें।
5. फ़ॉर्म ने जवाबों के साथ क्या किया, यह देखने के लिए **What happened next** पढ़ें।
6. **Partly done** या **Not accepted: …** खोजें। ये बताते हैं कि कौन-सा चरण पूरा नहीं हुआ और क्यों।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| गिनती 0 है। | अभी किसी ने सबमिट नहीं किया। | लिंक शेयर करें। |
| कोई रिस्पॉन्स **Partly done** है। | कोई एक नतीजा फ़ेल हो गया, जैसे बुकिंग। | **Submissions** खोलें और **Retry** पर क्लिक करें। |
