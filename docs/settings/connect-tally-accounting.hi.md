# Tally अकाउंटिंग कनेक्ट करें { #connect-tally-accounting }

अपने लेजर, पार्टी, आइटम और वाउचर को Ohanvi के साथ सिंक में रखने के लिए **Accounting ERP** से Tally कनेक्ट करें। आप कनेक्ट करते हैं, कंपनी चुनते हैं, बदलाव का प्रीव्यू देखने के लिए ड्राई रन चलाते हैं, फिर सिंक करते हैं। पहले कनेक्शन में करीब 20 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **Settings** में **Integrations** खोल सकते हों। अगर **Accounting ERP** नहीं दिख रहा, तो किसी एडमिन से कहें कि आपके संगठन के लिए Accounting ERP चालू करे।
- Tally इंस्टॉल हो और जिस कंपनी को सिंक करना है, वह उसमें खुली हो।
- आपको पता हो कि Ohanvi, Tally तक कैसे पहुँचेगा:
    - **Direct:** Tally खुला हो और उसका HTTP सर्वर चालू हो, और आपको उसका पता मालूम हो।
    - **Bridge:** Tally नेटवर्क पर पहुँच में नहीं है। आप Tally चलाने वाले कंप्यूटर पर एक छोटा ब्रिज एजेंट इंस्टॉल करते हैं।

## जो शब्द आपको दिखेंगे { #words-you-will-see }

| शब्द | मतलब |
| --- | --- |
| **Connection** | Ohanvi और Tally की एक कंपनी के बीच सेव किया हुआ एक लिंक। |
| **Bridge** | Tally वाले कंप्यूटर पर चलने वाला छोटा एजेंट। वह Tally तक लोकल तौर पर पहुँचता है, इसलिए Tally को इंटरनेट पर होना ज़रूरी नहीं। |
| **Dry run** | ऐसा सिंक जो कुछ नहीं लिखता। वह सिर्फ़ दिखाता है कि क्या बदलेगा। |
| **Sync now** | असली सिंक जो बदलाव लिखता है। |
| **Run** | एक सिंक, जिसमें **Fetched**, **Created**, **Updated**, **Conflicts** और **Errors** की गिनती होती है। |
| **Mapping** | Tally के लेजर ग्रुप, वाउचर टाइप, यूनिट और गोदामों को Ohanvi के कोड से मिलाना। |

## चरण { #steps }

### Accounting ERP खोलें { #open-accounting-erp }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. बाईं सूची में **Workspace** के नीचे **Integrations** चुनें।
3. **Connectors** के नीचे **Accounting ERP** पर क्लिक करें। **Accounting ERP** पेज खुलता है।
4. शीर्षक के नीचे की लाइन पढ़ें। उसमें लिखा है कि Tally कनेक्ट करें और लेजर, पार्टी, आइटम और वाउचर सिंक में रखें।
5. अपने प्रोवाइडर का कार्ड खोजें। उस पर **Set up** या **1 connected** जैसी गिनती दिखती है। BUSY का कार्ड इसके बजाय उसका व्हाट्सऐप सेटअप खोलता है। देखें [व्हाट्सऐप वेबहुक और इंटीग्रेशन सेट करें](../whatsapp/whatsapp-webhooks-and-integrations.md)।

### Tally कनेक्ट करें { #connect-tally }

1. **Connect ERP** पर क्लिक करें, या Tally कार्ड पर **Connect** पर क्लिक करें। कनेक्ट विज़ार्ड खुलता है। उसके चरण हैं **Provider**, **Transport**, **Test**, **Company**, **Scope** और **Done**।
2. **Provider** पर, **Which accounting system do you use?** के नीचे Tally चुनें। जिस प्रोवाइडर पर **Coming soon** लिखा है, उसे अभी चुना नहीं जा सकता। **Continue** पर क्लिक करें।
3. **Transport** पर **Connection name** लिखें, जैसे `Head office Tally`। यह हब पर दिखता है।
4. **How should we reach** Tally **?** के नीचे एक चिप चुनें, जैसे **HTTP** या **Bridge**।
5. डायरेक्ट कनेक्शन के लिए, दिखने वाले फ़ील्ड भरें। तारे के निशान वाले फ़ील्ड ज़रूरी हैं। जैसे, Tally के HTTP सर्वर का पता और पोर्ट। फ़ील्ड के नाम हर प्रोवाइडर के हिसाब से दिए जाते हैं।
6. ब्रिज के लिए, नीचे दिए **Add a bridge** के चरण अपनाएँ, फिर उसे सूची में से चुनें। सूची में हर ब्रिज का **Heartbeat** दिखता है।
7. **Continue** पर क्लिक करें।

### ब्रिज जोड़ें { #add-a-bridge }

1. कनेक्ट विज़ार्ड में **Add bridge** पर क्लिक करें। हब पेज पर **Bridges** के पास **Add bridge** पर भी क्लिक कर सकते हैं।
2. **Name this computer** में नाम लिखें, जैसे `Office PC`। यह ज़रूरी है।
3. ब्रिज को Tally वाले कंप्यूटर पर इंस्टॉल करें। **Download bridge** पर क्लिक करें।
4. ब्रिज जब माँगे, तो विंडो में दिखा कोड डालें। कोड सिर्फ़ एक बार दिखता है। कॉपी करने के लिए कॉपी आइकन पर क्लिक करें। विंडो में **Valid until** और एक समय दिखता है।
5. **Bridge status** देखते रहें। ब्रिज के कनेक्ट होने तक उसमें **Waiting for the bridge…** लिखा रहता है।
6. उस कंप्यूटर पर Tally खुला रखें।

### कनेक्शन टेस्ट करें { #test-the-connection }

1. **Test** पर, हेडिंग के नीचे की लाइन पढ़ें। ब्रिज के लिए उसमें लिखा है कि Ohanvi कनेक्शन सेव करेगा और ब्रिज से Tally तक पहुँचने को कहेगा, और उस कंप्यूटर पर Tally खुला होना चाहिए। डायरेक्ट कनेक्शन के लिए लिखा है कि Ohanvi आपके दिए पते पर Tally को कॉल करेगा, और Tally खुला होना चाहिए और उसका HTTP सर्वर चालू होना चाहिए।
2. **Test connection** पर क्लिक करें।
3. अगर यह काम करता है, तो नतीजे में **Connected** लिखा होता है और वर्शन, रिस्पॉन्स का समय और **companies visible** दिखते हैं।
4. अगर फ़ेल होता है, तो नतीजे में **Could not reach the ERP** लिखा होता है। वजह ठीक करें और **Test again** पर क्लिक करें।
5. **Continue** पर क्लिक करें।

### कंपनी चुनें { #choose-the-company }

1. **Company** पर **Which company should this connection sync?** पढ़ें। हर कंपनी के साथ उसका **GSTIN**, **Books from** तारीख या वित्तीय वर्ष की शुरुआत दिखती है।
2. जिस कंपनी को चाहिए उस पर क्लिक करें।
3. अगर सूची में **No companies found** लिखा है, तो Tally में कंपनी खोलें। फिर **Ask Tally again** पर क्लिक करें।
4. **Continue** पर क्लिक करें।

### चुनें कि क्या सिंक करना है { #choose-what-to-sync }

1. **Scope** पर, **What to sync** के नीचे हर वह रिकॉर्ड टाइप टिक करें जो लाना है, जैसे लेजर, पार्टी, आइटम या वाउचर।
2. **Voucher types** के नीचे वे वाउचर टाइप टिक करें जो चाहिए। कोई भी टिक न हो तो हर वाउचर टाइप शामिल होता है।
3. अगर **Direction** का विकल्प मिले, तो उसे सेट करें।
4. **Sync mode** में चुनें कि कैसे सिंक करना है। **Automatic** चुनने पर **Every (minutes)** लिखें।
5. **When both sides changed** में चुनें कि टकराव कैसे सुलझाया जाए।
6. अगर आप चाहते हैं कि लेजर, पार्टी और आइटम बिना प्रीव्यू के लागू हो जाएँ, तो **Apply master changes automatically** चालू करें। वाउचर हमेशा ड्राई-रन रिव्यू का इंतज़ार करते हैं।
7. **Save and finish** पर क्लिक करें।
8. **Done** पर **Connection name is ready** पढ़ें। उसमें लिखा है कि कुछ भी लिखे जाने से पहले बदलाव का प्रीव्यू देखने के लिए ड्राई रन से शुरू करें। **Open connection** पर क्लिक करें।

### ड्राई रन चलाएँ { #run-a-dry-run }

1. कनेक्शन पेज पर **Dry run** पर क्लिक करें। आप **More actions** से **Dry run** भी चुन सकते हैं।
2. **Runs** टैब खोलें। नया रन **Running — this page updates by itself.** दिखाता है।
3. खत्म होने पर संदेश **Dry run ready for review** दिखता है। उसमें लिखा होता है कि अभी कुछ नहीं लिखा गया है।
4. गिनती पढ़ें: **Fetched**, **Staged**, **Created**, **Updated**, **Skipped**, **Conflicts**, **Errors** और **Pushed**। **By record type** टेबल उन्हें अलग-अलग बाँटकर दिखाती है।
5. हर बदलाव पढ़ने के लिए **Preview & apply** पर क्लिक करें।
6. अगर बदलाव सही लगें, तो उन्हें लागू करें।

अगर पेज कहता है कि अकाउंटिंग एडॉप्टर इस सर्वर पर इंस्टॉल नहीं है, तो आप प्रीव्यू पढ़ सकते हैं पर लागू नहीं कर सकते। सपोर्ट से संपर्क करें।

### कोड मैप करें { #map-codes }

1. कनेक्शन पेज पर **Mapping** टैब खोलें।
2. अगर उसमें **Nothing to map yet** लिखा है, तो पहले ड्राई रन चलाएँ। लेजर ग्रुप, वाउचर टाइप, यूनिट और गोदाम लाए जाने के बाद दिखते हैं।
3. संख्या के साथ **unmapped** बैज पढ़ें। **Unmapped** चिह्नित पंक्ति को Ohanvi कोड चाहिए।
4. हर पंक्ति के लिए **Ohanvi code** लिखें, या खाली पंक्तियों को नाम मिलाकर भरने के लिए **Auto-map by name** पर क्लिक करें। संदेश **Unmapped keys filled by name.** दिखता है।
5. बदलावों की संख्या के साथ **Save** पर क्लिक करें। संदेश **Mapping saved.** दिखता है। अपने बदलाव छोड़ने के लिए **Discard** पर क्लिक करें।

### सिंक सेटिंग्स बदलें { #change-sync-settings }

1. **Sync settings** टैब खोलें।
2. फ़ील्ड बदलें, जैसा **Choose what to sync** में है।
3. **Save settings** पर क्लिक करें। संदेश **Sync settings saved.** दिखता है। अपने बदलाव छोड़ने के लिए **Discard** पर क्लिक करें।

### असली सिंक करें { #sync-for-real }

1. कनेक्शन पेज पर **Sync now** पर क्लिक करें।
2. **Runs** टैब देखते रहें। रन को पढ़ने के लिए उसे खोलें। कार्ड में **Last run**, **Fetched**, **Created**, **Updated**, **Conflicts** और **Errors** दिखते हैं।
3. अगर **Conflicts** 0 से ऊपर है, तो कार्ड में **Review in the run** लिखा होता है। रन खोलें और उनकी समीक्षा करें।

### सिंक की गड़बड़ियाँ ठीक करें { #fix-sync-errors }

1. **Errors** टैब खोलें। ऊपर की सूची से स्टेटस के हिसाब से फ़िल्टर करें, **All** से शुरू करके।
2. हर पंक्ति में रिकॉर्ड, एरर कोड और संदेश दिखता है।
3. किसी पंक्ति पर **Resolve** पर क्लिक करें।
4. कोई कार्रवाई चुनें: **Retry**, **Skip**, **Apply theirs** या **Keep ours**।
5. वैकल्पिक: नोट जोड़ें। पुष्टि करें। संदेश **Error updated.** दिखता है और पंक्ति में आपका नोट दिखता है।
6. अगर टैब में **No errors** लिखा है, तो किसी चीज़ पर ध्यान देने की ज़रूरत नहीं।

### कंपनी बदलें { #change-the-company }

1. **Companies** टैब खोलें।
2. सूची रीफ़्रेश करने के लिए **Ask the ERP again** पर क्लिक करें। संदेश **Company list refreshed.** दिखता है।
3. किसी दूसरी कंपनी पर **Use this company** पर क्लिक करें। संदेश बताता है कि वह कंपनी चुनी गई। चुनी हुई कंपनी पर **Selected** दिखता है।

### कनेक्शन टेस्ट करें या रद्द करें { #test-or-revoke-a-connection }

1. कनेक्शन पेज पर **Test** पर क्लिक करें (या **More actions** इस्तेमाल करें)। काम करने पर संदेश **Connected in** और एक संख्या **ms.** दिखता है। पेज **Test passed** या **Test failed** दिखाता है।
2. उसे हटाने के लिए **Revoke** पर क्लिक करें।
3. **Revoke this connection?** में चेतावनी पढ़ें: सेव किए क्रेडेंशियल मिटा दिए जाते हैं और कतार में लगे सिंक रद्द हो जाते हैं। जो रिकॉर्ड Ohanvi में पहले सिंक हो चुके हैं, वे बने रहते हैं। सिंक करने के लिए आपको दोबारा कनेक्ट करना होगा।
4. **Revoke** पर क्लिक करें। संदेश **Connection revoked.** दिखता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No ERP connectors on this server** | आपके संगठन के लिए Accounting ERP चालू नहीं है। | किसी एडमिन से इसे चालू करने को कहें। |
| **Could not reach the ERP** | Tally बंद है, या उसका HTTP सर्वर बंद है, या ब्रिज ऑफ़लाइन है। | Tally को HTTP सर्वर चालू करके खोलें, या ब्रिज जाँचें, फिर **Test again** पर क्लिक करें। |
| **No companies found** | कंपनी Tally में खुली नहीं है। | Tally में कंपनी खोलें, फिर **Ask Tally again** पर क्लिक करें। |
| **Waiting for the bridge…** बदल नहीं रहा | ब्रिज इंस्टॉल नहीं है या कोड डाला नहीं गया। | Tally वाले कंप्यूटर पर ब्रिज इंस्टॉल करें और कोड डालें। कोड एक ही बार दिखता है, इसलिए एक्सपायर हो गया हो तो नया ब्रिज जोड़ें। |
| **Could not start the sync.** | अनुरोध फ़ेल हो गया। | अपना कनेक्शन जाँचें और फिर कोशिश करें। |
| वाउचर लागू नहीं हो रहे। | वाउचर हमेशा ड्राई-रन रिव्यू का इंतज़ार करते हैं। | रन खोलें और **Preview & apply** पर क्लिक करें। |
| **Could not save the mapping.** | मैपिंग का अनुरोध फ़ेल हो गया। | फिर कोशिश करें। |
| **Could not resolve the error.** | रिज़ॉल्व का अनुरोध फ़ेल हो गया। | फिर कोशिश करें। |
