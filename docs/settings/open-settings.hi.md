# सेटिंग्स खोलें और कोई सेटिंग खोजें { #open-settings-and-find-a-setting }

अपने प्रोफ़ाइल मेन्यू से **Settings** खोलें और जानें कि वह कैसे सजी है। आपको पता चलेगा कि आपके अकाउंट, टीम, बिलिंग, नोटिफ़िकेशन और मॉड्यूल की सेटिंग्स कहाँ हैं, और स्क्रीन छोड़े बिना हर एक को कैसे खोलें।

## शुरू करने से पहले { #before-you-start }

- आप Ohanvi में साइन इन हों। देखें [Ohanvi में साइन इन करें](../sign-in.md)।

## चरण { #steps }

### सेटिंग्स खोलें { #open-settings }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें। प्रोफ़ाइल मेन्यू खुलता है।
2. **Settings** पर क्लिक करें। **Settings** स्क्रीन खुलती है।

फ़ोन पर, नाम के पहले अक्षरों वाला बटन इसकी जगह ऊपर दाएँ कोने में होता है।

### लेआउट समझें { #read-the-layout }

**Settings** के बाईं ओर वह सब दिखता है जिसे आप कॉन्फ़िगर कर सकते हैं:

- सबसे ऊपर **आपका नाम और ईमेल**। इसमें आपकी टीम, बिलिंग, नोटिफ़िकेशन और डेवलपर सेटिंग्स होती हैं।
- **Workspace** — साझा टूल, जैसे **Integrations**।
- **Modules** — हर उस मॉड्यूल की एक एंट्री जिसे आप खोल सकते हैं, जैसे **WhatsApp**, **CRM**, **Email Marketing** और **Appointments**।

आपको सिर्फ़ वही मॉड्यूल दिखते हैं जिन्हें आपका वर्कस्पेस और आपका रोल खोल सकता है। सूची के ऊपर का सर्च बॉक्स अभी चालू नहीं है।

### कोई सेटिंग खोलें { #open-a-setting }

1. बाईं ओर अपने नाम पर, या **CRM** जैसे किसी मॉड्यूल पर क्लिक करें। उसकी सेटिंग्स की सूची दाईं ओर शीर्षकों के नीचे समूहों में दिखती है।
2. किसी पंक्ति पर क्लिक करें, जैसे **Notifications**। वह सेटिंग दाईं ओर खुलती है।
3. सूची पर लौटने के लिए सेटिंग के ऊपर का बैक लिंक क्लिक करें। उस पर आपका नाम दिखता है, या मॉड्यूल के लिए **<Module> settings**।

सिर्फ़ 1 सेटिंग वाला मॉड्यूल, जैसे **Appointments**, वह सेटिंग सीधे खोल देता है।

### आपके नाम के नीचे क्या है { #what-is-under-your-name }

आपका नाम इन समूहों को खोलता है। आपको सिर्फ़ वही पंक्तियाँ दिखती हैं जो आपका रोल अनुमति देता है।

| समूह | पंक्तियाँ |
| --- | --- |
| **Team & access** | **App User**, **User Group** |
| **Billing & credits** | **Plans & Pricing**, **Billing**, **Invoice Details**, **Credits**, **Current Usage**, **Connectors**, **Refer & Earn** |
| **Preferences** | **Notifications** |
| **Developer** | **Developer APIs** |

अगर सूची में **Nothing to manage with your current role.** दिखे, तो अपने वर्कस्पेस के मालिक से एक्सेस माँगें।

### प्रोफ़ाइल मेन्यू की दूसरी चीज़ें { #other-items-in-the-profile-menu }

- **My Account** खोलने के लिए प्रोफ़ाइल मेन्यू में सबसे ऊपर अपने नाम पर क्लिक करें। देखें [अपनी प्रोफ़ाइल और पासवर्ड अपडेट करें](update-your-profile.md)।
- जब आपके पास 1 से ज़्यादा रोल हों, तब **Switch role** दिखता है। ऐप को उस रोल की तरह देखने के लिए कोई रोल चुनें।
- **Current usage** इस बिलिंग साइकल का आपका ब्योरेवार इस्तेमाल खोलता है।
- **Sign out** आपको साइन आउट करता है।

| **Search settings** में टाइप करने पर कुछ नहीं होता | सेटिंग्स में खोज अभी उपलब्ध नहीं है। | बाईं ओर मॉड्यूल चुनें, फिर उसके समूह देखें। |
