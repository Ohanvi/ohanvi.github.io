# रेफ़र करें और कमाएँ { #refer-and-earn }

दूसरे बिज़नेस को Ohanvi पर बुलाएँ। वो जितने महीने पेमेंट करते रहेंगे, उतने महीने आपको उसका एक हिस्सा मिलेगा। आपका कमीशन पहले आपके अपने प्लान का खर्च भरता है। उसके बाद जो बचे, वो आप निकाल सकते हैं। पेआउट सेट करने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आप एडमिन के तौर पर साइन इन हैं।
- पैसे निकालने के लिए आपके पास अपने नाम का बैंक अकाउंट या UPI ID होना चाहिए।

## स्टेप { #steps }

### रेफ़र करें और कमाएँ खोलें { #open-refer-and-earn }

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **Billing & credits** के नीचे **Refer & Earn** पर क्लिक करें। **Refer & earn** पेज खुलेगा।
3. **How it works** पैनल पढ़ें। कोई बिज़नेस आपके कोड से साइन अप करता है और अपना पहला इनवॉइस भरता है। इसके बाद वो जितने महीने पेमेंट करता रहे, आपको उसके प्लान का एक हिस्सा मिलता है।

### अपना कोड शेयर करें { #share-your-code }

1. **YOUR REFERRAL CODE** ढूँढें।
2. **Copy code** पर क्लिक करें। **Referral code copied** मैसेज आएगा।
3. या **Copy invite link** पर क्लिक करें। **Invite link copied** मैसेज आएगा। यह लिंक उस बिज़नेस को भेज दें।
4. बिज़नेस साइन अप करते समय **Have a referral code?** में आपका कोड भी लिख सकता है। देखें [Ohanvi पर साइन अप करें](../sign-up.md)।

### अपनी कमाई देखें { #read-your-earnings }

1. **Total referred**, **Lifetime earned**, **This month** और **Monthly commission** देखें।
2. **Your plan this month** देखें। जब आपका कमीशन आपके प्लान का खर्च भर देता है, तो **Commission covering your plan** दिखता है। बाकी रकम **Balance beyond your next invoice** में दिखती है।
3. **Referred businesses** में हर बिज़नेस का स्टेटस देखें: **Signed up, not paid**, **Active & paying** या **Stopped paying**।

### पेआउट की जानकारी जोड़ें { #add-payout-details }

1. **Add payout details** पर क्लिक करें। अगर जानकारी पहले से भरी है, तो **Update payout details** या **Change** पर क्लिक करें।
2. **Bank** या **UPI ID** चुनें।
3. बैंक के लिए **Account holder name**, **Bank name**, **Account number** और **IFSC** भरें, जैसे `HDFC0001234`। UPI के लिए अपनी **UPI ID** लिखें, जैसे `name@okhdfcbank`।
4. **Save** पर क्लिक करें। जानकारी एन्क्रिप्ट होकर सेव होती है, और दोबारा पूरी नहीं दिखती। नई जानकारी सेव करने पर पुरानी हट जाती है।

### कमाई निकालें { #withdraw-earnings }

1. **Withdrawable** के नीचे अपना बैलेंस देखें।
2. **Withdraw** या **Request withdrawal** पर क्लिक करें। **Withdraw earnings** विंडो खुलेगी।
3. **Amount** लिखें। रकम दिखाई गई कम से कम रकम से कम नहीं होनी चाहिए, और आपके बैलेंस से ज़्यादा भी नहीं।
4. **Request withdrawal** पर क्लिक करें। **Withdrawal requested — we will review it shortly** मैसेज आएगा।
5. **Withdrawals** में इसका स्टेटस देखते रहें। स्टेटस **Requested** से **Approved** और फिर **Paid** होता है, या **Declined** दिखता है। **Paid** वाली लाइन में UTR भी दिखता है।
6. पैसे 3–5 कामकाजी दिनों में आपके अकाउंट में पहुँच जाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No payout account yet — add one to withdraw.** | पेआउट की कोई जानकारी सेव नहीं है। | **Add payout details** पर क्लिक करें। |
| **Enter a valid IFSC, e.g. HDFC0001234** | IFSC का फ़ॉर्मैट गलत है। | कोड जाँचकर दोबारा लिखें। |
| **Enter a valid UPI ID, e.g. name@okhdfcbank** | UPI ID का फ़ॉर्मैट गलत है। | उसे जाँचकर दोबारा लिखें। |
| **Minimum withdrawal is** और एक रकम | आपकी रकम कम है। | कम से कम उतनी रकम लिखें जितनी दिख रही है। |
| **Could not request the withdrawal.** | रिक्वेस्ट नहीं जा पाई। | दोबारा कोशिश करें। |
