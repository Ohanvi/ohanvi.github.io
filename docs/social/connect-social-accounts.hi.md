# सोशल अकाउंट कनेक्ट करें { #connect-social-accounts }

आप जिन सोशल नेटवर्क पर पोस्ट करते हैं, उन्हें **Social Connections** पेज से कनेक्ट करें। पूरा होने पर नेटवर्क के कार्ड पर **Connected** दिखता है, और उसका चैनल पोस्ट कंपोज़र में चालू हो जाता है। Google Business बिज़नेस जानकारी, रिव्यू और परफ़ॉर्मेंस के लिए अपनी स्क्रीन भी खोल देता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Connect** दिखता हो और उसके पैनल में **Social Connections** हो। अगर नहीं, तो अपने एडमिन से कहें कि आपके रोल को एक्सेस दें। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।
- आप जिस नेटवर्क को कनेक्ट करना चाहते हैं, उसमें साइन इन कर सकते हों। Facebook पेज या LinkedIn कंपनी पेज के लिए, आप उस पेज के एडमिन होने चाहिए।
- Instagram के लिए, अकाउंट प्रोफ़ेशनल अकाउंट (**Business** या **Creator**) हो। निजी Instagram अकाउंट कनेक्ट नहीं हो सकते।

## जिन नेटवर्क को आप कनेक्ट कर सकते हैं { #networks-you-can-connect }

| नेटवर्क | आप क्या कनेक्ट करते हैं | कनेक्ट करने के बाद आप क्या कर सकते हैं |
| --- | --- | --- |
| **Google Business** | एक **Business Location** | लोकल पोस्ट (स्टैंडर्ड, इवेंट, ऑफ़र और अलर्ट), रिव्यू पढ़ना और जवाब देना, परफ़ॉर्मेंस मेट्रिक्स |
| **Facebook** | एक **Page** | टेक्स्ट, लिंक और इमेज पोस्ट, शेड्यूल करके पब्लिश करना, पोस्ट एंगेजमेंट मेट्रिक्स |
| **Instagram** | एक **Business or Creator account** | सिंगल-इमेज पोस्ट, शेड्यूल करके पब्लिश करना |
| **LinkedIn** | एक **Company Page or Profile** | कंपनी पेज से या अपनी प्रोफ़ाइल से टेक्स्ट, लिंक और इमेज पोस्ट |
| **Threads** | एक **Profile** | टेक्स्ट, इमेज और वीडियो पोस्ट, पोस्ट इनसाइट्स |
| **X** | एक **Profile** | टेक्स्ट और इमेज पोस्ट, शेड्यूल करके पब्लिश करना, पोस्ट एंगेजमेंट मेट्रिक्स |

कंपोज़र में YouTube, Vimeo, TikTok, Mastodon और Bluesky के चिप भी दिखते हैं। इन्हें आप अभी कनेक्ट नहीं कर सकते और न इन पर पब्लिश कर सकते हैं।

## चरण { #steps }

### कोई नेटवर्क कनेक्ट करें { #connect-a-network }

1. लेफ़्ट रेल में **Connect** खोलें, फिर **Social Connections** चुनें। **Social Connections** पेज खुलता है, जिसमें हर नेटवर्क का एक कार्ड होता है।
2. नेटवर्क के कार्ड पर **Connect** पर क्लिक करें, उसके बाद नेटवर्क का नाम, जैसे **Connect Facebook**।
3. अगर नेटवर्क कनेक्ट करने के एक से ज़्यादा तरीके देता है, तो **How would you like to connect …?** विंडो खुलती है। एक चुनें:
    - **Instagram**: **Professional** (**Direct Instagram login**, Facebook पेज की ज़रूरत नहीं) या **Via linked Facebook Page** (Meta Business Portfolio से मैनेज होने वाले Instagram अकाउंट के लिए)।
    - **LinkedIn**: **Company Page** (पोस्ट कंपनी की ओर से दिखती हैं) या **Personal Profile** (पोस्ट आपकी ओर से दिखती हैं)।
4. **Permissions requested** के नीचे दी अनुमतियाँ पढ़ें, फिर **Open** पर क्लिक करें, उसके बाद नेटवर्क का नाम। नेटवर्क का साइन-इन एक नई विंडो में खुलता है।
5. नेटवर्क में साइन इन करें और एक्सेस की अनुमति दें। अगर नेटवर्क की विंडो खुली रह जाए तो उसे बंद करें, और Ohanvi पर लौट आएँ।
6. **Continue** पर क्लिक करें।
7. अगर नेटवर्क आपसे पूछे कि किस पर पोस्ट करना है, तो उसे चुनें और **Next** या **Finish** पर क्लिक करें:
    - **Google Business**: **Choose a Google account**, फिर **Choose a location**।
    - **Facebook**: **Choose a Page**।
    - **Instagram via linked Facebook Page**: **Choose the linked Page**, फिर **Choose an Instagram account**।
    - **LinkedIn Company Page**: **Choose a company page**।
8. मैसेज **… connected. Its channel is now available in the Publish composer.** आता है। कार्ड पर अब **Connected** दिखता है।

Threads, X और Instagram के डायरेक्ट लॉगिन में चरण 7 नहीं होता। पोस्ट उसी प्रोफ़ाइल की ओर से जाती हैं जिससे आपने साइन इन किया।

!!! note "ध्यान दें"
    अगर आप आखिरी चरण से पहले विंडो से बाहर निकल जाते हैं, तो Ohanvi पूछता है **… connection in progress**। पूरा करने के लिए **Continue connection** पर क्लिक करें, या **Exit connection** पर क्लिक करें, जिससे आपकी प्रगति खो जाती है।

### ऐप क्रेडेंशियल से कनेक्ट करें { #connect-with-app-credentials }

इसे तभी इस्तेमाल करें जब टोकन आपका अपना डेवलपर ऐप जारी करता हो, या जब आपके वर्कस्पेस पर नेटवर्क में साइन-इन का विकल्प न हो।

1. नेटवर्क के कार्ड पर **Use credentials** पर क्लिक करें। जब साइन-इन उपलब्ध नहीं होता, तो कार्ड पर उसकी जगह **Connect** दिखता है।
2. **Connect … with credentials** विंडो खुलती है। फ़ील्ड भरें, जैसे **App ID**, **App secret** और **Page access token**। मदद के लिए किसी फ़ील्ड के पास **How do I get this?** पर क्लिक करें।
3. **Active** को चालू रखें, ताकि नेटवर्क पब्लिशिंग और बैकग्राउंड सिंक में शामिल रहे।
4. **Connect** पर क्लिक करें।

### जिन पेजों पर आप पोस्ट करते हैं, उन्हें जोड़ें या बदलें { #add-or-change-the-pages-you-post-to }

जो नेटवर्क किसी पेज या लोकेशन पर पोस्ट करते हैं, वे एक से ज़्यादा रख सकते हैं।

1. कनेक्ट किए गए कार्ड पर **Manage** पर क्लिक करें, उसके बाद आइटम का प्रकार, जैसे Google Business कार्ड पर **Manage locations**।
2. **Add** पर क्लिक करें, उसके बाद आइटम का प्रकार, जैसे **Add location**। एक चुनें, फिर **Add** पर क्लिक करें।
3. किसी एक पर पोस्ट करना बंद करने के लिए उसके पास **Remove** पर क्लिक करें। काम पूरा होने पर **Close** पर क्लिक करें।

### कोई नेटवर्क दोबारा कनेक्ट करें { #reconnect-a-network }

Facebook, Instagram और LinkedIn का एक्सेस नेटवर्क की तय की हुई अवधि के बाद खत्म हो जाता है। जहाँ नेटवर्क इजाज़त देता है, वहाँ Ohanvi एक्सेस अपने आप रिन्यू करता है।

- जब एक्सेस 14 दिन या उससे कम में खत्म होने वाला हो, तो कार्ड पर दिखता है **…'s access token expires in N days. Reconnect before then to avoid interrupted publishing.**
- जब नेटवर्क एक्सेस रद्द कर देता है, जैसे पासवर्ड बदलने के बाद, तो कार्ड पर दिखता है **… has revoked access. Reconnect to resume publishing — data already synced is unaffected.**

दोबारा कनेक्ट करने के लिए कार्ड पर **Reconnect** पर क्लिक करें और कनेक्ट करने के चरण दोहराएँ। अगर आप किसी दूसरे अकाउंट से साइन इन करते हैं, तो Ohanvi पुराने को डिस्कनेक्ट कर देता है और मैसेज में यह बता देता है।

### कोई नेटवर्क डिस्कनेक्ट करें { #disconnect-a-network }

1. कनेक्ट किए गए कार्ड पर **Disconnect** पर क्लिक करें। **Disconnect …?** विंडो खुलती है।
2. पुष्टि के लिए **Disconnect** पर क्लिक करें। उस नेटवर्क पर पब्लिश करना बंद हो जाता है। जो पोस्ट पहले पब्लिश हो चुकी हैं, वे पब्लिश रहती हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| कार्ड पर **Unavailable** और **This network is not enabled on this server yet.** दिखता है | नेटवर्क आपके वर्कस्पेस के लिए चालू नहीं है। | अपने एडमिन से उसे चालू करवाएँ, फिर **Refresh** पर क्लिक करें। |
| **This Facebook user administers no Pages.** | आप किसी भी Facebook पेज के एडमिन नहीं हैं। | किसी मौजूदा पेज एडमिन से अपने को एडमिन एक्सेस दिलवाएँ, फिर दोबारा कनेक्ट करें। |
| **No Instagram professional account is linked to that Page.** | Instagram अकाउंट उस पेज से लिंक नहीं है जो आपने चुना। | उसे Meta में लिंक करें, या वापस जाकर **Direct Instagram login** से कनेक्ट करें। |
| **This Google user does not manage any Business Profile accounts.** | आपने ऐसे Google अकाउंट से साइन इन किया जो उस लिस्टिंग को मैनेज नहीं करता। | उस Google अकाउंट से साइन इन करें जो आपकी Business Profile मैनेज करता है। |
| **Connecting … was cancelled — access was not granted.** | आपने नेटवर्क के पेज पर एक्सेस देने से मना कर दिया। | फिर **Connect** पर क्लिक करें और एक्सेस की अनुमति दें। |
| **Could not start the … sign-in.** | आपके वर्कस्पेस पर इस नेटवर्क के लिए साइन-इन सेट नहीं है। | **Use credentials** पर क्लिक करें, या अपने एडमिन से पूछें। |
