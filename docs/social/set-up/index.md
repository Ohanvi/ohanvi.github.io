# Set up Social

Set up connects your social networks to Ohanvi. You connect each network once. The Social panel then lists your channels and lets you start a post.

**Where to find it:** open **Social** in the left rail. The **New** button and **CHANNELS** list are in the panel. Connecting happens in **Connect** → **Social Connections**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Connect social accounts](../connect-social-accounts.md) | You connect, reconnect or disconnect a network. |
| [Use the Social sidebar](../use-the-social-sidebar.md) | You want to start a post or open one channel. |

## Before you start

- You can sign in as an admin of the network, such as the Facebook Page or Google listing you want to use.
