# Zapier कनेक्ट करें { #connect-zapier }

Ohanvi को Zapier से कनेक्ट करें, ताकि आपका CRM, व्हाट्सऐप, फ़ॉर्म और ईमेल बिना कोड के हज़ारों दूसरे ऐप से जुड़ सकें। आप Ohanvi में एक API key बनाते हैं, उसे Zapier में पेस्ट करते हैं, और अपने Zap वहीं बनाते हैं। इसमें लगभग 10 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **Settings** में **Integrations** खोल सकते हैं। अगर यह नहीं दिखता, तो अपने वर्कस्पेस ओनर से कहें।
- आपका zapier.com पर Zapier अकाउंट है।
- आपको पता है कि key का मालिक कौन-सा यूज़र होगा। key उसी यूज़र की अनुमतियों से काम करती है जिसने उसे बनाया है। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](roles-and-permissions.md)।

## Zapier और Ohanvi साथ कैसे काम करते हैं { #how-zapier-and-ohanvi-work-together }

कनेक्शन Zapier शुरू करता है, इसलिए Ohanvi में एक key के अलावा "कनेक्ट" करने जैसा कुछ नहीं है। इस स्क्रीन पर Ohanvi तीन काम करता है:

- यह API keys जारी करता है, उनकी सूची दिखाता है और उन्हें रद्द करता है।
- यह वे **Triggers** (आपके अकाउंट में ऐसा होने पर) और **Searches** (कोई रिकॉर्ड खोजना) दिखाता है जो Ohanvi, Zapier को देता है।
- यह **Popular automations** के नीचे बने-बनाए आइडिया दिखाता है।

आपके बनाए Zap यहाँ सूचीबद्ध नहीं होते। उन्हें अपने Zapier डैशबोर्ड में प्रबंधित करें।

## चरण { #steps }

### Zapier स्क्रीन खोलें { #open-the-zapier-screen }

1. नीचे-बाएँ कोने में अपने इनिशियल पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. बाईं सूची में **Workspace** के नीचे **Integrations** चुनें।
3. **Integration** के नीचे **Zapier** पर क्लिक करें। **Zapier** पेज खुलता है।
4. टाइटल के नीचे की पिल पढ़ें। एक पिल बताती है कि कितनी key चालू हैं, जैसे **1 active key**। कोई न हो तो **No active key yet** लिखा होता है।

### API key बनाएँ { #create-an-api-key }

1. **Create key** पर क्लिक करें। **Create Zapier API key** विंडो खुलती है।
2. **Key name** में अपने लिए कोई नाम लिखें, जैसे `Marketing Zaps`। उसे उन Zap के नाम पर रखें जो वह चलाएगी। यह ज़रूरी है। खाली छोड़ने पर विंडो कहती है **Give the key a name so you can recognise it later.**
3. **Expires after** में **30 days**, **90 days**, **1 year** या **Never expires** चुनें।
4. नीचे का नोट पढ़ें। key आपकी अपनी अनुमतियों से काम करती है। Zapier कितना कुछ छू सकता है, यह सीमित करने के लिए किसी सीमित अनुमति वाले यूज़र के रूप में साइन इन करें और key वहीं बनाएँ।
5. **Create key** पर क्लिक करें। **Connect Zapier** विंडो खुलती है।

### key को Zapier में कॉपी करें { #copy-the-key-into-zapier }

1. **Connect Zapier** विंडो में चेतावनी पढ़ें। key **केवल एक बार** दिखाई जाती है। खो जाए तो नई key बनानी पड़ेगी।
2. **Base URL** कॉपी करें। Zapier इसे माँगता है।
3. **API Key** कॉपी करें। Zapier इसे भी माँगता है।
4. **I have copied my key somewhere safe** पर टिक करें।
5. **Open Zapier** पर क्लिक करें। Zapier नए ब्राउज़र टैब में खुलता है।
6. Zapier में नया Zap शुरू करें, ऐप के रूप में Ohanvi चुनें, और कनेक्ट करने को कहे जाने पर key पेस्ट करें।

### Zap बनाएँ { #build-a-zap }

1. Zapier में कोई ट्रिगर चुनें। जैसे **New Lead**, फिर चुनें कि दूसरे ऐप में क्या होना चाहिए।
2. कनेक्शन जाँचने के लिए Zapier को एक सैंपल रिकॉर्ड खींचने दें।
3. सैंपल सही दिखे तो Zap पब्लिश करें। इसके बाद वह अपने-आप चलता है।

पेज **How to set this up** के नीचे यही चार चरण बताता है: key बनाएँ, Zapier में कनेक्ट करें, ट्रिगर चुनें, टेस्ट करके चालू करें।

### बने-बनाए आइडिया से शुरू करें { #start-from-a-ready-made-idea }

1. **Popular automations** तक स्क्रॉल करें। उसके नीचे की लाइन बताती है कि हर आइडिया Zapier खोलता है, और आप कार्ड पर बताया गया ट्रिगर चुनते हैं।
2. **Bring data in from other apps** में वे आइडिया ढूँढें जो कहीं और से शुरू होते हैं और Ohanvi में रिकॉर्ड बनाते हैं।
3. किसी कार्ड पर **Set up in Zapier** पर क्लिक करें। Zapier खुलता है और पेज एक हिंट दिखाता है, जैसे **In Zapier, choose the "New Lead" trigger.**
4. अगर अभी कोई key नहीं है, तो कार्ड **Create a key first** दिखाते हैं। आगे बढ़ने से पहले key बनाएँ।

आइडिया के उदाहरण: हर नई लीड का व्हाट्सऐप पर स्वागत करें, नई लीड्स को शीट में दर्ज करें, जीती हुई डील्स का जश्न मनाएँ, ऑर्डर शिप होने पर व्हाट्सऐप टेम्प्लेट भेजें, और फ़ॉर्म के जवाबों को लीड्स में बदलें।

### देखें कि आप क्या ऑटोमेट कर सकते हैं { #see-what-you-can-automate }

1. **What you can automate** तक स्क्रॉल करें। उसके नीचे की लाइन बताती है कि ये वे ट्रिगर और सर्च हैं जो यह सर्वर Zapier को देता है।
2. **Triggers** पढ़ें, जिस पर **When this happens in your account…** लिखा है। हर एक एक नाम है जो आपको Zap बनाते समय दिखेगा।
3. **Searches** पढ़ें, जिस पर **Look up a record from another app…** लिखा है।

### key जाँचें या रद्द करें { #check-or-revoke-a-key }

1. **API keys** में हर key पढ़ें। वह अपना नाम, key की शुरुआत, और **Created**, **Last used** और **Expires** दिखाती है।
2. किसी key को रोकने के लिए उसकी पंक्ति पर **Revoke** पर क्लिक करें।
3. **Revoke "name"?** में **Revoke** पर क्लिक करें। इस key का इस्तेमाल करने वाला हर Zap तुरंत काम करना बंद कर देता है। आपको नई key बनानी होगी और उन Zap को Zapier में दोबारा कनेक्ट करना होगा।
4. **Key revoked.** संदेश दिखता है। रद्द और एक्सपायर हुई key रिकॉर्ड के तौर पर सूची में बनी रहती हैं।
5. सूची दोबारा लोड करने के लिए ऊपर **Refresh** पर क्लिक करें।

!!! warning "रद्द करने को वापस नहीं किया जा सकता"
    रद्द की गई key का इस्तेमाल करने वाली हर चीज़ अपने अगले ही अनुरोध पर फ़ेल हो जाती है। अगर Zap को चलते रहना है, तो पहले नई key बना लें।
