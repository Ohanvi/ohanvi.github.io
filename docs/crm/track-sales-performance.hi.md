# CRM डैशबोर्ड पढ़ें { #read-the-crm-dashboard }

देखें कि आज आपकी पाइपलाइन कैसी चल रही है। इस गाइड के बाद आप ओपन पाइपलाइन, जीती हुई डील्स और ठंडी पड़ रही डील्स पढ़ पाएँगे। आप अपनी डील्स की फ़ाइल भी डाउनलोड कर पाएँगे। डैशबोर्ड पढ़ने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **CRM** दिखे, और उसके पैनल में **Dashboard**। इसके लिए CRM रिपोर्ट का एक्सेस चाहिए। न दिखे, तो अपने एडमिन से पूछें।
- आपकी डील्स में स्टेज, रकम और अनुमानित क्लोज़ की तारीख़ भरी हो। आँकड़े इन्हीं से बनते हैं। देखें [डील्स बनाएँ और मैनेज करें](manage-deals.md)।

## स्टेप { #steps }

### डैशबोर्ड पढ़ें { #read-the-dashboard }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Dashboard** चुनें।
2. ऊपर दिखने वाले आँकड़े पढ़ें:
    - **Open pipeline** — सभी ओपन डील्स की कुल कीमत।
    - **Closing this week** — वे ओपन डील्स जिनकी अनुमानित क्लोज़ तारीख़ अगले 7 दिनों में है।
    - **Won** — चुनी हुई अवधि में जीती हुई डील्स।
    - **Win rate** — पूरी हो चुकी डील्स में से कितनी जीती गईं। इसके लिए कम से कम 4 पूरी हो चुकी डील्स चाहिए। **Funnel** खोलने के लिए इस पर क्लिक करें।
    - **Avg deal** — जीती हुई डील का औसत, और सेल्स साइकल में आम तौर पर कितना समय लगता है। **Forecast** खोलने के लिए इस पर क्लिक करें।
    - **Going cold** — वे ओपन डील्स जिन पर 7 दिन या उससे ज़्यादा से कोई काम नहीं हुआ।
3. बंद हो चुकी डील्स के आँकड़ों की अवधि बदलनी हो, तो अवधि वाले बटन पर क्लिक करें। **What should the closed figures cover?** में **This month**, **Last month**, **This quarter**, **This year** या **All time** चुनें।
4. नीचे स्क्रॉल करें और **When the money is due**, **How long since anyone touched them**, **Pipeline**, **Where deals die**, **Where wins come from** और **Won by owner** देखें।
5. अपनी डील्स की CSV फ़ाइल डाउनलोड करने के लिए **Export** पर क्लिक करें।

आप कोई भी अवधि चुनें, ओपन पाइपलाइन, बकाया रकम और ठंडी पड़ चुकी डील्स हमेशा अभी की स्थिति दिखाती हैं।
