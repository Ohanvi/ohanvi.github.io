# व्हाट्सऐप मीडिया लाइब्रेरी प्रबंधित करें { #manage-the-whatsapp-media-library }

जाँचें कि आपका व्हाट्सऐप मीडिया कितना क्लाउड स्टोरेज इस्तेमाल करता है, और जो फ़ाइलें अब ज़रूरी नहीं हैं उन्हें डिलीट करें। अंत में आपको अपनी स्टोरेज सीमा पता होगी और बेकार फ़ाइलें हटकर जगह खाली हो चुकी होगी। इसमें लगभग 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट है। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आप **Media Library** पेज खोल सकते हैं। [VERIFY: यूज़र इसे कैसे खोलते हैं, और इसके लिए कौन-सी रोल अनुमति चाहिए]
- आपको पता है कि कौन-सी फ़ाइलें आप डिलीट कर सकते हैं। डिलीट की गई फ़ाइल वापस नहीं आ सकती।

## मीडिया लाइब्रेरी में क्या होता है { #what-the-media-library-holds }

**Media Library** में वे फ़ाइलें सूचीबद्ध होती हैं जो आप व्हाट्सऐप पर भेजते और पाते हैं, जैसे इमेज, वीडियो, ऑडियो और PDF फ़ाइलें। यह दिखाती है कि वे आपके क्लाउड स्टोरेज का कितना हिस्सा इस्तेमाल करती हैं।

हर पंक्ति में फ़ाइल का नाम, फ़ाइल का प्रकार और साइज़ दिखता है। सूची के ऊपर एक **Cloud storage** कार्ड इस्तेमाल हुई जगह और आपकी सीमा दिखाता है।

!!! note "मीडिया लाइब्रेरी कैसे खोलें"
    फ़िलहाल **WhatsApp** पैनल में **Media Library** का कोई आइटम नहीं है। [VERIFY: यूज़र इसे कैसे खोलते हैं। मेन्यू की एंट्री छिपी है, और डैशबोर्ड पर **Manage storage** बिलिंग खोलता है, यह पेज नहीं]

## चरण { #steps }

### अपना स्टोरेज जाँचें { #check-your-storage }

1. **Media Library** पेज खोलें। इसका टाइटल **Media Library** है, और लाइन है **Stored media and the cloud storage it uses.**
2. **Cloud storage** कार्ड पढ़ें। यह इस्तेमाल हुई जगह और आपकी सीमा दिखाता है, इस रूप में: इस्तेमाल / सीमा।
3. उसके नीचे का बार देखें। बार 80% भरने पर रंग बदलता है, और पूरा भरने पर लाल हो जाता है।
4. जब स्टोरेज भर जाता है, तो कार्ड पर लिखा होता है **Storage full — delete media below to free space, or upgrade your plan.**
5. सूची और आँकड़े दोबारा लोड करने के लिए **Refresh** पर क्लिक करें।

### डिलीट करने के लिए फ़ाइल खोजें { #find-a-file-to-delete }

1. **Cloud storage** कार्ड के नीचे सूची को स्क्रॉल करें।
2. हर पंक्ति पढ़ें। पंक्ति में फ़ाइल का नाम दिखता है, और उसके नीचे फ़ाइल का प्रकार और साइज़, जैसे `image/jpeg · 240 KB`।
3. वे फ़ाइलें चुनें जो सबसे ज़्यादा जगह लेती हैं, या जिन्हें आप अब इस्तेमाल नहीं करते।

### फ़ाइल डिलीट करें { #delete-a-file }

1. पंक्ति पर **Delete** पर क्लिक करें। आइकन एक कूड़ेदान है।
2. **Delete media?** विंडो में फ़ाइल का नाम और साइज़ जाँचें।
3. **Delete** पर क्लिक करें। **Media deleted** संदेश दिखता है, और पंक्ति सूची से हट जाती है।
4. **Refresh** पर क्लिक करें। **Cloud storage** कार्ड आपकी खाली की गई जगह दिखाता है।

!!! warning "डिलीट करने को वापस नहीं किया जा सकता"
    फ़ाइल डिलीट करने से उसका स्टोरेज हमेशा के लिए खाली हो जाता है। अगर आप पक्के नहीं हैं, तो विंडो रद्द कर दें।

### डैशबोर्ड के स्टोरेज अलर्ट पर कार्रवाई करें { #respond-to-the-dashboard-storage-alert }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Dashboard** चुनें।
2. अलर्ट **Cloud storage is full.** या **Cloud storage is** के बाद प्रतिशत और **full.** ढूँढें। यह 80% या उससे ज़्यादा होने पर दिखता है।
3. संदेश पढ़ें। इसमें व्हाट्सऐप मीडिया से इस्तेमाल हुई जगह और आपकी सीमा दिखती है।
4. **Manage storage** पर क्लिक करें। [VERIFY: यह Billing & Usage खोलता है, Media Library नहीं]

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No media stored yet** | व्हाट्सऐप पर अब तक कोई फ़ाइल भेजी या पाई नहीं गई। | कुछ ठीक करने की ज़रूरत नहीं। मीडिया भेजने या पाने के बाद फ़ाइलें दिखने लगती हैं। |
| सूची में लाल एरर दिखता है। | सूची लोड नहीं हुई। | **Refresh** पर क्लिक करें। अगर फिर भी न चले, तो पेज रीलोड करें। |
| **Failed to delete media** | फ़ाइल हट नहीं पाई। | फिर से **Delete** पर क्लिक करें। अगर दो बार फ़ेल हो, तो पेज रीलोड करके एक बार और कोशिश करें। |
| **Cloud storage** कार्ड नहीं दिख रहा। | आपके अकाउंट के लिए कोई स्टोरेज सीमा तय नहीं है। [VERIFY] | अपने एडमिन से कहें। |
| डैशबोर्ड पर **Cloud storage is full.** | आपका व्हाट्सऐप मीडिया आपका स्टोरेज भर रहा है। | यहाँ पुरानी फ़ाइलें डिलीट करें, या अपना प्लान अपग्रेड करें। |
