# फ़ाइल, वॉइस नोट और AI से लिखे जवाब भेजें { #send-files-voice-notes-and-ai-written-replies }

WhatsApp Inbox में आप सिर्फ़ टेक्स्ट ही नहीं, और भी चीज़ें भेज सकते हैं। इस गाइड के अंत तक आप कैप्शन के साथ फ़ाइल या फ़ोटो भेजना सीख जाएँगे। फ़ोन से वॉइस मैसेज रिकॉर्ड करके भेजना भी सीखेंगे। टाइप करने की जगह बोलकर जवाब लिखना सीखेंगे। और AI से अपना जवाब लिखवाना या सुधरवाना भी।

## शुरू करने से पहले { #before-you-start }

- **WhatsApp** पैनल में आपको **Inbox** दिखता हो और कोई चैट खुली हो। देखें [WhatsApp Inbox का इस्तेमाल करें](use-whatsapp-inbox.md)।
- चैट 24 घंटे की विंडो के अंदर हो। विंडो बंद होने के बाद WhatsApp सिर्फ़ अप्रूव्ड Template ही भेजने देता है। देखें [WhatsApp Inbox का इस्तेमाल करें](use-whatsapp-inbox.md#reply-after-the-24-hour-window-closes)।
- **Rephrase with AI** और **Help me write** चलाने के लिए आपकी कंपनी में AI प्रोवाइडर सेट होना चाहिए। [VERIFY: where this is switched on]

## बटन कहाँ हैं { #where-the-buttons-are }

| लेआउट | बटन कहाँ मिलेंगे |
| --- | --- |
| कंप्यूटर | जवाब के बॉक्स के ऊपर टूलबार में **Saved replies**, **Emoji**, **Voice note**, **Rephrase with AI** और **Help me write** हैं। **Document**, **Photo or video**, **Template**, **Emoji**, **Bold**, **Italic**, **Strikethrough** और **Schedule this reply** के लिए **Add to this message** पर क्लिक करें। |
| फ़ोन | टूलबार को साइड में स्क्रॉल कर सकते हैं। उसमें **Attach a document**, **Record a voice message**, **Attach an image**, **Emoji**, **Quick replies ("/")**, **Send a template**, **Bold**, **Rephrase with AI** और **Help me write** हैं। **More** मेन्यू में **Strikethrough**, **Voice to text** और **Schedule this reply** हैं। |

## स्टेप्स { #steps }

### फ़ाइल, फ़ोटो या वीडियो अटैच करें { #attach-a-file-picture-or-video }

1. **WhatsApp** → **Inbox** में कोई चैट खोलें।
2. चाहें तो जवाब के बॉक्स में कैप्शन लिखें। यह टेक्स्ट फ़ाइल का कैप्शन बन जाएगा।
3. कंप्यूटर पर **Add to this message** पर क्लिक करें, फिर **Document** या **Photo or video** चुनें। फ़ोन पर **Attach a document** या **Attach an image** पर टैप करें।
4. अपने डिवाइस से फ़ाइल चुनें। हर विकल्प में यही फ़ाइल चुनने वाली विंडो खुलती है।
5. फ़ाइल अपलोड होने तक रुकें। जब तक अपलोड चल रहा है, बटन पर घूमता हुआ स्पिनर दिखता है।
6. फ़ाइल चैट में भेज दी जाती है। जवाब का बॉक्स खाली हो जाता है और चैट नए मैसेज तक स्क्रॉल हो जाती है।

इनबॉक्स रिबन के **Send Reply** मेन्यू में **Attach file or image** पर क्लिक करके भी फ़ाइल अटैच कर सकते हैं।

इन तरह की फ़ाइलें अटैच हो सकती हैं:

- फ़ोटो: `jpg`, `jpeg`, `png`, `webp`।
- वीडियो: `mp4`, `3gp`।
- डॉक्यूमेंट: `pdf`, `doc`, `docx`, `xls`, `xlsx`, `ppt`, `pptx`, `txt`, `csv`।

कैप्शन फ़ोटो, वीडियो और डॉक्यूमेंट, तीनों के साथ जाता है। एक बार में सिर्फ़ एक फ़ाइल भेज सकते हैं।

### वॉइस मैसेज रिकॉर्ड करके भेजें { #record-and-send-a-voice-message }

वॉइस मैसेज रिकॉर्ड करने का विकल्प फ़ोन पर मिलता है।

1. अपने फ़ोन पर कोई चैट खोलें।
2. माइक्रोफ़ोन पर टैप करें। उस पर टूलटिप **Record a voice message** लिखा आता है।
3. फ़ोन माइक्रोफ़ोन की अनुमति माँगे, तो अनुमति दे दें। मना करने पर मैसेज **Microphone permission was denied.** दिखता है।
4. अब बोलें। एक टाइमर सेकंड गिनता रहता है।
5. बोलना पूरा हो जाए, तो **Stop recording** पर टैप करें। रिकॉर्डिंग हटानी हो, तो **Cancel recording** पर टैप करें।
6. सुनने के लिए **Play preview** पर टैप करें। रोकने के लिए **Pause** पर टैप करें। क्लिप कितनी लंबी है, यह बटनों के पास दिखता है।
7. भेजने के लिए **Send voice message** पर टैप करें। मिटाने के लिए **Discard** पर टैप करें।

ग्राहक को यह WhatsApp ऑडियो मैसेज की तरह मिलता है।

### टाइप करने की जगह बोलकर जवाब लिखें { #speak-a-reply-instead-of-typing-it }

1. कंप्यूटर पर टूलबार में माइक्रोफ़ोन पर क्लिक करें। उस पर टूलटिप **Voice note** लिखा आता है। फ़ोन पर **More** पर टैप करें, फिर **Voice to text** चुनें।
2. ब्राउज़र माइक्रोफ़ोन की अनुमति माँगे, तो अनुमति दे दें।
3. अब बोलें। आपके शब्द जवाब के बॉक्स में कर्सर वाली जगह पर लिखते जाते हैं।
4. रोकने के लिए माइक्रोफ़ोन पर दोबारा क्लिक करें। फ़ोन पर **More** में **Stop listening** पर टैप करें।
5. टेक्स्ट एडिट करें, फिर **Send Reply** पर क्लिक करें।

इससे आपके बोले शब्द टाइप होते हैं। ऑडियो नहीं भेजा जाता।

!!! note "ब्राउज़र सपोर्ट"
    बोलकर जवाब लिखना सिर्फ़ उन ब्राउज़र में चलता है जिनमें स्पीच इनपुट है। बाकी ब्राउज़र में **Voice input is not supported in this browser.** दिखता है।

### AI से जवाब का ड्राफ़्ट बनवाएँ { #draft-a-reply-with-ai }

1. कोई चैट खोलें और **Help me write** पर क्लिक करें। **Help me write** विंडो खुलेगी।
2. एक छोटा निर्देश लिखें, जैसे `ask for their delivery address`।
3. **Generate** पर क्लिक करें, या Enter दबाएँ। जवाब तैयार होने तक स्पिनर दिखता है।
4. ड्राफ़्ट पढ़ें। यह जवाब के बॉक्स में आ जाता है। AI इसे लिखते समय पूरी चैट को देखता है।
5. जो बदलना हो बदलें, फिर **Send Reply** पर क्लिक करें।

ड्राफ़्ट बनाए बिना विंडो बंद करनी हो, तो **Cancel** पर क्लिक करें। निर्देश खाली हो, तो कुछ नहीं होता।

!!! warning "चेतावनी"
    भेजने से पहले ड्राफ़्ट ज़रूर जाँचें। AI तथ्यों में गलती कर सकता है। पहले जवाब पढ़ें और कीमत, तारीख़ और वादे ठीक कर लें।

### AI से अपना ड्राफ़्ट सुधरवाएँ { #rephrase-your-draft-with-ai }

1. जवाब के बॉक्स में अपना जवाब लिखें।
2. **Rephrase with AI** पर क्लिक करें। काम होने तक स्पिनर दिखता है।
3. नए शब्द पढ़ें। ये जवाब के बॉक्स में आपके ड्राफ़्ट की जगह आ जाते हैं।
4. ज़रूरत हो तो एडिट करें, फिर **Send Reply** पर क्लिक करें।

जवाब का बॉक्स खाली हो, तो **Rephrase with AI** कुछ नहीं करता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Upload failed — the file wasn't sent.** | फ़ाइल अपलोड नहीं हुई। | इंटरनेट कनेक्शन देखें, फिर फ़ाइल दोबारा अटैच करें। |
| **Upload failed — no file link came back. Try attaching it again.** | अपलोड पूरा हुआ, पर फ़ाइल का लिंक नहीं मिला। | फ़ाइल दोबारा अटैच करें। |
| **Upload failed.** | अपलोड में कोई गड़बड़ी हुई। | दोबारा कोशिश करें, या छोटी फ़ाइल लें। |
| फ़ाइल चुनने वाली विंडो में फ़ाइल नहीं दिख रही | उसकी तरह (टाइप) लिस्ट में नहीं है। | उसे लिस्ट में दी गई किसी तरह की फ़ाइल में बदलें। |
| **Microphone permission was denied.** | फ़ोन ने माइक्रोफ़ोन रोक रखा है। | फ़ोन की सेटिंग्स में Ohanvi को माइक्रोफ़ोन की अनुमति दें। |
| **Could not start recording.** | रिकॉर्डर माइक्रोफ़ोन चालू नहीं कर सका। | माइक्रोफ़ोन इस्तेमाल करने वाले बाकी ऐप बंद करें, फिर कोशिश करें। |
| **Recording failed.** | रिकॉर्डिंग गड़बड़ी की वजह से रुक गई। | दोबारा रिकॉर्ड करें। |
| **Upload failed — the voice message wasn't sent.** | क्लिप अपलोड नहीं हुई। | इंटरनेट कनेक्शन देखें, फिर दोबारा रिकॉर्ड करें। |
| **The voice message could not be sent. Please try again.** | WhatsApp ने ऑडियो मैसेज नहीं लिया। | दोबारा कोशिश करें। |
| **Voice input is not supported in this browser.** | आपके ब्राउज़र में स्पीच इनपुट नहीं है। | दूसरा ब्राउज़र इस्तेमाल करें, या जवाब टाइप करें। |
| **Rephrase with AI** या **Help me write** में एरर दिखता है | AI प्रोवाइडर से जवाब नहीं मिला। | दोबारा कोशिश करें। फिर भी न चले, तो अपने एडमिन से पूछें। |
