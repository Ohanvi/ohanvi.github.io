# टीम और एक्सेस { #team-and-access }

टीम और एक्सेस में आपकी अपनी प्रोफ़ाइल, आपके वर्कस्पेस के लोग और हर किसी के पास क्या करने की अनुमति है, यह सब रहता है। इससे टीम के सदस्य जोड़ें या हटाएँ और उनके रोल तय करें।

## यह कहाँ मिलेगा { #where-to-find-it }

नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें। अपने नाम के नीचे **Team & access** खोलें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [अपनी प्रोफ़ाइल और पासवर्ड अपडेट करें](../update-your-profile.md) | आप अपना नाम, ईमेल, फ़ोन या पासवर्ड बदलना चाहते हैं। |
| [टीम, रोल और अनुमतियाँ](../roles-and-permissions.md) | आप टीम के सदस्य जोड़ना, एडिट करना या हटाना चाहते हैं, या उनका रोल चुनना चाहते हैं। |
| [लिंक से टीम के सदस्यों को बुलाएँ](../invite-teammates.md) | आप चाहते हैं कि टीम के सदस्य खुद साइन अप करें। |
| [अपना अकाउंट बंद करें](../deactivate-your-account.md) | आप ओनर हैं और पूरा अकाउंट रोकना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आप साइन इन हैं। देखें [Ohanvi में साइन इन करें](../../sign-in.md)।
- टीम और इनवाइट की सेटिंग्स **Super Admin** के लिए हैं।
