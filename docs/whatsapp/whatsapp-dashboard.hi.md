# व्हाट्सऐप डैशबोर्ड पढ़ें { #read-the-whatsapp-dashboard }

अपने मैसेज कैसा कर रहे हैं, यह एक नज़र में देखने के लिए व्हाट्सऐप **Dashboard** का इस्तेमाल करें। इस पेज के अंत तक आप भेजे गए, डिलीवर हुए, पढ़े गए और जवाब मिले मैसेज की संख्या पढ़ सकेंगे, अपनी रोज़ की भेजने की सीमा और क्वालिटी रेटिंग जाँच सकेंगे, और किसी भी संख्या के पीछे का ब्रॉडकास्ट या चैट खोल सकेंगे।

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर कनेक्ट है। जब तक वह नहीं होता, **Dashboard** की जगह कनेक्ट करने के चरण दिखते हैं। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आप **WhatsApp** पैनल में **Dashboard** देख सकते हैं। न दिखे, तो अपने एडमिन से पूछें। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](../settings/roles-and-permissions.md)।

## चरण { #steps }

### डैशबोर्ड खोलें { #open-the-dashboard }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Dashboard** चुनें।
2. डैशबोर्ड खुलता है। वह क्या दिखाता है, यह आपके रोल पर निर्भर करता है:

    | रोल | मुख्य सेक्शन |
    | --- | --- |
    | एडमिन या बिज़नेस ओनर | पूरे बिज़नेस का **Message performance**। |
    | मैनेजर | **Team throughput**, जिसमें **Sent today**, **Running now**, **Waiting for a reply** और **Failed today** हैं। इनबॉक्स पर जाने के लिए **Open shared inbox** पर क्लिक करें। |
    | एग्ज़िक्यूटिव | **Your messages**, जिसमें **Inbox**, **Contacts**, **Chat history** और **Your WhatsApp link** के शॉर्टकट हैं। |

    ![एडमिन के लिए व्हाट्सऐप Dashboard, जिसमें Message performance, Messages per day चार्ट और अकाउंट पैनल है](../assets/screenshots/whatsapp-dashboard-1-overview.png)

### अलर्ट पर कार्रवाई करें { #act-on-alerts }

जब किसी चीज़ पर आपका ध्यान चाहिए, तो डैशबोर्ड के ऊपर एक बार दिखता है। बार के दाईं ओर का बटन दबाएँ:

| बार | बटन | क्या खुलता है |
| --- | --- | --- |
| **2 messages failed.** | **Review failures** | उस अवधि के **Failed messages**। हर मैसेज में संपर्क, कारण (जैसे **Media upload error**) और वह ब्रॉडकास्ट दिखता है जिससे वह आया। हर फ़ेल मैसेज को उसके **Error code** और **Error message** के साथ देखने के लिए नीचे **Open Delivery Logs** पर क्लिक करें। |

### मैसेज का प्रदर्शन पढ़ें { #read-message-performance }

1. अवधि चुनें: **Week**, **Month**, **Quarter** या **Year**। **Message performance** के बगल का टेक्स्ट दिखाता है कि कौन-सी तारीख़ें शामिल हैं, जैसे **Week** के लिए **Monday to today** और **Month** के लिए **This calendar month**।
2. 4 संख्याएँ पढ़ें:

    | संख्या | इसका मतलब |
    | --- | --- |
    | **Sent** | अवधि में भेजे गए मैसेज, और कितने संपर्कों तक पहुँचा जा सकता है। |
    | **Delivered** | वे मैसेज जो फ़ोन तक पहुँचे, भेजे गए मैसेज के हिस्से के रूप में। |
    | **Read** | वे मैसेज जो ग्राहक ने खोले, डिलीवर हुए मैसेज के हिस्से के रूप में। |
    | **Replied** | वे मैसेज जिनका ग्राहक ने जवाब दिया, डिलीवर हुए मैसेज के हिस्से के रूप में। |

    ![Sent, Delivered, Read और Replied संख्याएँ, साथ में Week, Month, Quarter और Year पिकर](../assets/screenshots/whatsapp-dashboard-2-numbers.png)

3. किसी भी संख्या पर क्लिक करके उसके पीछे के मैसेज खोलें। उदाहरण के लिए, **Sent** उस अवधि के **Messages sent** खोलता है। हर मैसेज में संपर्क, उसका स्टेटस (**Sent**, **Delivered**, **Read**, **Replied**) और वह ब्रॉडकास्ट दिखता है जिससे वह आया। किसी मैसेज पर क्लिक करके उसे दाईं ओर पढ़ें।
4. नीचे का **Messages per day** चार्ट पढ़ें। **This period** ठोस लाइन है और **Previous** टूटी हुई लाइन।

चार्ट के नीचे एक पट्टी आपका सबसे ताज़ा ब्रॉडकास्ट और उसके कितने मैसेज भेजे गए, यह दिखाती है, जैसे **1 of 1 sent**। पट्टी पर **Watch** पर क्लिक करके एक साइड पैनल खोलें, जिसमें उसका स्टेटस (जैसे **Completed**), भेजे, डिलीवर हुए, पढ़े गए और फ़ेल हुए मैसेज की गिनती, और पाने वालों की सूची है।

### भेजने की क्षमता और क्वालिटी जाँचें { #check-sending-capacity-and-quality }

चौड़ी स्क्रीन पर दाईं ओर का पैनल आपका अकाउंट दिखाता है:

| आइटम | इसका मतलब |
| --- | --- |
| **Sending capacity** | आज आप कितने लोगों को मैसेज कर सकते हैं। नंबर वेरिफ़ाई होने और मैसेज भेजने के बाद Meta इसे तय करता है। |
| क्वालिटी | **Quality: High**, **Quality: Medium**, **Quality: Low** या **Quality: Not rated yet**। Meta इसे इस आधार पर रेट करता है कि ग्राहक आपके मैसेज पर कैसी प्रतिक्रिया देते हैं। |
| **Plan messages** | इस महीने आपके प्लान में से इस्तेमाल हुए मैसेज, और उससे ज़्यादा मैसेज का चार्ज। **Add credit** बटन इसके नीचे है। |
| बिज़नेस कार्ड | आपके बिज़नेस का नाम, व्हाट्सऐप नंबर और `wa.me` लिंक, साथ में **View Profile** और **Apply for Blue Tick**। |
| **Quick Actions** | **Customize WhatsApp Link** और **Website Chat Widget**। |
| **Setup Progress** | **WhatsApp Business API Connected** और **Business Name Verified by Meta** दोनों पूरे होने तक दिखता है। उसके बाद छिपा रहता है। |

![अकाउंट पैनल, जिसमें Sending capacity, Quality: High, Plan messages, बिज़नेस कार्ड और Quick Actions हैं](../assets/screenshots/whatsapp-dashboard-3-account-panel.png)

जब आप अपनी रोज़ की सीमा का कम से कम आधा इस्तेमाल कर लेते हैं और क्वालिटी **High** रहती है, तो Meta सीमा बढ़ा देता है। जब तक क्वालिटी Medium या Low है, Meta इसे नहीं बढ़ाता।

### हाल के ब्रॉडकास्ट देखें { #check-recent-broadcasts }

1. **Broadcasts** तक स्क्रॉल करें। यह आपके ताज़ा 6 ब्रॉडकास्ट **Audience**, **Delivered**, **Read** और **Replies** के साथ सूचीबद्ध करता है।

    ![Broadcasts तालिका, जिसमें एक ब्रॉडकास्ट और उसके Audience, Delivered, Read और Replies हैं](../assets/screenshots/whatsapp-dashboard-4-broadcasts.png)

2. **Campaign** में कैंपेन की पूरी सूची खोलने के लिए नीचे **View all campaigns** पर क्लिक करें।
3. नया शुरू करने के लिए ऊपर **Start Broadcast** पर क्लिक करें। **New broadcast** डायलॉग खुलता है। देखें [ब्रॉडकास्ट कैंपेन भेजें](send-broadcast-campaign.md)।

    ![New broadcast डायलॉग, जिसमें Campaign name, Who receives it और Message template हैं](../assets/screenshots/whatsapp-dashboard-5-new-broadcast.png)

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Dashboard** में संख्याओं की जगह **Connect WhatsApp** दिखता है | अभी कोई नंबर कनेक्ट नहीं है। | [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md) का पालन करें। |
| **Some WhatsApp data could not load** | डेटा का कुछ हिस्सा लोड नहीं हुआ। | पेज रीफ़्रेश करें। फिर भी दिखता रहे, तो **Configuration** में अपना नंबर जाँचें। |
| **No broadcasts yet** | आपने अभी तक कोई ब्रॉडकास्ट नहीं भेजा है। | **Start Broadcast** पर क्लिक करें। |
| भेजने की क्षमता वही बनी रहती है | क्वालिटी Medium या Low है, या आपने अपनी सीमा का आधे से कम इस्तेमाल किया। | क्वालिटी सुधारें, फिर हर दिन सीमा का कम से कम आधा इस्तेमाल करते रहें। |
| **Cloud storage is full.** | आपका मीडिया स्टोरेज भर गया है। | पुराना मीडिया डिलीट करें या अपना प्लान अपग्रेड करें। **Manage storage** पर क्लिक करें। |
