# Manage branches

Give each branch of your business its own review page, Google listing, QR code, flyer and numbers. You add a branch, confirm its Google listing, and switch between branches on every Google Reviews screen. Adding a branch takes about 5 minutes.

## Before you start

- Your first review page is set up. See [Get more Google reviews](get-more-google-reviews.md).
- Each branch has its own listing on Google Maps.
- You can see **Google Reviews** under **More** on the left rail. If not, ask your admin. See [Team, roles and permissions](../settings/roles-and-permissions.md).

## What each branch has

Each branch is a separate review page. It has its own:

- Google listing, so its customers' reviews go to that branch on Google.
- QR code and link.
- Flyer.
- Settings, questions and names customers can pick.
- **Google Reviews Annual Pack**. A pack covers only the branch you bought it for. See [Buy the Annual Pack for a branch](buy-the-annual-pack.md).
- Stats, private notes, profile check and auto-reply.

Your first review page is your default branch. Until you name it, it shows as **Main branch**.

## Steps

### Add a branch

1. Click **More** on the left rail, then select **Google Reviews** → **Branches**.
2. Click **Add branch** in the top bar. The **Add branch** window opens.
3. In **Branch name**, type a name customers and your team know, such as `Andheri West`. Use 2 to 80 characters.
4. Click **Add branch**. The message **Branch added. Find its Google listing next.** appears, and **Review page** opens for the new branch.
5. Confirm the branch's Google listing. See [Confirm your business on Google](get-more-google-reviews.md#confirm-your-business-on-google).
6. Download the new branch's QR code, or design its flyer. See [Share the QR code or link](get-more-google-reviews.md#share-the-qr-code-or-link).

A new branch starts with the language, questions and flyer of your default branch. Change them on its **Review page** and **Flyer**.

!!! warning "Confirm a listing for every branch"
    A new branch has no Google listing yet. Its QR code and link stay closed until you confirm one. Check the address, so that reviews go to the right branch on Google.

### Switch between branches

When you have 2 or more branches, every Google Reviews screen shows the branch picker above its content: **Review page**, **Flyer**, **Stats**, **Private notes**, **Profile check** and **Auto-reply**.

1. Click **Branch:** followed by the branch name. The list of branches opens. A tick marks the branch you are on, and **Default** marks the default branch.
2. Click a branch. The screen reloads with that branch's page, numbers and settings.

The screens you open next stay on the same branch. The list also has **Add branch**, and **Manage branches**, which opens **Branches**.

With 1 branch, the picker is hidden. Use **Branches** in the menu to add the second one.

### Read the Branches screen

**Branches** shows every branch with its last 30 days:

- The first card, **All** followed by the number of branches, adds up **Scans**, **Drafts made**, **Copies**, **Google opens** and **Private notes** for all branches. **Private notes** also shows how many are unread.
- Each branch card shows the branch name, **Default** on the default branch, and **Live** or **Off**.
- Under the name you see the Google listing's name, rating and address, or **No Google listing yet**.
- The card lists the branch's **Scans**, **Drafts made**, **Copies**, **Google opens** and **Private notes**, and a line such as **2 unread private notes**.
- Click **Open review page** to work on that branch.

The same totals show on **Stats** when you have several branches. See [Read Google review stats](read-google-review-stats.md#compare-branches).

### Rename a branch

1. On **Branches**, click **⋯** on the branch card, then click **Rename**. The **Rename branch** window opens.
2. Type the new name in **Branch name**.
3. Click **Save**. The message **Branch renamed** appears.

### Make a branch the default

The default branch's link is the one Ohanvi uses wherever there is room for only one review link:

- The WhatsApp message in [Ask for a Google review after an appointment](ask-for-a-review-after-an-appointment.md).
- Your store's **Review request** automation, when Ohanvi fills in the link. See [Automate store messages](../flows/store-journeys.md).

To change it:

1. On **Branches**, click **⋯** on the branch card, then click **Make default**. A window asks **Make** followed by the branch name and **the default?**
2. Click **Make default**. A message says the branch is now the default branch, and the **Default** badge moves to it.

### Delete a branch

Delete a branch when it has closed, or when you added it by mistake.

1. On **Branches**, click **⋯** on the branch card, then click **Delete**. A window asks **Delete** followed by the branch name.
2. Read the message: **Its QR code, link and printed flyers stop working, and it leaves your stats. You can't undo this.**
3. Click **Delete branch**. The message **Branch deleted** appears.

!!! warning "Printed QR codes and flyers stop working"
    Customers who scan a deleted branch's QR code or flyer can't reach Google from it. Take its flyers down first.

You can't delete the default branch while you have other branches. Make another branch the default first. You can delete your only branch.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **Name the branch in 2 to 80 characters.** | The name is too short or too long. | Type a name of 2 to 80 characters. |
| **You already have a branch with this name.** | Another branch has the same name, in any mix of capital and small letters. | Pick a different name, such as the area or street. |
| **Delete** is missing on a branch, or you see **Make another branch the default first.** | It is the default branch, and you have other branches. | Make another branch the default, then delete this one. |
| The branch picker doesn't show | You have only 1 branch. | Add a branch on **Branches**. The picker shows from the second branch. |
| A new branch's QR code opens **This review link is not active** | The branch has no confirmed Google listing yet. | Click **Open review page** on its card and confirm its listing. |
| Appointment messages send the wrong branch's link | They always use the default branch. | Make the right branch the default. |
| **Couldn't refresh the branches** | The list didn't load. | Click **Try again**. |
