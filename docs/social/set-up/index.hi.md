# Social सेट करें { #set-up-social }

सेट अप में आप अपने सोशल नेटवर्क को Ohanvi से जोड़ते हैं। हर नेटवर्क सिर्फ़ एक बार कनेक्ट करना होता है। इसके बाद Social पैनल में आपके चैनल की लिस्ट दिखती है, और वहीं से आप पोस्ट शुरू कर सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Social** खोलें। **New** बटन और **CHANNELS** लिस्ट इसी पैनल में हैं। नेटवर्क कनेक्ट करने का काम **Connect** → **Social Connections** में होता है।

## गाइड { #guides }

| गाइड | कब देखें |
| --- | --- |
| [सोशल अकाउंट कनेक्ट करें](../connect-social-accounts.md) | जब आपको कोई नेटवर्क कनेक्ट, दोबारा कनेक्ट या डिस्कनेक्ट करना हो। |
| [सोशल साइडबार का इस्तेमाल करें](../use-the-social-sidebar.md) | जब आपको पोस्ट शुरू करनी हो या कोई एक चैनल खोलना हो। |

## शुरू करने से पहले { #before-you-start }

- आप उस नेटवर्क के एडमिन के तौर पर साइन इन कर पाएँ। जैसे, वह Facebook पेज या Google लिस्टिंग जो आप इस्तेमाल करना चाहते हैं।
