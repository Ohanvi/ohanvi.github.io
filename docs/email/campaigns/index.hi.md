# कैंपेन { #campaigns }

ईमेल कैंपेन बनाएँ, शेड्यूल करें और भेजें, फिर नतीजे पढ़ें।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Email** खोलें, फिर **Campaigns** चुनें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [ईमेल कैंपेन भेजें](../send-email-campaign.md) | आप कैंपेन बनाना और भेजना चाहते हैं। |
| [नतीजे ट्रैक करें और अनसब्सक्राइब संभालें](../track-email-results.md) | आप ओपन, क्लिक और बाउंस देखना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- एक वेरिफ़ाइड सेंडर और सब्सक्राइब किए हुए संपर्कों की एक सूची।
