# Create a WhatsApp message template

Prepare a reusable message that can be approved and used for campaigns, reminders, and automated follow-ups.

## Before you start

- WhatsApp Business account is connected.
- You know the template purpose: marketing, utility, or authentication.
- You have sample values for every variable.

## Write the template

1. Open **WhatsApp Marketing**.
2. Select **Templates**.
3. Choose **Create template**.
4. Enter a short template name, such as `festival_offer_2026`.
5. Choose the language and category.
6. Write the message body in clear customer-facing language.

## Add variables

Use variables for details that change per customer, such as name, order number, appointment date, or offer code.

| Variable | Sample value |
| --- | --- |
| `{{1}}` | Rahul |
| `{{2}}` | OH1234 |
| `{{3}}` | 6 PM today |

Example body:

> Hello `{{1}}`, your order `{{2}}` is ready for pickup. Visit us before `{{3}}`.

## Submit for approval

1. Preview the message for spelling and spacing.
2. Add header, footer, or button content if required.
3. Click **Submit for approval**.
4. Wait for approval status before using the template in broadcasts.

## Use the approved template

1. Open a broadcast or workflow action.
2. Select the approved template.
3. Map variables to contact fields.
4. Send a test before publishing.
