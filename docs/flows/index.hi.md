# फ़्लो { #flows }

फ़्लो चरणों का एक सेट अपने आप चलाता है जब कुछ होता है: कोई ग्राहक कीवर्ड भेजता है, ऑर्डर आता है, कोई संपर्क जुड़ता है, या कोई समय आता है। व्हाट्सऐप चैटबॉट, ऑटोमेशन और स्टोर जर्नी, सब एक ही **Flows** कैनवास पर बनते हैं।

![बिल्डर कैनवास पर चैटबॉट फ़्लो, जिसमें हर बटन के लिए एक शाखा है](../assets/screenshots/flows-overview-5-canvas.png)

## यह कहाँ मिलेगा { #where-to-find-it }

**Flows** 2 जगहों से खुलता है। दोनों एक ही **Automation flows** स्क्रीन खोलते हैं।

- **WhatsApp** → **Flows** — चैटबॉट और व्हाट्सऐप स्टोर मैसेज के लिए।
- **Connect** → **Flows** (**Integration** ग्रुप में, Zapier और Pabbly के बगल में) — कनेक्ट किए गए ऐप्स का इस्तेमाल करने वाले ऑटोमेशन के लिए। यह एंट्री डिफ़ॉल्ट रूप से एडमिन के लिए है, क्योंकि हर चरण फ़्लो के ओनर के रूप में चलता है।

कनेक्टर कैटलॉग, जहाँ आप बाहरी ऐप्स कनेक्ट करते हैं, **Connect** → **Connectors** में है।

## शुरू करने से पहले { #before-you-start }

- आपको **WhatsApp** या **Connect** के नीचे **Flows** दिखता हो। फ़्लो बनाने या बदलने के लिए आपके रोल को फ़्लो का सेव एक्सेस भी चाहिए। इसके बिना स्क्रीन पर **Your role can view flows but not create them.** लिखा आता है।
- फ़्लो जो कुछ इस्तेमाल करता है, वह पहले कनेक्ट हो: आपका व्हाट्सऐप नंबर, आपका स्टोर, या वह ऐप जिसे आप कॉल करना चाहते हैं।
- फ़्लो जो व्हाट्सऐप टेम्प्लेट भेजता है, वे Meta से Approved हों। देखें [व्हाट्सऐप मैसेज टेम्प्लेट बनाएँ](../whatsapp/create-message-template.md)।
