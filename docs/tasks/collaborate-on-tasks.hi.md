# कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें { #comment-mention-and-attach-files }

टास्क के बारे में बातचीत टास्क पर ही रखें। आखिर में आप कमेंट और रिप्लाई कर सकते हैं, किसी टीममेट को @मेंशन करके उन्हें बता सकते हैं, फ़ाइलें और स्क्रीनशॉट अटैच कर सकते हैं, जो टास्क आपका नहीं है उसे फ़ॉलो कर सकते हैं, बिताया हुआ समय लॉग कर सकते हैं, और चुन सकते हैं कि Ohanvi आपको टास्क के बदलावों के बारे में कैसे बताए।

## शुरू करने से पहले { #before-you-start }

- आप कोई सेव किया हुआ टास्क खोल सकते हों। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।
- जिन टीममेट को आप मेंशन करना चाहते हैं, वे आपके वर्कस्पेस के यूज़र हों।

## चरण { #steps }

### कमेंट जोड़ें { #add-a-comment }

1. बोर्ड या **Tasks** पैनल से कोई टास्क खोलें। टास्क डायलॉग खुलता है।
2. **Activity** तक स्क्रॉल करें और **Add a comment...** पर क्लिक करें।
3. अपना कमेंट लिखें। नई लाइन के लिए Shift + Enter दबाएँ।
4. उसे पोस्ट करने के लिए Enter दबाएँ। कमेंट **Comments** के नीचे दिखता है।

जल्दी जवाब के लिए बॉक्स के नीचे कोई तैयार कमेंट चुनें, जैसे **Looks good!**, **Need help?** या **This is blocked...**, फिर उसे एडिट करें और Enter दबाएँ।

### किसी टीममेट को मेंशन करें { #mention-a-teammate }

1. कमेंट में या टास्क के **Description** में `@` लिखें।
2. व्यक्ति के नाम के पहले अक्षर लिखें और सूची में से उन्हें चुनें।
3. कमेंट पोस्ट करें, या डिस्क्रिप्शन के लिए **Save** पर क्लिक करें। Ohanvi आपके मेंशन किए लोगों को "[task key] … mentioned you" सब्जेक्ट के साथ ईमेल भेजता है।

### कमेंट का जवाब दें, उस पर रिएक्ट करें, उसे एडिट करें या डिलीट करें { #reply-to-react-to-edit-or-delete-a-comment }

- **जवाब दें:** कमेंट पर रिप्लाई आइकन (टूलटिप **Reply**) पर क्लिक करें, **Write a reply…** में लिखें और Enter दबाएँ।
- **रिएक्ट करें:** कमेंट पर स्माइली आइकन पर क्लिक करें और कोई इमोजी चुनें। अपना रिएक्शन वापस लेने के लिए इमोजी पर फिर क्लिक करें।
- **एडिट करें:** पेंसिल आइकन (टूलटिप **Edit**) पर क्लिक करें, टेक्स्ट बदलें और सेव करने के लिए Enter दबाएँ।
- **कमेंट का लिंक कॉपी करें:** **More actions** → **Copy link** पर क्लिक करें। **Comment link copied** मैसेज आता है।
- **डिलीट करें:** **More actions** → **Delete** पर क्लिक करें, फिर **Delete comment?** डायलॉग में **Delete** पर क्लिक करें।

!!! warning "चेतावनी: डिलीट किए कमेंट वापस नहीं आ सकते"
    **Delete comment?** कमेंट को हमेशा के लिए हटा देता है।

### फ़ाइलें अटैच करें { #attach-files }

1. टास्क खोलें और **Attachments** तक स्क्रॉल करें।
2. फ़ाइलों को उस बॉक्स पर ड्रैग करें जिस पर **Drop files here to attach them or browse** लिखा है, या **browse** पर क्लिक करें और फ़ाइलें चुनें।
3. फ़ाइलें अपलोड होती हैं और सूची में दिखती हैं। फ़ाइल का अधिकतम साइज़: [LIMIT]।

आप स्क्रीनशॉट या फ़ाइल सीधे **Description** में पेस्ट भी कर सकते हैं। अटैचमेंट देखने के लिए **Preview** (सिर्फ़ इमेज और वीडियो के लिए) या **Download** पर क्लिक करें। किसी को हटाने के लिए उसके डिलीट आइकन पर क्लिक करें और **Delete Attachment** डायलॉग में **Delete** से पुष्टि करें।

### टास्क को वॉच करें { #watch-a-task }

1. टास्क खोलें।
2. डायलॉग के ऊपर आँख के आइकन (टूलटिप **Watch**) पर क्लिक करें।

वॉचर को वही ईमेल मिलते हैं जो टास्क के रिपोर्टर और असाइनी को मिलते हैं। रोकने के लिए आइकन पर फिर क्लिक करें (टूलटिप **Stop watching**)।

### टास्क शेयर करें { #share-a-task }

1. टास्क खोलें।
2. डायलॉग के ऊपर शेयर आइकन (टूलटिप **Share**) पर क्लिक करें। **Copied ticket link: …** मैसेज आता है।
3. लिंक को चैट या ईमेल में पेस्ट करें। जिन टीममेट के पास टास्क का एक्सेस है, वे वही टास्क खोलते हैं।

### समय लॉग करें { #log-time }

1. टास्क खोलें और **Activity** तक स्क्रॉल करें।
2. **Work log** पर क्लिक करें, फिर **Log time** पर क्लिक करें।
3. **Time spent** में समय लिखें, जैसे `1h 30m`। w, d, h और m इस्तेमाल करें। सिर्फ़ संख्या का मतलब मिनट है।
4. **Date** सेट करें और, चाहें तो, **Work description (optional)** भी लिखें।
5. **Save** पर क्लिक करें। एंट्री **Time logged** के नीचे दिखती है।

### टास्क की हिस्ट्री देखें { #see-a-tasks-history }

**Activity** में हर स्टेटस बदलाव, असाइनी बदलाव और एडिट देखने के लिए **History** पर क्लिक करें, जिसमें यह भी दिखता है कि किसने और कब किया। कमेंट और हिस्ट्री एक साथ देखने के लिए **All** पर क्लिक करें।

### चुनें कि टास्क के बदलावों की जानकारी आपको कैसे मिले { #choose-how-you-hear-about-task-changes }

जब कोई टास्क बनता है, असाइन होता है, नए स्टेटस में जाता है या उस पर कमेंट होता है, तो Ohanvi रिपोर्टर, असाइनी और सभी वॉचर को ईमेल भेजता है। आपने खुद जो बदलाव किया, उसके लिए आपको ईमेल नहीं मिलता।

1. लेफ़्ट रेल से **Settings** खोलें, फिर **Notifications** चुनें।
2. **Task Management** वाली पंक्ति ढूँढें ("Assigned tickets, mentions and status changes")।
3. **In-app**, **Push** या **Email** को चालू या बंद करें। **Email** कॉलम सिर्फ़ सुपर एडमिन बदल सकता है।

### टास्क रिमाइंडर पाएँ { #get-task-reminders }

रिमाइंडर वह समय है जब आप चाहते हैं कि किसी टास्क के बारे में आपको याद दिलाया जाए। आप इसे व्हाट्सऐप कॉल नोट से **Remind me on** और **Remind me at** के साथ सेट करते हैं, और Ohanvi उसके लिए एक टास्क बना देता है।

- जब रिमाइंडर का समय निकल जाता है, तो टास्क कार्ड पर **Reminder due** दिखता है, और बोर्ड पर कॉलम के ऊपर **1 reminder due** जैसी पट्टी दिखती है।
- असाइनी को, या किसी के असाइन न होने पर रिपोर्टर को, बेल में नोटिफ़िकेशन मिलता है: **Reminder: [task key] — [summary]**। पुश नोटिफ़िकेशन चालू होने पर यह उनके फ़ोन पर भी जाता है।
- रिमाइंडर के लिए आपके वर्कस्पेस का रिमाइंडर शेड्यूल चालू होना चाहिए। [VERIFY: reminders are enabled in production]

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not save comment.** | कमेंट सर्वर तक नहीं पहुँचा। | आपका टेक्स्ट बॉक्स में बना रहता है। Enter फिर दबाएँ। |
| कोई टीममेट @ सूची में नहीं है | वे आपके वर्कस्पेस के यूज़र नहीं हैं, या अक्षर उनके नाम से नहीं मिलते। | स्पेलिंग जाँचें, या अपने एडमिन से उन्हें यूज़र के रूप में जुड़वाएँ। |
| **Preview is available for images and videos only.** | फ़ाइल PDF, स्प्रेडशीट या कोई और दस्तावेज़ है। | उसे खोलने के लिए **Download** पर क्लिक करें। |
| **Failed to delete attachment.** | डिलीट सेव नहीं हुआ। | टास्क बंद करके दोबारा खोलें, फिर कोशिश करें। |
| **Could not resolve your account to watch.** | Ohanvi आपके लॉगिन को किसी प्रोजेक्ट सदस्य से नहीं मिला पाया। | साइन आउट करके दोबारा साइन इन करें, फिर **Watch** पर फिर क्लिक करें। |
| टास्क के ईमेल नहीं आ रहे | **Task Management** के लिए Email बंद है, या ईमेल स्पैम में चले गए। | **Settings** → **Notifications** जाँचें, फिर अपना स्पैम फ़ोल्डर। |
