# फ़ाइलें, वॉइस नोट और AI से लिखे जवाब भेजें { #send-files-voice-notes-and-ai-written-replies }

व्हाट्सऐप इनबॉक्स में जवाब में सिर्फ़ टेक्स्ट से ज़्यादा जोड़ें। अंत में आप कैप्शन के साथ फ़ाइल या तस्वीर भेज सकते हैं, फ़ोन से वॉइस मैसेज रिकॉर्ड करके भेज सकते हैं, टाइप करने की जगह बोलकर जवाब लिख सकते हैं, और AI से अपने शब्दों का ड्राफ़्ट बनवा या उन्हें निखरवा सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **WhatsApp** पैनल में **Inbox** देख सकते हैं और कोई चैट खुली है। देखें [व्हाट्सऐप इनबॉक्स का इस्तेमाल करें](use-whatsapp-inbox.md)।
- चैट 24 घंटे की विंडो के अंदर है। उसके बाहर व्हाट्सऐप सिर्फ़ मंज़ूर टेम्प्लेट डिलीवर करता है। देखें [व्हाट्सऐप इनबॉक्स का इस्तेमाल करें](use-whatsapp-inbox.md#reply-after-the-24-hour-window-closes)।
- **Rephrase with AI** और **Help me write** इस्तेमाल करने के लिए, आपके संगठन में AI प्रोवाइडर सेट होना चाहिए। [VERIFY: where this is switched on]

## बटन कहाँ हैं { #where-the-buttons-are }

| लेआउट | वे कहाँ मिलते हैं |
| --- | --- |
| कंप्यूटर | जवाब के बॉक्स के ऊपर के टूलबार में **Saved replies**, **Emoji**, **Voice note**, **Rephrase with AI** और **Help me write** हैं। **Document**, **Photo or video**, **Template**, **Emoji**, **Bold**, **Italic**, **Strikethrough** और **Schedule this reply** के लिए **Add to this message** पर क्लिक करें। |
| फ़ोन | टूलबार बगल की ओर स्क्रॉल होता है। उसमें **Attach a document**, **Record a voice message**, **Attach an image**, **Emoji**, **Quick replies ("/")**, **Send a template**, **Bold**, **Rephrase with AI** और **Help me write** हैं। **More** मेन्यू में **Strikethrough**, **Voice to text** और **Schedule this reply** हैं। |

## चरण { #steps }

### फ़ाइल, तस्वीर या वीडियो अटैच करें { #attach-a-file-picture-or-video }

1. **WhatsApp** → **Inbox** में कोई चैट खोलें।
2. वैकल्पिक: जवाब के बॉक्स में कैप्शन लिखें। यह टेक्स्ट फ़ाइल का कैप्शन बन जाता है।
3. कंप्यूटर पर **Add to this message** पर क्लिक करें, फिर **Document** या **Photo or video** चुनें। फ़ोन पर **Attach a document** या **Attach an image** पर टैप करें।
4. अपने डिवाइस से फ़ाइल चुनें। हर विकल्प के लिए वही फ़ाइल पिकर खुलता है।
5. फ़ाइल अपलोड होने तक इंतज़ार करें। पूरा होने तक बटन पर स्पिनर दिखता है।
6. फ़ाइल चैट में भेज दी जाती है। जवाब का बॉक्स खाली हो जाता है और चैट नए मैसेज तक स्क्रॉल हो जाती है।

आप इनबॉक्स रिबन के **Send Reply** मेन्यू में **Attach file or image** पर भी क्लिक कर सकते हैं।

जिन प्रकारों की फ़ाइलें आप अटैच कर सकते हैं:

- तस्वीरें: `jpg`, `jpeg`, `png`, `webp`।
- वीडियो: `mp4`, `3gp`।
- डॉक्यूमेंट: `pdf`, `doc`, `docx`, `xls`, `xlsx`, `ppt`, `pptx`, `txt`, `csv`।

कैप्शन तस्वीरों, वीडियो और डॉक्यूमेंट के साथ जाता है। आप एक बार में एक फ़ाइल भेजते हैं।

### वॉइस मैसेज रिकॉर्ड करके भेजें { #record-and-send-a-voice-message }

वॉइस मैसेज रिकॉर्ड करना फ़ोन के लेआउट में है।

1. अपने फ़ोन पर कोई चैट खोलें।
2. माइक्रोफ़ोन पर टैप करें। उसका टूलटिप **Record a voice message** है।
3. अगर आपका फ़ोन पूछे, तो माइक्रोफ़ोन की अनुमति दें। अगर आप मना करते हैं, तो संदेश **Microphone permission was denied.** दिखता है।
4. बोलें। एक टाइमर सेकंड गिनता है।
5. पूरा होने पर **Stop recording** पर टैप करें। उसे फेंकने के लिए **Cancel recording** पर टैप करें।
6. सुनने के लिए **Play preview** पर टैप करें। रोकने के लिए **Pause** पर टैप करें। क्लिप की लंबाई बटन के बगल में दिखती है।
7. भेजने के लिए **Send voice message** पर टैप करें। डिलीट करने के लिए **Discard** पर टैप करें।

वॉइस मैसेज ग्राहक को व्हाट्सऐप ऑडियो मैसेज के रूप में जाता है।

### टाइप करने की जगह बोलकर जवाब लिखें { #speak-a-reply-instead-of-typing-it }

1. कंप्यूटर पर टूलबार में माइक्रोफ़ोन पर क्लिक करें। उसका टूलटिप **Voice note** है। फ़ोन पर **More** पर टैप करें, फिर **Voice to text**।
2. अगर आपका ब्राउज़र पूछे, तो माइक्रोफ़ोन की अनुमति दें।
3. बोलें। शब्द जवाब के बॉक्स में कर्सर की जगह पर आते हैं।
4. रोकने के लिए माइक्रोफ़ोन पर फिर से क्लिक करें, या **More** में **Stop listening** पर।
5. टेक्स्ट एडिट करें, फिर **Send Reply** पर क्लिक करें।

यह आपके शब्द टाइप करता है। यह ऑडियो नहीं भेजता।

!!! note "ब्राउज़र सपोर्ट"
    बोलकर जवाब लिखना उन ब्राउज़र में काम करता है जो स्पीच इनपुट सपोर्ट करते हैं। दूसरों में **Voice input is not supported in this browser.** दिखता है।

### AI से जवाब का ड्राफ़्ट बनवाएँ { #draft-a-reply-with-ai }

1. कोई चैट खोलें और **Help me write** पर क्लिक करें। **Help me write** विंडो खुलती है।
2. एक छोटा निर्देश लिखें, जैसे `ask for their delivery address`।
3. **Generate** पर क्लिक करें, या Enter दबाएँ। जवाब लिखे जाने तक स्पिनर दिखता है।
4. ड्राफ़्ट पढ़ें। यह जवाब के बॉक्स में भर जाता है और चैट को संदर्भ के रूप में इस्तेमाल करता है।
5. जो चाहिए वह एडिट करें, फिर **Send Reply** पर क्लिक करें।

ड्राफ़्ट के बिना विंडो बंद करने के लिए **Cancel** पर क्लिक करें। खाली निर्देश से कुछ नहीं होता।

!!! warning "चेतावनी"
    भेजने से पहले ड्राफ़्ट जाँच लें। AI तथ्यों में गलती कर सकता है। पहले जवाब पढ़ें और कीमतें, तारीख़ें और वादे ठीक करें।

### AI से अपना ड्राफ़्ट नए ढंग से लिखवाएँ { #rephrase-your-draft-with-ai }

1. जवाब के बॉक्स में अपना जवाब लिखें।
2. **Rephrase with AI** पर क्लिक करें। काम होने तक स्पिनर दिखता है।
3. नए शब्द पढ़ें। वे जवाब के बॉक्स में आपके ड्राफ़्ट की जगह ले लेते हैं।
4. उसे एडिट करें, फिर **Send Reply** पर क्लिक करें।

जवाब का बॉक्स खाली होने पर **Rephrase with AI** कुछ नहीं करता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Upload failed — the file wasn't sent.** | फ़ाइल अपलोड नहीं हुई। | अपना कनेक्शन जाँचें, फिर उसे दोबारा अटैच करें। |
| **Upload failed — no file link came back. Try attaching it again.** | अपलोड बिना लिंक के पूरा हुआ। | फ़ाइल दोबारा अटैच करें। |
| **Upload failed.** | अपलोड में गड़बड़ी हुई। | फिर कोशिश करें, या छोटी फ़ाइल इस्तेमाल करें। |
| फ़ाइल पिकर में फ़ाइल नहीं दिख रही | उसका प्रकार सूची में नहीं है। | उसे सूची में दिए किसी प्रकार में बदलें। |
| **Microphone permission was denied.** | फ़ोन ने माइक्रोफ़ोन ब्लॉक कर दिया। | अपने फ़ोन की सेटिंग्स में Ohanvi के लिए माइक्रोफ़ोन की अनुमति दें। |
| **Could not start recording.** | रिकॉर्डर माइक्रोफ़ोन नहीं खोल सका। | माइक्रोफ़ोन इस्तेमाल करने वाले दूसरे ऐप बंद करें, फिर कोशिश करें। |
| **Recording failed.** | रिकॉर्डिंग गड़बड़ी के साथ रुक गई। | फिर से रिकॉर्ड करें। |
| **Upload failed — the voice message wasn't sent.** | क्लिप अपलोड नहीं हुई। | अपना कनेक्शन जाँचें, फिर दोबारा रिकॉर्ड करें। |
| **The voice message could not be sent. Please try again.** | व्हाट्सऐप ने ऑडियो मैसेज ठुकरा दिया। | फिर कोशिश करें। |
| **Voice input is not supported in this browser.** | आपके ब्राउज़र में स्पीच इनपुट नहीं है। | दूसरा ब्राउज़र इस्तेमाल करें, या जवाब टाइप करें। |
| **Rephrase with AI** या **Help me write** में गड़बड़ी दिखती है | AI प्रोवाइडर ने जवाब नहीं दिया। | फिर कोशिश करें। फिर भी न हो, तो अपने एडमिन से पूछें। |
