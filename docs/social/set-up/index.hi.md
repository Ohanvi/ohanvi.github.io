# सोशल सेट करें { #set-up-social }

सेटअप आपके सोशल नेटवर्क को Ohanvi से जोड़ता है। हर नेटवर्क आपको एक ही बार कनेक्ट करना होता है। इसके बाद Social पैनल आपके चैनल की सूची दिखाता है और आपको पोस्ट शुरू करने देता है।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Social** खोलें। **New** बटन और **CHANNELS** सूची पैनल में हैं। कनेक्ट करना **Connect** → **Social Connections** में होता है।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [सोशल अकाउंट कनेक्ट करें](../connect-social-accounts.md) | आप कोई नेटवर्क कनेक्ट, दोबारा कनेक्ट या डिस्कनेक्ट करते हैं। |
| [सोशल साइडबार का इस्तेमाल करें](../use-the-social-sidebar.md) | आप पोस्ट शुरू करना चाहते हैं या कोई एक चैनल खोलना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आप उस नेटवर्क के एडमिन के रूप में साइन इन कर सकें, जैसे वह Facebook पेज या Google लिस्टिंग जिसे आप इस्तेमाल करना चाहते हैं।
