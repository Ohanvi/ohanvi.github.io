# फ़्लो टेस्ट करें और फ़ेल हुए रन ठीक करें { #test-a-flow-and-fix-failed-runs }

टेस्ट रन शुरू करें, फिर पढ़ें कि हर चरण ने क्या किया और क्या लौटाया। आख़िर में आपको पता होगा कि आपका फ़्लो काम करता है या नहीं, कोई रन क्यों फ़ेल हुआ, और रुके हुए फ़्लो को दोबारा कैसे चालू करें।

## शुरू करने से पहले { #before-you-start }

- फ़्लो कम से कम एक बार पब्लिश हो चुका हो। टेस्ट पब्लिश किया हुआ वर्शन चलाता है, आपका बिना सेव किया ड्राफ़्ट नहीं। देखें [ऑटोमेशन फ़्लो बनाएँ](build-automation-flow.md)।
- आपको फ़्लो के पैनल में **Run test** दिखता हो। इसके लिए फ़्लो सेव करने का एक्सेस चाहिए।

## रन कैसे काम करते हैं { #how-runs-work }

- हर ट्रिगर इवेंट एक **रन** शुरू करता है। रन चरणों से क्रम में गुज़रता है।
- जो चरण फ़ेल होता है, उसे थोड़ी देर रुककर अपने आप दोबारा आज़माया जाता है। जिन चरणों को दोहराना सुरक्षित नहीं है, जैसे कुछ सेंड, उन्हें एक ही बार आज़माया जाता है। रीट्राई के दौरान रन **Running** दिखाता है।
- अगर कोई चरण फिर भी फ़ेल हो, तो रन **Failed** पर खत्म हो जाता है और बाकी चरण नहीं चलते।
- रन **Succeeded**, **Filtered** (किसी कंडीशन से रुका, फ़ेल नहीं हुआ) या **Cancelled** पर भी खत्म हो सकता है। **Waiting** का मतलब है कि कोई चरण टाइमर पर है।

## चरण { #steps }

### सूची से टेस्ट चलाएँ { #run-a-test-from-the-list }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।
2. फ़्लो की पंक्ति पर क्लिक करें।
3. **Run test** पर क्लिक करें। रन चलते समय पंक्ति उसकी स्थिति दिखाती है।
4. संदेश पढ़ें, जैसे **Test run succeeded.** या **Test run failed:** और उसके बाद वजह।

!!! warning "टेस्ट रन असली रन होता है"
    **Run test** पब्लिश किया हुआ वर्शन असली असर के साथ चलाता है। इससे भेजे गए मैसेज असली लोगों तक जाते हैं, और बनाए गए रिकॉर्ड असली होते हैं।

अगर फ़्लो पॉज़ है, तो **Run a test while paused?** विंडो खुलती है। **Run test** पर क्लिक करें। इसके बाद भी फ़्लो पॉज़ ही रहता है।

### बिल्डर से टेस्ट चलाएँ { #run-a-test-from-the-builder }

1. फ़्लो खोलें और टूलबार में **Test** पर क्लिक करें। **Step** पैनल में **Test** टैब खुलता है।
2. **Run test** पर क्लिक करें। अगर आपके बदलाव सेव नहीं हैं, तो फ़्लो पहले सेव होता है।
3. बटन के नीचे की सूची में हर चरण की स्थिति पढ़ें। उसे अपडेट करने के लिए **Refresh** पर क्लिक करें।
4. आप कैनवास के नीचे **Logs** भी खोल सकते हैं और वहाँ **Run test** पर क्लिक कर सकते हैं।

चैटबॉट के लिए, **Test** टैब कीवर्ड जाँचता है और आपको ग्राहक बनकर चैट करने देता है। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)।

### रन हिस्ट्री पढ़ें { #read-the-run-history }

1. सूची में फ़्लो की पंक्ति पर क्लिक करें, फिर **Recent runs** टैब खोलें।
2. हर रन पढ़ें: उसकी स्थिति, कब शुरू हुआ और कितना समय लगा। रन के नीचे लाल नोट गड़बड़ी दिखाता है, जैसे **Step 2 failed:** और उसके बाद वजह।
3. हर चरण, उसकी स्थिति और उसने क्या लौटाया, यह देखने के लिए **View details** पर क्लिक करें।
4. रन को **Latest output** टैब में खोलने के लिए **View output** पर क्लिक करें।

### किसी चरण का आउटपुट पढ़ें { #read-a-steps-output }

1. **Latest output** टैब खोलें। यह सबसे हाल का रन दिखाता है।
2. **Every step** के नीचे किसी चरण पर क्लिक करें। उसका आउटपुट और कोई भी गड़बड़ी दिखती है।
3. **Run id**, **Version pinned**, **Started**, **Finished** और **WHAT STARTED THIS RUN** देखने के लिए **Run details** खोलें।
4. सपोर्ट को देने के लिए आउटपुट कॉपी करने के लिए **Copy JSON** पर क्लिक करें। सबसे नए रन पर लौटने के लिए **Back to latest** पर क्लिक करें।

बिल्डर में, कोई चरण चुनें और उसका **Output** टैब खोलें, ताकि देख सकें कि पिछले रन में उसने क्या बनाया।

### फ़ेल हुए रन को ठीक करें { #fix-a-failed-run }

1. **Recent runs** या **Latest output** में गड़बड़ी पढ़ें।
2. बिल्डर खोलें, फ़ेल हुआ चरण चुनें, और उसे ठीक करें। आम सुधार हैं: खाली फ़ील्ड भरना, गलत टेम्प्लेट नाम बदलना या एक्सपायर हुआ कनेक्शन दोबारा जोड़ना।
3. **Save** पर क्लिक करें, फिर **Publish** पर।
4. सुधार जाँचने के लिए **Run test** पर क्लिक करें।

फ़्लो ठीक करने के बाद फ़ेल हुआ रन अपने आप दोबारा नहीं चलता। अगला ट्रिगर इवेंट नए वर्शन पर नया रन शुरू करता है।

### चल रहे रन रोकें { #stop-runs-in-progress }

1. फ़्लो की पंक्ति पर क्लिक करें, फिर **More** (**…**) खोलें।
2. **Stop runs** पर क्लिक करें। यह विकल्प सिर्फ़ तब दिखता है जब कोई रन चल रहा हो।
3. **Stop the runs in progress?** में **Stop runs** पर क्लिक करें। संदेश **Runs stopped.** दिखता है।

!!! warning "रोके गए रन दोबारा शुरू नहीं किए जा सकते"
    रोके गए रन cancelled के रूप में दर्ज हो जाते हैं और उनके बचे हुए चरण छोड़ दिए जाते हैं। जो चरण पहले से चल रहा है, वह पूरा हो जाता है।

### सिस्टम द्वारा रोका गया फ़्लो दोबारा शुरू करें { #restart-a-flow-the-system-stopped }

अगर **When a record appears** ट्रिगर अपने ऐप तक लगातार कई बार (डिफ़ॉल्ट रूप से 10) नहीं पहुँच पाता, तो Ohanvi फ़्लो को रोक देता है। उसके मालिक को आख़िरी गड़बड़ी के साथ नोटिफ़िकेशन **Automation stopped** मिलता है।

1. कनेक्शन ठीक करें। देखें [कोई ऐप कनेक्ट करें और उसे फ़्लो में इस्तेमाल करें](connect-apps-for-flows.md)।
2. फ़्लो खोलें और बिल्डर टूलबार में **Active** स्विच से उसे फिर चालू करें [VERIFY: how a system-stopped flow is labelled in the list and whether the switch turns it back on]।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **This flow is DRAFT. Only an active or paused flow can be tested.** | फ़्लो कभी पब्लिश नहीं हुआ। | **Publish** पर क्लिक करें, फिर **Run test** पर। |
| **This flow has never been published, so there is no version to run.** | अभी तक कोई पब्लिश किया हुआ वर्शन नहीं है। | पहले फ़्लो पब्लिश करें। |
| **Could not start a run — the flow is at its concurrency limit. Wait for a run to finish and try again.** | इस फ़्लो के बहुत सारे रन एक साथ चल रहे हैं। | किसी रन के खत्म होने का इंतज़ार करें, फिर दोबारा कोशिश करें। |
| **The run stopped at a filter — that is a normal outcome, not a failure.** | **Continue only if…** कंडीशन आपके टेस्ट डेटा से मेल नहीं खाई। | कंडीशन जाँचें, या ऐसे इवेंट से टेस्ट करें जो उससे मेल खाता हो। |
| पंक्ति में **Stuck** दिखता है | कोई रन 6 घंटे से ज़्यादा से चल रहा है या इंतज़ार में है। | **Recent runs** खोलें। **Wait** चरण जानबूझकर किसी रन को कई दिनों तक रोक सकता है। नहीं तो रन रोकें और फिर टेस्ट करें। |
| **Run test** धुंधला (ग्रे) है | फ़्लो में कोई चरण नहीं है, टेस्ट पहले से चल रहा है, या स्टोर या व्हाट्सऐप कनेक्शन नहीं है। | चरण जोड़ें, चल रहे टेस्ट के खत्म होने का इंतज़ार करें, या **Connect store** या **Connect WhatsApp** पर क्लिक करें। |
