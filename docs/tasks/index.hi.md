# टास्क { #tasks }

टास्क Ohanvi का अपना टास्क बोर्ड है। प्रोजेक्ट बनाएँ और काम के हर स्टेप के लिए एक कॉलम जोड़ें। टीम जैसे-जैसे काम करे, टास्क को एक कॉलम से दूसरे में खिसकाते जाएँ।

## कहाँ मिलेगा { #where-to-find-it }

टास्क **दाईं ओर** की रेल में है, नोटिफ़िकेशन बेल और **Help** के पास। यह लेफ़्ट रेल में नहीं है।

- **Tasks** पैनल खोलने के लिए **Tasks** पर क्लिक करें। इसमें **Today**, **Assigned to me** और **Created by me** टैब हैं, साथ में **Create** और **Board** बटन भी।
- पूरा टास्क बोर्ड खोलने के लिए **Board** पर क्लिक करें। इसके टूलबार से आप **Summary**, **Timeline**, **Backlog**, **Board** और **List** व्यू के बीच बदल सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपके रोल को Task एक्सेस मिला है। इसके बिना **Tasks** आइकन नहीं दिखता।
- आपके वर्कस्पेस में कम से कम 1 बोर्ड कॉलम वाला टास्क प्रोजेक्ट है। नया प्रोजेक्ट बिना किसी कॉलम के शुरू होता है। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- जिन सदस्यों को आप काम सौंपना चाहते हैं, वे प्रोजेक्ट के सदस्य हैं। असाइनी की लिस्ट में सिर्फ़ प्रोजेक्ट के सदस्य दिखते हैं।
