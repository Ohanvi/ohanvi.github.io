# वेलकम ईमेल और अपने ब्रोशर सेट करें { #set-up-the-welcome-email-and-your-brochures }

डिफ़ॉल्ट वेलकम मैसेज एक बार सेट करें, और अपने ब्रोशर एक ही लाइब्रेरी में रखें ताकि पूरी टीम उन्हें अटैच कर सके। अंत में **Send Welcome Email** आपके अपने शब्दों से शुरू होगा और आपकी फ़ाइलें अटैच करने के लिए तैयार होंगी। सेटअप में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Contacts** दिखता है, और उसके पैनल में **All contacts** है।
- आपके पास फ़ाइलें तैयार हैं: जैसे कोई बुकलेट या प्राइस लिस्ट।
- आपकी टीम का कोई भी सदस्य आपके अपलोड किए ब्रोशर इस्तेमाल कर सकता है। निजी फ़ाइलें अपलोड न करें।

## चरण { #steps }

### सेटअप विंडो खोलें { #open-the-setup-window }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. ऊपर की बार में **Welcome Email Setup (message + brochures)** आइकन पर क्लिक करें। **Welcome Email Setup** विंडो खुल जाती है।

### डिफ़ॉल्ट मैसेज सेव करें { #save-the-default-message }

1. **Message** के नीचे दिया नोट पढ़ें। उसमें लिखा है कि **Send Welcome Email** पर क्लिक करने पर यही डिफ़ॉल्ट सब्जेक्ट और बॉडी इस्तेमाल होती है। आप हर बार भेजते समय इसे बदल भी सकते हैं।
2. **Subject** लिखें।
3. **Body** लिखें। बॉक्स लंबा है, इसलिए आप कई पंक्तियाँ लिख सकते हैं।
4. **Save** पर क्लिक करें। **Welcome message saved** मैसेज दिखता है।

अगर दोनों बॉक्स खाली हैं, तो विंडो में **Add a subject or message before saving** दिखता है। सेव न हो पाए तो **Could not save. Please retry.** दिखता है।

### ब्रोशर अपलोड करें { #upload-a-brochure }

1. **Brochures** के नीचे दिया नोट पढ़ें: बुकलेट या प्राइस लिस्ट एक बार अपलोड करें और जब चाहें अटैच करें। यह आपकी पूरी टीम के बीच शेयर होता है।
2. **Upload brochure** पर क्लिक करें।
3. अपने कंप्यूटर से फ़ाइल चुनें। जब तक अपलोड पूरा नहीं होता, बटन पर **Uploading…** लिखा रहता है।
4. **Brochure uploaded** मैसेज आने का इंतज़ार करें। फ़ाइल अपने साइज़ के साथ सूची में दिखने लगती है।

ब्रोशर के नियम:

- 25 MB तक की फ़ाइलें। इससे बड़ी फ़ाइल पर **File exceeds the 25 MB limit** दिखता है।
- PDF, PNG, JPG, DOC, DOCX, PPT या PPTX फ़ाइलें इस्तेमाल करें, ताकि वे संपर्क के मेल ऐप में खुल सकें।

अगर अभी कोई ब्रोशर नहीं है, तो सूची में **No brochures yet. Upload a booklet or price list to attach it to emails.** दिखता है।

### ब्रोशर डिलीट करें { #delete-a-brochure }

1. सूची में वह फ़ाइल खोजें।
2. उसके बगल में **Delete** आइकन पर क्लिक करें। **Delete brochure?** विंडो पूछती है **Remove "name" from the library?**
3. **Delete** पर क्लिक करें। **Brochure deleted** मैसेज दिखता है।

फ़ाइल सबके लिए हट जाती है। जो ईमेल पहले ही भेजे जा चुके हैं, उनमें फ़ाइल की कॉपी बनी रहती है।

### ब्रोशर अलग से प्रबंधित करें { #manage-brochures-on-their-own }

1. **Send Welcome Email** विंडो में **Attach brochures** के बगल में **Manage** पर क्लिक करें।
2. **Manage Brochures** विंडो में वही लाइब्रेरी दिखती है, जिसमें **Upload brochure** और हर पंक्ति पर **Delete** होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not read the selected file** | फ़ाइल खुल नहीं सकी। | उसे उसी प्रोग्राम से दोबारा सेव करें और फिर अपलोड करें। |
| **Upload failed. Please retry.** | अपलोड पूरा नहीं हुआ। | **Upload brochure** पर दोबारा क्लिक करें। |
| **Could not delete the brochure** | डिलीट का अनुरोध सर्वर तक नहीं पहुँचा। | थोड़ी देर बाद फिर कोशिश करें। |
| नया डिफ़ॉल्ट मैसेज इस्तेमाल नहीं हो रहा | विंडो बिना सेव किए बंद कर दी गई थी। | **Welcome Email Setup** दोबारा खोलें और **Save** पर क्लिक करें। |
