# कंपोज़र में AI Assistant इस्तेमाल करें { #use-the-ai-assistant-in-the-composer }

**AI Assistant** आपकी पोस्ट के लिए कैप्शन लिखता है और इमेज ढूँढता है। जब तक आप वापस नहीं जाते, यह **Create Post** विंडो के प्रीव्यू वाले हिस्से में खुला रहता है। इसके बाद आप कैप्शन दोबारा लिखवा सकते हैं या इमेज बदल सकते हैं। इसमें करीब 3 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- **Create Post** विंडो खुली होनी चाहिए और उसमें कम से कम एक चैनल चुना होना चाहिए। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।
- आपको पता होना चाहिए कि पोस्ट किस बारे में है। या फिर आप किसी ट्रेंडिंग टॉपिक से शुरू कर सकते हैं।

## स्टेप { #steps }

### Assistant खोलें { #open-the-assistant }

1. **Create Post** में सबसे ऊपर **AI Assistant** पर क्लिक करें। इसका नाम बदलकर **Close AI Assistant** हो जाएगा।
2. **Writing for …** वाली लाइन पढ़ें। इसमें आपके चुने हुए चैनलों के नाम होते हैं। Assistant उन चैनलों में से सबसे कम लिमिट वाले के हिसाब से लिखता है।
3. Assistant से बाहर आने के लिए पीछे वाले तीर (**Back to preview**) पर क्लिक करें।

### पोस्ट के बारे में बताएँ { #describe-the-post }

1. **What should this post be about?** के नीचे अपना टॉपिक लिखें। जैसे: `Diwali sale on ethnic wear`।
2. अगर कंपोज़र में पहले से कैप्शन है, तो इस बॉक्स में **Write something new** लिखा होता है।
3. इमेज नहीं चाहिए, तो **Caption only, no image** पर टिक करें।
4. **Generate post** पर क्लिक करें। बटन पर **Generating…** लिखा आएगा, और पैनल में **Writing your caption and finding an image…** दिखेगा।
5. काम पूरा होने पर कैप्शन और इमेज कंपोज़र में आ जाएँगे।

### ट्रेंडिंग टॉपिक से शुरू करें { #start-from-a-trending-topic }

1. **Or start from what's trending** के नीचे, दाईं तरफ़ की लिस्ट में से कोई टॉपिक एरिया चुनें।
2. किसी टॉपिक चिप पर क्लिक करें। Assistant ज़्यादा से ज़्यादा 20 टॉपिक दिखाता है।
3. **Generate post** पर क्लिक करें।
4. अगर टॉपिक वाले बॉक्स में पहले से कुछ लिखा है, तो चिप की जगह आपका लिखा टेक्स्ट इस्तेमाल होगा।

पैनल में **Trending topics aren't available right now — type your own above.** लिखा आए, तो अपना टॉपिक खुद लिखें। अगर किसी टॉपिक एरिया में कुछ ट्रेंड नहीं कर रहा, तो **No trending topics for this area right now — try another, or type your own above.** लिखा आता है।

### कैप्शन दोबारा लिखवाएँ { #rewrite-the-caption }

1. कैप्शन बनने के बाद **Refine your caption** ढूँढें।
2. इनमें से किसी एक बटन पर क्लिक करें:
    - **Rephrase** वही बात नए शब्दों में लिख देता है।
    - **Shorten to N** कैप्शन को इतना छोटा करता है कि वह आपके चैनलों की सबसे कम लिमिट में आ जाए। `N` वही लिमिट है।
    - **Expand** कैप्शन को लंबा करता है।
    - **More casual** कैप्शन को दोस्ताना बना देता है।
    - **More formal** कैप्शन को ज़्यादा प्रोफ़ेशनल बना देता है।
3. काम होते समय बटन पर घूमता हुआ स्पिनर दिखता है। फिर कंपोज़र का कैप्शन बदल जाता है।

### इमेज बदलें { #swap-the-image }

1. **Image** के नीचे **Search words, e.g. diwali lights** में शब्द बदलें। शुरू में यहाँ वही शब्द होते हैं जो AI ने चुने थे।
2. **Change image** पर क्लिक करें। ढूँढते समय इस पर **Finding…** लिखा रहता है।
3. नई इमेज पुरानी इमेज की जगह आ जाएगी। कैप्शन नहीं बदलेगा।

### पोस्ट पूरी करें { #finish-the-post }

1. हर चैनल पर पोस्ट कैसी दिखेगी, यह देखने के लिए पीछे वाले तीर (**Back to preview**) पर क्लिक करें।
2. **Publish Now**, **Save Draft** या **Schedule** पर क्लिक करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Generate post** ग्रे है | टॉपिक वाला बॉक्स खाली है और कोई ट्रेंड भी नहीं चुना। | कोई टॉपिक लिखें, या किसी ट्रेंड चिप पर क्लिक करें। |
| Assistant लाल रंग में एरर दिखाता है | AI काम पूरा नहीं कर पाया। | **Generate post** पर फिर से क्लिक करें, या अपना टॉपिक छोटा करें। |
| **Change image** से सही इमेज नहीं मिलती | सर्च के शब्द बहुत आम हैं। | ज़्यादा साफ़ शब्द लिखें, फिर **Change image** पर दोबारा क्लिक करें। |
| कैप्शन किसी चैनल के लिए बहुत लंबा है | Assistant सबसे कम लिमिट के हिसाब से लिखता है, पर आपने कैप्शन एडिट करके बढ़ा दिया। | **Shorten to N** पर क्लिक करें। |
