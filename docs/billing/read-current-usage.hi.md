# अपना मौजूदा इस्तेमाल पढ़ें { #read-your-current-usage }

**Current usage** पेज पर देखें कि किसी बिलिंग साइकल में आपके क्रेडिट कहाँ खर्च हुए। आपको हर प्रोडक्ट का हर रेट पर खर्च, साइकल के बाकी दिनों का अनुमान, और एक CSV फ़ाइल मिलती है जिसे आप अपनी अकाउंट्स टीम को भेज सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आप Ohanvi में साइन इन हैं। देखें [Ohanvi में साइन इन करें](../sign-in.md)।
- आप जानते हैं कि क्रेडिट कैसे काम करते हैं। देखें [Credits and billing in Ohanvi](../credits-and-billing.md)।
- आप अपने वर्कस्पेस के एडमिन हैं। बिलिंग के पेज सिर्फ़ आपके वर्कस्पेस के अपने एडमिन को दिखते हैं। अगर आप इन्हें नहीं खोल पा रहे, तो अपने एडमिन से पूछें।

## बिलिंग साइकल कैसे काम करते हैं { #how-billing-cycles-work }

- एक बिलिंग साइकल एक कैलेंडर महीने का होता है, महीने की 1 तारीख से आखिरी दिन तक।
- चल रहा साइकल बताता है कि आप उसमें कितना आगे बढ़ चुके हैं, जैसे **Cycle 1 Sep – 30 Sep · day 25 of 30**।
- पूरा हो चुका साइकल दिनों की गिनती की जगह **closed** दिखाता है।
- आप मौजूदा साइकल और उससे पहले के 5 साइकल देख सकते हैं।
- 1 तारीख को कुछ भी देय नहीं होता। हर शुल्क होते ही आपके क्रेडिट बैलेंस से कट जाता है।

## चरण { #steps }

### Current usage खोलें { #open-current-usage }

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें। प्रोफ़ाइल मेन्यू खुलता है।
2. **Current usage** पर क्लिक करें। **Current usage** पेज खुलता है।

आप **Credits** पेज के ऊपर से भी **Current usage** पर क्लिक कर सकते हैं।

### साइकल चुनें { #pick-a-cycle }

1. ऊपर दाईं ओर साइकल चिप पर क्लिक करें, जैसे **Cycle 1 Sep – 30 Sep · day 25 of 30**। हाल के साइकल की सूची खुलती है।
2. अपना मनचाहा महीना चुनें, जैसे **Aug 2026**। मौजूदा महीने पर **this cycle** लिखा होता है।
3. पेज के सारे कार्ड उसी साइकल के हिसाब से अपडेट हो जाते हैं।

### कार्ड पढ़ें { #read-the-cards }

| कार्ड | यह क्या बताता है |
| --- | --- |
| **Spend by product** | इस साइकल का खर्च प्रोडक्ट के हिसाब से बँटा हुआ, जैसे **WhatsApp messages**, **AI replies**, **Email delivered**, **Extra messages over plan** और **Social posts**। |
| **Biggest line items** | आपके 6 सबसे बड़े खर्च। हर लाइन एक रेट पर एक प्रोडक्ट है, साथ में कुल खर्च में उसका हिस्सा। |
| **Breakdown** | साइकल का हर शुल्क, प्रोडक्ट के हिसाब से समूहित। कॉलम: **RATE LINE**, **CHARGES**, **USED**, **PERIOD** और **COST**, और हर प्रोडक्ट का **SUBTOTAL**। |
| **Cost this cycle** | **Actual**: **Used so far** और **Credit balance now**। चल रहे साइकल के लिए **Forecast** (आज के रेट पर): **Rest of the cycle**, **Cycle total**, और **Left at cycle end** या **Short by**। |

!!! tip "फ़ोरकास्ट कैसे पढ़ें"
    फ़ोरकास्ट मानता है कि आप आज की रोज़ाना दर से खर्च करते रहेंगे। अगर यह **Short by** दिखाए, तो महीने के खत्म होने से पहले आपका बैलेंस खत्म हो जाएगा। कार्ड में **Recharge credits** बटन दिखता है। देखें [पैसे जोड़ें](../add-funds.md)।

### इस्तेमाल को CSV में एक्सपोर्ट करें { #export-the-usage-as-csv }

1. जिस साइकल को एक्सपोर्ट करना है उसे चुनें।
2. पेज के ऊपर **Export CSV** पर क्लिक करें। `usage-2026-09.csv` जैसे नाम की फ़ाइल डाउनलोड होती है और **Usage downloaded.** दिखता है।
3. फ़ाइल को Excel या Google Sheets में खोलें।

फ़ाइल में हर रेट लाइन की एक पंक्ति होती है, जिसके कॉलम हैं **Product**, **Category**, **Rate**, **Charges**, **Quantity**, **Cost**, **First** और **Last**। आखिरी 3 पंक्तियों में **Used so far this cycle**, **Projected to cycle end** और **Credit balance now** होते हैं।

जब तक साइकल में कम से कम एक शुल्क न हो, **Export CSV** ग्रे रहता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No usage yet this cycle.** | चुने हुए साइकल में कोई पेड मैसेज नहीं भेजा गया। | पहले का कोई साइकल चुनें, या अपना पहला पेड मैसेज भेजें। |
| **Export CSV** ग्रे है | चुने हुए साइकल में अभी कोई शुल्क नहीं है। | ऐसा साइकल चुनें जिसमें शुल्क हों। |
| **Failed to load this cycle’s usage.** | पेज Ohanvi तक नहीं पहुँच पाया। | पेज के ऊपर **Refresh** पर क्लिक करें। अगर फिर भी न चले, तो साइन आउट करके दोबारा साइन इन करें। |
| **Cost this cycle** में **Short by** दिख रहा है | आज के रेट पर आपका बैलेंस महीने के आखिर तक नहीं चलेगा। | अगला कैंपेन चलाने से पहले रीचार्ज करें। देखें [पैसे जोड़ें](../add-funds.md)। |
| 6 महीने से पुराना साइकल नहीं मिल रहा | साइकल पिकर में सिर्फ़ मौजूदा साइकल और उससे पहले के 5 साइकल दिखते हैं। | अपना स्टेटमेंट डाउनलोड करने के लिए **Credits** पेज पर **Export CSV** इस्तेमाल करें। देखें [स्टेटमेंट और इनवॉइस](statement-and-invoices.md)। |
