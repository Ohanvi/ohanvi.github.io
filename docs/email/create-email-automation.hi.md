# जर्नी से ईमेल ऑटोमेट करें { #automate-emails-with-journeys }

ऐसा ऑटोमेशन फ़्लो (जर्नी) बनाएँ जो संपर्कों को अपने-आप ईमेल भेजे, जैसे किसी के आपकी न्यूज़लेटर लिस्ट में जुड़ने पर वेलकम सीरीज़। आखिर में फ़्लो **Active** होता है, और शुरुआती शर्त पूरी करने वाला हर नया संपर्क बिना आपके कुछ भेजे उसके चरणों से गुज़रता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Email** दिखे और उसके पैनल में **Flows** हो। अगर नहीं दिखता, तो अपने एडमिन से एक्सेस माँगें।
- आपके पास एक वेरिफ़ाइड भेजने वाला पता और कम से कम 1 Approved ईमेल टेम्प्लेट हो। देखें [भेजने वाला पता सेट करें और अपना डोमेन वेरिफ़ाई करें](set-up-sender-identity.md) और [ईमेल टेम्प्लेट बनाएँ](create-email-template.md)।
- मंज़ूरी का एक्सेस रखने वाला कोई टीम सदस्य उपलब्ध हो। जो फ़्लो आपने खुद बनाया है, उसे आप खुद एक्टिवेट नहीं कर सकते।
- फ़्लो से भेजा गया हर ईमेल क्रेडिट इस्तेमाल करता है। देखें [क्रेडिट और बिलिंग](../credits-and-billing.md)।

## चरण { #steps }

### फ़्लो शुरू करें { #start-a-flow }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Flows** चुनें। साझा **Flows** स्क्रीन खुलती है। ईमेल ऑटोमेशन उसी कैनवास पर बनते हैं जिस पर बाकी चैनलों के फ़्लो बनते हैं। देखें [ऑटोमेशन फ़्लो बनाएँ](../flows/build-automation-flow.md)। पुरानी जर्नी **Not yet migrated** के नीचे दिखती हैं।
2. शुरू करने का तरीका चुनें:
    - शुरुआती फ़्लो चुनने के लिए **Choose flow template** पर क्लिक करें, जैसे **Single Welcome Email**, **Simple 2-Email Nurture**, **Welcome Series (3 emails)**, **Tag Engaged Contacts** या **Win-Back Then Sunset**।
    - खाली फ़्लो के लिए **Build from scratch** पर क्लिक करें।
3. **Build a New Flow** पेज खुलता है। सब कुछ इसी 1 पेज पर सेट होता है।

### फ़्लो का नाम रखें और शुरुआत चुनें { #name-the-flow-and-choose-what-starts-it }

1. **Journey Name** में ऐसा नाम लिखें जिसे आपकी टीम पहचान सके, जैसे `New Subscriber Welcome`।
2. शुरुआती बिंदु चुनें:

    | शुरुआती बिंदु | कब शुरू होता है | और क्या भरें |
    | --- | --- | --- |
    | **Signs up for email** | कोई संपर्क आपकी चुनी हुई लिस्ट में जुड़ता है, उस लिस्ट के साइनअप फ़ॉर्म से आए साइनअप भी इसमें आते हैं। | **Trigger List (enroll on join)** |
    | **Tag added** | आपका चुना हुआ टैग किसी संपर्क पर लगता है, हाथ से, बल्क में या इम्पोर्ट से। | **Trigger Tag (enroll when added)** |
    | **Birthday** | संपर्क का जन्मदिन है, या उससे तय दिन पहले। | **Days Before Birthday** (0–365) |
    | **Abandons a cart** | कोई खरीदार आपके कनेक्ट किए स्टोर पर चेकआउट बिना भुगतान किए छोड़ देता है। अगर वह खरीद लेता है, तो यह अपने-आप रद्द हो जाता है। | — |

3. वैकल्पिक: **Filter contacts** के नीचे ऐसी शर्तें जोड़ें जो तय करें कि फ़्लो में किन्हें लिया जाए।

### चरण जोड़ें { #add-the-steps }

1. **Sender** चुनें।
2. पैलेट से चरणों को फ़्लो मैप पर खींचकर रखें:
    - **Send Email** — **Template \*** चुनें।
    - **Wait** — **Wait (minutes) \*** सेट करें। जैसे, 1440 मिनट यानी 1 दिन।
    - **Tag Contact** और **Remove Tag** — टैग जोड़ें या हटाएँ।
    - **If/Else** — **Field**, **Operator** और **Value \*** के आधार पर शाखा बनाएँ।
    - **Split Path (A/B)** — संपर्कों को बराबर-बराबर 2 रास्तों में बाँटें।
    - **Unsubscribe** — संपर्क को आगे के सभी ईमेल से अनसब्सक्राइब करें।
    - **Webhook** — किसी दूसरे सिस्टम में **Webhook URL \*** को कॉल करें।
3. चरणों का क्रम बदलने के लिए उन्हें खींचें।
4. **Check everything before saving** के नीचे दिया सारांश जाँचें।
5. **Save Flow** पर क्लिक करें। फ़्लो **Draft** के रूप में सेव होता है। वह अभी चलता नहीं।

कार्ट वाले ईमेल के लिए टेम्प्लेट में `{{cartValue}}`, `{{cartItems}}` और `{{recoveryUrl}}` इस्तेमाल करें।

### फ़्लो चालू करें { #turn-the-flow-on }

1. किसी टीम सदस्य से **Flows** खोलने को कहें।
2. वे फ़्लो पर **⋮** (**More actions**) पर क्लिक करें, फिर **Activate** पर क्लिक करें। स्टेटस **Active** हो जाता है।

नए संपर्कों का आना रोकने के लिए **⋮** → **Pause** पर क्लिक करें। जो संपर्क पहले से फ़्लो में हैं, वे जहाँ हैं वहीं रुके रहते हैं, जब तक आप फ़्लो फिर से एक्टिवेट न करें। फ़्लो की कॉपी बनाने के लिए **⋮** → **Clone** पर क्लिक करें।

!!! note "ध्यान दें"
    चालू फ़्लो को एडिट करने के लिए पहले उसे पॉज़ करें, बदलाव करें, फिर उसे दोबारा एक्टिवेट करें।

## फ़्लो के स्टेटस { #flow-statuses }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | सेव है और एडिट किया जा सकता है। कोई संपर्क जुड़ा नहीं है। |
| **Active** | संपर्कों को जोड़ रहा है और ईमेल भेज रहा है। |
| **Paused** | नए संपर्क नहीं जुड़ते, और फ़्लो में पहले से मौजूद संपर्क आगे नहीं बढ़ते। |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **You cannot activate your own journey.** | फ़्लो चालू करने के लिए दूसरे व्यक्ति की ज़रूरत होती है। | मंज़ूरी का एक्सेस रखने वाले टीम सदस्य से **Activate** पर क्लिक करने को कहें। |
| **Journey has no steps.** या **A journey needs at least one step.** | फ़्लो मैप खाली है। | मैप पर कम से कम 1 **Send Email** चरण खींचकर रखें। |
| **Pause the journey before editing it.** | फ़्लो **Active** है। | **Pause** पर क्लिक करें, एडिट करें, फिर दोबारा एक्टिवेट करें। |
| **A journey named '…' already exists.** | यह नाम पहले से लिया जा चुका है। | कोई दूसरा **Journey Name** रखें। |
| **Trigger tag is required for a Tag Added journey.** | **Tag added** चुना गया है पर टैग नहीं दिया। | **Trigger Tag (enroll when added)** भरें। |
| **Enter a whole number of days between 0 and 365** | **Days Before Birthday** सीमा से बाहर है। | 0 से 365 के बीच की संख्या लिखें। |
