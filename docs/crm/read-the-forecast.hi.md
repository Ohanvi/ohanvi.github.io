# सेल्स फ़ोरकास्ट पढ़ें { #read-the-sales-forecast }

देखें कि आपकी खुली डील से कितनी कमाई होने की उम्मीद है, और यह आपके टारगेट के कितने पास है। इस गाइड के बाद आप एक ही स्क्रीन देखकर बता पाएँगे कि "क्या हम इस महीने का टारगेट पूरा करेंगे?" फ़ोरकास्ट पढ़ने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **CRM** दिखना चाहिए, और उसके पैनल में **Forecast**। इसके लिए CRM रिपोर्ट का एक्सेस चाहिए। न दिखे, तो अपने एडमिन से कहें।
- आपकी डील में स्टेज, रकम और अनुमानित क्लोज़ की तारीख भरी हो, क्योंकि आँकड़े इन्हीं से बनते हैं। देखें [डील बनाएँ और मैनेज करें](manage-deals.md)।
- कोटा के आँकड़े देखने के लिए पहले कोटा सेट करें। देखें [सेल्स कोटा सेट करें](set-sales-quotas.md)।

## स्टेप { #steps }

### फ़ोरकास्ट खोलें { #open-the-forecast }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Forecast** चुनें।

### तीनों आँकड़े पढ़ें { #read-the-three-figures }

1. **Weighted forecast** पढ़ें। यह हर खुली डील की कीमत को उसके जीतने की संभावना से गुणा करके निकलता है।
2. **Open pipeline** पढ़ें। अगर हर खुली डील जीत ली जाए, तो यह सबसे अच्छी हालत की रकम है।
3. **Committed** पढ़ें। यह उन डील की वेटेड कीमत है जो 80% या उससे ऊपर वाले स्टेज में हैं।

### चार्ट पढ़ें { #read-the-charts }

1. **Weighted pipeline by stage** पढ़कर देखें कि पैसा किस स्टेज में अटका है।
2. **Quota attainment** पढ़कर देखें कि महीने के कोटा में कितना काम हो चुका है।
3. **3-month forecast** पढ़ें। इस चार्ट में **Committed** वह रकम है जो पहले ही जीती जा चुकी है। **Upside** खुली डील की वेटेड कीमत है।

### फ़ोरकास्ट डाउनलोड करें { #download-the-forecast }

1. **Export** पर क्लिक करें।
2. फ़ोरकास्ट की फ़ाइल डाउनलोड हो जाती है।

### कोटा खोलें { #open-the-quotas }

1. **Manage quotas** पर क्लिक करें। **Sales Quotas** की लिस्ट खुलती है।
2. नया टारगेट जोड़ने के लिए [सेल्स कोटा सेट करें](set-sales-quotas.md) देखें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| आँकड़े 0 हैं | आपकी खुली डील में रकम या क्लोज़ की तारीख नहीं भरी है। | अपनी डील में **Amount** और **Expected close** भरें। |
| **Quota attainment** खाली है | इस समय के लिए कोई कोटा सेट नहीं है। | कोटा जोड़ें। देखें [सेल्स कोटा सेट करें](set-sales-quotas.md)। |
| **CRM** पैनल में **Forecast** नहीं है | आपके रोल के पास CRM रिपोर्ट का एक्सेस नहीं है। | अपने एडमिन से कहें। |
