# सप्रेशन लिस्ट से पते ब्लॉक करें { #block-addresses-with-the-suppression-list }

सप्रेशन लिस्ट में वे सभी पते होते हैं जिन पर आपके अकाउंट से कभी ईमेल नहीं जाना चाहिए। बाउंस, शिकायतें और अनसब्सक्राइब अपने-आप यहाँ आ जाते हैं, और आप पते हाथ से भी जोड़ सकते हैं। अंत में हर कैंपेन, जर्नी और डाइजेस्ट ब्लॉक किए गए पते छोड़ देता है।

## शुरू करने से पहले { #before-you-start }

- **Email** पैनल में आपको **Manage** दिखता हो। न दिखे तो अपने एडमिन से कहें।
- हाथ से ब्लॉक करने के लिए आपके पास पते हों, और चाहें तो वजह का एक नोट भी।

## चरण { #steps }

### लिस्ट खोलें { #open-the-list }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।
2. **Suppression List** चुनें। पेज का शीर्षक **Suppression list** लिखा होता है।
3. शीर्षक के नीचे की लाइन पढ़ें। कुछ भी ब्लॉक न होने पर उसमें लिखा होता है: **Addresses that must never receive email — bounces, complaints and unsubscribes land here automatically.**
4. **Email**, **Reason**, **Remarks**, **Suppressed On** और **Status** कॉलम पढ़ें।

### फ़िल्टर और एक्सपोर्ट करें { #filter-and-export }

1. सिर्फ़ किसी एक वजह वाले पते देखने के लिए लिस्ट के ऊपर उस **Reason** चिप पर क्लिक करें। हर चिप पर गिनती दिखती है। सब देखने के लिए पहले चिप पर क्लिक करें।
2. जो पंक्तियाँ आप देख रहे हैं उन्हें डाउनलोड करने के लिए **Export CSV** पर क्लिक करें।

### किसी पते को हाथ से ब्लॉक करें { #block-an-address-by-hand }

1. **Add** पर क्लिक करें। **Add to Suppression List** डायलॉग खुलता है।
2. **Email Addresses** में हर लाइन पर 1 पता लिखें या पेस्ट करें, या उन्हें कॉमा से अलग करें, जैसे `jane@example.com`।
3. वैकल्पिक: **Remarks (optional)** में वजह लिखें, जैसे `Requested via support ticket #1234`।
4. **Add to List** पर क्लिक करें। डायलॉग बताता है कि कितने जुड़े। कुछ फ़ेल हों तो वह उन्हें सूचीबद्ध करता है।

इन पतों पर इस अकाउंट से कभी कैंपेन, जर्नी या डाइजेस्ट नहीं जाते।

### किसी एक पते का ब्योरा देखें { #see-the-details-of-one-address }

1. किसी पंक्ति पर **View Details** पर क्लिक करें। **Suppression Details** डायलॉग खुलता है।
2. **Source Campaign** पढ़ें। आपने जो पते जोड़े हैं, उनके लिए यह **Manually added** बताता है।
3. अगर संपर्क मौजूद है, तो उसे खोलने के लिए **View Contact** पर क्लिक करें।
4. **Record Status**, **Record Info** और **History** पढ़ें।

### कोई पता हटाएँ { #remove-an-address }

1. पंक्ति पर **Delete** पर क्लिक करें और पुष्टि करें।

!!! warning "चेतावनी"
    अनसब्सक्राइब, हार्ड बाउंस और शिकायतें स्थायी अनुपालन रिकॉर्ड हैं और इन्हें हटाया नहीं जा सकता। सिर्फ़ वही पते हटाए जा सकते हैं जो आपने हाथ से जोड़े थे। जिसने अनसब्सक्राइब किया है, उसे खुद दोबारा साइन अप करना होगा।

!!! note "ध्यान दें"
    पंक्तियाँ जोड़ी या डिलीट की जाती हैं। उन्हें एडिट नहीं किया जा सकता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Enter at least one email address** | **Email Addresses** बॉक्स खाली है। | कोई पता लिखें या पेस्ट करें। |
| **Invalid email address: …** | कोई एंट्री सही पता नहीं है। | पता ठीक करें और फिर कोशिश करें। |
| **Added N of M. Failed: …** | कुछ पते जोड़े नहीं जा सके। | फ़ेल हुई सूची पढ़ें, उन्हें ठीक करें और फिर जोड़ें। |
| **Export CSV** धूसर है। | लिस्ट खाली है। | पहले कोई पता जोड़ें। |
| Send Logs में **Skipped suppressed** दिखता है। | पाने वाला इस लिस्ट में है। | उसे ब्लॉक ही रहने दें। उस भेजने का शुल्क नहीं लगता। |
