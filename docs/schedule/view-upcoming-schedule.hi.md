# देखें आगे क्या आने वाला है { #see-what-is-coming-up }

आगे की प्लानिंग के लिए **Upcoming** व्यू इस्तेमाल करें। इसमें आज से आगे के वे आइटम दिन के हिसाब से दिखते हैं जो अभी इंतज़ार में हैं या चल रहे हैं। इसे पढ़कर आप जान लेंगे कि अगले कुछ दिनों में क्या जाने वाला है। चाहें तो किसी भी आइटम का समय बदल सकते हैं या उसे रोक सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। न दिखे तो अपने एडमिन से कहें।
- किसी एक मॉड्यूल में भी आज या आगे के किसी दिन के लिए कुछ शेड्यूल होना चाहिए।

## स्टेप { #steps }

### Upcoming खोलें { #open-upcoming }

1. लेफ़्ट रेल में **Schedule** खोलें और **Upcoming** चुनें। पेज का टाइटल **Upcoming** होता है और पेज **List** व्यू में खुलता है।
2. दिन के टाइटल पढ़ें। पहले **Today**, फिर **Tomorrow**, और उसके बाद **Fri, 3 Oct** जैसी तारीख़ दिखती है।
3. किसी लाइन पर क्लिक करें। दाईं ओर उसकी जानकारी खुल जाती है।

### जानें कि Upcoming में क्या-क्या आता है { #know-what-upcoming-includes }

Upcoming में आइटम तभी दिखता है जब ये दोनों बातें सही हों:

- उसकी तारीख़ आज की या उसके बाद की हो।
- उसका स्टेटस **Scheduled** या **Live** हो।

!!! note
    जिन आइटम का स्टेटस **Draft**, **Sent**, **Paused**, **Cancelled** या **Failed** है, वे **Upcoming** में नहीं आते। **Paused** आइटम **All schedules** में स्टेटस **Scheduled** चुनने पर फिर भी दिखता है।

### लिस्ट को छोटा करें { #narrow-the-list }

1. एक ही चैनल देखने के लिए उसकी चैनल चिप पर क्लिक करें। दूसरे चैनल वापस जोड़ने के लिए और चिप पर क्लिक करें।
2. सिर्फ़ अपने आइटम देखने हैं तो **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
3. लिस्ट और छोटी करनी हो तो **Any status** पर क्लिक करें। आपका चुना हुआ स्टेटस **Upcoming** के नियम के साथ ही काम करता है।

### आने वाले आइटम का समय बदलें या उसे रोकें { #move-or-stop-an-upcoming-item }

1. आइटम पर क्लिक करें।
2. नई तारीख़ और समय चुनने के लिए **Reschedule** पर क्लिक करें। उसे रोकना हो तो **Cancel** पर क्लिक करें। इसके बारे में पढ़ें: [शेड्यूल किए गए आइटम को रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।

### ज़्यादा आगे तक देखें { #see-a-longer-range }

1. वही फ़िल्टर रखकर पूरा महीना देखने के लिए **Calendar** पर क्लिक करें।
2. अगले महीने जाने के लिए महीने के नाम के पास वाले तीर दबाएँ। वापस आने के लिए **Today** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | आज से आगे कुछ इंतज़ार में नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | दूसरे चैनल की चिप पर क्लिक करें, **Everyone's schedule** चुनें, या स्टेटस **Any status** कर दें। |
| रोका हुआ ब्रॉडकास्ट नहीं दिख रहा | **Upcoming** में सिर्फ़ **Scheduled** और **Live** आइटम दिखते हैं। | **All schedules** खोलें और स्टेटस **Scheduled** करें। |
| ड्राफ़्ट नहीं दिख रहा | ड्राफ़्ट का अपना अलग व्यू है। | **Drafts** खोलें। पढ़ें: [ड्राफ़्ट खोजें और पूरे करें](find-and-finish-drafts.md)। |
| आज पहले जा चुकी कोई चीज़ नहीं दिख रही | अब उसका स्टेटस **Sent** है। | उसे देखने के लिए **Today** खोलें। |
