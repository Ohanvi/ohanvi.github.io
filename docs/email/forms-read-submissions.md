# Read form submissions

**Submissions** lists answers from every form and every source. Use it to fix anything that did not process.

## Before you start

- You can see **Submissions** under **Forms** in the left rail.

## Steps

1. Open **Forms** in the left rail, then select **Submissions**.
2. Click a filter: **All**, **Unmatched**, **Pending**, **Processed**, **Partly done** or **Failed**.
3. Read the source on each row: **WhatsApp chat**, **WhatsApp form**, **Public link** or **Meta lead ad**.
4. Read the status: **Processed**, **No form matched**, **Failed**, **Partly done**, **Processing** or **Waiting**.
5. Click **Show all N answers** if a row shows only the first 6.
6. For **No form matched**, click **Attach form**. In **Which form was this?**, pick the form.
7. For a failed row that can be retried, click **Retry**.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **Retry** is missing. | The failure cannot be retried. | Read the reason and fix the cause. |
| A submission is **Waiting**. | It has not been picked up yet. | Wait, then refresh. |
