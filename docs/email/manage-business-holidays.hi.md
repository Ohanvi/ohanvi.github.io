# छुट्टियाँ और बंद दिन जोड़ें { #add-holidays-and-closed-days }

Business Holidays में राष्ट्रीय दिन, त्योहार और आपके अपने बंद दिन होते हैं। शेड्यूलर इन्हें महीने के कैलेंडर पर रंग देकर दिखाता है, ताकि आप किसी ऐसे दिन ईमेल भेजना प्लान न कर दें जब जवाब देने के लिए कोई मौजूद ही न हो। आखिर में आपके अपने दिन शेड्यूलर में दिखने लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको **Email** पैनल में **Manage** दिखे। अगर नहीं दिखता, तो अपने एडमिन से कहें।
- आपको पता हो कि कौन-सी तारीखें चिह्नित करनी हैं।

## चरण { #steps }

### छुट्टियों की सूची खोलें { #open-the-holiday-list }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।
2. **Business Holidays** चुनें। पेज का शीर्षक **Holidays** है।
3. शीर्षक के नीचे की पंक्ति पढ़ें। उसमें प्रोडक्ट के साथ आई छुट्टियों और आपकी अपनी छुट्टियों की गिनती होती है।

आप सूची शेड्यूलर से भी खोल सकते हैं। शेड्यूलर में ऊपर **Holidays** पर क्लिक करें।

### सूची पढ़ें { #read-the-list }

1. **Date**, **Holiday**, **Type**, **Source**, **Note** और **Status** कॉलम देखें।
2. **Source** में, **Shipped** का मतलब है कि छुट्टी प्रोडक्ट के साथ आती है और हर अकाउंट में एक जैसी है। **Yours** का मतलब है कि आपने उसे जोड़ा है।
3. **Type** में देखें कि हर प्रकार का भेजने के लिए क्या मतलब है:

    | प्रकार | मतलब |
    | --- | --- |
    | **Festival** | भेजने के लिए अच्छा दिन। |
    | **National** | भेजने के लिए अच्छा दिन। |
    | **Closed** | आपकी कंपनी बंद है। न भेजें। |
    | **Optional** | कुछ लोग छुट्टी पर होंगे। |

### अपनी छुट्टी जोड़ें { #add-your-own-holiday }

1. **Add** पर क्लिक करें। जोड़ने का फ़ॉर्म खुलता है।
2. **Date** में दिन चुनें।
3. **Holiday** में नाम लिखें, जैसे `Annual stock count`।
4. **Type** में **Festival — a good day to send**, **National day — a good day to send**, **Company closed — do not send** या **Optional — some will be away** चुनें।
5. वैकल्पिक: **Note** में अपनी टीम के लिए रिमाइंडर लिखें।
6. फ़ॉर्म सेव करें। छुट्टी **Source** में **Yours** के साथ दिखती है।

### छुट्टी एडिट या डिलीट करें { #edit-or-delete-a-holiday }

1. अपनी किसी पंक्ति पर **Edit** पर क्लिक करें। फ़ील्ड बदलें और सेव करें।
2. उसे हटाने के लिए **Delete** पर क्लिक करें और पुष्टि करें।

!!! warning "चेतावनी"
    Shipped छुट्टी को आप एडिट या डिलीट नहीं कर सकते। उसकी **Date (shipped holiday — read only)** फ़ील्ड लॉक रहती है, क्योंकि एक अकाउंट के नाम बदलने से वह सभी अकाउंट में बदल जाएगा। संदेश कहता है: **This holiday ships with the product and is shared by every account, so it cannot be deleted. Add your own instead.**

!!! note "ध्यान दें"
    कोई छुट्टी कभी भी भेजने को नहीं रोकती। शेड्यूलर में किसी कैंपेन को **Closed** दिन पर ले जाने पर बस आपसे पुष्टि माँगी जाती है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Delete** ग्रे है। | पंक्ति **Shipped** छुट्टी की है। | उसे वैसे ही रहने दें, या उस दिन के लिए अपनी छुट्टी जोड़ें। |
| फ़ील्ड लॉक हैं। | पंक्ति **Shipped** छुट्टी की है। | इसके बजाय अपनी छुट्टी जोड़ें। |
| कोई छुट्टी शेड्यूलर में नहीं दिखती। | पेज रीफ़्रेश नहीं हुआ था। | शेड्यूलर में **Refresh** पर क्लिक करें। |
