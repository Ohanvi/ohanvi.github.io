# टेम्प्लेट { #template }

व्हाट्सऐप पर कोई बिज़नेस चैट तभी शुरू कर सकता है जब टेम्प्लेट को Meta ने Approved किया हो। यहाँ आप उन टेम्प्लेट को बनाते, सबमिट करते और प्रबंधित करते हैं।

**इसे कहाँ खोलें:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Template** चुनें।

![All, Favorites, Approved और Action Required टैब और एक टेम्प्लेट प्रीव्यू के साथ Template स्क्रीन](../../assets/screenshots/whatsapp-template-0-overview.png)

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [मैसेज टेम्प्लेट बनाएँ](../create-message-template.md) | आप नया टेम्प्लेट लिखकर Meta को भेजना चाहते हैं। |
| [टेम्प्लेट लाइब्रेरी का इस्तेमाल करें](../use-template-library.md) | आप बने-बनाए टेम्प्लेट से शुरू करना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट है। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस है। न दिखे तो अपने एडमिन से पूछें।
