# एनालिटिक्स के लिए डेटा सेट करें { #set-up-data-for-analytics }

अपनी **Analytics** स्क्रीन को असली आँकड़ों से भरें। अंत में **Marketing Analytics** दिखाता है कि आपके व्हाट्सऐप ब्रॉडकास्ट का प्रदर्शन कैसा रहा, और **Store Analytics** आपके कनेक्ट किए गए Shopify या WooCommerce स्टोर के ऑर्डर और रेवेन्यू दिखाता है, साथ में यह भी कि व्हाट्सऐप ने क्या जोड़ा।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Analytics** दिखता है। यह तभी दिखता है जब आपके वर्कस्पेस में व्हाट्सऐप चालू हो और आपका रोल व्हाट्सऐप खोल सकता हो।
- आपका व्हाट्सऐप नंबर कनेक्ट है। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](../whatsapp/connect-whatsapp-number.md)।
- स्टोर के आँकड़े चाहिए तो आपके पास अपने Shopify या WooCommerce स्टोर में एडमिन अधिकार हों।

## चरण { #steps }

### देखें कि आपको क्या दिखता है { #check-what-you-can-see }

1. लेफ़्ट रेल में **Analytics** खोलें। पैनल में वे स्क्रीन दिखती हैं जो आपका रोल खोल सकता है।
2. **Marketing Analytics** खोजें। यह तब दिखता है जब आपका रोल व्हाट्सऐप ब्रॉडकास्ट देख सकता हो।
3. **Store Analytics** खोजें। यह तब दिखता है जब आपका रोल स्टोर इंटीग्रेशन देख सकता हो।

कोई आइटम न दिखे तो अपने एडमिन से कहें कि वह एक्सेस आपके रोल में जोड़ें। दोनों न दिखें तो **Analytics** आइकन दिखता ही नहीं।

### Marketing Analytics में डेटा लाएँ { #feed-marketing-analytics }

**Marketing Analytics** सिर्फ़ व्हाट्सऐप **Campaign** ब्रॉडकास्ट से भेजे गए मैसेज गिनता है। **Inbox** की चैट नहीं गिनी जातीं।

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।
2. कम से कम एक संपर्क को ब्रॉडकास्ट भेजें।
3. व्हाट्सऐप के डिलीवरी और रीड बताने का इंतज़ार करें। ये अपडेट अगले कुछ मिनटों और घंटों में आते हैं।
4. लेफ़्ट रेल में **Analytics** खोलें, फिर **Marketing Analytics** चुनें। ताज़ा आँकड़े लोड करने के लिए **Refresh** पर क्लिक करें।

### Store Analytics और रेवेन्यू के लिए स्टोर कनेक्ट करें { #connect-a-store-for-store-analytics-and-revenue }

1. लेफ़्ट रेल में **Connect** खोलें, फिर **Store Connections** चुनें।
2. Shopify या WooCommerce कार्ड पर **Connect store** या **Connect** पर क्लिक करें।
3. अपने स्टोर की अपनी स्क्रीन पर एक्सेस मंज़ूर करें। लौटने पर एक संदेश बताता है कि स्टोर कनेक्ट हो गया है और ग्राहक और ऑर्डर सिंक हो रहे हैं।
4. सिंक पूरा होने तक रुकें। इसके बाद नए ऑर्डर आपके स्टोर के भेजते ही आ जाते हैं।
5. लेफ़्ट रेल में **Analytics** खोलें, फिर **Store Analytics** चुनें। **Refresh** पर क्लिक करें।

यहाँ कनेक्ट किया गया स्टोर व्हाट्सऐप के स्टोर फ़ीचर भी चलाता है। उसे **WhatsApp** → **Manage** → **Integrations** में दोबारा कनेक्ट करने की ज़रूरत नहीं।

!!! note "ध्यान दें"
    स्टोर कनेक्ट होने के बाद **Marketing Analytics** में एक **Orders** टाइल और **What it earned** पैनल भी दिखता है। ऑर्डर तब ब्रॉडकास्ट के खाते में गिना जाता है जब खरीदार ने उसे पाने के 7 दिन के अंदर ऑर्डर किया हो (last-touch attribution)।

### तारीख की अवधि चुनें { #pick-a-date-window }

दोनों स्क्रीन में पहले से तय अवधियाँ हैं। अपनी मर्ज़ी की तारीख सीमा नहीं चुन सकते।

| स्क्रीन | अवधियाँ |
| --- | --- |
| **Marketing Analytics** | **7d**, **30d** (डिफ़ॉल्ट), **90d**, **All** |
| **Store Analytics** | **7d**, **30d** (डिफ़ॉल्ट), **90d**, **1y**, **All** |

1. ऊपर दाईं ओर किसी अवधि वाले पिल पर क्लिक करें। स्क्रीन उस अवधि के लिए दोबारा लोड होती है।
2. अवधि बदले बिना दोबारा लोड करने के लिए **Refresh** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| लेफ़्ट रेल में **Analytics** नहीं है | आपके वर्कस्पेस में व्हाट्सऐप चालू नहीं है, या आपके रोल के पास दोनों में से कोई एनालिटिक्स एक्सेस नहीं है। | अपने एडमिन से कहें कि व्हाट्सऐप चालू करें और आपके रोल को ब्रॉडकास्ट या स्टोर एक्सेस दें। |
| **No broadcasts in this window** | चुनी हुई अवधि में कोई **Campaign** ब्रॉडकास्ट नहीं भेजा गया। | **90d** या **All** जैसी लंबी अवधि चुनें, या ब्रॉडकास्ट भेजें। |
| **Store Analytics** पर **No orders in this window** | कोई स्टोर कनेक्ट नहीं है, या उसने इस अवधि में कोई ऑर्डर नहीं भेजा। | **Connect** → **Store Connections** में स्टोर कनेक्ट करें, या लंबी अवधि चुनें। |
| **Access was not approved on …, so nothing was connected.** | आपने WooCommerce की मंज़ूरी स्क्रीन पर एक्सेस नहीं दिया। | **Connect** पर फिर क्लिक करें और एक्सेस मंज़ूर करें। |
| कनेक्ट करने के ठीक बाद आँकड़े कम दिखते हैं | ग्राहक और ऑर्डर अभी आपके स्टोर से सिंक हो रहे हैं। | कुछ मिनट रुकें, फिर **Refresh** पर क्लिक करें। |
| **Marketing Analytics** पर **Orders** टाइल नहीं है | कोई स्टोर कनेक्ट और चालू नहीं है। | स्टोर कनेक्ट करें, फिर **Refresh** पर क्लिक करें। |
