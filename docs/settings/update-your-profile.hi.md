# अपनी प्रोफ़ाइल और पासवर्ड बदलें { #update-your-profile-and-password }

**My Account** स्क्रीन पर अपना नाम, ईमेल, फ़ोन नंबर और पासवर्ड बदलें। सेव करते ही आपकी जानकारी बदल जाती है। नया पासवर्ड अगली बार साइन इन करते समय काम करेगा।

## शुरू करने से पहले { #before-you-start }

- आप Ohanvi में साइन इन हों। पासवर्ड भूल गए हैं, तो [अपना पासवर्ड रीसेट करें](../reset-password.md) देखें।

## स्टेप { #steps }

### My Account खोलें { #open-my-account }

1. नीचे-बाएँ कोने में अपने नाम के शुरुआती अक्षरों पर क्लिक करें। प्रोफ़ाइल मेन्यू खुलेगा।
2. मेन्यू में सबसे ऊपर अपने नाम पर क्लिक करें। **My Account** स्क्रीन खुलेगी।

### अपनी जानकारी बदलें { #change-your-details }

1. **Your details** के नीचे **Name**, **Email** या **Phone Number** बदलें। तीनों भरना ज़रूरी है।
2. कंट्री कोड चुनें। फिर कंट्री कोड के बिना अपना नंबर लिखें।
3. **Save changes** पर क्लिक करें। **Your account details were updated.** मैसेज दिखेगा।

**Username** नहीं बदला जा सकता। आप इसी नाम से साइन इन करते हैं।

### अपना पासवर्ड बदलें { #change-your-password }

1. **New password** में नया पासवर्ड लिखें। आँख के आइकन पर क्लिक करके पासवर्ड दिखा या छिपा सकते हैं।
2. बॉक्स के नीचे की चेकलिस्ट देखें। हर शर्त पूरी होते ही हरी हो जाती है:
    - **8+ characters**
    - **Upper & lower case**
    - **2+ digits**
    - **1+ special character**
    - **Not a common or predictable password**
3. **Save changes** पर क्लिक करें। **Your account details were updated.** मैसेज दिखेगा और बॉक्स खाली हो जाएगा।
4. अगली बार नए पासवर्ड से साइन इन करें।

पासवर्ड नहीं बदलना है, तो **New password** खाली छोड़ दें।

मज़बूत पासवर्ड में ये बातें भी नहीं होनी चाहिए:

- 64 अक्षरों से ज़्यादा लंबा न हो,
- 1234, abcd, qwer या aaaa जैसे लगातार या दोहराए हुए अक्षर न हों,
- आपका यूज़रनेम, नाम या ईमेल उसमें न हो।

कुछ अलग-अलग शब्द लें और उनमें अंक और एक चिह्न जोड़ दें, जैसे Mango#River42Lamp।

### अपना रोल देखें { #check-your-role }

**Role** बॉक्स में वह रोल दिखता है जो आपके वर्कस्पेस ने आपको दिया है, जैसे **Super Admin**, **Manager** या **Executive**। इसे आप यहाँ नहीं बदल सकते। अगर आपने ही वर्कस्पेस बनाया है, तो **You are the account owner.** लिखा आएगा। वरना वर्कस्पेस के मालिक से रोल बदलने को कहें। [टीम के मेंबर, रोल और अनुमतियाँ मैनेज करें](roles-and-permissions.md) देखें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Password needs: 8+ characters, 2+ digits** (या दूसरी शर्तें) | नया पासवर्ड 1 या ज़्यादा शर्तें पूरी नहीं करता। | मैसेज में जो कमी लिखी है, उसे जोड़ें। फिर दोबारा **Save changes** पर क्लिक करें। |
| **This password is too common and easy to guess (like Password@123).** | यह पासवर्ड आम पासवर्ड की लिस्ट में है। | कुछ अलग-अलग शब्द लें, जैसे Mango#River42Lamp। |
| **Password must not contain sequences or repeats like 1234, abcd, qwer or aaaa.** | पासवर्ड में कीबोर्ड की लगातार कुंजियाँ या दोहराया हुआ अक्षर है। | वह हिस्सा हटा दें। |
| **Password must not contain your username, name or email.** | पासवर्ड में आपके नाम या ईमेल का कुछ हिस्सा है। | ऐसे शब्द चुनें जिनका आपसे कोई लेना-देना न हो। |
| **Email … already exists with user: …** | किसी दूसरे एक्टिव यूज़र के पास यही ईमेल पहले से है। | दूसरा ईमेल इस्तेमाल करें, या वर्कस्पेस के मालिक से पूछें। |
| **Phone number is required.** | फ़ोन नंबर का बॉक्स खाली है। | अपना मोबाइल नंबर लिखें और सेव करें। |
