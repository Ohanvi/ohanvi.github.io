# पोस्ट टेम्प्लेट का इस्तेमाल करें { #use-post-templates }

जो पोस्ट टेक्स्ट आप बार-बार इस्तेमाल करते हैं, उसे टेम्प्लेट के रूप में सेव करें, फिर एक क्लिक में उसे कंपोज़र में खोलें। आप तैयार लाइब्रेरी देख सकते हैं, खाली जगह वाले अपने टेम्प्लेट लिख सकते हैं, या AI से किसी विषय या ट्रेंड पर एक टेम्प्लेट का ड्राफ़्ट बनवा सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Social** दिखता है और उसके पैनल में **Templates** भी।
- टेम्प्लेट से पब्लिश करने के लिए कम से कम एक नेटवर्क कनेक्ट होना चाहिए। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।

## चरण { #steps }

### टेम्प्लेट खोजें { #find-a-template }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Templates** चुनें।
2. बाईं ओर एक व्यू चुनें:
    - **Discover** — तैयार लाइब्रेरी, जिसमें **Recommended for you** और **More templates** हैं।
    - **My Templates** — आपके बनाए टेम्प्लेट।
    - **AI Generated** — AI के बनाए ड्राफ़्ट टेम्प्लेट।
    - **Saved** — वे टेम्प्लेट जिन्हें आपने दिल के आइकन से चिह्नित किया।
    - **Recently Used** — वे टेम्प्लेट जिन्हें आपने कंपोज़र में खोला।
3. **CATEGORIES** के नीचे **All Templates** या कोई श्रेणी चुनें, जैसे **Marketing**, **Announcement**, **Event**, **Review** या **General**।
4. **Filter by platform** के नीचे कोई नेटवर्क चुनें ताकि सिर्फ़ उसके टेम्प्लेट दिखें, या **All platforms** चुनें।

### टेम्प्लेट इस्तेमाल करें { #use-a-template }

1. टेम्प्लेट कार्ड पर **Use Template** पर क्लिक करें। **Create Post** विंडो टेम्प्लेट के टेक्स्ट और इमेज के साथ खुलती है।
2. हर `[bracketed]` खाली जगह को अपने शब्दों से बदलें।
3. अपने नेटवर्क चुनें और पोस्ट पब्लिश या शेड्यूल करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

आप कंपोज़र के अंदर से भी टेम्प्लेट चुन सकते हैं: ऊपर **Templates** पर क्लिक करें, फिर **Start from a template** में एक चुनें।

### टेम्प्लेट बनाएँ { #create-a-template }

1. **Create Template** पर क्लिक करें। **New Template** विंडो खुलती है।
2. **Template Name** में नाम लिखें।
3. **Category** में श्रेणी चुनें।
4. वैकल्पिक: **Thumbnail** के नीचे **Add image** पर क्लिक करें। इमेज 500 KB से छोटी होनी चाहिए।
5. **Content** में पोस्ट का टेक्स्ट लिखें। किसी भी शब्द को `[brackets]` में रखने से वह खाली जगह बन जाता है, जैसे `It helps [Target Audience] save time.`
6. **Platforms** के नीचे चुनें कि टेम्प्लेट कहाँ इस्तेमाल हो सकता है।
7. **Live Preview** देखें, फिर **Save Template** पर क्लिक करें। **Template saved.** संदेश आता है।

AI से यह फ़ॉर्म भरवाने के लिए विंडो के ऊपर **Draft with AI** पर क्लिक करें और पोस्ट का ब्योरा दें।

### AI से टेम्प्लेट बनवाएँ { #generate-a-template-with-ai }

1. **Generate with AI** पर क्लिक करें। **Generate a template** विंडो खुलती है।
2. **Trending in** के नीचे कोई ट्रेंडिंग विषय चुनें, या **Or write your own topic** के नीचे अपना विषय लिखें, जैसे `Independence Day sale`।
3. **Generate** पर क्लिक करें। Ohanvi कैप्शन लिखता है और इमेज खोजता है। इसमें एक मिनट तक लग सकता है।
4. **Review your template** में **Template name**, **Category**, **Content** और **Platforms** जाँचें। जो बदलना चाहें बदलें।
5. **Save template** पर क्लिक करें। **Saved "…" to your templates** संदेश आता है। उसे कंपोज़र में खोलने के लिए **Use now** पर क्लिक करें।

### टेम्प्लेट सेव करें और उसे दोबारा खोजें { #save-a-template-and-find-it-again }

1. टेम्प्लेट कार्ड पर प्रीव्यू के ऊपर दाईं ओर दिल के आइकन पर क्लिक करें। भरा हुआ दिल मतलब सेव है।
2. हटाने के लिए दिल पर फिर क्लिक करें।
3. अपने दिल वाले टेम्प्लेट देखने के लिए **Templates** खोलें और **Saved** चुनें।
4. जिन टेम्प्लेट को आपने कंपोज़र में खोला, उन्हें देखने के लिए **Recently Used** चुनें।
5. कार्ड की किसी पंक्ति में उसके सभी टेम्प्लेट देखने के लिए **View all** पर क्लिक करें।

!!! note "ध्यान दें"
    सेव किए हुए और हाल में इस्तेमाल किए टेम्प्लेट मौजूदा सेशन तक रखे जाते हैं।

### अपना टेम्प्लेट एडिट या डिलीट करें { #edit-or-delete-your-template }

1. आपके बनाए टेम्प्लेट पर **More** (⋯) मेनू पर क्लिक करें।
2. बदलने के लिए **Edit** पर क्लिक करें, या हटाने के लिए **Delete** पर। **Delete** के लिए **Delete template?** विंडो में पुष्टि करें।

आप सिर्फ़ अपने बनाए टेम्प्लेट ही एडिट या डिलीट कर सकते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Image too large — pick one under 500 KB.** | थंबनेल साइज़ की सीमा से बड़ा है। | इमेज को कंप्रेस करें और फिर से जोड़ें। |
| **Name is required** या **Description is required** | **Template Name** या **Content** खाली है। | दोनों फ़ील्ड भरें। |
| **No templates match here** | आपकी श्रेणी, प्लेटफ़ॉर्म या सर्च फ़िल्टर हर टेम्प्लेट को छिपा रहा है। | **All Templates** और **All platforms** चुनें। |
| **Trending topics aren't available right now — type your own below.** | ट्रेंड फ़ीड से कुछ नहीं आया। | अपना विषय खुद लिखें। |
| **Could not generate a caption right now. Please try again.** | AI का अनुरोध फ़ेल हो गया। | थोड़ी देर रुकें और **Generate** पर फिर क्लिक करें। |
