# अपना अकाउंट बंद करें { #deactivate-your-account }

अपना पूरा Ohanvi अकाउंट पॉज़ करें। सब लोग साइन आउट हो जाते हैं और कोई साइन इन नहीं कर पाता। पर कुछ भी डिलीट नहीं होता। आप अपने पासवर्ड और ईमेल पर आए OTP से कन्फ़र्म करते हैं। इसमें करीब 2 मिनट लगते हैं। दोबारा साइन इन करके आप अकाउंट वापस चालू कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **account owner** हों, यानी जिसने अकाउंट बनाया था। दूसरे एडमिन को **Deactivate account** नहीं दिखता।
- आपको अपना पासवर्ड याद हो।
- आप अपने अकाउंट के ईमेल पते का इनबॉक्स खोल सकते हों। Ohanvi OTP वहीं भेजता है।
- आप जानते हों कि यह **पूरे** अकाउंट पर लागू होता है। यानी उसके हर यूज़र पर, सिर्फ़ आप पर नहीं।

## अकाउंट बंद करने से क्या होता है { #what-deactivating-does }

| क्या होता है | ब्योरा |
| --- | --- |
| सब लोग तुरंत साइन आउट हो जाते हैं। | अकाउंट में कोई साइन इन नहीं कर सकता। |
| कुछ भी डिलीट नहीं होता। | आपके कॉन्टैक्ट, चैट, सेटिंग्स और इनवॉइस बने रहते हैं। |
| आपका डेटा स्क्रीन पर बताए गए दिनों तक कम से कम रखा जाता है। | स्क्रीन पर डिफ़ॉल्ट रूप से **at least 90 days** लिखा होता है। |
| आप वापस आ सकते हैं। | उस समय के अंदर खुद दोबारा साइन इन करें। अकाउंट अपने-आप फिर चालू हो जाता है। |
| उस समय के बाद Ohanvi इसे डिलीट कर सकता है। | डिलीट Ohanvi टीम करती है, इस स्क्रीन से नहीं होता। |

!!! warning "अकाउंट बंद करने से आपकी पूरी टीम साइन आउट हो जाती है"
    शुरू करने से पहले अपने साथियों को बता दें। साइन आउट होने पर उनका चल रहा काम सेव नहीं होता।

## स्टेप { #steps }

### स्क्रीन खोलें { #open-the-screen }

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. बाईं लिस्ट में अपने नाम पर क्लिक करें। आपके अकाउंट की सेटिंग्स खुलेंगी।
3. **More** के नीचे **Deactivate account** ढूँढकर उस पर क्लिक करें। पेज का टाइटल **Deactivate account** होगा। यह रो सिर्फ़ अकाउंट ओनर को दिखती है।
4. टाइटल के नीचे की लाइन पढ़ें। उसमें आपके अकाउंट का नाम है। साथ में लिखा है कि आपसे पासवर्ड और ईमेल पर भेजा गया कोड माँगा जाएगा।

### अकाउंट बंद करें { #deactivate-the-account }

1. **Deactivate account** कार्ड पर **Deactivate…** पर क्लिक करें। **Deactivate your account** विंडो खुलेगी।
2. विंडो में सबसे ऊपर की चेतावनी पढ़ें।
3. **Step 1 of 2 — confirm it is you** के नीचे **Your password** में अपना पासवर्ड लिखें। पासवर्ड दिखाने या छिपाने के लिए आँख के आइकन पर क्लिक करें।
4. **Continue** पर क्लिक करें। Ohanvi आपके रजिस्टर्ड ईमेल पते पर OTP भेजेगा।
5. **Step 2 of 2 — enter the code we emailed you** के नीचे बैनर पढ़ें। उसमें आधा छिपा ईमेल पता दिखता है। साथ में यह भी कि कोड कितनी देर चलेगा।
6. **Verification code** में कोड लिखें।
7. **Deactivate account** पर क्लिक करें। सब लोग साइन आउट हो जाएँगे। साइन-इन स्क्रीन पर अकाउंट के बारे में Ohanvi का मैसेज दिखेगा।

कोड न आए तो **Resend code** पर क्लिक करें।

### अकाउंट वापस चालू करें { #bring-the-account-back }

1. Ohanvi का साइन-इन पेज खोलें। देखें [Ohanvi में साइन इन करें](../sign-in.md)।
2. **Deactivate account** स्क्रीन पर बताए गए दिनों के अंदर ओनर के तौर पर साइन इन करें।
3. अकाउंट अपने-आप फिर चालू हो जाएगा। अपने साथियों को बता दें कि वे दोबारा साइन इन कर सकते हैं।

### अकाउंट हमेशा के लिए डिलीट करें { #delete-the-account-for-good }

Settings से अकाउंट डिलीट नहीं होता। स्क्रीन पर लिखा है कि Ohanvi सपोर्ट से info@ohanvi.com पर संपर्क करें। डिलीट Ohanvi टीम करती है, और उसे वापस नहीं लाया जा सकता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Deactivate account** लिस्ट में नहीं है। | आप अकाउंट ओनर नहीं हैं। | ओनर से अकाउंट बंद करने को कहें, या Ohanvi सपोर्ट से संपर्क करें। |
| पेज पर **Only the account owner — the person who created this account — can deactivate it.** दिखता है | आपका यूज़र अकाउंट बनाने वाला ओनर नहीं है। | ओनर के तौर पर साइन इन करें। |
| **Enter your password.** | पासवर्ड का बॉक्स खाली है। | अपना पासवर्ड लिखें और **Continue** पर क्लिक करें। |
| **Could not send the code.** | कोड वाला ईमेल नहीं गया। | अपना इंटरनेट कनेक्शन देखें और **Continue** पर फिर से क्लिक करें। |
| **Enter the code from your email.** | कोड का बॉक्स खाली है। | ईमेल से कोड देखकर लिखें। |
| **The request failed. Nothing was changed.** | कोड गलत है या एक्सपायर हो गया है। | **Resend code** पर क्लिक करें, फिर नया कोड डालें। |
