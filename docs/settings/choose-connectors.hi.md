# अपनी या Ohanvi की मैनेज्ड सेवाएँ चुनें { #choose-your-own-or-ohanvis-managed-services }

व्हाट्सऐप, AI और ईमेल के लिए चुनें कि Ohanvi आपका अपना प्रोवाइडर अकाउंट इस्तेमाल करे या अपनी मैनेज्ड सेवा। अंत में हर चैनल दिखाता है कि कौन-सा विकल्प चालू है और उसके इस्तेमाल का बिल कैसे बनता है।

## शुरू करने से पहले { #before-you-start }

- आपको **Settings** में अपने नाम के नीचे **Connectors** दिखता हो। अगर नहीं दिखता, तो अपने वर्कस्पेस ओनर से पूछें।
- व्हाट्सऐप का विकल्प चुनने के लिए, आपका व्हाट्सऐप नंबर पहले से कनेक्ट हो। अगर नहीं है, तो **WhatsApp (Meta)** कार्ड पर **Set up WhatsApp** पर क्लिक करें।
- अपना AI या ईमेल प्रोवाइडर इस्तेमाल करने के लिए, आपके पास उस प्रोवाइडर की API key या लॉगिन हो।

## बिलिंग में क्या फ़र्क है { #how-billing-differs }

मैनेज्ड इस्तेमाल का बिल आपके क्रेडिट से कटता है। आपके अपने अकाउंट का बिल प्रोवाइडर बनाता है। देखें [Ohanvi में क्रेडिट और बिलिंग](../credits-and-billing.md)।

| चैनल | Ohanvi मैनेज्ड | आपका अपना |
| --- | --- | --- |
| **WhatsApp (Meta)** | **Pay through Ohanvi** — आपके क्रेडिट से Meta की दर और Ohanvi का कमीशन चुकता होता है। | **Pay Meta directly** — आप Meta को सीधे भुगतान करते हैं; आपके क्रेडिट सिर्फ़ Ohanvi का इस्तेमाल कमीशन चुकाते हैं। |
| **AI** | **Ohanvi’s AI key** — Ohanvi की साझा AI key। | **Your key · connected** — आपकी अपनी Gemini, OpenAI या Anthropic key। |
| **Email** | **Ohanvi’s shared sender** | **Your provider · connected** — आपका अपना ईमेल प्रोवाइडर। |

## चरण { #steps }

### Connectors खोलें { #open-connectors }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. Settings की सूची में सबसे ऊपर अपने नाम पर क्लिक करें।
3. **Billing & credits** के नीचे **Connectors** पर क्लिक करें। **Connectors** पेज 3 कार्ड के साथ खुलता है।

### चुनें कि व्हाट्सऐप का बिल कैसे बने { #choose-how-whatsapp-is-billed }

1. **WhatsApp (Meta)** कार्ड पर **Pay through Ohanvi** या **Pay Meta directly** पर क्लिक करें।
2. **WhatsApp billing updated.** संदेश आता है।

अगर कार्ड पर **Not set up** दिखता है, तो पहले **Set up WhatsApp** पर क्लिक करके अपना नंबर कनेक्ट करें।

### अपनी AI key इस्तेमाल करें { #use-your-own-ai-key }

1. **AI** कार्ड पर **Connect your own AI key** पर क्लिक करें। **AI Connectors** पेज खुलता है।
2. **Provider** के नीचे **Gemini**, **OpenAI** या **Anthropic** चुनें। **Credentials** के नीचे **API key** पेस्ट करें और एक **Model** चुनें। **Test connection** पर क्लिक करें, फिर **Connect** पर।
3. **Connectors** पर वापस जाएँ और **Refresh** पर क्लिक करें। कार्ड पर **Your key · connected** दिखता है।

इसे बाद में बदलने के लिए **Manage AI provider** पर क्लिक करें।

### अपना ईमेल प्रोवाइडर इस्तेमाल करें { #use-your-own-email-provider }

1. **Email** कार्ड पर **Connect your own provider** पर क्लिक करें। ईमेल प्रोवाइडर पेज खुलता है।
2. अपने प्रोवाइडर की जानकारी डालें और सेव करें। प्रोवाइडर सेटअप के लिए [ईमेल सेक्शन](../email/index.md) देखें।
3. **Connectors** पर वापस जाएँ और **Refresh** पर क्लिक करें। कार्ड पर **Your provider · connected** दिखता है।

इसे बाद में बदलने के लिए **Manage email providers** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not update WhatsApp billing.** | बदलाव सेव नहीं हुआ। | दोबारा कोशिश करें। अगर फिर भी न हो, तो सपोर्ट से संपर्क करें। |
| **WhatsApp (Meta)** पर **Not set up** दिख रहा है | कोई व्हाट्सऐप नंबर कनेक्ट नहीं है। | **Set up WhatsApp** पर क्लिक करें और अपना व्हाट्सऐप कॉन्फ़िगरेशन जोड़ें। |
| AI या Email कार्ड पर अब भी Ohanvi की सेवा दिख रही है | key जोड़ने के बाद पेज रीलोड नहीं हुआ है। | **Refresh** पर क्लिक करें। |
| अपने नाम के नीचे **Connectors** नहीं दिख रहा | आपके रोल को यह दिखाई नहीं देता। | अपने वर्कस्पेस ओनर से पूछें। |
