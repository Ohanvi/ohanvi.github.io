# Google रिव्यू का जवाब दें { #reply-to-google-reviews }

आपकी Google लिस्टिंग के रिव्यू Ohanvi में आ जाते हैं। यहीं से आप सबको दिखने वाला जवाब दे सकते हैं। जवाब बदल या डिलीट भी कर सकते हैं। किसी रिव्यू पर बाद में काम करना हो, तो उस पर प्राइवेट नोट लिखकर उसे फ़्लैग कर दें। इसमें लगभग 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका Google Business कनेक्ट होना चाहिए। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
- लेफ़्ट रेल में **Social** दिखना चाहिए। रिव्यू Google से बैकग्राउंड में सिंक होते हैं, इसलिए नया रिव्यू दिखने में थोड़ा समय लग सकता है।

## स्टेप { #steps }

### रिव्यू खोलें { #open-the-reviews }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Home** चुनें।
2. **NEEDS ATTENTION** के नीचे **Google reviews** ढूँढें और **Reply →** पर क्लिक करें। रिव्यू का पेज खुल जाएगा।
3. पेज के ऊपर रिव्यू की गिनती दिखती है, जैसे **12 review(s)**।

### रिव्यू फ़िल्टर करें { #filter-the-reviews }

1. रेटिंग की लिस्ट खोलें। शुरू में उसमें **All ratings** चुना होता है।
2. **1 star**, **2 stars**, **3 stars**, **4 stars** या **5 stars** चुनें।
3. जिन रिव्यू का जवाब आपने नहीं दिया, उन्हें देखने के लिए **Unreplied only** चालू करें।
4. ताज़ा रिव्यू लाने के लिए रीफ़्रेश आइकन पर क्लिक करें।
5. लिस्ट में आगे-पीछे जाने के लिए तीरों (**Previous page** और **Next page**) का इस्तेमाल करें। **Page N of M** वाली लाइन बताती है कि आप कौन से पेज पर हैं।

अगर फ़िल्टर की वजह से कुछ नहीं दिखता, तो पेज पर **No reviews match these filters** लिखा आता है। सारे रिव्यू फिर से देखने के लिए **Clear filters** पर क्लिक करें।

अगर अभी तक कुछ सिंक नहीं हुआ है, तो **No reviews synced yet** लिखा आता है। **Go to dashboard** पर क्लिक करें। इससे **Insights** खुलेगा। वहाँ पेज के ऊपर **Sync from Google** पर क्लिक करें। Google कनेक्ट न हो, तो यह बटन बंद रहता है।

### रिव्यू का जवाब दें { #reply-to-a-review }

1. जिस रिव्यू का जवाब देना है, उस पर **Reply** पर क्लिक करें। **Reply to …** विंडो खुलती है। उसमें रिव्यू का टेक्स्ट दिखता है।
2. **Public reply** में अपना जवाब लिखें।
3. पहले से सेव किए टेक्स्ट से शुरू करना हो, तो **Insert template** में से कोई एक चुनें।
4. जवाब का सुझाव चाहिए, तो **Suggest reply** पर क्लिक करें। भेजने से पहले उसे एक बार देखकर ज़रूरत हो तो बदल लें।
5. **Send Reply** पर क्लिक करें। **Reply posted to Google** मैसेज आएगा।
6. **Posted publicly on Google.** वाली लाइन पढ़ लें। इसका मतलब है कि आपका जवाब सबको दिखेगा।

अगर बॉक्स खाली है, तो **Reply text is required** लिखा आता है।

### जवाब बदलें { #change-a-reply }

1. अपने जवाब के नीचे **Edit** पर क्लिक करें।
2. टेक्स्ट बदलें।
3. **Update Reply** पर क्लिक करें।

### जवाब डिलीट करें { #delete-a-reply }

1. अपने जवाब के नीचे **Delete** पर क्लिक करें। **Delete reply?** विंडो खुलेगी।
2. **Delete** पर क्लिक करें। **Reply deleted** मैसेज आएगा।

!!! warning "डिलीट करने के बाद जवाब वापस नहीं आता"
    डिलीट करने पर आपका जवाब Google से भी हट जाता है।

### रिव्यू को फ़ॉलो-अप के लिए फ़्लैग करें { #mark-a-review-for-follow-up }

1. जिस रिव्यू को फ़्लैग करना है, उस पर फ़्लैग आइकन (**Flag for follow-up**) पर क्लिक करें।
2. इंसान वाले आइकन (**Assign / note**) पर क्लिक करें। **Assign / internal note** विंडो खुलेगी।
3. **Assigned to** में टीम के मेंबर का नाम लिखें।
4. **Internal note** में नोट लिखें। इसे आपकी टीम के बाहर कोई नहीं देख सकता, और यह Google पर नहीं दिखता।
5. **Save** पर क्लिक करें।
6. अब रिव्यू पर **Assigned:** और **Note:** वाली लाइनें दिखेंगी।
