# फ़ॉर्म बनाएँ और प्रबंधित करें { #create-and-manage-forms }

फ़ॉर्म ग्राहकों से जवाब इकट्ठा करते हैं, चैट में, वेब पर या शेयर किए गए लिंक से। अंत में आपके पास ऐसा फ़ॉर्म होगा जिसे आप ढूँढ सकते हैं, पब्लिश कर सकते हैं और व्यवस्थित रख सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Forms** दिखता है। अगर नहीं दिखता, तो अपने एडमिन से पूछें।

## चरण { #steps }

### अपने फ़ॉर्म खोलें { #open-your-forms }

1. लेफ़्ट रेल में **Forms** खोलें, फिर **Forms** चुनें।
2. टाइटल के नीचे की लाइन पढ़ें: **Whatever your customers fill in — chat, web, or a shared link.**
3. **All**, **Draft**, **Active** या **Archived** पर क्लिक करें। हर एक अपनी गिनती दिखाता है।
4. फ़ॉर्म कहाँ से आया, यह छाँटने के लिए **Any source** पिकर इस्तेमाल करें। नाम खोजने के लिए सर्च बॉक्स इस्तेमाल करें।

### नया फ़ॉर्म शुरू करें { #start-a-new-form }

1. **New form** पर क्लिक करें। **Start a new form** खुलता है।
2. अपने बिज़नेस के हिसाब से कोई टेम्प्लेट चिप चुनें, या **Start blank** पर क्लिक करें।
3. फ़ॉर्म बिल्डर खुलता है। देखें [फ़ॉर्म बनाएँ](forms-build-a-form.md)।

### फ़ॉर्म की पंक्ति पढ़ें { #read-a-form-row }

1. **From <source>** बैज दिखाता है कि फ़ॉर्म कहाँ से आया।
2. **Live in chat** का मतलब है कि कोई चैटबॉट उसे इस्तेमाल कर रहा है।
3. **Public link** का मतलब है कि लिंक वाला कोई भी उसे खोल सकता है।
4. उसे बिल्डर में खोलने के लिए पंक्ति पर क्लिक करें।

### पंक्ति का मेन्यू इस्तेमाल करें { #use-the-row-menu }

1. पंक्ति पर **⋮** मेन्यू खोलें।
2. जवाब पढ़ने के लिए **Responses** चुनें। देखें [फ़ॉर्म के जवाब पढ़ें](forms-read-responses.md)।
3. **Share link and QR** चुनें। देखें [फ़ॉर्म का प्रीव्यू देखें और शेयर करें](forms-share-and-preview.md)।
4. **Publish to WhatsApp** चुनें, या बदलाव के बाद **Republish to WhatsApp**।
5. **Duplicate** चुनें। इसमें **Duplicated as a draft** लिखा आता है।
6. **Pause** चुनें। इसमें **Paused — the link no longer opens** लिखा आता है।
7. बिना डिलीट किए छिपाने के लिए **Archive** चुनें।
8. **Delete** चुनें। **Delete <name>?** की पुष्टि करें। जो सबमिशन पहले आ चुके हैं, वे बने रहते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No forms yet** | आपने अभी कोई फ़ॉर्म नहीं बनाया। | **New form** पर क्लिक करें। |
| **No forms match** | कोई फ़िल्टर या सर्च उन्हें छिपा रहा है। | **Clear filters** पर क्लिक करें। |
| पब्लिक लिंक नहीं खुलता। | फ़ॉर्म पॉज़ है या अभी ड्राफ़्ट है। | स्टेटस **Active** करें। |
