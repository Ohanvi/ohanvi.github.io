# नतीजे ट्रैक करें और अनसब्सक्राइब व बाउंस संभालें { #track-results-and-handle-unsubscribes-and-bounces }

देखें कि आपके ईमेल का नतीजा कैसा रहा, हर पाने वाले तक, और अपनी लिस्ट साफ़ रखें। आख़िर में आपको पता होगा कि हर कैंपेन किसे मिला, किसने खोला और किसने क्लिक किया। यह भी पता होगा कि कुछ लोगों को क्यों छोड़ा गया, अनसब्सक्राइब किया गया या सप्रेस किया गया।

## शुरू करने से पहले { #before-you-start }

- आपने कम से कम 1 कैंपेन भेजा हो। इसके लिए [ईमेल कैंपेन भेजें](send-email-campaign.md) देखें।
- लेफ़्ट रेल में आपको **Email** दिखे और उसके पैनल में **Manage** भी। Send Logs उसी के अंदर है। अगर यह नहीं दिखता, तो अपने एडमिन से पूछें।

## स्टेप { #steps }

### कैंपेन के आँकड़े पढ़ें { #read-the-campaign-figures }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Campaigns** चुनें। किसी कैंपेन के आँकड़े देखने के लिए उसे खोलें। इस रिलीज़ में पूरा डैशबोर्ड छिपा हुआ है।
2. नए अकाउंट में **Get set up to send** के स्टेप पूरे करें: **Confirm a sending address**, **Add your contacts**, **Put them in a list** और **Send your first campaign**।
3. कुल आँकड़े पढ़ें: **Sent**, **Delivered**, **Opened** और **Clicked**।
4. नीचे स्क्रॉल करके **Campaign Funnel**, **Recent Campaigns**, **Engagement Trend**, **Subscriber Growth**, **Top Links Clicked**, **Device Analytics** और **Suppression Breakdown** देखें।

उस कैंपेन के आँकड़े खोलने के लिए **Recent Campaigns** की किसी लाइन में **View Report** पर क्लिक करें।

### Send Logs में हर पाने वाले को देखें { #see-each-recipient-in-send-logs }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें, फिर **Send Logs**। इसके लिए [सेंड लॉग पढ़ें](read-send-logs.md) देखें।
2. **Campaign** में कोई कैंपेन चुनें। टेबल में हर पाने वाला **Recipient**, **Status**, **Sent**, **Opened**, **Clicked**, **Unsubscribed** और **Error** के साथ दिखता है।
3. लिस्ट छोटी करने के लिए कोई फ़िल्टर चुनें: **All**, **Queued**, **Failed**, **Opened**, **Not Opened**, **Clicked**, **Bounced**, **Complained** या **Unsubscribed**।
4. किसी एक व्यक्ति को खोजने के लिए **Search recipient email** में लिखें।
5. किसी लाइन पर क्लिक करके उसकी **Activity Timeline** देखें। ज़्यादा जानकारी के लिए **View Contact** या **View Template** पर क्लिक करें।
6. डाउनलोड करने के लिए **Export** पर क्लिक करें, फिर **Export Excel (full log)** या **Export CSV (current page)** चुनें।

### हर सेंड स्टेटस का मतलब { #what-each-send-status-means }

| स्टेटस | मतलब |
| --- | --- |
| **Queued** | भेजे जाने का इंतज़ार कर रहा है। |
| **Sent** | भेजने वाले सर्वर को दे दिया गया है। |
| **Delivered** | पाने वाले के इनबॉक्स प्रोवाइडर ने ईमेल ले लिया है। |
| **Bounced** | पता ईमेल नहीं पा सका। |
| **Complained** | पाने वाले ने इसे स्पैम बताया। |
| **Failed** | ईमेल भेजना पूरा नहीं हुआ। वजह **Error** कॉलम में लिखी होती है। |
| **Skipped suppressed** | ईमेल नहीं भेजा गया, क्योंकि पता सप्रेशन लिस्ट में है। |

### अनसब्सक्राइब, बाउंस और शिकायतें कैसे काम करती हैं { #how-unsubscribes-bounces-and-complaints-work }

Ohanvi इन लोगों को आगे के ईमेल से अपने-आप हटा देता है:

- **Unsubscribe** — जब कोई पाने वाला `{{unsubscribeUrl}}` लिंक पर क्लिक करता है, तो कॉन्टैक्ट **Unsubscribed** हो जाता है और पता सप्रेस कर दिया जाता है।
- **Hard bounce** — जो पता हमेशा के लिए बाउंस होता है, उसे सप्रेस कर दिया जाता है।
- **Complaint** — जो पाने वाला आपके ईमेल को स्पैम बताता है, उसे सप्रेस कर दिया जाता है।

हर कैंपेन सप्रेस और अनसब्सक्राइब हुए लोगों को छोड़ देता है। वे **Send Logs** में **Skipped suppressed** दिखते हैं, और उनके लिए आपसे कोई चार्ज नहीं लिया जाता।

!!! warning "चेतावनी"
    अनसब्सक्राइब, हार्ड बाउंस और शिकायतें कानूनी तौर पर ज़रूरी रिकॉर्ड हैं। आप इन्हें हटा नहीं सकते। जिसने अनसब्सक्राइब किया है, उसे खुद दोबारा साइन अप करना होगा।

### किसी कॉन्टैक्ट को हाथ से अनसब्सक्राइब या दोबारा चालू करें { #unsubscribe-or-reactivate-a-contact-by-hand }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Audience** चुनें, फिर **Emails** टैब।
2. कॉन्टैक्ट की लाइन का मेन्यू खोलें, फिर **Unsubscribe** पर क्लिक करें। **Unsubscribe Contact** में **Unsubscribe** पर क्लिक करें।
3. हाथ से किया गया अनसब्सक्राइब वापस लेने के लिए **Reactivate (mark Subscribed)** पर क्लिक करें, फिर **Reactivate** पर क्लिक करें।

सिर्फ़ उसी को दोबारा चालू करें जिसे आपने खुद अनसब्सक्राइब किया था। अगर कॉन्टैक्ट ने खुद अनसब्सक्राइब किया है, तो उसकी नई सहमति उसी से आनी चाहिए।

### किसी पते को सभी ईमेल से ब्लॉक करें { #block-an-address-from-all-sends }

**Suppression List** स्क्रीन पर हर ब्लॉक किया गया पता उसके **Reason** के साथ दिखता है। इसे **Email** → **Manage** → **Suppression List** से खोलें। इसके लिए [सप्रेशन लिस्ट से पते ब्लॉक करें](use-the-suppression-list.md) देखें।

1. **Suppression List** खोलें, फिर **Add** पर क्लिक करें। **Add to Suppression List** डायलॉग खुलेगा।
2. **Email Addresses** में हर लाइन पर 1 पता लिखें। **Remarks (optional)** जोड़ें, जैसे सपोर्ट टिकट नंबर।
3. **Add to List** पर क्लिक करें।

लिस्ट से बाद में सिर्फ़ वही पते हटाए जा सकते हैं जिन्हें आपने हाथ से जोड़ा था।

### देखें कि ईमेल पर कितना खर्च हुआ { #see-what-email-cost-you }

हर डिलीवर हुआ ईमेल क्रेडिट इस्तेमाल करता है। **Spend by product** और हर चार्ज देखने के लिए ऊपर दाईं ओर का **Credits** बॉक्स खोलें। इसके लिए [क्रेडिट और बिलिंग](../credits-and-billing.md) देखें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| Send Logs पर **Select a campaign** | कोई कैंपेन चुना नहीं गया है। | **Campaign** में एक कैंपेन चुनें। |
| **No send logs yet** | कैंपेन अभी किसी को भेजा नहीं गया है। | **Campaigns** पर उसका स्टेटस देखें। |
| कई लाइनों में **Failed** दिख रहा है | भेजने वाला वेरिफ़ाई नहीं है, या आपके अपने ईमेल प्रोवाइडर ने कनेक्शन मना कर दिया। | **Error** कॉलम पढ़ें। **Sender Identities** और **Email Provider** स्क्रीन जाँचें। |
| **… suppressions are permanent and cannot be lifted.** | पते ने अनसब्सक्राइब किया, बाउंस हुआ या शिकायत की। | उसे सप्रेस ही रहने दें। अगर व्यक्ति आपके ईमेल चाहता है, तो उससे दोबारा साइन अप करने को कहें। |
| कैंपेन **Sending** पर अटका है | ईमेल भेजना बीच में रुक गया। | **Campaigns** पर **⋮** → **Finish sending** खोलें। |
| ओपन कम दिख रहे हैं | कुछ इनबॉक्स ट्रैकिंग इमेज को ब्लॉक कर देते हैं। | ओपन के साथ क्लिक की भी तुलना करें। |
