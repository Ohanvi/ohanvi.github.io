# हाल के संपर्कों पर वापस जाएँ { #jump-back-to-recent-contacts }

जिन लोगों के साथ आपने अभी-अभी काम किया था, उन्हें एक छोटी सूची से खोलें। अंत में आप दो क्लिक में उनके रिकॉर्ड पर वापस होंगे। यह सूची आपके अपने डिवाइस पर रखी जाती है, इसलिए सिर्फ़ आपके लिए है।

## शुरू करने से पहले { #before-you-start }

- आपको बाएँ रेल में **Contacts** दिखता हो और उसके पैनल में **All contacts** हो।
- आपने इस डिवाइस से कम से कम एक संपर्क खोला हो या उसे कॉल किया हो।

## चरण { #steps }

### सूची खोलें { #open-the-list }

1. बाएँ रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. ऊपर की बार में **Recent Contacts** आइकन पर क्लिक करें।
3. सूची पढ़ें। हर पंक्ति में संपर्क का नाम और उसके नीचे एक लाइन होती है। बिना नाम वाले संपर्क के लिए **Unnamed contact** दिखता है।

### सूची से कोई संपर्क खोलें { #open-a-contact-from-the-list }

1. **Recent Contacts** में किसी नाम पर क्लिक करें।
2. विंडो बंद हो जाती है और संपर्क का ओवरव्यू खुल जाता है।

### सूची बंद करें { #close-the-list }

1. **Close** पर क्लिक करें।

### संपर्क सूची में कैसे जुड़ता है { #what-adds-a-contact-to-the-list }

- ग्रिड में संपर्क खोलने पर वह जुड़ जाता है।
- संपर्क को कॉल करने पर भी वह जुड़ जाता है। देखें [संपर्कों को कॉल करें और अपनी कॉल की समीक्षा करें](call-contacts-and-review-calls.md)।

अगर सूची खाली है, तो विंडो में **No recent contacts yet.** लिखा होता है। कोई संपर्क खोलें या कॉल करें, वह यहाँ दिखने लगेगा।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No recent contacts yet.** | आपने इस डिवाइस से किसी को खोला या कॉल नहीं किया है। | कोई संपर्क खोलें, फिर दोबारा देखें। |
| दूसरे कंप्यूटर पर सूची अलग है | सूची हर डिवाइस पर अलग रखी जाती है। | वही डिवाइस इस्तेमाल करें, या संपर्क को खोजें। |
| कोई संपर्क अब नहीं खुलता | संपर्क डिलीट या मर्ज हो गया है। | **All contacts** में खोजें। देखें [संपर्क प्रबंधित करें](manage-contacts.md)। |
