# Audience

Audience holds the **Emails** tab for contacts and the **Email Groups** tab for lists and segments.

## Where to find it

Open **Email** in the left rail, then select **Audience**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Add contacts, lists and segments](../manage-email-contacts.md) | You are bringing people in. |
| [Find, tag and export contacts](../find-tag-and-export-contacts.md) | You want to filter, label or export. |
| [Use Email Groups](../use-email-groups.md) | You manage lists and rule segments. |

## Before you start

- Permission to email the people you add.
