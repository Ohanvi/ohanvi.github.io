# Ads Manager { #ads-manager }

**Ads Manager** से आप Ohanvi के अंदर ही Facebook और Instagram के विज्ञापन चला सकते हैं। यहाँ Meta कनेक्ट करें, विज्ञापन बनाएँ, नतीजे देखें और वेबसाइट इवेंट वापस Meta को भेजें। नीचे के हर पेज में इसका एक हिस्सा समझाया गया है।

![Ads Manager टैब, जिसमें टूलबार, स्टेटस फ़िल्टर, मेट्रिक कार्ड और विज्ञापनों की टेबल दिख रही है](../../assets/screenshots/ads-manager-manage-your-ads-01.png)

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट है। देखें [अपना WhatsApp नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आप एक Facebook Page और एक Meta ad account चलाते हैं।
- आपको **WhatsApp** पैनल में **Ads Manager** दिखता है। न दिखे तो अपने एडमिन से पूछें।
