# बार-बार चलने वाले शेड्यूल मैनेज करें { #manage-recurring-schedules }

बार-बार चलने वाला शेड्यूल हर बार मैसेज भेजता रहता है, जैसे हर हफ़्ते दोहराया जाने वाला WhatsApp ब्रॉडकास्ट। ऐसे सारे शेड्यूल एक लिस्ट में देखने के लिए **Recurring** खोलें। वहाँ से किसी सीरीज़ का समय बदल सकते हैं, उसे पॉज़ कर सकते हैं या बंद कर सकते हैं। इस गाइड के बाद आपको पता होगा कि क्या, कब दोहराया जा रहा है और उसे कैसे बंद करना है।

## शुरू करने से पहले { #before-you-start }

- आप लेफ़्ट रेल में **Schedule** खोल सकते हों। देखें [जो कुछ भी शेड्यूल है, सब देखें](view-schedule.md)।
- आपके पास कम से कम 1 दोहराया जाने वाला आइटम हो। अभी ऐसे शेड्यूल उन WhatsApp ब्रॉडकास्ट से आते हैं जिनमें **Repeat** ऑप्शन (**Daily**, **Weekly**, **Monthly** या **Yearly**) चुना गया हो।

## स्टेप { #steps }

### देखें कि क्या दोहराया जाता है { #see-what-repeats }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Recurring** चुनें। **Recurring** पेज लिस्ट व्यू में खुलता है।
2. किसी सीरीज़ पर क्लिक करें। जानकारी में **Recurrence** फ़ील्ड दोहराने का नियम दिखाती है, जैसे **WEEKLY** [VERIFY: displayed value format]।
3. स्टेटस देखें। चल रही सीरीज़ में **Live** या **Scheduled** दिखता है।

### अगले मैसेज का समय बदलें { #move-the-next-send }

1. सीरीज़ चुनें और **Reschedule** पर क्लिक करें।
2. नई तारीख और समय चुनें। **Rescheduled.** मैसेज आता है।

### पॉज़ करें, बंद करें या दोहराने का नियम बदलें { #pause-stop-or-change-the-repeat-rule }

Schedule में सीरीज़ दिखती है, पर उसे WhatsApp **Scheduler** चलाता है।

1. सीरीज़ चुनें और **Edit** पर क्लिक करें। WhatsApp **Scheduler** खुल जाता है।
2. सीरीज़ चुनें। पैनल में **Repeats**, **Next send** और **Ends** दिखते हैं।
3. अब चुनें कि क्या करना है:
    - सीरीज़ को रोकने के लिए **Pause** पर क्लिक करें। फिर शुरू करने के लिए **Resume** पर क्लिक करें।
    - सीरीज़ को पूरी तरह खत्म करने के लिए **Stop** पर क्लिक करें।
    - आखिरी तारीख तय करने के लिए **Ends** बदलें। या **No end date** चुनें, तब सीरीज़ आपके रोकने तक चलती रहेगी।

आप **WhatsApp** → **Manage** → **Scheduler** से भी WhatsApp **Scheduler** में जा सकते हैं।

### नया बार-बार जाने वाला ब्रॉडकास्ट बनाएँ { #set-up-a-new-repeating-broadcast }

1. **New schedule** पर क्लिक करें, फिर **New in WhatsApp** पर।
2. ब्रॉडकास्ट की **When** फ़ील्ड में **Schedule** चुनें और पहले मैसेज का समय चुनें।
3. **Repeat** में **Daily**, **Weekly**, **Monthly** या **Yearly** चुनें। नीचे दिखने वाला हिंट पहले मैसेज का समय और दोहराने का नियम बता देता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Recurring** में **Nothing scheduled here** दिख रहा है | किसी भी आइटम का दोहराने का नियम **Once** के अलावा कुछ नहीं है। | किसी WhatsApp ब्रॉडकास्ट में **Repeat** सेट करें। या देखें कि सीरीज़ बंद तो नहीं हो गई। |
| बंद की हुई सीरीज़ अब भी लिस्ट में दिख रही है | बंद सीरीज़ **Cancelled** स्टेटस के साथ Schedule में रह सकती है। | उसे छिपाने के लिए स्टेटस फ़िल्टर में **Scheduled** चुनें। |
| बार-बार चलने वाली सीरीज़ पर **Cancel** करने से पूरी सीरीज़ हट जाती है | WhatsApp शेड्यूल कैंसिल करने पर जॉब ही बंद हो जाता है। "सिर्फ़ एक बार छोड़ें" का ऑप्शन नहीं है। | किसी एक मैसेज को छोड़ना हो, तो **Reschedule** पर क्लिक करें और अगले मैसेज का समय आगे कर दें। |
| **Could not reschedule.** | WhatsApp शेड्यूलिंग ने नया समय नहीं माना। | आगे का कोई समय चुनें और दोबारा कोशिश करें। |
