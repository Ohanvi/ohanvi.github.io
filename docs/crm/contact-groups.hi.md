# संपर्क समूह बनाएँ और प्रबंधित करें { #create-and-manage-contact-groups }

संपर्क समूह लोगों की एक सेव की हुई सूची है, जिसे हर मॉड्यूल टार्गेट कर सकता है, जैसे व्हाट्सऐप ब्रॉडकास्ट या CRM की कोई सूची। इस पेज के अंत तक आपके पास एक समूह होगा, जो हाथ से या किसी नियम से भरा होगा और ब्रॉडकास्ट के लिए तैयार होगा।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Contacts** दिखता है और उसके पैनल में **Contact groups** है। अगर नहीं, तो अपने एडमिन से कहें कि आपके रोल को CRM सेगमेंट का एक्सेस दें। देखें [सेटिंग्स ओवरव्यू](../settings/index.md)।
- समूह बनाने, एडिट करने या डिलीट करने के लिए आपके रोल के पास CRM सेगमेंट का सेव एक्सेस होना चाहिए। इसके बिना **New group**, **Edit** और **Delete** नहीं दिखते।
- आपके पास कुछ संपर्क हैं। देखें [संपर्क प्रबंधित करें](manage-contacts.md) या [संपर्क इम्पोर्ट और सिंक करें](import-and-sync-contacts.md)।

## चरण { #steps }

### अपने समूह खोलें { #open-your-groups }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **Contact groups** चुनें।

    ![Contact groups, जिसमें बाईं ओर समूहों की सूची और दाईं ओर चुने हुए समूह के सदस्य हैं (सदस्य धुंधले किए गए हैं)](../assets/screenshots/crm-contacts-3-groups.png)

2. बाईं ओर की सूची में CRM और व्हाट्सऐप, दोनों के सभी समूह दिखते हैं। किसी को खोजने के लिए **Search groups…** में टाइप करें।
3. किसी समूह पर क्लिक करें। उसके सदस्य दाईं ओर दिखते हैं, साथ में एक लाइन बताती है कि उसे कौन-से कैंपेन इस्तेमाल करते हैं, जैसे **Not used by a campaign yet**।

हर समूह बताता है कि वह अपडेट कैसे रहता है:

| बैज | मतलब |
| --- | --- |
| **Rule** | सदस्यता नियम के हिसाब से चलती है — लोग अपने-आप जुड़ते और हटते हैं। |
| **Auto** | अपने-आप अपडेट रहता है, जैसे किसी कनेक्टेड स्टोर से। |
| कोई बैज नहीं | हाथ से जोड़ा गया। |

### समूह बनाएँ { #create-a-group }

1. **New group** पर क्लिक करें। **New group** डायलॉग खुलता है।
2. **Name** में समूह का नाम लिखें, जैसे `Wholesale partners`।
3. **What this group is** में बताएँ कि इसमें कौन आएगा, जैसे `Account type: Wholesale`।
4. लोगों को हाथ से जोड़ने के लिए **Fill it from a rule** को बंद रहने दें।
5. **Save** पर क्लिक करें। **Group created.** संदेश दिखता है।

### नियम से समूह भरें { #fill-a-group-from-a-rule }

जब सदस्यता किसी फ़ील्ड के हिसाब से चलनी चाहिए, जैसे एक ही शहर के सभी लोग, तब नियम इस्तेमाल करें।

1. **New group** डायलॉग में **Fill it from a rule** चालू करें।
2. **Rule (criteria JSON)** में नियम लिखें। उदाहरण के लिए, सभी क्वालिफ़ाइड लीड:

    ```json
    {"memberType":"LEAD","filters":{"leadStatus":"QUALIFIED"}}
    ```

3. `memberType` को `CONTACT` या `LEAD` पर सेट करें। `filters` के अंदर एक या ज़्यादा फ़ील्ड और मिलाने की वैल्यू लिखें। किसी व्यक्ति को हर फ़िल्टर से मेल खाना होगा।
    - संपर्कों के लिए: `city`, `state`, `country`, `department`, `accountId`, `leadSourceId`।
    - लीड के लिए: `leadStatus`, `rating`, `city`, `state`, `country`, `industry`, `leadSourceId`।
4. **Save** पर क्लिक करें।

वैल्यू बिल्कुल मिलनी चाहिए, पर अक्षर छोटे-बड़े होने से फ़र्क नहीं पड़ता। उदाहरण के लिए, `{"memberType":"CONTACT","filters":{"city":"Pune"}}` उन संपर्कों को ढूँढता है जिनका शहर Pune या pune है।

### समूह में लोगों को जोड़ें { #add-people-to-a-group }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. हर व्यक्ति के बगल वाले चेकबॉक्स पर टिक करें। एक बार दिखाती है कि कितने चुने गए हैं।
3. **Add to segment** पर क्लिक करें। **Add to which group?** सूची खुलती है।
4. समूह चुनें। **Added N to …** संदेश इसकी पुष्टि करता है।

सिर्फ़ हाथ से भरे जाने वाले समूह ही दिखते हैं। नियम वाला समूह अपने सदस्य खुद तय करता है।

आप **WhatsApp** → **Contact** से इम्पोर्ट करते समय भी लोगों को जोड़ सकते हैं, जहाँ **Add to List** फ़ील्ड में आप कोई सूची चुन सकते हैं।

### समूह से लोगों को हटाएँ { #remove-people-from-a-group }

1. **Contact groups** में समूह खोलें।
2. किसी सदस्य पर हटाने का आइकन (**Remove from group**) क्लिक करें, या कई सदस्यों पर टिक करके **Remove from group** पर क्लिक करें।
3. पुष्टि में **Remove** पर क्लिक करें। संपर्क Ohanvi में बने रहते हैं; सिर्फ़ समूह में उनकी जगह हटती है।

नियम वाला समूह इसके बजाय **Membership follows the rule** दिखाता है। समूह में कौन रहे, यह बदलने के लिए नियम बदलें।

### समूह को ब्रॉडकास्ट करें { #broadcast-to-a-group }

1. समूह पर **Broadcast** क्लिक करें। Ohanvi **Opening the broadcast composer for …** दिखाता है और व्हाट्सऐप ब्रॉडकास्ट कंपोज़र खोलता है।
2. कंपोज़र में ऑडियंस के रूप में वही समूह चुनें। समूह अपने-आप नहीं चुना जाता। देखें [व्हाट्सऐप ब्रॉडकास्ट कैंपेन भेजें](../whatsapp/send-broadcast-campaign.md)।

### समूह एडिट या डिलीट करें { #edit-or-delete-a-group }

1. समूह खोलें और **Edit** पर क्लिक करें। नाम, विवरण या नियम बदलें, फिर **Save** पर क्लिक करें। **Group updated.** संदेश दिखता है।
2. डिलीट करने के लिए **Delete** पर क्लिक करें, फिर **Delete group** की पुष्टि में **Delete** पर क्लिक करें।

!!! warning "समूह डिलीट करने को वापस नहीं किया जा सकता"
    सेव की हुई सूची उन सभी मॉड्यूल से हट जाती है जो उसे इस्तेमाल करते हैं। उसमें मौजूद लोग आपके संपर्कों में बने रहते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not save the group.** | नाम किसी दूसरे समूह में इस्तेमाल हो चुका है, नाम खाली है, या नियम का JSON सही नहीं है। | अलग नाम रखें। जाँचें कि नियम में `memberType` `LEAD` या `CONTACT` पर सेट है और सिर्फ़ ऊपर बताए गए फ़िल्टर हैं। |
| **No hand-picked group to add them to.** | आपके पास हाथ से भरा जाने वाला कोई समूह नहीं है। | **Fill it from a rule** बंद रखकर एक समूह बनाएँ। |
| किसी को हटाते समय **Membership follows the rule — …** | नियम वाले समूहों में हाथ से चुने सदस्य नहीं होते। | इसके बजाय नियम एडिट करें। |
| **CRM groups did not load** या **WhatsApp groups did not load** | समूहों का एक स्रोत नहीं खुल पाया। | बाकी समूह काम करते रहते हैं। थोड़ी देर बाद पेज रीलोड करें। |
| नियम वाला समूह खाली है | कोई भी हर फ़िल्टर से मेल नहीं खाता, या किसी वैल्यू की स्पेलिंग अलग है। | कुछ संपर्कों पर सटीक वैल्यू जाँचें, फिर नियम एडिट करें। |
