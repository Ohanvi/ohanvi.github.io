# Tally अकाउंटिंग कनेक्ट करें { #connect-tally-accounting }

अपने लेजर, पार्टी, आइटम और वाउचर को Ohanvi के साथ सिंक में रखने के लिए **Accounting ERP** से Tally कनेक्ट करें। पहले आप Tally कनेक्ट करते हैं और कंपनी चुनते हैं। फिर ड्राई रन चलाकर देखते हैं कि क्या बदलेगा, और उसके बाद सिंक करते हैं। पहला कनेक्शन बनाने में करीब 20 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **Settings** में **Integrations** खोल पाते हों। **Accounting ERP** न दिखे, तो किसी एडमिन से कहें कि वह आपके संगठन के लिए Accounting ERP चालू कर दे।
- Tally इंस्टॉल हो और जिस कंपनी को सिंक करना है, वह Tally में खुली हो।
- आपको पता हो कि Ohanvi, Tally तक कैसे पहुँचेगा:
    - **Direct:** Tally खुला हो और उसका HTTP सर्वर चालू हो। आपको उसका पता भी मालूम हो।
    - **Bridge:** नेटवर्क से Tally तक पहुँचा नहीं जा सकता। तब आप Tally वाले कंप्यूटर पर एक छोटा ब्रिज एजेंट इंस्टॉल करते हैं।

## जो शब्द आपको दिखेंगे { #words-you-will-see }

| शब्द | मतलब |
| --- | --- |
| **Connection** | Ohanvi और Tally की एक कंपनी के बीच सेव किया हुआ एक लिंक। |
| **Bridge** | Tally वाले कंप्यूटर पर चलने वाला एक छोटा एजेंट। वह उसी कंप्यूटर पर Tally तक पहुँचता है, इसलिए Tally को इंटरनेट पर रखने की ज़रूरत नहीं पड़ती। |
| **Dry run** | ऐसा सिंक जो कुछ नहीं लिखता। वह बस दिखाता है कि क्या बदलेगा। |
| **Sync now** | असली सिंक, जो बदलाव लिख देता है। |
| **Run** | एक बार का सिंक। इसमें **Fetched**, **Created**, **Updated**, **Conflicts** और **Errors** की गिनती दिखती है। |
| **Mapping** | Tally के लेजर ग्रुप, वाउचर टाइप, यूनिट और गोदाम को Ohanvi के कोड से मिलाना। |

## स्टेप { #steps }

### Accounting ERP खोलें { #open-accounting-erp }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. बाईं तरफ़ की लिस्ट में **Workspace** के नीचे **Integrations** चुनें।
3. **Connectors** के नीचे **Accounting ERP** पर क्लिक करें। **Accounting ERP** पेज खुलता है।
4. टाइटल के नीचे की लाइन पढ़ें। उसमें लिखा है कि Tally कनेक्ट करें और लेजर, पार्टी, आइटम और वाउचर सिंक में रखें।
5. अपने प्रोवाइडर का कार्ड ढूँढें। उस पर **Set up** लिखा दिखता है, या **1 connected** जैसी गिनती। BUSY का कार्ड इसकी जगह उसका WhatsApp सेटअप खोलता है। [WhatsApp वेबहुक और इंटीग्रेशन सेट करें](../whatsapp/whatsapp-webhooks-and-integrations.md) देखें।

### Tally कनेक्ट करें { #connect-tally }

1. **Connect ERP** पर क्लिक करें, या Tally कार्ड पर **Connect** पर क्लिक करें। कनेक्ट विज़ार्ड खुलता है। उसके स्टेप हैं **Provider**, **Transport**, **Test**, **Company**, **Scope** और **Done**।
2. **Provider** पर **Which accounting system do you use?** के नीचे Tally चुनें। जिस प्रोवाइडर पर **Coming soon** लिखा है, उसे अभी नहीं चुन सकते। **Continue** पर क्लिक करें।
3. **Transport** पर **Connection name** लिखें, जैसे `Head office Tally`। यह नाम हब पर दिखता है।
4. **How should we reach** Tally **?** के नीचे एक चिप चुनें, जैसे **HTTP** या **Bridge**।
5. Direct कनेक्शन के लिए स्क्रीन पर दिख रहे फ़ील्ड भरें। तारे (*) वाले फ़ील्ड ज़रूरी हैं। जैसे, Tally के HTTP सर्वर का पता और पोर्ट। फ़ील्ड के नाम हर प्रोवाइडर के हिसाब से अलग होते हैं।
6. Bridge के लिए नीचे दिए **Add a bridge** के स्टेप फ़ॉलो करें, फिर लिस्ट में से अपना ब्रिज चुनें। लिस्ट में हर ब्रिज का **Heartbeat** दिखता है।
7. **Continue** पर क्लिक करें।

### ब्रिज जोड़ें { #add-a-bridge }

1. कनेक्ट विज़ार्ड में **Add bridge** पर क्लिक करें। आप हब पेज पर **Bridges** के पास वाले **Add bridge** पर भी क्लिक कर सकते हैं।
2. **Name this computer** में कंप्यूटर का नाम लिखें, जैसे `Office PC`। यह ज़रूरी है।
3. ब्रिज को Tally वाले कंप्यूटर पर इंस्टॉल करें। इसके लिए **Download bridge** पर क्लिक करें।
4. ब्रिज कोड माँगे, तो विंडो में दिखा हुआ कोड डालें। कोड सिर्फ़ एक बार दिखता है। उसे कॉपी करने के लिए कॉपी आइकन पर क्लिक करें। विंडो में **Valid until** के साथ एक समय भी दिखता है।
5. **Bridge status** पर नज़र रखें। ब्रिज के कनेक्ट होने तक उसमें **Waiting for the bridge…** लिखा रहता है।
6. उस कंप्यूटर पर Tally खुला रखें।

### कनेक्शन टेस्ट करें { #test-the-connection }

1. **Test** पर हेडिंग के नीचे की लाइन पढ़ें। Bridge के लिए उसमें लिखा है कि Ohanvi कनेक्शन सेव करेगा और ब्रिज से Tally तक पहुँचने को कहेगा। इसके लिए उस कंप्यूटर पर Tally खुला होना चाहिए। Direct कनेक्शन के लिए लिखा है कि Ohanvi आपके दिए पते पर Tally को कॉल करेगा। इसके लिए Tally खुला होना चाहिए और उसका HTTP सर्वर चालू होना चाहिए।
2. **Test connection** पर क्लिक करें।
3. कनेक्शन ठीक हो, तो नतीजे में **Connected** लिखा आता है। साथ में वर्शन, रिस्पॉन्स का समय और **companies visible** दिखते हैं।
4. कनेक्शन न बने, तो नतीजे में **Could not reach the ERP** लिखा आता है। वजह ठीक करें और **Test again** पर क्लिक करें।
5. **Continue** पर क्लिक करें।

### कंपनी चुनें { #choose-the-company }

1. **Company** पर **Which company should this connection sync?** पढ़ें। हर कंपनी के साथ उसका **GSTIN** और **Books from** तारीख या वित्तीय वर्ष की शुरुआत दिखती है।
2. जिस कंपनी को सिंक करना है, उस पर क्लिक करें।
3. लिस्ट में **No companies found** लिखा हो, तो Tally में कंपनी खोलें। फिर **Ask Tally again** पर क्लिक करें।
4. **Continue** पर क्लिक करें।

### चुनें कि क्या सिंक करना है { #choose-what-to-sync }

1. **Scope** पर **What to sync** के नीचे वे सभी रिकॉर्ड टाइप टिक करें जो लाने हैं, जैसे लेजर, पार्टी, आइटम या वाउचर।
2. **Voucher types** के नीचे अपने काम के वाउचर टाइप टिक करें। एक भी टिक न हो, तो सभी वाउचर टाइप शामिल होते हैं।
3. **Direction** का विकल्प मिले, तो उसे सेट करें।
4. **Sync mode** में चुनें कि सिंक कैसे हो। **Automatic** चुनें, तो **Every (minutes)** में मिनट लिखें।
5. **When both sides changed** में चुनें कि दोनों तरफ़ बदलाव होने पर टकराव कैसे सुलझे।
6. लेजर, पार्टी और आइटम के बदलाव बिना प्रीव्यू के सीधे लागू करवाने हों, तो **Apply master changes automatically** चालू करें। वाउचर हमेशा ड्राई-रन रिव्यू के बाद ही लागू होते हैं।
7. **Save and finish** पर क्लिक करें।
8. **Done** पर **Connection name is ready** पढ़ें। उसमें लिखा है कि कुछ भी लिखे जाने से पहले ड्राई रन से शुरू करें और देखें कि क्या बदलेगा। **Open connection** पर क्लिक करें।

### ड्राई रन चलाएँ { #run-a-dry-run }

1. कनेक्शन पेज पर **Dry run** पर क्लिक करें। आप **More actions** में जाकर **Dry run** भी चुन सकते हैं।
2. **Runs** टैब खोलें। नए रन के आगे **Running — this page updates by itself.** लिखा दिखता है।
3. रन पूरा होने पर **Dry run ready for review** मैसेज आता है। उसमें लिखा होता है कि अभी कुछ नहीं लिखा गया है।
4. गिनती देखें: **Fetched**, **Staged**, **Created**, **Updated**, **Skipped**, **Conflicts**, **Errors** और **Pushed**। **By record type** टेबल में यही गिनती रिकॉर्ड टाइप के हिसाब से अलग-अलग दिखती है।
5. हर बदलाव देखने के लिए **Preview & apply** पर क्लिक करें।
6. बदलाव सही लगें, तो उन्हें लागू करें।

अगर पेज बताए कि अकाउंटिंग एडॉप्टर इस सर्वर पर इंस्टॉल नहीं है, तो आप प्रीव्यू देख तो सकते हैं, पर बदलाव लागू नहीं कर सकते। ऐसे में सपोर्ट से संपर्क करें।

### कोड मैप करें { #map-codes }

1. कनेक्शन पेज पर **Mapping** टैब खोलें।
2. उसमें **Nothing to map yet** लिखा हो, तो पहले ड्राई रन चलाएँ। लेजर ग्रुप, वाउचर टाइप, यूनिट और गोदाम Tally से आने के बाद ही दिखते हैं।
3. नंबर के साथ **unmapped** बैज देखें। जिस रो पर **Unmapped** लिखा है, उसे Ohanvi कोड चाहिए।
4. हर रो के लिए **Ohanvi code** लिखें। या **Auto-map by name** पर क्लिक करें। इससे खाली रो नाम मिलाकर भर जाती हैं। तब **Unmapped keys filled by name.** मैसेज आता है।
5. जितने बदलाव किए हैं, उनकी संख्या के साथ दिख रहे **Save** पर क्लिक करें। **Mapping saved.** मैसेज आता है। अपने बदलाव कैंसिल करने हों, तो **Discard** पर क्लिक करें।

### सिंक सेटिंग्स बदलें { #change-sync-settings }

1. **Sync settings** टैब खोलें।
2. फ़ील्ड वैसे ही बदलें, जैसे **Choose what to sync** में बताया है।
3. **Save settings** पर क्लिक करें। **Sync settings saved.** मैसेज आता है। अपने बदलाव कैंसिल करने हों, तो **Discard** पर क्लिक करें।

### असली सिंक करें { #sync-for-real }

1. कनेक्शन पेज पर **Sync now** पर क्लिक करें।
2. **Runs** टैब पर नज़र रखें। रन की जानकारी देखने के लिए उसे खोलें। कार्ड में **Last run**, **Fetched**, **Created**, **Updated**, **Conflicts** और **Errors** दिखते हैं।
3. **Conflicts** 0 से ज़्यादा हो, तो कार्ड पर **Review in the run** लिखा आता है। रन खोलें और उन्हें देखें।

### सिंक की गड़बड़ियाँ ठीक करें { #fix-sync-errors }

1. **Errors** टैब खोलें। ऊपर की लिस्ट से स्टेटस के हिसाब से फ़िल्टर करें। शुरुआत **All** से होती है।
2. हर रो में रिकॉर्ड, एरर कोड और मैसेज दिखता है।
3. किसी रो पर **Resolve** पर क्लिक करें।
4. एक ऐक्शन चुनें: **Retry**, **Skip**, **Apply theirs** या **Keep ours**।
5. चाहें तो एक नोट जोड़ें। फिर कन्फ़र्म करें। **Error updated.** मैसेज आता है और रो में आपका नोट दिखता है।
6. टैब में **No errors** लिखा हो, तो कुछ करने की ज़रूरत नहीं है।

### कंपनी बदलें { #change-the-company }

1. **Companies** टैब खोलें।
2. लिस्ट रीफ़्रेश करने के लिए **Ask the ERP again** पर क्लिक करें। **Company list refreshed.** मैसेज आता है।
3. किसी दूसरी कंपनी पर **Use this company** पर क्लिक करें। मैसेज में बताया जाता है कि वह कंपनी चुन ली गई है। चुनी हुई कंपनी पर **Selected** दिखता है।

### कनेक्शन टेस्ट करें या कैंसिल करें { #test-or-revoke-a-connection }

1. कनेक्शन पेज पर **Test** पर क्लिक करें (या **More actions** में जाएँ)। कनेक्शन ठीक हो, तो **Connected in** के साथ एक नंबर और **ms.** लिखा मैसेज आता है। पेज पर **Test passed** या **Test failed** दिखता है।
2. कनेक्शन हटाना हो, तो **Revoke** पर क्लिक करें।
3. **Revoke this connection?** में चेतावनी पढ़ें। सेव किए हुए क्रेडेंशियल मिट जाते हैं और लाइन में लगे सिंक कैंसिल हो जाते हैं। जो रिकॉर्ड पहले ही Ohanvi में सिंक हो चुके हैं, वे बने रहते हैं। फिर से सिंक करने के लिए आपको दोबारा कनेक्ट करना होगा।
4. **Revoke** पर क्लिक करें। **Connection revoked.** मैसेज आता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No ERP connectors on this server** | आपके संगठन के लिए Accounting ERP चालू नहीं है। | किसी एडमिन से इसे चालू करने को कहें। |
| **Could not reach the ERP** | Tally बंद है, या उसका HTTP सर्वर बंद है, या ब्रिज ऑफ़लाइन है। | Tally को HTTP सर्वर चालू करके खोलें, या ब्रिज देखें। फिर **Test again** पर क्लिक करें। |
| **No companies found** | कंपनी Tally में खुली नहीं है। | Tally में कंपनी खोलें, फिर **Ask Tally again** पर क्लिक करें। |
| **Waiting for the bridge…** बदल नहीं रहा | ब्रिज इंस्टॉल नहीं हुआ है या कोड डाला नहीं गया। | Tally वाले कंप्यूटर पर ब्रिज इंस्टॉल करें और कोड डालें। कोड सिर्फ़ एक बार दिखता है। वह एक्सपायर हो गया हो, तो नया ब्रिज जोड़ें। |
| **Could not start the sync.** | रिक्वेस्ट फ़ेल हो गई। | अपना कनेक्शन देखें और दोबारा कोशिश करें। |
| वाउचर लागू नहीं हो रहे। | वाउचर हमेशा ड्राई-रन रिव्यू के बाद ही लागू होते हैं। | रन खोलें और **Preview & apply** पर क्लिक करें। |
| **Could not save the mapping.** | मैपिंग की रिक्वेस्ट फ़ेल हो गई। | दोबारा कोशिश करें। |
| **Could not resolve the error.** | Resolve की रिक्वेस्ट फ़ेल हो गई। | दोबारा कोशिश करें। |
