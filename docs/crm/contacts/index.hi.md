# संपर्क { #contacts }

**Contacts** में वे लोग रहते हैं जिनसे आपका बिज़नेस बात करता है। व्हाट्सऐप, ईमेल, कॉमर्स और CRM सब एक ही रिकॉर्ड पढ़ते हैं, इसलिए यहाँ किया गया बदलाव हर जगह दिखता है। अपने संपर्क जोड़ने, खोजने, कॉल करने, ईमेल करने, ग्रुप में रखने और सुरक्षित रखने के लिए इन गाइड का इस्तेमाल करें।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Contacts** खोलें।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में CRM मॉड्यूल हो, और आपके रोल को CRM एक्सेस मिला हो। वरना **Contacts** आइकन नहीं दिखता। अपने एडमिन से पूछें।
- चैट से संपर्क अपने आप आने के लिए, आपका व्हाट्सऐप नंबर कनेक्ट हो।
