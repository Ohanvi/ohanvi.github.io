# CRM कॉन्फ़िगर करें { #configure-the-crm }

इन्हें एक बार सेट करें, फिर ज़्यादातर वैसे ही रहने दें। हर डील, बोर्ड, फ़नल और फ़ोरकास्ट इन्हीं का इस्तेमाल करता है। ये स्क्रीन एडमिन के लिए हैं।

**कहाँ मिलेगा:** नीचे बाईं ओर अपने नाम के पहले अक्षरों पर क्लिक करें, **Settings** चुनें, फिर **CRM**।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [पाइपलाइन सेट करें](../set-up-pipelines.md) | आप वे चरण बनाते हैं जिनसे होकर डील आगे बढ़ती है। |
| [लीड के स्रोत प्रबंधित करें और देखें कि कौन से कन्वर्ट होते हैं](../manage-lead-sources.md) | आप वे चैनल जोड़ते हैं जहाँ से आपकी लीड आती हैं। |
| [प्रोडक्ट्स जोड़ें](../add-products.md) | आप जो बेचते हैं उसे जोड़ते हैं, ताकि डील में प्रोडक्ट लाइनें जुड़ सकें। |
| [सेल्स कोटा तय करें](../set-sales-quotas.md) | आप हर सेल्सपर्सन को महीने का टारगेट देते हैं। |

## शुरू करने से पहले { #before-you-start }

- आप एडमिन हों। CRM सेटिंग्स पेज पर लिखा होता है **Configure how your CRM works — admin only**।
- आपके वर्कस्पेस में CRM मॉड्यूल हो।
