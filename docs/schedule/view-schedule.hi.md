# जो कुछ भी शेड्यूल है, सब देखें { #view-everything-scheduled }

व्हाट्सऐप, CRM, ईमेल, सोशल और अपॉइंटमेंट में आपके वर्कस्पेस ने जो कुछ भी कतार में रखा है, उसे देखने के लिए **Schedule** सेक्शन का इस्तेमाल करें। आख़िर में आपके पास एक कैलेंडर या सूची होगी, जो उस दिन, चैनल, मालिक और स्टेटस तक सीमित है जो आपके काम का है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखता हो। अगर नहीं, तो अपने एडमिन से कहें कि आपके रोल को शेड्यूल का एक्सेस दें। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल के पास होता है। देखें [सेटिंग्स](../settings/index.md)।
- कम से कम एक मॉड्यूल में कुछ पहले से शेड्यूल हो, जैसे व्हाट्सऐप ब्रॉडकास्ट या ईमेल कैंपेन। Schedule सेक्शन आइटम दिखाता है; आप उन्हें उनके अपने मॉड्यूल में बनाते हैं।

## चरण { #steps }

### Schedule खोलें { #open-the-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **All schedules** चुनें। **My Schedule** पेज मौजूदा महीने के **Calendar** व्यू में खुलता है।
2. पिछले या अगले महीने पर जाने के लिए महीने के नाम के बगल के तीरों का इस्तेमाल करें। मौजूदा महीने पर लौटने के लिए **Today** पर क्लिक करें।
3. हर आइटम अपने समय और शीर्षक के साथ रंगीन चिप के रूप में दिखता है। रंग से चैनल पता चलता है।
4. किसी दिन पर क्लिक करें, उस दिन शेड्यूल हर चीज़ की सूची खुलती है, जैसे **Today · 4 scheduled**। किसी आइटम का ब्योरा खोलने के लिए उस पर क्लिक करें।
5. अगर किसी दिन में डिब्बे में समाने से ज़्यादा आइटम हैं, तो डिब्बे में **+N more** दिखता है, जैसे **+3 more**। सब देखने के लिए दिन पर क्लिक करें।

### कैलेंडर और सूची के बीच बदलें { #switch-between-calendar-and-list }

1. पेज के ऊपर **List** पर क्लिक करें। आइटम समय के क्रम में सूची में दिखते हैं, दिन के शीर्षकों के तहत। शीर्षक **Yesterday**, **Today**, **Tomorrow** और फिर **Fri, 3 Oct** जैसी तारीख होते हैं।
2. सूची में किसी आइटम पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।
3. महीने के व्यू पर लौटने के लिए **Calendar** पर क्लिक करें।

!!! note "ध्यान दें"
    ब्योरे वाला पैनल तभी दिखता है जब विंडो काफ़ी चौड़ी हो, जैसे लैपटॉप या टैबलेट पर। छोटी विंडो पर आपको सिर्फ़ सूची दिखती है।

### बना-बनाया व्यू खोलें { #open-a-ready-made-view }

पैनल का हर आइटम वही पेज खोलता है, एक फ़िल्टर पहले से लगा हुआ:

| पैनल आइटम | यह क्या दिखाता है |
| --- | --- |
| **All schedules** | सब कुछ, कैलेंडर व्यू में। |
| **Today** | आज के लिए शेड्यूल आइटम, लिस्ट व्यू में। |
| **Upcoming** | आज से आगे के आइटम जो **Scheduled** या **Live** हैं, लिस्ट व्यू में। |
| **Drafts** | वे आइटम जो अभी **Draft** में हैं, लिस्ट व्यू में। |
| **WhatsApp**, **CRM**, **Email**, **Social**, **Appointments** | सिर्फ़ एक चैनल। पेज का शीर्षक बदल जाता है, जैसे **WhatsApp schedule**। |
| **Recurring** | वे आइटम जो दोहराए जाते हैं। देखें [बार-बार चलने वाले शेड्यूल प्रबंधित करें](manage-recurring-schedules.md)। |

### व्यू को फ़िल्टर करें { #filter-the-view }

1. **All schedules** पर किसी चैनल चिप पर क्लिक करें: **WhatsApp**, **CRM**, **Email**, **Social** या **Appointments**। पहले क्लिक पर सिर्फ़ वही चैनल दिखता है। चैनल वापस जोड़ने के लिए और चिप पर क्लिक करें।
2. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
3. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें। **Scheduled** में वे आइटम भी आते हैं जो **Live** या **Paused** हैं।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | सेव है पर अभी भेजने के लिए शेड्यूल नहीं हुआ। |
| **Scheduled** | दिखाए गए समय के लिए कतार में है। |
| **Live** | अभी चल रहा है, जैसे कोई बार-बार चलने वाली श्रृंखला। |
| **Sent** | जा चुका है। |
| **Paused** | अपने मॉड्यूल में रोका हुआ है। |
| **Cancelled** | रद्द किया गया। रिकॉर्ड रखा जाता है। |
| **Failed** | भेजना पूरा नहीं हुआ। वजह जानने के लिए आइटम को उसके मॉड्यूल में खोलें। |

### कुछ नया शेड्यूल करें { #schedule-something-new }

1. **New schedule** पर क्लिक करें। **New schedule — pick a channel** शीट खुलती है।
2. **New in WhatsApp**, **New in CRM**, **New in Email**, **New in Social** या **New in Appointments** चुनें। Ohanvi उस मॉड्यूल की अपनी स्क्रीन खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here**, साथ में संदेश **No schedules match these filters. Try another channel or clear the status filter.** | कोई आइटम चैनल, मालिक या स्टेटस फ़िल्टर से मेल नहीं खाता। | दूसरे चैनल चिप पर क्लिक करें, **Everyone's schedule** चुनें, या स्टेटस को वापस **Any status** करें। |
| **Could not load your schedule.** | पेज सर्वर तक नहीं पहुँच सका। | संदेश पर रीट्राई बटन पर क्लिक करें। फिर भी फ़ेल हो, तो साइन आउट करके दोबारा साइन इन करें। |
| लेफ़्ट रेल में **Schedule** नहीं है | आपके रोल में शेड्यूल का एक्सेस शामिल नहीं है। | अपने एडमिन से इसे आपके रोल में जोड़ने को कहें। |
| आपका बनाया आइटम नहीं दिख रहा | बिना तारीख और समय वाले आइटम Schedule में नहीं दिखते। | आइटम को उसके मॉड्यूल में खोलें और उसे शेड्यूल का समय दें। |
| **List** व्यू में ब्योरे वाला पैनल या एक्शन बटन नहीं हैं | ब्योरे वाले पैनल के लिए विंडो बहुत छोटी है। | ब्राउज़र विंडो चौड़ी करें, या लैपटॉप या टैबलेट इस्तेमाल करें। |
