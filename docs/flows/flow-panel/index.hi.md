# फ़्लो पैनल { #the-flow-panel }

फ़्लो पर क्लिक करने पर **Flows** सूची के बगल में फ़्लो पैनल खुलता है। यह दिखाता है कि फ़्लो क्या करता है, उसके रन कैसे रहे, और उसका इतिहास। यहीं से आप टेस्ट, पब्लिश, पॉज़ या बिल्डर भी खोल सकते हैं।

**कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, **Flows** चुनें, फिर किसी फ़्लो पर क्लिक करें।

## गाइड { #guides }

| टैब | गाइड | इसका इस्तेमाल तब करें जब |
| --- | --- | --- |
| **Overview** | [फ़्लो और फ़्लो की सूची को समझें](../flows-overview-and-list.md) | आप फ़्लो के चरण पढ़ना, उसे पब्लिश करना, चालू या बंद करना, कॉपी या डिलीट करना चाहते हैं। |
| **Recent runs** | [फ़्लो टेस्ट करें और फ़ेल हुए रन ठीक करें](../test-and-monitor-flows.md) | आप टेस्ट चलाना, रन का इतिहास पढ़ना या रन रोकना चाहते हैं। |
| **Latest output** | [किसी रन का आउटपुट विस्तार से पढ़ें](../read-a-runs-output.md) | आप देखना चाहते हैं कि हर चरण ने क्या लौटाया और कोई चरण क्यों फ़ेल हुआ। |
| **Versions** | [फ़्लो के वर्शन की समीक्षा करें](../review-flow-versions.md) | आप देखना चाहते हैं कि कौन-सा वर्शन लाइव है और हर वर्शन किसने पब्लिश किया। |

## शुरू करने से पहले { #before-you-start }

- आपको **WhatsApp** पैनल में **Flows** दिखता है। न दिखे तो अपने एडमिन से पूछें।
- फ़्लो पब्लिश, टेस्ट या बदलने के लिए आपके रोल के पास फ़्लो सेव करने का एक्सेस भी होना चाहिए।
