# सेल्स कोटा सेट करें { #set-sales-quotas }

हर सेल्सपर्सन को महीने का सेल्स टारगेट दें, फिर देखें कि वह उसके कितने करीब है। इसके बाद फ़ोरकास्ट में हर ओनर की उपलब्धि उसके कोटा के सामने दिखेगी। एक कोटा जोड़ने में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **CRM** दिखे, और उसके पैनल में **Forecast**।
- आपको ओनर का यूज़रनेम, महीना और टारगेट की रकम पता हो।

## स्टेप { #steps }

### Sales Quotas खोलें { #open-sales-quotas }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Forecast** चुनें।
2. **Manage quotas** पर क्लिक करें। **Sales Quotas** लिस्ट खुलेगी।

आप **Ctrl K** (Mac पर **⌘K**) दबाकर **Sales Quotas** लिखें और उसे चुनें, तब भी यह स्क्रीन खुल जाती है।

### कोटा जोड़ें { #add-a-quota }

1. **Add** पर क्लिक करें। **Add Sales Quotas** फ़ॉर्म खुलेगा।
2. **Owner Username** भरें। यह उस व्यक्ति का यूज़रनेम है जिसका यह टारगेट है।
3. वैकल्पिक: **Owner Display Name** भरें।
4. **Year** चुनें।
5. **Month** चुनें।
6. **Target Amount** लिखें।
7. **Currency** देख लें। यह पहले से **INR** चुनी होती है।
8. **Submit** पर क्लिक करें। **Quota created** मैसेज आएगा।

एक ओनर का एक महीने में सिर्फ़ 1 कोटा हो सकता है।

### कोटा के मुक़ाबले प्रगति देखें { #check-progress-against-a-quota }

1. **Sales Quotas** लिस्ट में उस कोटा की लाइन ढूँढें।
2. **Achievement** कॉलम में **View** पर क्लिक करें।
3. उस महीने की **Forecast vs Quota** विंडो खुल जाएगी।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **A quota for this owner and period already exists.** | उस ओनर का उस महीने का कोटा पहले से बना है। | नया बनाने की जगह मौजूदा कोटा बदलें। |
| **Target amount must be positive.** | **Target Amount** 0 या उससे कम है। | 0 से ज़्यादा रकम लिखें। |
| **Month must be between 1 and 12.** | महीना 1 से 12 के बाहर है। | 1 से 12 के बीच का महीना चुनें। |
| **Forecast vs Quota** में पूरी टीम के आँकड़े दिखते हैं | रिपोर्ट अभी ओनर के हिसाब से फ़िल्टर नहीं हो पाती। | ओनर के कोटा को **Dashboard** पर **Won by owner** से मिलाकर देखें। |
