# अपनी शेड्यूल की हुई सोशल पोस्ट देखें { #see-your-scheduled-social-posts }

शेड्यूल की हुई सभी पोस्ट एक कैलेंडर या लिस्ट में देखने के लिए **Social** व्यू खोलें। यहाँ आप देख सकते हैं कि हर पोस्ट किस नेटवर्क पर कब लाइव होगी। आप पोस्ट का समय बदल सकते हैं या उसे रोक सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। अगर यह नहीं दिख रहा, तो अपने एडमिन से कहें।
- पोस्ट में पब्लिश होने का समय तय हो। देखें [पोस्ट शेड्यूल करें और कतार मैनेज करें](../social/schedule-social-posts.md)।

## स्टेप { #steps }

### Social शेड्यूल खोलें { #open-the-social-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Social** चुनें। पेज का टाइटल **Social schedule** दिखेगा।
2. पेज इस महीने के **Calendar** व्यू में खुलता है। चैनल चिप्स यहाँ नहीं दिखते, क्योंकि यह पेज पहले से सिर्फ़ Social दिखाता है।
3. किसी दिन के आइटम देखने के लिए उस दिन पर क्लिक करें। समय के हिसाब से, दिन के हेडिंग के नीचे आइटम देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसकी जानकारी दाईं तरफ़ खुलती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर Type का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि यह आइटम किस तरह का है।

| Type | यह क्या है |
| --- | --- |
| **Post** | कनेक्ट किए हुए अकाउंट पर पब्लिश होने के लिए शेड्यूल की गई सोशल पोस्ट। |

**Audience / with** लाइन में वह सोशल नेटवर्क दिखता है, जहाँ पोस्ट जाएगी, जैसे Instagram।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | पोस्ट समय के साथ ड्राफ़्ट में सेव है। |
| **Scheduled** | पोस्ट **Scheduled** या **Queued** है और अपने समय का इंतज़ार कर रही है। |
| **Live** | पोस्ट अभी पब्लिश हो रही है। |
| **Sent** | पोस्ट पब्लिश हो चुकी है, या सिर्फ़ कुछ नेटवर्क पर पब्लिश हुई है। |
| **Failed** | पोस्ट पब्लिश नहीं हो सकी। |
| **Cancelled** | कैंसिल कर दी गई। यह पब्लिश नहीं होगी। |

### किसी आइटम में बदलाव करें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [शेड्यूल किए गए आइटम को रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।
2. Social की **Publish** स्क्रीन खोलने के लिए **Edit** पर क्लिक करें। देखें [पोस्ट शेड्यूल करें और कतार मैनेज करें](../social/schedule-social-posts.md)।
3. पोस्ट कैंसिल करने के लिए **Cancel** पर क्लिक करें। शेड्यूल की हुई पोस्ट कैंसिल हो जाती है और पब्लिश नहीं होती।
4. आइटम को Social से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छाँटें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in Social** चुनें। Ohanvi Social की **Publish** स्क्रीन खोल देगा। नया आइटम आप वहीं बनाएँगे।

## समस्या का समाधान { #troubleshooting }

| समस्या | वजह | हल |
| --- | --- | --- |
| **Nothing scheduled here** | किसी पोस्ट में पब्लिश होने का समय तय नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | Social **Publish** में कोई पोस्ट शेड्यूल करें। |
| पोस्ट **Sent** दिखती है, पर एक नेटवर्क पर नहीं है | पोस्ट सिर्फ़ कुछ नेटवर्क पर पब्लिश हुई थी। | पोस्ट को Social **Publish** में खोलें और देखें कि किस नेटवर्क पर फ़ेल हुई। |
| **Could not cancel.** | पोस्ट पहले ही पब्लिश हो चुकी है, या आपका रोल उसमें बदलाव नहीं कर सकता। | स्टेटस देखें। Social एक्सेस के लिए अपने एडमिन से कहें। |
