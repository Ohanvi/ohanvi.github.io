# फ़नल पढ़ें और बोर्ड पर लीड्स को आगे बढ़ाएँ { #read-the-funnel-and-move-leads-on-the-board }

देखें कि कितनी लीड्स हर स्टेज तक पहुँचती हैं और आप उन्हें कहाँ खो देते हैं। आख़िर में आपको पता होगा कि किस स्टेज और किस लीड सोर्स पर काम करना है, और आप लीड कार्ड को खींचकर एक स्टेज से दूसरे में ले जा सकेंगे। फ़नल पढ़ने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **CRM** दिखता हो और उसके पैनल में **Funnel** हो। इसके लिए CRM रिपोर्ट का एक्सेस चाहिए। अगर यह नहीं दिखता, तो अपने एडमिन से पूछें।
- आपके पास लीड्स हों। देखें [लीड्स के साथ काम करें](leads.md)।

## चरण { #steps }

### फ़नल खोलें { #open-the-funnel }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Funnel** चुनें।
2. ऊपर देखें कि **Funnel | Board** स्विच में **Funnel** चुना हुआ है।

### कन्वर्ज़न फ़नल पढ़ें { #read-the-conversion-funnel }

1. **Conversion funnel** पढ़ें। हर बार एक स्टेज है।
2. हर बार के नीचे देखें कि अगली स्टेज से पहले कितना हिस्सा छूट गया।
3. सबसे बड़ी गिरावट खोजें। यही वह स्टेज है जहाँ लीड्स ठंडी पड़ जाती हैं।

### लीड सोर्स की तुलना करें { #compare-lead-sources }

1. **Funnel by source** तक स्क्रॉल करें।
2. सबसे ज़्यादा कन्वर्ज़न वाला सोर्स खोजें।
3. वह स्क्रीन खोलने के लिए **Lead Sources** पर क्लिक करें। देखें [लीड के स्रोत प्रबंधित करें](manage-lead-sources.md)।

### फ़नल डाउनलोड करें { #download-the-funnel }

1. **Export** पर क्लिक करें।
2. Ohanvi फ़नल की एक Excel फ़ाइल डाउनलोड करता है।

### लीड बोर्ड पर जाएँ { #switch-to-the-lead-board }

1. **Funnel | Board** स्विच में **Board** पर क्लिक करें।
2. बाएँ से दाएँ 6 कॉलम पढ़ें: **New**, **Contacted**, **Qualified**, **Unqualified**, **Lost** और **Converted**। हर कॉलम के हेडर में उसकी लीड्स की गिनती दिखती है।
3. एक कार्ड पढ़ें। उस पर लीड का नाम होता है, उसके नीचे कंपनी, और अगर लीड का स्कोर है तो **Score** के साथ उसका नंबर।
4. अगर सभी 6 कॉलम एक साथ नहीं समाते, तो बगल में स्क्रॉल करें।
5. बार्स पर वापस जाने के लिए **Funnel** पर क्लिक करें।

कॉलम तय हैं। आप उनका नाम नहीं बदल सकते और नए कॉलम नहीं जोड़ सकते।

### लीड को दूसरी स्टेज में ले जाएँ { #move-a-lead-to-another-stage }

1. किसी लीड कार्ड को थोड़ी देर दबाए रखें।
2. उसे दूसरे कॉलम में खींचें।
3. छोड़ दें। लीड का नया स्टेटस हो जाता है।

अगर मूव नहीं हो पाता, तो संदेश **Could not move the lead.** आता है। कार्ड वहीं रहता है जहाँ था।

!!! note "ध्यान दें"
    लीड तभी **Converted** में पहुँचती है जब आप उसे **Convert** एक्शन से कन्वर्ट करते हैं। देखें [लीड्स के साथ काम करें](leads.md)।

### बदलें कि कौन-सी स्टेज दिखें { #change-which-stages-show }

1. **Edit stages** खोजें। यह सिर्फ़ प्लेटफ़ॉर्म sysadmin को दिखता है।
2. अगर यह दिखे, तो उस पर क्लिक करके अपने फ़नल व्यू में स्टेज छिपाएँ या उनका क्रम बदलें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| फ़नल खाली है | आपके पास कोई लीड नहीं है, या इस अवधि में कोई नहीं है। | लीड्स जोड़ें। देखें [लीड्स के साथ काम करें](leads.md)। |
| **CRM** पैनल में **Funnel** नहीं दिख रहा | आपके रोल को CRM रिपोर्ट का एक्सेस नहीं है। | अपने एडमिन से CRM रिपोर्ट का एक्सेस माँगें। |
| **Could not move the lead.** | स्टेटस का बदलाव सेव नहीं हुआ। | दोबारा कोशिश करें। अगर बार-बार फ़ेल हो, तो लीड पर **Move Status** का इस्तेमाल करें। |
| कार्ड खिंच नहीं रहा | आपने दबाए रखने की जगह सिर्फ़ टैप किया। | कार्ड को दबाए रखें, फिर खींचें। |
