# स्प्रिंट में काम की योजना बनाएँ { #plan-work-in-sprints }

अपनी टीम के काम की योजना स्प्रिंट नाम की तय समय-सीमाओं में बनाएँ, जो आमतौर पर 1 से 4 हफ़्ते की होती हैं। अंत में आपके पास लक्ष्य और टास्क के साथ एक स्प्रिंट होगा, वह चल रहा होगा, और खत्म होने पर अधूरा काम अगले स्प्रिंट में या वापस बैकलॉग में चला जाएगा।

## शुरू करने से पहले { #before-you-start }

- आपके प्रोजेक्ट में टास्क हैं। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।
- आपके बोर्ड का आखिरी कॉलम आपका "पूरा हुआ" कॉलम है। स्प्रिंट पूरा करते समय आखिरी कॉलम के टास्क पूरे माने जाते हैं।

## चरण { #steps }

### स्प्रिंट बनाएँ { #create-a-sprint }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. **Backlog** व्यू पर क्लिक करें। **Backlog** सेक्शन में वे सभी टास्क दिखते हैं जो किसी स्प्रिंट में नहीं हैं।
3. **Create sprint** पर क्लिक करें। **Create sprint** डायलॉग खुल जाता है।
4. **Sprint name** में कोई नाम लिखें, जैसे "Sprint 12"।
5. **Start date** और **End date** सेट करें।
6. वैकल्पिक: **Sprint goal** में लिखें कि स्प्रिंट में क्या हासिल करना है।
7. **Create** पर क्लिक करें। स्प्रिंट बैकलॉग के ऊपर दिखने लगता है।

### स्प्रिंट में टास्क जोड़ें { #add-tasks-to-a-sprint }

1. **Backlog** व्यू में किसी टास्क को **Backlog** से खींचकर स्प्रिंट में डालें।
2. इस स्प्रिंट में जो भी टास्क पूरे करने की योजना है, उनके लिए यही दोहराएँ।

किसी टास्क को बाहर निकालने के लिए उसे वापस **Backlog** में खींचें। आप टास्क के अंदर **Sprint** फ़ील्ड भी सेट कर सकते हैं। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

### स्प्रिंट शुरू करें { #start-a-sprint }

एक प्रोजेक्ट में एक समय पर सिर्फ़ 1 सक्रिय स्प्रिंट हो सकता है।

1. जिस स्प्रिंट को चलाना है उस पर **Start sprint** पर क्लिक करें। **Start another sprint** डायलॉग खुल जाता है।
2. **Sprint name** जाँचें।
3. **1 week** से **4 weeks** तक की **Duration** चुनें, और **Start date** सेट करें। **End date** अवधि के हिसाब से अपने आप तय हो जाती है।
4. वैकल्पिक: **Sprint goal** अपडेट करें।
5. **Start** पर क्लिक करें। स्प्रिंट पर **ACTIVE** का निशान लग जाता है।

### स्प्रिंट पूरा करें { #complete-a-sprint }

1. सक्रिय स्प्रिंट पर **Complete sprint** पर क्लिक करें। डायलॉग में दिखता है कि कितने वर्क आइटम पूरे हैं और कितने खुले हैं।
2. **Move open work items to** में कोई प्लान किया हुआ स्प्रिंट या **Backlog** चुनें।
3. **Complete sprint** पर क्लिक करें। खुले टास्क आपकी चुनी हुई जगह पर चले जाते हैं।

पूरे हुए वर्क आइटम वे हैं जो बोर्ड के आखिरी कॉलम में हैं। खुले वर्क आइटम बाकी किसी भी कॉलम के सभी आइटम हैं।

### स्प्रिंट एडिट या डिलीट करें { #edit-or-delete-a-sprint }

1. स्प्रिंट पर **More actions** पर क्लिक करें।
2. उसका नाम, तारीख़ें या लक्ष्य बदलने के लिए **Edit sprint** पर क्लिक करें, फिर **Update** पर क्लिक करें।

!!! warning "स्प्रिंट डिलीट करना वापस नहीं हो सकता"
    **Delete sprint** स्प्रिंट को हमेशा के लिए हटा देता है। अगर आपको उसके टास्क की योजना बनाए रखनी है, तो पहले उन्हें बैकलॉग में ले जाएँ।

3. इसके बजाय उसे डिलीट करने के लिए **Delete sprint** पर क्लिक करें, फिर **Delete sprint?** डायलॉग में **Delete** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not start sprint.** | प्रोजेक्ट में पहले से एक सक्रिय स्प्रिंट है, या सेव फ़ेल हो गया। | पहले सक्रिय स्प्रिंट पूरा करें, फिर अगला शुरू करें। |
| **Could not create sprint.** | कोई ज़रूरी फ़ील्ड खाली है, या सेव फ़ेल हो गया। | **Sprint name**, **Start date** और **End date** भरें, फिर **Create** पर दोबारा क्लिक करें। |
| **Could not move ticket to sprint.** | स्प्रिंट पूरा हो चुका है, या मूव सेव नहीं हुआ। | इसके बजाय टास्क को किसी प्लान किए हुए या सक्रिय स्प्रिंट में खींचें। |
| **Could not complete sprint.** | सेव सर्वर तक नहीं पहुँचा। | **Complete sprint** पर दोबारा क्लिक करें। |
| **Sprint completed but refresh failed.** | स्प्रिंट बंद हो गया, लेकिन व्यू रीलोड नहीं हुआ। | बोर्ड पर **Refresh** पर क्लिक करें। |
| **Your backlog is empty.** | हर टास्क पहले से किसी स्प्रिंट में है, या अभी कोई टास्क नहीं है। | टास्क बनाएँ, या किसी स्प्रिंट से एक टास्क बाहर खींच लें। |
