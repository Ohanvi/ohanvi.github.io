Step-by-step sample

Import contacts from a CSV file

Add customers or leads into Ohanvi so they can be used in WhatsApp, email, workflow, and ad follow-up campaigns.

Beginner7 minutesCRM

Goal

By the end of this guide, the user has imported a contact list, mapped the important fields, and confirmed which rows were added or skipped.

Prepare the CSV file

1. Create the required columns

Use one row per contact. Keep the first row as column names such as name, phone, email, city, tags, and opt-in status.

2. Format phone numbers

Use country code format for WhatsApp numbers, for example 919876543210. Avoid spaces, brackets, and symbols.

3. Save as CSV

Export the spreadsheet as a comma-separated CSV file before uploading it to Ohanvi.

Upload the file

  1. Open CRM from the left navigation.
  2. Select Contacts, then choose Import.
  3. Drag the CSV file into the upload area or choose it from your computer.
  4. Select whether duplicate contacts should be skipped or updated.
  5. Click Continue.

Fix skipped rows

  • If phone numbers are skipped, confirm country codes are present.
  • If duplicates are skipped, choose update existing contacts and upload again.
  • If tags do not appear, separate multiple tags with commas or the format supported by your import screen.
