# Schedule a post across connected channels

Prepare content once, preview it per channel, and publish it at the best time.

## Steps

1. Open **Social Media**.
2. Select **Composer**.
3. Choose the channels for publishing.
4. Add caption, media, hashtags, and tracking links.
5. Preview each channel.
6. Resolve validation warnings.
7. Select **Schedule**.
8. Choose the publishing date and time.

## Tips

- Use UTM links when the post is part of a campaign.
- Keep channel-specific captions short enough for mobile previews.
- Add an approval step if customers, compliance, or internal teams need to review posts.
