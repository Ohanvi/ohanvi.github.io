# Auto Calling से एक के बाद एक कई कॉन्टैक्ट को कॉल करें { #call-many-contacts-in-a-row-with-auto-calling }

कुछ कॉन्टैक्ट चुनें और उन्हें एक के बाद एक कॉल करें। हर बार लिस्ट में वापस जाने की ज़रूरत नहीं पड़ती। हर कॉल का रिव्यू भी साथ-साथ भरा जाता है। आप बीच में रुक सकते हैं और बाद में वहीं से फिर शुरू कर सकते हैं। 10 कॉल में उतना ही समय लगता है, जितना उन कॉल में बात करने में लगता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Contacts** दिखता हो और उसके पैनल में **All contacts** हो।
- आप जिन कॉन्टैक्ट को चुनें, उनके पास **Mobile** या **Phone** नंबर हो।
- आपको पता हो कि कॉल रिव्यू कैसे काम करता है। देखें [कॉन्टैक्ट को कॉल करें और अपनी कॉल रिव्यू करें](call-contacts-and-review-calls.md)।

## स्टेप { #steps }

### रन शुरू करें { #start-a-run }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. टॉप बार में **Auto Calling** आइकन पर क्लिक करें।
3. **Search contacts…** में नाम लिखें। इससे लिस्ट छोटी हो जाती है।
4. चाहें तो **Today's follow-ups only** पर क्लिक करें। तब सिर्फ़ वे कॉन्टैक्ट दिखते हैं जिनसे आज बात करनी है।
5. जिन कॉन्टैक्ट को कॉल करना है, उन पर टिक लगाएँ। **N selected** लाइन में उनकी गिनती दिखती है।
6. **Start Auto Calling** पर क्लिक करें।

विंडो का टाइटल बदलकर **Auto Calling — 1 of N** हो जाता है। उसमें पहले कॉन्टैक्ट का नाम और नंबर दिखता है।

### हर कॉल करें { #make-each-call }

1. विंडो में कॉन्टैक्ट का नाम और नंबर देखें।
2. कॉल आपके डिवाइस पर शुरू हो जाती है। शुरू न हो, तो **Call Again** पर क्लिक करें।
3. कॉन्टैक्ट से बात करें।
4. कॉल खत्म होने पर Ohanvi में लौट आएँ। **Waiting for the call to finish — the Call Review dialog will open automatically once you return to the app.** वाली लाइन हट जाती है और **Call Review** विंडो खुल जाती है।
5. रिव्यू भरें और **Save** पर क्लिक करें। इसके लिए देखें [कॉन्टैक्ट को कॉल करें और अपनी कॉल रिव्यू करें](call-contacts-and-review-calls.md)।
6. Auto Calling अगले कॉन्टैक्ट पर चली जाती है। टाइटल में गिनती बढ़ जाती है, जैसे **Auto Calling — 2 of 10**।

आखिरी कॉल पूरी होने पर विंडो में **All calls completed.** दिखता है। **Done** पर क्लिक करें।

### रन रोकें { #stop-a-run }

1. आप कभी भी **Stop Auto Calling** पर क्लिक कर सकते हैं।
2. अब तक का काम इसी डिवाइस पर सेव हो जाता है।

### रन फिर से शुरू करें { #resume-a-run }

1. **Auto Calling** आइकन पर फिर से क्लिक करें।
2. **You have an unfinished Auto Calling run.** मैसेज पढ़ें। इसमें दिखता है कि कितनी कॉल हो चुकी हैं, जैसे **4 of 10 done — 6 remaining.**
3. आगे बढ़ने के लिए **Resume (6)** पर क्लिक करें। पुराना रन छोड़कर नए सिरे से कॉन्टैक्ट चुनने हों, तो **Start New** पर क्लिक करें।

!!! note "ध्यान दें"
    अधूरा रन उसी डिवाइस पर रहता है जिस पर आपने उसे शुरू किया था। वह भी सिर्फ़ करीब एक दिन तक। फिर से शुरू करने के लिए उसी डिवाइस पर Auto Calling खोलें।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No contacts match this view.** | सर्च या फ़ॉलो-अप फ़िल्टर से कोई कॉन्टैक्ट नहीं मिला। | सर्च हटा दें, या **Today's follow-ups only** बंद करें। |
| विंडो बस इंतज़ार करती रहती है | कॉल शुरू नहीं हुई। | **Call Again** पर क्लिक करें। |
| **Resume** का विकल्प नहीं दिख रहा | पुराने रन को एक दिन से ज़्यादा हो गया है, या वह किसी दूसरे डिवाइस पर था। | **Start Auto Calling** पर क्लिक करें और कॉन्टैक्ट फिर से चुनें। |
