# फ़्लो के वर्शन की समीक्षा करें { #review-a-flows-versions }

फ़्लो की हिस्ट्री उसके पैनल में देखें। आखिर में आपको पता होता है कि अभी कौन-सा वर्शन चल रहा है, आप कौन-सा ड्राफ़्ट एडिट कर रहे हैं, और हर वर्शन कब और किसने पब्लिश किया।

## शुरू करने से पहले { #before-you-start }

- फ़्लो कम से कम एक बार सेव हो चुका हो।
- आपको **WhatsApp** पैनल में **Flows** दिखे। बिल्डर में पुराना वर्शन खोलने के लिए आपके रोल के पास फ़्लो सेव करने का एक्सेस भी होना चाहिए।

## वर्शन कैसे काम करते हैं { #how-versions-work }

- पब्लिश किया गया वर्शन कभी नहीं बदलता। पब्लिश किए गए फ़्लो को एडिट करने पर नया ड्राफ़्ट शुरू होता है।
- जो रन पहले से चल रहे हैं, वे उसी वर्शन पर रहते हैं जिससे शुरू हुए थे। नए रन लाइव वर्शन इस्तेमाल करते हैं।
- फ़्लो की दो तरह की हिस्ट्री हो सकती है। **THIS FLOW** फ़्लो के अपने वर्शन हैं। **CONVERSATION:** के बाद नाम हो, तो वह उस चैटबॉट कन्वर्सेशन के वर्शन हैं जिसे फ़्लो इस्तेमाल करता है।

## चरण { #steps }

### Versions टैब खोलें { #open-the-versions-tab }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।
2. फ़्लो की पंक्ति पर क्लिक करें। सूची के बगल में पैनल खुलता है।
3. **Versions** टैब पर क्लिक करें। पहली बार सूची लोड होने तक लोडर दिखता है।
4. ऊपर का नोट पढ़ें: **A published version never changes — editing one starts a draft, and runs already going stay on the version they started with.**

### वर्शन की पंक्ति पढ़ें { #read-a-version-row }

हर पंक्ति एक वर्शन दिखाती है।

1. वर्शन नंबर पढ़ें, जैसे **v3**।
2. उसके बगल का चिप पढ़ें।
    - **Running now** ऑटोमेशन का लाइव वर्शन है।
    - **Live** चैटबॉट कन्वर्सेशन का लाइव वर्शन है।
    - **Published** वह वर्शन है जो पहले लाइव था और बदल दिया गया।
    - **Being edited** वह ड्राफ़्ट है जिस पर आप काम कर रहे हैं।
    - **Draft** वह ड्राफ़्ट है जो एडिट नहीं हो रहा।
3. उसके नीचे की पंक्ति पढ़ें। उसमें चरणों की संख्या दिखती है, जैसे **3 steps**, फिर **Published** समय और पब्लिश करने वाले के साथ, या **Not published**। अगर बदलाव का नोट सेव किया गया था, तो वह आखिर में दिखता है।

अगर फ़्लो का कोई वर्शन नहीं है, तो टैब में **No versions yet.** लिखा आता है।

### पुराना वर्शन खोलें { #open-an-older-version }

1. जो पंक्ति लाइव नहीं है, उस पर **Open** पर क्लिक करें। बिल्डर खुलता है।
2. पुराने वर्शन को लाइव करने के लिए, या उससे नया ड्राफ़्ट शुरू करने के लिए, बिल्डर में **Versions** बटन इस्तेमाल करें। देखें [फ़्लो बिल्डर को समझें](../whatsapp/understand-the-flow-builder.md)।

**Open** बटन लाइव वर्शन पर, चैटबॉट कन्वर्सेशन के वर्शन पर, या तब नहीं दिखता जब आपका रोल फ़्लो नहीं बदल सकता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No versions yet.** | फ़्लो कभी सेव नहीं किया गया। | बिल्डर खोलें, एक चरण जोड़ें और **Save** पर क्लिक करें। |
| पंक्ति में **Open** बटन नहीं है | वर्शन लाइव है, वह कन्वर्सेशन का वर्शन है, या आपका रोल फ़्लो नहीं बदल सकता। | अपने एडमिन से फ़्लो सेव करने का एक्सेस माँगें। |
| वर्शन की दो सूचियाँ | फ़्लो के अपने वर्शन हैं और चैटबॉट कन्वर्सेशन के अपने। उनकी गिनती अलग-अलग होती है। | हर सूची को उसके शीर्षक के नीचे पढ़ें। |
| ड्राफ़्ट **Being edited** की जगह **Draft** दिखता है | यह वह ड्राफ़्ट नहीं है जो फ़्लो अभी इस्तेमाल कर रहा है। | बिल्डर खोलें और देखें कि कौन-सा ड्राफ़्ट खुला है। |
