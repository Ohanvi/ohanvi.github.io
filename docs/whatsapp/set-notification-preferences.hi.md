# नोटिफ़िकेशन की पसंद सेट करें { #set-notification-preferences }

Notification Preferences तय करती हैं कि आपको नए मैसेज या इंसान की ज़रूरत वाली चैट जैसे व्हाट्सऐप इवेंट की खबर कैसे मिले। आखिर में हर इवेंट आप तक आपकी पसंद के तरीके से पहुँचता है, और क्वाइट आवर्स आपकी रातें शांत रखते हैं। बदलाव करते ही सेव हो जाते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **WhatsApp** पैनल में **Manage** खोल सकें। न खुले, तो अपने एडमिन से पूछें।
- टीम का डिफ़ॉल्ट सेट करने के लिए आपके रोल को उसे एडिट करने की अनुमति चाहिए।

## इवेंट और खबर पाने के तीन तरीके { #the-events-and-the-three-ways-to-be-told }

| इवेंट | यह कब होता है |
| --- | --- |
| **New message** | कोई ग्राहक आपको व्हाट्सऐप मैसेज भेजता है। |
| **Chat needs a human** | बॉट कोई बातचीत आपकी टीम को सौंपता है। |
| **Chat taken over** | कोई टीम सदस्य किसी बातचीत में दखल देता है। |
| **Missed call** | कोई ग्राहक व्हाट्सऐप पर कॉल करता है और कोई जवाब नहीं देता। |
| **Broadcast finished** | कोई कैंपेन सबको भेजना पूरा कर लेता है। |
| **Scheduled send fired** | कोई शेड्यूल किया ब्रॉडकास्ट या मैसेज भेजना शुरू करता है। |

| खबर पाने का तरीका | यह क्या है |
| --- | --- |
| **In-app** | Ohanvi के अंदर नोटिफ़िकेशन बेल। |
| **Push** | आपके फ़ोन पर पुश नोटिफ़िकेशन। |
| **Email** | आपके अकाउंट के पते पर ईमेल। |

## चरण { #steps }

### Notification Preferences खोलें { #open-notification-preferences }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें।
2. **Notification Preferences** चुनें।

    ![My alerts और Workspace default टैब, In-app, Push और Email स्विच, और Quiet hours के साथ Notification Preferences](../assets/screenshots/whatsapp-notification-preferences-1-alerts.png)

3. अपने अलर्ट सेट करने के लिए **My alerts** चुना रहने दें।

### चुनें कि हर इवेंट की खबर कैसे मिले { #choose-how-you-hear-about-each-event }

1. इवेंट खोजें, जैसे **New message**।
2. **In-app** चालू या बंद करें।
3. **Push** चालू या बंद करें।
4. **Email** चालू या बंद करें।

पेज पर **Changes save automatically** लिखा है। कोई सेव बटन नहीं है। अगर कोई बदलाव फ़ेल हो, तो **Couldn't save that change — please try again.** दिखता है। उसे फिर से बदलें।

### सारे अलर्ट एक साथ चालू या बंद करें { #turn-every-alert-on-or-off-at-once }

1. हर अलर्ट बंद करने के लिए **Mute all** पर क्लिक करें।
2. हर अलर्ट चालू करने के लिए **Enable all** पर क्लिक करें।

### क्वाइट आवर्स सेट करें { #set-quiet-hours }

1. **Quiet hours** खोजें। यह रात भर पुश और ईमेल रोक देता है।
2. स्विच चालू करें।
3. **From** के बाद का समय चुनें, जैसे रात 9:00 बजे।
4. **to** के बाद का समय चुनें, जैसे सुबह 9:00 बजे।

क्वाइट आवर्स में भी इन-ऐप बेल अलर्ट इकट्ठा करती रहती है, इसलिए आपका कुछ नहीं छूटता।

### अपनी पसंद की जगह टीम का डिफ़ॉल्ट इस्तेमाल करें { #use-the-team-default-instead-of-your-own-choices }

1. **Follow workspace default** पर क्लिक करें।
2. **Follow the workspace default?** विंडो में मैसेज पढ़ें। आपकी अपनी पसंद हट जाती हैं।
3. **Follow default** पर क्लिक करें।

इसके बाद आपको वही मिलता है जो आपका एडमिन सेट करता है, बाद के बदलाव भी। अपनी पसंद रखने के लिए **Cancel** पर क्लिक करें।

### पूरी टीम के लिए डिफ़ॉल्ट सेट करें { #set-the-default-for-the-whole-team }

1. ऊपर **Workspace default** पर क्लिक करें।
2. इवेंट, तीनों स्विच और **Quiet hours** ऊपर की तरह ही सेट करें।

फिर पेज पर **What a teammate gets before they change anything themselves.** लिखा आता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Couldn't save that change — please try again.** | बदलाव सर्वर तक नहीं पहुँचा। | अपना कनेक्शन जाँचें और उसे फिर से बदलें। |
| आपको पुश अलर्ट नहीं मिलते | **Push** बंद है, या **Quiet hours** चालू है। | **Push** चालू करें, और **Quiet hours** जाँचें। |
| आपको ईमेल नहीं मिलते | उस इवेंट के लिए **Email** बंद है। | उसके लिए **Email** चालू करें। |
| आपकी पसंद बदलती रहती हैं | आपने **Follow workspace default** चुना है। | डिफ़ॉल्ट छोड़ने के लिए स्विच खुद बदलें। |
| आपको **Workspace default** नहीं दिखता | आपका रोल टीम का डिफ़ॉल्ट एडिट नहीं कर सकता। | अपने एडमिन से पूछें। |
