# सोशल इनसाइट्स देखें { #read-social-insights }

आपकी पोस्ट कैसा चल रही हैं, यह देखने के लिए **Insights** खोलें। यहाँ आप अलग-अलग नेटवर्क की तुलना कर सकते हैं और अपनी सबसे अच्छी पोस्ट ढूँढ सकते हैं। आपने जो भी पोस्ट पब्लिश की है, उसके आँकड़े भी खोल सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखना चाहिए, और उसके पैनल में **Home** और **Insights** होने चाहिए। न दिखें, तो अपने एडमिन से कहें कि आपके रोल को Social का एक्सेस दे दें। इसके लिए [सेटिंग्स का परिचय](../settings/index.md) देखें।
- कम से कम एक नेटवर्क कनेक्ट हो और आपने एक पोस्ट पब्लिश की हो। इसके लिए [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md) देखें।

## स्टेप { #steps }

### Social Home देखें { #check-social-home }

Social Home का अपना अलग पेज है। इसके लिए [Social Home का इस्तेमाल करें](use-social-home.md) देखें।

### Insights पर परफ़ॉर्मेंस की तुलना करें { #compare-performance-on-insights }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Insights** चुनें।
2. सिर्फ़ एक नेटवर्क देखना हो, तो **All Channels** पर क्लिक करें और एक चैनल चुनें।
3. तारीखों की रेंज चुनें: **7 days**, **30 days** या **Month to date**। हर आँकड़े की तुलना उससे पहले की अवधि से होती है।
4. **Summary** देखें: **Posts**, **Reactions**, **Comments**, **Eng. Rate**, **Impressions** और **Shares**। किसी आँकड़े पर माउस ले जाएँ। तब दिखेगा कि वह क्या गिनता है।
5. **Performance** में हर चैनल के **Posts**, **Reactions**, **Comments** और **Eng. Rate** की तुलना करें।
6. **Top 5 Posts** में **Reactions** और **Comments** के बीच बदलें। इससे आपकी सबसे अच्छी पोस्ट का क्रम दिखता है।
7. **Performance per Post** में देखें कि उस अवधि में पब्लिश हुई हर पोस्ट के आँकड़े क्या हैं।

### एक पोस्ट के आँकड़े देखें { #see-the-numbers-for-one-post }

1. **Social** → **Publish** खोलें, फिर **Sent** टैब पर क्लिक करें।
2. हर पोस्ट पर उसकी **Reach**, **Engagement**, **Likes** और **Comments** दिखती हैं।
3. पोस्ट पर **View Analytics** पर क्लिक करें। **Post Analytics** विंडो खुलती है, जिसमें हर नेटवर्क के आँकड़े होते हैं।
4. देखने के बाद **Close** पर क्लिक करें।

!!! note "नेटवर्क क्या बताते हैं"
    हर नेटवर्क हर आँकड़ा नहीं देता। कनेक्ट किए हुए नेटवर्क अभी फ़ॉलोअर की संख्या, इंप्रेशन और रीच नहीं बताते। इसलिए **Total Followers** और **Followers** चार्ट खाली रह सकते हैं। **Shares** सिर्फ़ Facebook से आते हैं। **Eng. Rate** के लिए इंप्रेशन चाहिए, इसलिए वह अक्सर खाली रहता है।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No published posts in this period.** | आपकी चुनी हुई तारीखों में कोई पोस्ट पब्लिश नहीं हुई। | लंबी रेंज चुनें, या कोई पोस्ट पब्लिश करें। |
| **No channels connected** | कोई नेटवर्क कनेक्ट नहीं है। | **Connect** → **Social Connections** में एक नेटवर्क कनेक्ट करें। |
| **No published targets for this post yet.** | पोस्ट अभी किसी नेटवर्क पर गई नहीं है। | पोस्ट के **Published** होने तक रुकें, फिर **View Analytics** दोबारा खोलें। |
| किसी नेटवर्क के लिए **Analytics not available** | वह नेटवर्क पोस्ट के आँकड़े Ohanvi को नहीं देता। | आँकड़े उसी नेटवर्क पर जाकर देखें। |
| आँकड़े पुराने लगते हैं | आँकड़े बैकग्राउंड में रिफ़्रेश होते हैं। | **Refresh** पर क्लिक करें। |
