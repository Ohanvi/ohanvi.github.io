# सोशल पोस्ट बनाएँ और पब्लिश करें { #create-and-publish-a-social-post }

कंपोज़र में पोस्ट एक बार लिखें और अपने चुने हुए हर कनेक्टेड नेटवर्क पर भेजें। आप फ़ोटो या वीडियो जोड़ सकते हैं, AI असिस्टेंट इस्तेमाल कर सकते हैं, हर चैनल का प्रीव्यू देख सकते हैं, और फिर तुरंत पब्लिश कर सकते हैं या ड्राफ़्ट सेव कर सकते हैं। बाद में पब्लिश करने के लिए देखें [पोस्ट शेड्यूल करें और क्यू संभालें](schedule-social-posts.md)।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखता हो, और उसके पैनल में **Publish** हो। न दिखे तो अपने एडमिन से अपने रोल को Social एक्सेस देने के लिए कहें। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।
- कम से कम एक नेटवर्क कनेक्ट हो। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।

## चरण { #steps }

### कंपोज़र खोलें { #open-the-composer }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. **New Post** पर क्लिक करें। **Create Post** विंडो खुलती है।

आप **Social** पैनल के ऊपर **New** पर क्लिक करके फिर **Post** पर भी क्लिक कर सकते हैं।

अगर आपने पहले कंपोज़र बिना सेव किए बंद कर दिया था, तो Ohanvi पूछता है **Resume Unfinished Post?**। उसे जारी रखने के लिए **Resume Post** पर क्लिक करें, या नए सिरे से शुरू करने के लिए **Discard** पर।

### नेटवर्क चुनें { #pick-the-networks }

1. चैनल स्ट्रिप में हर उस नेटवर्क पर क्लिक करें जिस पर आप पोस्ट करना चाहते हैं। एक पोस्ट एक साथ कई नेटवर्क पर जा सकती है।
2. किसी ग्रे चिप पर माउस ले जाकर देखें कि वह बंद क्यों है। **… — connect it in Integrations → Social Connections** का मतलब है कि नेटवर्क अभी कनेक्ट नहीं है।

लिखते समय दिखने वाली अक्षर सीमा आपके चुने हुए नेटवर्क में सबसे कम वाली सीमा होती है:

| नेटवर्क | अक्षर सीमा |
| --- | --- |
| **X** | 280 |
| **Threads** | 500 |
| **Google Business** | 1,500 |
| **Instagram** | 2,200 |
| **LinkedIn** | 3,000 |
| **Facebook** | 63,206 |

### पोस्ट लिखें { #write-the-post }

1. जिस बॉक्स पर **Start writing or get inspired with Templates** लिखा है, उसमें अपना टेक्स्ट लिखें।
2. **Emoji** या **Hashtag** जोड़ने के लिए, या चुने हुए टेक्स्ट को **Bold**, **Italic** या **Underline** करने के लिए टूलबार इस्तेमाल करें।
3. सेव किए हुए टेक्स्ट से शुरू करने के लिए कंपोज़र के ऊपर **Templates** पर क्लिक करें, फिर **Start from a template** में कोई टेम्प्लेट चुनें। हर `[bracketed]` खाली जगह को अपने शब्दों से बदलें।
4. AI से टेक्स्ट का ड्राफ़्ट बनवाने के लिए **AI Assistant** पर क्लिक करें। **What should this post be about?** के नीचे पोस्ट का विषय बताएँ, फिर **Generate post** पर क्लिक करें।

!!! note "ध्यान दें"
    कुछ नेटवर्क पर Bold, italic और underline वाले अक्षर 1 से ज़्यादा अक्षर गिने जाते हैं। Underline हर अक्षर पर 1 अक्षर जोड़ता है।

### फ़ोटो या वीडियो जोड़ें { #add-photos-or-video }

1. **Add photos or videos** पर क्लिक करें, या फ़ाइलों को **Drag & drop or select a file** वाले हिस्से पर खींचकर छोड़ें।
2. अगर **Crop image** विंडो खुले, तो एक शेप चुनें और **Crop** पर क्लिक करें। शेप में **Square** (1:1), **Instagram portrait** (4:5), **Twitter / X** (16:9) और **Stories / Reels** (9:16) शामिल हैं। चुने हुए हर चैनल के लिए एक ही क्रॉप इस्तेमाल होता है।

मीडिया के नियम:

- हर इमेज 25 MB तक की हो सकती है। हर वीडियो 200 MB तक का हो सकता है।
- वीडियो MP4, MOV, M4V, WEBM, AVI या MKV फ़ाइलें होती हैं।
- **Instagram** सिर्फ़ टेक्स्ट वाली पोस्ट नहीं लेता। फ़ोटो जोड़ें, या Instagram का चयन हटा दें।
- **Facebook** वीडियो पोस्ट नहीं लेता। वीडियो हटाएँ, या Facebook का चयन हटा दें।

### Google Business के विकल्प सेट करें { #set-google-business-options }

जब Google Business आपके चैनलों में हो, तब ये **Google Business options** के नीचे दिखते हैं।

1. पोस्ट का प्रकार चुनें: **Standard**, **Event**, **Offer** या **Alert**।
2. **Event** के लिए **Event title**, **Starts** और **Ends** भरें।
3. **Offer** के लिए **Coupon code**, **Redeem URL** और **Terms & conditions** भरें।
4. चाहें तो **Link (optional)** जोड़ें। यह Google पर पोस्ट के मुख्य टेक्स्ट के नीचे दिखता है।
5. चाहें तो **Call to action** चुनें, जैसे **BOOK**, **ORDER**, **SHOP**, **LEARN_MORE**, **SIGN_UP** या **CALL**, फिर **CTA URL** भरें।

### प्रीव्यू देखें और पब्लिश करें { #preview-and-publish }

1. हर चुने हुए नेटवर्क पर पोस्ट कैसी दिखेगी, यह देखने के लिए **Preview** पर क्लिक करें।
2. चुनें कि क्या करना है:
    - पोस्ट को हर चुने हुए नेटवर्क पर भेजने के लिए **Publish Now** पर क्लिक करें। संदेश **Publishing to … — track it under Sent.** दिखता है।
    - बाद के लिए रखने के लिए **Save Draft** पर क्लिक करें। संदेश **Post saved as draft — publish it when ready** दिखता है।
    - तारीख और समय चुनने के लिए **Schedule** पर क्लिक करें। देखें [पोस्ट शेड्यूल करें और क्यू संभालें](schedule-social-posts.md)।

बाद में किसी ड्राफ़्ट को एडिट करने के लिए **Social** → **Publish** खोलें, **Drafts** टैब पर क्लिक करें, और पोस्ट के **Edit** आइकन पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| मुख्य बटन पर **Connect a Channel to Post** लिखा है और वह ग्रे है | कोई नेटवर्क नहीं चुना गया। | चैनल स्ट्रिप में किसी नेटवर्क पर क्लिक करें। |
| **Post text is required** | टेक्स्ट बॉक्स खाली है। | पोस्ट का टेक्स्ट लिखें। |
| **Post text is over the … character … limit** | टेक्स्ट आपके चुने हुए सबसे सख़्त नेटवर्क की सीमा से लंबा है। | टेक्स्ट छोटा करें, या कम सीमा वाले नेटवर्क का चयन हटा दें। |
| **Instagram needs a photo or video — add one, or deselect it.** | Instagram पर सिर्फ़ टेक्स्ट वाली पोस्ट नहीं होती। | फ़ोटो जोड़ें, या Instagram का चयन हटा दें। |
| **Facebook does not accept video posts — remove the video, or deselect it.** | Ohanvi Facebook Page पर वीडियो पोस्ट नहीं कर सकता। | वीडियो हटाएँ, या Facebook का चयन हटा दें। |
| **Too large to attach: … (over 25 MB)** | फ़ाइल साइज़ की सीमा से बड़ी है। | फ़ाइल को कंप्रेस करें और दोबारा जोड़ें। |
