# टास्क एडिटर में लिखें { #write-in-the-task-editor }

टास्क के विवरण और उसके कमेंट के पीछे एक ही एडिटर है। इससे साफ़ टास्क लिखें: हेडिंग, सूचियाँ, चेकलिस्ट, टेबल, तस्वीरें और बहुत कुछ। ब्लॉक जोड़ने के लिए `/` दबाएँ, या सपोर्ट करने वाले ब्राउज़र में अपनी आवाज़ से बोलकर लिखें।

## शुरू करने से पहले { #before-you-start }

- आप कोई टास्क खोल सकते हैं। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।
- बोलकर लिखने के लिए ऐसा ब्राउज़र इस्तेमाल करें जो स्पीच रिकग्निशन सपोर्ट करता हो, जैसे Chrome। **Voice to text** बटन तभी दिखता है जब आपका ब्राउज़र इसे सपोर्ट करे।

## एडिटर कहाँ दिखता है { #where-the-editor-appears }

| जगह | आप क्या लिखते हैं |
| --- | --- |
| टास्क का विवरण | वह बॉक्स जिसमें **Add a description...** लिखा है। |
| कमेंट | टास्क के नीचे का बॉक्स, और कमेंट पर **Write a reply…** बॉक्स। |
| एडिट किया जा रहा कमेंट | वह बॉक्स जिसमें **Edit comment… Enter to save · Shift + Enter for a new line.** लिखा है। |

## चरण { #steps }

### टेक्स्ट फ़ॉर्मैट करें { #format-text }

1. जिन शब्दों को बदलना है उन्हें चुनें।
2. बॉक्स के ऊपर टूलबार का कोई बटन दबाएँ। आप शॉर्टकट भी इस्तेमाल कर सकते हैं: Mac पर `Cmd`, या Windows और Linux पर `Ctrl`।
3. ये शॉर्टकट इस्तेमाल करें:

    | शॉर्टकट | यह क्या करता है |
    | --- | --- |
    | `Cmd` या `Ctrl` + B | **Bold** |
    | `Cmd` या `Ctrl` + I | **Italic** |
    | `Cmd` या `Ctrl` + U | **Underline** |
    | `Cmd` या `Ctrl` + Shift + S | **Strikethrough** |
    | `Cmd` या `Ctrl` + `` ` `` | **Inline code** |
    | `Cmd` या `Ctrl` + K | **Insert link** |
    | `Cmd` या `Ctrl` + Z | **Undo** |
    | `Cmd` या `Ctrl` + Y | **Redo** |
    | `Cmd` या `Ctrl` + M | **Indent** |
    | `Cmd` या `Ctrl` + Shift + M | **Outdent** |

4. फ़ॉर्मैटिंग हटाने के लिए टेक्स्ट चुनें और टूलबार के क्लियर-फ़ॉर्मैट बटन पर क्लिक करें।

### सूची या चेकलिस्ट बनाएँ { #make-a-list-or-a-checklist }

1. बुलेट सूची शुरू करने के लिए `- ` लिखें और Space दबाएँ।
2. क्रमांकित सूची शुरू करने के लिए `1. ` लिखें और Space दबाएँ।
3. अगला आइटम जोड़ने के लिए Enter दबाएँ। सूची अगली पंक्ति में जारी रहती है।
4. किसी पंक्ति को बदलने के लिए बुलेट सूची के लिए `Cmd` या `Ctrl` + Shift + L, क्रमांकित सूची के लिए + Shift + O, या चेकलिस्ट के लिए + Shift + C इस्तेमाल करें।
5. हेडिंग के लिए `# ` लिखें और Space दबाएँ।
6. कोट के लिए `Cmd` या `Ctrl` + Shift + B इस्तेमाल करें।
7. कोड ब्लॉक के लिए `Cmd` या `Ctrl` + Shift + `~` इस्तेमाल करें।

### प्लस बटन या स्लैश से ब्लॉक जोड़ें { #add-a-block-with-the-plus-button-or-a-slash }

1. टूलबार के **+** बटन पर क्लिक करें। उसका टूलटिप **Insert block  ( / )** है। आप पंक्ति की शुरुआत में `/` भी लिख सकते हैं।
2. सूची छोटी करने के लिए कुछ अक्षर लिखें। कुछ न मिले तो **No matching blocks** दिखता है।
3. कोई ब्लॉक चुनें:

    | ब्लॉक | यह क्या जोड़ता है |
    | --- | --- |
    | **Text** | सादा पैराग्राफ़। |
    | **Heading 1** | बड़ी सेक्शन हेडिंग। |
    | **Heading 2** | मध्यम सेक्शन हेडिंग। |
    | **Heading 3** | छोटी सेक्शन हेडिंग। |
    | **Bulleted list** | बिना क्रम की सूची। |
    | **Numbered list** | क्रम वाली सूची। |
    | **Task list** | चेकबॉक्स वाली चेकलिस्ट। |
    | **Quote** | ब्लॉक कोट। |
    | **Code block** | मोनोस्पेस कोड। |
    | **Panel** | जानकारी या चेतावनी वाला कॉलआउट बॉक्स। |

### रंगीन पैनल जोड़ें { #add-a-coloured-panel }

1. **Panel** ब्लॉक जोड़ें। एक बॉक्स दिखता है जिसमें **Empty panel — tap to edit** लिखा है।
2. बॉक्स पर क्लिक करें। एक विंडो खुलती है।
3. टाइप चुनें: **Info**, **Success**, **Warning** या **Error**।
4. टेक्स्ट लिखें, फिर सेव करें।

### टेबल जोड़ें { #insert-a-table }

1. टूलबार के ग्रिड बटन पर क्लिक करें। उसका टूलटिप **Insert Grid** है। **Insert Grid (Table)** विंडो खुलती है।
2. **Columns** स्लाइडर खींचें। आप 1 से 10 तक चुन सकते हैं।
3. **Rows** स्लाइडर खींचें। आप 1 से 15 तक चुन सकते हैं।
4. **Insert** पर क्लिक करें। शुरुआती आकार 3 बाय 3 की टेबल है।
5. टेबल बदलने के लिए उस पर क्लिक करें। **Edit Grid** विंडो खुलती है।
6. सेल में लिखें। सबसे ऊपर की पंक्ति में हेडर होते हैं।
7. आकार बदलने के लिए **Add Row**, **Remove Row**, **Add Column** या **Remove Column** पर क्लिक करें।
8. टेबल हटाने के लिए **Delete Table**, छोड़ने के लिए **Cancel**, या बदलाव रखने के लिए **Save** पर क्लिक करें।

### किसी व्यक्ति को मेंशन करें { #mention-a-person }

1. **@** बटन पर क्लिक करें, जिसका टूलटिप **Mention** है, या `@` लिखें।
2. कोई नाम लिखें। कोई न मिले तो **No matching people** दिखता है।
3. व्यक्ति को चुनें। उन्हें नोटिफ़िकेशन मिलता है। देखें [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](collaborate-on-tasks.md)।

### इमोजी जोड़ें { #add-an-emoji }

1. स्माइल वाले बटन पर क्लिक करें। उसका टूलटिप **Emoji** है।
2. ग्रिड में किसी इमोजी पर क्लिक करें। वह आपके कर्सर की जगह आ जाती है।

### तस्वीर जोड़ें { #add-a-picture }

1. पेस्ट करने के लिए कोई इमेज कॉपी करें, बॉक्स में क्लिक करें, और `Cmd` या `Ctrl` + V दबाएँ। तस्वीर टेक्स्ट में आ जाती है। अगर आप इसकी जगह कोई डॉक्यूमेंट पेस्ट करते हैं, तो वह अटैचमेंट बन जाता है।
2. फ़ाइल चुनने के लिए टूलबार के इमेज बटन पर क्लिक करें और तस्वीर चुनें।
3. तस्वीर पर क्लिक करें। वह पूरे आकार में खुलती है, **Copy** और **Download** के साथ।
4. मेन्यू खोलने के लिए तस्वीर को दबाए रखें, या राइट-क्लिक करें: **Open preview**, **Copy image**, **Download** और **Delete Image**।
5. **Copy image** के बाद संदेश **Image copied — paste it anywhere** दिखता है।

### आवाज़ से बोलकर लिखें { #dictate-with-your-voice }

1. जिस बॉक्स में टेक्स्ट चाहिए उसमें क्लिक करें।
2. माइक्रोफ़ोन बटन पर क्लिक करें। उसका टूलटिप **Voice to text** है। ब्राउज़र पूछे तो माइक्रोफ़ोन की अनुमति दें।
3. एक वाक्य बोलें। टेक्स्ट आपके कर्सर की जगह दिखता है। डिक्टेशन English (US) सुनता है।
4. रोकने के लिए बटन पर फिर क्लिक करें। जब तक वह सुन रहा होता है, टूलटिप में **Stop dictation** लिखा होता है और आइकन लाल हो जाता है।

### ज़्यादा या कम टूल दिखाएँ { #show-more-or-fewer-tools }

1. अगर टूलबार भरा हुआ है, तो हर पंक्ति दिखाने के लिए **More tools** पर क्लिक करें।
2. उसे वापस समेटने के लिए **Fewer tools** पर क्लिक करें।

### सेव करें, और हर शॉर्टकट देखें { #save-and-see-every-shortcut }

1. सेव करने के लिए `Cmd` या `Ctrl` + Enter दबाएँ।
2. **Editor shortcuts** खोलने के लिए `Cmd` या `Ctrl` + `/` दबाएँ, या कीबोर्ड बटन पर क्लिक करें।
3. समूह पढ़ें: **Text formatting**, **Lists and blocks**, **Editing** और **Files and saving**।
4. **Close** पर क्लिक करें।

!!! tip "कमेंट अलग तरह से सेव होते हैं"
    जिस कमेंट को आप एडिट कर रहे हैं, उसमें सेव करने के लिए Enter दबाएँ। नई पंक्ति के लिए Shift + Enter दबाएँ।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| माइक्रोफ़ोन बटन नहीं है। | आपका ब्राउज़र स्पीच रिकग्निशन सपोर्ट नहीं करता। | नया Chrome इस्तेमाल करें, या टाइप करें। |
| डिक्टेशन कुछ नहीं लिखता। | माइक्रोफ़ोन ब्लॉक है, या आप उसके शुरू होने से पहले बोल पड़े। | माइक्रोफ़ोन की अनुमति दें, फिर बटन दबाएँ और बोलें। |
| **No matching blocks** | आपके अक्षर किसी ब्लॉक से मेल नहीं खाते। | एक अक्षर मिटाएँ, या `/` के बाद का टेक्स्ट हटाएँ। |
| **No matching people** | प्रोजेक्ट में कोई मेल नहीं खाता। | स्पेलिंग जाँचें, या उस व्यक्ति को प्रोजेक्ट में जोड़ें। |
| टेबल में **Invalid grid data** दिखता है। | टेबल का डेटा पढ़ा नहीं जा सका। | टेबल हटाएँ और दोबारा जोड़ें। |
| तस्वीर पेस्ट नहीं होती। | ब्राउज़र ने इमेज पेज को नहीं दी। | इसकी जगह इमेज बटन इस्तेमाल करें। |
