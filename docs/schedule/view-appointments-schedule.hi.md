# अपने शेड्यूल किए हुए अपॉइंटमेंट देखें { #see-your-scheduled-appointments }

हर बुकिंग को कैलेंडर या सूची में देखने के लिए **Appointments** व्यू इस्तेमाल करें। आखिर में आप देख सकते हैं कि किसकी बुकिंग कब है, और शेड्यूल छोड़े बिना किसी बुकिंग को आगे-पीछे या रद्द कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखता है। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल के पास होता है। अगर यह नहीं दिखता, तो अपने एडमिन से पूछें।
- बुकिंग मौजूद हैं। देखें [व्हाट्सऐप पर बुकिंग लें](../appointments/take-bookings-on-whatsapp.md)।

## चरण { #steps }

### Appointments शेड्यूल खोलें { #open-the-appointments-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Appointments** चुनें। पेज का शीर्षक **Appointments schedule** दिखता है।
2. पेज मौजूदा महीने के **Calendar** व्यू में खुलता है। चैनल चिप्स छिपे होते हैं, क्योंकि पेज पहले से सिर्फ़ Appointments तक सीमित है।
3. किसी दिन के आइटम देखने के लिए उस दिन पर क्लिक करें। उन्हें दिन के शीर्षकों के नीचे समय के हिसाब से देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर प्रकार का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि आइटम किस तरह का है।

| प्रकार | यह क्या है |
| --- | --- |
| **Booking** | किसी प्रोवाइडर के साथ बुक किया गया एक अपॉइंटमेंट। |

बुकिंग से पहले जाने वाले रिमाइंडर **WhatsApp** व्यू में **Appointment reminder** के रूप में दिखते हैं।

**Audience / with** लाइन में ग्राहक का फ़ोन नंबर दिखता है।

### स्थिति पढ़ें { #read-the-status }

| स्थिति | मतलब |
| --- | --- |
| **Scheduled** | बुकिंग **Requested**, **Confirmed** या **Rescheduled** है। |
| **Sent** | बुकिंग **Completed** या **No-show** है। |
| **Cancelled** | बुकिंग **Cancelled** या **Rejected** है। |

### किसी आइटम में बदलाव करें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [शेड्यूल किए गए आइटम को रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।
2. **Appointments** पेज खोलने के लिए **Edit** पर क्लिक करें। देखें [अपॉइंटमेंट प्रबंधित करें](../appointments/manage-appointments.md)।
3. बुकिंग रद्द करने के लिए **Cancel** पर क्लिक करें। बुकिंग **Cancelled** हो जाती है और उसके रिमाइंडर हटा दिए जाते हैं।
4. उसे Appointments से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छोटा करें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in Appointments** चुनें। Ohanvi **Appointments** पेज खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | कोई बुकिंग नहीं है, या कोई फ़िल्टर उन्हें छिपा रहा है। | **Everyone's schedule** और **Any status** चुनें। |
| **Could not reschedule.** | नया समय पहले से भरा है, काम के घंटों से बाहर है, या आपके बुकिंग नियमों से बाहर है। | कोई दूसरा समय चुनें, या **Appointments** पेज पर **Move** इस्तेमाल करें, जो खाली समय दिखाता है। |
| **Delete** बुकिंग हटाने के बजाय उसे रद्द कर देता है | अपॉइंटमेंट कभी डिलीट नहीं किए जाते। | कुछ करने की ज़रूरत नहीं। बुकिंग **Cancelled** के रूप में बनी रहती है। |
