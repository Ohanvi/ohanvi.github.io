# किसी रन का आउटपुट विस्तार से पढ़ें { #read-a-runs-output-in-detail }

**Latest output** टैब खोलें। यहाँ दिखता है कि रन के हर स्टेप ने क्या किया और क्या नतीजा दिया। इसे पढ़कर आप जान सकते हैं कि कौन सा स्टेप फ़ेल हुआ और क्यों, किसी स्टेप को क्या डेटा मिला और रन ने कौन सा वर्शन इस्तेमाल किया। आप चाहें तो आउटपुट कॉपी करके सपोर्ट को भेज सकते हैं।

## शुरू करने से पहले { #before-you-start }

- फ़्लो कम से कम एक बार चल चुका हो। अभी रन शुरू करना हो, तो देखें [फ़्लो टेस्ट करें और फ़ेल रन ठीक करें](test-and-monitor-flows.md)।
- **WhatsApp** पैनल में आपको **Flows** दिखता हो।

## टैब में क्या दिखता है { #what-the-tab-shows }

- **Latest output** टैब में फ़्लो का सबसे नया रन दिखता है।
- सबसे ऊपर एक समरी होती है। उसमें रन की स्थिति, शुरू होने का समय, और कौन सा ट्रिगर और वर्शन इस्तेमाल हुआ, यह लिखा होता है। जैसे **Published v3**।
- रन फ़ेल हो जाए, तो समरी के नीचे लाल लाइन में एरर दिखता है।
- उसके नीचे की लिस्ट में हर स्टेप की एक लाइन होती है।

### स्टेप की स्थितियाँ { #step-states }

| स्थिति | मतलब |
| --- | --- |
| **Done** | स्टेप पूरा हो गया। |
| **Failed** | स्टेप फ़ेल हो गया। उस पर क्लिक करें, तो उसका एरर दिखता है। |
| **Running** | स्टेप अभी चल रहा है। |
| **Waiting to start** | स्टेप अभी शुरू नहीं हुआ। |
| **Waiting** | स्टेप टाइमर पर रुका है, या किसी दूसरे सिस्टम के जवाब का इंतज़ार कर रहा है। |
| **Deactivated** | बिल्डर में यह स्टेप बंद है, इसलिए रन ने इसे छोड़ दिया। |
| **Answered in chat** | चैट में कोई व्यक्ति पहले ही जवाब दे चुका था, इसलिए स्टेप छोड़ दिया गया। |
| **Not needed** | स्टेप छोड़ दिया गया, जैसे कंडीशन मेल न खाने पर। |
| **Stopped** | इस स्टेप से पहले ही रन रोक दिया गया था। |

## स्टेप { #steps }

### Latest output टैब खोलें { #open-the-latest-output-tab }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।
2. फ़्लो की लाइन पर क्लिक करें।
3. **Latest output** टैब पर क्लिक करें।
4. फ़्लो अभी तक चला नहीं है, तो टैब में **No output yet** और **Run this flow to see what each step returns.** लिखा आता है। रन शुरू करने के लिए **Run test** पर क्लिक करें।
5. रन चल रहा हो, तो टैब में **Run in progress** और **Output will update as steps finish.** दिखता है।

### किसी एक स्टेप का आउटपुट पढ़ें { #read-one-steps-output }

1. **Step output** के नीचे किसी स्टेप पर क्लिक करें। उसका आउटपुट लिस्ट के नीचे खुल जाता है।
2. अगर स्टेप ने कोई नतीजा दिया है, तो उसकी वैल्यू पढ़ें।
3. आउटपुट में तस्वीर या कार्ड जैसी कोई चीज़ हो, तो वह **Visual result** के नीचे भी दिखती है।
4. स्टेप फ़ेल हुआ हो, तो पहले एरर बॉक्स पढ़ें। फ़ेल होने से पहले स्टेप ने जितना नतीजा दिया था, वह **Partial output** के नीचे दिखता है।
5. स्टेप कनेक्शन की वजह से फ़ेल हुआ हो, तो कार्ड में **Review the connection used by this step.** भी लिखा होता है। **Connect** → **Connectors** में जाकर वह कनेक्शन खोलें। देखें [कोई ऐप कनेक्ट करें और उसे फ़्लो में इस्तेमाल करें](connect-apps-for-flows.md)।

किसी स्टेप का अभी कोई रिकॉर्ड न हो, तो टैब में **No step records for this run yet.** लिखा आता है।

### इंतज़ार करते या फ़ेल हुए स्टेप की और जानकारी देखें { #see-more-about-a-step-that-is-waiting-or-failed }

1. स्टेप पर क्लिक करें।
2. अगर वह टाइमर पर रुका है, तो एक लाइन में **Resumes** के बाद समय दिखता है।
3. अगर वह फ़ेल हुआ है, तो एक लाइन में **Error code:** के बाद कोड दिखता है। यह कोड सपोर्ट को बताएँ।
4. अगर उसने किसी बाहरी सर्विस को कॉल किया था, तो एक लाइन में **Vendor job:** के बाद जॉब का नंबर दिखता है।

### पूरा एक्ज़ीक्यूशन देखें { #view-the-full-execution }

1. समरी के ऊपर दाईं तरफ़ **View full execution** पर क्लिक करें।
2. **Run details** पढ़ें।
    - **Run id** रन का नंबर है।
    - **Version pinned** वह वर्शन है जो इस रन ने इस्तेमाल किया।
    - **Started** और **Finished** शुरू और खत्म होने का समय हैं।
    - **Billable steps** बताता है कि कितने स्टेप का चार्ज लगा।
    - **Correlation id** वह नंबर है जो इस रन को उस इवेंट से जोड़ता है जिससे यह शुरू हुआ।
    - **Replay of** तब दिखता है जब यह रन किसी पुराने रन को दोबारा चलाकर बना हो।
3. रन किस इवेंट से शुरू हुआ, यह **WHAT STARTED THIS RUN** में पढ़ें।
4. **Every step** के नीचे हर स्टेप की स्थिति और समय पढ़ें। हर स्टेप में **What it was sent** भी दिखता है। यह वह डेटा है जो स्टेप को मिला।
5. छोटे व्यू पर लौटने के लिए **Hide full execution** पर क्लिक करें।

### पुराना रन देखें { #look-at-an-older-run }

1. **Recent runs** टैब खोलें और किसी रन पर **View output** पर क्लिक करें। देखें [फ़्लो टेस्ट करें और फ़ेल रन ठीक करें](test-and-monitor-flows.md)।
2. **Latest output** टैब खुलता है। उसमें **Viewing run from** और उसके बाद समय वाला बैनर दिखता है।
3. सबसे नए रन पर वापस जाने के लिए **Back to latest** पर क्लिक करें।

### आउटपुट कॉपी करें { #copy-the-output }

1. किसी स्टेप के आउटपुट के नीचे **Copy JSON** पर क्लिक करें।
2. उसे सपोर्ट को भेजे जाने वाले मैसेज में पेस्ट करें।

लंबा आउटपुट बीच में कट जाता है। उसके नीचे नोट में **Truncated — copy to see the whole payload.** लिखा होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No output yet** | फ़्लो कभी चला ही नहीं। | **Run test** पर क्लिक करें। |
| **No step records for this run yet.** | रन अभी-अभी शुरू हुआ है। | कुछ सेकंड रुकें और टैब दोबारा खोलें। |
| कोई स्टेप **Deactivated** दिखता है | बिल्डर में वह स्टेप बंद है। | बिल्डर में उसे चालू करें, फिर पब्लिश करें। |
| कोई स्टेप **Not needed** दिखता है | उससे पहले की कोई कंडीशन मेल नहीं खाई। | कंडीशन जाँचें, या ऐसे डेटा से टेस्ट करें जो कंडीशन से मेल खाए। |
| कोई स्टेप बहुत देर तक **Waiting** दिखता है | वह **Wait** टाइमर पर है, या किसी दूसरे सिस्टम का इंतज़ार कर रहा है। | **Resumes** पढ़ें। अगर वह आगे नहीं बढ़ता, तो रन रोकें और दोबारा टेस्ट करें। |
| **Review the connection used by this step.** | ऐप का कनेक्शन एक्सपायर हो गया है या गलत है। | **Connect** → **Connectors** में जाकर उसे दोबारा कनेक्ट करें। |
