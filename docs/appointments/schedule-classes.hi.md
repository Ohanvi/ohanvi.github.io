# क्लास शेड्यूल करें { #schedule-a-class }

क्लास का मतलब है एक इंस्ट्रक्टर, एक समय और कई बुक किए हुए लोग, जैसे योगा का बैच या कोचिंग सेशन। एक-से-एक अपॉइंटमेंट के उलट, यहाँ कई ग्राहक एक ही स्लॉट साझा करते हैं। आखिर में आपकी साप्ताहिक सूची में क्लास दिखेंगी, और हर क्लास में दिखेगा कि कितनी सीटें भर चुकी हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Appts** दिखता हो। अगर **Classes** नहीं दिखता, तो अपने एडमिन से Appointments क्लास का एक्सेस माँगें।
- क्लास के लिए आपके पास एक सर्विस हो, जैसे `Morning Yoga`। देखें [बुक की जा सकने वाली सर्विस जोड़ें](add-services.md)।
- इंस्ट्रक्टर चुनने के लिए, आपने उन्हें प्रोवाइडर के रूप में जोड़ा हो। देखें [प्रोवाइडर और काम के घंटे जोड़ें](add-providers.md)।

## चरण { #steps }

### क्लास शेड्यूल करें { #schedule-a-class_1 }

1. लेफ़्ट रेल में **Appts** खोलें, फिर **Classes** चुनें। **Classes** पेज इसी हफ़्ते पर खुलता है।
2. **Schedule a class** पर क्लिक करें। **Schedule a class** डायलॉग खुलता है।
3. **Class** में सर्विस चुनें। डायलॉग में लिखा आता है: **Everyone booked into a class shares the instructor and the time — that is what makes it different from an appointment.**
4. **Instructor** में कोई प्रोवाइडर चुनें, या **Not assigned** रहने दें।
5. **Starts** बॉक्स पर क्लिक करें। पहले तारीख चुनें, फिर समय। यह कल सुबह 7:00 AM से शुरू होता है।
6. **Lasts** में अवधि चुनें: 30, 45, 60, 75, 90 या 120 मिनट।
7. **Places** में लिखें कि कितने लोग जुड़ सकते हैं। यह `20` से शुरू होता है।
8. **Schedule class** पर क्लिक करें। **Saved** मैसेज आता है और क्लास सूची में दिखने लगती है।

### खाली क्लास सूची को समझें { #read-an-empty-class-list }

1. अगर उस हफ़्ते में कोई क्लास नहीं है, तो पेज पर **No classes in this week** और **Schedule one to let several people book the same time.** दिखता है। वहीं **Schedule a class** पर क्लिक करें, या **Next week** का इस्तेमाल करें।
2. पेज के सबटाइटल में लिखा होता है **One instructor, one time, several people booked in.**

### देखें कि क्लास कितनी भरी है { #check-how-full-a-class-is }

1. **Classes** पेज पर हफ़्ते बदलने के लिए **Previous week** और **Next week** का इस्तेमाल करें।
2. हर क्लास में कुल सीटों में से भरी हुई सीटें दिखती हैं, जैसे **12/20**। जब 2 या उससे कम सीटें बचती हैं तो बैज एम्बर रंग का हो जाता है, और कोई सीट न बचे तो **Full** दिखता है।
3. हर बुक किए गए ग्राहक का फ़ोन नंबर और स्टेटस देखने के लिए लिस्ट आइकन (**Who is booked**) पर क्लिक करें। यह आइकन तब दिखता है जब कम से कम 1 सीट भर चुकी हो। अगर किसी ने बुक नहीं किया है, तो सूची में **Nobody booked yet** और **Places taken will be listed here.** दिखता है।

### क्लास एडिट करें { #edit-a-class }

1. क्लास पर पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit class** डायलॉग खुलता है।
2. इंस्ट्रक्टर, समय, अवधि या सीटें बदलें।
3. **Save class** पर क्लिक करें।

आप **Places** को पहले से बुक हो चुके लोगों की संख्या से कम नहीं कर सकते। **Places** के नीचे का संकेत बताता है कि कितने लोग बुक हैं, जैसे **5 already booked — cannot go below that**।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Add a service first — a class is a service booked by several people.** | कोई सर्विस मौजूद नहीं है। | **Appts** → **Services** में एक सर्विस जोड़ें। देखें [बुक की जा सकने वाली सर्विस जोड़ें](add-services.md)। |
| **Class** के नीचे **Required** | कोई सर्विस नहीं चुनी गई। | **Class** में सर्विस चुनें। |
| **Places** के नीचे **At least 1** | **Places** खाली है, 0 है या संख्या नहीं है। | 1 या उससे ज़्यादा की संख्या लिखें। |
| **Places** के नीचे **At least 5 are already booked** | आपने पहले से बुक लोगों से कम सीटें रखने की कोशिश की। | **Places** को बुक की गई संख्या के बराबर या उससे ज़्यादा रखें। |
| **No classes in this week** | दिख रहे हफ़्ते में कुछ भी शेड्यूल नहीं है। | **Next week** पर क्लिक करें, या **Schedule a class** पर क्लिक करें। |
| **Could not save the class** | सर्वर ने क्लास नहीं ली, जैसे इसलिए कि खत्म होने का समय शुरू होने के समय के बाद नहीं था। | **Starts** और **Lasts** जाँचें, फिर दोबारा कोशिश करें। |
