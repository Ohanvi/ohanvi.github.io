# फ़ॉर्म सबमिशन पढ़ें { #read-form-submissions }

**Submissions** में हर फ़ॉर्म और हर सोर्स से आए जवाब दिखते हैं। जो जवाब प्रोसेस नहीं हुआ, उसे ठीक करने के लिए इसका इस्तेमाल करें।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Forms** के नीचे **Submissions** दिखता हो।

## स्टेप { #steps }

1. लेफ़्ट रेल में **Forms** खोलें, फिर **Submissions** चुनें।
2. किसी एक फ़िल्टर पर क्लिक करें: **All**, **Unmatched**, **Pending**, **Processed**, **Partly done** या **Failed**।
3. हर लाइन में सोर्स देखें: **WhatsApp chat**, **WhatsApp form**, **Public link** या **Meta lead ad**।
4. स्टेटस देखें: **Processed**, **No form matched**, **Failed**, **Partly done**, **Processing** या **Waiting**।
5. अगर किसी लाइन में सिर्फ़ पहले 6 जवाब दिख रहे हैं, तो **Show all N answers** पर क्लिक करें।
6. **No form matched** वाली लाइन में **Attach form** पर क्लिक करें। **Which form was this?** में फ़ॉर्म चुनें।
7. जो फ़ेल हुई लाइन दोबारा आज़माई जा सकती है, उसमें **Retry** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Retry** नहीं दिख रहा। | इस फ़ेल को दोबारा नहीं आज़माया जा सकता। | कारण पढ़ें और उसे ठीक करें। |
| कोई सबमिशन **Waiting** है। | उसे अभी तक उठाया नहीं गया है। | थोड़ा इंतज़ार करें, फिर रीफ़्रेश करें। |
