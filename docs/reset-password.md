# Reset your password

If you forgot your password, enter your email, type the 6-digit code Ohanvi sends you, and choose a new password. You are then signed out of every other device, and you sign in again with the new password.

## Before you start

- You can open the inbox of the email address on your Ohanvi account.
- You are on the Ohanvi login page at [app.ohanvi.com](https://app.ohanvi.com).

## Steps

### Get a code

1. On the login page, click **Forgot Password?**. The **Reset your password** panel opens.
2. In **Enter your email**, type the email on your Ohanvi account.
3. Click **Send code**. The **Enter verification code** screen opens and shows **We sent a 6-digit code to** your email.

    Ohanvi shows this screen whether or not the email has an account, so nobody can use it to check who uses Ohanvi. If no email arrives, see [Troubleshooting](#troubleshooting).

### Enter the code

4. Open your email. Find the message **Your password reset code**. The code is in the subject and in the email.
5. Type the 6-digit code into the box.
6. Click **Verify**. The new password screen opens.

The code works for 10 minutes. If it expired or never arrived, click **Resend code**. To use another email, click **Use a different email**.

### Choose a new password

7. In **New password**, type your new password. The checklist under the box turns green as each rule is met:

    - **8+ characters**
    - **Upper & lower case**
    - **2+ digits**
    - **1+ special character**
    - **Not a common or predictable password** — for example, `Password@123`, `Welcome#2024` or anything with `1234` is refused.

    Your password also cannot contain your username, name or email.

8. Type the same password in **Confirm new password**.
9. Click **Reset password**. The message **Password reset. Sign in with your new password.** appears, and the login page opens.
10. Sign in with your new password. See [Sign in to Ohanvi](sign-in.md).

!!! note "You are signed out everywhere else"
    Resetting your password signs your account out of every other browser and device. Ohanvi also emails you **Your password was changed**. If you did not reset your password, contact support right away.

!!! tip "Pick a password you can remember"
    Join a few unrelated words with a symbol and 2 digits, for example `Mango#River42Lamp`.

## Limits

To protect your account, each email address can, in any 24 hours:

- receive up to **5** codes (the first code plus resends), and
- reset its password up to **5** times.

Each code allows **3** wrong tries. After the third, request a new code. When a limit is reached, contact support to reset your password.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| No email arrived | The email has no Ohanvi account, it went to spam, or it was typed wrong. | Check spam and promotions. Click **Use a different email** and check the spelling. Use the email you signed up with. |
| **Incorrect code. 2 attempt(s) remaining.** | The code does not match. | Check the latest email — each **Resend code** replaces the previous code. |
| **Too many incorrect attempts. Please request a new code.** | 3 wrong codes were entered. | Click **Resend code** and use the new code. |
| **This code has expired. Please request a new one.** | More than 10 minutes passed. | Click **Resend code**. |
| **You've requested 5 codes in the last 24 hours. Please contact support to reset your password.** | The daily code limit was reached. | Contact support, or try again after 24 hours. |
| **You've reset your password 5 times in the last 24 hours. Please contact support to reset it again.** | The daily reset limit was reached. | Contact support. |
| **More than one account uses this email. Please contact support to reset your password.** | Several accounts share this email, so Ohanvi cannot tell which one to reset. | Contact support. |
| **Your reset session has expired. Please start again.** | More than 15 minutes passed after the code was accepted. | Reload the page, click **Forgot Password?** and start again. |
| **This password is too common and easy to guess** | The password is a common word with digits or symbols added. | Pick unrelated words, for example `Mango#River42Lamp`. |
| **Password must not contain your username, name or email.** | The password includes part of your name or email. | Choose a password without them. |
