# अपना अकाउंट बंद करें { #deactivate-your-account }

अपना पूरा Ohanvi अकाउंट पॉज़ करें। सब लोग साइन आउट हो जाते हैं और कोई साइन इन नहीं कर सकता, पर कुछ भी डिलीट नहीं होता। आप अपने पासवर्ड और ईमेल पर भेजे गए एक बार इस्तेमाल होने वाले कोड से पुष्टि करते हैं। इसमें लगभग 2 मिनट लगते हैं। दोबारा साइन इन करके आप अकाउंट वापस ला सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आप **account owner** हैं, यानी वह व्यक्ति जिसने अकाउंट बनाया था। दूसरे एडमिन को **Deactivate account** नहीं दिखता।
- आपको अपना पासवर्ड पता है।
- आप अपने अकाउंट के ईमेल पते को खोल सकते हैं। Ohanvi एक बार इस्तेमाल होने वाला कोड वहीं भेजता है।
- आप समझते हैं कि यह **पूरे** अकाउंट पर असर करता है, उसके हर यूज़र पर, सिर्फ़ आप पर नहीं।

## अकाउंट बंद करने से क्या होता है { #what-deactivating-does }

| क्या होता है | ब्योरा |
| --- | --- |
| सब लोग तुरंत साइन आउट हो जाते हैं। | अकाउंट में कोई साइन इन नहीं कर सकता। |
| कुछ भी डिलीट नहीं होता। | आपके संपर्क, चैट, सेटिंग्स और इनवॉइस बने रहते हैं। |
| आपका डेटा स्क्रीन पर दिखाए गए दिनों तक कम से कम रखा जाता है। | स्क्रीन पर डिफ़ॉल्ट रूप से **at least 90 days** लिखा होता है। |
| आप वापस आ सकते हैं। | उस समय के अंदर खुद दोबारा साइन इन करें। अकाउंट अपने-आप फिर चालू हो जाता है। |
| उस समय के बाद Ohanvi इसे डिलीट कर सकता है। | डिलीट करने का काम Ohanvi टीम करती है, इस स्क्रीन से नहीं। |

!!! warning "अकाउंट बंद करने से आपकी पूरी टीम साइन आउट हो जाती है"
    शुरू करने से पहले अपने साथियों को बता दें। साइन आउट होने पर उनका चल रहा काम सेव नहीं होता।

## चरण { #steps }

### स्क्रीन खोलें { #open-the-screen }

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. बाईं सूची में अपने नाम पर क्लिक करें। आपके अकाउंट की सेटिंग्स खुलती हैं।
3. **More** के नीचे **Deactivate account** ढूँढें और उस पर क्लिक करें। पेज का टाइटल **Deactivate account** होता है। यह पंक्ति सिर्फ़ अकाउंट ओनर को दिखती है।
4. टाइटल के नीचे की लाइन पढ़ें। उसमें आपके अकाउंट का नाम है और लिखा है कि यह आपका पासवर्ड और ईमेल पर भेजा गया कोड माँगता है।

### अकाउंट बंद करें { #deactivate-the-account }

1. **Deactivate account** कार्ड पर **Deactivate…** पर क्लिक करें। **Deactivate your account** विंडो खुलती है।
2. विंडो के ऊपर की चेतावनी पढ़ें।
3. **Step 1 of 2 — confirm it is you** के नीचे **Your password** में अपना पासवर्ड लिखें। उसे दिखाने या छिपाने के लिए आँख के आइकन पर क्लिक करें।
4. **Continue** पर क्लिक करें। Ohanvi आपके रजिस्टर्ड पते पर एक बार इस्तेमाल होने वाला कोड ईमेल करता है।
5. **Step 2 of 2 — enter the code we emailed you** के नीचे बैनर पढ़ें। उसमें छिपा हुआ ईमेल पता और कोड कितनी देर तक मान्य है, यह दिखता है।
6. **Verification code** में कोड लिखें।
7. **Deactivate account** पर क्लिक करें। सब लोग साइन आउट हो जाते हैं। साइन-इन स्क्रीन पर अकाउंट के बारे में Ohanvi का संदेश दिखता है।

अगर कोड नहीं आता, तो **Resend code** पर क्लिक करें।

### अकाउंट वापस लाएँ { #bring-the-account-back }

1. Ohanvi का साइन-इन पेज खोलें। देखें [Ohanvi में साइन इन करें](../sign-in.md)।
2. **Deactivate account** स्क्रीन पर दिखाए गए दिनों के अंदर ओनर के रूप में साइन इन करें।
3. अकाउंट अपने-आप फिर चालू हो जाता है। अपने साथियों को बताएँ कि वे दोबारा साइन इन कर सकते हैं।

### अकाउंट हमेशा के लिए डिलीट करें { #delete-the-account-for-good }

आप सेटिंग्स से अकाउंट डिलीट नहीं कर सकते। स्क्रीन पर लिखा है कि Ohanvi सपोर्ट से info@ohanvi.com पर संपर्क करें। डिलीट करने का काम Ohanvi टीम करती है, और उसे वापस नहीं किया जा सकता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Deactivate account** सूची में नहीं है। | आप अकाउंट ओनर नहीं हैं। | ओनर से बंद करने को कहें, या Ohanvi सपोर्ट से संपर्क करें। |
| पेज पर **Only the account owner — the person who created this account — can deactivate it.** दिखता है | आपका यूज़र अकाउंट बनाने वाला ओनर नहीं है। | ओनर के रूप में साइन इन करें। |
| **Enter your password.** | पासवर्ड का बॉक्स खाली है। | अपना पासवर्ड लिखें और **Continue** पर क्लिक करें। |
| **Could not send the code.** | कोड वाला ईमेल नहीं गया। | अपना कनेक्शन जाँचें और फिर से **Continue** पर क्लिक करें। |
| **Enter the code from your email.** | कोड का बॉक्स खाली है। | ईमेल से कोड लिखें। |
| **The request failed. Nothing was changed.** | कोड गलत है या एक्सपायर हो गया है। | **Resend code** पर क्लिक करें, फिर नया कोड डालें। |
