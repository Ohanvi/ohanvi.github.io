# इंटीग्रेशन { #integrations }

इंटीग्रेशन से Ohanvi उन टूल से जुड़ जाता है जो आप पहले से इस्तेमाल करते हैं। हर कनेक्शन एक ही बार बनाना पड़ता है। उसके बाद हर मॉड्यूल उसे इस्तेमाल कर सकता है।

## यह कहाँ मिलेगा { #where-to-find-it }

नीचे-बाएँ कोने में अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** पर क्लिक करें। **Workspace** के नीचे **Integrations** पर क्लिक करें।

## गाइड { #guides }

| गाइड | कब काम आएगी |
| --- | --- |
| [अपना ऑनलाइन स्टोर कनेक्ट करें](../connect-your-store.md) | आप Shopify, WooCommerce, Wix या Zoho Commerce इस्तेमाल करते हैं। |
| [Tally अकाउंटिंग कनेक्ट करें](../connect-tally-accounting.md) | आप चाहते हैं कि लेजर, पार्टी, आइटम और वाउचर Tally के साथ सिंक रहें। |
| [Google Workspace कनेक्ट करें](../connect-google-workspace.md) | आप चाहते हैं कि फ़्लो में Google Sheets, Calendar, Meet, Forms या Contacts इस्तेमाल हो सकें। |
| [Zapier कनेक्ट करें](../connect-zapier.md) | आप चाहते हैं कि Ohanvi बिना कोड के दूसरे ऐप से जुड़े। |
| [Pabbly कनेक्ट करें](../connect-pabbly.md) | आप Pabbly Connect वर्कफ़्लो इस्तेमाल करते हैं। |
| [अपनी या Ohanvi की मैनेज्ड सर्विस चुनें](../choose-connectors.md) | आप अपना खुद का WhatsApp, AI या ईमेल प्रोवाइडर इस्तेमाल करना चाहते हैं। |
| [डेवलपर API से WhatsApp मैसेज भेजें](../developer-apis.md) | किसी डेवलपर को आपके सिस्टम से मैसेज भेजने हैं। |

## शुरू करने से पहले { #before-you-start }

- आप **Settings** में **Integrations** खोल सकते हों।
