# शेड्यूल किए गए आइटम को रीशेड्यूल, रद्द या डिलीट करें { #reschedule-cancel-or-delete-a-scheduled-item }

**Schedule** सेक्शन से बाहर गए बिना किसी शेड्यूल किए गए आइटम में बदलाव करें। आप उसे नई तारीख और समय पर ले जा सकते हैं, कंटेंट एडिट करने के लिए उसके अपने मॉड्यूल में खोल सकते हैं, रद्द कर सकते हैं या डिलीट कर सकते हैं। बदलाव सिर्फ़ Schedule पर नहीं, बल्कि व्हाट्सऐप, CRM, ईमेल, सोशल या अपॉइंटमेंट में मौजूद असली आइटम पर होता है।

## शुरू करने से पहले { #before-you-start }

- आप लेफ़्ट रेल में **Schedule** खोल सकें। देखें [जो कुछ भी शेड्यूल है, सब देखें](view-schedule.md)।
- आपका रोल उस आइटम को उसके अपने मॉड्यूल में बदल सकता हो। जैसे ईमेल कैंपेन रद्द करने के लिए आपके पास Email Marketing का एक्सेस होना चाहिए।
- आपकी ब्राउज़र विंडो इतनी चौड़ी हो कि डिटेल्स पैनल दिखे। एक्शन बटन वहीं होते हैं।

## चरण { #steps }

### आइटम खोलें { #open-the-item }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **All schedules** चुनें।
2. **List** पर क्लिक करें, फिर आइटम पर क्लिक करें। उसकी जानकारी दाईं ओर खुलती है। **Calendar** व्यू में इसके बजाय आइटम के चिप पर क्लिक करें; पेज **List** पर बदल जाता है और आइटम चुना हुआ दिखता है।
3. जानकारी के नीचे आपको चार बटन दिखते हैं: **Reschedule**, **Edit**, **Cancel** और **Delete**।

### नए समय पर रीशेड्यूल करें { #reschedule-to-a-new-time }

1. **Reschedule** पर क्लिक करें। तारीख चुनने वाला खुलता है।
2. नई तारीख चुनें और **OK** पर क्लिक करें। समय चुनने वाला खुलता है।
3. नया समय चुनें और **OK** पर क्लिक करें। **Rescheduled.** मैसेज दिखता है और आइटम Schedule पर नए समय पर पहुँच जाता है।

आइटम का अपना मॉड्यूल नया समय दोबारा जाँचता है। अपॉइंटमेंट के लिए नया समय खाली और काम के घंटों के भीतर होना चाहिए, और रिमाइंडर भी उसके साथ खिसक जाते हैं। बार-बार चलने वाले व्हाट्सऐप शेड्यूल के लिए इससे अगले भेजने का समय बदलता है।

### कंटेंट एडिट करें { #edit-the-content }

1. **Edit** पर क्लिक करें। **Opening WhatsApp…** (या आइटम के चैनल का नाम) मैसेज दिखता है।
2. Ohanvi वह मॉड्यूल खोलता है जहाँ आइटम बना था: व्हाट्सऐप **Scheduler**, CRM गतिविधियाँ, ईमेल कैंपेन, सोशल पब्लिशिंग या **Appointments**।
3. वहाँ आइटम खोजें और उसका कंटेंट बदलें।

### आइटम रद्द करें { #cancel-an-item }

1. **Cancel** पर क्लिक करें। **Cancel schedule** डायलॉग खुलता है और बताता है कि आइटम उसके चैनल में रद्द होता है और रिकॉर्ड बना रहता है।
2. **Cancel it** पर क्लिक करें। **Cancelled.** मैसेज दिखता है और स्टेटस **Cancelled** हो जाता है।

हर मॉड्यूल में रद्द करने का असर:

| चैनल | नतीजा |
| --- | --- |
| **WhatsApp** | शेड्यूल किया गया जॉब रुक जाता है और व्हाट्सऐप **Scheduler** से हट जाता है। |
| **CRM** | गतिविधि का स्टेटस रद्द पर सेट हो जाता है। |
| **Email** | कैंपेन रद्द हो जाता है और नहीं भेजा जाता। |
| **Social** | शेड्यूल किया गया पोस्ट रद्द हो जाता है। |
| **Appointments** | बुकिंग **Cancelled** पर सेट हो जाती है और उसके रिमाइंडर हट जाते हैं। |

### आइटम डिलीट करें { #delete-an-item }

!!! warning "Delete से आइटम उसके मॉड्यूल से भी हट जाता है"
    Delete आइटम को सिर्फ़ Schedule से नहीं, बल्कि व्हाट्सऐप, CRM, ईमेल या सोशल से भी हटा देता है। अपॉइंटमेंट कभी डिलीट नहीं होते: **Delete** की जगह बुकिंग रद्द हो जाती है।

1. **Delete** पर क्लिक करें। **Delete schedule** डायलॉग खुलता है।
2. **Delete** पर क्लिक करें। **Deleted.** मैसेज दिखता है और आइटम Schedule से हट जाता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not reschedule.** | मॉड्यूल ने नया समय नहीं माना। अपॉइंटमेंट के लिए समय भरा हो सकता है, काम के घंटों से बाहर हो सकता है, या आपके बुकिंग नियमों के बाहर हो सकता है। | कोई दूसरा समय चुनें। अपॉइंटमेंट के लिए **Appointments** पेज पर **Move** इस्तेमाल करें, जो खाली समय सुझाता है। देखें [अपॉइंटमेंट प्रबंधित करें](../appointments/index.md)। |
| **Could not cancel.** | आइटम पहले ही भेजा जा चुका है, पूरा हो चुका है या रद्द हो चुका है, या आपका रोल उसे उसके मॉड्यूल में नहीं बदल सकता। | स्टेटस जाँचें। जिस मॉड्यूल का वह आइटम है, उसके एक्सेस के लिए अपने एडमिन से कहें। |
| **Could not delete.** | आपका रोल उस मॉड्यूल में डिलीट नहीं कर सकता, या आइटम अब मौजूद नहीं है। | पेज रीफ़्रेश करें। उस मॉड्यूल में डिलीट एक्सेस के लिए अपने एडमिन से कहें। |
| **Reschedule**, **Edit**, **Cancel** और **Delete** नहीं दिख रहे | छोटी विंडो में डिटेल्स पैनल छिपा रहता है। | ब्राउज़र विंडो चौड़ी करें। |
| **Rescheduled.** के बाद भी आइटम पर पुराना समय दिख रहा है | पेज रीफ़्रेश नहीं हुआ है। | पैनल का कोई दूसरा आइटम खोलकर वापस आएँ, या पेज रीलोड करें। |
