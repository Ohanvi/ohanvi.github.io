# कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें { #comment-mention-and-attach-files }

टास्क के बारे में बातचीत टास्क पर ही रखें। यहाँ आप कमेंट और रिप्लाई कर सकते हैं, किसी टीममेट को @मेंशन करके उसे बता सकते हैं, फ़ाइलें और स्क्रीनशॉट अटैच कर सकते हैं, और जो टास्क आपका नहीं है उसे भी फ़ॉलो कर सकते हैं। आप काम में लगा समय लॉग कर सकते हैं, और यह भी चुन सकते हैं कि टास्क के बदलावों की जानकारी Ohanvi आपको कैसे दे।

## शुरू करने से पहले { #before-you-start }

- आप कोई सेव किया हुआ टास्क खोल पाते हों। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।
- जिन टीममेट को आप मेंशन करना चाहते हैं, वे आपके वर्कस्पेस के यूज़र हों।

## स्टेप { #steps }

### कमेंट जोड़ें { #add-a-comment }

1. बोर्ड या **Tasks** पैनल से कोई टास्क खोलें। टास्क डायलॉग खुलेगा।
2. **Activity** तक स्क्रॉल करें और **Add a comment...** पर क्लिक करें।
3. अपना कमेंट लिखें। नई लाइन के लिए Shift + Enter दबाएँ।
4. पोस्ट करने के लिए Enter दबाएँ। कमेंट **Comments** के नीचे दिखेगा।

जल्दी जवाब देना हो, तो बॉक्स के नीचे से कोई तैयार कमेंट चुनें, जैसे **Looks good!**, **Need help?** या **This is blocked...**। फिर उसमें बदलाव करें और Enter दबाएँ।

### किसी टीममेट को मेंशन करें { #mention-a-teammate }

1. कमेंट में या टास्क के **Description** में `@` लिखें।
2. व्यक्ति के नाम के शुरुआती अक्षर लिखें और लिस्ट में से उसे चुनें।
3. कमेंट पोस्ट करें। डिस्क्रिप्शन में मेंशन किया हो, तो **Save** पर क्लिक करें। जिन्हें आपने मेंशन किया, उन्हें Ohanvi एक ईमेल भेजता है। उसका सब्जेक्ट होता है "[task key] … mentioned you"।

### कमेंट का जवाब दें, रिएक्ट करें, एडिट करें या डिलीट करें { #reply-to-react-to-edit-or-delete-a-comment }

- **जवाब दें:** कमेंट पर रिप्लाई आइकन (टूलटिप **Reply**) पर क्लिक करें, **Write a reply…** में लिखें और Enter दबाएँ।
- **रिएक्ट करें:** कमेंट पर स्माइली आइकन पर क्लिक करें और कोई इमोजी चुनें। अपना रिएक्शन वापस लेने के लिए उसी इमोजी पर फिर क्लिक करें।
- **एडिट करें:** पेंसिल आइकन (टूलटिप **Edit**) पर क्लिक करें, टेक्स्ट बदलें और सेव करने के लिए Enter दबाएँ।
- **कमेंट का लिंक कॉपी करें:** **More actions** → **Copy link** पर क्लिक करें। **Comment link copied** मैसेज आएगा।
- **डिलीट करें:** **More actions** → **Delete** पर क्लिक करें, फिर **Delete comment?** डायलॉग में **Delete** पर क्लिक करें।

!!! warning "चेतावनी: डिलीट किया कमेंट वापस नहीं आता"
    **Delete comment?** से कमेंट हमेशा के लिए हट जाता है।

### फ़ाइलें अटैच करें { #attach-files }

1. टास्क खोलें और **Attachments** तक स्क्रॉल करें।
2. फ़ाइलों को उस बॉक्स पर ड्रैग करें जिस पर **Drop files here to attach them or browse** लिखा है। या **browse** पर क्लिक करें और फ़ाइलें चुनें।
3. फ़ाइलें अपलोड होकर लिस्ट में दिखेंगी। फ़ाइल का ज़्यादा से ज़्यादा साइज़: [LIMIT]।

स्क्रीनशॉट या फ़ाइल को सीधे **Description** में पेस्ट भी कर सकते हैं। अटैचमेंट देखने के लिए **Preview** (सिर्फ़ इमेज और वीडियो के लिए) या **Download** पर क्लिक करें। किसी अटैचमेंट को हटाने के लिए उसके डिलीट आइकन पर क्लिक करें और **Delete Attachment** डायलॉग में **Delete** पर क्लिक करके पक्का करें।

### टास्क को वॉच करें { #watch-a-task }

1. टास्क खोलें।
2. डायलॉग के ऊपर आँख वाले आइकन (टूलटिप **Watch**) पर क्लिक करें।

वॉचर को वही ईमेल मिलते हैं जो टास्क के रिपोर्टर और असाइनी को मिलते हैं। वॉच करना बंद करने के लिए आइकन पर फिर क्लिक करें (टूलटिप **Stop watching**)।

### टास्क शेयर करें { #share-a-task }

1. टास्क खोलें।
2. डायलॉग के ऊपर शेयर आइकन (टूलटिप **Share**) पर क्लिक करें। **Copied ticket link: …** मैसेज आएगा।
3. लिंक को चैट या ईमेल में पेस्ट करें। जिन टीममेट के पास टास्क का एक्सेस है, वे उसी लिंक से टास्क खोल सकेंगे।

### समय लॉग करें { #log-time }

1. टास्क खोलें और **Activity** तक स्क्रॉल करें।
2. **Work log** पर क्लिक करें, फिर **Log time** पर क्लिक करें।
3. **Time spent** में समय लिखें, जैसे `1h 30m`। w, d, h और m इस्तेमाल करें। सिर्फ़ नंबर लिखने पर वह मिनट माना जाता है।
4. **Date** सेट करें। चाहें तो **Work description (optional)** में भी कुछ लिखें।
5. **Save** पर क्लिक करें। एंट्री **Time logged** के नीचे दिखेगी।

### टास्क की हिस्ट्री देखें { #see-a-tasks-history }

**Activity** में **History** पर क्लिक करें। यहाँ हर स्टेटस बदलाव, असाइनी बदलाव और एडिट दिखता है, साथ में यह भी कि किसने किया और कब किया। कमेंट और हिस्ट्री एक साथ देखने के लिए **All** पर क्लिक करें।

### चुनें कि टास्क के बदलावों की जानकारी आपको कैसे मिले { #choose-how-you-hear-about-task-changes }

टास्क बनने, असाइन होने, नए स्टेटस में जाने या उस पर कमेंट होने पर Ohanvi रिपोर्टर, असाइनी और सभी वॉचर को ईमेल भेजता है। आपने खुद जो बदलाव किया, उसका ईमेल आपको नहीं आता।

1. लेफ़्ट रेल से **Settings** खोलें, फिर **Notifications** चुनें।
2. **Task Management** वाली पंक्ति ढूँढें ("Assigned tickets, mentions and status changes")।
3. **In-app**, **Push** या **Email** को चालू या बंद करें। **Email** कॉलम सिर्फ़ सुपर एडमिन बदल सकता है।

### टास्क रिमाइंडर पाएँ { #get-task-reminders }

रिमाइंडर वह समय है जब आप चाहते हैं कि किसी टास्क की आपको याद दिलाई जाए। इसे आप WhatsApp कॉल नोट में **Remind me on** और **Remind me at** से सेट करते हैं। Ohanvi उसके लिए एक टास्क बना देता है।

- रिमाइंडर का समय निकल जाने पर टास्क कार्ड पर **Reminder due** दिखता है। बोर्ड पर कॉलम के ऊपर **1 reminder due** जैसी पट्टी भी दिखती है।
- असाइनी को बेल में नोटिफ़िकेशन मिलता है: **Reminder: [task key] — [summary]**। अगर किसी को असाइन नहीं किया है, तो यह रिपोर्टर को मिलता है। पुश नोटिफ़िकेशन चालू हो, तो यह उनके फ़ोन पर भी आता है।
- रिमाइंडर के लिए आपके वर्कस्पेस का रिमाइंडर शेड्यूल चालू होना चाहिए। [VERIFY: reminders are enabled in production]

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not save comment.** | कमेंट सर्वर तक नहीं पहुँचा। | आपका टेक्स्ट बॉक्स में बना रहता है। Enter फिर से दबाएँ। |
| कोई टीममेट @ लिस्ट में नहीं दिख रहा | वह आपके वर्कस्पेस का यूज़र नहीं है, या अक्षर उसके नाम से नहीं मिल रहे। | स्पेलिंग जाँचें, या अपने एडमिन से कहें कि उसे यूज़र बनाएँ। |
| **Preview is available for images and videos only.** | फ़ाइल PDF, स्प्रेडशीट या कोई और डॉक्यूमेंट है। | उसे खोलने के लिए **Download** पर क्लिक करें। |
| **Failed to delete attachment.** | डिलीट सेव नहीं हुआ। | टास्क बंद करके दोबारा खोलें, फिर कोशिश करें। |
| **Could not resolve your account to watch.** | Ohanvi आपके लॉगिन को प्रोजेक्ट के किसी मेंबर से मिला नहीं पाया। | साइन आउट करके दोबारा साइन इन करें, फिर **Watch** पर फिर से क्लिक करें। |
| टास्क के ईमेल नहीं आ रहे | **Task Management** के लिए Email बंद है, या ईमेल स्पैम में चले गए। | **Settings** → **Notifications** जाँचें, फिर अपना स्पैम फ़ोल्डर देखें। |
