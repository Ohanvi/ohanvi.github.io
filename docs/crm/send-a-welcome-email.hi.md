# किसी संपर्क को वेलकम ईमेल भेजें { #send-a-welcome-email-to-a-contact }

Ohanvi से बाहर गए बिना किसी एक संपर्क को एक ईमेल भेजें। आखिर में संपर्क के इनबॉक्स में वह ईमेल आपके चुने ब्रोशर के साथ पहुँच जाता है, और ईमेल उनकी गतिविधि हिस्ट्री में दिखता है। इसमें करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Contacts** दिखता हो और उसके पैनल में **All contacts** हो।
- संपर्क का **Email** भरा हो। देखें [संपर्क प्रबंधित करें](manage-contacts.md)।
- डिफ़ॉल्ट मैसेज बदलना हो तो देखें [वेलकम ईमेल सेट करें](set-up-the-welcome-email.md)।

## भेजने के दो तरीके { #two-ways-to-send }

| मोड | कब इस्तेमाल करें |
| --- | --- |
| **Compose + PDF** | आप सब्जेक्ट और मैसेज एडिट करना और अपनी फ़ाइलें अटैच करना चाहते हैं। |
| **Ohanvi brochure** | आप ऐसा तैयार ईमेल चाहते हैं जिसमें ब्रोशर मैसेज के अंदर दिखे। सब्जेक्ट और बॉडी आपके लिए बने होते हैं। |

## चरण { #steps }

### ईमेल विंडो खोलें { #open-the-email-window }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. संपर्क पर क्लिक करें, फिर **More actions** (**…** बटन) पर क्लिक करें।
3. **Send Welcome Email** पर क्लिक करें। ईमेल विंडो खुलती है।
4. **To** बॉक्स पढ़ें। उसमें संपर्क का ईमेल दिखता है और आप उसे यहाँ बदल नहीं सकते।
5. विंडो बड़ी करने के लिए उसके हेडर में मैक्सिमाइज़ बटन पर क्लिक करें।

### Compose + PDF से भेजें { #send-with-compose-pdf }

1. विंडो के ऊपर **Compose + PDF** पर क्लिक करें।
2. वैकल्पिक: **Email Template** के नीचे कोई सेव किया हुआ ईमेल टेम्प्लेट चुनें। बॉक्स में **Select a template (optional)** लिखा होता है। सब्जेक्ट और बॉडी अपने आप भर जाते हैं।
3. **Subject** जाँचें। विंडो आपके सेव किए वेलकम सब्जेक्ट के साथ शुरू होती है।
4. **Body** जाँचें। चाहें तो इस संपर्क के लिए उसे एडिट करें। आपका बदलाव सिर्फ़ इसी ईमेल पर असर डालता है।
5. **Attach brochures** के नीचे हर वह फ़ाइल टिक करें जिसे आप अटैच करना चाहते हैं। हर नाम के नीचे उसका साइज़ दिखता है।
6. **Send** पर क्लिक करें। **Welcome email sent to …** मैसेज आता है।

अगर **Subject** खाली है, तो विंडो में **Add a subject before sending** लिखा आता है। अगर **Body** खाली है, तो **Add a message before sending** लिखा आता है।

### Ohanvi ब्रोशर ईमेल भेजें { #send-the-ohanvi-brochure-email }

1. विंडो के ऊपर **Ohanvi brochure** पर क्लिक करें।
2. ईमेल समझाने वाला बॉक्स पढ़ें। यह एक तैयार मैसेज है जिसके अंदर ब्रोशर दिखता है। आपको सब्जेक्ट या बॉडी नहीं लिखनी पड़ती।
3. वैकल्पिक: **Add images to the email** के नीचे **Click to add images** पर क्लिक करें या उस पर फ़ाइलें ड्रॉप करें। PNG, JPG, GIF या WEBP फ़ाइलें इस्तेमाल करें, हर एक अधिकतम 5 MB की। काउंटर दिखाता है कि आपने कितनी जोड़ी हैं, जैसे **2/6**।
4. **Attach brochures** के नीचे वे ब्रोशर टिक करें जिन्हें शामिल करना है।
5. **Send** पर क्लिक करें।

### इसी विंडो से ब्रोशर जोड़ें { #add-a-brochure-from-this-window }

1. **Attach brochures** के पास **Manage** पर क्लिक करें। **Manage Brochures** विंडो खुलती है।
2. **Upload brochure** पर क्लिक करें और कोई फ़ाइल चुनें। फ़ाइल के नियमों के लिए देखें [वेलकम ईमेल सेट करें](set-up-the-welcome-email.md)।
3. विंडो बंद करें। नई फ़ाइल सूची में आ गई है। उसे टिक करें।

अगर अभी आपकी कोई फ़ाइल नहीं है, तो सूची में **No brochures yet. Tap Manage to upload the booklet.** लिखा आता है।

### जाँचें कि वह लॉग हुआ { #check-that-it-was-logged }

1. संपर्क चुनें और **More actions** से **Notes & Activities** खोलें। या बीच वाले पैन में **Email** टैब खोलें।
2. अपना भेजा हुआ ईमेल ढूँढें। हर वेलकम ईमेल संपर्क पर एक ईमेल गतिविधि के रूप में सेव होता है।
3. **All contacts** सूची पर वापस जाएँ। उस संपर्क की ईमेल गिनती 1 बढ़ गई है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not send the email. Please retry.** | ईमेल नहीं गया। | **Send** पर फिर क्लिक करें। संपर्क का **Email** जाँचें। |
| **To** बॉक्स खाली है | संपर्क का कोई ईमेल नहीं है। | **Identity** ब्लॉक में **Email** जोड़ें, फिर **Update contact** पर क्लिक करें। |
| सूची में कोई अटैच की गई फ़ाइल नहीं दिखती | वह अपलोड नहीं हुई थी, या डिलीट हो गई। | **Manage** पर क्लिक करें और उसे दोबारा अपलोड करें। |
| संपर्क पर **Email Opt-out** टिक है | संपर्क ने ईमेल न पाने को कहा है। | उनकी पसंद का सम्मान करें। देखें [संपर्क की सहमति ट्रैक करें](consent-and-compliance.md)। |
