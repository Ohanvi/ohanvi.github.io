# Publish के फ़िल्टर, ओवरव्यू और पोस्ट की डिटेल { #use-publish-filters-overview-and-post-details }

इस पेज में **Publish** के छोटे हिस्से बताए गए हैं: चैनल फ़िल्टर, साइड पैनल, हर पोस्ट का मेन्यू और डिटेल वाली विंडो। इनसे आप कोई भी पोस्ट ढूँढ सकते हैं और नेटवर्क पर उसका लिंक कॉपी कर सकते हैं। आप यह भी देख सकते हैं कि कौन-सा चैनल फ़ेल हुआ। किसी पोस्ट की कॉपी बनाकर दोबारा भी इस्तेमाल कर सकते हैं। इसमें करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखना चाहिए, और उसके पैनल में **Publish** होना चाहिए।
- कम से कम एक नेटवर्क कनेक्ट हो और आपने कम से कम एक पोस्ट बनाई हो। इसके लिए [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md) देखें।

## स्टेप { #steps }

### टैब और गिनती देखें { #read-the-tabs-and-counts }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. ऊपर के टैब देखें: **Queue**, **Drafts**, **Approvals** और **Sent**। हर टैब में लिखा होता है कि उसमें कितनी पोस्ट हैं।
3. व्यू बदलने के लिए **List** या **Calendar** पर क्लिक करें। कैलेंडर के बारे में जानने के लिए [पोस्ट शेड्यूल करें और Queue संभालें](schedule-social-posts.md) देखें।
4. कोई टैब खाली हो, तो उसमें **No … posts yet.** लिखा आता है।
5. पोस्ट दोबारा लोड करने के लिए रिफ़्रेश आइकन पर क्लिक करें।

### पहली बार शुरू करें { #start-for-the-first-time }

कोई चैनल कनेक्ट न हो, तो **Publish** में **Welcome to Publish** दिखता है।

1. अपना पहला नेटवर्क कनेक्ट करने के लिए **Connect a Channel** पर क्लिक करें। इसके लिए [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md) देखें।
2. या पहले अपनी टीम के लोगों को जोड़ने के लिए **Invite your Team** पर क्लिक करें।

### चैनल से फ़िल्टर करें { #filter-by-channel }

1. फ़िल्टर वाली लाइन में **Channels** पर क्लिक करें। छोटी स्क्रीन पर पहले **Filters** पर क्लिक करें।
2. चैनल ढूँढने के लिए **Search channels** में टाइप करें।
3. जो चैनल चाहिए, उन पर टिक लगाएँ। सभी चैनल चुनने के लिए **Select all** पर क्लिक करें।
4. कोई चैनल न मिले, तो लिस्ट में **No channels found** लिखा आता है। नया चैनल जोड़ने के लिए **Connect a Channel** पर क्लिक करें।
5. अब लिस्ट और गिनती में सिर्फ़ वही चैनल दिखते हैं।

### Tags और Timezone फ़िल्टर देखें { #check-the-tags-and-timezone-filters }

1. **Tags** पर क्लिक करें। वहाँ **No tags** और **Use tags to organise your content** लिखा है। अभी टैग चुने नहीं जा सकते।
2. **Timezone** पर क्लिक करें। वहाँ **Based on this device — per-user timezones are coming soon.** लिखा है। यानी पोस्ट का समय आपके डिवाइस के हिसाब से चलता है।

### बिना तारीख वाले ड्राफ़्ट ढूँढें { #find-drafts-with-no-date }

1. **Calendar** व्यू में **No Date** पर क्लिक करें।
2. **Undated drafts** देखें। इसमें वे ड्राफ़्ट और अप्रूवल दिखते हैं जिनकी शेड्यूल तारीख तय नहीं है।
3. ऐसा कोई न हो, तो **No Undated Drafts** लिखा आता है।

### Publishing Overview देखें { #read-the-publishing-overview }

1. **Publish** के दाईं तरफ़ वाला पैनल देखें।
2. **Publishing Overview** में **This Week** देखें। इसमें **Queued**, **Drafts**, **Published** और **Failed** की गिनती होती है।
3. उसके नीचे की लाइन पढ़ें। वह बताती है कि इस हफ़्ते आपकी कितने प्रतिशत पोस्ट सफलता से पब्लिश हुईं।

### Quick Actions चलाएँ { #use-quick-actions }

1. उसी पैनल में **Quick Actions** देखें।
2. कंपोज़र खोलने के लिए **Create Post** पर क्लिक करें।
3. **Templates** खोलने के लिए **Create from Template** पर क्लिक करें। इसके लिए [पोस्ट Template इस्तेमाल करें](use-post-templates.md) देखें।
4. कैलेंडर पर जाने के लिए **View Calendar** पर क्लिक करें।
5. **Bulk Schedule** और **Media Library** पर क्लिक करने से मैसेज आता है कि ये जल्द आ रहे हैं।

### पोस्ट का मेन्यू इस्तेमाल करें { #use-the-menu-on-a-post }

1. किसी पोस्ट के **⋯** मेन्यू पर क्लिक करें।
2. **Queue** की पोस्ट पर **Publish Now** या **Cancel schedule** पर क्लिक कर सकते हैं।
3. किसी भी पोस्ट पर **Duplicate** पर क्लिक करें। इससे उसकी कॉपी बनती है, जिसे आप बदलकर दोबारा भेज सकते हैं।
4. पोस्ट हटाने के लिए **Delete** पर क्लिक करें।
5. **Sent** की पोस्ट पर **Post Details** और **Copy link** भी मिलते हैं।
6. नेटवर्क पर पोस्ट का लिंक कॉपी करने के लिए **Copy link** पर क्लिक करें। मैसेज **Link copied.** दिखता है। पोस्ट का लिंक अभी न बना हो, तो **No published link available yet.** लिखा आता है।

### पोस्ट की डिटेल खोलें { #open-the-post-details }

1. **Sent** की पोस्ट पर **⋯** पर क्लिक करें, फिर **Post Details** चुनें।
2. ऊपर **Published on** और तारीख लिखी होती है।
3. चैनल और पोस्ट का टेक्स्ट पढ़ें। मीडिया नीचे एक पट्टी में दिखता है।
4. **Channels** में देखें कि किस नेटवर्क पर पोस्ट पब्लिश हुई और किस पर फ़ेल हुई। फ़ेल हुए नेटवर्क के आगे उसकी एरर दिखती है।
5. पोस्ट के आँकड़ों वाली लाइन देखें।
6. नेटवर्क पर पोस्ट खोलने के लिए **Go to post** पर क्लिक करें। लिंक अभी न बना हो, तो **No published link available yet.** लिखा आता है।

### एक पोस्ट का एनालिटिक्स देखें { #see-the-analytics-of-one-post }

1. जो **Sent** पोस्ट फ़ेल नहीं हुई, उस पर **View Analytics** पर क्लिक करें। फ़ेल हुई पोस्ट पर इसकी जगह **Retry** दिखता है।
2. **Post Analytics** विंडो खुलती है। उसमें हर नेटवर्क की एक लाइन होती है।
3. अभी आँकड़े न आए हों, तो **No published targets for this post yet.** लिखा आता है।
4. देखने के बाद **Close** पर क्लिक करें।

### शेड्यूल की हुई पोस्ट कैंसिल करें { #cancel-a-scheduled-post }

1. **Queue** की पोस्ट पर **⋯** पर क्लिक करें, फिर **Cancel schedule** चुनें।
2. **Cancel this scheduled post?** में कैंसिल करने के लिए **Cancel schedule** पर क्लिक करें। पोस्ट को शेड्यूल ही रहने देना हो, तो **Keep scheduled** पर क्लिक करें।

### फ़ीडबैक भेजें { #send-feedback }

1. **Publish** के ऊपर **Share Feedback** पर क्लिक करें।
2. अपनी बात लिखें और **Submit** पर क्लिक करें। बिना भेजे बंद करना हो, तो **Close** पर क्लिक करें।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Welcome to Publish** दिखता है | कोई चैनल कनेक्ट नहीं है। | **Connect a Channel** पर क्लिक करें। |
| **No channels found** | आपकी खोज से कुछ मिला नहीं, या कुछ भी कनेक्ट नहीं है। | खोज मिटा दें, या कोई चैनल कनेक्ट करें। |
| **No published link available yet.** | नेटवर्क ने अभी लिंक वापस नहीं भेजा। | एक मिनट रुकें और फिर कोशिश करें। |
| **Bulk Schedule** या **Media Library** सिर्फ़ मैसेज दिखाते हैं | ये अभी बने नहीं हैं। | पोस्ट एक-एक करके शेड्यूल करें। |
| **Tags** में **No tags** लिखा है | अभी टैग जोड़े नहीं जा सकते। | कोई समाधान नहीं। |
