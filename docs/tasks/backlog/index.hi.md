# बैकलॉग { #backlog }

**Backlog** व्यू में वे टास्क दिखते हैं जो अभी किसी स्प्रिंट में नहीं हैं। उनके ऊपर आपके स्प्रिंट दिखते हैं। यहाँ टास्क जोड़ें और सजाएँ, फिर उन्हें स्प्रिंट में डालें।

**इसे कहाँ खोलें:** दाईं ओर की रेल में **Tasks** पर क्लिक करें, **Board** पर क्लिक करें, फिर व्यू स्विचर में **Backlog** पर क्लिक करें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [बैकलॉग के आइटम के साथ काम करें](../work-with-the-backlog.md) | आपको टास्क जोड़ना, उसका नाम बदलना, किसी और को सौंपना या ड्रैग करना है। |
| [स्प्रिंट में काम की योजना बनाएँ](../plan-sprints.md) | आपको स्प्रिंट बनाना, शुरू करना और पूरा करना है। |

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल पाते हैं। देखें [टास्क प्रोजेक्ट सेट करें](../set-up-task-project.md)।
- आपके प्रोजेक्ट में कम से कम 1 बोर्ड कॉलम है।
