# सेल्स कोटा सेट करें { #set-sales-quotas }

हर सेल्सपर्सन को महीने का सेल्स टारगेट दें, फिर देखें कि वे उसके कितने करीब हैं। आखिर में फ़ोरकास्ट हर ओनर की उपलब्धि उसके कोटा के मुकाबले दिखाता है। एक कोटा जोड़ने में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **CRM** दिखता है और उसके पैनल में **Forecast** है।
- आपको ओनर का यूज़रनेम, महीना और टारगेट की रकम पता है।

## चरण { #steps }

### Sales Quotas खोलें { #open-sales-quotas }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Forecast** चुनें।
2. **Manage quotas** पर क्लिक करें। **Sales Quotas** सूची खुलती है।

आप **Ctrl K** (Mac पर **⌘K**) दबाकर **Sales Quotas** लिखें और उसे चुनें, तब भी यह खुलता है।

### कोटा जोड़ें { #add-a-quota }

1. **Add** पर क्लिक करें। **Add Sales Quotas** फ़ॉर्म खुलता है।
2. **Owner Username** भरें। यह वह व्यक्ति है जिसका टारगेट है।
3. वैकल्पिक: **Owner Display Name** भरें।
4. **Year** चुनें।
5. **Month** चुनें।
6. **Target Amount** लिखें।
7. **Currency** जाँचें। यह डिफ़ॉल्ट रूप से **INR** होती है।
8. **Submit** पर क्लिक करें। **Quota created** संदेश दिखता है।

हर ओनर का हर महीने के लिए 1 कोटा हो सकता है।

### कोटा के मुकाबले प्रगति जाँचें { #check-progress-against-a-quota }

1. **Sales Quotas** सूची में वह पंक्ति खोजें।
2. **Achievement** कॉलम में **View** पर क्लिक करें।
3. उस महीने के लिए **Forecast vs Quota** विंडो खुलती है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **A quota for this owner and period already exists.** | उस ओनर का उस महीने का कोटा पहले से है। | इसके बजाय मौजूदा कोटा एडिट करें। |
| **Target amount must be positive.** | **Target Amount** 0 या उससे कम है। | 0 से ज़्यादा रकम लिखें। |
| **Month must be between 1 and 12.** | महीना सीमा से बाहर है। | 1 से 12 के बीच का महीना चुनें। |
| **Forecast vs Quota** में पूरी टीम के आँकड़े दिखते हैं | रिपोर्ट अभी ओनर के हिसाब से फ़िल्टर नहीं कर सकती। | ओनर के कोटा की तुलना **Dashboard** पर **Won by owner** से करें। |
