# अपना खुद का ईमेल प्रोवाइडर कनेक्ट करें { #connect-your-own-email-provider }

अपना SMTP रिले, SendGrid, Mailgun या Postmark अकाउंट कनेक्ट करें, ताकि आपके ईमेल उसी से जाएँ। आखिर में प्रोवाइडर के कार्ड पर **Active** दिखता है, और कैंपेन व ट्रांज़ैक्शनल ईमेल Ohanvi के साझा डिफ़ॉल्ट सेंडर की जगह उसी से भेजे जाते हैं।

## शुरू करने से पहले { #before-you-start }

- ईमेल भेजने के लिए आपको इस पेज की ज़रूरत नहीं है। कुछ भी कनेक्ट न हो, तो हर ईमेल Ohanvi के साझा डिफ़ॉल्ट सेंडर (Amazon SES) से जाता है।
- आपके पास अपने प्रोवाइडर की जानकारी हो: SMTP होस्ट, पोर्ट, यूज़रनेम और पासवर्ड, या API key। Mailgun के लिए आपको अपना सेंडिंग डोमेन भी चाहिए।
- आपको लेफ़्ट रेल में **Connect** दिखे और उसके पैनल में **Email Provider** हो, या **Email** पैनल में **Manage** → **Email Sending Server** दिखे। दोनों एक ही स्क्रीन खोलते हैं। अगर दोनों में से कुछ न दिखे, तो अपने एडमिन से एक्सेस माँगें।

## चरण { #steps }

### Email Provider स्क्रीन खोलें { #open-the-email-provider-screen }

1. लेफ़्ट रेल में **Connect** खोलें, फिर **Email Provider** चुनें। आप **Email** खोलकर **Manage** और फिर **Email Sending Server** भी चुन सकते हैं।
2. **Email Provider** स्क्रीन पर **SMTP**, **SendGrid**, **Mailgun** और **Postmark** के लिए एक-एक कार्ड दिखता है। जो कार्ड आपने सेट नहीं किया है उस पर **not connected** और **Set up** चिप लिखा होता है।

### SMTP सर्वर कनेक्ट करें { #connect-an-smtp-server }

1. **SMTP** कार्ड पर **Connect** पर क्लिक करें। **Connect SMTP** डायलॉग खुलता है।
2. वैकल्पिक: **Name (optional)** में कोई ऐसा नाम लिखें जिसे आप पहचान सकें।
3. **SMTP Host \*** में अपने सर्वर का होस्ट नेम लिखें।
4. **Port \*** में वह पोर्ट लिखें जो आपका प्रोवाइडर देता है।
5. **Username** और **Password** में अपना SMTP लॉगिन लिखें।
6. अपने प्रोवाइडर की सेटिंग्स के हिसाब से **Auth**, **STARTTLS** या **SSL** चालू या बंद करें।
7. **Test connection** पर क्लिक करें। **Connected successfully.** दिखने तक रुकें।
8. अगर अब से इसी प्रोवाइडर से ईमेल भेजने हैं, तो **Use for sending once saved** पर टिक लगा रहने दें।
9. **Connect** पर क्लिक करें। कार्ड पर **Connected** दिखता है, या सेंडर होने पर **Active**।

### SendGrid, Mailgun या Postmark कनेक्ट करें { #connect-sendgrid-mailgun-or-postmark }

1. प्रोवाइडर के कार्ड पर **Connect** पर क्लिक करें।
2. **API Key \*** में अपने प्रोवाइडर के डैशबोर्ड से API key पेस्ट करें।
3. सिर्फ़ Mailgun के लिए: **Sending Domain \*** में अपना Mailgun डोमेन लिखें, और **Region** में **US** या **EU** चुनें।
4. वैकल्पिक: **API Base URL Override (optional)** तभी भरें जब आपके प्रोवाइडर ने कोई दूसरा पता इस्तेमाल करने को कहा हो।
5. **Test connection** पर क्लिक करें, फिर **Connect** पर क्लिक करें।

### प्रोवाइडर बदलें, एडिट करें या हटाएँ { #switch-edit-or-remove-a-provider }

- किसी कनेक्टेड प्रोवाइडर को सेंडर बनाने के लिए उसके कार्ड पर **Set active** पर क्लिक करें। एक समय में सिर्फ़ 1 प्रोवाइडर एक्टिव रहता है। **… is now sending email.** मैसेज दिखता है।
- जानकारी बदलने के लिए **Configure** पर क्लिक करें। सेव किया हुआ सीक्रेट रखने के लिए **Password (leave blank to keep)** या **API Key (leave blank to keep)** खाली छोड़ें। **Save changes** पर क्लिक करें।
- प्रोवाइडर हटाने के लिए **Disconnect** पर क्लिक करें, फिर डायलॉग में दोबारा **Disconnect** पर क्लिक करें।

!!! note
    सेव किए हुए कनेक्शन का प्रोवाइडर टाइप बदला नहीं जा सकता। उसे डिस्कनेक्ट करें और उसकी जगह दूसरा प्रोवाइडर कनेक्ट करें।

### आपका प्रोवाइडर भेजे तो क्या बदलता है { #what-changes-when-your-own-provider-sends }

- आपका सेंडर एड्रेस अब भी **Sender Identities** से आता है। देखें [भेजने वाले का पता सेट करें और अपना डोमेन वेरिफ़ाई करें](set-up-sender-identity.md)।
- **Sender Identities** के DNS रिकॉर्ड Ohanvi के डिफ़ॉल्ट सेंडर के लिए आपके डोमेन को प्रमाणित करते हैं। जब आपका अपना प्रोवाइडर भेजे, तो उसके दिए SPF और DKIM रिकॉर्ड भी जोड़ें।
- ईमेल अब भी क्रेडिट इस्तेमाल करते हैं। अपने प्रोवाइडर के साथ हर ईमेल भेजते समय ही चार्ज होता है, क्योंकि आपका प्रोवाइडर डिलीवरी की जानकारी Ohanvi को वापस नहीं देता। देखें [क्रेडिट और बिलिंग](../credits-and-billing.md)।
- ओपन, क्लिक और अनसब्सक्राइब अब भी ट्रैक होते हैं। **Delivered**, बाउंस और शिकायत के आँकड़े सिर्फ़ Ohanvi के डिफ़ॉल्ट सेंडर से आते हैं [VERIFY: own-provider delivery tracking]।

| **SMTP username is required when auth is enabled.** | **Auth** चालू है लेकिन **Username** खाली है। | यूज़रनेम लिखें, या अगर आपके रिले को लॉगिन नहीं चाहिए तो **Auth** बंद करें। |
| **Mailgun sending domain is required.** | **Sending Domain \*** खाली है। | वह डोमेन लिखें जो आपने Mailgun में सेट किया है। |
