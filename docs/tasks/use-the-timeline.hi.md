# टाइमलाइन का इस्तेमाल करें { #use-the-timeline }

**Timeline** आपके टास्क को शुरू की तारीख से ड्यू तारीख तक कैलेंडर पर बार के रूप में दिखाती है। इससे देखें कि क्या ओवरलैप हो रहा है, क्या देर से चल रहा है, और पैरेंट टास्क व उनके चाइल्ड टास्क कैसे बैठते हैं। यहाँ आप सिर्फ़ पढ़ते हैं, टास्क एडिट कहीं और करते हैं।

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल सकते हैं। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- आपके टास्क में शुरू की तारीख या ड्यू तारीख है। जिस टास्क में दोनों नहीं हैं, वह नहीं दिखता। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

## चरण { #steps }

### Timeline खोलें { #open-the-timeline }

1. दाईं रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. ऊपर व्यू स्विचर में **Timeline** पर क्लिक करें।
3. अगर पेज पर **No work items yet. Create tickets (and set a start / due date)** लिखा है, तो पहले अपने टास्क में तारीखें जोड़ें।
4. अगर **No project selected** लिखा है, तो बोर्ड हेडर से कोई प्रोजेक्ट चुनें।

### समय का पैमाना बदलें { #change-the-time-scale }

1. Timeline के ऊपर दाईं ओर के बटन देखें।
2. **Weeks**, **Months** या **Quarters** पर क्लिक करें। हेडर और बार दोबारा बन जाते हैं।
3. आज की तारीख तक स्क्रॉल करने के लिए **Today** पर क्लिक करें। आज की तारीख तारीख वाले हेडर में चिह्नित होती है।

### पंक्ति पढ़ें { #read-a-row }

1. बाईं ओर का **Work** कॉलम पढ़ें। हर पंक्ति एक टास्क है।
2. दाईं ओर बार खोजें। यह टास्क की शुरू की तारीख से उसकी ड्यू तारीख तक चलता है।
3. बार का रंग देखें। यह टास्क के स्टेटस के साथ बदलता है।
4. बार की शुरू और खत्म की तारीख देखने के लिए उस पर माउस ले जाएँ।
5. पैरेंट पंक्ति पर गिनती पढ़ें, जैसे **Done: 2 of 5**। यह बताती है कि कितने चाइल्ड टास्क पूरे हो चुके हैं।

### पैरेंट टास्क खोलें और बंद करें { #expand-and-collapse-parent-tasks }

1. ऐसी पंक्ति खोजें जिसके चाइल्ड हैं। उस पर तीर होता है।
2. उसके नीचे चाइल्ड टास्क दिखाने के लिए तीर पर क्लिक करें। तीर पर टूलटिप **Expand** दिखता है।
3. उन्हें छिपाने के लिए तीर पर दोबारा क्लिक करें। टूलटिप **Collapse** लिखा होता है।

### पंक्तियाँ चुनें { #select-rows }

1. उस टास्क को चुनने के लिए पंक्ति की शुरुआत के बॉक्स पर टिक करें।
2. ध्यान दें कि उसके चाइल्ड पर भी टिक लग जाता है, और उनके बॉक्स लॉक हो जाते हैं।
3. पूरे समूह को साफ़ करने के लिए पैरेंट का टिक हटाएँ।

### Work कॉलम को चौड़ा करें { #widen-the-work-column }

1. **Work** कॉलम और कैलेंडर के बीच की रेखा पर पॉइंटर ले जाएँ।
2. जब पॉइंटर बाएँ-दाएँ तीर में बदल जाए, तो रेखा को खींचें।
3. कॉलम मनचाही चौड़ाई का हो जाए तो छोड़ दें। चौड़ाई 200 से 800 पिक्सल के बीच रहती है।

### पंक्ति से चाइल्ड टास्क शुरू करें { #start-a-child-task-from-a-row }

1. टॉप-लेवल टास्क की पंक्ति पर माउस ले जाएँ। उसके दाईं ओर दो छोटे बटन दिखते हैं।
2. **+** बटन पर क्लिक करें। उसका टूलटिप **Create child work item** है। टास्क के नीचे नई पंक्ति खुलती है।
3. टाइप चुनने के लिए टाइप बटन पर क्लिक करें, जिसका टूलटिप **Select issue type** है। डिफ़ॉल्ट स्टोरी होती है।
4. **What needs to be done?** में शीर्षक लिखें।
5. पंक्ति के आखिर में व्यक्ति वाले बटन से असाइन करने वाला चुनें।
6. पंक्ति में सेव बटन नहीं है, और **Enter** से टास्क नहीं बनता। अभी के लिए चाइल्ड टास्क बोर्ड से बनाएँ।

### More actions मेन्यू खोलें { #open-the-more-actions-menu }

1. पंक्ति पर माउस ले जाएँ और **...** बटन पर क्लिक करें। उसका टूलटिप **More actions** है।
2. मेन्यू पढ़ें: **Create work item**, **Move work item**, **Change work item color**, **Edit dates** और **Edit dependencies**।
3. किसी आइटम को चुनने से अभी कुछ नहीं होता। तारीखें और पैरेंट बदलने के लिए इसके बजाय टास्क का ब्योरा खोलें।

!!! note "Timeline सिर्फ़ पढ़ने के लिए है"
    तारीखें बदलने के लिए आप बार को खींच नहीं सकते। टास्क खोलें और वहाँ **Start date** और **Due date** बदलें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No work items yet. Create tickets (and set a start / due date)** | किसी भी टास्क में शुरू या ड्यू तारीख नहीं है। | कोई टास्क खोलें और उसकी तारीखें सेट करें। |
| **No project selected** | बोर्ड पर कोई प्रोजेक्ट खुला नहीं है। | बोर्ड हेडर में कोई प्रोजेक्ट चुनें। |
| **Failed to load timeline** | Timeline लोड नहीं हो सकी। | किसी दूसरे व्यू पर जाकर वापस आएँ, या पेज रीलोड करें। |
| Timeline में कोई टास्क नहीं दिख रहा। | उसमें न शुरू की तारीख है, न ड्यू तारीख। | टास्क में कोई तारीख जोड़ें। |
| **More actions** मेन्यू कुछ नहीं करता। | मेन्यू के आइटम अभी चालू नहीं हैं। | टास्क को उसकी डिटेल विंडो से एडिट करें। |
