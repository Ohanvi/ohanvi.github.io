# सोशल इनसाइट्स पढ़ें { #read-social-insights }

अपने पोस्ट का प्रदर्शन देखने के लिए **Insights** का इस्तेमाल करें। आप नेटवर्क की आपस में तुलना कर सकते हैं, अपने टॉप पोस्ट खोज सकते हैं, और आपके पब्लिश किए किसी भी एक पोस्ट के आँकड़े खोल सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखता हो, और उसके पैनल में **Home** और **Insights** हों। अगर नहीं दिखता, तो अपने एडमिन से कहें कि वह आपके रोल को Social एक्सेस दे। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।
- कम से कम एक नेटवर्क कनेक्ट हो, और आपने एक पोस्ट पब्लिश किया हो। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## चरण { #steps }

### Social Home देखें { #check-social-home }

Social Home का अपना अलग पेज है। देखें [Social Home का इस्तेमाल करें](use-social-home.md)।

### Insights पर प्रदर्शन की तुलना करें { #compare-performance-on-insights }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Insights** चुनें।
2. किसी एक नेटवर्क तक सीमित करने के लिए **All Channels** पर क्लिक करें और एक चैनल चुनें।
3. तारीखों की सीमा चुनें: **7 days**, **30 days** या **Month to date**। हर आँकड़े की तुलना पिछली अवधि से की जाती है।
4. **Summary** पढ़ें: **Posts**, **Reactions**, **Comments**, **Eng. Rate**, **Impressions** और **Shares**। किसी आँकड़े पर माउस ले जाकर देखें कि वह क्या गिनता है।
5. **Performance** के नीचे हर चैनल के **Posts**, **Reactions**, **Comments** और **Eng. Rate** की तुलना करें।
6. **Top 5 Posts** के नीचे, अपने सबसे अच्छे पोस्ट रैंक करने के लिए **Reactions** और **Comments** के बीच बदलें।
7. **Performance per Post** के नीचे, उस अवधि में पब्लिश हुए हर पोस्ट के आँकड़े देखें।

### किसी एक पोस्ट के आँकड़े देखें { #see-the-numbers-for-one-post }

1. **Social** → **Publish** खोलें, फिर **Sent** टैब पर क्लिक करें।
2. हर पोस्ट पर उसकी **Reach**, **Engagement**, **Likes** और **Comments** दिखती हैं।
3. पोस्ट पर **View Analytics** पर क्लिक करें। **Post Analytics** विंडो हर नेटवर्क के आँकड़ों के साथ खुलती है।
4. काम पूरा होने पर **Close** पर क्लिक करें।

!!! note "नेटवर्क क्या बताते हैं"
    हर नेटवर्क हर आँकड़ा नहीं देता। कनेक्ट किए गए नेटवर्क से फ़ॉलोअर की संख्या, इंप्रेशन और रीच अभी रिपोर्ट नहीं होते, इसलिए **Total Followers** और **Followers** चार्ट खाली रह सकते हैं। **Shares** सिर्फ़ Facebook से आते हैं। **Eng. Rate** के लिए इंप्रेशन चाहिए, इसलिए वह अक्सर खाली रहता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No published posts in this period.** | आपकी चुनी हुई तारीखों में कुछ पब्लिश नहीं हुआ। | लंबी अवधि चुनें, या कोई पोस्ट पब्लिश करें। |
| **No channels connected** | कोई नेटवर्क कनेक्ट नहीं है। | **Connect** → **Social Connections** में एक कनेक्ट करें। |
| **No published targets for this post yet.** | पोस्ट अभी तक किसी नेटवर्क पर नहीं गया है। | पोस्ट के **Published** होने तक इंतज़ार करें, फिर **View Analytics** दोबारा खोलें। |
| किसी नेटवर्क के लिए **Analytics not available** | वह नेटवर्क पोस्ट के आँकड़े Ohanvi के साथ साझा नहीं करता। | आँकड़े उसी नेटवर्क पर जाकर देखें। |
| आँकड़े पुराने लगते हैं | आँकड़े बैकग्राउंड में रीफ़्रेश होते हैं। | **Refresh** पर क्लिक करें। |
