# चुनें कि नोटिफ़िकेशन आप तक कैसे पहुँचें { #choose-how-notifications-reach-you }

मॉड्यूल-दर-मॉड्यूल चुनें कि Ohanvi आपको ऐप में बताए, पुश नोटिफ़िकेशन से बताए या ईमेल से। स्विच पलटते ही बदलाव सेव हो जाते हैं, इसलिए स्विच सही दिखने पर आपका काम पूरा है।

## शुरू करने से पहले { #before-you-start }

- आप Ohanvi में साइन इन हैं। देखें [Ohanvi में साइन इन करें](../sign-in.md)।
- आपके पास कम से कम 1 ऐसे मॉड्यूल का एक्सेस है जो नोटिफ़िकेशन भेजता है, जैसे **WhatsApp** या **CRM**।

## चरण { #steps }

### नोटिफ़िकेशन चालू या बंद करें { #turn-notifications-on-or-off }

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. Settings की सूची में सबसे ऊपर अपने नाम पर क्लिक करें।
3. **Preferences** के नीचे **Notifications** पर क्लिक करें। **Notifications** पेज खुलता है, जिसमें हर मॉड्यूल की 1 पंक्ति होती है।
4. किसी मॉड्यूल की पंक्ति में **In-app** या **Push** के नीचे का स्विच पलटें। ऊपर थोड़ी देर के लिए **Saving…** दिखता है।

सिर्फ़ वही मॉड्यूल सूची में दिखते हैं जिन्हें आप खोल सकते हैं। जब आपको नए मॉड्यूल का एक्सेस मिलता है, तो वे जुड़ जाते हैं।

### अलग-अलग इवेंट को बारीकी से सेट करें { #fine-tune-single-events }

1. किसी मॉड्यूल की पंक्ति में **Fine-tune per event** पर क्लिक करें। उस मॉड्यूल की अपनी नोटिफ़िकेशन सेटिंग्स खुलती हैं।
2. वहाँ अलग-अलग इवेंट चालू या बंद करें।

हर मॉड्यूल में यह लिंक नहीं होता।

### पूरे वर्कस्पेस के लिए ईमेल नोटिफ़िकेशन { #email-notifications-for-the-whole-workspace }

Super Admin को एक **Email** कॉलम भी दिखता है। यह उस मॉड्यूल के ईमेल अलर्ट पूरे वर्कस्पेस के लिए चालू या बंद करता है, सिर्फ़ आपके लिए नहीं। बाकी सब को सिर्फ़ **In-app** और **Push** दिखते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Couldn't save that change — please try again.** | बदलाव सर्वर तक नहीं पहुँचा। | अपना कनेक्शन जाँचें और स्विच फिर से पलटें। |
| **Couldn't save the email setting — please try again.** | ईमेल वाला स्विच सेव नहीं हुआ। | फिर से कोशिश करें। फिर भी न हो, तो सपोर्ट से संपर्क करें। |
| **No notification settings for your current access yet — they appear as you get access to modules that send notifications.** | आपके रोल में ऐसा कोई मॉड्यूल नहीं है जो नोटिफ़िकेशन भेजता हो। | अपने वर्कस्पेस के मालिक से मॉड्यूल का एक्सेस माँगें। |
| **Email** कॉलम नहीं दिख रहा | सिर्फ़ Super Admin ईमेल अलर्ट बदल सकते हैं। | अपने वर्कस्पेस के मालिक से कहें। |
| पुश नोटिफ़िकेशन नहीं आ रहे | आपका ब्राउज़र या फ़ोन Ohanvi के नोटिफ़िकेशन रोक रहा है। | अपने ब्राउज़र या फ़ोन की सेटिंग्स में app.ohanvi.com के लिए नोटिफ़िकेशन की अनुमति दें [VERIFY: push delivery requirements]। |
