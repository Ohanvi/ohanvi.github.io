# अपनी व्हाट्सऐप बिज़नेस प्रोफ़ाइल सेट करें { #set-up-your-whatsapp-business-profile }

वह प्रोफ़ाइल भरें जो ग्राहकों को व्हाट्सऐप के अंदर आपके बिज़नेस के नाम पर टैप करने पर दिखती है। आखिर में आपकी फ़ोटो, About पंक्ति, पता, ईमेल और वेबसाइट व्हाट्सऐप पर लाइव होती हैं, और आपको पता होता है कि बाकी हर व्हाट्सऐप सेटिंग कहाँ है।

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर कनेक्ट हो। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आपका रोल व्हाट्सऐप **Configuration** और **Business Profile** खोल सकता हो। ये एडमिन स्क्रीन हैं। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](../settings/roles-and-permissions.md)।
- आपका लोगो 5 MB या उससे छोटी वर्गाकार इमेज हो, जिसका बैकग्राउंड ठोस रंग का हो।

## चरण { #steps }

### बिज़नेस प्रोफ़ाइल खोलें { #open-the-business-profile }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **WhatsApp** चुनें, फिर **Business Profile**। **Business Profile** स्क्रीन खुलती है।

    ![Business Profile स्क्रीन, जिसमें Business Name, Verified badge, Profile Picture, About और Description दिख रहे हैं](../assets/screenshots/whatsapp-business-profile-1-screen.png)

जब आप पहले से किसी व्हाट्सऐप सेटिंग स्क्रीन पर हों, तो बाईं ओर की **Settings** सूची में से भी **Business Profile** चुन सकते हैं।

### प्रोफ़ाइल फ़ोटो बदलें { #change-the-profile-picture }

1. **Profile Picture** के नीचे **Change** पर क्लिक करें।
2. कोई इमेज चुनें। 640×640 की वर्गाकार इमेज सबसे अच्छी रहती हैं।
3. अगर **This image has a transparent background** दिखे, तो **Pick another** पर क्लिक करें और ठोस बैकग्राउंड वाली इमेज चुनें। व्हाट्सऐप पारदर्शी हिस्सों को काले रंग से भर देता है।
4. संदेश **Profile picture updated.** दिखता है।

### प्रोफ़ाइल का ब्योरा एडिट करें { #edit-the-profile-details }

1. जो फ़ील्ड चाहिए उन्हें भरें:

    | फ़ील्ड | क्या लिखें | सीमा |
    | --- | --- | --- |
    | **About** | एक छोटी एक-पंक्ति का स्टेटस, जैसे **Available 9am–6pm**। | 139 अक्षर |
    | **Description** | आपका बिज़नेस क्या करता है। | 512 अक्षर |
    | **Address** | आपके बिज़नेस का पता। | 256 अक्षर |
    | **Email** | वह ईमेल जिस पर ग्राहक संपर्क कर सकें। | 128 अक्षर |
    | **Business Category** | वह श्रेणी जो आपके बिज़नेस पर सबसे ठीक बैठती है। | — |
    | **Websites** | हर लिंक के लिए **Add website** पर क्लिक करें। | ज़्यादा से ज़्यादा 2 URL |

    ![Business Profile पर भरे हुए Address, Email, Business Category और Websites](../assets/screenshots/whatsapp-business-profile-2-details.png)

2. ऊपर दाईं ओर **Save Changes** पर क्लिक करें। संदेश **Business profile saved.** दिखता है।

**Business Name** पर **Verified by Meta** दिखता है और इसे यहाँ एडिट नहीं किया जा सकता। इसे बदलने के लिए Meta की समीक्षा हेतु WhatsApp Manager में डिस्प्ले नेम बदलने का अनुरोध भेजें।

### ब्लू टिक के लिए आवेदन करें { #apply-for-the-blue-tick }

1. **Verified badge** के नीचे **Official Business Account (blue tick)** नोट पढ़ें।

    ![Verified badge कार्ड, जिसमें Official Business Account (blue tick) नोट और Apply for Blue Tick बटन है](../assets/screenshots/whatsapp-business-profile-3-verified-badge.png)

2. **Apply for Blue Tick** पर क्लिक करें। Meta का WhatsApp Manager नए टैब में खुलता है।
3. अनुरोध वहीं पूरा करें। बैज मुफ़्त है। Meta इसे इस आधार पर मंज़ूर करता है कि आपका ब्रांड कितना जाना-माना है।

### बाकी व्हाट्सऐप सेटिंग्स ढूँढें { #find-other-whatsapp-settings }

व्हाट्सऐप सेटिंग्स **Settings** और **Manage** स्क्रीन के बीच बँटी हैं।

**Settings** → **WhatsApp** में **Setup** के नीचे:

| पंक्ति | इसमें क्या है |
| --- | --- |
| **Business Profile** | यही पेज। |
| **Configuration** | आपके कनेक्ट किए नंबर। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)। |
| **Webhooks** | Meta के लिए Webhook URL और Verify Token, और आने वाली घटनाएँ। देखें [वेबहुक और इंटीग्रेशन](whatsapp-webhooks-and-integrations.md)। |
| **Website Button** | आपकी वेबसाइट के लिए व्हाट्सऐप चैट बटन। |
| **Developer API** | अपने सॉफ़्टवेयर से व्हाट्सऐप संदेश भेजने की कुंजियाँ। देखें [वेबहुक और इंटीग्रेशन](whatsapp-webhooks-and-integrations.md)। |
| **BUSY** | BUSY अकाउंटिंग सॉफ़्टवेयर से इनवॉइस व्हाट्सऐप पर भेजता है। देखें [वेबहुक और इंटीग्रेशन](whatsapp-webhooks-and-integrations.md)। |
| **Migrate to Ohanvi** | किसी दूसरे व्हाट्सऐप प्रोवाइडर से आने के चरण। देखें [अपना नंबर Ohanvi पर लाएँ](migrate-to-ohanvi.md)। |

![Settings, WhatsApp सूची, जिसमें Setup और Chat & engagement पंक्तियाँ हैं](../assets/screenshots/whatsapp-business-profile-5-settings-list.png)

लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें। बाईं ओर की इसकी सूची में ये हैं:

| आइटम | इसमें क्या है |
| --- | --- |
| **Opt-in Management** | अतिरिक्त ऑप्ट-आउट और ऑप्ट-इन शब्द, और पुष्टि के जवाब। देखें [व्हाट्सऐप संपर्क प्रबंधित करें](manage-whatsapp-contacts.md)। |
| **Live Chat Settings** | ऑटो-रिज़ॉल्व, वेलकम, ऑफ़-आवर्स और हैंडऑफ़ संदेश, और काम के घंटे। देखें [व्हाट्सऐप इनबॉक्स का इस्तेमाल करें](use-whatsapp-inbox.md)। |
| **Canned Messages** | सेव किए हुए जवाब, जिन्हें आपकी टीम इनबॉक्स में **/** से डालती है। |
| **Agents** | आपकी व्हाट्सऐप टीम। देखें [व्हाट्सऐप एजेंट जोड़ें](add-whatsapp-agents.md)। |
| **Tags** | संपर्कों के टैग की सूची। **Create** पर क्लिक करें और **Tag Name** लिखें। |
| **User Attributes** | हर संपर्क पर सेव होने वाली कस्टम फ़ील्ड, जैसे **Text**, **Number**, **Date** या **Yes / No**। |
| **Custom Events** | वे घटनाएँ जो आपके अपने सिस्टम API के ज़रिए फ़्लो शुरू करने के लिए भेजते हैं। |
| **Scheduler** | बाद में भेजने के लिए शेड्यूल किए संदेश और जॉब। |
| **Delivery Logs** | भेजे गए हर संदेश का डिलीवरी स्टेटस। |
| **Connection Health** | आपके नंबर का कनेक्शन काम कर रहा है या नहीं। |
| **Integrations** | वे सेवाएँ जिनसे आपके ऑटोमेशन पढ़ते और जिनमें लिखते हैं। |
| **Notification Preferences** | व्हाट्सऐप की कौन-सी घटनाएँ आपको नोटिफ़िकेशन देती हैं। |
| **API Key** | **Cloud API Access** खोलता है: Ohanvi का असिस्टेड सेटअप लें, या अपना नंबर खुद Meta Cloud API से कनेक्ट करें। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)। |
| **Billing & Usage** | Meta के कन्वर्सेशन शुल्क। |
| **Recycle Bin** | आपके डिलीट किए आइटम। उन्हें चुनें और **Restore selected** पर क्लिक करें। |

![Manage स्क्रीन, जिसमें बाईं ओर इसकी सूची और दाईं ओर Tags खुला है](../assets/screenshots/whatsapp-business-profile-4-manage.png)

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **That image is …MB. WhatsApp allows up to 5MB — please pick a smaller one.** | तस्वीर 5 MB से बड़ी है। | इमेज का साइज़ घटाएँ या उसे कंप्रेस करें, फिर **Change** पर दोबारा क्लिक करें। |
| व्हाट्सऐप में लोगो काले बैकग्राउंड पर दिखता है | इमेज का बैकग्राउंड पारदर्शी था। | ठोस बैकग्राउंड वाला वर्शन अपलोड करें। |
| **Could not load business profile** | Ohanvi व्हाट्सऐप से प्रोफ़ाइल नहीं पढ़ पाया, अक्सर इसलिए कि कोई नंबर कनेक्ट नहीं है या टोकन की अवधि खत्म हो गई। | **Retry** पर क्लिक करें। फिर भी असफल हो, तो **Configuration** में नंबर जाँचें। |
| आप **Business Name** एडिट नहीं कर सकते | डिस्प्ले नेम को Meta वेरिफ़ाई करता है। | WhatsApp Manager में डिस्प्ले नेम बदलने का अनुरोध भेजें। |
| **Could not save the business profile.** | व्हाट्सऐप ने बदलाव को नामंज़ूर कर दिया। | ऊपर दी गई फ़ील्ड की सीमाएँ जाँचें और फिर कोशिश करें। |
