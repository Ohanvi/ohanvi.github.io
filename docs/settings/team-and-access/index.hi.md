# टीम और एक्सेस { #team-and-access }

टीम और एक्सेस में आपकी अपनी प्रोफ़ाइल, आपके वर्कस्पेस के लोग और हर किसी के रोल की सारी सेटिंग्स मिलती हैं। यहाँ से आप टीम के मेंबर जोड़ या हटा सकते हैं और उनके रोल तय कर सकते हैं।

## यह कहाँ मिलेगा { #where-to-find-it }

नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें। अपने नाम के नीचे **Team & access** खोलें।

## गाइड { #guides }

| गाइड | कब काम आएगी |
| --- | --- |
| [अपनी प्रोफ़ाइल और पासवर्ड अपडेट करें](../update-your-profile.md) | आपको अपना नाम, ईमेल, फ़ोन या पासवर्ड बदलना है। |
| [टीम के मेंबर, रोल और अनुमतियाँ मैनेज करें](../roles-and-permissions.md) | आपको टीम के मेंबर जोड़ने, एडिट करने या हटाने हैं, या उनका रोल चुनना है। |
| [लिंक भेजकर टीम के मेंबर को जोड़ें](../invite-teammates.md) | आप चाहते हैं कि साथी खुद साइन अप करें। |
| [अपना अकाउंट बंद करें](../deactivate-your-account.md) | आप मालिक हैं और पूरा अकाउंट रोकना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आप साइन इन हों। देखें [Ohanvi में साइन इन करें](../../sign-in.md)।
- टीम और इनवाइट की सेटिंग्स सिर्फ़ **Super Admin** के लिए हैं।
