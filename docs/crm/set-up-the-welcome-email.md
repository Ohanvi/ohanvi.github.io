# Set up the welcome email and your brochures

Set the default welcome message once, and keep your brochures in one library that the whole team can attach. At the end, **Send Welcome Email** starts with your own words and your files are ready to attach. Setup takes about 5 minutes.

## Before you start

- You can see **Contacts** in the left rail with **All contacts** in its panel.
- You have the files ready: for example a booklet or a price list.
- Anyone on your team can use the brochures you upload. Do not upload private files.

## Steps

### Open the setup window

1. Open **Contacts** in the left rail, then select **All contacts**.
2. Click the **Welcome Email Setup (message + brochures)** icon in the top bar. The **Welcome Email Setup** window opens.

### Save the default message

1. Under **Message**, read the note. It says this is the default subject and body used when you click **Send Welcome Email**. You can still edit it for each send.
2. Type the **Subject**.
3. Type the **Body**. The box is tall, so you can write several lines.
4. Click **Save**. The message **Welcome message saved** appears.

If both boxes are empty, the window says **Add a subject or message before saving**. If the save fails, it says **Could not save. Please retry.**

### Upload a brochure

1. Under **Brochures**, read the note: upload the booklet or price list once and attach it any time. It is shared across your team.
2. Click **Upload brochure**.
3. Pick a file on your computer. The button reads **Uploading…** until it finishes.
4. Wait for the message **Brochure uploaded**. The file shows in the list with its size.

Brochure rules:

- Files up to 25 MB. A bigger file gives **File exceeds the 25 MB limit**.
- Use PDF, PNG, JPG, DOC, DOCX, PPT or PPTX files so they open in the contact's mail app.

If you have none yet, the list says **No brochures yet. Upload a booklet or price list to attach it to emails.**

### Delete a brochure

1. Find the file in the list.
2. Click the **Delete** icon next to it. The window **Delete brochure?** asks **Remove "name" from the library?**
3. Click **Delete**. The message **Brochure deleted** appears.

The file is gone for everyone. Emails already sent keep their copy.

### Manage brochures on their own

1. In the **Send Welcome Email** window, click **Manage** next to **Attach brochures**.
2. The **Manage Brochures** window shows the same library, with **Upload brochure** and **Delete** on each row.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **Could not read the selected file** | The file could not be opened. | Save it again from its program and re-upload. |
| **Upload failed. Please retry.** | The upload did not finish. | Click **Upload brochure** again. |
| **Could not delete the brochure** | The delete did not reach the server. | Try again in a moment. |
| New default message is not used | The window was closed without saving. | Reopen **Welcome Email Setup** and click **Save**. |
