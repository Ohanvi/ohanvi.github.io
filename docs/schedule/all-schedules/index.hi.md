# सभी शेड्यूल { #all-schedules }

सभी शेड्यूल मुख्य Schedule स्क्रीन है। यह हर मॉड्यूल के शेड्यूल किए गए सभी आइटम एक कैलेंडर या सूची में दिखाती है, ताकि आप पूरी योजना एक साथ देख सकें और यहीं से किसी भी आइटम को बदल सकें।

**यह कहाँ मिलेगा:** बाएँ रेल में **Schedule** खोलें, फिर **All schedules** चुनें।


## गाइड { #guides }

| गाइड | इसका इस्तेमाल कब करें |
| --- | --- |
| [जो कुछ भी शेड्यूल है, सब देखें](../view-schedule.md) | आप कैलेंडर या सूची देखना, उसे फ़िल्टर करना और स्टेटस पढ़ना चाहते हैं। |
| [शेड्यूल किए गए आइटम को रीशेड्यूल, रद्द या डिलीट करें](../reschedule-cancel-delete.md) | योजना बदल गई है और किसी आइटम को आगे ले जाना या रोकना है। |

## शुरू करने से पहले { #before-you-start }

- आपको बाएँ रेल में **Schedule** दिखता हो। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल के पास होता है।
- कम से कम एक मॉड्यूल में कुछ शेड्यूल किया गया हो।
