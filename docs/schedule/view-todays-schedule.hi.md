# देखें कि आज क्या शेड्यूल है { #see-what-is-scheduled-for-today }

**Today** व्यू में आपको WhatsApp, CRM, ईमेल, सोशल और अपॉइंटमेंट, सबका आज का शेड्यूल एक जगह मिलता है। इसे पढ़कर आप जान लेंगे कि आज क्या जाने वाला है, वह किसका है, और किसमें बदलाव करना है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। न दिखे तो अपने एडमिन से कहें।
- किसी एक मॉड्यूल में भी आज के लिए कुछ शेड्यूल होना चाहिए। आइटम आप उसी के अपने मॉड्यूल में बनाते हैं।

## स्टेप { #steps }

### Today खोलें { #open-today }

1. लेफ़्ट रेल में **Schedule** खोलें और **Today** चुनें। पेज का टाइटल **Today** होता है और पेज **List** व्यू में खुलता है।
2. लिस्ट पढ़ें। सारी लाइनें **Today** नाम के एक दिन के नीचे, समय के हिसाब से लगी होती हैं।
3. हर लाइन में समय, टाइटल, चैनल, टाइप और स्टेटस पिल दिखता है। जैसे **WhatsApp · Broadcast** और **Scheduled**।
4. किसी लाइन पर क्लिक करें। दाईं ओर उसकी जानकारी खुल जाती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

!!! note "ध्यान दें"
    **Today** में आज के हर स्टेटस के आइटम दिखते हैं, **Sent** और **Cancelled** वाले भी। शाम तक लिस्ट में वे आइटम भी दिखने लगते हैं जो जा चुके हैं।

### लिस्ट को छोटा करें { #narrow-the-list }

1. किसी चैनल चिप पर क्लिक करें: **WhatsApp**, **CRM**, **Email**, **Social** या **Appointments**। पहले क्लिक पर सिर्फ़ वही चैनल दिखता है। दूसरे चैनल वापस जोड़ने के लिए और चिप पर क्लिक करें।
2. सिर्फ़ अपने आइटम देखने हैं तो **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
3. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### आज जाने वाला आइटम बदलें { #change-an-item-that-is-due-today }

1. आइटम पर क्लिक करें। दाईं ओर उसकी जानकारी खुल जाती है।
2. समय बदलने के लिए **Reschedule** पर क्लिक करें। उसी के अपने मॉड्यूल में खोलने के लिए **Edit**, रोकने के लिए **Cancel** और हटाने के लिए **Delete** पर क्लिक करें। इसके बारे में पढ़ें: [शेड्यूल किया हुआ आइटम रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।

### आज को कैलेंडर पर देखें { #look-at-today-on-the-calendar }

1. पेज के ऊपर **Calendar** पर क्लिक करें। महीने का व्यू खुल जाता है।
2. आज की तारीख ढूँढें। यहाँ सिर्फ़ आज के आइटम दिखते हैं, क्योंकि फ़िल्टर अभी भी **Today** है।
3. वापस जाने के लिए **List** पर क्लिक करें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें। **New schedule — pick a channel** शीट खुलती है।
2. **New in WhatsApp**, **New in CRM**, **New in Email**, **New in Social** या **New in Appointments** चुनें। Ohanvi उस मॉड्यूल की अपनी स्क्रीन खोल देता है। आइटम आप वहीं बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** और मैसेज **No schedules match these filters. Try another channel or clear the status filter.** | आज कुछ तय नहीं है, या कोई चैनल, ओनर या स्टेटस फ़िल्टर उसे छिपा रहा है। | दूसरे चैनल चिप पर क्लिक करें, **Everyone's schedule** चुनें, या स्टेटस **Any status** कर दें। |
| आज जाने वाला कोई आइटम नहीं दिख रहा | उसमें तारीख और समय नहीं डाला गया, या आपने उसका चैनल बंद कर रखा है। | उस आइटम के अपने मॉड्यूल में उसे शेड्यूल का समय दें। चैनल चिप फिर से चालू करें। |
| **Could not load your schedule.** | पेज सर्वर से कनेक्ट नहीं हो पाया। | मैसेज में दिए रीट्राई बटन पर क्लिक करें। फिर भी न चले तो साइन आउट करें और दोबारा साइन इन करें। |
| **Reschedule**, **Edit**, **Cancel** और **Delete** नहीं दिख रहे | छोटी विंडो में जानकारी वाला पैनल छिप जाता है। | ब्राउज़र विंडो को चौड़ा करें। |
