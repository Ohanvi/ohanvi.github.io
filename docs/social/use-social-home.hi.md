# सोशल होम का इस्तेमाल करें { #use-social-home }

सोशल होम **Social** की पहली स्क्रीन है। यह दिखाता है कि आज किस पर कार्रवाई करनी है, कौन से पोस्ट जाने वाले हैं, आपके नतीजे क्या हैं और हाल के पोस्ट कौन से हैं। यहीं से आप पोस्ट शुरू कर सकते हैं और कमेंट का जवाब दे सकते हैं। इसे सीखने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखे और उसके पैनल में **Home** हो। न दिखे, तो अपने एडमिन से अपने रोल को Social का एक्सेस देने को कहें। देखें [सेटिंग्स का परिचय](../settings/index.md)।
- कम से कम एक नेटवर्क कनेक्ट हो। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।

## चरण { #steps }

### सोशल होम खोलें { #open-social-home }

1. लेफ़्ट रेल में **Social** खोलें।
2. **Home** चुनें।

अगर कोई नेटवर्क कनेक्ट नहीं है, तो होम पर **Connect your first social account** दिखता है। शुरू करने के लिए **Connect Platforms** पर क्लिक करें। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।

### सिर्फ़ एक नेटवर्क दिखाएँ { #show-one-network-only }

1. ऊपर के प्लेटफ़ॉर्म बटन पर क्लिक करें। जब तक आप कोई चुन नहीं लेते, उस पर **All platforms** लिखा रहता है।
2. टिक वाले किसी नेटवर्क पर क्लिक करें, ताकि होम सिर्फ़ उसे दिखाए।
3. सब कुछ फिर से देखने के लिए **All platforms** पर क्लिक करें।
4. जो नेटवर्क कनेक्ट नहीं है, उस पर **… — connect** लिखा होता है। कनेक्ट स्क्रीन खोलने के लिए उस पर क्लिक करें।
5. **Connect** → **Social Connections** खोलने के लिए **Manage connections** पर क्लिक करें।
6. ताज़ा आँकड़े लाने के लिए **Refresh** पर क्लिक करें।

### होम से पोस्ट शुरू करें { #start-a-post-from-home }

1. **What's on your mind?** लिखे बॉक्स पर क्लिक करें। **Create Post** विंडो खुलती है।
2. या बॉक्स के नीचे के छोटे आइकन में से किसी पर क्लिक करें। ये फ़ोटो, वीडियो, इमोजी, टैग, जगह और नोट के लिए हैं। हर एक वही **Create Post** विंडो खोलता है।
3. पोस्ट पूरा करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

### जिस पर ध्यान चाहिए, उस पर कार्रवाई करें { #act-on-what-needs-attention }

1. **NEEDS ATTENTION** पढ़ें। हर पंक्ति में एक गिनती, एक लेबल और एक एक्शन दिखता है। बाईं ओर की रंगीन पट्टी बताती है कि मामला कितना ज़रूरी है।
2. कार्रवाई करने के लिए किसी पंक्ति पर क्लिक करें:
    - **Comments · need replies**: **Reply →** पर क्लिक करें। **Comments** विंडो खुलती है।
    - **Google reviews · needs response**: **Reply →** पर क्लिक करें। रिव्यू पेज खुलता है। देखें [Google रिव्यू का जवाब दें](reply-to-google-reviews.md)।
    - **Failed posts · needs retry**: **Retry →** पर क्लिक करें। **Publish** खुलता है। देखें [पोस्ट शेड्यूल और प्रबंधित करें](schedule-social-posts.md)।
    - **Platform connections · needs attention**: **Fix →** पर क्लिक करें। **Connect** → **Social Connections** खुलता है।
3. पंक्ति तभी दिखती है जब कुछ करने को हो।

### किसी कमेंट का जवाब दें { #reply-to-a-comment }

1. **Comments** विंडो में कमेंट खोजें।
2. उसके बगल में **Reply** पर क्लिक करें। **Write a reply…** लिखा एक बॉक्स खुलता है।
3. अपना जवाब लिखें।
4. सेंड आइकन पर क्लिक करें। भेजते समय स्पिनर दिखता है।
5. बिना भेजे बॉक्स बंद करने के लिए **Cancel** पर क्लिक करें।
6. काम पूरा होने पर **Close** पर क्लिक करें।

अगर जवाब देने को कुछ नहीं है, तो विंडो में **No comments waiting on a reply.** लिखा आता है।

### आज के पोस्ट देखें { #check-todays-posts }

1. **TODAY** पढ़ें। इसमें आज जाने वाले पोस्ट की सूची होती है।
2. अगर कुछ तय नहीं है, तो **Nothing scheduled** लिखा होता है।
3. **Publish** में पूरा कैलेंडर खोलने के लिए **Calendar** पर क्लिक करें।

### अपने नतीजे पढ़ें { #read-your-results }

1. **Performance** के नीचे **This Week**, **Last 30 Days** या **Last 90 Days** चुनें।
2. **Reach**, **Engagement**, **Followers** और **Posts** पढ़ें।
3. चार्ट और पोस्ट-दर-पोस्ट टेबल के लिए **Insights** खोलें। देखें [सोशल इनसाइट्स पढ़ें](view-social-insights.md)।

### हाल की गतिविधि और पोस्ट देखें { #review-recent-activity-and-posts }

1. **RECENT ACTIVITY** तक स्क्रॉल करें। ज़्यादा पंक्तियाँ देखने के लिए **View more** पर क्लिक करें, या उन्हें समेटने के लिए **View less** पर।
2. अगर अभी कुछ नहीं है, तो **No activity yet** लिखा होता है।
3. **RECENT POSTS** में **Publish** खोलने के लिए **View all** पर क्लिक करें।
4. किसी पोस्ट को देखने के लिए उस पर क्लिक करें। उसे प्रबंधित करने के लिए **Open in Publish** पर क्लिक करें, या वापस जाने के लिए **Close** पर।
5. अगर आपका कोई पोस्ट नहीं है, तो **No posts yet** लिखा होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| होम पर **Connect your first social account** दिखता है | कोई नेटवर्क कनेक्ट नहीं है। | **Connect Platforms** पर क्लिक करें और एक कनेक्ट करें। |
| **NEEDS ATTENTION** खाली है | किसी पर कार्रवाई की ज़रूरत नहीं है। | कुछ करने की ज़रूरत नहीं। |
| आँकड़े पुराने लगते हैं | पेज रीफ़्रेश नहीं हुआ था। | **Refresh** पर क्लिक करें। |
| प्लेटफ़ॉर्म सूची में कोई नेटवर्क **— connect** दिखाता है | वह नेटवर्क कनेक्ट नहीं है। | उस पर क्लिक करें, फिर कनेक्ट करना पूरा करें। |
