# नाम, फ़ोन, ईमेल और पता पूछें, फिर इंतज़ार करें या ब्रांच करें { #ask-for-name-phone-email-and-address-then-wait-or-branch }

चार ब्लॉक तैयार सवाल हैं: **Ask name**, **Ask phone**, **Ask email** और **Ask address**। हर एक सवाल पूछता है, जवाब जाँचता है और उसे संपर्क पर सेव कर देता है। दो और ब्लॉक चैट को चलाते हैं: **Delay** बॉट को रोकता है, और **Condition** चैट को एक या दूसरी तरफ़ भेजता है। यह पेज बताता है कि हर एक को कैसे भरें।

## शुरू करने से पहले { #before-you-start }

- आपने बिल्डर में कोई फ़्लो खोला हो। देखें [फ़्लो बिल्डर को समझें](understand-the-flow-builder.md)।
- खुले टेक्स्ट वाले सवाल के लिए **Ask Question** इस्तेमाल करें। देखें [Ask और wait ब्लॉक](chatbot-ask-and-wait-blocks.md)।

## हर ब्लॉक क्या करता है { #what-each-block-does }

| ब्लॉक | ग्रुप | यह क्या करता है |
| --- | --- | --- |
| **Ask name** | **Ask the customer** | ग्राहक का नाम पूछता है। उसे `name` के रूप में सेव करता है। |
| **Ask phone** | **Ask the customer** | फ़ोन नंबर पूछता है। उसे `contact_number` के रूप में सेव करता है। |
| **Ask email** | **Ask the customer** | ईमेल पता पूछता है। उसे `email` के रूप में सेव करता है। |
| **Ask address** | **Ask the customer** | डिलीवरी का पता पूछता है। उसे `address` के रूप में सेव करता है। |
| **Delay** | **Ask the customer** | अगले मैसेज से पहले फ़्लो को रोकता है। |
| **Condition** | **Actions** | चैट को **True** निकास या **False** निकास पर भेजता है। |

## चरण { #steps }

### तैयार सवाल जोड़ें { #add-a-ready-made-question }

1. जिस चरण के बाद सवाल आना है, उसके बाद **+** पर क्लिक करें।
2. **All steps** पर क्लिक करें।
3. **Ask the customer** में **Ask name**, **Ask phone**, **Ask email** या **Ask address** पर क्लिक करें।
4. नए ब्लॉक पर क्लिक करें। उसकी सेटिंग्स **Step** पैनल में खुलती हैं।

ब्लॉक भरा हुआ आता है। आप उसका कोई भी हिस्सा बदल सकते हैं।

### नाम पूछें { #ask-for-the-name }

1. **Ask name** ब्लॉक जोड़ें।
2. **Question** देखें। उसमें `Hi! What's your name?` लिखा होता है। चाहें तो बदल दें, जैसे `Hello! May I know your name?`
3. **Save the answer as** देखें। उसमें **Name** लिखा होता है। जवाब `name` वेरिएबल के रूप में सेव होता है।
4. **The answer should be** देखें। उसमें **Short text** लिखा होता है।
5. बाद के किसी मैसेज में जवाब इस्तेमाल करने के लिए `{{name}}` लिखें, जैसे `Thanks {{name}}!`

### फ़ोन नंबर पूछें { #ask-for-the-phone-number }

1. **Ask phone** ब्लॉक जोड़ें।
2. **Question** देखें। उसमें `What is your phone number?` लिखा होता है।
3. **Save the answer as** देखें। उसमें **Phone** लिखा होता है। जवाब `contact_number` के रूप में सेव होता है।
4. **The answer should be** देखें। उसमें **Phone number** लिखा होता है। अगर ग्राहक फ़ोन नंबर के अलावा कुछ और भेजता है, तो बॉट सवाल दोबारा पूछता है। दोबारा कोशिश की सीमा के बाद वह फ़्लो के फ़ॉलबैक एक्शन पर चला जाता है।

### ईमेल पता पूछें { #ask-for-the-email-address }

1. **Ask email** ब्लॉक जोड़ें।
2. **Question** देखें। उसमें `What is your email address?` लिखा होता है।
3. **Save the answer as** देखें। उसमें **Email** लिखा होता है। जवाब `email` के रूप में सेव होता है।
4. **The answer should be** देखें। उसमें **Email** लिखा होता है। अगर ग्राहक ईमेल के अलावा कुछ और भेजता है, तो बॉट सवाल दोबारा पूछता है। दोबारा कोशिश की सीमा के बाद वह फ़्लो के फ़ॉलबैक एक्शन पर चला जाता है।

### पता पूछें { #ask-for-the-address }

1. **Ask address** ब्लॉक जोड़ें।
2. **Question** देखें। उसमें `Please share your address.` लिखा होता है।
3. **Save the answer as** देखें। उसमें **Address** लिखा होता है। जवाब `address` के रूप में सेव होता है।
4. **The answer should be** देखें। उसमें **Long text** लिखा होता है, ताकि ग्राहक कई पंक्तियाँ लिख सके।

### जवाब को अपने नाम से सेव करें { #save-an-answer-under-your-own-name }

1. कोई भी ask ब्लॉक खोलें।
2. **Save the answer as** पर क्लिक करें। एक सूची खुलती है जिसमें **Name**, **Phone**, **Email**, **Address**, **City**, `interests` और `goal` होते हैं, साथ में वे नाम भी जो आपका फ़्लो पहले से इस्तेमाल करता है।
3. नया नाम इस्तेमाल करने के लिए **Custom…** चुनें। उसमें **Your own name, e.g. company_name** लिखा होता है।
4. बॉक्स में कोई नाम लिखें, जैसे `company name`। सहायक टेक्स्ट में **Use it in a message as {{company_name}}** लिखा होता है।
5. **Use** पर क्लिक करें। नाम छोटे अक्षरों में और अंडरस्कोर के साथ सेव होता है।

जब आप **Name**, **Phone**, **Email**, **Address** या **City** चुनते हैं, तो बिल्डर जवाब को मेल खाते CRM फ़ील्ड से भी जोड़ देता है। बाद का **CRM** चरण उसे सही जगह रख देता है।

### कुछ समय के लिए रुकें { #wait-for-a-time }

**Delay** अगले मैसेज से पहले फ़्लो को रोकता है।

1. चरण के बाद **+** पर क्लिक करें, फिर **All steps** पर क्लिक करें।
2. **Ask the customer** में **Delay** पर क्लिक करें।
3. **Wait for · wait_minutes** में मिनट लिखें, जैसे `60`।
4. बॉक्स के नीचे की लाइन पढ़ें। वह समय को घंटों या दिनों में दिखाती है, जैसे `1 hours`। उसमें लिखा होता है कि संपर्क कतार से निकल जाता है और समय आने पर लौट आता है।
5. ब्लॉक के अंत में **+** पर क्लिक करें और इंतज़ार के बाद चलने वाला चरण जोड़ें।

!!! note "छोटे विराम के लिए Set Delay इस्तेमाल करें"
    किसी एक मैसेज से पहले कुछ सेकंड रुकने के लिए **Text** ब्लॉक पर **Set Delay** इस्तेमाल करें। देखें [टेक्स्ट और लिस्ट ब्लॉक](chatbot-text-and-list-blocks.md)। [VERIFY: how the Delay block behaves in a live chat flow]

### कंडीशन से चैट को बाँटें { #split-the-chat-with-a-condition }

**Condition** एक सेव किया हुआ जवाब पढ़कर एक निकास चुनता है।

1. चरण के बाद **+** पर क्लिक करें, फिर **All steps** पर क्लिक करें।
2. **Actions** में **Condition** पर क्लिक करें।
3. **If the answer saved as** के नीचे **Choose…** पर क्लिक करें और जाँचने वाला जवाब चुनें, जैसे **Email**।
4. तुलना पर क्लिक करें, जिस पर शुरू में **is** लिखा होता है। **How to compare** नाम की सूची खुलती है। इनमें से एक चुनें:
    - **is**
    - **is not**
    - **contains**
    - **does not contain**
    - **is more than**
    - **is less than**
    - **is set**
    - **is empty**
5. **is set** और **is empty** को छोड़कर हर विकल्प के लिए **Value** लिखें, जैसे `Delhi`।
6. नोट **Yes and No are the ports on the right.** पढ़ें। कार्ड पर निकासों के लेबल **True** और **False** हैं।
7. **True** पर **+** पर क्लिक करें और मेल खाने वाले मामले का चरण जोड़ें, जैसे दिल्ली स्टोर के पते वाला मैसेज।
8. **False** पर **+** पर क्लिक करें और मेल न खाने वाले मामले का चरण जोड़ें।

उदाहरण: **If the answer saved as** को **City** पर सेट करें, **is** चुनें, और **Value** में **Delhi** लिखें। दिल्ली के ग्राहक **True** पर जाते हैं। बाकी सब **False** पर जाते हैं।

!!! tip "दोनों निकास टेस्ट करें"
    **Test** दो बार चलाएँ, एक बार मेल खाते जवाब के साथ और एक बार बिना मेल वाले जवाब के साथ। देखें [चैट सिम्युलेटर से चैटबॉट फ़्लो टेस्ट करें](test-a-flow-with-the-chat-simulator.md)।

### जवाब न मिलने को संभालें { #handle-no-reply }

1. कोई ask ब्लॉक खोलें।
2. **Set Timeout** चालू करें।
3. **Timeout after (minutes)** लिखें।
4. **Timed out** निकास को किसी रिमाइंडर से जोड़ें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| बॉट दोबारा पूछता है | जवाब **The answer should be** से मेल नहीं खाया, जैसे फ़ोन वाले सवाल में टेक्स्ट। | **The answer should be** में टाइप जाँचें, या **Short text** चुनें। |
| `{{name}}` सादे टेक्स्ट की तरह दिखता है | वेरिएबल में कैपिटल अक्षर है, या सेव किया हुआ नाम अलग है। | `{{name}}` छोटे अक्षरों में लिखें, या मैसेज बॉक्स के नीचे के चिप का इस्तेमाल करें। |
| **Condition** हमेशा **False** पर जाता है | सेव किया हुआ जवाब खाली है, या **Value** की स्पेलिंग अलग है। | **If the answer saved as** में नाम जाँचें और स्पेलिंग मिलाएँ। |
| **Condition** में **Value** बॉक्स नहीं है | **is set** और **is empty** जवाब को ही जाँचते हैं। | अगर आप किसी वैल्यू से तुलना करना चाहते हैं, तो कोई दूसरी तुलना चुनें। |
