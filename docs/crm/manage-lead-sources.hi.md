# लीड के स्रोत मैनेज करें और देखें कि कौन-से स्रोत कन्वर्ट होते हैं { #manage-lead-sources-and-see-which-ones-convert }

लीड सोर्स वह चैनल है जिससे कोई लीड आपके पास आई, जैसे आपकी वेबसाइट, कोई रेफ़रल या Instagram। इस गाइड के बाद हर लीड का एक स्रोत होगा, और आप देख पाएँगे कि किन स्रोतों से आने वाले लोग क्वालिफ़ाई होते हैं। स्रोत जोड़ने में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आप एडमिन हों, क्योंकि CRM सेटिंग्स सिर्फ़ एडमिन के लिए हैं।
- आपको पता हो कि आपके पास पूछताछ किन चैनलों से आती है।

## स्टेप { #steps }

### Lead Sources खोलें { #open-lead-sources }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **CRM** चुनें, फिर **Lead Sources** पर क्लिक करें।

आप **Ctrl K** (Mac पर **⌘K**) दबाकर **Lead Sources** टाइप करें और उसे चुन लें। यह भी चलेगा।

### परफ़ॉर्मेंस व्यू पढ़ें { #read-the-performance-view }

1. **Lead Sources** हेडिंग देखें। उसके नीचे की लाइन में **Where your N leads come from — and which convert best** लिखा होता है।
2. **Performance by source** देखें। **Last 30 days** चिप समय बताता है। सिर्फ़ पिछले 30 दिनों में बनी लीड्स गिनी जाती हैं।
3. हर लाइन देखें। उसमें स्रोत का नाम, कुल लीड्स में उसके हिस्से की एक पट्टी और गिनती दिखती है, जैसे **48 leads**।
4. हर लाइन के नीचे **N qualified · N% conv** देखें। जिस लीड का स्टेटस **QUALIFIED** या **CONVERTED** हो, वह क्वालिफ़ाइड गिनी जाती है।
5. ऐसे स्रोत ढूँढें जिनकी लीड्स ज़्यादा हैं पर कन्वर्ज़न दर कम है। ये आपकी लिस्ट तो भरते हैं, पर शायद ही कभी क्वालिफ़ाई होते हैं।

जिस स्रोत से सबसे ज़्यादा लीड्स आती हैं, वह सबसे ऊपर रहता है।

### स्रोत जोड़ें { #add-a-source }

1. **Add source** पर क्लिक करें। **Add Lead Source** फ़ॉर्म खुलता है।
2. **Name** में स्रोत लिखें, जैसे `Instagram`।
3. वैकल्पिक: **Description** लिखें।
4. वैकल्पिक: **Default Source** पर टिक करें। तब नई लीड्स पर यह स्रोत पहले से चुना हुआ दिखेगा।
5. **Submit** पर क्लिक करें। **Lead source created** मैसेज आता है।

शुरुआत में Ohanvi आपको ये स्रोत देता है: **Website**, **Referral**, **Cold Call**, **Trade Show**, **Social Media**, **Email Campaign**, **Partner** और **Other**।

### लीड पर स्रोत लगाएँ { #use-a-source-on-a-lead }

1. कोई लीड खोलें, या **Add lead** पर क्लिक करें। देखें [लीड्स के साथ काम करें](leads.md)।
2. **Lead Source** चुनें।
3. लीड सेव करें। अब वह उस स्रोत की लाइन में गिनी जाएगी।

अभी कोई स्रोत न हो, तो स्क्रीन पर **No lead sources yet** दिखता है। **Add source** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No lead sources yet** | कोई स्रोत नहीं है। | **Add source** पर क्लिक करें। |
| किसी स्रोत में 0 लीड्स दिखती हैं | पिछले 30 दिनों में उस स्रोत वाली कोई लीड नहीं बनी। | जाँचें कि लीड्स पर स्रोत चुना गया है। |
| CRM सेटिंग्स में **Lead Sources** नहीं दिखता | आपका रोल एडमिन का नहीं है। | अपने एडमिन से कहें। |
