# CRM { #crm }

**CRM** आपके संपर्कों पर बनी कंपनियों, डील्स और सेल्स के काम को ट्रैक करता है। यह दिखाता है कि आज क्या करना है और महीना कैसा चल रहा है। अपनी पाइपलाइन सेट करने, डील्स पर काम करने और अपने आँकड़े पढ़ने के लिए इन गाइड का इस्तेमाल करें।

**इसे कहाँ खोलें:** लेफ़्ट रेल में **CRM** खोलें।

## गाइड { #guides }

| टैब | गाइड | कब इस्तेमाल करें |
| --- | --- | --- |
| **Dashboard** | [CRM डैशबोर्ड पढ़ें](../track-sales-performance.md) | आप अपनी खुली पाइपलाइन, जीती हुई डील्स और ठंडी पड़ती डील्स देखना चाहते हैं। |
| **Deals** | [डील्स बनाएँ और प्रबंधित करें](../manage-deals.md) | आप डील जोड़ते हैं, उसे चरणों में आगे बढ़ाते हैं और बंद करते हैं। |
| **Accounts** | [अकाउंट्स जोड़ें और प्रबंधित करें](../manage-accounts.md) | आप उन कंपनियों को ट्रैक करते हैं जिन्हें आप बेचते हैं। |
| Activities, Calendar, Notes | [गतिविधियाँ और नोट्स दर्ज करें](../log-activities-and-notes.md) | आप कॉल और मीटिंग की योजना बनाते हैं या नोट्स लिखते हैं। |
| **Campaigns** | [कैंपेन और कैंपेन टेम्प्लेट ट्रैक करें](../track-campaigns.md) | आप कोई कैंपेन और उसके नतीजे दर्ज करते हैं। |
| **Automations** | [CRM ऑटोमेशन प्रबंधित करें](../manage-automations.md) | आप नियमों को रोकते, फिर चालू करते या नए बनाते हैं। |
| **Funnel** | [फ़नल पढ़ें और बोर्ड पर लीड्स को आगे बढ़ाएँ](../read-the-funnel.md) | आप देखना चाहते हैं कि लीड्स कहाँ छूट रही हैं। |
| **Forecast** | [सेल्स फ़ोरकास्ट पढ़ें](../read-the-forecast.md) | आप पाइपलाइन की तुलना अपने टार्गेट से करते हैं। |
| Sales reports | [सेल्स रिपोर्ट चलाएँ](../run-sales-reports.md) | आपको Excel या PDF फ़ाइल के रूप में रिपोर्ट चाहिए। |
| Pipelines, Products, Lead Sources, Sales Quotas | [CRM कॉन्फ़िगर करें](../configure/index.md) | आप वे हिस्से सेट करते हैं जिनमें आपका CRM नापा जाता है। |

कुछ स्क्रीन पैनल में नहीं हैं: **Deal Board**, **Campaign Templates**, **Activities**, **Activity Calendar**, **Notes**, **Sales reports**, **Pipelines**, **Products**, **Sales Quotas** और **Lead Sources**। हर गाइड बताती है कि उन्हें कैसे खोलें।

## कॉन्फ़िगर करें { #configure }

सेटअप स्क्रीन **Settings** → **CRM** में हैं। ये एडमिन के लिए हैं। देखें [CRM कॉन्फ़िगर करें](../configure/index.md)।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में CRM मॉड्यूल है, और आपके रोल को CRM का एक्सेस है। नहीं तो **CRM** आइकन नहीं दिखता। अपने एडमिन से पूछें।
- **Dashboard**, **Funnel**, **Forecast** और **Sales reports** के लिए CRM रिपोर्ट का एक्सेस चाहिए। **Automations** के लिए ऑटोमेशन का एक्सेस चाहिए।
