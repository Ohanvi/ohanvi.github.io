# फ़्लो में ऐप का स्टेप जोड़ें { #add-an-app-step-to-a-flow }

ऐसा स्टेप जोड़ें जो आपके अपने अकाउंट से किसी बाहरी ऐप में कोई काम करे।

## शुरू करने से पहले { #before-you-start }

- फ़्लो एक ऑटोमेशन या स्टोर जर्नी हो। WhatsApp चैटबॉट में ऐप के स्टेप नहीं मिलते।
- आपके रोल के पास फ़्लो बनाने और बदलने का एक्सेस हो। देखें [फ़्लो और फ़्लो की लिस्ट को समझें](flows-overview-and-list.md)।
- आप ऐप में साइन इन कर सकते हों, या आपके पास उसकी API key हो। ऐप को स्टेप से ही कनेक्ट किया जा सकता है।

## ऐप का स्टेप कैसा दिखता है { #how-an-app-step-is-laid-out }

**Step** पैनल में ऐप का स्टेप ऊपर से नीचे, नंबर वाले हिस्सों में दिखता है:

- **ऐप का हेडर:** ऐप का लोगो और नाम, एक्शन, और **Change**।
- **1 · Account:** वह अकाउंट जिससे स्टेप साइन इन करता है।
- **2 · What to send:** वे वैल्यू जो स्टेप ऐप को भेजता है।
- **3 · Test:** स्टेप को एक बार चलाता है। देखें [स्टेप टेस्ट करें और सैंपल डेटा पिन करें](test-a-step-and-pin-sample-data.md)।
- **If this step fails:** देखें [तय करें कि स्टेप फ़ेल होने पर क्या हो](choose-what-happens-when-a-step-fails.md)।

अकाउंट सबसे पहले आता है, क्योंकि कुछ फ़ील्ड के विकल्प उसी अकाउंट से लोड होते हैं।

कुछ ऐप को अकाउंट की ज़रूरत नहीं होती, जैसे पहले से बना **Formatter**। उनमें हिस्सों के नाम बिना नंबर के **What to send** और **Test** होते हैं।

## स्टेप { #steps }

### ऐप और एक्शन चुनें { #pick-the-app-and-the-action }

1. फ़्लो को बिल्डर में खोलें। देखें [ऑटोमेशन फ़्लो बनाएँ](build-automation-flow.md)।
2. ट्रिगर के बाद या किसी स्टेप के बाद **+** पर क्लिक करें। **Add a step after** पैनल खुलता है।
3. **Apps** तक स्क्रॉल करें। हर ऐप के साथ लिखा होता है कि उसमें क्या है, जैसे **4 actions · 2 searches**। साथ में **Connected** या **Connect** भी दिखता है।
4. ऐप पर क्लिक करें। उसके एक्शन हेडिंग के नीचे खुलते हैं।
    - बड़े ऐप उन्हें विषय के हिसाब से बाँटते हैं, जैसे **Orders**, **Shipments** या **Tracking**।
    - बाकी ऐप पहले **Actions**, फिर **Searches** दिखाते हैं।
    - **Advanced** हमेशा सबसे आख़िर में होता है।

    [SCREENSHOT: Add a step after पैनल, जिसमें Shiprocket खुला हो और Orders, Shipments और Tracking हेडिंग दिख रही हों]

5. एक्शन ढूँढने के लिए **Search** और ऐप के नाम वाले बॉक्स में टाइप करें। सबसे ऊपर वाला नतीजा जोड़ने के लिए **Enter** दबाएँ।
6. एक्शन पर क्लिक करें। स्टेप कैनवस पर आ जाता है और उसका **Step** पैनल खुलता है।

आप ऐप या एक्शन का नाम सीधे **Search steps** में भी टाइप कर सकते हैं। तब नतीजों में हर ऐप के एक्शन दिखते हैं।

### अकाउंट चुनें { #choose-the-account }

1. **1 · Account** के नीचे **Account** खोलें और अकाउंट चुनें। सिर्फ़ एक अकाउंट हो, तो वह पहले से चुना होता है।
2. दूसरा अकाउंट जोड़ना हो, तो लिस्ट के नीचे **Connect** और ऐप के नाम वाले बटन पर क्लिक करें।
3. अभी कोई अकाउंट न हो, तो पैनल में **No … account connected yet. Connect one to let this step sign in.** लिखा आता है। **Connect** और ऐप के नाम वाले बटन पर क्लिक करें।

    [SCREENSHOT: 1 · Account, जिसमें अभी कोई अकाउंट न हो और Connect Shiprocket बटन दिख रहा हो]

ऐप किस तरह कनेक्ट होगा, यह ऐप पर निर्भर करता है। चारों तरीके नीचे दिए गए हैं।

#### डिलीवरी पार्टनर (Shiprocket) कनेक्ट करें { #connect-a-delivery-partner-shiprocket }

1. **Connect Shiprocket** विंडो खुलती है। उसमें तीन छोटे निर्देश होते हैं।
2. **Open Shiprocket** पर क्लिक करें। Shiprocket में **Settings → API → Configure** खोलें और एक API यूज़र बनाएँ।
3. Ohanvi पर वापस आकर **API user email** और **API user password** लिखें।
4. **Connect** पर क्लिक करें। स्टेप नया अकाउंट अपने आप ले लेता है।

कोई पिकअप लोकेशन सेट न हो, तो मैसेज में उसे **Integrations → Delivery partners** में जोड़ने को कहा जाता है।

#### साइन-इन वाला ऐप (OAuth) कनेक्ट करें { #connect-a-sign-in-app-oauth }

1. ऐप की साइन-इन विंडो खुलती है। Ohanvi में **Approve in the other window** मैसेज दिखता है।
2. ऐप में साइन इन करें और एक्सेस की मंज़ूरी दें। विंडो अपने आप बंद हो जाती है।
3. **… connected.** मैसेज आता है और स्टेप अकाउंट ले लेता है।

पॉप-अप ब्लॉक हों, तो ऐप नई टैब में खुलता है। वहाँ मंज़ूरी दें, वापस आएँ और **Done** पर क्लिक करें।

#### API key वाला ऐप कनेक्ट करें { #connect-an-api-key-app }

1. ऐप के नाम के साथ **Connect** विंडो खुलती है।
2. **Label** वैसा ही रहने दें या बदलें। एक ऐप के लिए हर लेबल अलग होना चाहिए।
3. ऐप जो फ़ील्ड माँगे, उन्हें भरें, जैसे API key।
4. **Who can build on this** को **Everyone in this organisation** पर ही रहने दें। तब दूसरों के एडिट करने पर भी फ़्लो चलता रहता है।
5. **Connect** पर क्लिक करें।

#### अपनी स्क्रीन वाला ऐप कनेक्ट करें { #connect-an-app-that-has-its-own-screen }

सोशल अकाउंट और Shopify जैसे स्टोर Ohanvi के अपने पेज पर कनेक्ट होते हैं।

1. ऐप का कनेक्ट पेज नई टैब में खुलता है।
2. वहीं कनेक्ट करना पूरा करें।
3. फ़्लो पर वापस आएँ। **Finished connecting …?** में **I've connected it** पर क्लिक करें। स्टेप अकाउंट ले लेता है।

स्टोर के लिए देखें [अपना ऑनलाइन स्टोर कनेक्ट करें](../settings/connect-your-store.md)।

### भेजी जाने वाली वैल्यू भरें { #fill-in-what-to-send }

1. **2 · What to send** के नीचे वे सारी फ़ील्ड भरें जिनके नाम के आख़िर में `*` है। ये ज़रूरी हैं।
2. किसी फ़ील्ड में ट्रिगर या पिछले स्टेप का डेटा भरना हो, तो उसके बगल का ब्रेसिज़ आइकन दबाएँ। उसका टूलटिप **Use a field from the trigger or an earlier step** है। देखें [स्टेप टेस्ट करें और सैंपल डेटा पिन करें](test-a-step-and-pin-sample-data.md#pick-a-value-from-earlier-data)।
3. वैकल्पिक फ़ील्ड देखने के लिए **+N more fields** पर क्लिक करें, जैसे **+18 more fields**। उन्हें फिर से छिपाने के लिए **Hide optional fields** पर क्लिक करें।
4. जो ड्रॉप-डाउन अकाउंट का अपना डेटा दिखाता है, जैसे पिकअप लोकेशन, उसके लिए पहले अकाउंट चुनें। तब तक उसमें **Choose an account to load options** लिखा रहता है।
5. वैकल्पिक: वैल्यू को JSON में देखने और बदलने के लिए **JSON** पर क्लिक करें। वापस जाने के लिए **Form** पर क्लिक करें।

    [SCREENSHOT: 2 · What to send, जिसमें ज़रूरी फ़ील्ड, ब्रेसिज़ आइकन और +N more fields लिंक दिख रहा हो]

खाली छोड़ी गई वैकल्पिक फ़ील्ड में उसकी डिफ़ॉल्ट वैल्यू हल्के रंग में दिखती है, जैसे **Default: India**। पिछले डेटा से आई वैल्यू ड्रॉप-डाउन के नीचे **Currently:** के बाद दिखती है।

### एक्शन बदलें { #change-the-action }

1. ऐप के हेडर में **Change** पर क्लिक करें। उसका टूलटिप **Change what this step does** है।
2. उसी ऐप का कोई दूसरा एक्शन चुनें। सारे एक्शन देखने के लिए **Something else…** पर क्लिक करें।

नया एक्शन अपनी डिफ़ॉल्ट वैल्यू से शुरू होता है। पुराने एक्शन के लिए भरी गई वैल्यू हट जाती हैं।

### सेव और पब्लिश करें { #save-and-publish }

1. **Save** पर क्लिक करें।
2. **Publish** पर क्लिक करें। देखें [ऑटोमेशन फ़्लो बनाएँ](build-automation-flow.md#save-and-publish)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No … account connected yet. Connect it under Integrations → Connectors before this step can sign in.** | स्टेप ख़ुद ऐप कनेक्ट नहीं कर सकता, जैसे पब्लिश किए हुए वर्शन पर। | **Connect** → **Connectors** में अकाउंट जोड़ें। देखें [कोई ऐप कनेक्ट करें और उसे फ़्लो में इस्तेमाल करें](connect-apps-for-flows.md)। |
| **Couldn't open …'s sign-in page. Check that pop-ups are allowed, then try again.** | ब्राउज़र ने साइन-इन विंडो रोक दी। | app.ohanvi.com के लिए पॉप-अप की अनुमति दें, फिर **Connect** पर दोबारा क्लिक करें। |
| **Ask a manager to connect Shiprocket — your role cannot.** | आपका रोल डिलीवरी पार्टनर नहीं बदल सकता। | किसी मैनेजर से Shiprocket कनेक्ट करवाएँ। फिर स्टेप में अकाउंट चुनें। |
| ड्रॉप-डाउन में **Choose an account to load options** लिखा है | अभी कोई अकाउंट नहीं चुना गया। | **1 · Account** के नीचे अकाउंट चुनें। |
| ड्रॉप-डाउन में **Nothing to choose from** लिखा है | अकाउंट में अभी ऐसा कोई रिकॉर्ड नहीं है, जैसे कोई पिकअप लोकेशन नहीं। | ऐप में एक जोड़ें, फिर अकाउंट दोबारा चुनें। |
| हेडर में **This operation is no longer in the catalog** लिखा है | ऐप से यह एक्शन हटा दिया गया। | **Change** पर क्लिक करें और कोई दूसरा एक्शन चुनें। |
