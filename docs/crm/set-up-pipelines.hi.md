# पाइपलाइन सेट करें { #set-up-pipelines }

अपनी पाइपलाइन बनाएँ, जिसमें आपकी डील्स आगे बढ़ती हैं। उसके स्टेज रखें और हर स्टेज पर जीतने की संभावना तय करें। पाइपलाइन बनते ही हर डील, बोर्ड, फ़नल और फ़ोरकास्ट उसी का इस्तेमाल करता है। लीड के स्रोत और प्रोडक्ट्स के लिए अलग पेज हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **CRM** दिखना चाहिए। न दिखे, तो अपने एडमिन से कहें कि वे आपके रोल को CRM का एक्सेस दें। आपके वर्कस्पेस में CRM चालू भी होना चाहिए।
- आप एडमिन हों। CRM सेटिंग्स पेज पर लिखा होता है **Configure how your CRM works — admin only**।

## स्टेप { #steps }

### CRM सेटिंग्स खोलें { #open-the-crm-settings }

1. नीचे-बाएँ कोने में अपने इनिशियल पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **CRM** चुनें। यहाँ **Pipelines**, **Lead Sources**, **Products** और **Funnel Stages** दिखते हैं।
3. जिसे सेट करना है, उस लाइन पर क्लिक करें। उसकी स्क्रीन खुल जाती है।

आप **Ctrl K** (Mac पर **⌘K**) दबाकर भी स्क्रीन खोल सकते हैं। **Pipelines**, **Lead Sources** या **Products** टाइप करें और स्क्रीन चुनें।

### डिफ़ॉल्ट स्टेज से शुरू करें { #start-with-the-default-stages }

अभी कोई पाइपलाइन न हो, तो **Pipelines** टैब में **No pipelines yet** दिखता है।

1. **Use the default 10 stages** पर क्लिक करें।
2. Ohanvi **Sales Pipeline** नाम की पाइपलाइन बना देता है और **Default funnel stages created.** दिखाता है।

डिफ़ॉल्ट स्टेज और उन पर जीतने की संभावना ये हैं:

| स्टेज | प्रॉबेबिलिटी | कैटेगरी |
| --- | --- | --- |
| New Lead | 5% | Open |
| Contacted | 10% | Open |
| Qualified | 25% | Open |
| Meeting Scheduled | 40% | Open |
| Needs Analysis | 50% | Open |
| Proposal Sent | 65% | Open |
| Negotiation | 80% | Open |
| Nurture | 15% | Open |
| Lost | 0% | Lost |
| Won | 100% | Won |

!!! note "ध्यान दें"
    पाइपलाइन सेट करने से पहले अगर आप डील बना लें, तो Ohanvi खुद यह डिफ़ॉल्ट पाइपलाइन बना देता है। डील उसके पहले स्टेज में चली जाती है।

### पाइपलाइन बनाएँ { #create-a-pipeline }

1. **Pipelines** में **New pipeline** पर क्लिक करें। **Add Pipeline** फ़ॉर्म खुलता है।
2. **Pipeline Name** में कोई नाम लिखें, जैसे `Enterprise Sales`।
3. चाहें तो **Description** जोड़ें।
4. नई डील्स इसी पाइपलाइन में शुरू करनी हों, तो **Default Pipeline** पर टिक करें।
5. **Stages (top to bottom = board order)** में हर लाइन भरें:
    - **Stage Name** — स्टेज का नाम।
    - **Prob %** — इस स्टेज की डील के जीतने की संभावना, 0 से 100 के बीच।
    - **Category** — चालू स्टेज के लिए **OPEN**, जीत वाले स्टेज के लिए **WON**, हार वाले स्टेज के लिए **LOST**।
6. और लाइनें चाहिए तो **Add Stage** पर क्लिक करें। कोई लाइन हटानी हो, तो हटाने वाले आइकन (**Remove stage**) पर क्लिक करें।
7. **Submit** पर क्लिक करें। **Pipeline created** मैसेज आता है और पाइपलाइन कार्ड के रूप में दिखने लगती है।

हर पाइपलाइन में ठीक 1 **WON** स्टेज और 1 **LOST** स्टेज रखें। डील पर **Mark Won** और **Mark Lost** इन्हीं दोनों को ढूँढते हैं।

### मौजूदा पाइपलाइन में स्टेज जोड़ें { #add-a-stage-to-an-existing-pipeline }

1. पाइपलाइन के कार्ड पर **+ Stage** पर क्लिक करें। **Add stage** विंडो खुलती है।
2. **Stage name** में नाम लिखें, जैसे `Proposal sent`।
3. **Add stage** पर क्लिक करें। **Stage added.** मैसेज आता है।

इस तरह जोड़ा स्टेज पाइपलाइन के आख़िर में लगता है। उसकी संभावना 0% और कैटेगरी **OPEN** होती है।

पाइपलाइन की डील्स खोलने के लिए उसके कार्ड पर **Open board →** पर क्लिक करें।

### फ़नल के स्टेज बदलें { #change-funnel-stages }

**Funnel Stages** टैब सिर्फ़ देखने के लिए है। उस पर **Sysadmin only** लिखा है। स्टेज का नाम बदलना, क्रम बदलना या उन्हें छिपाना सिर्फ़ प्लेटफ़ॉर्म sysadmin कर सकता है। इसके लिए **Funnel** → **Edit stages** पर जाना होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Pipeline 'Sales' already exists.** | किसी दूसरी पाइपलाइन का यही नाम पहले से है। | कोई दूसरा **Pipeline Name** रखें। |
| **Stage probability must be between 0 and 100.** | कोई **Prob %** 0 से कम या 100 से ज़्यादा है। | 0 से 100 के बीच की संख्या डालें। |
| **Pipeline has active deals in stage '…'. Move or delete them first.** | आपने ऐसी पाइपलाइन डिलीट करनी चाही जिसमें अभी डील्स हैं। | उन डील्स को किसी दूसरी पाइपलाइन के स्टेज में ले जाएँ, या डिलीट कर दें। फिर दोबारा कोशिश करें। |
| डील को Won मार्क करते समय **No WON stage configured for this deal's pipeline** आता है | पाइपलाइन में **WON** कैटेगरी वाला कोई स्टेज नहीं है (हार के लिए **LOST** स्टेज भी नहीं है)। | पाइपलाइन एडिट करें। एक स्टेज की **Category** **WON** करें (और एक की **LOST**)। |
| पाइपलाइन कार्ड से किसी मौजूदा स्टेज की संभावना या क्रम नहीं बदल पा रहे | चौड़े कार्ड व्यू में स्टेज सिर्फ़ आख़िर में जोड़ा जा सकता है। | **Pipelines** को छोटी विंडो में खोलें। वहाँ हर पाइपलाइन की लाइन में **Edit** का विकल्प मिलता है, जिसमें पूरा स्टेज एडिटर है [VERIFY: edit path on desktop]। |
