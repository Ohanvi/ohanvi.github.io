# देखें आगे क्या आने वाला है { #see-what-is-coming-up }

आगे की योजना बनाने के लिए **Upcoming** व्यू इस्तेमाल करें। इसमें आज से आगे के वे आइटम दिन के हिसाब से समूहों में दिखते हैं जो अभी इंतज़ार में हैं या चल रहे हैं। अंत में आपको पता होगा कि अगले दिनों में क्या भेजा जाएगा, और आप कोई भी आइटम आगे-पीछे कर सकेंगे या रोक सकेंगे।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Schedule** दिखता है। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। न दिखे तो अपने एडमिन से पूछें।
- कम से कम एक मॉड्यूल में आज या आगे के किसी दिन के लिए कुछ शेड्यूल है।

## चरण { #steps }

### Upcoming खोलें { #open-upcoming }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Upcoming** चुनें। पेज का शीर्षक **Upcoming** दिखता है और पेज **List** व्यू में खुलता है।
2. दिन के शीर्षक पढ़ें। वे **Today**, **Tomorrow** और उसके बाद **Fri, 3 Oct** जैसी तारीख़ के रूप में दिखते हैं।
3. किसी पंक्ति पर क्लिक करें, उसका ब्योरा दाईं ओर खुल जाता है।

### जानें कि Upcoming में क्या-क्या आता है { #know-what-upcoming-includes }

Upcoming में कोई आइटम तभी दिखता है जब ये दोनों बातें सही हों:

- उसकी तारीख़ आज या उसके बाद की हो।
- उसका स्टेटस **Scheduled** या **Live** हो।

!!! note
    जिन आइटम का स्टेटस **Draft**, **Sent**, **Paused**, **Cancelled** या **Failed** है, वे **Upcoming** में नहीं आते। **Paused** आइटम स्टेटस **Scheduled** चुनने पर **All schedules** में फिर भी दिखता है।

### सूची को छोटा करें { #narrow-the-list }

1. किसी एक चैनल को दिखाने के लिए चैनल चिप पर क्लिक करें। और चैनल वापस जोड़ने के लिए और चिप पर क्लिक करें।
2. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
3. और छोटा करने के लिए **Any status** पर क्लिक करें। आपका चुना हुआ स्टेटस **Upcoming** के नियम के साथ मिलकर काम करता है।

### किसी आने वाले आइटम को आगे-पीछे करें या रोकें { #move-or-stop-an-upcoming-item }

1. आइटम पर क्लिक करें।
2. नई तारीख़ और समय चुनने के लिए **Reschedule** पर क्लिक करें, या उसे रद्द करने के लिए **Cancel** पर क्लिक करें। देखें [शेड्यूल किए गए आइटम को रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।

### ज़्यादा लंबी अवधि देखें { #see-a-longer-range }

1. उसी फ़िल्टर के साथ महीना देखने के लिए **Calendar** पर क्लिक करें।
2. अगले महीने पर जाने के लिए महीने के नाम के बगल के तीरों का इस्तेमाल करें। वापस आने के लिए **Today** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | आज से आगे कुछ इंतज़ार में नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | दूसरे चैनल की चिप पर क्लिक करें, **Everyone's schedule** चुनें, या स्टेटस **Any status** करें। |
| रोका हुआ ब्रॉडकास्ट नहीं दिख रहा | **Upcoming** सिर्फ़ **Scheduled** और **Live** आइटम दिखाता है। | **All schedules** खोलें और स्टेटस **Scheduled** करें। |
| ड्राफ़्ट नहीं दिख रहा | ड्राफ़्ट का अपना अलग व्यू है। | **Drafts** खोलें। देखें [ड्राफ़्ट खोजें और पूरे करें](find-and-finish-drafts.md)। |
| आज पहले जा चुकी कोई चीज़ नहीं दिख रही | अब वह **Sent** है। | उसे देखने के लिए **Today** खोलें। |
