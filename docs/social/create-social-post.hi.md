# सोशल पोस्ट बनाएँ और पब्लिश करें { #create-and-publish-a-social-post }

कंपोज़र में पोस्ट एक बार लिखें और अपने चुने हुए हर कनेक्टेड नेटवर्क पर भेज दें। फ़ोटो या वीडियो जोड़ सकते हैं, AI Assistant से मदद ले सकते हैं और हर चैनल का प्रीव्यू देख सकते हैं। फिर पोस्ट तुरंत पब्लिश करें या ड्राफ़्ट में सेव कर लें। बाद में पब्लिश करनी हो, तो [पोस्ट शेड्यूल करें और क्यू मैनेज करें](schedule-social-posts.md) देखें।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखता हो, और उसके पैनल में **Publish** हो। न दिखे, तो अपने एडमिन से कहें कि वे आपके रोल को Social का एक्सेस दें। [सेटिंग्स का ओवरव्यू](../settings/index.md) देखें।
- कम से कम एक नेटवर्क कनेक्ट हो। [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md) देखें।

## स्टेप { #steps }

### कंपोज़र खोलें { #open-the-composer }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. **New Post** पर क्लिक करें। **Create Post** विंडो खुलेगी।

**Social** पैनल में सबसे ऊपर **New** पर क्लिक करके, फिर **Post** पर क्लिक करके भी कंपोज़र खोल सकते हैं।

पिछली बार कंपोज़र बिना सेव किए बंद किया था, तो Ohanvi पूछता है **Resume Unfinished Post?**। पुरानी पोस्ट जारी रखने के लिए **Resume Post** पर क्लिक करें। नई पोस्ट शुरू करनी हो, तो **Discard** पर क्लिक करें।

### नेटवर्क चुनें { #pick-the-networks }

1. चैनल स्ट्रिप में हर उस नेटवर्क पर क्लिक करें जिस पर पोस्ट करनी है। एक पोस्ट एक साथ कई नेटवर्क पर जा सकती है।
2. किसी ग्रे चिप पर माउस ले जाएँ। पता चलेगा कि वह बंद क्यों है। **… — connect it in Integrations → Social Connections** का मतलब है कि वह नेटवर्क अभी कनेक्ट नहीं है।

लिखते समय जो अक्षर सीमा दिखती है, वह आपके चुने हुए नेटवर्क में सबसे कम वाली सीमा होती है:

| नेटवर्क | अक्षर सीमा |
| --- | --- |
| **X** | 280 |
| **Threads** | 500 |
| **Google Business** | 1,500 |
| **Instagram** | 2,200 |
| **LinkedIn** | 3,000 |
| **Facebook** | 63,206 |

### पोस्ट लिखें { #write-the-post }

1. जिस बॉक्स में **Start writing or get inspired with Templates** लिखा है, उसमें अपना टेक्स्ट लिखें।
2. **Emoji** या **Hashtag** जोड़ने के लिए टूलबार इस्तेमाल करें। चुने हुए टेक्स्ट को **Bold**, **Italic** या **Underline** करने के लिए भी यही टूलबार है।
3. सेव किए हुए टेक्स्ट से शुरू करना हो, तो कंपोज़र में सबसे ऊपर **Templates** पर क्लिक करें। फिर **Start from a template** में कोई Template चुनें। हर `[bracketed]` खाली जगह में अपने शब्द लिखें।
4. AI से टेक्स्ट लिखवाना हो, तो **AI Assistant** पर क्लिक करें। **What should this post be about?** के नीचे बताएँ कि पोस्ट किस बारे में है। फिर **Generate post** पर क्लिक करें।

!!! note "ध्यान दें"
    कुछ नेटवर्क पर Bold, Italic और Underline वाले अक्षर 1 से ज़्यादा अक्षर गिने जाते हैं। Underline में हर अक्षर के लिए 1 अक्षर और जुड़ता है।

### फ़ोटो या वीडियो जोड़ें { #add-photos-or-video }

1. **Add photos or videos** पर क्लिक करें, या फ़ाइलों को **Drag & drop or select a file** वाली जगह पर खींचकर छोड़ दें।
2. **Crop image** विंडो खुले, तो एक शेप चुनें और **Crop** पर क्लिक करें। शेप में **Square** (1:1), **Instagram portrait** (4:5), **Twitter / X** (16:9) और **Stories / Reels** (9:16) मिलते हैं। चुने हुए सभी चैनल के लिए एक ही क्रॉप इस्तेमाल होता है।

मीडिया के नियम:

- हर इमेज 25 MB तक की हो सकती है। हर वीडियो 200 MB तक का हो सकता है।
- वीडियो MP4, MOV, M4V, WEBM, AVI या MKV फ़ाइल होना चाहिए।
- **Instagram** पर सिर्फ़ टेक्स्ट वाली पोस्ट नहीं चलती। फ़ोटो जोड़ें, या Instagram को अनचुना कर दें।
- **Facebook** पर वीडियो पोस्ट नहीं चलती। वीडियो हटा दें, या Facebook को अनचुना कर दें।

### Google Business के ऑप्शन सेट करें { #set-google-business-options }

आपके चैनलों में Google Business हो, तब ये ऑप्शन **Google Business options** के नीचे दिखते हैं।

1. पोस्ट का टाइप चुनें: **Standard**, **Event**, **Offer** या **Alert**।
2. **Event** के लिए **Event title**, **Starts** और **Ends** भरें।
3. **Offer** के लिए **Coupon code**, **Redeem URL** और **Terms & conditions** भरें।
4. चाहें तो **Link (optional)** जोड़ें। Google पर यह पोस्ट के टेक्स्ट के नीचे दिखता है।
5. चाहें तो **Call to action** चुनें, जैसे **BOOK**, **ORDER**, **SHOP**, **LEARN_MORE**, **SIGN_UP** या **CALL**। फिर **CTA URL** भरें।

### प्रीव्यू देखें और पब्लिश करें { #preview-and-publish }

1. हर चुने हुए नेटवर्क पर पोस्ट कैसी दिखेगी, यह देखने के लिए **Preview** पर क्लिक करें।
2. अब चुनें कि आगे क्या करना है:
    - पोस्ट को सभी चुने हुए नेटवर्क पर भेजने के लिए **Publish Now** पर क्लिक करें। **Publishing to … — track it under Sent.** मैसेज दिखेगा।
    - बाद के लिए रखना हो, तो **Save Draft** पर क्लिक करें। **Post saved as draft — publish it when ready** मैसेज दिखेगा।
    - तारीख और समय चुनने के लिए **Schedule** पर क्लिक करें। [पोस्ट शेड्यूल करें और क्यू मैनेज करें](schedule-social-posts.md) देखें।

ड्राफ़्ट को बाद में एडिट करना हो, तो **Social** → **Publish** खोलें, **Drafts** टैब पर क्लिक करें और पोस्ट के **Edit** आइकन पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| मुख्य बटन पर **Connect a Channel to Post** लिखा है और वह ग्रे है | कोई नेटवर्क नहीं चुना गया है। | चैनल स्ट्रिप में किसी नेटवर्क पर क्लिक करें। |
| **Post text is required** | टेक्स्ट बॉक्स खाली है। | पोस्ट का टेक्स्ट लिखें। |
| **Post text is over the … character … limit** | टेक्स्ट आपके चुने हुए नेटवर्क की सबसे कम सीमा से लंबा है। | टेक्स्ट छोटा करें, या कम सीमा वाले नेटवर्क को अनचुना कर दें। |
| **Instagram needs a photo or video — add one, or deselect it.** | Instagram पर सिर्फ़ टेक्स्ट वाली पोस्ट नहीं होती। | फ़ोटो जोड़ें, या Instagram को अनचुना कर दें। |
| **Facebook does not accept video posts — remove the video, or deselect it.** | Ohanvi, Facebook Page पर वीडियो पोस्ट नहीं कर सकता। | वीडियो हटाएँ, या Facebook को अनचुना कर दें। |
| **Too large to attach: … (over 25 MB)** | फ़ाइल साइज़ की सीमा से बड़ी है। | फ़ाइल कंप्रेस करें और दोबारा जोड़ें। |
