# फ़्लो पैनल { #the-flow-panel }

फ़्लो पर क्लिक करते ही **Flows** लिस्ट के बगल में उसका पैनल खुल जाता है। इसमें दिखता है कि फ़्लो क्या करता है, उसके रन कैसे गए और उसकी पुरानी हिस्ट्री क्या है। यहीं से आप टेस्ट, पब्लिश, पॉज़ या बिल्डर भी खोल सकते हैं।

**कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, **Flows** चुनें, फिर किसी फ़्लो पर क्लिक करें।

## गाइड { #guides }

| टैब | गाइड | कब पढ़ें |
| --- | --- | --- |
| **Overview** | [फ़्लो और फ़्लो की लिस्ट को समझें](../flows-overview-and-list.md) | आपको फ़्लो के स्टेप देखने हैं, उसे पब्लिश करना है, चालू या बंद करना है, या कॉपी या डिलीट करना है। |
| **Recent runs** | [फ़्लो टेस्ट करें और फ़ेल हुए रन ठीक करें](../test-and-monitor-flows.md) | आपको टेस्ट चलाना है, रन की हिस्ट्री देखनी है या रन रोकने हैं। |
| **Latest output** | [किसी रन का आउटपुट विस्तार से पढ़ें](../read-a-runs-output.md) | आपको देखना है कि हर स्टेप से क्या नतीजा आया और कोई स्टेप क्यों फ़ेल हुआ। |
| **Versions** | [फ़्लो के वर्शन देखें](../review-flow-versions.md) | आपको देखना है कि कौन-सा वर्शन लाइव है और हर वर्शन किसने पब्लिश किया। |

## शुरू करने से पहले { #before-you-start }

- आपको **WhatsApp** पैनल में **Flows** दिखना चाहिए। न दिखे तो अपने एडमिन से पूछें।
- फ़्लो पब्लिश करने, टेस्ट करने या बदलने के लिए आपके रोल को फ़्लो सेव करने का एक्सेस भी चाहिए।
