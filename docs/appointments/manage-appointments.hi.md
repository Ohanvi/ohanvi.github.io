# अपॉइंटमेंट मैनेज करें { #manage-appointments }

**Appointments** पेज पर आपकी बुकिंग दिन के हिसाब से और स्टेटस के साथ दिखती हैं। यहाँ से आप नई रिक्वेस्ट मंज़ूर करते हैं, बुकिंग का समय बदलते हैं, उसे कैंसल करते हैं और विज़िट के बाद बंद करते हैं। आखिर में हर बुकिंग का सही स्टेटस होगा, और ग्राहक को हर बदलाव की खबर WhatsApp पर मिल चुकी होगी।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Appts** दिखे। न दिखे तो अपने एडमिन से कहें कि वे आपके रोल को Appointments का एक्सेस दें।
- आपके पास बुकिंग आ रही हों। देखें [WhatsApp पर बुकिंग लें](take-bookings-on-whatsapp.md)।

## स्टेप { #steps }

### बुकिंग खोजें { #find-a-booking }

1. लेफ़्ट रेल में **Appts** खोलें, फिर **Appointments** चुनें। **Appointments** पेज खुल जाता है। सबटाइटल में दिखता है कि कितनी रिक्वेस्ट इंतज़ार में हैं, जैसे **3 pending requests**।
2. बुकिंग दिन के हेडिंग के नीचे ग्रुप में दिखती हैं: **Today**, **Tomorrow**, फिर पूरी तारीख।
3. हर लाइन में स्टेटस, सर्विस और समय, ग्राहक का फ़ोन नंबर और प्रोवाइडर दिखता है, जैसे **with Dr Mehta**।
4. सिर्फ़ एक दिन देखना हो तो **Today** पर क्लिक करें। दिन बदलने के लिए **Previous day** और **Next day** दबाएँ। सारे दिन फिर से देखने के लिए **Show all upcoming** (X आइकन) पर क्लिक करें।
5. नई बुकिंग लोड करने के लिए **Refresh** पर क्लिक करें।

### खाली लिस्ट का मतलब { #read-an-empty-list }

1. पेज पर **No appointments yet** दिखे, तो अभी कोई बुकिंग नहीं है। साथ में लिखा आता है **Requests booked over WhatsApp and manual bookings will appear here.** पहले WhatsApp बुकिंग सेट करें। देखें [WhatsApp पर बुकिंग लें](take-bookings-on-whatsapp.md)।
2. पेज पर **Nothing on this day** दिखे, तो आप जो एक दिन देख रहे हैं उसमें कोई बुकिंग नहीं है। साथ में लिखा आता है **Pick another day, or clear the filter to see everything.** **Show all upcoming** पर क्लिक करें।
3. पेज पर **Please try again.** के साथ एरर दिखे, तो **Refresh** पर क्लिक करें।

### रिक्वेस्ट कन्फ़र्म या रिजेक्ट करें { #confirm-or-reject-a-request }

नई रिक्वेस्ट का स्टेटस **Requested** होता है।

1. बुकिंग पर **Confirm** पर क्लिक करें तो वह मंज़ूर हो जाती है। मना करना हो तो **Reject** पर क्लिक करें।
2. **Done** मैसेज आता है। स्टेटस बदलकर **Confirmed** या **Rejected** हो जाता है।

Ohanvi ग्राहक को WhatsApp मैसेज भेज देता है: **Your appointment has been confirmed.** या **Sorry, your appointment request could not be accepted.**

### बुकिंग को दूसरे समय पर ले जाएँ { #move-a-booking-to-another-time }

**Move** का ऑप्शन **Requested** और **Confirmed** बुकिंग पर मिलता है।

1. **Move** पर क्लिक करें। तारीख चुनने वाली विंडो खुलती है। नई तारीख चुनें।
2. अब समय चुनने वाली विंडो खुलती है। नया समय चुनें।
3. समय खाली हो, तो **Appointment moved** मैसेज आता है। बुकिंग नए समय पर कन्फ़र्म हो जाती है, और उसके रिमाइंडर भी नए समय पर चले जाते हैं।
4. समय खाली न हो, तो **Move appointment** डायलॉग खुलता है। उसमें वजह और **These times are free:** लिखा होता है। जिस समय पर बुकिंग ले जानी हो, दिखाए गए समयों में से उस पर क्लिक करें।

**Move** से ग्राहक को कोई मैसेज नहीं जाता। नया समय उन्हें खुद बताएँ।

### बुकिंग कैंसल करें { #cancel-a-booking }

1. **Requested** या **Confirmed** बुकिंग पर **Cancel** पर क्लिक करें।
2. **Done** मैसेज आता है और स्टेटस बदलकर **Cancelled** हो जाता है। जो रिमाइंडर भेजने के लिए लगे थे, वे हट जाते हैं।

Ohanvi ग्राहक को **Your appointment has been cancelled.** भेज देता है।

!!! warning "कैंसल की हुई बुकिंग दोबारा नहीं खुल सकती"
    **Cancelled**, **Rejected**, **Completed** और **No-show** आखिरी स्टेटस हैं। ग्राहक को वापस बुलाना हो, तो उन्हें नई बुकिंग करनी होगी।

### विज़िट बंद करें { #close-off-a-visit }

1. **Confirmed** बुकिंग पर तीन-डॉट वाले मेन्यू पर क्लिक करें।
2. विज़िट हो जाए तो **Mark completed** चुनें। ग्राहक न आए तो **Mark no-show** चुनें।

नो-शो अपने आप मार्क करवाना हो, तो **Mark as no-show after (minutes, 0 = never)** सेट करें। देखें [बुकिंग के नियम और रिमाइंडर सेट करें](set-booking-rules-and-reminders.md)।

### बुकिंग के स्टेटस { #booking-statuses }

| स्टेटस | मतलब | मिलने वाले ऑप्शन |
| --- | --- | --- |
| **Requested** | आपकी मंज़ूरी का इंतज़ार है। | **Confirm**, **Reject**, **Move**, **Cancel** |
| **Confirmed** | बुक हो गई। रिमाइंडर चालू हैं तो वे भेजने के लिए लगे रहते हैं। | **Move**, **Cancel**, **Mark completed**, **Mark no-show** |
| **Rescheduled** | नए समय पर चली गई। | इस पेज पर कोई नहीं |
| **Rejected**, **Cancelled**, **Completed**, **No-show** | बंद हो चुकी। | कोई नहीं |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Action failed** | इसी बीच बुकिंग बदल गई। जैसे वह पहले ही कैंसल या पूरी हो चुकी थी। | **Refresh** पर क्लिक करें और स्टेटस देखें। |
| **That time is not available** | नया समय काम के घंटों या आपके बुकिंग नियमों से बाहर है, या कोई प्रोवाइडर खाली नहीं है। | **These times are free:** के नीचे दिए समयों में से कोई एक चुनें। |
| **Somebody just took that time** | आप बुकिंग को आगे-पीछे कर रहे थे, तभी किसी और बुकिंग ने वह स्लॉट ले लिया। | दिखाए गए समयों में से कोई एक चुनें। |
| ग्राहक को WhatsApp मैसेज नहीं मिला | स्टेटस मैसेज सादे टेक्स्ट में जाते हैं। जिस ग्राहक ने पिछले 24 घंटे में आपको मैसेज नहीं किया, उसे WhatsApp सादा टेक्स्ट भेजने नहीं देता। | WhatsApp इनबॉक्स से मंज़ूर हुए टेम्प्लेट के ज़रिए ग्राहक से बात करें। |
| **No appointments yet** | अभी तक कोई बुकिंग नहीं हुई। | बुकिंग फ़्लो जोड़ें। देखें [WhatsApp पर बुकिंग लें](take-bookings-on-whatsapp.md)। |
| कोई पुरानी बुकिंग नहीं दिख रही | पेज सिर्फ़ सबसे नई बुकिंग लोड करता है [LIMIT]। | उसे **Schedule** → **Appointments** व्यू में ढूँढें। देखें [शेड्यूल](../schedule/index.md)। |
