# ऑडियंस { #audience }

ऑडियंस में संपर्कों के लिए **Emails** टैब और लिस्ट व सेगमेंट के लिए **Email Groups** टैब होता है।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Email** खोलें, फिर **Audience** चुनें।

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [संपर्क, लिस्ट और सेगमेंट जोड़ें](../manage-email-contacts.md) | आप लोगों को जोड़ रहे हैं। |
| [संपर्क खोजें, टैग करें और एक्सपोर्ट करें](../find-tag-and-export-contacts.md) | आप फ़िल्टर, लेबल या एक्सपोर्ट करना चाहते हैं। |
| [ईमेल ग्रुप का इस्तेमाल करें](../use-email-groups.md) | आप लिस्ट और नियम वाले सेगमेंट संभालते हैं। |
