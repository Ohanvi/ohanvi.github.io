# Ads Manager { #ads-manager }

**Ads Manager** Ohanvi के अंदर से Facebook और Instagram के विज्ञापन चलाता है। इससे Meta कनेक्ट करें, विज्ञापन बनाएँ, नतीजे ट्रैक करें, और वेबसाइट इवेंट वापस Meta को भेजें। नीचे का हर पेज मॉड्यूल के एक हिस्से के बारे में है।

![Ads Manager टैब, जिसमें टूलबार, स्टेटस फ़िल्टर, मेट्रिक कार्ड और विज्ञापनों की तालिका दिख रही है](../../assets/screenshots/ads-manager-manage-your-ads-01.png)

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट है। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आप एक Facebook Page और एक Meta ad account संभालते हैं।
- आपको **WhatsApp** पैनल में **Ads Manager** दिखता है। न दिखे तो अपने एडमिन से पूछें।
