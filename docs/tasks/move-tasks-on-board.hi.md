# बोर्ड पर टास्क आगे बढ़ाएँ { #move-tasks-across-the-board }

काम आगे बढ़ने के साथ टास्क को अपने वर्कफ़्लो में आगे खिसकाते जाएँ। बोर्ड के कॉलम ऐसे बनाएँ कि वे आपकी टीम के काम करने के तरीके से मेल खाएँ। इसके बाद हर टास्क उस कॉलम में होगा जो उसके असली स्टेटस से मेल खाता है, और प्रोजेक्ट के सब लोग वही कॉलम उसी क्रम में देखेंगे।

## शुरू करने से पहले { #before-you-start }

- आपके प्रोजेक्ट में कॉलम वाला बोर्ड हो। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- बोर्ड पर कम से कम 1 टास्क हो। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

## स्टेप { #steps }

### टास्क को नए कॉलम में ड्रैग करें { #drag-a-task-to-a-new-column }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें। बोर्ड **Board** व्यू में खुलेगा।
2. टास्क कार्ड को एक कॉलम से ड्रैग करें और दूसरे कॉलम पर छोड़ें। खाली कॉलम में **Drop tasks here** दिखता है।
3. कार्ड खिसक जाएगा, और यह बदलाव टास्क की हिस्ट्री में सेव हो जाएगा।

अगर जिस कॉलम में आप टास्क डाल रहे हैं, उसकी काम की सीमा (work-in-progress limit) भर चुकी है, तो **WIP limit reached** डायलॉग खुलता है। फिर भी टास्क ले जाना हो, तो **Move anyway** पर क्लिक करें। टास्क को जहाँ था वहीं रखना हो, तो **Cancel** पर क्लिक करें।

### बिना ड्रैग किए स्टेटस बदलें { #change-the-status-without-dragging }

इनमें से जो तरीका आपके सबसे पास हो, वही इस्तेमाल करें:

- **कार्ड पर:** कार्ड के **…** मेन्यू पर क्लिक करें, **Change status** पर माउस ले जाएँ, और कोई कॉलम चुनें।
- **टास्क डायलॉग में:** टास्क खोलें और दाईं ओर के पैनल में सबसे ऊपर के ड्रॉपडाउन से स्टेटस चुनें। **Save** पर क्लिक करें।
- **Tasks पैनल में:** दाईं ओर की रेल में **Tasks** पर क्लिक करें और टास्क की समरी के नीचे के ड्रॉपडाउन से स्टेटस चुनें। बदलाव तुरंत सेव हो जाता है।

### एक साथ कई टास्क का स्टेटस बदलें { #change-the-status-of-many-tasks-at-once }

1. बोर्ड पर **List** व्यू पर क्लिक करें।
2. जिन टास्क को बदलना है, उन पर टिक करें, या **Select all** पर टिक करें।
3. **Change status** पर क्लिक करें और कोई स्टेटस चुनें। प्रायोरिटी बदलनी हो, तो **Set priority** पर क्लिक करें।

### कॉलम जोड़ें { #add-a-column }

1. बोर्ड के दाएँ सिरे पर **+** (टूलटिप **Add column**) पर क्लिक करें।
2. **Column name** में नाम लिखें।
3. **Save** (टिक) पर क्लिक करें। कॉलम सबसे अंत में जुड़ जाएगा।

### कॉलम का नाम बदलें { #rename-a-column }

1. कॉलम के टाइटल पर, या उसके **…** बटन (टूलटिप **More actions**) पर क्लिक करें।
2. नाम बदलें।
3. **Save** (टिक) पर क्लिक करें। पुराना नाम ही रखना हो, तो **Cancel** (क्रॉस) पर क्लिक करें।

### कॉलम का क्रम बदलें { #reorder-columns }

1. किसी कॉलम के हेडर पर पॉइंटर ले जाएँ। पॉइंटर हाथ का निशान बन जाएगा।
2. हेडर को बाएँ या दाएँ ड्रैग करें और नई जगह पर छोड़ें।

नया क्रम पूरे प्रोजेक्ट के लिए सेव होता है, इसलिए हर मेंबर को वही क्रम दिखता है।

### कॉलम हटाएँ { #remove-a-column }

!!! warning "टास्क दूसरे कॉलम में चले जाते हैं"
    कॉलम हटाने पर उसके सारे टास्क किसी दूसरे कॉलम में चले जाते हैं। हटाने से पहले डायलॉग आपको उस कॉलम का नाम बताता है।

1. कॉलम के **…** बटन (टूलटिप **More actions**) पर क्लिक करें।
2. बिन आइकन (टूलटिप **Remove column**) पर क्लिक करें। **Remove column?** डायलॉग खुलेगा और दिखाएगा कि टास्क कहाँ जाएँगे।
3. **Remove** पर क्लिक करें।

बोर्ड पर कम से कम 1 कॉलम हमेशा रहता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not update status.** | बदलाव सेव नहीं हुआ, इसलिए कार्ड वापस अपनी जगह चला जाता है। | **Refresh** बटन से बोर्ड रिफ़्रेश करें और दोबारा कोशिश करें। |
| Tasks पैनल में **That status is not available on this project.** | बोर्ड पर वह कॉलम हटा दिया गया है या उसका नाम बदल गया है। | मौजूदा कॉलम लोड करने के लिए **Tasks** पैनल बंद करके दोबारा खोलें। |
| **Statuses load with your tasks — try again in a moment.** | पैनल में प्रोजेक्ट के कॉलम अभी लोड नहीं हुए हैं। | कुछ सेकंड रुकें और फ़िल्टर पर फिर क्लिक करें। |
| **At least one column must stay on the board.** | आपने आखिरी कॉलम हटाने की कोशिश की। | पहले दूसरा कॉलम जोड़ें, फिर इसे हटाएँ। |
| **Could not add column. Please try again.** | कॉलम सेव नहीं हुआ। | फिर कोशिश करें। फिर भी न हो, तो कॉलम का कोई दूसरा नाम आज़माएँ। |
| कॉलम की गिनती वाला बैज एम्बर या लाल हो जाता है | कॉलम अपनी काम की सीमा पर है या उससे ऊपर है। | उस कॉलम के टास्क पूरे करें या उन्हें बाहर ले जाएँ। |
