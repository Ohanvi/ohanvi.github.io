# फ़नल पढ़ें और बोर्ड पर लीड्स को आगे बढ़ाएँ { #read-the-funnel-and-move-leads-on-the-board }

देखें कि हर स्टेज तक कितनी लीड्स पहुँचती हैं और आप उन्हें कहाँ खो देते हैं। इस गाइड के बाद आपको पता होगा कि किस स्टेज और किस लीड सोर्स पर काम करना है। आप लीड कार्ड खींचकर एक स्टेज से दूसरे में भी ले जा सकेंगे। फ़नल पढ़ने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **CRM** दिखना चाहिए, और उसके पैनल में **Funnel**। इसके लिए CRM रिपोर्ट का एक्सेस चाहिए। न दिखे, तो अपने एडमिन से पूछें।
- आपके पास लीड्स हों। देखें [लीड्स के साथ काम करें](leads.md)।

## स्टेप { #steps }

### फ़नल खोलें { #open-the-funnel }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Funnel** चुनें।
2. ऊपर देखें कि **Funnel | Board** स्विच में **Funnel** चुना हुआ है।

### कन्वर्ज़न फ़नल पढ़ें { #read-the-conversion-funnel }

1. **Conversion funnel** पढ़ें। हर बार एक स्टेज दिखाता है।
2. हर बार के नीचे देखें कि अगले स्टेज तक पहुँचने से पहले कितना हिस्सा छूट गया।
3. सबसे बड़ी गिरावट ढूँढें। इसी स्टेज पर लीड्स ठंडी पड़ जाती हैं।

### लीड सोर्स की तुलना करें { #compare-lead-sources }

1. **Funnel by source** तक स्क्रॉल करें।
2. सबसे ज़्यादा कन्वर्ज़न वाला सोर्स ढूँढें।
3. सोर्स की स्क्रीन खोलने के लिए **Lead Sources** पर क्लिक करें। देखें [लीड के स्रोत मैनेज करें](manage-lead-sources.md)।

### फ़नल डाउनलोड करें { #download-the-funnel }

1. **Export** पर क्लिक करें।
2. फ़नल की एक Excel फ़ाइल डाउनलोड हो जाती है।

### लीड बोर्ड पर जाएँ { #switch-to-the-lead-board }

1. **Funnel | Board** स्विच में **Board** पर क्लिक करें।
2. बाएँ से दाएँ 6 कॉलम पढ़ें: **New**, **Contacted**, **Qualified**, **Unqualified**, **Lost** और **Converted**। हर कॉलम के हेडर में उसकी लीड्स की गिनती दिखती है।
3. एक कार्ड देखें। उस पर लीड का नाम होता है, और उसके नीचे कंपनी। अगर लीड का स्कोर है, तो **Score** के साथ उसका नंबर भी दिखता है।
4. अगर सारे 6 कॉलम एक साथ स्क्रीन पर न आएँ, तो बगल में स्क्रॉल करें।
5. बार वाले व्यू पर लौटने के लिए **Funnel** पर क्लिक करें।

कॉलम पहले से तय हैं। आप उनका नाम नहीं बदल सकते और नए कॉलम नहीं जोड़ सकते।

### लीड को दूसरे स्टेज में ले जाएँ { #move-a-lead-to-another-stage }

1. किसी लीड कार्ड को थोड़ी देर दबाए रखें।
2. उसे दूसरे कॉलम में खींचें।
3. कार्ड को छोड़ दें। लीड का स्टेटस नए कॉलम के हिसाब से बदल जाता है।

अगर लीड मूव न हो, तो **Could not move the lead.** मैसेज आता है। कार्ड वहीं रहता है जहाँ था।

!!! note "ध्यान दें"
    लीड **Converted** में तभी जाती है जब आप उसे **Convert** एक्शन से कन्वर्ट करते हैं। देखें [लीड्स के साथ काम करें](leads.md)।

### बदलें कि कौन-से स्टेज दिखें { #change-which-stages-show }

1. **Edit stages** ढूँढें। यह सिर्फ़ प्लेटफ़ॉर्म sysadmin को दिखता है।
2. अगर यह दिखे, तो उस पर क्लिक करें और अपने फ़नल व्यू में स्टेज छिपाएँ या उनका क्रम बदलें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| फ़नल खाली है | आपके पास कोई लीड नहीं है, या इस समय में कोई लीड नहीं आई। | लीड्स जोड़ें। देखें [लीड्स के साथ काम करें](leads.md)। |
| **CRM** पैनल में **Funnel** नहीं दिख रहा | आपके रोल को CRM रिपोर्ट का एक्सेस नहीं है। | अपने एडमिन से CRM रिपोर्ट का एक्सेस माँगें। |
| **Could not move the lead.** | स्टेटस का बदलाव सेव नहीं हुआ। | दोबारा कोशिश करें। अगर बार-बार फ़ेल हो, तो लीड पर **Move Status** का इस्तेमाल करें। |
| कार्ड खिंच नहीं रहा | आपने कार्ड को दबाए रखने की जगह सिर्फ़ टैप किया। | कार्ड को दबाए रखें, फिर खींचें। |
