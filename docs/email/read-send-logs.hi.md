# भेजने के लॉग पढ़ें { #read-the-send-logs }

Send Logs दिखाता है कि कैंपेन के हर प्राप्तकर्ता के साथ क्या हुआ। इससे देखें कि किसे ईमेल मिला, किसने खोला और क्लिक किया, और कुछ सेंड क्यों फ़ेल हुए। आख़िर में आप पूरा लॉग एक्सपोर्ट कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपने कम से कम 1 कैंपेन भेजा हो। देखें [ईमेल कैंपेन भेजें](send-email-campaign.md)।
- आपको **Email** पैनल में **Manage** दिखता हो। न दिखे तो अपने एडमिन से पूछें।

## चरण { #steps }

### किसी कैंपेन का लॉग खोलें { #open-the-log-for-a-campaign }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।
2. **Send Logs** चुनें।
3. **Campaign** में कैंपेन चुनें। जब तक आप नहीं चुनते, पेज पर **Select a campaign** लिखा रहता है।
4. टेबल पढ़ें। उसमें हर व्यक्ति के लिए **Recipient**, **Status**, **Sent**, **Opened**, **Clicked**, **Unsubscribed** और **Error** दिखते हैं।

### फ़िल्टर और खोज { #filter-and-search }

1. सूची को छोटा करने के लिए किसी फ़िल्टर पर क्लिक करें: **All**, **Queued**, **Failed**, **Opened**, **Not Opened**, **Clicked**, **Bounced**, **Complained** या **Unsubscribed**।
2. किसी एक व्यक्ति को खोजने के लिए **Search recipient email** में टाइप करें।

### एक प्राप्तकर्ता को पढ़ें { #read-one-recipient }

1. किसी पंक्ति पर क्लिक करें। उसकी **Activity Timeline** खुलती है।
2. उस व्यक्ति को खोलने के लिए **View Contact** पर क्लिक करें, या उन्हें जो ईमेल मिला वह देखने के लिए **View Template** पर।

### लॉग एक्सपोर्ट करें { #export-the-log }

1. **Export** पर क्लिक करें।
2. हर पंक्ति के लिए **Export Excel (full log)** पर क्लिक करें, या स्क्रीन पर दिख रही पंक्तियों के लिए **Export CSV (current page)** पर।

### हर स्टेटस का मतलब { #what-each-status-means }

| स्टेटस | मतलब |
| --- | --- |
| **Queued** | भेजे जाने का इंतज़ार कर रहा है। |
| **Sent** | भेजने वाले सर्वर को सौंप दिया गया। |
| **Delivered** | प्राप्तकर्ता के इनबॉक्स प्रोवाइडर ने स्वीकार कर लिया। |
| **Bounced** | वह पता इसे पा नहीं सका। |
| **Complained** | प्राप्तकर्ता ने इसे स्पैम बताया। |
| **Failed** | सेंड पूरा नहीं हुआ। **Error** कॉलम में वजह लिखी होती है। |
| **Skipped suppressed** | नहीं भेजा गया, क्योंकि पता सप्रेशन लिस्ट में है। |

टेस्ट सेंड Send Logs में नहीं दिखता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Select a campaign** | कोई कैंपेन चुना नहीं गया है। | **Campaign** में एक चुनें। |
| **No send logs yet** | कैंपेन अभी किसी को भेजा नहीं गया है। | **Campaigns** पर उसका स्टेटस देखें। |
| कई पंक्तियों में **Failed** दिख रहा है। | भेजने वाला वेरिफ़ाई नहीं है, या आपके अपने प्रोवाइडर ने कनेक्शन मना कर दिया। | **Error** कॉलम पढ़ें। **Sender Identities** और **Email Sending Server** जाँचें। |
| ओपन कम दिख रहे हैं। | कुछ इनबॉक्स ट्रैकिंग इमेज को ब्लॉक कर देते हैं। | ओपन के साथ क्लिक की भी तुलना करें। |
