# HR { #hr }

HR में आपके कर्मचारियों का रिकॉर्ड और हाज़िरी एक जगह रहती है। जो स्टाफ़ ऐप इस्तेमाल नहीं करता, उसे भी नाम और WhatsApp नंबर से जोड़ा जा सकता है। वह WhatsApp पर एक शब्द भेजकर हाज़िरी लगाता है और चैट पर ही अपनी हाज़िरी पूछ सकता है।

**इसे कहाँ खोलें:** साइडबार में **HR** खोलें। हाज़िरी के अपने मेन्यू आइटम हैं, जिनमें **Attendance Dashboard** और **WhatsApp attendance** शामिल हैं। [VERIFY: HR entry name in the left rail]

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [स्टाफ़ जोड़ें](add-staff.md) | आपको ऐसे लोग जोड़ने हैं जो WhatsApp पर काम करते हैं, बिना लॉगिन और बिना पेड सीट के। |
| [WhatsApp पर हाज़िरी लगाएँ](whatsapp-attendance.md) | आप चाहते हैं कि स्टाफ़ एक शब्द भेजकर चेक-इन, चेक-आउट और ब्रेक करे। |
| [हाज़िरी की रिपोर्ट और डैशबोर्ड देखें](attendance-reports-and-dashboard.md) | आपको देखना है कि आज कौन आया है, या चैट पर हाज़िरी की रिपोर्ट भेजनी है। |

## शुरू करने से पहले { #before-you-start }

- आपके रोल के पास HR का एक्सेस है।
- WhatsApp वाली गाइड के लिए आपके बिज़नेस का एक WhatsApp नंबर Ohanvi से जुड़ा है।
