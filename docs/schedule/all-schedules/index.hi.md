# सभी शेड्यूल { #all-schedules }

सभी शेड्यूल Schedule का मुख्य स्क्रीन है। इसमें हर मॉड्यूल के शेड्यूल किए हुए सारे आइटम एक ही कैलेंडर या लिस्ट में दिखते हैं। इससे आप पूरा प्लान एक साथ देख सकते हैं और किसी भी आइटम को यहीं से बदल सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Schedule** खोलें, फिर **All schedules** चुनें।


## गाइड { #guides }

| गाइड | कब काम आएगी |
| --- | --- |
| [जो कुछ भी शेड्यूल है, सब देखें](../view-schedule.md) | आप कैलेंडर या लिस्ट देखना चाहते हैं, उसे फ़िल्टर करना चाहते हैं और स्टेटस पढ़ना चाहते हैं। |
| [शेड्यूल किए आइटम को रीशेड्यूल, कैंसिल या डिलीट करें](../reschedule-cancel-delete.md) | प्लान बदल गया है और किसी आइटम को आगे-पीछे करना या रोकना है। |

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है।
- कम से कम एक मॉड्यूल में कुछ शेड्यूल किया हुआ हो।
