# Social साइडबार का इस्तेमाल करें { #use-the-social-sidebar }

बाईं तरफ़ के **Social** पैनल में मेन्यू के अलावा भी कुछ है। उसमें एक **New** बटन है और आपके कनेक्ट किए हुए चैनलों की लिस्ट है। यहाँ से आप पोस्ट शुरू कर सकते हैं और किसी एक चैनल के Publish या Insights पर जा सकते हैं। आप और नेटवर्क भी कनेक्ट कर सकते हैं। इसमें करीब 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखना चाहिए। न दिखे, तो अपने एडमिन से कहें कि आपके रोल को Social का एक्सेस दे दें। इसके लिए [सेटिंग्स का परिचय](../settings/index.md) देखें।

## स्टेप { #steps }

### कुछ नया शुरू करें { #start-something-new }

1. लेफ़्ट रेल में **Social** खोलें।
2. पैनल के ऊपर **New** पर क्लिक करें। एक मेन्यू खुलता है।
3. **Create Post** विंडो खोलने के लिए **Post** पर क्लिक करें। इसके लिए [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md) देखें।
4. **Connect** → **Social Connections** खोलने के लिए **Connect a new channel** पर क्लिक करें।
5. **Idea** ग्रे दिखता है। यह अभी बना नहीं है।

### Channels की लिस्ट देखें { #read-the-channels-list }

1. पैनल में नीचे **CHANNELS** तक स्क्रॉल करें। हर कनेक्ट किए हुए अकाउंट की एक लाइन है, जिसमें उसका आइकन और नाम होता है।
2. किसी लाइन पर क्लिक करके उसे खोलें।
3. उसके नीचे **Publish** और **Insights** दिखते हैं।
4. सिर्फ़ उसी चैनल की पोस्ट देखने के लिए **Publish** पर क्लिक करें। इसके लिए [Publish के फ़िल्टर, ओवरव्यू और पोस्ट की डिटेल](use-publish-filters-and-extras.md) देखें।
5. सिर्फ़ उसी चैनल के नतीजे देखने के लिए **Insights** पर क्लिक करें। इसके लिए [Insights के चार्ट और एक चैनल की रिपोर्ट](explore-insights-charts.md) देखें।
6. आपने जो चैनल खोला है, वह हाइलाइट रहता है। दो अकाउंट एक ही नेटवर्क के हों, तो दोनों साथ में चालू दिखते हैं।

### और चैनल कनेक्ट करें { #connect-more-channels }

1. **CHANNELS** के ऊपर दाईं तरफ़ तीन आइकन हैं: सर्च, सेटिंग्स और प्लस का निशान।
2. **Connect** → **Social Connections** खोलने के लिए सेटिंग्स आइकन (**Settings**) पर क्लिक करें।
3. वही स्क्रीन खोलने के लिए प्लस के निशान (**Connect a new channel**) पर क्लिक करें।
4. **Connect more channels** में किसी नेटवर्क के लोगो पर क्लिक करें। उसका कनेक्ट विज़ार्ड खुल जाता है।
5. सभी नेटवर्क देखने के लिए प्लस टाइल पर क्लिक करें।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **CHANNELS** खाली है | कोई अकाउंट कनेक्ट नहीं है। | प्लस के निशान पर क्लिक करें और एक अकाउंट कनेक्ट करें। |
| **Idea** ग्रे है | यह अभी उपलब्ध नहीं है। | इसकी जगह **Post** इस्तेमाल करें। |
| चैनल की लाइन नहीं खुलती | पैनल सिकुड़ा हुआ है। | ग्रुप के नाम पर क्लिक करके उसे खोलें। |
