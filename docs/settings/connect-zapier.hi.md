# Zapier कनेक्ट करें { #connect-zapier }

Ohanvi को Zapier से कनेक्ट करें। फिर आपका CRM, WhatsApp, फ़ॉर्म और ईमेल बिना कोड के हज़ारों दूसरे ऐप से जुड़ जाएँगे। आप Ohanvi में एक API key बनाते हैं और उसे Zapier में पेस्ट करते हैं। अपने Zap आप वहीं बनाते हैं। इसमें करीब 10 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको **Settings** में **Integrations** खोलना आता हो। अगर यह नहीं दिखता, तो अपने वर्कस्पेस ओनर से पूछें।
- zapier.com पर आपका Zapier अकाउंट हो।
- आपको पता हो कि key किस यूज़र के नाम से बनेगी। key उसी यूज़र की अनुमतियों से चलती है जिसने उसे बनाया है। देखें [टीम के मेंबर, रोल और अनुमतियाँ मैनेज करें](roles-and-permissions.md)।

## Zapier और Ohanvi साथ कैसे काम करते हैं { #how-zapier-and-ohanvi-work-together }

कनेक्शन Zapier की तरफ़ से शुरू होता है। इसलिए Ohanvi में key के अलावा कुछ "कनेक्ट" नहीं करना पड़ता। इस स्क्रीन पर Ohanvi तीन काम करता है:

- API keys बनाता है, उनकी लिस्ट दिखाता है और उन्हें कैंसिल करता है।
- वे **Triggers** (आपके अकाउंट में कुछ होने पर) और **Searches** (कोई रिकॉर्ड ढूँढना) दिखाता है, जो Ohanvi, Zapier को देता है।
- **Popular automations** के नीचे बने-बनाए आइडिया दिखाता है।

आपके बनाए Zap यहाँ नहीं दिखते। उन्हें अपने Zapier डैशबोर्ड में मैनेज करें।

## स्टेप { #steps }

### Zapier स्क्रीन खोलें { #open-the-zapier-screen }

1. नीचे-बाएँ कोने में अपने इनिशियल पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. बाईं लिस्ट में **Workspace** के नीचे **Integrations** चुनें।
3. **Integration** के नीचे **Zapier** पर क्लिक करें। **Zapier** पेज खुल जाएगा।
4. टाइटल के नीचे की पिल देखें। उसमें लिखा होता है कि कितनी key चालू हैं, जैसे **1 active key**। कोई key न हो तो **No active key yet** लिखा आता है।

### API key बनाएँ { #create-an-api-key }

1. **Create key** पर क्लिक करें। **Create Zapier API key** विंडो खुलेगी।
2. **Key name** में अपनी पहचान के लिए कोई नाम लिखें, जैसे `Marketing Zaps`। जिन Zap में key लगेगी, उनके हिसाब से नाम रखें। यह नाम ज़रूरी है। खाली छोड़ने पर विंडो में लिखा आएगा **Give the key a name so you can recognise it later.**
3. **Expires after** में **30 days**, **90 days**, **1 year** या **Never expires** चुनें।
4. नीचे का नोट पढ़ें। key आपकी अपनी अनुमतियों से काम करती है। Zapier कितना कुछ देख सके, यह सीमित करना हो, तो सीमित अनुमति वाले यूज़र से साइन इन करें और key वहीं बनाएँ।
5. **Create key** पर क्लिक करें। **Connect Zapier** विंडो खुलेगी।

### key को Zapier में कॉपी करें { #copy-the-key-into-zapier }

1. **Connect Zapier** विंडो में चेतावनी पढ़ें। key **सिर्फ़ एक बार** दिखती है। खो जाए तो नई key बनानी पड़ेगी।
2. **Base URL** कॉपी करें। Zapier यह माँगेगा।
3. **API Key** कॉपी करें। Zapier यह भी माँगेगा।
4. **I have copied my key somewhere safe** पर टिक करें।
5. **Open Zapier** पर क्लिक करें। Zapier नए ब्राउज़र टैब में खुलेगा।
6. Zapier में नया Zap शुरू करें और ऐप में Ohanvi चुनें। कनेक्ट करने को कहे, तब key पेस्ट कर दें।

### Zap बनाएँ { #build-a-zap }

1. Zapier में कोई ट्रिगर चुनें, जैसे **New Lead**। फिर चुनें कि दूसरे ऐप में क्या होना चाहिए।
2. कनेक्शन जाँचने के लिए Zapier से एक सैंपल रिकॉर्ड मँगवाएँ।
3. सैंपल सही लगे तो Zap पब्लिश करें। इसके बाद वह अपने-आप चलेगा।

पेज पर **How to set this up** के नीचे भी यही चार स्टेप लिखे हैं: key बनाएँ, Zapier में कनेक्ट करें, ट्रिगर चुनें, टेस्ट करके चालू करें।

### बने-बनाए आइडिया से शुरू करें { #start-from-a-ready-made-idea }

1. **Popular automations** तक स्क्रॉल करें। उसके नीचे लिखा है कि हर आइडिया Zapier खोलता है, और कार्ड पर जो ट्रिगर बताया है, वही आप चुनें।
2. **Bring data in from other apps** में वे आइडिया देखें जो किसी दूसरे ऐप से शुरू होते हैं और Ohanvi में रिकॉर्ड बनाते हैं।
3. किसी कार्ड पर **Set up in Zapier** पर क्लिक करें। Zapier खुलेगा और पेज पर एक हिंट दिखेगा, जैसे **In Zapier, choose the "New Lead" trigger.**
4. अगर अभी कोई key नहीं है, तो कार्ड पर **Create a key first** दिखता है। आगे बढ़ने से पहले key बना लें।

आइडिया के कुछ उदाहरण: हर नई लीड को WhatsApp पर वेलकम करें, नई लीड्स को शीट में लिखें, जीती हुई डील्स का जश्न मनाएँ, ऑर्डर शिप होने पर WhatsApp टेम्प्लेट भेजें, और फ़ॉर्म के जवाबों को लीड्स बनाएँ।

### देखें कि क्या-क्या ऑटोमेट हो सकता है { #see-what-you-can-automate }

1. **What you can automate** तक स्क्रॉल करें। उसके नीचे लिखा है कि ये वे ट्रिगर और सर्च हैं जो यह सर्वर Zapier को देता है।
2. **Triggers** पढ़ें। इस पर **When this happens in your account…** लिखा है। Zap बनाते समय आपको यही नाम दिखेंगे।
3. **Searches** पढ़ें। इस पर **Look up a record from another app…** लिखा है।

### key देखें या कैंसिल करें { #check-or-revoke-a-key }

1. **API keys** में हर key देखें। उसमें नाम, key की शुरुआत, और **Created**, **Last used** और **Expires** दिखते हैं।
2. किसी key को बंद करने के लिए उसकी रो में **Revoke** पर क्लिक करें।
3. **Revoke "name"?** में **Revoke** पर क्लिक करें। इस key वाले सारे Zap तुरंत बंद हो जाएँगे। आपको नई key बनानी होगी और उन Zap को Zapier में दोबारा कनेक्ट करना होगा।
4. **Key revoked.** मैसेज आएगा। कैंसिल और एक्सपायर हुई key रिकॉर्ड के लिए लिस्ट में रहती हैं।
5. लिस्ट दोबारा लोड करने के लिए ऊपर **Refresh** पर क्लिक करें।

!!! warning "कैंसिल करने के बाद वापस नहीं हो सकता"
    कैंसिल की गई key से चलने वाली हर चीज़ अपनी अगली रिक्वेस्ट पर ही फ़ेल हो जाती है। अगर Zap को चालू रखना है, तो पहले नई key बना लें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not create the key.** | key बनाने की रिक्वेस्ट फ़ेल हो गई। | अपना इंटरनेट कनेक्शन देखें, फिर **Create key** पर दोबारा क्लिक करें। |
| **Give the key a name so you can recognise it later.** | **Key name** खाली है। | नाम लिखें और **Create key** पर दोबारा क्लिक करें। |
| मेरी key खो गई। | key सिर्फ़ एक बार दिखती है, दोबारा नहीं दिखती। | नई key बनाएँ, Zapier में बदलें, फिर पुरानी key कैंसिल करें। |
| **Could not open Zapier.** | आपके ब्राउज़र ने नया टैब रोक दिया। | Ohanvi के लिए पॉप-अप की अनुमति दें, या zapier.com खुद खोलें। |
| Popular automations में **Create a key first** दिख रहा है। | कोई चालू key नहीं है। | ऊपर **Create key** पर क्लिक करें। |
| कोई Zap चलना बंद हो गया। | उसकी key कैंसिल हो गई है या एक्सपायर हो गई है। | नई key बनाएँ और Zap को Zapier में दोबारा कनेक्ट करें। |
