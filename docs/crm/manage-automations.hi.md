# CRM ऑटोमेशन प्रबंधित करें { #manage-crm-automations }

आपकी लीड्स और डील्स पर काम करने वाले हर बैकग्राउंड नियम को देखें, जैसे शांत हो गई लीड को याद दिलाना, और जाँचें कि हर नियम चल रहा है या नहीं। आखिर में आपको पता होता है कि कौन से नियम **Active** हैं, कौन से रुके हुए या अभी ड्राफ़्ट हैं, और हर नियम आखिरी बार कब चला।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **CRM** दिखता है और उसके पैनल में **Automations** भी। इस आइटम के लिए ऑटोमेशन फ़्लो का एक्सेस ज़रूरी है। अगर यह नहीं दिखता, तो अपने एडमिन से पूछें।

## चरण { #steps }

### अपने नियम जाँचें { #check-your-rules }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Automations** चुनें।
2. हर नियम का कार्ड पढ़ें। उसमें दिखता है कि नियम किससे शुरू होता है (**When**), कोई शर्तें हों तो (**And**), और वह क्या करता है (**Then**)।
3. नाम के नीचे की स्थिति वाली लाइन पढ़ें:
    - **Draft — not running yet** — नियम पब्लिश नहीं हुआ है।
    - **Paused — not running** — नियम बंद किया गया है।
    - **Active · has not run yet** — नियम चालू है और पहले इवेंट का इंतज़ार कर रहा है।
    - **Active · last run …** — नियम चालू है, साथ में उसके आखिरी रन का नतीजा दिखता है।

चैटबॉट और जर्नी यहाँ नहीं दिखते। उन्हें **WhatsApp** और **Email** में खोजें।

### नियम को रोकें या दोबारा चालू करें { #pause-or-resume-a-rule }

1. नियम के कार्ड पर **Active** स्विच पर क्लिक करें। **Pause "…"?** विंडो खुलती है।
2. चेतावनी पढ़ें: जो रन पहले से चल रहा है वह पूरा होगा, और जो मैसेज भेजना आधा हो चुका है वह भी।
3. **Pause** पर क्लिक करें। स्विच पर **Paused** दिखता है।
4. दोबारा चालू करने के लिए **Paused** स्विच पर क्लिक करें। नियम फिर से **Active** हो जाता है।

### नियम बनाएँ या एडिट करें { #create-or-edit-a-rule }

1. नियम बनाने के लिए **New automation** पर क्लिक करें। **Automation flows** स्क्रीन खुलती है, जहाँ आप उसे बनाते हैं।
2. नियम एडिट करने के लिए उसके कार्ड पर क्लिक करें। नियम ऑटोमेशन बिल्डर में खुलता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not change that automation.** | रोकना या दोबारा चालू करना सेव नहीं हुआ। | पेज रीफ़्रेश करें और फिर कोशिश करें। |
| **Could not load your automations** | सूची लोड नहीं हुई। अधूरी सूची दिखाने के बजाय कुछ नहीं दिखाया जाता। | पेज रीफ़्रेश करें। अगर बार-बार यही हो, तो अपने एडमिन से ऑटोमेशन फ़्लो का आपका एक्सेस जाँचने को कहें। |
| **No steps yet — this rule does nothing until it has one.** | नियम में ट्रिगर है लेकिन कोई एक्शन नहीं। | कार्ड पर क्लिक करें और बिल्डर में एक चरण जोड़ें। |
| नियम रोकने के बाद भी एक मैसेज चला गया | रोकने से सिर्फ़ नए रन बंद होते हैं। जो रन शुरू हो चुका था, वह पूरा होता है। | रन के पूरा होने का इंतज़ार करें। अगली बार पहले रोकें। |
| **No automations yet** | अभी तक कोई नियम नहीं बनाया गया है। | **New automation** पर क्लिक करें। |
