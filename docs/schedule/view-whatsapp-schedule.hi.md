# अपने शेड्यूल किए व्हाट्सऐप संदेश देखें { #see-your-scheduled-whatsapp-messages }

**WhatsApp** व्यू से व्हाट्सऐप पर शेड्यूल की गई हर चीज़ एक कैलेंडर या सूची में देखें: ब्रॉडकास्ट, अकेले संदेश, जवाब, कार्ट रिमाइंडर और अपॉइंटमेंट रिमाइंडर। आखिर में आप इनमें से किसी को भी जाँच, आगे-पीछे या बंद कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखे। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। अगर नहीं दिखता, तो अपने एडमिन से पूछें।
- व्हाट्सऐप में कुछ शेड्यूल किया गया हो, जैसे कोई ब्रॉडकास्ट। देखें [ब्रॉडकास्ट कैंपेन भेजें](../whatsapp/send-broadcast-campaign.md)।

## चरण { #steps }

### WhatsApp शेड्यूल खोलें { #open-the-whatsapp-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **WhatsApp** चुनें। पेज का शीर्षक **WhatsApp schedule** है।
2. पेज मौजूदा महीने के **Calendar** व्यू में खुलता है। चैनल चिप छिपे रहते हैं, क्योंकि पेज पहले से सिर्फ़ व्हाट्सऐप तक सीमित है।
3. किसी दिन पर क्लिक करके उसके आइटम देखें। दिन के शीर्षकों के नीचे समय के क्रम में देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर प्रकार का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि आइटम किस तरह का है।

| प्रकार | यह क्या है |
| --- | --- |
| **Broadcast** | संपर्कों के समूह को भेजा जाने वाला कैंपेन। |
| **Message** | एक व्यक्ति को शेड्यूल किया गया एक संदेश। |
| **Reply** | किसी ग्राहक को शेड्यूल किया गया जवाब। |
| **Cart nudge** | छोड़ी गई कार्ट का रिमाइंडर। |
| **Appointment reminder** | बुकिंग से पहले भेजा जाने वाला रिमाइंडर। यह आपके अपॉइंटमेंट रिमाइंडर नियमों से बनता है। |
| **Bot step timeout** | चैटबॉट का वह चरण जो जवाब का इंतज़ार करता है और जवाब न आने पर चैट को आगे बढ़ा देता है। |

**Audience / with** पंक्ति वह फ़ोन नंबर दिखाती है जिसे संदेश जाएगा।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Scheduled** | अपने समय का इंतज़ार कर रहा है। |
| **Live** | अभी भेजा जा रहा है। |
| **Sent** | भेज दिया गया। |
| **Paused** | व्हाट्सऐप **Scheduler** में रोका गया है। |
| **Failed** | भेजना सफल नहीं हुआ। |
| **Cancelled** | रद्द कर दिया गया। रिकॉर्ड रखा जाता है। |

### किसी आइटम में बदलाव करें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [शेड्यूल किया आइटम रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।
2. व्हाट्सऐप **Scheduler** खोलने के लिए **Edit** पर क्लिक करें। देखें [शेड्यूल किए संदेश और डिलीवरी लॉग देखें](../whatsapp/scheduler-and-delivery-logs.md)।
3. उसे रद्द करने के लिए **Cancel** पर क्लिक करें। शेड्यूल किया गया जॉब रुक जाता है और व्हाट्सऐप **Scheduler** से हट जाता है।
4. उसे व्हाट्सऐप से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को सीमित करें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in WhatsApp** चुनें। Ohanvi व्हाट्सऐप **Scheduler** खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | कोई व्हाट्सऐप आइटम ओनर या स्टेटस फ़िल्टर से मेल नहीं खाता। | **Everyone's schedule** और **Any status** चुनें। |
| कोई आइटम **Failed** है | भेजना सफल नहीं हुआ, जैसे टेम्प्लेट Approved नहीं था। | कारण देखने के लिए आइटम को व्हाट्सऐप **Scheduler** में खोलें, फिर उसे दोबारा भेजें। |
| बार-बार चलने वाला ब्रॉडकास्ट सिर्फ़ एक बार दिखता है | कैलेंडर अगला भेजना दिखाता है। | पूरी सीरीज़ देखने के लिए **Recurring** खोलें। |
| **Could not reschedule.** | नया समय स्वीकार नहीं किया गया। | कोई दूसरा समय चुनें। |
