# टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें { #manage-team-members-roles-and-permissions }

अपने वर्कस्पेस में टीम के सदस्य जोड़ें, हर एक को सही रोल दें, और बाद में उन्हें एडिट या हटाएँ। अंत में आपकी टीम का हर व्यक्ति अपने अकाउंट से साइन इन करता है और सिर्फ़ वही देखता है जो उसका रोल इजाज़त देता है।

## शुरू करने से पहले { #before-you-start }

- आप वर्कस्पेस के ओनर या कोई दूसरे **Super Admin** हैं। टीम स्क्रीन पर **Add**, **Invite teammate** और **Edit** सिर्फ़ एडमिन को दिखते हैं।
- आपके प्लान में एक खाली सीट है। सभी सीट भर जाने पर **Add** और **Invite teammate** छिपे रहते हैं। सीट बढ़ाने के लिए देखें [Ohanvi में क्रेडिट और बिलिंग](../credits-and-billing.md) और [बिलिंग सेक्शन](../billing/index.md)।
- आपके पास हर सदस्य का नाम, ईमेल और मोबाइल नंबर है।

## Ohanvi में रोल { #roles-in-ohanvi }

हर व्यक्ति का ठीक 1 रोल होता है। रोल तय करता है कि वह हर मॉड्यूल में क्या कर सकता है।

| रोल | यह क्या इजाज़त देता है |
| --- | --- |
| **Super Admin** | पूरा एक्सेस, टीम और बिलिंग समेत। |
| **Manager** | डिलीट को छोड़कर सब कुछ। |
| **Executive** | रोज़ का काम, बिना डिलीट, मंज़ूर या रद्द करने के। |

अनुमतियाँ रोल से मिलती हैं। आप किसी एक व्यक्ति के लिए अलग-अलग काम चालू या बंद नहीं कर सकते। किसी की अनुमतियाँ बदलनी हों तो उसका रोल बदलें।

जिसने वर्कस्पेस बनाया है वह अकाउंट ओनर है। उसका रोल नहीं बदला जा सकता और उसका अकाउंट डिलीट नहीं हो सकता।

## चरण { #steps }

### टीम की सूची खोलें { #open-the-team-list }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. Settings की सूची में सबसे ऊपर अपने नाम पर क्लिक करें।
3. **Team & access** के तहत **App User** पर क्लिक करें। **App User Management** सूची खुलती है।

सूची में हर व्यक्ति के लिए **Status**, **Name**, **Username**, **Role**, **Email** और **Phone Number** दिखते हैं।

### टीम का सदस्य जोड़ें { #add-a-teammate }

इसका इस्तेमाल तब करें जब आप सदस्य का यूज़रनेम और पहला पासवर्ड खुद तय करना चाहते हैं। अगर उन्हें खुद साइन अप करने देना है, तो इसकी जगह [उन्हें लिंक से बुलाएँ](invite-teammates.md)।

1. **Add** पर क्लिक करें। **Add teammate** विंडो खुलती है।
2. **User Details** के तहत **Name**, **Username**, **Email** और **Phone Number** भरें।
3. **Username** के नीचे **Username available** दिखने तक रुकें। अगर **Username already taken** दिखे, तो कोई दूसरा आज़माएँ।
4. **User Type** को **Standard** ही रहने दें। **Generic** सिर्फ़ ऐसे बाहरी यूज़र के लिए चुनें जिसे चंद अनुमत कामों की छोटी सूची चाहिए।
5. पहला **Password** लिखें। उसे बॉक्स के नीचे की चेकलिस्ट का हर नियम पूरा करना होगा।
6. **Role** के तहत **Super Admin**, **Manager** या **Executive** पर क्लिक करें।
7. अगर आपने **Executive** चुना है, तो **Reports To** → **Manager (optional)** में चुनें कि वह किसे रिपोर्ट करेगा। सिर्फ़ Manager और Super Admin सूची में आते हैं।
8. **Add teammate** पर क्लिक करें। संदेश **<Name> added to your team.** दिखता है।
9. यूज़रनेम और पासवर्ड अपने सदस्य को दें। वे पासवर्ड बाद में **My Account** पर बदल सकते हैं।

### सदस्य की जानकारी या रोल बदलें { #change-a-teammates-details-or-role }

1. **App User Management** सूची में व्यक्ति की पंक्ति पर पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit teammate** विंडो खुलती है।
2. उनकी जानकारी बदलें, या **Role** के तहत नया रोल चुनें।
3. उनका पासवर्ड रीसेट करने के लिए **Password** में नया पासवर्ड लिखें। मौजूदा पासवर्ड रखना हो तो उसे खाली छोड़ें।
4. **Save** पर क्लिक करें। संदेश **<Name> updated.** दिखता है।

अकाउंट बनने के बाद आप **Username** नहीं बदल सकते।

### प्लान डाउनग्रेड के बाद सदस्य को वापस लाएँ { #bring-back-a-teammate-after-a-plan-downgrade }

जब प्लान डाउनग्रेड के बाद सीट लोगों से कम रह जाती हैं, तो कुछ अकाउंट बंद कर दिए जाते हैं। उनकी पंक्ति पर सीट आइकन दिखता है, जिसके टूलटिप में **Deactivated by a plan downgrade — no free seat.** लिखा होता है।

1. कोई सीट खाली करें, या अपने प्लान में सीट जोड़ें।
2. उनकी पंक्ति पर पेंसिल आइकन (**Edit**) पर क्लिक करें, फिर **Save** पर क्लिक करें। अकाउंट फिर चालू हो जाता है।

### सदस्य को हटाएँ { #remove-a-teammate }

!!! warning "सदस्य का एक्सेस तुरंत चला जाता है"
    हटाया गया सदस्य अब साइन इन नहीं कर सकता। उसका पुराना काम Ohanvi में बना रहता है।

1. व्यक्ति की पंक्ति पर **Delete** पर क्लिक करें। एक पुष्टि दिखती है।
2. पुष्टि करने के लिए **Delete** पर क्लिक करें।

### User Groups से सदस्यों को समूह में रखें { #group-teammates-with-user-groups }

Super Admin को **Team & access** के तहत **User Group** भी दिखता है। यूज़र ग्रुप में वे लोग रहते हैं जिनका रोल एक जैसा है।

1. **Team & access** के तहत **User Group** पर क्लिक करें। **User Group Management** सूची खुलती है।
2. यह देखने के लिए कि ग्रुप में कौन है, **Users Count** देखें, या ग्रुप खोलें।
3. सदस्य बदलने के लिए ग्रुप एडिट करें, फिर **App Users** में नाम जोड़ें या हटाएँ।
4. सेव पर क्लिक करें [VERIFY: exact save button label in the grid form]।

जब हो सके, रोल **App User** से ही बदलें। ग्रुप हाथ से एडिट करने पर लोग एक रोल से दूसरे में जा सकते हैं।

### अपने ही रोल के बीच स्विच करें { #switch-between-your-own-roles }

अगर आपके पास 1 से ज़्यादा रोल हैं, तो नीचे बाएँ अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Switch role** पर, और रोल चुनें। ऐप उस रोल के एक्सेस के साथ दोबारा लोड होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Add** और **Invite teammate** नहीं दिख रहे | आप Super Admin नहीं हैं, या आपके प्लान की सभी सीट भर चुकी हैं। | वर्कस्पेस के ओनर से कहें, या [बिलिंग सेक्शन](../billing/index.md) में सीट जोड़ें। |
| **Cannot reactivate: the tenant's plan has no free seats (…). Upgrade the plan or add seats first.** | सभी सीट इस्तेमाल में हैं। | किसी को हटाएँ या सीट जोड़ें, फिर दोबारा कोशिश करें। |
| **Email … already exists with user: …** | किसी दूसरे सक्रिय यूज़र के पास यही ईमेल है। | इस सदस्य के लिए दूसरा ईमेल इस्तेमाल करें। |
| **Mobile number … already exists with user: …** | किसी दूसरे यूज़र के पास यही मोबाइल नंबर है। | दूसरा नंबर इस्तेमाल करें। |
| **Delete** ग्रे है और **This account can't be deleted** दिखता है | यह अकाउंट ओनर है। | ओनर का अकाउंट हटाया नहीं जा सकता। |
| **This is the account owner — their role can’t be changed.** | आपने ओनर का अकाउंट खोला है। | इसकी जगह दूसरे सदस्यों के रोल बदलें। |
