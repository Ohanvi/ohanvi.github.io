# Manage { #manage }

Manage में वे सेटिंग्स और लिस्ट हैं जिन पर WhatsApp का बाकी काम टिका है: चैट के नियम, ऑप्ट-इन शब्द, सेव किए हुए जवाब, आपकी टीम, टैग, शेड्यूल, लॉग और बहुत कुछ।

**इसे कहाँ पाएँ:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें।

![Manage स्क्रीन, जिसमें बाईं ओर आइटम की लिस्ट है](../../assets/screenshots/whatsapp-manage-0-overview.png)

## गाइड { #guides }

| गाइड | कब काम आती है |
| --- | --- |
| [Opt-in Management](../manage-opt-in-and-opt-out-words.md) | आप ऐसे शब्द तय करना चाहते हैं जिनसे लोग ऑप्ट-इन या ऑप्ट-आउट हों। |
| [Live Chat Settings](../set-up-live-chat-settings.md) | आपको ऑटो-रिप्लाई, काम के घंटे और हैंडऑफ़ के नियम सेट करने हैं। |
| [Canned Messages](../create-canned-messages.md) | आपको सेव किए हुए जवाब चाहिए, जिन्हें आपकी टीम / दबाकर डाल सके। |
| [Agents](../add-whatsapp-agents.md) | आपको अपनी टीम के लोगों को WhatsApp में जोड़ना है। |
| [Tags, User Attributes and Custom Events](../tags-attributes-and-events.md) | आपको कॉन्टैक्ट्स पर लेबल लगाने हैं या उनकी और जानकारी रखनी है। |
| [Scheduler and Delivery Logs](../scheduler-and-delivery-logs.md) | आपको शेड्यूल किए हुए मैसेज देखने हैं या डिलीवरी जाँचनी है। |
| [Connection Health](../check-connection-health.md) | आपको जानना है कि आपका नंबर ठीक चल रहा है या नहीं। |
| [Integrations](../manage-whatsapp-integrations.md) | आपको दूसरी सर्विस कनेक्ट करनी हैं। |
| [Notification Preferences](../set-notification-preferences.md) | आपको चुनना है कि WhatsApp के किन इवेंट पर आपको नोटिफ़िकेशन मिले। |
| [API Key and Cloud API access](../get-cloud-api-access.md) | आपको अपना नंबर Meta Cloud API से जोड़ने में मदद चाहिए। |
| [Billing and Usage](../read-billing-and-usage.md) | आपको देखना है कि Meta कितना चार्ज करता है। |
| [Health, alerts and billing](../health-notifications-and-billing.md) | आपको सेहत, अलर्ट और बिलिंग की जानकारी एक ही जगह चाहिए। |
| [Media Library](../manage-media-library.md) | आपको देखना है कि आपका अकाउंट कौन-सा मीडिया सेव करता है, या जगह खाली करनी है। |
| [Recycle Bin](../restore-deleted-items.md) | आपने कुछ डिलीट कर दिया और उसे वापस चाहिए। |

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट होना चाहिए। देखें [अपना WhatsApp नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस मिला होना चाहिए। स्क्रीन न दिखे, तो अपने एडमिन से पूछें।
