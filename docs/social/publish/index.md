# Publish

Publish is where posts are created and managed. You can write a post, schedule it, send it for review, and track it after it goes out.

**Where to find it:** open **Social** in the left rail, then select **Publish**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Create and publish a social post](../create-social-post.md) | You want to write a post and send it. |
| [Use the AI Assistant in the composer](../use-ai-assistant-in-the-composer.md) | You want AI to write the caption or find an image. |
| [Schedule posts and manage the queue](../schedule-social-posts.md) | You want to schedule, retry or cancel posts. |
| [Use Publish filters, overview and post details](../use-publish-filters-and-extras.md) | You want to filter, copy a link or see which channel failed. |
| [Review posts before they publish](../approve-social-posts.md) | You approve or send back posts. |

## Before you start

- At least one network is connected. See [Connect social accounts](../connect-social-accounts.md).
