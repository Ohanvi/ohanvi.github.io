# स्टेप टेस्ट करें और सैंपल डेटा पिन करें { #test-a-step-and-pin-sample-data }

किसी एक स्टेप को अकेले चलाएँ और उसका नतीजा रख लें, ताकि आगे के स्टेप उसमें से असली फ़ील्ड चुन सकें।

## शुरू करने से पहले { #before-you-start }

- फ़्लो में एक ट्रिगर और कम से कम एक एक्शन स्टेप हो। देखें [फ़्लो में ऐप का स्टेप जोड़ें](add-an-app-step.md)।
- आप ड्राफ़्ट पर हों। पब्लिश किए हुए वर्शन पर **Open the draft to test a step.** लिखा आता है।
- ऐप के स्टेप के लिए **1 · Account** के नीचे अकाउंट चुना हुआ हो।

## सैंपल कैसे काम करते हैं { #how-samples-work }

- **सैंपल** किसी एक स्टेप का उदाहरण डेटा है: ट्रिगर ने क्या भेजा, या किसी स्टेप ने क्या लौटाया।
- आगे के स्टेप अपनी वैल्यू इन्हीं सैंपल से चुनते हैं, जैसे `{{2.value[0].awb_code}}`।
- सफल टेस्ट का नतीजा उस स्टेप के सैंपल के रूप में पिन हो जाता है। आप उसे एडिट या अनपिन भी कर सकते हैं।
- ट्रिगर का अपना सैंपल होता है, जो **Get sample event** से आता है।

## स्टेप { #steps }

### ट्रिगर के लिए सैंपल इवेंट लाएँ { #get-a-sample-event-for-the-trigger }

1. फ़्लो को एक बार सेव करें। **Sample data** हिस्सा सिर्फ़ सेव किए हुए फ़्लो पर दिखता है।
2. कैनवस की शुरुआत में ट्रिगर पर क्लिक करें। **When this runs** पैनल खुलता है।
3. **Sample data** के नीचे **Get sample event** पर क्लिक करें। Ohanvi एक असली इवेंट लाता है, या ऐप का भेजा हुआ आख़िरी इवेंट।
4. प्रीव्यू पढ़ें। उसमें पहली 5 फ़ील्ड दिखती हैं, फिर **+ N more**।
5. बाद में दोबारा लाना हो, तो **Get a new sample** पर क्लिक करें।

    [SCREENSHOT: When this runs पैनल, जिसमें Sample data, Get a new sample बटन और फ़ील्ड का प्रीव्यू दिख रहा हो]

सैंपल को हाथ से बदलना हो, तो **Edit** पर क्लिक करें। **Edit sample event** में JSON बदलें, फिर **Save sample** पर क्लिक करें। उसे हटाने के लिए **Clear** पर क्लिक करें।

### एक स्टेप टेस्ट करें { #test-one-step }

1. स्टेप चुनें। उसका **Step** पैनल खुलता है।
2. **3 · Test** के नीचे **Test this step** पर क्लिक करें। चलते समय बटन पर **Testing…** लिखा रहता है। बिना नंबर वाले स्टेप में इसकी जगह **Test** दिखता है।
3. कोई बदलाव सेव न हुआ हो, तो पहले ड्राफ़्ट सेव होता है।
4. अगर स्टेप कोई असली काम करता है, तो **Run this step for real?** विंडो बताती है कि वह क्या करेगा। **Run it for real** या **Cancel** पर क्लिक करें।

    [SCREENSHOT: Run this step for real? विंडो, जिसमें Run it for real और Cancel बटन हों]

5. नतीजा पढ़ें। **Worked** के साथ लगा समय दिखता है। **Failed** के साथ लाल बॉक्स में गड़बड़ी दिखती है।
6. **What this step was given** देखने के लिए **Sent** पर क्लिक करें। इसमें हर `{{…}}` की जगह असली वैल्यू भरी होती है।

**Cancel** पर क्लिक करने पर स्टेप में **Not run — nothing was sent.** लिखा आता है।

!!! warning "टेस्ट असली काम करता है"
    **Create an order** जैसे एक्शन को टेस्ट करने पर ऐप में असली ऑर्डर बनता है। टेस्ट अकाउंट या टेस्ट डेटा इस्तेमाल करें।

### सैंपल रखें, एडिट करें या अनपिन करें { #keep-edit-or-unpin-the-sample }

1. सफल टेस्ट के बाद **📌 Pinned sample — later steps map and test against this data** बैनर दिखता है। उसके नीचे नतीजा दिखता है।
2. सैंपल बदलना हो, तो **Edit** पर क्लिक करें। **Edit the pinned sample** विंडो खुलती है।
3. JSON बदलें और **Pin it** पर क्लिक करें। सैंपल एक JSON ऑब्जेक्ट होना चाहिए।
4. सैंपल हटाने के लिए **Unpin** पर क्लिक करें।

    [SCREENSHOT: पिन किए हुए सैंपल का बैनर, जिसमें Edit और Unpin हों और नीचे सैंपल आउटपुट दिख रहा हो]

जब ऐप ने ख़ाली लिस्ट लौटाई हो, या कोई ज़रूरी रिकॉर्ड न हो, तब सैंपल एडिट करें। तब आगे के स्टेप आपके डेटा पर बनते हैं।

टोकन जैसी संवेदनशील वैल्यू छिपी हुई दिख सकती हैं। चलता हुआ फ़्लो फिर भी असली वैल्यू पढ़ता है।

### पिछले डेटा से वैल्यू चुनें { #pick-a-value-from-earlier-data }

1. आगे के किसी स्टेप में फ़ील्ड के बगल का ब्रेसिज़ आइकन दबाएँ। उसका टूलटिप **Use a field from the trigger or an earlier step** है।
2. ग्रुप पढ़ें। सबसे पहले **Trigger** आता है, फिर पिछला हर स्टेप, जैसे **2 · Shiprocket · Assign an AWB**।
3. ग्रुप के बगल का टैग पढ़ें:
    - **pinned:** आपका अपना टेस्ट किया हुआ या पिन किया हुआ डेटा।
    - **example:** ऐप के दस्तावेज़ों में दिया उदाहरण, आपके अकाउंट का डेटा नहीं।
    - **last run:** स्क्रीन पर खुले रन से लिया गया डेटा।
4. अंदर की फ़ील्ड अपनी पैरेंट फ़ील्ड के नीचे थोड़ा खिसककर दिखती हैं। सैंपल वैल्यू दाईं तरफ़ दिखती है।
5. बहुत सारी फ़ील्ड हों, तो **Search fields** में टाइप करें। सबसे ऊपर वाला नतीजा लेने के लिए **Enter** दबाएँ।
6. फ़ील्ड पर क्लिक करें। Ohanvi उसकी वैल्यू बॉक्स में डाल देता है, जैसे `{{2.value[0].awb_code}}`।

    [SCREENSHOT: फ़ील्ड की लिस्ट, जिसमें Trigger ग्रुप, ऐप के लोगो वाला स्टेप ग्रुप, अंदर की फ़ील्ड और सैंपल वैल्यू दिख रही हों]

वैल्यू में दिया नंबर कैनवस पर स्टेप की जगह है। `value[0]` स्टेप का लौटाया हुआ पहला रिकॉर्ड है।

### किसी असली रन का डेटा पिन करें { #pin-the-data-from-a-real-run }

1. फ़्लो का **Latest output** टैब खोलें। देखें [किसी रन का आउटपुट विस्तार से पढ़ें](read-a-runs-output.md)।
2. जो रन चाहिए, उसे खोलें, जैसे **Recent runs** में **View output** से।
3. ऊपर दाईं तरफ़ **Test with this data** पर क्लिक करें। काम होते समय उस पर **Pinning…** लिखा रहता है।
4. मैसेज पढ़ें, जैसे **Pinned 3 steps — later steps now map and test against this run.** जो स्टेप छूट गए, वे **Skipped:** के बाद लिखे होते हैं।

**Test with this data** सिर्फ़ तब दिखता है जब फ़्लो में बिना पब्लिश किए बदलाव हों और रन पूरा हो चुका हो।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Test step 2 · … first, so this step has data to work with.** | पिछले किसी स्टेप का अभी कोई सैंपल नहीं है। | पहले उस स्टेप को टेस्ट करें, या उसके लिए सैंपल पिन करें। |
| **Get a sample event on the trigger first, so this step has data to work with.** | ट्रिगर का कोई सैंपल नहीं है। | ट्रिगर पर **Get sample event** पर क्लिक करें। |
| **Open the draft to test a step.** | आप पब्लिश किया हुआ वर्शन देख रहे हैं। | वर्शन चिप से ड्राफ़्ट खोलें, फिर टेस्ट करें। |
| **The sample must be a JSON object, like { "id": 1 }.** | एडिट किया हुआ सैंपल एक लिस्ट या अकेली वैल्यू है। | उसे नाम वाली फ़ील्ड के साथ `{ }` में लिखें। |
| **example** ग्रुप की कोई फ़ील्ड असली रन में ख़ाली आती है | ऐप के उदाहरण में ऐसी फ़ील्ड है जो आपका अकाउंट नहीं लौटाता। | स्टेप टेस्ट करें, या कोई असली रन पिन करें, फिर फ़ील्ड दोबारा चुनें। |
| **Test with this data** नहीं दिख रहा | फ़्लो में बिना पब्लिश किए बदलाव नहीं हैं, या रन अभी चल रहा है। | फ़्लो में कोई बदलाव सेव करें, या रन पूरा होने तक रुकें। |
| **Change** के बाद ट्रिगर का सैंपल हट गया | दूसरा ऐप या इवेंट अलग फ़ील्ड भेजता है, इसलिए पुराना सैंपल हटा दिया जाता है। | नए ट्रिगर के लिए फिर से **Get sample event** पर क्लिक करें। |
