# अपने स्टेज में Leads आगे बढ़ाएँ { #move-leads-through-your-stages }

Leads अब स्टेज की किसी लिस्ट या बोर्ड पर नहीं बैठतीं, जहाँ आप उन्हें खींचकर ले जाते थे। वे **CRM** → **Leads** में फ़ेज़ और स्टेप के प्लान पर चलती हैं। इस पेज में दिखाया गया है कि हर पुराना काम कहाँ गया और कौन सा चुनाव कौन सा स्टेटस तय करता है।

## हर काम अब कहाँ है { #where-each-task-went }

| पहले आप | अब |
| --- | --- |
| लिस्ट में Lead जोड़ते थे | **Leads** पर **Add lead** पर क्लिक करें। देखें [Leads के साथ काम करें](leads.md)। |
| कार्ड को दूसरे स्टेज में खींचते थे | Lead के चालू स्टेप पर चुनाव करें। देखें [पहली कॉल के बाद फ़ैसला लें](leads.md#decide-after-the-first-call)। |
| Lead को कॉन्टैक्ट और Deal में कन्वर्ट करते थे | **Mark converted** पर क्लिक करें। देखें [Lead को कन्वर्ट करें](leads.md#convert-a-lead)। |
| फ़ाइल से Leads इम्पोर्ट करते थे | **Leads** पर **Import** पर क्लिक करें। देखें [Leads और Deals इम्पोर्ट करें](import-leads-and-deals.md)। |
| **Contacts** से Leads खोलते थे | **CRM** → **Leads** खोलें। पुराना पता `/contacts/leads` भी उसे खोलता है। |

## हर चुनाव क्या सेट करता है { #what-each-choice-sets }

| चुनाव | Lead का स्टेटस |
| --- | --- |
| **In** | Qualified |
| **Out** | Unqualified |
| **Lost: not interested** | Lost |
| **Mark converted** | Converted |

Lead **Converted** तभी होती है जब उसे कन्वर्ट किया जाए। आपके स्टेज और फ़ील्ड, और स्टेज के हिसाब से Leads गिनने वाला फ़नल अब भी काम करते हैं। देखें [स्टेज और फ़ील्ड सेट करें](set-up-stages-and-fields.md) और [फ़नल पढ़ें और बोर्ड पर Leads आगे बढ़ाएँ](read-the-funnel.md)।
