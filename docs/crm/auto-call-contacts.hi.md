# ऑटो कॉलिंग से एक के बाद एक कई संपर्कों को कॉल करें { #call-many-contacts-in-a-row-with-auto-calling }

संपर्कों का एक समूह चुनें और हर बार सूची में लौटे बिना उन्हें एक के बाद एक कॉल करें। अंत में हर कॉल का रिव्यू मौजूद होता है, और आप बीच में रुककर बाद में दोबारा शुरू कर सकते हैं। 10 कॉल के रन में उतना ही समय लगता है जितना कॉलों में लगता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Contacts** दिखता हो और उसके पैनल में **All contacts** हो।
- आपके चुने संपर्कों के पास **Mobile** या **Phone** नंबर हो।
- आपको पता हो कि कॉल रिव्यू कैसे काम करता है। देखें [संपर्कों को कॉल करें और अपनी कॉल की समीक्षा करें](call-contacts-and-review-calls.md)।

## चरण { #steps }

### रन शुरू करें { #start-a-run }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. टॉप बार में **Auto Calling** आइकन पर क्लिक करें।
3. **Search contacts…** में नाम लिखकर सूची छोटी करें।
4. वैकल्पिक: सिर्फ़ आज जिनसे बात करनी है उन्हें देखने के लिए **Today's follow-ups only** पर क्लिक करें।
5. जिन संपर्कों को कॉल करना है, उन पर टिक करें। **N selected** लाइन उनकी गिनती बताती है।
6. **Start Auto Calling** पर क्लिक करें।

विंडो का शीर्षक बदलकर **Auto Calling — 1 of N** हो जाता है। उसमें पहले संपर्क का नाम और नंबर दिखता है।

### हर कॉल करें { #make-each-call }

1. विंडो में संपर्क का नाम और नंबर देखें।
2. कॉल आपके डिवाइस पर शुरू होती है। अगर नहीं होती, तो **Call Again** पर क्लिक करें।
3. संपर्क से बात करें।
4. कॉल खत्म होने पर Ohanvi में वापस आएँ। **Waiting for the call to finish — the Call Review dialog will open automatically once you return to the app.** वाली लाइन हट जाती है और **Call Review** विंडो खुल जाती है।
5. रिव्यू भरें और **Save** पर क्लिक करें। देखें [संपर्कों को कॉल करें और अपनी कॉल की समीक्षा करें](call-contacts-and-review-calls.md)।
6. ऑटो कॉलिंग अगले संपर्क पर चली जाती है। शीर्षक में गिनती बढ़ती है, जैसे **Auto Calling — 2 of 10**।

आखिरी कॉल पूरी होने पर विंडो में **All calls completed.** दिखता है। **Done** पर क्लिक करें।

### रन रोकें { #stop-a-run }

1. कभी भी **Stop Auto Calling** पर क्लिक करें।
2. आपकी प्रगति इसी डिवाइस पर सेव हो जाती है।

### रन फिर से शुरू करें { #resume-a-run }

1. **Auto Calling** आइकन पर दोबारा क्लिक करें।
2. संदेश **You have an unfinished Auto Calling run.** पढ़ें। इसमें दिखता है कि कितने हो चुके हैं, जैसे **4 of 10 done — 6 remaining.**
3. आगे बढ़ने के लिए **Resume (6)** पर क्लिक करें, या पुराना रन छोड़कर फिर से चुनने के लिए **Start New** पर क्लिक करें।

!!! note "ध्यान दें"
    अधूरा रन उसी डिवाइस पर रहता है जहाँ आपने उसे शुरू किया था, और सिर्फ़ करीब एक दिन तक। फिर से शुरू करने के लिए उसी डिवाइस पर ऑटो कॉलिंग खोलें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No contacts match this view.** | सर्च या फ़ॉलो-अप फ़िल्टर से कोई संपर्क नहीं मिल रहा। | सर्च साफ़ करें, या **Today's follow-ups only** बंद करें। |
| विंडो इंतज़ार करती रहती है और कुछ नहीं होता | कॉल शुरू नहीं हुई। | **Call Again** पर क्लिक करें। |
| **Resume** का विकल्प नहीं दिख रहा | पुराना रन एक दिन पुराना हो गया है, या वह दूसरे डिवाइस पर था। | **Start Auto Calling** पर क्लिक करें और दोबारा चुनें। |
