# टास्क प्रोजेक्ट सेट करें { #set-up-a-task-project }

वह प्रोजेक्ट बनाएँ जिसमें आपके टास्क रहेंगे, उसका बोर्ड खोलें, और उन टीम के सदस्यों को जोड़ें जो उस पर काम करेंगे। अंत में आपकी टीम के पास एक साझा बोर्ड होगा जिस पर आपके जोड़े हुए किसी भी व्यक्ति को टास्क असाइन किए जा सकते हैं, और हर टास्क को प्रोजेक्ट के key से बना एक key मिलेगा, जैसे OHANVI-1।

## शुरू करने से पहले { #before-you-start }

- आपको दाईं ओर के रेल में, नोटिफ़िकेशन की घंटी के बगल में, **Tasks** आइकन (टिक वाला बॉक्स) दिखता हो। न दिखे तो अपने एडमिन से कहें कि आपके रोल को Task का एक्सेस दें। देखें [सेटिंग्स का अवलोकन](../settings/index.md)।
- आपकी टीम के सदस्यों के पास पहले से Ohanvi लॉगिन हों। आप सिर्फ़ उन्हीं लोगों को जोड़ सकते हैं जो आपके वर्कस्पेस में यूज़र हैं।

## चरण { #steps }

### Tasks पैनल से अपना पहला प्रोजेक्ट बनाएँ { #create-your-first-project-from-the-tasks-panel }

1. दाईं ओर के रेल में **Tasks** पर क्लिक करें। **Tasks** पैनल पेज के बगल में खुलता है।
2. अगर आपके वर्कस्पेस में अभी कोई प्रोजेक्ट नहीं है, तो पैनल में **Set up your tasks** दिखता है। बॉक्स में प्रोजेक्ट का नाम लिखें, जैसे आपकी कंपनी का नाम।
3. **Create project** पर क्लिक करें। पैनल आपकी टास्क सूची पर बदल जाता है, जिसके ऊपर **Create** और **Board** होते हैं।

Ohanvi नाम के अक्षरों से प्रोजेक्ट का key बनाता है, उन्हें बड़े अक्षरों में करके और 6 अक्षरों पर काटकर। जैसे "Ohanvi" से OHANVI बनता है। जिस नाम में कोई अक्षर न हो, उसे key TASK मिलता है।

### बोर्ड से दूसरा प्रोजेक्ट बनाएँ { #create-another-project-from-the-board }

1. **Tasks** पैनल में **Board** पर क्लिक करें। पूरा टास्क बोर्ड खुलता है।
2. बाएँ पैनल में **Task** के नीचे **Create project** पर क्लिक करें। **Create ticket project** डायलॉग खुलता है।
3. **Uniq key** में प्रोजेक्ट का छोटा key लिखें, जैसे SALES। key अधिकतम 10 अक्षर का हो सकता है।
4. **Name** में प्रोजेक्ट का डिस्प्ले नाम लिखें।
5. वैकल्पिक: **Description** में बताएँ कि प्रोजेक्ट किस काम आता है।
6. **Create project** पर क्लिक करें। नया प्रोजेक्ट बोर्ड पर खुलता है।

प्रोजेक्ट बदलने के लिए, बाएँ पैनल में **Task** के नीचे किसी प्रोजेक्ट के नाम पर क्लिक करें। हर प्रोजेक्ट की पंक्ति में उसका नाम और key दिखता है।

### अपने पहले कॉलम जोड़ें { #add-your-first-columns }

नए प्रोजेक्ट के बोर्ड पर अभी कोई कॉलम नहीं होता। कॉलम वे स्टेटस हैं जिनसे होकर टास्क गुज़रता है, जैसे To Do, In Progress और Done।

1. बोर्ड पर, बोर्ड के दाएँ सिरे पर **+** बटन (टूलटिप **Add column**) पर क्लिक करें।
2. **Column name** में कॉलम का नाम लिखें, फिर **Save** (टिक) पर क्लिक करें।
3. आपको जितने स्टेटस चाहिए, उतनी बार यही दोहराएँ। कॉलम उसी क्रम में बाएँ से दाएँ दिखते हैं जिसमें आप उन्हें जोड़ते हैं।

कॉलम का नाम बदलने, क्रम बदलने या हटाने के लिए बाद में देखें [बोर्ड पर टास्क इधर-उधर करें](move-tasks-on-board.md)।

### प्रोजेक्ट में मेंबर जोड़ें { #add-members-to-the-project }

असाइनी की सूची में सिर्फ़ प्रोजेक्ट के मेंबर दिखते हैं, इसलिए उन सभी को जोड़ें जिनके पास टास्क होंगे।

1. बोर्ड पर, टूलबार में **Add members** पर क्लिक करें। **Add people** डायलॉग खुलता है।
2. **Available people** के नीचे **Search by name…** में टाइप करें और जिन्हें जोड़ना है उन पर टिक करें।
3. **Selected Members & Roles** के नीचे हर व्यक्ति के लिए रोल चुनें: **Admin**, **Member** या **Viewer**। नए लोग **Member** से शुरू होते हैं।
4. **Add** पर क्लिक करें। **Members added successfully.** मैसेज दिखता है।

किसी को हटाने के लिए, **Add members** दोबारा खोलें और **Selected Members & Roles** के नीचे उनके नाम के बगल में लाल बिन आइकन पर क्लिक करें। **Member removed successfully.** मैसेज दिखता है।

### प्रोजेक्ट एडिट करें { #edit-the-project }

1. बोर्ड पर **Edit project** पर क्लिक करें। **Edit ticket project** डायलॉग खुलता है।
2. **Name** या **Description** बदलें। **Project key** बनाने के बाद बदली नहीं जा सकती।
3. **Update project** पर क्लिक करें।

### प्रोजेक्ट डिलीट करें { #delete-the-project }

!!! warning "प्रोजेक्ट डिलीट करना वापस नहीं किया जा सकता"
    **Delete project** प्रोजेक्ट को बोर्ड से हमेशा के लिए डिलीट कर देता है। डिलीट करने से पहले अपनी टीम से पूछ लें।

1. बोर्ड पर **Edit project** पर क्लिक करें।
2. **Delete project** पर क्लिक करें। **Delete ticket project?** डायलॉग खुलता है।
3. **Delete** पर क्लिक करें।

| --- | --- | --- |
| दाईं ओर के रेल में **Tasks** आइकन नहीं है | आपके रोल को Task मॉड्यूल का एक्सेस नहीं है। | अपने एडमिन से कहें कि आपके रोल को Task का एक्सेस दें। |
| **Enter a project name.** | आपने खाली नाम के साथ **Create project** पर क्लिक किया। | नाम लिखें, फिर **Create project** पर दोबारा क्लिक करें। |
| पैनल में **Could not create the project. Please try again.** | इस नाम से बना key कोई और प्रोजेक्ट पहले से इस्तेमाल कर रहा है, या नेटवर्क चला गया। | कोई दूसरा नाम आज़माएँ, या बोर्ड से अपनी **Uniq key** के साथ प्रोजेक्ट बनाएँ। |
| बोर्ड डायलॉग में **Could not create ticket project.** | **Uniq key** पहले से इस्तेमाल में है, या 10 अक्षर से लंबी है। | छोटा key इस्तेमाल करें जिसे कोई और प्रोजेक्ट इस्तेमाल न करता हो। |
| **Add people** में **No people found** | वह व्यक्ति आपके वर्कस्पेस में यूज़र नहीं है, या सर्च मेल नहीं खा रही। | स्पेलिंग जाँचें, या अपने एडमिन से कहें कि पहले उस व्यक्ति को यूज़र के रूप में जोड़ें। |
| **Failed to add members.** | सेव सर्वर तक नहीं पहुँचा। | **Add** पर दोबारा क्लिक करें। फिर भी फ़ेल हो तो पेज रीफ़्रेश करके दोबारा कोशिश करें। |
