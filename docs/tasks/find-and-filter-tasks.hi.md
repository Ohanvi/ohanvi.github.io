# टास्क खोजें, फ़िल्टर करें और देखें { #find-filter-and-view-tasks }

किसी भी स्क्रीन से वे काम ढूँढें जो अभी आपके लिए ज़रूरी हैं। पूरे प्रोजेक्ट को उसी व्यू में देखें जो आपके सवाल के हिसाब से ठीक हो। इसके बाद आप देख पाएँगे कि आज क्या-क्या ड्यू है। आप बोर्ड को किसी एक व्यक्ति, टाइप या प्रायोरिटी तक सीमित कर पाएँगे, और प्रोजेक्ट की प्रगति एक नज़र में समझ पाएँगे।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में टास्क प्रोजेक्ट हो और उसमें टास्क हों। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।

## स्टेप { #steps }

### Tasks पैनल में अपने टास्क देखें { #see-your-own-tasks-in-the-tasks-panel }

**Tasks** पैनल हर स्क्रीन पर चलता है। इसलिए जो काम आप कर रहे हैं, उसे छोड़े बिना अपने टास्क देख सकते हैं।

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें। **Tasks** पैनल खुलेगा।
2. लिस्ट के ऊपर से एक टैब चुनें:

    | टैब | क्या दिखाता है |
    | --- | --- |
    | **Today** | वे टास्क जिनकी ड्यू डेट आज है, या जो आज आपको असाइन हुए हैं। आज ड्यू होने वाले टास्क सबसे ऊपर आते हैं। |
    | **Assigned to me** | हर वह टास्क जिसके असाइनी आप हैं। |
    | **Created by me** | हर वह टास्क जो आपने रिपोर्ट किया है। |

3. हर पंक्ति के टैग पढ़ें: **Due today** (एम्बर) या **Overdue** (लाल)।
4. टास्क खोलने के लिए पंक्ति पर क्लिक करें। या समरी के नीचे ड्रॉपडाउन से उसका स्टेटस बदलें।

पैनल बंद करने के लिए दाईं रेल में दोबारा **Tasks** पर क्लिक करें, या Esc दबाएँ।

### Tasks पैनल को स्टेटस से फ़िल्टर करें { #filter-the-tasks-panel-by-status }

1. **Tasks** पैनल में टैब के दाएँ छोर पर फ़िल्टर आइकन पर क्लिक करें (टूलटिप **Filter by status**)।
2. **Filter by status** में जो स्टेटस देखने हैं, उन पर टिक करें।
3. **Done** पर क्लिक करें। जब तक फ़िल्टर चालू है, फ़िल्टर आइकन हाइलाइट रहेगा।

सारे स्टेटस फिर से देखने के लिए फ़िल्टर खोलें और **Clear** पर क्लिक करें।

### बोर्ड खोजें { #search-the-board }

1. **Tasks** पैनल में **Board** पर क्लिक करें। बोर्ड उसी प्रोजेक्ट पर खुलेगा।
2. **Search board** में टाइप करें। बोर्ड पर सिर्फ़ वे टास्क रहेंगे जिनके कोड (key) या समरी में आपका टेक्स्ट है।
3. सारे टास्क फिर से देखने के लिए क्रॉस पर क्लिक करें (टूलटिप **Clear search**)।

सीधे किसी टास्क पर जाना हो, तो टास्क कोड (key) लिखें, जैसे OHANVI-12।

### बोर्ड को टाइप, प्रायोरिटी या व्यक्ति से फ़िल्टर करें { #filter-the-board-by-type-priority-or-person }

- **Type:** **Type** पर क्लिक करें और **Epic**, **Story**, **Task**, **Bug** या **Sub-task** पर टिक करें।
- **Priority:** **Priority** पर क्लिक करें और **Highest**, **High**, **Medium**, **Low** और **Lowest** में से एक या ज़्यादा पर टिक करें।
- **Person:** किसी एक मेंबर के टास्क देखने के लिए टूलबार के दाएँ छोर पर उसके अवतार पर क्लिक करें। जिन टास्क का कोई ओनर नहीं है, उनके लिए **Unassigned** पर क्लिक करें। और लोग जोड़ने के लिए दूसरे अवतार पर क्लिक करें, या पूरी लिस्ट के लिए **More people** पर क्लिक करें।

फ़िल्टर एक साथ काम करते हैं। जैसे, **Bug** के साथ **Highest** और एक व्यक्ति चुनने पर उस व्यक्ति के सबसे ज़रूरी बग दिखेंगे। चुना हुआ विकल्प हटाने के लिए उस पर दोबारा क्लिक करें।

जब कोई फ़िल्टर **Filtered by epic** दिखाए, तो epic फ़िल्टर हटाने के लिए उस पर क्लिक करें।

### बोर्ड को स्विमलेन में ग्रुप करें { #group-the-board-into-swimlanes }

1. **Group** पर क्लिक करें (टूलटिप **Group by (swimlanes)**)।
2. **Assignee** या **Epic** चुनें। बोर्ड हर व्यक्ति या हर epic की अलग पंक्ति में बँट जाएगा। जिन टास्क में ये नहीं होते, वे **Unassigned** या **No epic** में जाते हैं।
3. पहले वाले एक ही बोर्ड पर लौटने के लिए **No swimlanes** चुनें।

### बोर्ड का व्यू बदलें { #switch-the-board-view }

बोर्ड के ऊपर के स्विचर से एक व्यू चुनें:

| व्यू | कब इस्तेमाल करें |
| --- | --- |
| **Summary** | प्रोजेक्ट को एक नज़र में देखना हो: **Status overview**, **Priority breakdown**, **Types of work**, **Team workload**, **Epic progress** और **Recent activity**। देखें [बोर्ड का Summary पढ़ें](read-the-board-summary.md)। |
| **Timeline** | टास्क को शुरू और ड्यू डेट के हिसाब से कैलेंडर पर देखना हो। स्केल **Weeks**, **Months** या **Quarters** से बदलें, और आज पर जाने के लिए **Today** पर क्लिक करें। देखें [Timeline का इस्तेमाल करें](use-the-timeline.md)। |
| **Backlog** | काम को स्प्रिंट में बाँटकर प्लान करना हो। देखें [बैकलॉग के टास्क संभालें](work-with-the-backlog.md) और [स्प्रिंट में काम की योजना बनाएँ](plan-sprints.md)। |
| **Board** | कार्ड को स्टेटस कॉलम के बीच खिसकाना हो। देखें [बोर्ड पर टास्क खिसकाएँ](move-tasks-on-board.md)। |
| **List** | टास्क को **Work**, **Assignee**, **Reporter**, **Priority**, **Status**, **Created**, **Updated** और **Due date** वाली टेबल में देखना हो, या कई टास्क एक साथ बदलने हों। देखें [List व्यू का इस्तेमाल करें](use-the-list-view.md)। |

**Timeline** में सिर्फ़ वे टास्क दिखते हैं जिनकी शुरू या ड्यू डेट डाली गई है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing due or assigned today.** | आज कोई टास्क ड्यू नहीं है और आज किसी ने आपको कोई टास्क असाइन नहीं किया। | अपने सारे टास्क देखने के लिए **Assigned to me** खोलें। |
| **No tasks are assigned to you.** | किसी भी टास्क में असाइनी की जगह आपका नाम नहीं है। | **Created by me** देखें, या टास्क के ओनर से कहें कि वह आपको असाइन करे। |
| **Could not load your tasks.** | लिस्ट लोड नहीं हुई। | **Retry** पर क्लिक करें। |
| **Could not identify the signed-in user.** | आपका सेशन अधूरा है। | साइन आउट करके दोबारा साइन इन करें। देखें [Ohanvi में साइन इन करें](../sign-in.md)। |
| हर कॉलम में **No matching tasks** | कोई सर्च या फ़िल्टर सारे टास्क छिपा रहा है। | **Search board** खाली करें और **Type**, **Priority** व व्यक्ति के फ़िल्टर से टिक हटाएँ। |
| व्यक्ति के फ़िल्टर में **No members assigned to this project.** | प्रोजेक्ट में अभी कोई मेंबर नहीं है। | बोर्ड पर **Add members** पर क्लिक करें। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)। |
