# Google रिव्यू का जवाब दें { #reply-to-google-reviews }

आपकी Google लिस्टिंग के रिव्यू Ohanvi में सिंक होते हैं। आप सार्वजनिक जवाब दे सकते हैं, जवाब बदल या डिलीट कर सकते हैं, और निजी नोट के साथ किसी रिव्यू को फ़ॉलो-अप के लिए चिह्नित कर सकते हैं। इसमें लगभग 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- Google Business कनेक्ट हो। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
- आपको लेफ़्ट रेल में **Social** दिखता हो। रिव्यू Google से बैकग्राउंड में सिंक होते हैं, इसलिए नए रिव्यू को दिखने में थोड़ा समय लग सकता है।

## चरण { #steps }

### रिव्यू खोलें { #open-the-reviews }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Home** चुनें।
2. **NEEDS ATTENTION** के नीचे **Google reviews** ढूँढें और **Reply →** पर क्लिक करें। रिव्यू का पेज खुलता है।
3. पेज के ऊपर रिव्यू की संख्या दिखती है, जैसे **12 review(s)**।

### रिव्यू फ़िल्टर करें { #filter-the-reviews }

1. रेटिंग की सूची खोलें। वह **All ratings** पर शुरू होती है।
2. **1 star**, **2 stars**, **3 stars**, **4 stars** या **5 stars** चुनें।
3. जिन रिव्यू का आपने जवाब नहीं दिया, उन्हें देखने के लिए **Unreplied only** चालू करें।
4. ताज़ा रिव्यू सिंक करने के लिए रीफ़्रेश आइकन पर क्लिक करें।
5. सूची में आगे-पीछे जाने के लिए तीरों (**Previous page** और **Next page**) का इस्तेमाल करें। **Page N of M** पंक्ति बताती है कि आप कहाँ हैं।

अगर फ़िल्टर सब कुछ छिपा दें, तो पेज **No reviews match these filters** कहता है। सभी रिव्यू फिर से देखने के लिए **Clear filters** पर क्लिक करें।

अगर अभी कुछ सिंक नहीं हुआ है, तो वह **No reviews synced yet** कहता है। **Go to dashboard** पर क्लिक करें, जो **Insights** खोलता है, और पेज हेडर में **Sync from Google** पर क्लिक करें। Google कनेक्ट न होने पर यह बटन बंद रहता है।

### रिव्यू का जवाब दें { #reply-to-a-review }

1. किसी रिव्यू पर **Reply** पर क्लिक करें। **Reply to …** विंडो खुलती है। उसमें रिव्यू का टेक्स्ट दिखता है।
2. **Public reply** में अपना जवाब लिखें।
3. सेव किए हुए टेक्स्ट से शुरू करने के लिए **Insert template** में से एक चुनें।
4. सुझाया हुआ जवाब पाने के लिए **Suggest reply** पर क्लिक करें। भेजने से पहले उसे एडिट करें।
5. **Send Reply** पर क्लिक करें। **Reply posted to Google** संदेश आता है।
6. **Posted publicly on Google.** पंक्ति पढ़ें। आपका जवाब सबको दिखता है।

अगर बॉक्स खाली है, तो वह **Reply text is required** कहता है।

### जवाब बदलें { #change-a-reply }

1. अपने जवाब के नीचे **Edit** पर क्लिक करें।
2. टेक्स्ट बदलें।
3. **Update Reply** पर क्लिक करें।

### जवाब डिलीट करें { #delete-a-reply }

1. अपने जवाब के नीचे **Delete** पर क्लिक करें। **Delete reply?** विंडो खुलती है।
2. **Delete** पर क्लिक करें। **Reply deleted** संदेश आता है।

!!! warning "इसे वापस नहीं किया जा सकता"
    डिलीट करने से आपका सार्वजनिक जवाब Google से हट जाता है।

### रिव्यू को फ़ॉलो-अप के लिए चिह्नित करें { #mark-a-review-for-follow-up }

1. किसी रिव्यू पर फ़्लैग आइकन (**Flag for follow-up**) पर क्लिक करें।
2. व्यक्ति वाले आइकन (**Assign / note**) पर क्लिक करें। **Assign / internal note** विंडो खुलती है।
3. **Assigned to** में टीम के सदस्य का नाम लिखें।
4. **Internal note** में एक नोट लिखें। आपकी टीम के बाहर कोई इसे नहीं देख सकता, और यह Google पर नहीं दिखता।
5. **Save** पर क्लिक करें।
6. रिव्यू पर अब **Assigned:** और **Note:** पंक्तियाँ दिखती हैं।
