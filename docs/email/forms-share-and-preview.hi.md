# फ़ॉर्म का प्रीव्यू देखें और शेयर करें { #preview-and-share-a-form }

प्रीव्यू में वही दिखता है जो ग्राहक देखता है। शेयर करने से फ़ॉर्म बाहर भेजा जाता है। अंत में लोग आपका फ़ॉर्म खोल और सबमिट कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपके फ़ॉर्म में कम से कम 1 सवाल हो। देखें [फ़ॉर्म बनाएँ](forms-build-a-form.md)।

## चरण { #steps }

### प्रीव्यू { #preview }

1. फ़ॉर्म खोलें और **Preview** पर क्लिक करें।
2. उसे भरें। पेज पर लिखा होता है **Preview only — submitting here records nothing**।
3. फिर से शुरू करने के लिए **Preview again** पर क्लिक करें। ज़रूरी सवालों पर **\* Indicates required question** का निशान होता है।

### लिंक या QR से शेयर करें { #share-by-link-or-qr }

1. **Share link and QR** पर क्लिक करें। **Share this form** खुलता है।
2. लिंक कॉपी करें, या **Download QR** पर क्लिक करें।
3. जब तक फ़ॉर्म **Active** है, इस लिंक वाला कोई भी व्यक्ति उसे खोलकर सबमिट कर सकता है।
4. जल्दी कॉपी करने के लिए टॉप बार में **Copy link** पर क्लिक करें।

### एम्बेड करें या चैट में इस्तेमाल करें { #embed-or-use-in-chat }

1. **More** मेन्यू खोलें।
2. **Embed HTML** पर क्लिक करें। इसमें **Embed snippet copied** दिखता है। उसे अपने पेज में पेस्ट करें।
3. इस फ़ॉर्म को चैटबॉट फ़्लो के अंदर पूछने के लिए **Use in your flow** पर क्लिक करें।
4. **Publish to WhatsApp** पर क्लिक करें, या एडिट करने के बाद **Republish to WhatsApp** पर।

### फ़ॉर्म को रोकें या बंद करें { #pause-or-retire-a-form }

1. **More** में, लिंक का खुलना रोकने के लिए **Pause** पर क्लिक करें।
2. फ़ॉर्म छिपाने के लिए **Archive** पर क्लिक करें, या हटाने के लिए **Delete** पर।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| लिंक कहता है कि फ़ॉर्म बंद है। | वह रोका हुआ है या ड्राफ़्ट है। | **Status** को **Active** करें। |
| प्रीव्यू के जवाब Responses में नहीं हैं। | प्रीव्यू कभी कुछ रिकॉर्ड नहीं करता। | टेस्ट करने के लिए असली लिंक से सबमिट करें। |
