# टाइमलाइन का इस्तेमाल करें { #use-the-timeline }

**Timeline** आपके टास्क को शुरू की तारीख से ड्यू डेट तक कैलेंडर पर बार के रूप में दिखाती है। इससे आप देख सकते हैं कि कौन-से काम एक-दूसरे पर चढ़ रहे हैं, कौन-से देर से चल रहे हैं, और पैरेंट टास्क व उनके चाइल्ड टास्क कैसे जुड़े हैं। यहाँ आप सिर्फ़ देख सकते हैं। टास्क में बदलाव कहीं और करना होता है।

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल पाते हों। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- आपके टास्क में शुरू की तारीख या ड्यू डेट डली हो। जिस टास्क में दोनों नहीं हैं, वह यहाँ नहीं दिखता। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

## स्टेप { #steps }

### Timeline खोलें { #open-the-timeline }

1. दाईं रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. ऊपर व्यू स्विचर में **Timeline** पर क्लिक करें।
3. अगर पेज पर **No work items yet. Create tickets (and set a start / due date)** लिखा है, तो पहले अपने टास्क में तारीखें डालें।
4. अगर **No project selected** लिखा है, तो बोर्ड हेडर से कोई प्रोजेक्ट चुनें।

### समय का स्केल बदलें { #change-the-time-scale }

1. Timeline के ऊपर दाईं ओर के बटन देखें।
2. **Weeks**, **Months** या **Quarters** पर क्लिक करें। हेडर और बार नए स्केल के हिसाब से दोबारा बन जाते हैं।
3. आज की तारीख तक जाने के लिए **Today** पर क्लिक करें। तारीख वाले हेडर में आज की तारीख पर निशान लगा होता है।

### पंक्ति पढ़ें { #read-a-row }

1. बाईं ओर का **Work** कॉलम पढ़ें। हर पंक्ति एक टास्क है।
2. दाईं ओर बार ढूँढें। यह टास्क की शुरू की तारीख से उसकी ड्यू डेट तक चलता है।
3. बार का रंग देखें। यह टास्क के स्टेटस के साथ बदलता है।
4. बार की शुरू और खत्म की तारीख देखने के लिए उस पर माउस ले जाएँ।
5. पैरेंट पंक्ति पर गिनती पढ़ें, जैसे **Done: 2 of 5**। इससे पता चलता है कि कितने चाइल्ड टास्क पूरे हो चुके हैं।

### पैरेंट टास्क खोलें और बंद करें { #expand-and-collapse-parent-tasks }

1. ऐसी पंक्ति ढूँढें जिसके चाइल्ड टास्क हैं। उस पर तीर बना होता है।
2. उसके नीचे चाइल्ड टास्क दिखाने के लिए तीर पर क्लिक करें। तीर की टूलटिप **Expand** दिखती है।
3. उन्हें छिपाने के लिए तीर पर दोबारा क्लिक करें। टूलटिप में **Collapse** लिखा होता है।

### पंक्तियाँ चुनें { #select-rows }

1. किसी टास्क को चुनने के लिए पंक्ति की शुरुआत के बॉक्स पर टिक करें।
2. आप देखेंगे कि उसके चाइल्ड पर भी अपने-आप टिक लग जाता है, और उनके बॉक्स लॉक हो जाते हैं।
3. पूरे ग्रुप का चुनाव हटाने के लिए पैरेंट का टिक हटाएँ।

### Work कॉलम को चौड़ा करें { #widen-the-work-column }

1. **Work** कॉलम और कैलेंडर के बीच की रेखा पर पॉइंटर ले जाएँ।
2. जब पॉइंटर बाएँ-दाएँ तीर में बदल जाए, तो रेखा को खींचें।
3. कॉलम जब मनचाही चौड़ाई का हो जाए, तो छोड़ दें। चौड़ाई 200 से 800 पिक्सल के बीच रहती है।

### पंक्ति से चाइल्ड टास्क शुरू करें { #start-a-child-task-from-a-row }

1. टॉप-लेवल टास्क की पंक्ति पर माउस ले जाएँ। उसके दाईं ओर दो छोटे बटन दिखेंगे।
2. **+** बटन पर क्लिक करें। उसकी टूलटिप **Create child work item** है। टास्क के नीचे नई पंक्ति खुलेगी।
3. टाइप चुनने के लिए टाइप बटन पर क्लिक करें, जिसकी टूलटिप **Select issue type** है। पहले से Story चुनी होती है।
4. **What needs to be done?** में टाइटल लिखें।
5. पंक्ति के आखिर में व्यक्ति वाले बटन से असाइनी चुनें।
6. पंक्ति में सेव बटन नहीं है, और **Enter** दबाने से टास्क नहीं बनता। अभी के लिए चाइल्ड टास्क बोर्ड से बनाएँ।

### More actions मेन्यू खोलें { #open-the-more-actions-menu }

1. पंक्ति पर माउस ले जाएँ और **...** बटन पर क्लिक करें। उसकी टूलटिप **More actions** है।
2. मेन्यू पढ़ें: **Create work item**, **Move work item**, **Change work item color**, **Edit dates** और **Edit dependencies**।
3. अभी इनमें से किसी आइटम को चुनने पर कुछ नहीं होता। तारीखें और पैरेंट बदलने के लिए टास्क खोलें।

!!! note "Timeline सिर्फ़ देखने के लिए है"
    तारीखें बदलने के लिए आप बार को खींच नहीं सकते। टास्क खोलें और वहाँ **Start date** और **Due date** बदलें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No work items yet. Create tickets (and set a start / due date)** | किसी भी टास्क में शुरू की तारीख या ड्यू डेट नहीं है। | कोई टास्क खोलें और उसकी तारीखें सेट करें। |
| **No project selected** | बोर्ड पर कोई प्रोजेक्ट खुला नहीं है। | बोर्ड हेडर में कोई प्रोजेक्ट चुनें। |
| **Failed to load timeline** | Timeline लोड नहीं हो पाई। | किसी दूसरे व्यू पर जाकर वापस आएँ, या पेज रीलोड करें। |
| Timeline में कोई टास्क नहीं दिख रहा। | उसमें न शुरू की तारीख है, न ड्यू डेट। | टास्क में कोई तारीख डालें। |
| **More actions** मेन्यू कुछ नहीं करता। | मेन्यू के आइटम अभी चालू नहीं हैं। | टास्क को उसकी डिटेल विंडो से एडिट करें। |
