# मैनेज करें { #manage }

Manage वह हब है जहाँ से आप ईमेल भेजने की सारी सेटिंग्स संभालते हैं।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [शेड्यूलर](../use-the-email-scheduler.md) | जब आप कैलेंडर पर ईमेल भेजने की प्लानिंग करते हों। |
| [बिज़नेस की छुट्टियाँ (Business Holidays)](../manage-business-holidays.md) | जब आपको कुछ दिनों में कोई ईमेल नहीं भेजना हो। |
| [भेजने वाले की पहचान (Sender Identities)](../set-up-sender-identity.md) | जब आप भेजने वाले का पता सेट करते हों। |
| [ईमेल भेजने वाला सर्वर (Email Sending Server)](../connect-email-provider.md) | जब आप अपना प्रोवाइडर कनेक्ट करते हों। |
| [भेजने के लॉग (Send Logs)](../read-send-logs.md) | जब आप हर पाने वाले का हाल जाँचते हों। |
| [सप्रेशन लिस्ट (Suppression List)](../use-the-suppression-list.md) | जब आप कुछ पते ब्लॉक करते हों। |
| [विषय (Topics)](../manage-email-topics.md) | जब आप ईमेल को विषय के हिसाब से ग्रुप में रखते हों। |

## शुरू करने से पहले { #before-you-start }

- आपके पास ऐसा एडमिन रोल हो जो **Manage** देख सकता हो।
