# हाल के कॉन्टैक्ट पर वापस जाएँ { #jump-back-to-recent-contacts }

जिन लोगों के साथ आपने अभी-अभी काम किया था, उन्हें एक छोटी लिस्ट से खोलें। बस दो क्लिक में आप उनके रिकॉर्ड पर वापस पहुँच जाएँगे। यह लिस्ट आपके अपने डिवाइस पर सेव रहती है, इसलिए यह सिर्फ़ आपको दिखती है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Contacts** दिखे और उसके पैनल में **All contacts** हो।
- आपने इस डिवाइस से कम से कम एक कॉन्टैक्ट खोला हो या उसे कॉल किया हो।

## स्टेप { #steps }

### लिस्ट खोलें { #open-the-list }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. ऊपर की बार में **Recent Contacts** आइकन पर क्लिक करें।
3. लिस्ट देखें। हर लाइन में कॉन्टैक्ट का नाम होता है और उसके नीचे एक और लाइन। जिस कॉन्टैक्ट का नाम नहीं है, उसके लिए **Unnamed contact** दिखता है।

### लिस्ट से कोई कॉन्टैक्ट खोलें { #open-a-contact-from-the-list }

1. **Recent Contacts** में किसी नाम पर क्लिक करें।
2. विंडो बंद हो जाएगी और उस कॉन्टैक्ट का ओवरव्यू खुल जाएगा।

### लिस्ट बंद करें { #close-the-list }

1. **Close** पर क्लिक करें।

### कॉन्टैक्ट लिस्ट में कैसे जुड़ता है { #what-adds-a-contact-to-the-list }

- ग्रिड में कोई कॉन्टैक्ट खोलने पर वह लिस्ट में जुड़ जाता है।
- किसी कॉन्टैक्ट को कॉल करने पर भी वह लिस्ट में जुड़ जाता है। देखें [कॉन्टैक्ट को कॉल करें और कॉल रिव्यू करें](call-contacts-and-review-calls.md)।

लिस्ट खाली हो, तो विंडो में **No recent contacts yet.** लिखा होता है। कोई कॉन्टैक्ट खोलें या कॉल करें, वह यहाँ दिखने लगेगा।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No recent contacts yet.** | आपने इस डिवाइस से अभी किसी को खोला या कॉल नहीं किया है। | कोई कॉन्टैक्ट खोलें, फिर लिस्ट दोबारा देखें। |
| दूसरे कंप्यूटर पर लिस्ट अलग है | लिस्ट हर डिवाइस पर अलग रहती है। | वही डिवाइस इस्तेमाल करें, या कॉन्टैक्ट को सर्च करें। |
| कोई कॉन्टैक्ट अब नहीं खुलता | वह कॉन्टैक्ट डिलीट या मर्ज हो चुका है। | **All contacts** में सर्च करें। देखें [कॉन्टैक्ट मैनेज करें](manage-contacts.md)। |
