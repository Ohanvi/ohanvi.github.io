# बोर्ड पर टास्क आगे बढ़ाएँ { #move-tasks-across-the-board }

काम बढ़ने के साथ टास्क को अपने वर्कफ़्लो में आगे बढ़ाएँ, और बोर्ड के कॉलम को इस तरह ढालें कि वे आपकी टीम के काम करने के तरीके से मेल खाएँ। अंत में हर टास्क उस कॉलम में होगा जो उसके असली स्टेटस से मेल खाता है, और प्रोजेक्ट के सभी लोग वही कॉलम उसी क्रम में देखेंगे।

## शुरू करने से पहले { #before-you-start }

- आपके प्रोजेक्ट में कॉलम वाला बोर्ड है। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- बोर्ड पर आपके कम से कम 1 टास्क है। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

## चरण { #steps }

### टास्क को नए कॉलम में ड्रैग करें { #drag-a-task-to-a-new-column }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें। बोर्ड **Board** व्यू में खुलता है।
2. एक कॉलम से टास्क कार्ड को ड्रैग करें और दूसरे कॉलम पर छोड़ें। खाली कॉलम में **Drop tasks here** दिखता है।
3. कार्ड खिसक जाता है, और बदलाव टास्क की हिस्ट्री में सेव हो जाता है।

अगर लक्ष्य कॉलम में काम की सीमा (work-in-progress limit) है और वह भरा है, तो **WIP limit reached** डायलॉग खुलता है। टास्क को फिर भी ले जाने के लिए **Move anyway** पर क्लिक करें, या उसे जहाँ था वहीं रखने के लिए **Cancel** पर।

### बिना ड्रैग किए स्टेटस बदलें { #change-the-status-without-dragging }

जो सबसे पास हो, उनमें से कोई भी तरीका इस्तेमाल करें:

- **कार्ड पर:** कार्ड के **…** मेन्यू पर क्लिक करें, **Change status** पर पॉइंट करें, और कोई कॉलम चुनें।
- **टास्क डायलॉग में:** टास्क खोलें और दाईं ओर के पैनल में सबसे ऊपर के ड्रॉपडाउन से स्टेटस चुनें। **Save** पर क्लिक करें।
- **Tasks पैनल में:** दाईं ओर की रेल में **Tasks** पर क्लिक करें और टास्क के सारांश के नीचे के ड्रॉपडाउन से स्टेटस चुनें। बदलाव तुरंत सेव हो जाता है।

### एक साथ कई टास्क का स्टेटस बदलें { #change-the-status-of-many-tasks-at-once }

1. बोर्ड पर **List** व्यू पर क्लिक करें।
2. जिन टास्क को बदलना है उन पर टिक करें, या **Select all** पर टिक करें।
3. **Change status** पर क्लिक करें और कोई स्टेटस चुनें। इसके बजाय प्राथमिकता बदलनी हो तो **Set priority** पर क्लिक करें।

### कॉलम जोड़ें { #add-a-column }

1. बोर्ड के दाएँ सिरे पर **+** (टूलटिप **Add column**) पर क्लिक करें।
2. **Column name** में नाम लिखें।
3. **Save** (टिक) पर क्लिक करें। कॉलम अंत में जुड़ जाता है।

### कॉलम का नाम बदलें { #rename-a-column }

1. कॉलम के टाइटल पर, या उसके **…** बटन (टूलटिप **More actions**) पर क्लिक करें।
2. नाम एडिट करें।
3. **Save** (टिक) पर क्लिक करें। पुराना नाम रखने के लिए **Cancel** (क्रॉस) पर क्लिक करें।

### कॉलम का क्रम बदलें { #reorder-columns }

1. किसी कॉलम के हेडर पर पॉइंटर ले जाएँ। पॉइंटर हाथ में बदल जाता है।
2. हेडर को बाएँ या दाएँ ड्रैग करें और नई जगह पर छोड़ें।

नया क्रम पूरे प्रोजेक्ट के लिए सेव होता है, इसलिए हर सदस्य वही व्यवस्था देखता है।

### कॉलम हटाएँ { #remove-a-column }

!!! warning "टास्क दूसरे कॉलम में चले जाते हैं"
    कॉलम हटाने पर उसके सभी टास्क किसी दूसरे कॉलम में चले जाते हैं। पुष्टि करने से पहले डायलॉग उस कॉलम का नाम बताता है।

1. कॉलम के **…** बटन (टूलटिप **More actions**) पर क्लिक करें।
2. बिन आइकन (टूलटिप **Remove column**) पर क्लिक करें। **Remove column?** डायलॉग खुलता है और दिखाता है कि टास्क कहाँ जाएँगे।
3. **Remove** पर क्लिक करें।

बोर्ड में हमेशा कम से कम 1 कॉलम रहता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not update status.** | बदलाव सेव नहीं हुआ, इसलिए कार्ड वापस चला जाता है। | **Refresh** बटन से बोर्ड रिफ़्रेश करें और दोबारा कोशिश करें। |
| Tasks पैनल में **That status is not available on this project.** | बोर्ड पर वह कॉलम हटा दिया गया या उसका नाम बदल दिया गया। | मौजूदा कॉलम लोड करने के लिए **Tasks** पैनल बंद करके दोबारा खोलें। |
| **Statuses load with your tasks — try again in a moment.** | पैनल ने अभी प्रोजेक्ट के कॉलम लोड नहीं किए हैं। | कुछ सेकंड रुकें और फ़िल्टर पर फिर क्लिक करें। |
| **At least one column must stay on the board.** | आपने आखिरी कॉलम हटाने की कोशिश की। | पहले दूसरा कॉलम जोड़ें, फिर इसे हटाएँ। |
| **Could not add column. Please try again.** | कॉलम सेव नहीं हुआ। | फिर कोशिश करें। फिर भी फ़ेल हो तो कॉलम का कोई दूसरा नाम आज़माएँ। |
| कॉलम की गिनती वाला बैज एम्बर या लाल हो जाता है | कॉलम अपनी काम की सीमा पर है या उससे ऊपर है। | उस कॉलम के टास्क पूरे करें या बाहर ले जाएँ। |
