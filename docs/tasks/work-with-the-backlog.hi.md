# बैकलॉग के टास्क संभालें { #work-with-items-in-the-backlog }

**Backlog** व्यू में वह काम दिखता है जो अभी किसी स्प्रिंट में नहीं है। उसके ऊपर हर स्प्रिंट दिखता है। यहाँ टास्क जोड़ें, उन्हें सजाएँ, और जिस स्प्रिंट में उन्हें होना है, उसमें खींच दें। स्प्रिंट शुरू और खत्म करना सीखने के लिए देखें [स्प्रिंट में काम की योजना बनाएँ](plan-sprints.md)।

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल पाते हों। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- आपके प्रोजेक्ट में कम से कम 1 बोर्ड कॉलम हो, ताकि टास्क के लिए चुनने को कोई स्टेटस मिले।

## स्टेप { #steps }

### Backlog खोलें { #open-the-backlog }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. व्यू स्विचर में **Backlog** पर क्लिक करें।
3. पेज देखें। स्प्रिंट सबसे ऊपर हैं। उनके नीचे **Backlog** लिस्ट है।
4. अगर लिस्ट में **Your backlog is empty.** लिखा है, तो नीचे अपना पहला टास्क जोड़ें।

### Backlog में टास्क जोड़ें { #add-a-task-to-the-backlog }

1. **Backlog** लिस्ट के नीचे **Create** पर क्लिक करें। एक पंक्ति खुलेगी।
2. टाइप बटन पर क्लिक करें और टाइप चुनें। पहले से Task चुना होता है।
3. टाइटल लिखें। जब तक आप कुछ लिख नहीं देते, **Create** बटन बंद रहता है।
4. चाहें तो तारीख के बटन पर क्लिक करें, फिर ड्यू डेट चुनने के लिए **Pick date** इस्तेमाल करें।
5. **Create** पर क्लिक करें। टास्क लिस्ट में आ जाएगा।
6. टास्क जोड़े बिना पंक्ति बंद करने के लिए **Cancel** पर क्लिक करें।

### टास्क का नाम बदलें { #rename-a-task }

1. टास्क के टाइटल पर माउस ले जाएँ। एक पेंसिल दिखेगी। उसकी टूलटिप **Edit summary** है।
2. पेंसिल पर क्लिक करें और नया टाइटल लिखें।
3. टिक पर क्लिक करें (टूलटिप **Save summary**), या Enter दबाएँ।
4. बदलाव कैंसिल करने के लिए क्रॉस पर क्लिक करें (टूलटिप **Cancel**)।

### टास्क का स्टेटस बदलें { #change-a-tasks-status }

1. पंक्ति के अंत में स्टेटस लेबल पर क्लिक करें। लेबल में मौजूदा स्टेटस दिखता है, जैसे **TO DO**।
2. लिस्ट से नया स्टेटस चुनें। लिस्ट में आपके बोर्ड के कॉलम दिखते हैं।
3. टास्क उस स्टेटस में चला जाएगा। अगर ऐसा न हो पाए, तो पेज पर **Could not update status.** लिखा आता है।

### टास्क का असाइनी बदलें { #change-a-tasks-assignee }

1. पंक्ति के अंत में व्यक्ति के आइकन पर क्लिक करें।
2. लिस्ट से किसी व्यक्ति को चुनें, या **Unassigned** चुनें।
3. आपका अपना नाम **You** दिखता है।

### स्टोरी पॉइंट का अनुमान हटाएँ { #remove-a-story-point-estimate }

1. टास्क पर अनुमान ढूँढें। वह एक छोटे नंबर के रूप में दिखता है।
2. उसके बगल के क्रॉस पर क्लिक करें। उसकी टूलटिप **Remove estimate** है।
3. अनुमान डालने के लिए टास्क खोलें और **Story point estimate** में भरें। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

### टास्क को स्प्रिंट में खींचें { #drag-a-task-into-a-sprint }

1. पंक्ति की शुरुआत में ड्रैग हैंडल ढूँढें। उसकी टूलटिप **Drag into sprint or backlog** है।
2. टास्क को किसी स्प्रिंट पर खींचें। आप उसे स्प्रिंट के फ़ुटर पर भी छोड़ सकते हैं।
3. माउस छोड़ दें। टास्क अब उस स्प्रिंट का हो जाएगा।
4. उसे स्प्रिंट से निकालने के लिए वापस **Backlog** लिस्ट में खींचें। अगर ऐसा न हो पाए, तो पेज पर **Could not move ticket to sprint.** लिखा आता है।
5. अगर कोई स्प्रिंट खाली है, तो उसमें लिखा होता है **Plan a sprint by dragging work items into it, or by dragging the sprint footer.**

### स्प्रिंट मेन्यू इस्तेमाल करें { #use-the-sprint-menu }

1. स्प्रिंट के हेडर पर **...** बटन पर क्लिक करें। उसकी टूलटिप **More actions** है।
2. स्प्रिंट का नाम, लक्ष्य या तारीखें बदलने के लिए **Edit sprint** पर क्लिक करें। देखें [स्प्रिंट में काम की योजना बनाएँ](plan-sprints.md)।
3. स्प्रिंट हटाने के लिए **Delete sprint** पर क्लिक करें। एक विंडो **Delete sprint?** पूछकर आपसे पक्का करवाएगी।
4. मेन्यू में **Reorder work items** भी है। यह अभी कुछ नहीं करता।

### पंक्ति मेन्यू इस्तेमाल करें { #use-the-row-menu }

1. टास्क की पंक्ति पर माउस ले जाएँ और **...** बटन पर क्लिक करें। उसकी टूलटिप **More actions** है।
2. लिस्ट पढ़ें: **Move work item**, **Copy link**, **Copy key**, **Add flag**, **Assignee**, **Story point estimate**, **Split Task** और **Delete**।
3. ये आइटम दिखते तो हैं, पर अभी कोई काम नहीं करते।
4. किसी टास्क का लिंक या key कॉपी करनी हो, तो टास्क खोलें और उसके हेडर के बटन इस्तेमाल करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Create** बंद रहता है। | टाइटल खाली है। | टाइटल लिखें। |
| **Could not create ticket.** | प्रोजेक्ट टास्क सेव नहीं कर पाया। | अपना कनेक्शन जाँचें और फिर कोशिश करें। |
| **Select or load a ticket project before creating work.** | कोई प्रोजेक्ट खुला नहीं है। | बोर्ड पर कोई प्रोजेक्ट चुनें। |
| **Could not load sprints.** | स्प्रिंट लोड नहीं हुए। | पेज रीलोड करें। |
| **Could not move ticket to sprint.** | टास्क छोड़ने का बदलाव सेव नहीं हुआ। | टास्क को दोबारा खींचें। |
| पंक्ति मेन्यू के आइटम कुछ नहीं करते। | वे अभी चालू नहीं हैं। | टास्क की डिटेल्स विंडो इस्तेमाल करें। |
