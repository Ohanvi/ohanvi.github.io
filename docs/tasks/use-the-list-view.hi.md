# List व्यू का इस्तेमाल करें { #use-the-list-view }

**List** व्यू आपके टास्क को टेबल में दिखाता है, हर टास्क की एक पंक्ति। टेबल छोड़े बिना टास्क जोड़ें, पंक्ति को वहीं एडिट करें, और एक ही बार में कई पंक्तियाँ अपडेट करें। **Summary** व्यू के कार्ड भी यहीं खुलते हैं।

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल पाते हों। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- प्रोजेक्ट में कम से कम 1 टास्क हो, या आप पहला टास्क जोड़ने के लिए **Create** का इस्तेमाल करें।

## List में क्या दिखता है { #what-the-list-shows }

| कॉलम | इसमें क्या रहता है |
| --- | --- |
| **Work** | टाइप आइकन, टास्क की key और टाइटल। |
| **Assignee** | टास्क का ओनर, या **Unassigned**। |
| **Reporter** | जिसने टास्क बनाया। |
| **Priority** | **Highest**, **High**, **Medium**, **Low** या **Lowest**। |
| **Status** | बोर्ड का वह कॉलम जिसमें टास्क है। |
| **Resolution** | जब तक टास्क हल नहीं होता, यहाँ **Unresolved** लिखा रहता है। |
| **Created** | टास्क बनने की तारीख। |
| **Updated** | आख़िरी बदलाव की तारीख। |
| **Due date** | टास्क पूरा होने की तारीख। |

## स्टेप { #steps }

### List खोलें { #open-the-list }

1. दाईं रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. व्यू स्विचर में **List** पर क्लिक करें।
3. अगर टेबल में **No tasks found** लिखा है, तो फ़िल्टर हटाएँ या कोई टास्क जोड़ें।

### List से टास्क जोड़ें { #add-a-task-from-the-list }

1. टेबल के नीचे **Create** पर क्लिक करें। एक पंक्ति खुलेगी।
2. टाइप बटन पर क्लिक करें, जिसकी टूलटिप **Select work type** है, और टाइप चुनें। पहले से Story चुनी होती है।
3. **What needs to be done?** में टाइटल लिखें।
4. चाहें तो व्यक्ति वाले बटन से असाइनी चुनें।
5. Enter दबाएँ, या **Create** पर क्लिक करें। टास्क टेबल में जुड़ जाएगा।
6. टास्क जोड़े बिना पंक्ति बंद करने के लिए **Cancel** पर क्लिक करें।

### टाइटल वहीं एडिट करें { #edit-a-title-in-place }

1. किसी पंक्ति के **Work** सेल पर क्लिक करें। टाइटल टेक्स्ट बॉक्स बन जाएगा।
2. नया टाइटल लिखें।
3. सेव करने के लिए सही के निशान पर क्लिक करें। कैंसिल करने के लिए क्रॉस पर क्लिक करें।

### स्टेटस या असाइनी वहीं बदलें { #change-a-status-or-an-assignee-in-place }

1. किसी पंक्ति के **Status** सेल पर क्लिक करें, फिर नया स्टेटस चुनें।
2. **Assignee** सेल पर क्लिक करें, फिर कोई व्यक्ति चुनें।
3. बदलाव तुरंत सेव हो जाता है। अगर सेव न हो, तो लिस्ट में **Error updating status** या **Error updating assignee** दिखता है।

### कॉलम खिसकाएँ, उनकी चौड़ाई बदलें या क्रम बदलें { #move-resize-or-reorder-columns }

1. कॉलम की चौड़ाई बदलने के लिए उसके हेडर का किनारा खींचें।
2. कॉलम को खिसकाने के लिए उसका हेडर बगल की ओर खींचें।
3. हेडर पंक्ति के अंत में जो कॉलम आइकन है, वह सिर्फ़ एक निशान है। उस पर क्लिक करने से यह लिस्ट नहीं खुलती कि कौन-से कॉलम दिखाने या छिपाने हैं।

### पंक्तियाँ चुनें { #select-rows }

1. किसी पंक्ति को चुनने के लिए उसकी शुरुआत के बॉक्स पर टिक करें।
2. और पंक्तियाँ जोड़ने के लिए उन पर भी टिक करें। टेबल के नीचे एक गहरे रंग की बार दिखेगी।
3. बार में लिखा नंबर पढ़ें। वह बताता है कि कितनी पंक्तियाँ चुनी हैं, और उसके बाद **selected** लिखा होता है।
4. सारी पंक्तियाँ चुनने के लिए बार में **Select all** पर क्लिक करें।
5. चुनाव हटाने के लिए बार के दाएँ सिरे पर क्रॉस पर क्लिक करें।

### कई टास्क की प्रायोरिटी बदलें { #change-the-priority-of-many-tasks }

1. पंक्तियाँ चुनें।
2. बार में **Set priority** पर क्लिक करें। एक विंडो खुलेगी।
3. **HIGHEST**, **HIGH**, **MEDIUM**, **LOW** या **LOWEST** पर क्लिक करें।
4. **Updated 3 work item(s).** मैसेज दिखेगा, जिसमें आपके चुने टास्क की संख्या होगी।
5. अगर बदलाव न हो पाए, तो मैसेज **Bulk action failed.** आता है।

### कई टास्क का स्टेटस बदलें { #change-the-status-of-many-tasks }

1. पंक्तियाँ चुनें।
2. बार में **Change status** पर क्लिक करें। आपके बोर्ड के कॉलम के साथ एक विंडो खुलेगी।
3. जो स्टेटस चाहिए, उस पर क्लिक करें।
4. **Updated N work item(s).** मैसेज दिखेगा।

!!! note "कई टास्क एक साथ डिलीट नहीं होते"
    बार में डिलीट बटन नहीं है। कई टास्क पूरे करने के लिए उनका स्टेटस किसी पूरे हुए कॉलम पर कर दें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No tasks found** | प्रोजेक्ट खाली है, या फ़िल्टर सारे टास्क छिपा रहे हैं। | फ़िल्टर हटाएँ, या **Create** पर क्लिक करें। |
| **Error creating ticket inline** | नया टास्क सेव नहीं हुआ। | टाइटल जाँचें और दोबारा कोशिश करें। |
| **Bulk action failed.** | बदलाव मंज़ूर नहीं हुआ। | कम पंक्तियाँ चुनें, या उन्हें एक-एक करके बदलें। |
| **Error updating summary** | नया टाइटल सेव नहीं हुआ। | टाइटल फिर से एडिट करें। |
| गहरे रंग की बार नहीं दिखती। | कोई पंक्ति चुनी नहीं है। | किसी पंक्ति पर टिक करें। |
