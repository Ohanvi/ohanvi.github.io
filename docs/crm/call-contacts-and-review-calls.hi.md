# कॉन्टैक्ट को कॉल करें और अपनी कॉल रिव्यू करें { #call-contacts-and-review-your-calls }

**All contacts** स्क्रीन से किसी कॉन्टैक्ट को कॉल करें और लिखें कि बात का क्या नतीजा रहा। हर कॉल के साथ उसका नतीजा सेव होता है। चाहें तो फ़ॉलो-अप की तारीख भी जोड़ सकते हैं। आपकी टीम इसे कॉन्टैक्ट की हिस्ट्री में देख सकती है। हर कॉल का रिव्यू भरने में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Contacts** दिखता हो और उसके पैनल में **All contacts** हो। देखें [कॉन्टैक्ट मैनेज करें](manage-contacts.md)।
- कॉन्टैक्ट के पास **Phone** या **Mobile** नंबर हो।
- **WhatsApp Call** के लिए आपका WhatsApp नंबर कनेक्ट होना चाहिए। देखें [WhatsApp कॉलिंग इस्तेमाल करें](../whatsapp/whatsapp-calling.md)।

## कॉल करने के तरीके { #ways-to-call }

| बटन | क्या होता है |
| --- | --- |
| **Call Now** | आप जिस डिवाइस पर हैं, उसी से कॉल शुरू होती है। Ohanvi में लौटते ही रिव्यू विंडो खुलती है। |
| **Call on Mobile — send this number to your phone** | नंबर आपके फ़ोन पर भेज देता है, ताकि आप वहाँ से डायल कर सकें। यह सिर्फ़ कंप्यूटर पर दिखता है। |
| **WhatsApp Call** | कॉन्टैक्ट को WhatsApp कॉल लगाता है। |

## स्टेप { #steps }

### किसी कॉन्टैक्ट को कॉल करें { #call-a-contact }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. लिस्ट में कॉन्टैक्ट पर क्लिक करें।
3. रिकॉर्ड हेडर में **More actions** (**…** बटन) पर क्लिक करें।
4. **Call Now** पर क्लिक करें। आपका डिवाइस कॉल शुरू कर देता है।
5. कॉन्टैक्ट से बात करें। कॉल खत्म होने पर Ohanvi में लौट आएँ। **Call Review** विंडो अपने आप खुल जाती है।

फ़ोन पर लिस्ट की हर रो में यही बटन दिखते हैं। रो में फ़ोन बटन पर टैप करें।

### नंबर अपने फ़ोन पर भेजें { #send-the-number-to-your-phone }

1. कॉन्टैक्ट चुनें, फिर **More actions** पर क्लिक करें।
2. **Call on Mobile — send this number to your phone** पर क्लिक करें।
3. अपने फ़ोन पर आया मैसेज खोलें और नंबर डायल करें।

फ़ोन पर यह बटन नहीं दिखता, क्योंकि डायलर पहले से आपके हाथ में होता है।

### कॉल रिव्यू करें { #review-a-call }

**Call Review — contact name** विंडो में दिखता है कि कॉल कितनी देर चली।

1. **Call Outcome** में से एक नतीजा चुनें। चाहें तो अपना नतीजा भी लिख सकते हैं। बॉक्स पर **Select or type an outcome** लिखा होता है। नतीजा चुनना ज़रूरी है।
2. पहले से मौजूद नतीजे ये हैं:
    - **Interested**
    - **Interested but Busy**
    - **Not Interested**
    - **Call Back**
    - **Call Tomorrow**
    - **Call in Two Days**
    - **No Answer**
    - **Invalid Number**
    - **Left Organization**
    - **Already Used Other Vendor**
3. बॉक्स के नीचे लिखा सुझाव देखें। Ohanvi कॉल की लंबाई देखकर नतीजे का अंदाज़ा लगाता है। बहुत छोटी कॉल पर वह **Invalid Number** सुझाता है। छोटी कॉल पर **Not Interested** और लंबी कॉल पर **Interested**। आप इसे बदल सकते हैं।
4. अपना लिखा नतीजा आगे भी इस्तेमाल करना हो, तो **Save "your text" as a reusable option** पर क्लिक करें।
5. **Already Used Other Vendor** चुना है, तो **Vendor Name** में नाम लिखें। बॉक्स पर **Which vendor is the contact using?** लिखा होता है। यह नाम लिखना ज़रूरी है।
6. **Remarks** में कॉल के बारे में नोट लिखें। बॉक्स पर **Notes about the call…** लिखा होता है। बोलकर लिखना हो, तो माइक्रोफ़ोन (**Dictate remarks (voice to text)**) पर क्लिक करें।
7. **Follow-up Date** सेट करें:
    - **Call Tomorrow** और **Call in Two Days** चुनने पर तारीख अपने आप भर जाती है। **Follow-up scheduled for …** वाली लाइन में वह तारीख दिखती है।
    - **Call Back** में आपको **Select a date** पर क्लिक करके खुद तारीख चुननी होती है।
8. **Save** पर क्लिक करें। कॉल कॉन्टैक्ट के **Calls** और **Activity** टैब में दिखने लगती है।

!!! note "ध्यान दें"
    **Call Outcome** ज़रूरी है। नतीजा खाली हो, तो विंडो में **Please select or type a call outcome.** दिखता है। **Call Back** चुना हो पर तारीख न हो, तो **Please pick a follow-up date for Call Back.** दिखता है।

### रिव्यू के दौरान कॉन्टैक्ट की जानकारी ठीक करें { #fix-the-contacts-details-during-the-review }

1. रिव्यू विंडो में **Update contact details** पर क्लिक करें।
2. जो लाइन दिखे, उसे पढ़ें। यह नतीजे के हिसाब से बदलती है:
    - **Update the contact details they shared:** ज़्यादातर नतीजों के लिए।
    - **Wrong number? Enter the correct one:** **Invalid Number** के लिए।
    - **They left — add the alternate details they gave you:** **Left Organization** के लिए।
3. **Mobile**, **Phone**, **Email** या **Designation** बदलें।
4. **Invalid Number** में अगर आप इस नंबर पर दोबारा कॉल नहीं करना चाहते, तो **Mark as invalid — set Do Not Call** पर टिक करें।
5. **Save** पर क्लिक करें।

### आखिरी कॉन्टैक्ट को दोबारा कॉल करें { #call-the-last-contact-again }

1. **All contacts** स्क्रीन पर टॉप बार में **Last Called** आइकन पर क्लिक करें।
2. नाम, नंबर और कॉल का समय देखें, जैसे **Called 2 hours ago**।
3. उसी कॉन्टैक्ट को फिर कॉल करने के लिए **Call Again** पर क्लिक करें। न करना हो, तो **Close** पर क्लिक करें।

इस डिवाइस से अभी तक कोई कॉल न की हो, तो **No calls placed from this device yet** मैसेज दिखता है।

### जिन कॉन्टैक्ट को कॉल कर चुके हैं, उन्हें छिपाएँ { #hide-contacts-you-have-already-called }

1. टॉप बार में फ़िल्टर आइकन पर क्लिक करें। इसका टूलटिप **Hide called contacts (already completed calls)** है।
2. अब लिस्ट में सिर्फ़ वे कॉन्टैक्ट दिखते हैं जिनकी कॉल पूरी नहीं हुई।
3. उसी आइकन पर दोबारा क्लिक करें। अब इसका टूलटिप **Show all contacts** है।

### अपने फ़ॉलो-अप देखें { #see-your-follow-ups }

1. टॉप बार में घंटी आइकन पर क्लिक करें। इसका टूलटिप **Follow-ups Due** है।
2. **Overdue**, **Upcoming** या **All** चुनें। हर एक के साथ उसकी गिनती दिखती है, जैसे **Overdue (3)**।
3. हर रो देखें। उसमें फ़ॉलो-अप, उसका ओनर और वह कॉन्टैक्ट दिखता है जिससे वह जुड़ा है।
4. दोबारा लोड करने के लिए **Refresh** पर क्लिक करें। बंद करने के लिए **Close** पर क्लिक करें।

कोई फ़ॉलो-अप बाकी न हो, तो लिस्ट में **No follow-ups in this view.** लिखा होता है।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| कॉल के बाद **Call Review** नहीं खुलता | आप Ohanvi टैब या ऐप पर वापस नहीं आए। | Ohanvi पर वापस जाएँ। वापस आते ही विंडो खुल जाती है। |
| **Could not save the call review. Please retry.** | सेव होकर सर्वर तक नहीं पहुँचा। | इंटरनेट कनेक्शन जाँचें और **Save** पर दोबारा क्लिक करें। |
| **Could not update the contact details. Please retry.** | आपका किया बदलाव सेव नहीं हुआ। | **Save** पर दोबारा क्लिक करें। |
| **Please enter the vendor name.** | आपने **Already Used Other Vendor** चुना, पर नाम नहीं लिखा। | **Vendor Name** में वेंडर का नाम लिखें। |
| **Call on Mobile** नहीं दिख रहा | आप फ़ोन पर हैं। | **Call Now** इस्तेमाल करें। |
