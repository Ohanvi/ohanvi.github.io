# अपने शेड्यूल किए हुए ईमेल कैंपेन देखें { #see-your-scheduled-email-campaigns }

शेड्यूल किए हुए सभी ईमेल कैंपेन एक कैलेंडर या लिस्ट में देखने के लिए **Email** व्यू खोलें। यहाँ आप देख सकते हैं कि हर कैंपेन कब जाएगा। कैंपेन जाने से पहले आप उसका समय बदल सकते हैं या उसे रोक सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। अगर यह नहीं दिख रहा, तो अपने एडमिन से कहें।
- कैंपेन में भेजने का समय तय हो। देखें [ईमेल कैंपेन भेजें](../email/send-email-campaign.md)।

## स्टेप { #steps }

### Email शेड्यूल खोलें { #open-the-email-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Email** चुनें। पेज का टाइटल **Email schedule** दिखेगा।
2. पेज इस महीने के **Calendar** व्यू में खुलता है। चैनल चिप्स यहाँ नहीं दिखते, क्योंकि यह पेज पहले से सिर्फ़ Email दिखाता है।
3. किसी दिन के आइटम देखने के लिए उस दिन पर क्लिक करें। समय के हिसाब से, दिन के हेडिंग के नीचे आइटम देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसकी जानकारी दाईं तरफ़ खुलती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर Type का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि यह आइटम किस तरह का है।

| Type | यह क्या है |
| --- | --- |
| **Regular** | आम कैंपेन, जिसे आप खुद लिखते और भेजते हैं। |
| **Rss** | RSS फ़ीड से बना कैंपेन। |

**Audience / with** लाइन में कैंपेन की ऑडियंस दिखती है। **Channel** फ़ील्ड में वह ईमेल चैनल दिखता है, जिससे कैंपेन भेजा जाता है।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | कैंपेन **Draft**, **Pending review** या **Rejected** है। |
| **Scheduled** | कैंपेन **Approved** या **Scheduled** है और अपने समय का इंतज़ार कर रहा है। |
| **Live** | कैंपेन अभी भेजा जा रहा है। |
| **Sent** | कैंपेन भेजा जा चुका है। |
| **Failed** | कैंपेन भेजा नहीं जा सका। |
| **Cancelled** | कैंसिल कर दिया गया। यह नहीं भेजा जाएगा। |

### किसी आइटम में बदलाव करें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [शेड्यूल किए गए आइटम को रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।
2. Email कैंपेन की स्क्रीन खोलने के लिए **Edit** पर क्लिक करें। देखें [ईमेल कैंपेन भेजें](../email/send-email-campaign.md)।
3. कैंपेन कैंसिल करने के लिए **Cancel** पर क्लिक करें। कैंपेन कैंसिल हो जाता है और नहीं भेजा जाता।
4. आइटम को Email से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छाँटें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in Email** चुनें। Ohanvi Email कैंपेन की स्क्रीन खोल देगा। नया आइटम आप वहीं बनाएँगे।

## समस्या का समाधान { #troubleshooting }

| समस्या | वजह | हल |
| --- | --- | --- |
| **Nothing scheduled here** | किसी कैंपेन में भेजने का समय तय नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | Email में कैंपेन खोलें और भेजने का समय तय करें। |
| कोई कैंपेन नहीं दिख रहा | जिस कैंपेन में भेजने का समय तय नहीं है, वह Schedule में नहीं दिखता। | उसमें भेजने का समय डालें। |
| **Could not cancel.** | कैंपेन जा चुका है, या आपका रोल उसमें बदलाव नहीं कर सकता। | स्टेटस देखें। Email एक्सेस के लिए अपने एडमिन से कहें। |
