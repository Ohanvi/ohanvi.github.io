# शेड्यूल { #schedule }

जो कुछ आगे के लिए तय है, वह सब Schedule में दिखता है। हर मॉड्यूल का आइटम एक ही कैलेंडर या लिस्ट में आता है। आइटम आप उसके अपने मॉड्यूल में बनाते हैं। उन्हें एक साथ देखने और बदलने के लिए Schedule है।

![महीने के Calendar व्यू में Schedule। WhatsApp, CRM, Email, Social और Appointments के आइटम अपने-अपने रंग में दिख रहे हैं](../assets/screenshots/schedule-1-calendar.png)

## कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Schedule** खोलें। पैनल में ये दिखते हैं:

- **All schedules**, **Today**, **Upcoming**, **Drafts**
- चैनल के हिसाब से: **WhatsApp**, **CRM**, **Email**, **Social**, **Appointments**
- **Recurring**

## शुरू करने से पहले { #before-you-start }

- आपके रोल को Schedule का एक्सेस हो। डिफ़ॉल्ट रूप से यह सिर्फ़ **Super Admin** रोल को मिलता है।
- आपने किसी दूसरे मॉड्यूल में कुछ शेड्यूल किया हो, जैसे WhatsApp ब्रॉडकास्ट या सोशल पोस्ट।
- रीशेड्यूल, कैंसिल या डिलीट करने के लिए विंडो इतनी चौड़ी रखें कि डिटेल्स पैनल दिखे। छोटी स्क्रीन पर ये बटन छिप जाते हैं।
