# बार-बार चलने वाले शेड्यूल प्रबंधित करें { #manage-recurring-schedules }

बार-बार चलने वाला शेड्यूल बार-बार भेजता रहता है, जैसे हर हफ़्ते दोहराया जाने वाला व्हाट्सऐप ब्रॉडकास्ट। इन सबको एक सूची में देखने के लिए **Recurring** का इस्तेमाल करें, फिर किसी सीरीज़ को आगे-पीछे करें, पॉज़ करें या बंद करें। अंत में आपको पता होगा कि क्या दोहराया जाता है, कब, और उसे कैसे रोकना है।

## शुरू करने से पहले { #before-you-start }

- आप लेफ़्ट रेल में **Schedule** खोल सकते हैं। देखें [जो कुछ भी शेड्यूल है, सब देखें](view-schedule.md)।
- आपके पास कम से कम 1 दोहराया जाने वाला आइटम है। अभी दोहराए जाने वाले शेड्यूल उन व्हाट्सऐप ब्रॉडकास्ट से आते हैं जिनमें **Repeat** विकल्प (**Daily**, **Weekly**, **Monthly** या **Yearly**) चुना गया हो।

## चरण { #steps }

### देखें कि क्या दोहराया जाता है { #see-what-repeats }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Recurring** चुनें। **Recurring** पेज लिस्ट व्यू में खुलता है।
2. किसी सीरीज़ पर क्लिक करें। ब्योरे में **Recurrence** फ़ील्ड दोहराने का नियम दिखाती है, जैसे **WEEKLY** [VERIFY: displayed value format]।
3. स्टेटस देखें। चल रही सीरीज़ में **Live** या **Scheduled** दिखता है।

### अगला सेंड आगे-पीछे करें { #move-the-next-send }

1. सीरीज़ चुनकर **Reschedule** पर क्लिक करें।
2. नई तारीख और समय चुनें। **Rescheduled.** संदेश दिखता है।

### पॉज़ करें, बंद करें या दोहराने का नियम बदलें { #pause-stop-or-change-the-repeat-rule }

Schedule सीरीज़ को दिखाता है; उसे व्हाट्सऐप **Scheduler** कंट्रोल करता है।

1. सीरीज़ चुनकर **Edit** पर क्लिक करें। व्हाट्सऐप **Scheduler** खुलता है।
2. सीरीज़ चुनें। पैनल में **Repeats**, **Next send** और **Ends** दिखते हैं।
3. चुनें कि क्या करना है:
    - सीरीज़ को रोकने के लिए **Pause** पर क्लिक करें। उसे फिर शुरू करने के लिए **Resume** पर क्लिक करें।
    - सीरीज़ को खत्म करने के लिए **Stop** पर क्लिक करें।
    - आख़िरी तारीख तय करने के लिए **Ends** बदलें, या **No end date** चुनें ताकि वह आपके रोकने तक चलती रहे।

आप व्हाट्सऐप **Scheduler** तक **WhatsApp** → **Manage** → **Scheduler** से भी पहुँच सकते हैं।

### नया दोहराया जाने वाला ब्रॉडकास्ट सेट करें { #set-up-a-new-repeating-broadcast }

1. **New schedule** पर क्लिक करें, फिर **New in WhatsApp** पर।
2. ब्रॉडकास्ट की **When** फ़ील्ड में **Schedule** चुनें और पहले सेंड का समय चुनें।
3. **Repeat** में **Daily**, **Weekly**, **Monthly** या **Yearly** चुनें। हिंट पहले सेंड का समय और दोहराने का नियम बताता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Recurring** पर **Nothing scheduled here** | किसी आइटम का दोहराने का नियम **Once** के अलावा कुछ नहीं है। | किसी व्हाट्सऐप ब्रॉडकास्ट पर **Repeat** सेट करें, या देखें कि सीरीज़ बंद तो नहीं हो गई। |
| आपकी बंद की हुई सीरीज़ अब भी सूची में है | बंद सीरीज़ **Cancelled** स्टेटस के साथ Schedule में रह सकती है। | उसे छिपाने के लिए स्टेटस फ़िल्टर **Scheduled** पर सेट करें। |
| दोहराई जाने वाली सीरीज़ पर **Cancel** पूरी सीरीज़ हटा देता है | व्हाट्सऐप शेड्यूल रद्द करने से जॉब बंद हो जाता है। "एक बार छोड़ें" का विकल्प नहीं है। | किसी एक सेंड को छोड़ने के लिए **Reschedule** पर क्लिक करें और अगला सेंड आगे बढ़ा दें। |
| **Could not reschedule.** | व्हाट्सऐप शेड्यूलिंग ने नया समय स्वीकार नहीं किया। | भविष्य का समय चुनें और दोबारा कोशिश करें। |
