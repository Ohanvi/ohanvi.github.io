# टास्क पैनल { #tasks-panel }

**Tasks** पैनल अपना काम देखने और नया टास्क जोड़ने का सबसे तेज़ तरीका है। यह टास्क को **Today**, **Assigned to me** और **Created by me** के नीचे दिखाता है। नीचे की गाइड टास्क बनाने, लिखने और खोजने के बारे में हैं।

**यह कहाँ मिलेगा:** दाईं ओर की रेल में नोटिफ़िकेशन बेल के पास **Tasks** पर क्लिक करें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [टास्क बनाएँ और असाइन करें](../create-and-assign-tasks.md) | आप काम जोड़ना और उसे ओनर, प्रायोरिटी और ड्यू डेट देना चाहते हैं। |
| [टास्क एडिटर में लिखें](../write-in-the-task-editor.md) | आप विवरण या कमेंट में हेडिंग, लिस्ट, टेबल, तस्वीरें या आवाज़ जोड़ना चाहते हैं। |
| [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](../collaborate-on-tasks.md) | आप किसी टास्क पर चर्चा करना, फ़ाइलें शेयर करना या समय दर्ज करना चाहते हैं। |
| [टास्क खोजें, फ़िल्टर करें और देखें](../find-and-filter-tasks.md) | आप सिर्फ़ अपना काम देखना चाहते हैं, या बोर्ड का व्यू बदलना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आपके रोल के पास Task का एक्सेस है। इसके बिना **Tasks** आइकन छिपा रहता है।
- आपके वर्कस्पेस में एक टास्क प्रोजेक्ट है। देखें [टास्क प्रोजेक्ट सेट करें](../set-up-task-project.md)।
