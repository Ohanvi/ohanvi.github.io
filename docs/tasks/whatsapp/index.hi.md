# WhatsApp पर टास्क { #whatsapp-tasks }

WhatsApp tasks से आपका स्टाफ़ WhatsApp से ही टास्क बोर्ड पर काम कर पाता है। हर नया टास्क उन्हें बटन वाले मैसेज के रूप में मिलता है। वे छोटे कमांड लिखकर काम की लिस्ट देखते हैं या उसे पूरा करते हैं, और सबूत के तौर पर फ़ोटो भेजते हैं। हर बदलाव उसी टास्क बोर्ड पर दिखता है जिसे आपका ऑफ़िस इस्तेमाल करता है।

**इसे कहाँ खोलें:** साइडबार में **Tasks** खोलें, फिर **WhatsApp tasks** पर क्लिक करें। इस पेज पर **Today**, **Analytics**, **Recurring** और **Settings** टैब हैं।

## शुरू करने से पहले { #before-you-start }

- आपके बिज़नेस का एक WhatsApp नंबर Ohanvi से जुड़ा है।
- जो लोग इसे इस्तेमाल करेंगे, वे WhatsApp नंबर के साथ स्टाफ़ या टीममेट के रूप में जोड़े गए हैं। देखें [स्टाफ़ जोड़ें](../../hr/add-staff.md)।
