# Configure the CRM

Set these up once, then mostly leave them alone. Every deal, board, funnel and forecast uses them. These screens are for admins.

**Where to find it:** click your initials at the bottom left, select **Settings**, then **CRM**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Set up pipelines](../set-up-pipelines.md) | You create the stages a deal moves through. |
| [Manage lead sources and see which ones convert](../manage-lead-sources.md) | You add the channels your leads come from. |
| [Add products](../add-products.md) | You add what you sell, so deals can carry product lines. |
| [Set sales quotas](../set-sales-quotas.md) | You give each salesperson a monthly target. |

## Before you start

- You are an admin. The CRM settings page reads **Configure how your CRM works — admin only**.
- Your workspace has the CRM module.
