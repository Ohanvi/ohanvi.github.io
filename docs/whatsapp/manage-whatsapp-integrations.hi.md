# व्हाट्सऐप इंटीग्रेशन प्रबंधित करें { #manage-whatsapp-integrations }

अपने व्हाट्सऐप ऑटोमेशन जिन बाहरी सेवाओं का इस्तेमाल करते हैं उन्हें कनेक्ट करने के लिए **Manage** में **Integrations** खोलें। अंत में कोई सेवा **Connected** दिखती है, आपने उसे टेस्ट कर लिया होता है, और आप जानते हैं कि उसकी जानकारी कैसे बदलनी या उसे कैसे हटाना है। कनेक्ट करने में लगभग 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका रोल व्हाट्सऐप **Manage** खोल सकता हो। अगर नहीं, तो अपने एडमिन से पूछें। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](../settings/roles-and-permissions.md)।
- आपके पास वह जानकारी हो जो सेवा माँगती है, जैसे key या टोकन। हर सेवा के कार्ड में सेटअप का एक छोटा संकेत दिखता है।
- आपको पता हो कि कौन-सा ऑटोमेशन इस सेवा का इस्तेमाल करेगा। देखें [फ़्लो के लिए ऐप कनेक्ट करें](../flows/connect-apps-for-flows.md)।

## Integrations स्क्रीन क्या दिखाती है { #what-the-integrations-screen-shows }

स्क्रीन का शीर्षक **Integrations** है। उसके नीचे आप पढ़ते हैं **Connect the services your automations read from and write to.** सेवाएँ बड़े अक्षरों वाले शीर्षक के नीचे समूहित होती हैं, हर कैटेगरी के लिए एक शीर्षक।

| कार्ड पर आप क्या देखते हैं | इसका मतलब |
| --- | --- |
| **Connected** | सेवा कनेक्ट है और चालू है। |
| **Paused** | सेवा कनेक्ट है लेकिन बंद है। |
| लाल स्टेटस लेबल | पिछली कनेक्शन जाँच में OK नहीं मिला। **Test** चलाएँ। |
| **Set up under AI Settings.** | यह सेवा AI सेटिंग्स स्क्रीन पर सेट होती है। कार्ड पर कोई बटन नहीं होता। |

## चरण { #steps }

### कोई सेवा कनेक्ट करें { #connect-a-service }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें।
2. **Integrations** चुनें। सेवाओं की सूची खुलती है।

    ![CRM, Automation और Helpdesk सेवाओं वाली Integrations सूची, जिनमें से हर एक पर Connect बटन है](../assets/screenshots/whatsapp-integrations-1-services.png)

3. सेवा ढूँढें। उसके नाम के नीचे का सेटअप संकेत पढ़ें।
4. **Connect** पर क्लिक करें। सेवा के नाम के शीर्षक वाली एक विंडो खुलती है।
5. हर फ़ील्ड भरें। key, secret, टोकन या पासवर्ड वाले फ़ील्ड में आप जो लिखते हैं वह छिपा रहता है।
6. अगर विंडो में **This integration needs no credentials — connecting is enough.** लिखा है, तो कुछ भरने की ज़रूरत नहीं।
7. **Save** पर क्लिक करें। **Integration saved.** संदेश आता है और कार्ड पर **Connected** दिखता है।

!!! note "फ़ील्ड के नाम"
    विंडो अपने फ़ील्ड सेवा से लेती है। `apiKey` नाम का फ़ील्ड **Api key** के रूप में दिखता है।

### कनेक्शन टेस्ट करें { #test-a-connection }

1. ऐसा कार्ड ढूँढें जिस पर **Connected** या **Paused** दिखता है।
2. **Test** पर क्लिक करें।
3. जो संदेश आए उसे पढ़ें। यह सेवा का अपना जवाब होता है, जैसे key क्यों नामंज़ूर हुई। अगर सेवा कोई टेक्स्ट नहीं भेजती, तो संदेश **Connection test finished.** होता है।
4. अगर उसके बाद कार्ड पर लाल स्टेटस लेबल दिखे, तो **Edit** पर क्लिक करें और जानकारी जाँचें।

### सेवा की जानकारी बदलें { #change-the-details-of-a-service }

1. कनेक्ट की हुई सेवा ढूँढें।
2. **Edit** पर क्लिक करें। वही विंडो खुलती है।
3. नई वैल्यू लिखें।
4. **Save** पर क्लिक करें। **Integration saved.** संदेश आता है।

पहले सेव की हुई वैल्यू रखने के लिए फ़ील्ड खाली छोड़ें। [VERIFY: क्या खाली फ़ील्ड सेव की हुई वैल्यू रखता है]

### सेवा हटाएँ { #remove-a-service }

1. कनेक्ट की हुई सेवा ढूँढें।
2. **Remove** पर क्लिक करें। **Remove this integration?** विंडो खुलती है।
3. चेतावनी पढ़ें। **Automations that depend on** सेवा **will stop working until it is connected again.**
4. पक्का करने के लिए **Remove** पर क्लिक करें, या उसे रखने के लिए **Cancel** पर। **Integration removed.** संदेश आता है।

!!! warning "ऑटोमेशन तुरंत रुक जाते हैं"
    हटाने से पहले जाँच लें कि कौन-से फ़्लो इस सेवा का इस्तेमाल करते हैं। हटाया हुआ इंटीग्रेशन आप **Recycle Bin** से वापस पा सकते हैं। देखें [डिलीट किए आइटम वापस लाएँ](restore-deleted-items.md)।

### सूची दोबारा लोड करें { #reload-the-list }

1. स्क्रीन के ऊपर दाईं ओर **Refresh** पर क्लिक करें।
2. अगर सूची लोड न हो, तो स्क्रीन **Could not load integrations.** दिखाती है। **Retry** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not save the integration.** | कोई ज़रूरी फ़ील्ड खाली या गलत है, या सेवा तक पहुँचा नहीं जा सका। | हर फ़ील्ड जाँचें, फिर दोबारा **Save** पर क्लिक करें। |
| **Could not reach the service.** | टेस्ट कनेक्ट नहीं हो पाया। | अपना इंटरनेट कनेक्शन और सेवा का अपना स्टेटस जाँचें, फिर दोबारा **Test** पर क्लिक करें। |
| कार्ड पर **Connect** बटन नहीं है और **Set up under AI Settings.** लिखा है | सेवा यहाँ नहीं, AI सेटिंग्स स्क्रीन पर कॉन्फ़िगर होती है। | AI सेटिंग्स खोलें। देखें [व्हाट्सऐप AI एजेंट सेट करें](set-up-ai-agent.md)। |
| कार्ड पर लाल स्टेटस लेबल दिख रहा है | पिछली जाँच फ़ेल हुई, जैसे key रद्द हो गई। | कारण पढ़ने के लिए **Test** पर क्लिक करें, फिर जानकारी ठीक करने के लिए **Edit** पर। |
| **Could not remove the integration.** | हटाना पूरा नहीं हुआ। | **Refresh** पर क्लिक करें, फिर दोबारा **Remove** आज़माएँ। |
| आपकी ज़रूरत की सेवा सूची में नहीं है | Ohanvi उसे यहाँ नहीं देता। | उसकी जगह वेबहुक या API इस्तेमाल करें। देखें [वेबहुक और इंटीग्रेशन](whatsapp-webhooks-and-integrations.md)। |
