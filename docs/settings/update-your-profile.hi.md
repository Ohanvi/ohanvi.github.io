# अपनी प्रोफ़ाइल और पासवर्ड अपडेट करें { #update-your-profile-and-password }

**My Account** स्क्रीन पर अपना नाम, ईमेल, फ़ोन नंबर और पासवर्ड अपडेट करें। काम पूरा होने पर आपकी जानकारी सेव हो जाती है और नया पासवर्ड अगली बार साइन इन करने पर चलता है।

## शुरू करने से पहले { #before-you-start }

- आप Ohanvi में साइन इन हैं। अगर आप पासवर्ड भूल गए हैं, तो देखें [अपना पासवर्ड रीसेट करें](../reset-password.md)।

## चरण { #steps }

### My Account खोलें { #open-my-account }

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें। प्रोफ़ाइल मेन्यू खुलता है।
2. मेन्यू में सबसे ऊपर अपने नाम पर क्लिक करें। **My Account** स्क्रीन खुलती है।

### अपनी जानकारी बदलें { #change-your-details }

1. **Your details** के नीचे **Name**, **Email** या **Phone Number** एडिट करें। तीनों ज़रूरी हैं।
2. कंट्री कोड चुनें, फिर अपना नंबर उसके बिना लिखें।
3. **Save changes** पर क्लिक करें। संदेश **Your account details were updated.** दिखता है।

आप **Username** नहीं बदल सकते। यही वह नाम है जिससे आप साइन इन करते हैं।

### अपना पासवर्ड बदलें { #change-your-password }

1. **New password** में नया पासवर्ड लिखें। उसे दिखाने या छिपाने के लिए आँख के आइकन पर क्लिक करें।
2. बॉक्स के नीचे की चेकलिस्ट देखें। हर नियम पूरा होने पर हरा हो जाता है:
    - **8+ characters**
    - **Upper & lower case**
    - **2+ digits**
    - **1+ special character**
    - **Not a common or predictable password**
3. **Save changes** पर क्लिक करें। संदेश **Your account details were updated.** दिखता है और बॉक्स खाली हो जाता है।
4. अगली बार नए पासवर्ड से साइन इन करें।

अपना मौजूदा पासवर्ड रखना हो, तो **New password** को खाली छोड़ दें।

एक मज़बूत पासवर्ड में ये भी नहीं होने चाहिए:

- 64 अक्षरों से लंबा न हो,
- 1234, abcd, qwer या aaaa जैसे क्रम या दोहराव न हों,
- आपका यूज़रनेम, नाम या ईमेल उसमें न हो।

अंकों और एक चिह्न के साथ कुछ बेमेल शब्द आज़माएँ, जैसे Mango#River42Lamp।

### अपना रोल जाँचें { #check-your-role }

**Role** बॉक्स वह रोल दिखाता है जो आपके वर्कस्पेस ने आपको दिया है, जैसे **Super Admin**, **Manager** या **Executive**। आप इसे यहाँ नहीं बदल सकते। अगर आपने वर्कस्पेस बनाया है, तो **You are the account owner.** दिखता है। नहीं तो, अपने वर्कस्पेस के मालिक से इसे बदलने के लिए कहें। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](roles-and-permissions.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Password needs: 8+ characters, 2+ digits** (या दूसरे नियम) | नया पासवर्ड 1 या ज़्यादा नियम पूरे नहीं करता। | संदेश में जो लिखा है वह जोड़ें, फिर दोबारा **Save changes** पर क्लिक करें। |
| **This password is too common and easy to guess (like Password@123).** | पासवर्ड आम पासवर्ड की सूची में है। | कुछ बेमेल शब्द इस्तेमाल करें, जैसे Mango#River42Lamp। |
| **Password must not contain sequences or repeats like 1234, abcd, qwer or aaaa.** | पासवर्ड में कीबोर्ड का क्रम या दोहराया हुआ अक्षर है। | वह क्रम या दोहराव हटाएँ। |
| **Password must not contain your username, name or email.** | आपके नाम या ईमेल का कोई हिस्सा पासवर्ड में है। | ऐसे शब्द चुनें जो आपसे जुड़े न हों। |
| **Email … already exists with user: …** | किसी दूसरे एक्टिव यूज़र के पास पहले से वही ईमेल है। | कोई दूसरा ईमेल इस्तेमाल करें, या अपने वर्कस्पेस के मालिक से पूछें। |
| **Phone number is required.** | फ़ोन का बॉक्स खाली है। | अपना मोबाइल नंबर लिखें, फिर सेव करें। |
