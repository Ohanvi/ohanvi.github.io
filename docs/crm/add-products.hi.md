# प्रोडक्ट्स जोड़ें { #add-products }

जो चीज़ें आप बेचते हैं, उन्हें CRM में जोड़ें। इसके बाद डील में प्रोडक्ट लाइनें जोड़ी जा सकती हैं, और डील की रकम उन लाइनों का जोड़ होती है। एक प्रोडक्ट जोड़ने में करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आप एडमिन हों। CRM सेटिंग्स सिर्फ़ एडमिन के लिए हैं।
- आपको हर प्रोडक्ट का कोड, नाम और कीमत पता हो।

## चरण { #steps }

### Products खोलें { #open-products }

1. नीचे बाएँ कोने में अपने नाम के शुरुआती अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **CRM** चुनें, फिर **Products** पर क्लिक करें।

आप **Ctrl K** (Mac पर **⌘K**) दबाकर **Products** लिख सकते हैं और उसे चुन सकते हैं।

### प्रोडक्ट जोड़ें { #add-a-product }

1. **Add** पर क्लिक करें। **Add Products** फ़ॉर्म खुलता है।
2. **Code** लिखें। यह यूनिक होना चाहिए।
3. **Name** लिखें।
4. **Unit Price** लिखें।
5. **Currency** देख लें। यह पहले से **INR** होती है।
6. **Active** पर टिक लगा रहने दें, ताकि डील पर यह प्रोडक्ट चुना जा सके।
7. **Submit** पर क्लिक करें। **Product created** मैसेज दिखता है।

**Code** और **Name** दोनों ज़रूरी हैं।

### डील में प्रोडक्ट इस्तेमाल करें { #use-a-product-on-a-deal }

1. कोई डील खोलें। देखें [डील बनाएँ और प्रबंधित करें](manage-deals.md)।
2. प्रोडक्ट लाइन जोड़ें और प्रोडक्ट चुनें।
3. डील की रकम उसकी लाइनों का जोड़ बन जाती है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Product code '…' already exists.** | किसी दूसरे प्रोडक्ट में वही कोड है। | प्रोडक्ट को कोई यूनिक **Code** दें। |
| डील पर प्रोडक्ट नहीं दिख रहा | **Active** पर टिक नहीं लगा था। | प्रोडक्ट एडिट करें और **Active** पर टिक लगाएँ। |
| CRM सेटिंग्स में **Products** नहीं दिख रहा | आपका रोल एडमिन नहीं है। | अपने एडमिन से कहें। |
