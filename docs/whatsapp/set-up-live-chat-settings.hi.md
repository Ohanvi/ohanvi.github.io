# लाइव चैट सेटिंग्स सेट करें { #set-up-live-chat-settings }

Live Chat Settings आपके टीम इनबॉक्स के आसपास के ऑटोमैटिक जवाब और टाइमर तय करती हैं। अंत में ग्राहकों को वेलकम या ऑफ़-आवर्स जवाब मिलेगा, इंतज़ार कर रहे ग्राहकों को बताया जाएगा कि आपकी टीम के पास उनकी चैट है, और बिना जवाब वाली चैट किसी दूसरे एजेंट के पास चली जाएँगी। इसमें करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट है। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आप **WhatsApp** पैनल में **Manage** खोल सकते हैं। न खुले तो अपने एडमिन से पूछें।
- आपके पास चैट का जवाब देने वाले एजेंट हैं। देखें [व्हाट्सऐप एजेंट जोड़ें](add-whatsapp-agents.md)।

## हर सेटिंग क्या करती है { #what-each-setting-does }

| सेटिंग | यह क्या करती है |
| --- | --- |
| **Auto Resolve Chats** | उन चैट को बंद करती है जो आपके अपने हाथ में लेने के बाद बिना छुए पड़ी रहती हैं, और उन हैंडऑफ़ की गई चैट को भी जिनका किसी ने जवाब नहीं दिया। इसके बाद बॉट ग्राहक को वापस संभाल लेता है। |
| **Welcome Message** | नई बातचीत के पहले मैसेज का ऑटोमैटिक जवाब, जो काम के घंटों में भेजा जाता है। |
| **Off Hours Message** | नई बातचीत के पहले मैसेज का ऑटोमैटिक जवाब, जो काम के घंटों के बाहर भेजा जाता है। |
| **Waiting for an Agent** | दोबारा मैसेज करने वाले ग्राहक को बताती है कि आपकी टीम के पास चैट है। |
| **Escalate Unanswered Handoffs** | बिना जवाब वाली हैंडऑफ़ चैट को किसी दूसरे उपलब्ध एजेंट के पास भेजती है, और आपकी टीम को अलर्ट करती है। |
| **Working Hours** | वे दिन और समय जो वेलकम और ऑफ़-आवर्स जवाब के बीच फ़ैसला करते हैं। हर नंबर के अपने घंटे भी **Configuration** के नीचे हो सकते हैं। देखें [कई व्हाट्सऐप नंबर चलाएँ](run-multiple-whatsapp-numbers.md)। |

!!! note "चैटबॉट फ़्लो पहले आते हैं"
    Welcome ट्रिगर वाला चैटबॉट फ़्लो **Welcome Message** पर प्राथमिकता रखता है। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)।

## चरण { #steps }

### Live Chat Settings खोलें { #open-live-chat-settings }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें।
2. **Live Chat Settings** चुनें। पेज पर ऊपर बताई गई सेटिंग्स और एक **Save** बटन दिखता है।

    ![Live Chat Settings, जिसमें Auto Resolve Chats, Welcome Message, Off Hours Message, Waiting for an Agent, Escalate Unanswered Handoffs और Working Hours दिख रहे हैं](../assets/screenshots/whatsapp-live-chat-settings-2-settings.png)

अगर कोई नंबर कनेक्ट नहीं है, तो पेज पर **No WhatsApp account connected** दिखता है। पहले कोई नंबर कनेक्ट करें।

### निष्क्रिय चैट अपने आप रिज़ॉल्व करें { #resolve-idle-chats-automatically }

1. **Auto Resolve Chats** चालू करें।
2. **Resolve after** सूची खोलें।
3. निष्क्रिय रहने का समय चुनें: **1 h**, **2 h**, **4 h**, **8 h**, **12 h**, **24 h**, **48 h** या **72 h**।
4. **Save** पर क्लिक करें।

### वेलकम मैसेज भेजें { #send-a-welcome-message }

1. **Welcome Message** चालू करें। एक टेक्स्ट बॉक्स खुलता है।
2. जवाब लिखें। बॉक्स में एक उदाहरण दिखता है: `Hey, welcome! How can we help you?`
3. **Save** पर क्लिक करें।

यह जवाब सिर्फ़ आपके काम के घंटों में जाता है।

### ऑफ़-आवर्स मैसेज भेजें { #send-an-off-hours-message }

1. **Off Hours Message** चालू करें। एक टेक्स्ट बॉक्स खुलता है।
2. जवाब लिखें। बॉक्स में एक उदाहरण दिखता है: `Hey there, our support is currently offline. We'll get back to you soon.`
3. **Save** पर क्लिक करें।

### इंतज़ार कर रहे ग्राहकों को बताएँ कि टीम के पास उनकी चैट है { #tell-waiting-customers-that-the-team-has-their-chat }

1. **Waiting for an Agent** चालू करें। एक टेक्स्ट बॉक्स खुलता है।
2. जवाब लिखें। बॉक्स में एक उदाहरण दिखता है: `Thanks for your patience — our team has your message and will reply here shortly.`
3. **Save** पर क्लिक करें।

सीमाएँ:

- यह जवाब हर 30 मिनट में ज़्यादा से ज़्यादा एक बार जाता है।
- किसी एजेंट के जवाब देने के बाद यह कभी नहीं भेजा जाता।
- काम के घंटों के बाहर इसकी जगह **Off Hours Message** इस्तेमाल होता है।

### जिन चैट का कोई जवाब नहीं देता उन्हें एस्केलेट करें { #escalate-chats-nobody-answers }

1. **Escalate Unanswered Handoffs** चालू करें। **Escalate after** सूची खुलती है।
2. **5 min**, **10 min**, **15 min**, **30 min** या **60 min** चुनें। डिफ़ॉल्ट **15 min** है।
3. **Save** पर क्लिक करें।

इसके बाद, बिना जवाब वाली हैंडऑफ़ चैट किसी दूसरे उपलब्ध एजेंट के पास जाती है। एडमिन, मैनेजर और असाइन किए गए व्यक्ति को अलर्ट मिलता है।

### अपने काम के घंटे सेट करें { #set-your-working-hours }

1. **Working Hours** तक स्क्रॉल करें।
2. **Timezone** सूची खोलें और अपना टाइमज़ोन चुनें, जैसे **Asia/Kolkata**।
3. हर दिन के लिए, दिन के नाम के आगे वाले बॉक्स पर टिक करें ताकि वह खुला माना जाए।
4. खुलने का समय सेट करने के लिए पहले समय पर क्लिक करें। टाइम पिकर खुलता है। समय चुनें।
5. बंद होने का समय सेट करने के लिए **to** के बाद वाले दूसरे समय पर क्लिक करें।
6. किसी दिन को बंद करने के लिए उसका बॉक्स खाली करें। तब पंक्ति में **Closed** दिखता है।

7. **Save** पर क्लिक करें। **Live chat settings saved.** मैसेज दिखता है।

!!! tip "अंत में एक बार सेव करें"
    एक **Save** पेज की हर सेटिंग को रख लेता है। अगर **Could not save settings.** दिखे, तो **Save** पर दोबारा क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No WhatsApp account connected** | इस वर्कस्पेस से कोई नंबर जुड़ा नहीं है। | कोई नंबर कनेक्ट करें। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)। |
| **Could not save settings.** | सेव का अनुरोध फ़ेल हो गया। | अपना कनेक्शन जाँचें, फिर **Save** पर दोबारा क्लिक करें। |
| वेलकम मैसेज नहीं जाता | चैट काम के घंटों के बाहर शुरू हुई, या Welcome ट्रिगर वाले चैटबॉट फ़्लो ने पहले जवाब दे दिया। | **Working Hours** जाँचें, और अपने फ़्लो जाँचें। |
| ग्राहकों को दिन में ऑफ़-आवर्स मैसेज मिलता है | **Timezone** या उस दिन के घंटे गलत हैं। | उन्हें **Working Hours** के नीचे ठीक करें और **Save** पर क्लिक करें। |
| चैट एस्केलेट नहीं हो रही | **Escalate Unanswered Handoffs** बंद है, या **Escalate after** का समय अभी पूरा नहीं हुआ। | इसे चालू करें और समय चुनें। |
