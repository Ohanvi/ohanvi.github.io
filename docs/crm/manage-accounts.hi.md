# Accounts जोड़ें और मैनेज करें { #add-and-manage-accounts }

जिन कंपनियों को आप बेचते हैं, उन्हें अकाउंट के रूप में सेव करें। इससे उनके कॉन्टैक्ट और Deals एक जगह जुड़े रहते हैं। हर अकाउंट में उसकी सेहत, कॉन्टैक्ट की संख्या, ओपन Pipeline की वैल्यू, वह सोर्स जहाँ से वह आया और उसका ओनर दिखता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **CRM** दिखना चाहिए, और उसके पैनल में **Accounts**। न दिखे, तो अपने एडमिन से CRM का एक्सेस माँगें।

## स्टेप { #steps }

### अकाउंट जोड़ें { #add-an-account }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Accounts** चुनें।
2. ऊपर दाईं ओर **Add account** पर क्लिक करें। **Add Account** फ़ॉर्म खुलता है।
3. **Basic Information** के नीचे **Account Name** लिखें। सिर्फ़ यही फ़ील्ड ज़रूरी है।
4. **Account Type** चुनें: **PROSPECT**, **CUSTOMER**, **PARTNER**, **VENDOR** या **OTHER**। डिफ़ॉल्ट **PROSPECT** है।
5. अगर यह कंपनी किसी ग्रुप की है, तो **Parent Account (Client Group)** चुनें। **Industry** और **Website** भी जोड़ें।
6. चाहें तो **Contact Information** (**Phone**, **Email**), **Company Details** (**Annual Revenue**, **Employees**), **Billing Address**, **Shipping Address** और **Description** भरें।
7. **Submit** पर क्लिक करें। अकाउंट लिस्ट में दिखने लगता है।

अगर किसी सेव किए अकाउंट का नाम, फ़ोन या ईमेल वही है, तो फ़ॉर्म में **Possible duplicate — "…" already has a matching name, phone or email.** दिखता है। आप फिर भी उसे सेव कर सकते हैं। पर पहले देख लें कि आप वही अकाउंट दोबारा तो नहीं बना रहे।

### अकाउंट की लिस्ट पढ़ें { #read-the-account-list }

हर रो में **Company**, **Health**, **Contacts**, **Open pipeline**, **Source** और **Owner** दिखते हैं। **Health** अकाउंट की Deals देखकर तय होती है:

| सेहत | मतलब |
| --- | --- |
| **Customer** | अकाउंट की कोई Deal जीती जा चुकी है, या उसका टाइप **CUSTOMER** है। |
| **Active** | उसकी ओपन Deals पिछले 30 दिनों में आगे बढ़ी हैं। |
| **At risk** | उसकी ओपन Deals हैं, पर कोई भी 30 दिन या उससे ज़्यादा से आगे नहीं बढ़ी। |
| **New** | उसकी अभी कोई ओपन Deal नहीं है। |

### अकाउंट फ़िल्टर करें और खोलें { #filter-and-open-accounts }

1. लिस्ट छोटी करने के लिए कोई एक व्यू चुनें: **Customers**, **At risk** या **My accounts**। **All** हर अकाउंट दिखाता है।
2. किसी अकाउंट पर क्लिक करें। Ohanvi उस कंपनी के कॉन्टैक्ट खोल देता है।

### लिस्ट एक्सपोर्ट करें { #export-the-list }

1. लिस्ट को फ़िल्टर करके सिर्फ़ वही अकाउंट रखें जो आपको चाहिए।
2. **Export** पर क्लिक करें। स्क्रीन पर दिख रही रो की CSV फ़ाइल डाउनलोड हो जाती है, और **Exported N accounts.** दिखता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Account name is required.** | **Account Name** खाली है। | नाम लिखें और दोबारा सबमिट करें। |
| **Invalid account type 'COMPETITOR'.** | **COMPETITOR** **Account Type** की लिस्ट में दिखता है, पर सर्वर उसे मंज़ूर नहीं करता। | उसकी जगह **OTHER** चुनें। |
| **Account has active contacts. Reassign or delete them first.** | आपने ऐसा अकाउंट डिलीट करने की कोशिश की जिसमें अब भी कॉन्टैक्ट हैं। | कॉन्टैक्ट को किसी दूसरे अकाउंट में ले जाएँ, या उन्हें डिलीट करें। फिर दोबारा कोशिश करें। |
| **Export** नहीं दिख रहा | लिस्ट खाली है। | पहले कोई अकाउंट जोड़ें। |
| अकाउंट **At risk** दिखता है, पर आपने इसी हफ़्ते उनसे बात की है | सेहत सिर्फ़ यह देखती है कि Deal आख़िरी बार कब अपडेट हुई। | Deal अपडेट करें, जैसे उसका **Next Step**। |
