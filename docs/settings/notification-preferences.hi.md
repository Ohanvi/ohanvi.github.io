# नोटिफ़िकेशन कैसे मिलें, खुद चुनें { #choose-how-notifications-reach-you }

हर मॉड्यूल के लिए चुनें कि Ohanvi आपको ऐप में बताए, पुश नोटिफ़िकेशन से बताए या ईमेल से। स्विच दबाते ही बदलाव सेव हो जाता है। इसलिए स्विच सही जगह आते ही आपका काम पूरा।

## शुरू करने से पहले { #before-you-start }

- आप Ohanvi में साइन इन हों। देखें [Ohanvi में साइन इन करें](../sign-in.md)।
- आपके पास कम से कम 1 ऐसे मॉड्यूल का एक्सेस हो जो नोटिफ़िकेशन भेजता है, जैसे **WhatsApp** या **CRM**।

## स्टेप { #steps }

### नोटिफ़िकेशन चालू या बंद करें { #turn-notifications-on-or-off }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. Settings की लिस्ट में सबसे ऊपर अपने नाम पर क्लिक करें।
3. **Preferences** के नीचे **Notifications** पर क्लिक करें। **Notifications** पेज खुलेगा, जिसमें हर मॉड्यूल की 1 रो होगी।
4. जिस मॉड्यूल को बदलना है, उसकी रो में **In-app** या **Push** के नीचे वाला स्विच दबाएँ। ऊपर थोड़ी देर **Saving…** दिखेगा।

लिस्ट में सिर्फ़ वही मॉड्यूल दिखते हैं जो आप खोल सकते हैं। नए मॉड्यूल का एक्सेस मिलते ही वे लिस्ट में जुड़ जाते हैं।

### अलग-अलग इवेंट चुनें { #fine-tune-single-events }

1. जिस मॉड्यूल की रो है, उसमें **Fine-tune per event** पर क्लिक करें। उस मॉड्यूल की अपनी नोटिफ़िकेशन सेटिंग्स खुलेंगी।
2. वहाँ हर इवेंट को अलग से चालू या बंद करें।

यह लिंक हर मॉड्यूल में नहीं होता।

### पूरे वर्कस्पेस के लिए ईमेल नोटिफ़िकेशन { #email-notifications-for-the-whole-workspace }

Super Admin को एक **Email** कॉलम भी दिखता है। इससे उस मॉड्यूल के ईमेल अलर्ट पूरे वर्कस्पेस के लिए चालू या बंद होते हैं, सिर्फ़ आपके लिए नहीं। बाकी सबको सिर्फ़ **In-app** और **Push** दिखते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Couldn't save that change — please try again.** | बदलाव सर्वर तक नहीं पहुँचा। | अपना इंटरनेट कनेक्शन देखें और स्विच दोबारा दबाएँ। |
| **Couldn't save the email setting — please try again.** | ईमेल वाला स्विच सेव नहीं हुआ। | दोबारा कोशिश करें। फिर भी न हो, तो सपोर्ट टीम से बात करें। |
| **No notification settings for your current access yet — they appear as you get access to modules that send notifications.** | आपके रोल में ऐसा कोई मॉड्यूल नहीं है जो नोटिफ़िकेशन भेजता हो। | अपने वर्कस्पेस के मालिक से मॉड्यूल का एक्सेस माँगें। |
| **Email** कॉलम नहीं दिख रहा | ईमेल अलर्ट सिर्फ़ Super Admin बदल सकते हैं। | अपने वर्कस्पेस के मालिक से कहें। |
| पुश नोटिफ़िकेशन नहीं आ रहे | आपका ब्राउज़र या फ़ोन Ohanvi के नोटिफ़िकेशन रोक रहा है। | अपने ब्राउज़र या फ़ोन की सेटिंग्स में app.ohanvi.com के नोटिफ़िकेशन की अनुमति दें [VERIFY: push delivery requirements]। |
