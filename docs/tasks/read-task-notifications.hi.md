# टास्क नोटिफ़िकेशन पढ़ें { #read-task-notifications }

नोटिफ़िकेशन बेल सारे अलर्ट एक पैनल में इकट्ठा करती है। इसका **Tasks** टैब आपके टास्क में हुए बदलाव तीन सूचियों में दिखाता है: **Created by me**, **New created** और **Watcher**। बेल पर लाल बिंदु का मतलब है कि कुछ अनपढ़ा है।

## शुरू करने से पहले { #before-you-start }

- आपको दाईं ओर की रेल में **Tasks** आइकन दिखता हो। टास्क एक्सेस के बिना **Tasks** टैब छिपा रहता है।
- आपने कम से कम 1 टास्क बनाया हो, या उसे वॉच करते हों। देखें [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](collaborate-on-tasks.md)।

## चरण { #steps }

### नोटिफ़िकेशन पैनल खोलें { #open-the-notifications-panel }

1. दाईं ओर की रेल में बेल खोजें।
2. उस पर छोटा लाल बिंदु देखें। बिंदु का मतलब है कि टास्क अलर्ट अनपढ़े हैं।
3. बेल पर क्लिक करें। **Notifications** पैनल खुलता है।
4. इसे बंद करने के लिए क्रॉस पर क्लिक करें, टूलटिप **Close**, या पैनल के बाहर क्लिक करें।

### General और Tasks के बीच बदलें { #switch-between-general-and-tasks }

1. टाइटल के नीचे दो टैब देखें: **General** और **Tasks**।
2. दूसरे मॉड्यूल के अलर्ट के लिए **General** पर क्लिक करें।
3. टास्क अलर्ट के लिए **Tasks** पर क्लिक करें। टैब के पास का नंबर बताता है कि कितने अनपढ़े हैं।

### टास्क की सूचियाँ पढ़ें { #read-the-task-lists }

1. **Tasks** टैब पर तीन टैब खोजें: **Created by me**, **New created** और **Watcher**।
2. आपके रिपोर्ट किए टास्क में हुए बदलाव के लिए **Created by me** पर क्लिक करें।
3. अभी-अभी बने टास्क के लिए **New created** पर क्लिक करें।
4. जिन टास्क को आप वॉच करते हैं उनके बदलाव के लिए **Watcher** पर क्लिक करें। देखें [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](collaborate-on-tasks.md)।
5. हर पंक्ति पढ़ें। अनपढ़े अलर्ट पर बिंदु दिखता है।
6. अगर कोई सूची खाली है, तो उसमें **No notifications here** लिखा होता है।

### फ़ेल हुई सूची दोबारा लोड करें { #reload-a-list-that-failed }

1. अगर किसी सूची में एरर दिखे, तो **Retry** बटन खोजें।
2. **Retry** पर क्लिक करें। सूची फिर से लोड होती है।

### अलर्ट आप तक कैसे पहुँचें, यह चुनें { #choose-how-alerts-reach-you }

1. टास्क अलर्ट चालू या बंद करने के लिए **Settings** खोलें।
2. [नोटिफ़िकेशन आप तक कैसे पहुँचें, यह चुनें](../settings/notification-preferences.md) का पालन करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Tasks** टैब नहीं दिख रहा। | आपके रोल के पास टास्क एक्सेस नहीं है। | अपने एडमिन से पूछें। देखें [टीम के सदस्य, रोल और अनुमतियाँ प्रबंधित करें](../settings/roles-and-permissions.md)। |
| **No notifications here** | उस सूची में कुछ नहीं बदला है। | कोई टास्क वॉच करें, या एक बनाएँ। |
| **Failed to load notifications** | सूची लोड नहीं हो सकी। | **Retry** पर क्लिक करें। |
| बेल पर लाल बिंदु बना रहता है। | कुछ अलर्ट अनपढ़े हैं। | हर सूची खोलें और पंक्तियाँ पढ़ें। [VERIFY: how alerts are marked as read] |
