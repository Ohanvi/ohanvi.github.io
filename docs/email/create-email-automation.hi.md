# जर्नी से ईमेल ऑटोमेट करें { #automate-emails-with-journeys }

ऐसा ऑटोमेशन Flow (जर्नी) बनाएँ जो कॉन्टैक्ट को अपने-आप ईमेल भेजे। जैसे, कोई आपकी न्यूज़लेटर लिस्ट में जुड़े, तो उसे वेलकम सीरीज़ चली जाए। आख़िर में Flow **Active** हो जाता है। जो भी नया कॉन्टैक्ट शुरुआती शर्त पूरी करता है, वह आपके कुछ किए बिना सारे स्टेप से गुज़रता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Email** दिखे और उसके पैनल में **Flows** हो। अगर नहीं दिखता, तो अपने एडमिन से एक्सेस माँगें।
- आपके पास एक वेरिफ़ाइड भेजने वाला पता और कम से कम 1 Approved ईमेल टेम्प्लेट हो। इसके लिए [भेजने वाला पता सेट करें और अपना डोमेन वेरिफ़ाई करें](set-up-sender-identity.md) और [ईमेल टेम्प्लेट बनाएँ](create-email-template.md) देखें।
- आपकी टीम में कोई ऐसा सदस्य हो जिसके पास मंज़ूरी देने का एक्सेस हो। जो Flow आपने खुद बनाया है, उसे आप खुद एक्टिवेट नहीं कर सकते।
- Flow से भेजा गया हर ईमेल क्रेडिट इस्तेमाल करता है। इसके लिए [क्रेडिट और बिलिंग](../credits-and-billing.md) देखें।

## स्टेप { #steps }

### Flow शुरू करें { #start-a-flow }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Flows** चुनें। साझा **Flows** स्क्रीन खुलेगी। ईमेल ऑटोमेशन उसी कैनवास पर बनते हैं जिस पर बाकी चैनलों के Flow बनते हैं। इसके लिए [ऑटोमेशन फ़्लो बनाएँ](../flows/build-automation-flow.md) देखें। पुरानी जर्नी **Not yet migrated** के नीचे दिखती हैं।
2. शुरू करने का तरीका चुनें:
    - पहले से बना Flow चुनने के लिए **Choose flow template** पर क्लिक करें, जैसे **Single Welcome Email**, **Simple 2-Email Nurture**, **Welcome Series (3 emails)**, **Tag Engaged Contacts** या **Win-Back Then Sunset**।
    - खाली Flow के लिए **Build from scratch** पर क्लिक करें।
3. **Build a New Flow** पेज खुलेगा। सब कुछ इसी 1 पेज पर सेट होता है।

### Flow का नाम रखें और शुरुआत चुनें { #name-the-flow-and-choose-what-starts-it }

1. **Journey Name** में ऐसा नाम लिखें जिसे आपकी टीम पहचान सके, जैसे `New Subscriber Welcome`।
2. शुरुआती पॉइंट चुनें:

    | शुरुआती पॉइंट | कब शुरू होता है | और क्या भरें |
    | --- | --- | --- |
    | **Signs up for email** | कोई कॉन्टैक्ट आपकी चुनी हुई लिस्ट में जुड़ता है। उस लिस्ट के साइनअप फ़ॉर्म से आए साइनअप भी इसमें गिने जाते हैं। | **Trigger List (enroll on join)** |
    | **Tag added** | आपका चुना हुआ टैग किसी कॉन्टैक्ट पर लगता है, चाहे हाथ से, बल्क में या इम्पोर्ट से। | **Trigger Tag (enroll when added)** |
    | **Birthday** | कॉन्टैक्ट का जन्मदिन है, या उससे तय दिन पहले। | **Days Before Birthday** (0–365) |
    | **Abandons a cart** | कोई खरीदार आपके कनेक्ट किए स्टोर पर पेमेंट किए बिना चेकआउट छोड़ देता है। अगर वह खरीद लेता है, तो यह अपने-आप कैंसिल हो जाता है। | — |

3. चाहें तो **Filter contacts** के नीचे ऐसी शर्तें जोड़ें जो तय करें कि Flow में किन कॉन्टैक्ट को लिया जाए।

### स्टेप जोड़ें { #add-the-steps }

1. **Sender** चुनें।
2. पैलेट से स्टेप खींचकर Flow मैप पर रखें:
    - **Send Email** — **Template \*** चुनें।
    - **Wait** — **Wait (minutes) \*** सेट करें। जैसे, 1440 मिनट यानी 1 दिन।
    - **Tag Contact** और **Remove Tag** — टैग जोड़ें या हटाएँ।
    - **If/Else** — **Field**, **Operator** और **Value \*** के आधार पर अलग रास्ता बनाएँ।
    - **Split Path (A/B)** — कॉन्टैक्ट को बराबर-बराबर 2 रास्तों में बाँटें।
    - **Unsubscribe** — कॉन्टैक्ट को आगे के सभी ईमेल से अनसब्सक्राइब करें।
    - **Webhook** — किसी दूसरे सिस्टम में **Webhook URL \*** को कॉल करें।
3. स्टेप का क्रम बदलने के लिए उन्हें खींचें।
4. **Check everything before saving** के नीचे दिया सारांश जाँचें।
5. **Save Flow** पर क्लिक करें। Flow **Draft** के रूप में सेव होगा। वह अभी चलेगा नहीं।

कार्ट वाले ईमेल के लिए टेम्प्लेट में `{{cartValue}}`, `{{cartItems}}` और `{{recoveryUrl}}` इस्तेमाल करें।

### Flow चालू करें { #turn-the-flow-on }

1. अपनी टीम के किसी सदस्य से **Flows** खोलने को कहें।
2. वे Flow पर **⋮** (**More actions**) पर क्लिक करें, फिर **Activate** पर क्लिक करें। स्टेटस **Active** हो जाएगा।

नए कॉन्टैक्ट का आना रोकने के लिए **⋮** → **Pause** पर क्लिक करें। जो कॉन्टैक्ट पहले से Flow में हैं, वे जहाँ हैं वहीं रुके रहेंगे। जब आप Flow फिर से एक्टिवेट करेंगे, तब वे आगे बढ़ेंगे। Flow की कॉपी बनाने के लिए **⋮** → **Clone** पर क्लिक करें।

!!! note "ध्यान दें"
    चालू Flow को एडिट करने के लिए पहले उसे पॉज़ करें, बदलाव करें, फिर उसे दोबारा एक्टिवेट करें।

## Flow के स्टेटस { #flow-statuses }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | सेव है और एडिट किया जा सकता है। कोई कॉन्टैक्ट जुड़ा नहीं है। |
| **Active** | कॉन्टैक्ट को जोड़ रहा है और ईमेल भेज रहा है। |
| **Paused** | नए कॉन्टैक्ट नहीं जुड़ते, और Flow में पहले से मौजूद कॉन्टैक्ट आगे नहीं बढ़ते। |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **You cannot activate your own journey.** | Flow चालू करने के लिए दूसरे व्यक्ति की ज़रूरत होती है। | मंज़ूरी का एक्सेस रखने वाले टीम मेंबर से **Activate** पर क्लिक करने को कहें। |
| **Journey has no steps.** या **A journey needs at least one step.** | Flow मैप खाली है। | मैप पर कम से कम 1 **Send Email** स्टेप खींचकर रखें। |
| **Pause the journey before editing it.** | Flow **Active** है। | **Pause** पर क्लिक करें, एडिट करें, फिर दोबारा एक्टिवेट करें। |
| **A journey named '…' already exists.** | यह नाम पहले से लिया जा चुका है। | कोई दूसरा **Journey Name** रखें। |
| **Trigger tag is required for a Tag Added journey.** | **Tag added** चुना गया है पर टैग नहीं दिया। | **Trigger Tag (enroll when added)** भरें। |
| **Enter a whole number of days between 0 and 365** | **Days Before Birthday** सीमा से बाहर है। | 0 से 365 के बीच की संख्या लिखें। |
