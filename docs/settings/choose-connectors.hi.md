# अपनी या Ohanvi की मैनेज्ड सर्विस चुनें { #choose-your-own-or-ohanvis-managed-services }

WhatsApp, AI और ईमेल के लिए आप तय कर सकते हैं कि Ohanvi आपका अपना प्रोवाइडर अकाउंट इस्तेमाल करे या अपनी मैनेज्ड सर्विस। आखिर में हर चैनल पर दिखेगा कि कौन-सा विकल्प चालू है और उसका बिल कैसे बनता है।

## शुरू करने से पहले { #before-you-start }

- **Settings** में आपके नाम के नीचे **Connectors** दिखना चाहिए। न दिखे, तो अपने वर्कस्पेस ओनर से पूछें।
- WhatsApp का विकल्प चुनने से पहले आपका WhatsApp नंबर कनेक्ट होना चाहिए। न हो, तो **WhatsApp (Meta)** कार्ड पर **Set up WhatsApp** पर क्लिक करें।
- अपना AI या ईमेल प्रोवाइडर लगाना है, तो उस प्रोवाइडर की API key या लॉगिन आपके पास होना चाहिए।

## बिलिंग में क्या फ़र्क है { #how-billing-differs }

मैनेज्ड सर्विस का बिल आपके क्रेडिट से कटता है। अपने अकाउंट का बिल प्रोवाइडर खुद बनाता है। ज़्यादा जानकारी के लिए [Ohanvi में क्रेडिट और बिलिंग](../credits-and-billing.md) देखें।

| चैनल | Ohanvi मैनेज्ड | आपका अपना |
| --- | --- | --- |
| **WhatsApp (Meta)** | **Pay through Ohanvi** — आपके क्रेडिट से Meta की दर और Ohanvi का कमीशन दोनों कटते हैं। | **Pay Meta directly** — आप Meta को सीधे पेमेंट करते हैं। आपके क्रेडिट से सिर्फ़ Ohanvi का इस्तेमाल कमीशन कटता है। |
| **AI** | **Ohanvi’s AI key** — Ohanvi की अपनी AI key, जो सबके लिए साझा है। | **Your key · connected** — आपकी अपनी Gemini, OpenAI या Anthropic key। |
| **Email** | **Ohanvi’s shared sender** | **Your provider · connected** — आपका अपना ईमेल प्रोवाइडर। |

## स्टेप { #steps }

### Connectors खोलें { #open-connectors }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. Settings की लिस्ट में सबसे ऊपर अपने नाम पर क्लिक करें।
3. **Billing & credits** के नीचे **Connectors** पर क्लिक करें। **Connectors** पेज खुलेगा और उसमें 3 कार्ड दिखेंगे।

### चुनें कि WhatsApp का बिल कैसे बने { #choose-how-whatsapp-is-billed }

1. **WhatsApp (Meta)** कार्ड पर **Pay through Ohanvi** या **Pay Meta directly** पर क्लिक करें।
2. **WhatsApp billing updated.** मैसेज आता है।

अगर कार्ड पर **Not set up** दिखे, तो पहले **Set up WhatsApp** पर क्लिक करें और अपना नंबर कनेक्ट करें।

### अपनी AI key इस्तेमाल करें { #use-your-own-ai-key }

1. **AI** कार्ड पर **Connect your own AI key** पर क्लिक करें। **AI Connectors** पेज खुलता है।
2. **Provider** में **Gemini**, **OpenAI** या **Anthropic** चुनें। **Credentials** में **API key** पेस्ट करें और एक **Model** चुनें। फिर **Test connection** पर क्लिक करें, और उसके बाद **Connect** पर।
3. **Connectors** पर वापस जाएँ और **Refresh** पर क्लिक करें। कार्ड पर **Your key · connected** दिखता है।

बाद में बदलाव करना हो, तो **Manage AI provider** पर क्लिक करें।

### अपना ईमेल प्रोवाइडर इस्तेमाल करें { #use-your-own-email-provider }

1. **Email** कार्ड पर **Connect your own provider** पर क्लिक करें। ईमेल प्रोवाइडर का पेज खुलता है।
2. अपने प्रोवाइडर की जानकारी भरें और सेव करें। प्रोवाइडर सेट करने का तरीका [ईमेल सेक्शन](../email/index.md) में देखें।
3. **Connectors** पर वापस जाएँ और **Refresh** पर क्लिक करें। कार्ड पर **Your provider · connected** दिखता है।

बाद में बदलाव करना हो, तो **Manage email providers** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not update WhatsApp billing.** | बदलाव सेव नहीं हुआ। | दोबारा कोशिश करें। फिर भी न हो, तो सपोर्ट से संपर्क करें। |
| **WhatsApp (Meta)** पर **Not set up** दिख रहा है | कोई WhatsApp नंबर कनेक्ट नहीं है। | **Set up WhatsApp** पर क्लिक करें और अपनी WhatsApp सेटिंग्स जोड़ें। |
| AI या Email कार्ड पर अब भी Ohanvi की सर्विस दिख रही है | key जोड़ने के बाद पेज दोबारा लोड नहीं हुआ। | **Refresh** पर क्लिक करें। |
| अपने नाम के नीचे **Connectors** नहीं दिख रहा | आपके रोल को यह दिखता ही नहीं। | अपने वर्कस्पेस ओनर से पूछें। |
