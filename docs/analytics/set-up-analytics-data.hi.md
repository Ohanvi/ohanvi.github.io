# एनालिटिक्स के लिए डेटा सेट करें { #set-up-data-for-analytics }

अपनी **Analytics** स्क्रीन में असली आँकड़े लाएँ। इसके बाद **Marketing Analytics** में दिखेगा कि आपके WhatsApp ब्रॉडकास्ट कैसे चले। **Store Analytics** में आपके कनेक्ट किए हुए Shopify या WooCommerce स्टोर के ऑर्डर और रेवेन्यू दिखेंगे। यह भी दिखेगा कि WhatsApp से कितना फ़ायदा हुआ।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Analytics** दिखता हो। यह तभी दिखता है जब आपके वर्कस्पेस में WhatsApp चालू हो और आपका रोल WhatsApp खोल सकता हो।
- आपका WhatsApp नंबर कनेक्ट हो। देखें [अपना WhatsApp नंबर कनेक्ट करें](../whatsapp/connect-whatsapp-number.md)।
- स्टोर के आँकड़े चाहिए, तो आपके पास अपने Shopify या WooCommerce स्टोर के एडमिन अधिकार हों।

## स्टेप { #steps }

### देखें कि आपको क्या-क्या दिखता है { #check-what-you-can-see }

1. लेफ़्ट रेल में **Analytics** खोलें। पैनल में वे स्क्रीन दिखेंगी जो आपका रोल खोल सकता है।
2. **Marketing Analytics** देखें। यह तब दिखता है जब आपका रोल WhatsApp ब्रॉडकास्ट देख सकता हो।
3. **Store Analytics** देखें। यह तब दिखता है जब आपका रोल स्टोर इंटीग्रेशन देख सकता हो।

कोई आइटम न दिखे, तो अपने एडमिन से कहें कि वह एक्सेस आपके रोल में जोड़ दें। दोनों न दिखें, तो **Analytics** आइकन भी नहीं दिखता।

### Marketing Analytics में डेटा लाएँ { #feed-marketing-analytics }

**Marketing Analytics** सिर्फ़ WhatsApp **Campaign** ब्रॉडकास्ट से भेजे गए मैसेज गिनता है। **Inbox** की चैट नहीं गिनी जातीं।

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।
2. कम से कम एक कॉन्टैक्ट को ब्रॉडकास्ट भेजें।
3. WhatsApp से डिलीवरी और रीड की जानकारी आने का इंतज़ार करें। ये अपडेट अगले कुछ मिनटों और घंटों में आते हैं।
4. लेफ़्ट रेल में **Analytics** खोलें, फिर **Marketing Analytics** चुनें। ताज़ा आँकड़े देखने के लिए **Refresh** पर क्लिक करें।

### Store Analytics और रेवेन्यू के लिए स्टोर कनेक्ट करें { #connect-a-store-for-store-analytics-and-revenue }

1. लेफ़्ट रेल में **Connect** खोलें, फिर **Store Connections** चुनें।
2. Shopify या WooCommerce कार्ड पर **Connect store** या **Connect** पर क्लिक करें।
3. अपने स्टोर की स्क्रीन पर एक्सेस की इजाज़त दें। वापस आने पर एक मैसेज दिखेगा कि स्टोर कनेक्ट हो गया है और ग्राहक व ऑर्डर सिंक हो रहे हैं।
4. सिंक पूरा होने तक रुकें। इसके बाद आपका स्टोर जैसे ही नया ऑर्डर भेजेगा, वह यहाँ आ जाएगा।
5. लेफ़्ट रेल में **Analytics** खोलें, फिर **Store Analytics** चुनें। **Refresh** पर क्लिक करें।

यहाँ कनेक्ट किया गया स्टोर WhatsApp के स्टोर फ़ीचर भी चलाता है। उसे **WhatsApp** → **Manage** → **Integrations** में दोबारा कनेक्ट करने की ज़रूरत नहीं है।

!!! note "ध्यान दें"
    स्टोर कनेक्ट होने के बाद **Marketing Analytics** में **Orders** टाइल और **What it earned** पैनल भी दिखने लगते हैं। कोई ऑर्डर किसी ब्रॉडकास्ट के नाम तब गिना जाता है, जब खरीदार ने वह ब्रॉडकास्ट मिलने के 7 दिन के अंदर ऑर्डर किया हो (last-touch attribution)।

### तारीख़ की अवधि चुनें { #pick-a-date-window }

दोनों स्क्रीन में अवधियाँ पहले से तय हैं। आप अपनी पसंद की तारीख़ें नहीं चुन सकते।

| स्क्रीन | अवधियाँ |
| --- | --- |
| **Marketing Analytics** | **7d**, **30d** (डिफ़ॉल्ट), **90d**, **All** |
| **Store Analytics** | **7d**, **30d** (डिफ़ॉल्ट), **90d**, **1y**, **All** |

1. ऊपर दाईं ओर किसी अवधि वाले बटन पर क्लिक करें। स्क्रीन उस अवधि के लिए दोबारा लोड होगी।
2. अवधि बदले बिना दोबारा लोड करना हो, तो **Refresh** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| लेफ़्ट रेल में **Analytics** नहीं है | आपके वर्कस्पेस में WhatsApp चालू नहीं है, या आपके रोल के पास दोनों में से कोई एनालिटिक्स एक्सेस नहीं है। | अपने एडमिन से कहें कि WhatsApp चालू करें और आपके रोल को ब्रॉडकास्ट या स्टोर का एक्सेस दें। |
| **No broadcasts in this window** | चुनी हुई अवधि में कोई **Campaign** ब्रॉडकास्ट नहीं भेजा गया। | **90d** या **All** जैसी लंबी अवधि चुनें, या ब्रॉडकास्ट भेजें। |
| **Store Analytics** में **No orders in this window** | कोई स्टोर कनेक्ट नहीं है, या स्टोर ने इस अवधि में कोई ऑर्डर नहीं भेजा। | **Connect** → **Store Connections** में स्टोर कनेक्ट करें, या लंबी अवधि चुनें। |
| **Access was not approved on …, so nothing was connected.** | आपने WooCommerce की मंज़ूरी स्क्रीन पर एक्सेस नहीं दिया। | **Connect** पर फिर से क्लिक करें और एक्सेस दे दें। |
| कनेक्ट करते ही आँकड़े कम दिख रहे हैं | ग्राहक और ऑर्डर अभी आपके स्टोर से सिंक हो रहे हैं। | कुछ मिनट रुकें, फिर **Refresh** पर क्लिक करें। |
| **Marketing Analytics** में **Orders** टाइल नहीं है | कोई स्टोर कनेक्ट और चालू नहीं है। | स्टोर कनेक्ट करें, फिर **Refresh** पर क्लिक करें। |
