# Create an event

Create an event in 2 steps: its details, then the design of the guest page. At the end you have a draft event, ready for photos. Publish it when guests should see their photos. Setup takes about 3 minutes.

## Before you start

- You can see **Photos** on the left rail. If not, ask your admin to give your role access. See [Team, roles and permissions](../settings/roles-and-permissions.md).

## Steps

### Find your events

1. Click **Photos** on the left rail, then select **Events**. The list reads **Every event you photograph, and its gallery.**
2. Pick a tab: **All**, **Published**, **Draft** or **Expired**.
3. To find one event, type in **Search events by name**.

| Tab | What it lists |
| --- | --- |
| **Published** | Events guests can open. |
| **Draft** | Events guests cannot open yet. |
| **Expired** | Events whose gallery has closed. The photos are kept. |

### Add the details

1. On **Events**, click **Create event**. The form reads **Set up the event, then choose how its gallery looks.**
2. In **Event name**, type the name guests will see, for example `Aarav & Diya Wedding`.
3. Pick the **Event type**: **Wedding**, **Engagement**, **Birthday**, **Corporate** or **Other**.
4. Under **Dates**, pick the **Start date** and **End date**. Leave the end date empty for a one-day event.
5. In **Venue**, type where it is held, for example `Rambagh Palace, Jaipur`.
6. Optional: in **Description**, type a line about the event. Guests see it on the gallery.
7. Click **Next: design**.

### Pick the guest-page design

1. Under **How the guest gallery looks**, pick a design.
2. Click **Create event**. The message **Event created. Upload its photos next.** appears, and the event opens as a draft.

| Design | How it looks |
| --- | --- |
| **Lavender Dream** | Soft lilac with floral corners. |
| **Red Frame** | A bold red border around every photo. |
| **Maroon Majesty** | Deep maroon with gold lettering. |
| **Golden Glow** | Warm gold on ivory. |
| **Plain** | Just the photos, nothing else. |

You can change the design later. Guests see it when they open the gallery.

A **Wedding** event comes with the folders Haldi, Mehendi, Sangeet, Pheras and Reception. See [Upload and organise photos](upload-and-organise-photos.md).

### Publish the event

Guests see no photos until you publish. They can still register on a draft event, so you can put the QR code up early.

1. Open the event from **Events**. The top of the workspace reads **Guests cannot open the gallery yet.**
2. Click **Publish**. The window **Publish "Aarav & Diya Wedding"?** opens and reads **Guests can open the gallery and find their photos with a selfie.**
3. Click **Publish**. The top now reads **Guests can open the gallery.**

To close the gallery, click **Unpublish**. Guests can no longer open the gallery. The photos are kept, and you can publish again.

### Edit or delete an event

- To edit, open the event and click **Edit event**, change the details or design, and click **Save changes**. The message **Event saved.** appears.
- To delete, open the event's menu on **Events** and click **Delete event**.

!!! warning "Guests lose the gallery"
    When you delete an event, it and its photos leave your list, and guests can no longer open its gallery.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **Give the event a name.** | **Event name** is empty. | Type a name, then click **Next: design**. |
| **The event cannot end before it starts.** | The end date is before the start date. | Pick a later end date, or leave it empty for a one-day event. |
| **Couldn't create the event.** or **Couldn't save the event.** | Ohanvi could not save it. | Check your connection and try again. |
| Guests scan the QR code and see no photos | The event is still a draft. | Click **Publish**. |
| The event is under **Expired** | The gallery has closed. | Open the event to see its photos. They are kept. |
