# ईमेल ग्रुप का इस्तेमाल करें { #use-email-groups }

Email Groups में आपकी लिस्ट और सेगमेंट एक ही जगह रहते हैं। फ़िक्स्ड ग्रुप वह लिस्ट है जिसे आप हाथ से भरते हैं। रूल ग्रुप वह सेगमेंट है जिसे कोई नियम अपने-आप अपडेट रखता है। अंत में आप सदस्यों को प्रबंधित कर सकते हैं, ग्रुप मर्ज कर सकते हैं और किसी भी तरह के ग्रुप पर कैंपेन चला सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको **Email** पैनल में **Audience** दिखता हो। अगर नहीं दिखता, तो अपने एडमिन से पूछें।
- आपके पास संपर्क हों। देखें [ईमेल संपर्क, लिस्ट और सेगमेंट जोड़ें](manage-email-contacts.md)।

## चरण { #steps }

### Email Groups खोलें { #open-email-groups }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Audience** चुनें।
2. **Email Groups** टैब खोलें।
3. **Fixed** या **Rule** चुनें। हर पिल पर एक गिनती दिखती है।
   - **Fixed** का मतलब: ऐसे ग्रुप जिनमें आप लोगों को हाथ से डालते हैं।
   - **Rule** का मतलब: ऐसे ग्रुप जिन्हें कोई नियम आपके संपर्क बदलने के साथ अपडेट रखता है।

### फ़िक्स्ड लिस्ट के साथ काम करें { #work-with-a-fixed-list }

1. **Create list** पर क्लिक करें और **List Name** और **Description** भरें। उसे सेव करें।
2. वैकल्पिक लिस्ट सेटिंग्स तय करें: **Require Double Opt-in**, **Default Sender Identity**, **Default Topic** और **Confirmation Email Template**।
3. लिस्ट का **⋮** मेन्यू खोलें और कोई कार्रवाई चुनें:
   - **Manage Members** लोगों को जोड़ता या हटाता है।
   - **Duplicate** लिस्ट की कॉपी बनाता है। कॉपी के नाम में **(Copy)** जुड़ जाता है। आप उसके सदस्य भी कॉपी कर सकते हैं।
   - **Merge Into Another List** इसके सदस्यों को आपकी चुनी हुई **Target List** में डाल देता है।
   - **Delete List** लिस्ट हटा देता है। संपर्क आपकी ऑडियंस में बने रहते हैं।

### रूल सेगमेंट के साथ काम करें { #work-with-a-rule-segment }

1. नियमों से सेगमेंट बनाने के लिए **Create segment** पर क्लिक करें। या व्हाट्सऐप ग्रुप से शुरू करने के लिए **From WhatsApp Group** चुनें।
2. किसी सेगमेंट का मेन्यू खोलें और कोई कार्रवाई चुनें:
   - **Edit conditions** नियम बदलता है।
   - **Preview Matches** दिखाता है कि अभी कौन मेल खाता है।
   - **Use in Campaign** उस सेगमेंट पर चलने वाला कैंपेन शुरू करता है।
   - **Combine Segments** 2 सेगमेंट से एक नया सेगमेंट बनाता है। **New Segment Name** लिखें, फिर **Combine With** चुनें। संपर्क को दोनों से मेल खाना होगा।
   - **Duplicate Segment** उसकी कॉपी बनाता है।
   - **Delete Segment** सेगमेंट हटाता है, संपर्क नहीं।

सेगमेंट लिस्ट को छोटा करता है। वह उन लोगों को कभी नहीं जोड़ता जो लिस्ट में नहीं हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No contacts match these conditions yet.** | नियम बहुत सख़्त है। | कोई फ़िल्टर ढीला करें, या **all** को **any** कर दें। |
| लिस्ट में उम्मीद से कम लोग हैं। | भेजते समय अनसब्सक्राइब हुए संपर्क छोड़ दिए जाते हैं। | **Emails** टैब पर **Unsubscribed** टैब देखें। |
| पैनल में **Lists** या **Segments** नहीं मिल रहे। | अब वे **Audience** के अंदर हैं। | **Audience** खोलें, फिर **Email Groups**। |
