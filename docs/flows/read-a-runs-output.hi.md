# किसी रन का आउटपुट विस्तार से पढ़ें { #read-a-runs-output-in-detail }

**Latest output** टैब खोलकर देखें कि रन के हर चरण ने क्या किया और क्या लौटाया। अंत में आप बता सकते हैं कि कौन सा चरण और क्यों फ़ेल हुआ, किसी चरण को क्या भेजा गया, और रन ने कौन सा वर्शन इस्तेमाल किया। आप आउटपुट कॉपी करके सपोर्ट को भेज भी सकते हैं।

## शुरू करने से पहले { #before-you-start }

- फ़्लो कम से कम एक बार चल चुका हो। अभी रन शुरू करने के लिए देखें [फ़्लो टेस्ट करें और फ़ेल रन ठीक करें](test-and-monitor-flows.md)।
- **WhatsApp** पैनल में आपको **Flows** दिखता हो।

## टैब में क्या दिखता है { #what-the-tab-shows }

- **Latest output** टैब फ़्लो का सबसे हाल का रन दिखाता है।
- ऊपर का सारांश रन की स्थिति, उसके शुरू होने का समय, और उसने कौन सा ट्रिगर और वर्शन इस्तेमाल किया, यह बताता है, जैसे **Published v3**।
- रन फ़ेल होने पर सारांश के नीचे एक लाल लाइन में एरर दिखता है।
- नीचे की सूची में हर चरण की एक पंक्ति होती है।

### चरण की स्थितियाँ { #step-states }

| स्थिति | मतलब |
| --- | --- |
| **Done** | चरण पूरा हो गया। |
| **Failed** | चरण फ़ेल हो गया। उस पर क्लिक करने पर उसका एरर दिखता है। |
| **Running** | चरण अभी चल रहा है। |
| **Waiting to start** | चरण अभी शुरू नहीं हुआ है। |
| **Waiting** | चरण किसी टाइमर पर है या किसी दूसरे सिस्टम के जवाब का इंतज़ार कर रहा है। |
| **Deactivated** | चरण बिल्डर में बंद है, इसलिए छोड़ दिया गया। |
| **Answered in chat** | चरण छोड़ दिया गया क्योंकि किसी व्यक्ति ने चैट में पहले ही जवाब दे दिया था। |
| **Not needed** | चरण छोड़ दिया गया, जैसे इसलिए कि कोई कंडीशन मेल नहीं खाई। |
| **Stopped** | रन इस चरण से पहले ही रोक दिया गया। |

## चरण { #steps }

### Latest output टैब खोलें { #open-the-latest-output-tab }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।
2. फ़्लो की पंक्ति पर क्लिक करें।
3. **Latest output** टैब पर क्लिक करें।
4. अगर फ़्लो चला ही नहीं है, तो टैब में **No output yet** और **Run this flow to see what each step returns.** लिखा होता है। रन शुरू करने के लिए **Run test** पर क्लिक करें।
5. रन चलने के दौरान टैब में **Run in progress** और **Output will update as steps finish.** दिखता है।

### किसी एक चरण का आउटपुट पढ़ें { #read-one-steps-output }

1. **Step output** के नीचे किसी चरण पर क्लिक करें। उसका आउटपुट सूची के नीचे खुलता है।
2. जिस चरण ने कोई नतीजा लौटाया है, उसके लौटाए मान पढ़ें।
3. अगर आउटपुट में कुछ देखने लायक है, जैसे तस्वीर या कार्ड, तो वह **Visual result** के नीचे भी दिखता है।
4. अगर चरण फ़ेल हुआ है, तो पहले एरर बॉक्स पढ़ें। अगर चरण ने फ़ेल होने से पहले अपना कुछ हिस्सा लौटा दिया था, तो वह हिस्सा **Partial output** के नीचे दिखता है।
5. अगर चरण किसी कनेक्शन की वजह से फ़ेल हुआ, तो कार्ड में **Review the connection used by this step.** भी लिखा होता है। कनेक्शन को **Connect** → **Connectors** में खोलें। देखें [कोई ऐप कनेक्ट करें और उसे फ़्लो में इस्तेमाल करें](connect-apps-for-flows.md)।

अगर किसी चरण का अभी कोई रिकॉर्ड नहीं है, तो टैब में **No step records for this run yet.** लिखा होता है।

### इंतज़ार करते या फ़ेल हुए चरण के बारे में और जानें { #see-more-about-a-step-that-is-waiting-or-failed }

1. चरण पर क्लिक करें।
2. अगर वह टाइमर पर इंतज़ार कर रहा है, तो एक लाइन में **Resumes** और उसके बाद समय लिखा होता है।
3. अगर वह फ़ेल हुआ है, तो एक लाइन में **Error code:** और उसके बाद कोड लिखा होता है। यह कोड सपोर्ट को दें।
4. अगर उसने किसी बाहरी सेवा को कॉल किया था, तो एक लाइन में **Vendor job:** और उसके बाद जॉब का नंबर लिखा होता है।

### पूरा एक्ज़ीक्यूशन देखें { #view-the-full-execution }

1. सारांश के ऊपर दाईं ओर **View full execution** पर क्लिक करें।
2. **Run details** पढ़ें।
    - **Run id** रन का नंबर है।
    - **Version pinned** वह वर्शन है जो इस रन ने इस्तेमाल किया।
    - **Started** और **Finished** समय हैं।
    - **Billable steps** बताता है कि कितने चरणों का शुल्क लगा।
    - **Correlation id** वह नंबर है जो इस रन को उस इवेंट से जोड़ता है जिसने इसे शुरू किया।
    - **Replay of** तब दिखता है जब रन किसी पुराने रन को दोहराया गया हो।
3. रन किस इवेंट से शुरू हुआ, यह जानने के लिए **WHAT STARTED THIS RUN** पढ़ें।
4. **Every step** के नीचे हर चरण को उसकी स्थिति और समय के साथ पढ़ें। चरण में **What it was sent** भी दिखता है, यानी उसे मिला डेटा।
5. छोटे व्यू में लौटने के लिए **Hide full execution** पर क्लिक करें।

### पुराना रन देखें { #look-at-an-older-run }

1. **Recent runs** टैब खोलें और किसी रन पर **View output** पर क्लिक करें। देखें [फ़्लो टेस्ट करें और फ़ेल रन ठीक करें](test-and-monitor-flows.md)।
2. **Latest output** टैब खुलता है, जिसमें बैनर **Viewing run from** और उसके बाद समय दिखता है।
3. सबसे नए रन पर लौटने के लिए **Back to latest** पर क्लिक करें।

### आउटपुट कॉपी करें { #copy-the-output }

1. किसी चरण के आउटपुट के नीचे **Copy JSON** पर क्लिक करें।
2. उसे सपोर्ट को भेजे जाने वाले अपने संदेश में पेस्ट करें।

लंबा आउटपुट काट दिया जाता है। उसके नीचे एक नोट में **Truncated — copy to see the whole payload.** लिखा होता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No output yet** | फ़्लो कभी चला ही नहीं। | **Run test** पर क्लिक करें। |
| **No step records for this run yet.** | रन अभी-अभी शुरू हुआ है। | कुछ सेकंड रुकें और टैब फिर खोलें। |
| कोई चरण **Deactivated** दिखाता है | चरण बिल्डर में बंद है। | बिल्डर में उसे चालू करें, फिर पब्लिश करें। |
| कोई चरण **Not needed** दिखाता है | पहले की कोई कंडीशन मेल नहीं खाई। | कंडीशन जाँचें या मेल खाने वाले डेटा से टेस्ट करें। |
| कोई चरण बहुत देर तक **Waiting** दिखाता है | वह **Wait** टाइमर पर है, या किसी दूसरे सिस्टम का इंतज़ार कर रहा है। | **Resumes** पढ़ें। अगर वह कभी आगे नहीं बढ़ता, तो रन रोकें और फिर टेस्ट करें। |
| **Review the connection used by this step.** | ऐप का कनेक्शन एक्सपायर हो गया है या गलत है। | उसे **Connect** → **Connectors** में दोबारा कनेक्ट करें। |
