# कॉन्टैक्ट को वेलकम ईमेल भेजें { #send-a-welcome-email-to-a-contact }

Ohanvi छोड़े बिना किसी एक कॉन्टैक्ट को ईमेल भेजें। आपका ईमेल चुने हुए ब्रोशर के साथ कॉन्टैक्ट के इनबॉक्स में पहुँचता है। वह ईमेल उसकी एक्टिविटी हिस्ट्री में भी दिखता है। इसमें करीब एक मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Contacts** दिखे, और उसके पैनल में **All contacts**।
- कॉन्टैक्ट का **Email** भरा हो। देखें [कॉन्टैक्ट मैनेज करें](manage-contacts.md)।
- डिफ़ॉल्ट मैसेज बदलना हो, तो देखें [वेलकम ईमेल सेट करें](set-up-the-welcome-email.md)।

## भेजने के दो तरीके { #two-ways-to-send }

| मोड | कब इस्तेमाल करें |
| --- | --- |
| **Compose + PDF** | आप सब्जेक्ट और मैसेज खुद लिखना चाहते हैं और अपनी फ़ाइलें लगाना चाहते हैं। |
| **Ohanvi brochure** | आप बना-बनाया ईमेल चाहते हैं, जिसमें ब्रोशर मैसेज के अंदर ही दिखे। सब्जेक्ट और बॉडी आपके लिए पहले से तैयार रहते हैं। |

## स्टेप { #steps }

### ईमेल विंडो खोलें { #open-the-email-window }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. कॉन्टैक्ट पर क्लिक करें, फिर **More actions** (**…** बटन) पर क्लिक करें।
3. **Send Welcome Email** पर क्लिक करें। ईमेल विंडो खुलेगी।
4. **To** बॉक्स देखें। उसमें कॉन्टैक्ट का ईमेल दिखता है। उसे आप यहाँ बदल नहीं सकते।
5. विंडो बड़ी करनी हो, तो उसके हेडर में मैक्सिमाइज़ बटन पर क्लिक करें।

### Compose + PDF से भेजें { #send-with-compose-pdf }

1. विंडो में सबसे ऊपर **Compose + PDF** पर क्लिक करें।
2. वैकल्पिक: **Email Template** के नीचे कोई सेव किया हुआ ईमेल Template चुनें। बॉक्स में **Select a template (optional)** लिखा होता है। Template चुनते ही सब्जेक्ट और बॉडी भर जाते हैं।
3. **Subject** देख लें। विंडो में आपका सेव किया हुआ वेलकम सब्जेक्ट पहले से भरा आता है।
4. **Body** देख लें। चाहें तो इस कॉन्टैक्ट के लिए उसमें बदलाव करें। यह बदलाव सिर्फ़ इसी ईमेल में लगेगा।
5. **Attach brochures** के नीचे, जो-जो फ़ाइल लगानी है उस पर टिक करें। हर नाम के नीचे उसका साइज़ दिखता है।
6. **Send** पर क्लिक करें। **Welcome email sent to …** मैसेज आएगा।

**Subject** खाली हो, तो विंडो में **Add a subject before sending** लिखा आता है। **Body** खाली हो, तो **Add a message before sending** लिखा आता है।

### Ohanvi ब्रोशर ईमेल भेजें { #send-the-ohanvi-brochure-email }

1. विंडो में सबसे ऊपर **Ohanvi brochure** पर क्लिक करें।
2. ईमेल के बारे में बताने वाला बॉक्स पढ़ें। यह तैयार मैसेज है, जिसके अंदर ब्रोशर दिखता है। सब्जेक्ट या बॉडी आपको खुद नहीं लिखनी पड़ती।
3. वैकल्पिक: **Add images to the email** के नीचे **Click to add images** पर क्लिक करें, या फ़ाइलें उस पर ड्रॉप करें। PNG, JPG, GIF या WEBP फ़ाइलें इस्तेमाल करें। हर फ़ाइल ज़्यादा से ज़्यादा 5 MB की हो। काउंटर बताता है कि आपने कितनी इमेज जोड़ी हैं, जैसे **2/6**।
4. **Attach brochures** के नीचे जो ब्रोशर भेजने हैं, उन पर टिक करें।
5. **Send** पर क्लिक करें।

### इसी विंडो से ब्रोशर जोड़ें { #add-a-brochure-from-this-window }

1. **Attach brochures** के पास **Manage** पर क्लिक करें। **Manage Brochures** विंडो खुलेगी।
2. **Upload brochure** पर क्लिक करें और फ़ाइल चुनें। फ़ाइल के नियम जानने के लिए देखें [वेलकम ईमेल सेट करें](set-up-the-welcome-email.md)।
3. विंडो बंद करें। नई फ़ाइल लिस्ट में आ जाएगी। उस पर टिक करें।

अभी तक आपकी कोई फ़ाइल न हो, तो लिस्ट में **No brochures yet. Tap Manage to upload the booklet.** लिखा आता है।

### देखें कि ईमेल दर्ज हुआ { #check-that-it-was-logged }

1. कॉन्टैक्ट चुनें और **More actions** से **Notes & Activities** खोलें। या बीच वाले पैनल में **Email** टैब खोलें।
2. अपना भेजा हुआ ईमेल ढूँढें। हर वेलकम ईमेल कॉन्टैक्ट पर एक ईमेल एक्टिविटी की तरह सेव होता है।
3. **All contacts** लिस्ट पर वापस जाएँ। उस कॉन्टैक्ट की ईमेल गिनती 1 बढ़ चुकी होगी।

## समस्या और समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not send the email. Please retry.** | ईमेल नहीं जा पाया। | **Send** पर दोबारा क्लिक करें। कॉन्टैक्ट का **Email** भी देख लें। |
| **To** बॉक्स खाली है | कॉन्टैक्ट का कोई ईमेल नहीं है। | **Identity** ब्लॉक में **Email** जोड़ें, फिर **Update contact** पर क्लिक करें। |
| लगाई हुई फ़ाइल लिस्ट में नहीं दिखती | फ़ाइल अपलोड नहीं हुई थी, या डिलीट हो गई। | **Manage** पर क्लिक करें और उसे फिर से अपलोड करें। |
| कॉन्टैक्ट पर **Email Opt-out** टिक है | कॉन्टैक्ट ने कहा है कि उसे ईमेल नहीं चाहिए। | उसकी बात मानें। देखें [कॉन्टैक्ट की सहमति ट्रैक करें](consent-and-compliance.md)। |
