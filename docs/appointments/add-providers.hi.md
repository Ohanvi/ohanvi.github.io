# प्रोवाइडर और काम के घंटे जोड़ें { #add-providers-and-working-hours }

प्रोवाइडर वह व्यक्ति है जिसके साथ अपॉइंटमेंट बुक होता है। Ohanvi हर प्रोवाइडर के हिसाब से खाली समय निकालता है, इसलिए कोई भी समय दिखाने से पहले कम से कम 1 प्रोवाइडर ज़रूरी है। अंत में आपके पास अपनी सर्विस से जुड़े प्रोवाइडर होंगे और काम के ऐसे घंटे होंगे जो तय करते हैं कि बुकिंग कब हो सकती है।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Appts** दिखता हो। न दिखे, तो अपने एडमिन से कहें कि आपके रोल को अपॉइंटमेंट का एक्सेस दें।
- आपने अपनी सर्विस जोड़ ली हों। देखें [बुक की जा सकने वाली सर्विस जोड़ें](add-services.md)।
- आपको हर उस व्यक्ति का Ohanvi यूज़रनेम पता हो जो बुकिंग लेगा।

## चरण { #steps }

### प्रोवाइडर जोड़ें { #add-a-provider }

1. लेफ़्ट रेल में **Appts** खोलें, फिर **Providers** चुनें। **Providers** पेज खुलता है।
2. **Add provider** पर क्लिक करें। **Add provider** डायलॉग खुलता है।
3. **Name** में वह नाम लिखें जो ग्राहक प्रोवाइडर चुनते समय देखते हैं, जैसे `Dr Mehta`।
4. **Username** में वह Ohanvi लॉगिन लिखें जिससे यह प्रोवाइडर जुड़ा है। बॉक्स के नीचे की मदद में लिखा होता है **The login this provider maps to**।
5. **Services performed** के नीचे उन सर्विस पर क्लिक करें जो यह व्यक्ति देता है। हेडिंग के नीचे की लाइन में लिखा होता है **None selected means every service.** अगर सूची में **No services set up yet.** दिखे, तो पहले अपनी सर्विस जोड़ें।
6. **Taking bookings** को चालू रहने दें। मदद में लिखा होता है **Turn off to keep the record but stop offering their times.**
7. **Add provider** पर क्लिक करें। संदेश **Saved** दिखता है और प्रोवाइडर अपने यूज़रनेम और सर्विस के साथ, या **all services** के साथ सूची में दिखता है।

!!! note "ध्यान दें"
    प्रोवाइडर जोड़ने के बाद आप **Username** नहीं बदल सकते। यह उनकी बुकिंग को उस व्यक्ति के कैलेंडर से जोड़ता है। कोई दूसरा लॉगिन इस्तेमाल करना हो, तो नया प्रोवाइडर जोड़ें और पुराने प्रोवाइडर पर **Taking bookings** बंद कर दें।

### प्रोवाइडर को एडिट करें या उनकी बुकिंग रोकें { #edit-a-provider-or-stop-their-bookings }

1. **Providers** पेज पर प्रोवाइडर के पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit provider** डायलॉग खुलता है।
2. **Name** या **Services performed** बदलें।
3. उनके समय दिखाना बंद करना हो लेकिन रिकॉर्ड रखना हो, तो **Taking bookings** बंद करें। प्रोवाइडर पर **Inactive** बैज दिखता है।
4. **Save provider** पर क्लिक करें।

### काम के घंटे सेट करें { #set-working-hours }

काम के घंटे पूरे बिज़नेस पर लागू होते हैं। ये आपकी व्हाट्सऐप सेटिंग्स से आते हैं, हर प्रोवाइडर से नहीं।

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **WhatsApp** चुनें, फिर **Live Chat Settings**। आप **WhatsApp** → **Manage** → **Live Chat Settings** से भी खोल सकते हैं।
3. **Working Hours** तक स्क्रॉल करें।
4. **Timezone** में अपने बिज़नेस का टाइमज़ोन चुनें, जैसे `Asia/Kolkata`।
5. हर दिन के लिए, उस दिन को खुला रखने के लिए बॉक्स पर टिक करें, फिर शुरू और खत्म होने का समय बदलने के लिए उन पर क्लिक करें। बिना टिक वाले दिन पर **Closed** दिखता है।
6. **Save** पर क्लिक करें।

Ohanvi सिर्फ़ इन्हीं घंटों के अंदर के समय दिखाता है। यही घंटे यह भी तय करते हैं कि ग्राहकों को कौन-सा व्हाट्सऐप ऑटो-रिप्लाई मिलेगा, **Welcome** या **Off Hours**।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No providers yet** — **Until one exists, no appointment slots can be offered.** | कोई प्रोवाइडर नहीं जोड़ा गया है। | **Add provider** पर क्लिक करें। |
| **Name** या **Username** के नीचे **Required** | फ़ील्ड खाली है। | दोनों फ़ील्ड भरें। |
| **Could not save the provider** | सर्वर ने सेव करने से मना कर दिया। | यूज़रनेम जाँचें और दोबारा कोशिश करें। फिर भी न हो, तो अपने एडमिन से पूछें। |
| किसी सर्विस के लिए कोई समय नहीं दिखता | कोई एक्टिव प्रोवाइडर वह सर्विस नहीं देता, या वह दिन **Closed** है या **Working Hours** में उसके घंटे सेव नहीं हैं। | सर्विस को किसी प्रोवाइडर के **Services performed** में जोड़ें, या और दिन खोलें। |
| रात में समय दिखाए जा रहे हैं | **Working Hours** में उस दिन रात के घंटे खुले हैं। | हर दिन के खुले घंटे सेट करें और **Save** पर क्लिक करें। |
