# चैटबॉट में टेक्स्ट और लिस्ट मैसेज भेजें { #send-text-and-list-messages-in-a-chatbot }

**Text** और **List / Buttons** सबसे ज़्यादा इस्तेमाल होने वाले दो ब्लॉक हैं। **Text** सादा मैसेज भेजता है, जिसमें 3 रिप्लाई बटन तक हो सकते हैं। **List / Buttons** ऐसा मैसेज भेजता है जिसमें 10 विकल्पों तक का मेनू होता है। हर मैसेज लिखने, विकल्प जोड़ने और उन्हें अगले चरणों से जोड़ने के लिए यह पेज देखें।

## शुरू करने से पहले { #before-you-start }

- आपने बिल्डर में कोई फ़्लो खोला है। देखें [फ़्लो बिल्डर को समझें](understand-the-flow-builder.md)।
- आपको पता है कि फ़्लो कहाँ से शुरू होता है। देखें [चुनें कि फ़्लो कैसे शुरू हो](chatbot-flow-start-and-triggers.md)।

## कौन सा ब्लॉक इस्तेमाल करें { #which-block-to-use }

| ब्लॉक | ग्राहक क्या देखता है | विकल्प | किसके लिए इस्तेमाल करें |
| --- | --- | --- | --- |
| **Text** | सादा मैसेज। चाहें तो उसके नीचे बटन। | 3 रिप्लाई बटन तक। | अभिवादन, जवाब, छोटे मेनू। |
| **List / Buttons** | ऐसा मैसेज जिसमें एक बटन मेनू खोलता है। | 10 लिस्ट पंक्तियों तक। | लंबे मेनू, जैसे विभाग या प्रोडक्ट। |

दोनों ब्लॉक **Step** पैनल के **Message types** समूह में हैं।

## चरण { #steps }

### टेक्स्ट मैसेज भेजें { #send-a-text-message }

1. जिस चरण के बाद मैसेज जाना है, उसके बाद **+** पर क्लिक करें। **Add a step after** मेनू खुलता है।
2. **All steps** पर क्लिक करें।
3. **Message types** के नीचे **Text** पर क्लिक करें। **Message** ब्लॉक वाला एक कार्ड दिखता है।
4. ब्लॉक पर क्लिक करें। उसकी सेटिंग्स **Step** पैनल में खुलती हैं।
5. जिस बॉक्स में **Type message...** लिखा है उस पर क्लिक करें और मैसेज लिखें, जैसे `Hi! How can I help you today?`। इसमें 1,024 अक्षर तक आ सकते हैं।
6. सेव किया हुआ जवाब दिखाने के लिए बॉक्स के नीचे किसी चिप पर क्लिक करें, जैसे **{Name}**। यह `{{name}}` डाल देता है।

!!! tip "सुझाव"
    दोहरे कर्ली ब्रैकेट और छोटे अक्षर इस्तेमाल करें। अगर आप वेरिएबल खुद लिखते हैं, तो `{{name}}` लिखें। बड़े अक्षर वाला, जैसे `{{Name}}`, ग्राहक को सादे टेक्स्ट के रूप में भेज दिया जाता है।

### टेक्स्ट मैसेज में रिप्लाई बटन जोड़ें { #add-reply-buttons-to-a-text-message }

1. मैसेज ब्लॉक के नीचे **+ Add Button** पर क्लिक करें। **New button** नाम का बटन दिखता है।
2. बटन पर क्लिक करें और उसका लेबल लिखें, जैसे `Fees`।
3. हर बटन के लिए दोहराएँ। एक टेक्स्ट मैसेज में 3 बटन तक आ सकते हैं।
4. किसी बटन के लिए अलग जवाब भेजने के लिए उस बटन के दाएँ सिरे पर **+** पर क्लिक करें और अगला चरण चुनें।

बटन की सीमाएँ:

- एक मैसेज पर 3 बटन तक।
- बटन के लेबल में 20 अक्षर तक आ सकते हैं। इससे लंबे लेबल कट जाते हैं।
- जिस बटन को आप नहीं जोड़ते, वह उसी कार्ड के अगले ब्लॉक पर चला जाता है।

### टेक्स्ट मैसेज पर डिले या टाइमआउट सेट करें { #set-a-delay-or-a-timeout-on-a-text-message }

1. ब्लॉक के नीचे का स्लेटी टाइमिंग एरिया खोजें।
2. **Set Delay** चालू करें और **Type delay in seconds...** में सेकंड लिखें, जैसे `3`। मैसेज उतनी देर रुककर जाता है।
3. **Set Timeout** चालू करें और **Timeout after (minutes)** लिखें, जैसे `30`। कार्ड पर **Timed out** एग्ज़िट दिखता है।
4. **Timed out** को किसी फ़ॉलो-अप चरण से जोड़ें, जैसे रिमाइंडर।

### लिस्ट मैसेज भेजें { #send-a-list-message }

1. जिस चरण के बाद मेनू जाना है, उसके बाद **+** पर क्लिक करें, फिर **All steps** पर क्लिक करें।
2. **Message types** के नीचे **List / Buttons** पर क्लिक करें। **List** ब्लॉक दिखता है।
3. **Header** में छोटा शीर्षक लिखें, जैसे `Our services`। इसमें 20 अक्षर तक आ सकते हैं। यह बॉक्स वैकल्पिक है।
4. **Body** में मैसेज लिखें, जैसे `Choose a service`। इसमें 4,096 अक्षर तक आ सकते हैं।
5. **Footer** में छोटी सी लाइन लिखें, जैसे `Reply any time`। इसमें 60 अक्षर तक आ सकते हैं। यह बॉक्स वैकल्पिक है।
6. **Button label** में मेनू खोलने वाले बटन पर लिखे जाने वाले शब्द लिखें, जैसे `View services`। इसमें 20 अक्षर तक आ सकते हैं।

### लिस्ट की पंक्तियाँ जोड़ें { #add-the-list-rows }

1. पहली पंक्ति में **Item one** की जगह विकल्प का नाम लिखें, जैसे `Haircut`। इसमें 24 अक्षर तक आ सकते हैं।
2. **Describe it** में नाम के नीचे की लाइन लिखें, जैसे `30 minutes`। इसमें 72 अक्षर तक आ सकते हैं।
3. एक और पंक्ति जोड़ने के लिए **+ Add Section** पर क्लिक करें। लिस्ट में बटन पर **+ Add Section** लिखा होता है, लेकिन वह **New item** नाम की पंक्ति जोड़ता है।
4. हर विकल्प के लिए दोहराएँ। एक लिस्ट में 10 पंक्तियाँ तक आ सकती हैं।
5. पंक्ति हटाने के लिए उसके नाम के बगल में छोटे **x** पर क्लिक करें।
6. नई पंक्ति **New item** नाम और **Describe it** लाइन के साथ शुरू होती है। **Multi product** ब्लॉक में पहली पंक्ति **Section one** होती है, और नई पंक्ति **New section**। **Buttons** ब्लॉक में नया विकल्प **New button** होता है। हर डिफ़ॉल्ट नाम बदलें।

### हर विकल्प को आगे से जोड़ें { #wire-each-choice }

1. किसी पंक्ति या बटन के दाएँ सिरे पर **+** पर क्लिक करें।
2. वह चरण चुनें जो तब चलेगा जब ग्राहक उस विकल्प पर टैप करे, जैसे कीमतों की सूची वाला **Text**।
3. हर विकल्प के लिए दोहराएँ।

बाद में किसी जवाब पर कार्रवाई करने के लिए **Condition** ब्लॉक इस्तेमाल करें। देखें [नाम, फ़ोन, ईमेल और पता पूछें](chatbot-ask-details-blocks.md)।

### लिस्ट पर टाइमआउट सेट करें { #set-a-timeout-on-a-list }

1. लिस्ट के नीचे टाइमिंग एरिया में **Set Timeout** चालू करें।
2. **Timeout after (minutes)** लिखें।
3. **Timed out** एग्ज़िट को रिमाइंडर चरण से जोड़ें।

लिस्ट में **Set Delay** नहीं होता। सवाल में देरी नहीं की जाती।

### मैसेज जाँचें { #check-the-message }

1. **Save** पर क्लिक करें।
2. **Test** पर क्लिक करें। मैसेज पढ़ें और हर विकल्प पर टैप करें। देखें [चैट सिम्युलेटर से चैटबॉट फ़्लो टेस्ट करें](test-a-flow-with-the-chat-simulator.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **+ Add Button** नहीं दिख रहा | ब्लॉक में पहले से 3 बटन हैं, या वह लिस्ट है। | कोई बटन हटाएँ, या **List / Buttons** ब्लॉक इस्तेमाल करें। |
| **Body** में और टेक्स्ट नहीं आ रहा | **Text** पर आप 1,024 अक्षर तक पहुँच गए, या लिस्ट पर 4,096। | मैसेज छोटा करें। |
| किसी पंक्ति में और टेक्स्ट नहीं आ रहा | पंक्ति के नाम में 24 अक्षर आते हैं और विवरण में 72। | टेक्स्ट छोटा करें। |
| ग्राहक को `{{Name}}` दिख रहा है | वेरिएबल में बड़ा अक्षर है। | `{{name}}` लिखें, या बॉक्स के नीचे की चिप इस्तेमाल करें। |
| टैप किया गया विकल्प कुछ नहीं करता | विकल्प से कोई कनेक्शन नहीं जुड़ा। | विकल्प पर **+** पर क्लिक करें और कोई चरण जोड़ें। |
