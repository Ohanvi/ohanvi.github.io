# टास्क पैनल { #tasks-panel }

**Tasks** पैनल में अपना काम देखना और नया टास्क जोड़ना सबसे तेज़ है। इसमें टास्क **Today**, **Assigned to me** और **Created by me** के नीचे दिखते हैं। नीचे की गाइड टास्क बनाने, लिखने और खोजने के बारे में हैं।

**यह कहाँ मिलेगा:** दाईं ओर की रेल में नोटिफ़िकेशन बेल के पास **Tasks** पर क्लिक करें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [टास्क बनाएँ और असाइन करें](../create-and-assign-tasks.md) | आपको काम जोड़ना है और उसे ओनर, प्रायोरिटी और ड्यू डेट देनी है। |
| [टास्क एडिटर में लिखें](../write-in-the-task-editor.md) | आपको डिस्क्रिप्शन या कमेंट में हेडिंग, लिस्ट, टेबल, तस्वीरें या आवाज़ जोड़नी है। |
| [कमेंट करें, मेंशन करें और फ़ाइलें अटैच करें](../collaborate-on-tasks.md) | आपको किसी टास्क पर बात करनी है, फ़ाइलें शेयर करनी हैं या समय दर्ज करना है। |
| [टास्क खोजें, फ़िल्टर करें और देखें](../find-and-filter-tasks.md) | आपको सिर्फ़ अपना काम देखना है, या बोर्ड का व्यू बदलना है। |

## शुरू करने से पहले { #before-you-start }

- आपके रोल को Task का एक्सेस मिला है। इसके बिना **Tasks** आइकन नहीं दिखता।
- आपके वर्कस्पेस में एक टास्क प्रोजेक्ट है। देखें [टास्क प्रोजेक्ट सेट करें](../set-up-task-project.md)।
