# इनसाइट्स के चार्ट और एक चैनल देखें { #explore-insights-charts-and-one-channel }

Insights में आपके सभी चैनल एक साथ दिखते हैं। किसी एक चैनल पर क्लिक करें, तो उसकी पोस्ट, हफ़्ते की मुख्य बातें और मेट्रिक्स चार्ट दिखते हैं। इस पेज पर **Insights** का हर चार्ट, टॉगल और फ़िल्टर समझाया गया है। इसमें लगभग 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखना चाहिए, और उसके पैनल में **Insights**।
- कम से कम एक नेटवर्क कनेक्ट हो और उस पर पोस्ट पब्लिश हो चुकी हों। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।
- कुल आँकड़े और टॉप पोस्ट देखने के लिए [सोशल इनसाइट्स पढ़ें](view-social-insights.md) देखें।

## स्टेप { #steps }

### अवधि और चैनल चुनें { #pick-the-period-and-the-channel }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Insights** चुनें।
2. ऊपर से **7 days**, **30 days** या **Month to date** चुनें। हर आँकड़ा उससे पिछली अवधि के साथ मिलाकर दिखता है।
3. **Channels** पर क्लिक करें।
4. **All Channels** चुनें, या कोई एक चैनल। आपके चुने हुए विकल्प पर भरा हुआ बिंदु लगा होता है।
5. कोई चैनल कनेक्ट न हो, तो लिस्ट में **No channels connected** लिखा आता है।
6. आँकड़े दोबारा लोड करने के लिए **Refresh** पर क्लिक करें।

### Tags फ़िल्टर इस्तेमाल करें { #use-the-tags-filter }

1. **Tags** पर क्लिक करें।
2. लिस्ट देखें। अभी उसमें **No tags available yet** लिखा है।

!!! note "ध्यान दें"
    टैग पोस्ट पर लगते हैं, लेकिन Insights अभी उनका कुल हिसाब नहीं दिखाता। फ़िल्टर मौजूद है, पर उसमें चुनने के लिए कुछ नहीं है।

### सभी चैनलों की Performance टेबल पढ़ें { #read-the-performance-table-for-all-channels }

1. **All Channels** चुनें और **Performance** तक स्क्रॉल करें।
2. हर चैनल के **Posts**, **Reactions**, **Comments** और **Eng. Rate** देखें।
3. किसी चैनल की रो पर क्लिक करें। Insights उसी चैनल पर चला जाता है।
4. किसी चैनल पर कोई पोस्ट न हो, तो टेबल में **No channel activity in this period.** लिखा आता है।

### Followers चार्ट पढ़ें { #read-the-followers-chart }

1. **Followers** तक स्क्रॉल करें।
2. चार्ट के ऊपर दाईं ओर **Bar**, **Line** या **Growth** पर क्लिक करें।
3. **Bar** में चैनलों की आपस में तुलना होती है। **Line** में फ़ॉलोअर का ट्रेंड दिखता है। **Growth** में दिखता है कि फ़ॉलोअर कितने घटे या बढ़े।

### Posts चार्ट पढ़ें { #read-the-posts-chart }

1. **Posts** तक स्क्रॉल करें।
2. हर चैनल ने कितनी पोस्ट पब्लिश कीं, यह मिलाने के लिए **Bar** पर क्लिक करें।
3. सभी चैनलों को एक के ऊपर एक रखकर देखने के लिए **Stacked Bar** पर क्लिक करें।

### एक चैनल देखें { #look-at-one-channel }

1. **Channels** में कोई एक चैनल चुनें, या **Performance** में उसकी रो पर क्लिक करें।
2. सबसे ऊपर **WEEKLY TAKEAWAYS** पढ़ें। इसे बंद करने के लिए बगल के तीर पर क्लिक करें।
3. नीचे के दो कार्ड पढ़ें:
    - **Start Building Your Posting Habit** में दिखता है कि इस अवधि में आपने कितनी पोस्ट पब्लिश कीं। **Publish** खोलने के लिए **Create a Post** पर क्लिक करें।
    - **Set a Posting Goal** आपको लक्ष्य तय करने की याद दिलाता है। इसमें अभी कोई बटन नहीं है।
4. **Performance per Post** पढ़ें। इसमें हर पोस्ट अपने **Reactions**, **Comments** और **Eng. Rate** के साथ दिखती है। **Posts · N** वाली लाइन पोस्ट की गिनती बताती है।
5. आपने कुछ पब्लिश नहीं किया हो, तो **No published posts in this period.** लिखा आता है।

### Metrics टैब पढ़ें { #read-the-metrics-tabs }

ये टैब तभी दिखते हैं जब एक चैनल चुना हो।

1. **Metrics** तक स्क्रॉल करें।
2. पोस्ट का चार्ट देखने के लिए **Content Impact** पर क्लिक करें।
3. फ़ॉलोअर का लाइन चार्ट देखने के लिए **Audience Growth** पर क्लिक करें।
4. **Visibility** पर क्लिक करें। वहाँ लिखा आता है: **Impressions and reach are not reported by the connected networks yet.**

### अपनी टॉप पोस्ट का क्रम देखें { #rank-your-top-posts }

1. **Top 5 Posts** के नीचे, ऊपर दाईं ओर **Reactions** या **Comments** पर क्लिक करें।
2. पाँचों पोस्ट कार्ड उसी क्रम में देखें। हर कार्ड पर चैनल, तारीख और पोस्ट का टेक्स्ट दिखता है।
3. कार्ड पर **Open post** आइकन अभी ग्रे है। किसी पोस्ट पर काम करना हो, तो उसे **Publish** में ढूँढें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| लिस्ट में **No channels connected** | कोई नेटवर्क कनेक्ट नहीं है। | कोई नेटवर्क कनेक्ट करें। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)। |
| **No channel activity in this period.** | चैनल पर उस अवधि में कोई पोस्ट नहीं हुई। | लंबी अवधि चुनें। |
| **No published posts in this period.** | इस चैनल पर कुछ पब्लिश नहीं हुआ। | लंबी अवधि चुनें, या कोई पोस्ट पब्लिश करें। |
| **No tags available yet** | Insights में अभी टैग का कुल हिसाब नहीं बनता। | बाकी फ़िल्टर इस्तेमाल करें। |
| **Visibility** खाली है | नेटवर्क अभी इम्प्रेशन और रीच नहीं भेजते। | इसका कोई हल नहीं है। इसकी जगह **Content Impact** देखें। |
