# एनालिटिक्स { #analytics }

एनालिटिक्स में आपको अपने WhatsApp ब्रॉडकास्ट और जुड़े हुए ऑनलाइन स्टोर की रिपोर्ट मिलती है। हर स्क्रीन के आख़िर में सुझाव भी होते हैं कि आगे क्या करें।

![Marketing Analytics, जिसमें Can you send?, Where you stand, Do this next और Performance over time दिख रहे हैं](../assets/screenshots/analytics-marketing-1-overview.png)

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Analytics** खोलें। पैनल में ये दो चीज़ें दिखती हैं:

- **Marketing Analytics** — आपके WhatsApp ब्रॉडकास्ट की डिलीवरी, रीड, फ़ेल हुए मैसेज और रेवेन्यू।
- **Store Analytics** — आपके Shopify या WooCommerce स्टोर के ऑर्डर, रेवेन्यू, ग्राहक और छोड़ी गई कार्ट।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में WhatsApp हो, और आपका रोल WhatsApp ब्रॉडकास्ट (**Marketing Analytics** के लिए) या स्टोर इंटीग्रेशन (**Store Analytics** के लिए) देख सकता हो। दोनों न हों, तो **Analytics** आइकन नहीं दिखता।
- आपने कम से कम 1 WhatsApp ब्रॉडकास्ट भेजा हो। नहीं तो आँकड़े खाली रहेंगे।
- स्टोर के आँकड़ों के लिए स्टोर **Connect** → **Store Connections** में कनेक्ट हो।
