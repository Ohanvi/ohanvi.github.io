# अकाउंट जोड़ें और प्रबंधित करें { #add-and-manage-accounts }

जिन कंपनियों को आप बेचते हैं उन्हें अकाउंट के रूप में सेव करें, ताकि उनके संपर्क और डील एक जगह जुड़े रहें। अंत में हर अकाउंट में उसकी सेहत, संपर्कों की संख्या, ओपन पाइपलाइन की वैल्यू, वह स्रोत जहाँ से वह आया और उसका ओनर दिखता है।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **CRM** दिखता है, और उसके पैनल में **Accounts**। न दिखे तो अपने एडमिन से CRM एक्सेस माँगें।

## चरण { #steps }

### अकाउंट जोड़ें { #add-an-account }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Accounts** चुनें।
2. ऊपर दाईं ओर **Add account** पर क्लिक करें। **Add Account** फ़ॉर्म खुलता है।
3. **Basic Information** के तहत **Account Name** लिखें। सिर्फ़ यही फ़ील्ड ज़रूरी है।
4. **Account Type** चुनें: **PROSPECT**, **CUSTOMER**, **PARTNER**, **VENDOR** या **OTHER**। डिफ़ॉल्ट **PROSPECT** है।
5. वैकल्पिक: अगर यह कंपनी किसी समूह की है तो **Parent Account (Client Group)** चुनें। **Industry** और **Website** जोड़ें।
6. वैकल्पिक: **Contact Information** (**Phone**, **Email**), **Company Details** (**Annual Revenue**, **Employees**), **Billing Address**, **Shipping Address** और **Description** भरें।
7. **Submit** पर क्लिक करें। अकाउंट सूची में दिखने लगता है।

अगर किसी सेव किए अकाउंट का नाम, फ़ोन या ईमेल वही है, तो फ़ॉर्म में **Possible duplicate — "…" already has a matching name, phone or email.** दिखता है। फिर भी आप उसे सेव कर सकते हैं। पहले जाँच लें कि आप दूसरी कॉपी तो नहीं बना रहे।

### अकाउंट की सूची पढ़ें { #read-the-account-list }

हर पंक्ति में **Company**, **Health**, **Contacts**, **Open pipeline**, **Source** और **Owner** दिखते हैं। **Health** अकाउंट की डील से निकाली जाती है:

| सेहत | मतलब |
| --- | --- |
| **Customer** | अकाउंट की कोई डील जीती जा चुकी है, या उसका टाइप **CUSTOMER** है। |
| **Active** | उसकी ओपन डील पिछले 30 दिनों में आगे बढ़ी हैं। |
| **At risk** | उसकी ओपन डील हैं, पर कोई भी 30 दिन या उससे ज़्यादा से आगे नहीं बढ़ी। |
| **New** | उसकी अभी कोई ओपन डील नहीं है। |

### अकाउंट फ़िल्टर करें और खोलें { #filter-and-open-accounts }

1. सूची को छोटा करने के लिए एक व्यू पर क्लिक करें: **Customers**, **At risk** या **My accounts**। **All** हर अकाउंट दिखाता है।
2. किसी अकाउंट पर क्लिक करें। Ohanvi उस कंपनी के संपर्क खोलता है।

### सूची एक्सपोर्ट करें { #export-the-list }

1. सूची को अपने चाहे अकाउंट तक फ़िल्टर करें।
2. **Export** पर क्लिक करें। स्क्रीन पर दिख रही पंक्तियों की CSV फ़ाइल डाउनलोड होती है, और **Exported N accounts.** दिखता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Account name is required.** | **Account Name** खाली है। | नाम लिखें और दोबारा सबमिट करें। |
| **Invalid account type 'COMPETITOR'.** | **COMPETITOR** **Account Type** की सूची में दिखता है, पर सर्वर उसे स्वीकार नहीं करता। | उसकी जगह **OTHER** चुनें। |
| **Account has active contacts. Reassign or delete them first.** | आपने ऐसा अकाउंट डिलीट करने की कोशिश की जिसमें अब भी संपर्क हैं। | संपर्कों को किसी दूसरे अकाउंट में ले जाएँ, या उन्हें डिलीट करें, फिर कोशिश करें। |
| **Export** नहीं दिख रहा | सूची खाली है। | पहले कोई अकाउंट जोड़ें। |
| अकाउंट **At risk** दिखता है पर आपने इसी हफ़्ते उनसे बात की | सेहत सिर्फ़ यह देखती है कि डील आख़िरी बार कब अपडेट हुई। | डील अपडेट करें, जैसे उसका **Next Step**। |
