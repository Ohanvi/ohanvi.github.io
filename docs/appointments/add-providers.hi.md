# प्रोवाइडर और काम के घंटे जोड़ें { #add-providers-and-working-hours }

प्रोवाइडर वह व्यक्ति है जिसके साथ अपॉइंटमेंट बुक होता है। Ohanvi हर प्रोवाइडर के हिसाब से खाली समय निकालता है। इसलिए कोई भी समय दिखने से पहले कम से कम 1 प्रोवाइडर होना ज़रूरी है। इस गाइड के आख़िर तक आपके पास अपनी सर्विस से जुड़े प्रोवाइडर होंगे। साथ ही काम के ऐसे घंटे होंगे जो तय करेंगे कि बुकिंग कब हो सकती है।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Appts** दिखता हो। न दिखे, तो अपने एडमिन से कहें कि आपके रोल को अपॉइंटमेंट का एक्सेस दें।
- आपने अपनी सर्विस जोड़ ली हों। देखें [बुक की जा सकने वाली सर्विस जोड़ें](add-services.md)।
- जो-जो व्यक्ति बुकिंग लेगा, उसका Ohanvi यूज़रनेम आपको पता हो।

## स्टेप { #steps }

### प्रोवाइडर जोड़ें { #add-a-provider }

1. लेफ़्ट रेल में **Appts** खोलें, फिर **Providers** चुनें। **Providers** पेज खुलेगा।
2. **Add provider** पर क्लिक करें। **Add provider** डायलॉग खुलेगा।
3. **Name** में वह नाम लिखें जो ग्राहक प्रोवाइडर चुनते समय देखेंगे, जैसे `Dr Mehta`।
4. **Username** में वह Ohanvi लॉगिन लिखें जो इस प्रोवाइडर का है। बॉक्स के नीचे लिखा होता है **The login this provider maps to**।
5. **Services performed** के नीचे उन सर्विस पर क्लिक करें जो यह व्यक्ति देता है। हेडिंग के नीचे लिखा होता है **None selected means every service.** अगर लिस्ट में **No services set up yet.** दिखे, तो पहले अपनी सर्विस जोड़ें।
6. **Taking bookings** को चालू ही रहने दें। उसके नीचे लिखा होता है **Turn off to keep the record but stop offering their times.**
7. **Add provider** पर क्लिक करें। **Saved** मैसेज आएगा। प्रोवाइडर लिस्ट में अपने यूज़रनेम और सर्विस के साथ दिखेगा। अगर कोई सर्विस नहीं चुनी, तो **all services** दिखेगा।

!!! note "ध्यान दें"
    प्रोवाइडर जोड़ने के बाद **Username** नहीं बदला जा सकता। इसी से उसकी बुकिंग उस व्यक्ति के कैलेंडर से जुड़ती है। कोई दूसरा लॉगिन इस्तेमाल करना हो, तो नया प्रोवाइडर जोड़ें और पुराने प्रोवाइडर पर **Taking bookings** बंद कर दें।

### प्रोवाइडर में बदलाव करें या उसकी बुकिंग रोकें { #edit-a-provider-or-stop-their-bookings }

1. **Providers** पेज पर प्रोवाइडर के पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit provider** डायलॉग खुलेगा।
2. **Name** या **Services performed** बदलें।
3. उसके समय दिखाना बंद करना हो, पर रिकॉर्ड रखना हो, तो **Taking bookings** बंद कर दें। प्रोवाइडर पर **Inactive** बैज दिखेगा।
4. **Save provider** पर क्लिक करें।

### काम के घंटे सेट करें { #set-working-hours }

काम के घंटे पूरे बिज़नेस के लिए होते हैं। ये आपकी WhatsApp सेटिंग्स से आते हैं, हर प्रोवाइडर के अलग नहीं होते।

1. नीचे-बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **WhatsApp** चुनें, फिर **Live Chat Settings**। आप **WhatsApp** → **Manage** → **Live Chat Settings** से भी खोल सकते हैं।
3. नीचे स्क्रॉल करके **Working Hours** तक जाएँ।
4. **Timezone** में अपने बिज़नेस का टाइमज़ोन चुनें, जैसे `Asia/Kolkata`।
5. जिस दिन बिज़नेस खुला रहता है, उसके बॉक्स पर टिक करें। फिर शुरू और खत्म होने का समय बदलने के लिए उन पर क्लिक करें। जिस दिन टिक नहीं है, वहाँ **Closed** दिखता है।
6. **Save** पर क्लिक करें।

Ohanvi सिर्फ़ इन्हीं घंटों के अंदर के समय दिखाता है। इन्हीं घंटों से यह भी तय होता है कि ग्राहक को कौन-सा WhatsApp ऑटो-रिप्लाई मिलेगा, **Welcome** या **Off Hours**।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No providers yet** — **Until one exists, no appointment slots can be offered.** | अभी कोई प्रोवाइडर नहीं जोड़ा गया है। | **Add provider** पर क्लिक करें। |
| **Name** या **Username** के नीचे **Required** दिख रहा है | वह फ़ील्ड खाली है। | दोनों फ़ील्ड भरें। |
| **Could not save the provider** | सर्वर ने सेव नहीं किया। | यूज़रनेम देख लें और दोबारा कोशिश करें। फिर भी न हो, तो अपने एडमिन से पूछें। |
| किसी सर्विस के लिए कोई समय नहीं दिखता | उस सर्विस को कोई एक्टिव प्रोवाइडर नहीं देता। या वह दिन **Closed** है, या **Working Hours** में उसके घंटे सेव नहीं हैं। | सर्विस को किसी प्रोवाइडर के **Services performed** में जोड़ें, या और दिन खोलें। |
| रात के समय दिख रहे हैं | **Working Hours** में उस दिन रात के घंटे खुले हैं। | हर दिन के खुले घंटे ठीक से सेट करें और **Save** पर क्लिक करें। |
