# Tasks

Tasks is Ohanvi's built-in task board. Create a project, add columns for each stage of work, and move tasks across them as your team makes progress.

## Where to find it

Tasks is in the **right-hand** rail, next to the notification bell and **Help** — not in the left rail.

- Click **Tasks** to open the **Tasks** panel. It has the tabs **Today**, **Assigned to me** and **Created by me**, and the buttons **Create** and **Board**.
- Click **Board** to open the full task board. Its toolbar switches between the **Summary**, **Timeline**, **Backlog**, **Board** and **List** views.

## Before you start

- Your role has Task access. Without it, the **Tasks** icon is hidden.
- Your workspace has a task project with at least 1 board column. A new project starts with no columns — see [Set up a task project](set-up-task-project.md).
- Teammates you want to assign work to are members of the project. The assignee list only shows project members.
