# देखें कि आज क्या शेड्यूल है { #see-what-is-scheduled-for-today }

व्हाट्सऐप, CRM, ईमेल, सोशल और अपॉइंटमेंट में आज के लिए शेड्यूल की हुई हर चीज़ देखने के लिए **Today** व्यू इस्तेमाल करें। अंत में आपको पता होगा कि आज क्या जाएगा, उसका मालिक कौन है, और किन आइटम में बदलाव चाहिए।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Schedule** दिखता है। डिफ़ॉल्ट रूप से यह केवल वर्कस्पेस के Super Admin रोल के पास होता है। न दिखे तो अपने एडमिन से पूछें।
- कम से कम एक मॉड्यूल में आज के लिए कुछ शेड्यूल है। आइटम आप उनके अपने मॉड्यूल में बनाते हैं।

## चरण { #steps }

### Today खोलें { #open-today }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Today** चुनें। पेज के टाइटल में **Today** लिखा होता है और पेज **List** व्यू में खुलता है।
2. सूची पढ़ें। पंक्तियाँ एक दिन के शीर्षक, **Today**, के नीचे समय के क्रम में होती हैं।
3. हर पंक्ति समय, टाइटल, चैनल, टाइप और स्टेटस पिल दिखाती है, जैसे **WhatsApp · Broadcast** और **Scheduled**।
4. किसी पंक्ति पर क्लिक करें। उसकी जानकारी दाईं ओर खुलती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

!!! note "ध्यान दें"
    **Today** आज के हर स्टेटस के आइटम दिखाता है, **Sent** और **Cancelled** वाले भी। शाम तक सूची में वे आइटम भी दिखते हैं जो पहले ही जा चुके हैं।

### सूची को छोटा करें { #narrow-the-list }

1. किसी चैनल चिप पर क्लिक करें: **WhatsApp**, **CRM**, **Email**, **Social** या **Appointments**। पहला क्लिक केवल वही चैनल दिखाता है। और चिप पर क्लिक करके चैनल वापस जोड़ें।
2. केवल अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
3. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### आज जाने वाला आइटम बदलें { #change-an-item-that-is-due-today }

1. आइटम पर क्लिक करें। उसकी जानकारी दाईं ओर खुलती है।
2. उसे आगे-पीछे करने के लिए **Reschedule**, उसके अपने मॉड्यूल में खोलने के लिए **Edit**, रद्द करने के लिए **Cancel**, या हटाने के लिए **Delete** पर क्लिक करें। देखें [शेड्यूल किया हुआ आइटम रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।

### आज को कैलेंडर पर देखें { #look-at-today-on-the-calendar }

1. पेज के ऊपर **Calendar** पर क्लिक करें। महीने का व्यू खुलता है।
2. आज की तारीख ढूँढें। केवल आज के आइटम दिखते हैं, क्योंकि फ़िल्टर अब भी **Today** है।
3. वापस जाने के लिए **List** पर क्लिक करें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें। **New schedule — pick a channel** शीट खुलती है।
2. **New in WhatsApp**, **New in CRM**, **New in Email**, **New in Social** या **New in Appointments** चुनें। Ohanvi उस मॉड्यूल की अपनी स्क्रीन खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** और संदेश **No schedules match these filters. Try another channel or clear the status filter.** | आज कुछ तय नहीं है, या कोई चैनल, मालिक या स्टेटस फ़िल्टर उसे छिपा रहा है। | दूसरे चैनल चिप पर क्लिक करें, **Everyone's schedule** चुनें, या स्टेटस **Any status** करें। |
| आज जाने वाला कोई आइटम नहीं दिख रहा | उसकी तारीख और समय नहीं है, या वह ऐसे चैनल का है जिसे आपने बंद किया है। | आइटम को उसके अपने मॉड्यूल में शेड्यूल किया हुआ समय दें। चैनल चिप फिर से चालू करें। |
| **Could not load your schedule.** | पेज सर्वर तक नहीं पहुँच पाया। | संदेश पर रीट्राई बटन पर क्लिक करें। फिर भी न हो तो साइन आउट करके दोबारा साइन इन करें। |
| **Reschedule**, **Edit**, **Cancel** और **Delete** नहीं दिख रहे | छोटी विंडो में जानकारी वाला पैनल छिपा रहता है। | ब्राउज़र विंडो चौड़ी करें। |
