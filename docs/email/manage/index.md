# Manage

Manage is the hub for how your email goes out.

## Where to find it

Open **Email** in the left rail, then select **Manage**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Scheduler](../use-the-email-scheduler.md) | You plan sends on a calendar. |
| [Business Holidays](../manage-business-holidays.md) | You need days with no sends. |
| [Sender Identities](../set-up-sender-identity.md) | You set up a from address. |
| [Email Sending Server](../connect-email-provider.md) | You connect your own provider. |
| [Send Logs](../read-send-logs.md) | You check each recipient. |
| [Suppression List](../use-the-suppression-list.md) | You block addresses. |
| [Topics](../manage-email-topics.md) | You group email by subject. |

## Before you start

- An admin role that can see **Manage**.
