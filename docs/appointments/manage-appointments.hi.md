# अपॉइंटमेंट प्रबंधित करें { #manage-appointments }

**Appointments** पेज आपकी बुकिंग दिन के हिसाब से और उनके स्टेटस के साथ दिखाता है। इसका इस्तेमाल नए अनुरोध मंज़ूर करने, बुकिंग का समय बदलने, उसे रद्द करने और विज़िट के बाद बंद करने के लिए करें। अंत में हर बुकिंग का सही स्टेटस होगा, और ग्राहक को बदलाव की जानकारी व्हाट्सऐप पर मिल चुकी होगी।

## शुरू करने से पहले { #before-you-start }

- आपको बाएँ रेल में **Appts** दिखता हो। न दिखे तो अपने एडमिन से कहें कि आपके रोल को Appointments का एक्सेस दें।
- बुकिंग आ रही हों। देखें [व्हाट्सऐप पर बुकिंग लें](take-bookings-on-whatsapp.md)।

## चरण { #steps }

### बुकिंग खोजें { #find-a-booking }

1. बाएँ रेल में **Appts** खोलें, फिर **Appointments** चुनें। **Appointments** पेज खुलता है। सबटाइटल बताता है कि कितने अनुरोध इंतज़ार में हैं, जैसे **3 pending requests**।
2. बुकिंग दिन के शीर्षकों के नीचे समूहों में होती हैं: **Today**, **Tomorrow**, फिर पूरी तारीख।
3. हर पंक्ति में स्टेटस, सर्विस और समय, ग्राहक का फ़ोन और प्रोवाइडर दिखता है, जैसे **with Dr Mehta**।
4. एक दिन देखने के लिए **Today** पर क्लिक करें। आगे-पीछे जाने के लिए **Previous day** और **Next day** इस्तेमाल करें। सभी दिन दोबारा देखने के लिए **Show all upcoming** (X आइकन) पर क्लिक करें।
5. नई बुकिंग लोड करने के लिए **Refresh** पर क्लिक करें।

### खाली सूची को समझें { #read-an-empty-list }

1. पेज पर **No appointments yet** दिखे, तो कोई बुकिंग नहीं है। मैसेज में लिखा होता है **Requests booked over WhatsApp and manual bookings will appear here.** पहले व्हाट्सऐप बुकिंग सेट करें। देखें [व्हाट्सऐप पर बुकिंग लें](take-bookings-on-whatsapp.md)।
2. पेज पर **Nothing on this day** दिखे, तो आप ऐसा एक दिन देख रहे हैं जिसमें कोई बुकिंग नहीं है। मैसेज में लिखा होता है **Pick another day, or clear the filter to see everything.** **Show all upcoming** पर क्लिक करें।
3. पेज पर **Please try again.** के साथ कोई एरर दिखे, तो **Refresh** पर क्लिक करें।

### अनुरोध मंज़ूर या अस्वीकार करें { #confirm-or-reject-a-request }

नए अनुरोधों का स्टेटस **Requested** दिखता है।

1. बुकिंग पर, स्वीकार करने के लिए **Confirm** या मना करने के लिए **Reject** पर क्लिक करें।
2. **Done** मैसेज दिखता है। स्टेटस बदलकर **Confirmed** या **Rejected** हो जाता है।

Ohanvi ग्राहक को व्हाट्सऐप मैसेज भेजता है: **Your appointment has been confirmed.** या **Sorry, your appointment request could not be accepted.**

### बुकिंग को दूसरे समय पर ले जाएँ { #move-a-booking-to-another-time }

**Move** **Requested** और **Confirmed** बुकिंग पर उपलब्ध है।

1. **Move** पर क्लिक करें। तारीख चुनने वाला खुलता है। नई तारीख चुनें।
2. समय चुनने वाला खुलता है। नया समय चुनें।
3. अगर समय खाली है, तो **Appointment moved** मैसेज दिखता है। बुकिंग नए समय पर कन्फ़र्म हो जाती है और उसके रिमाइंडर भी उसी के साथ खिसक जाते हैं।
4. अगर समय खाली नहीं है, तो **Move appointment** डायलॉग कारण और **These times are free:** के साथ खुलता है। बुकिंग को वहाँ ले जाने के लिए सुझाए गए समयों में से किसी एक पर क्लिक करें।

**Move** ग्राहक को कोई मैसेज नहीं भेजता। नया समय उन्हें खुद बताएँ।

### बुकिंग रद्द करें { #cancel-a-booking }

1. **Requested** या **Confirmed** बुकिंग पर **Cancel** पर क्लिक करें।
2. **Done** मैसेज दिखता है और स्टेटस बदलकर **Cancelled** हो जाता है। कतार में लगे रिमाइंडर हट जाते हैं।

Ohanvi ग्राहक को **Your appointment has been cancelled.** भेजता है।

!!! warning "रद्द की गई बुकिंग दोबारा नहीं खोली जा सकती"
    **Cancelled**, **Rejected**, **Completed** और **No-show** अंतिम स्टेटस हैं। ग्राहक को वापस लाने के लिए उन्हें दोबारा बुकिंग करनी होगी।

### विज़िट को बंद करें { #close-off-a-visit }

1. **Confirmed** बुकिंग पर तीन-डॉट वाले मेन्यू पर क्लिक करें।
2. विज़िट के बाद **Mark completed** चुनें, या ग्राहक न आया हो तो **Mark no-show** चुनें।

नो-शो अपने आप चिह्नित कराने के लिए **Mark as no-show after (minutes, 0 = never)** सेट करें। देखें [बुकिंग के नियम और रिमाइंडर सेट करें](set-booking-rules-and-reminders.md)।

### बुकिंग के स्टेटस { #booking-statuses }

| स्टेटस | मतलब | उपलब्ध कार्रवाइयाँ |
| --- | --- | --- |
| **Requested** | आपकी मंज़ूरी का इंतज़ार है। | **Confirm**, **Reject**, **Move**, **Cancel** |
| **Confirmed** | बुक हो गई। चालू हों तो रिमाइंडर कतार में रहते हैं। | **Move**, **Cancel**, **Mark completed**, **Mark no-show** |
| **Rescheduled** | नए समय पर ले जाई गई। | इस पेज पर कोई नहीं |
| **Rejected**, **Cancelled**, **Completed**, **No-show** | बंद। | कोई नहीं |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Action failed** | इस बीच बुकिंग बदल गई, जैसे वह पहले ही रद्द या पूरी हो चुकी थी। | **Refresh** पर क्लिक करें और स्टेटस देखें। |
| **That time is not available** | नया समय काम के घंटों या आपके बुकिंग नियमों से बाहर है, या कोई प्रोवाइडर खाली नहीं है। | **These times are free:** के नीचे दिए समयों में से कोई एक चुनें। |
| **Somebody just took that time** | आप इसे खिसका रहे थे तभी किसी और बुकिंग ने वह स्लॉट ले लिया। | सुझाए गए समयों में से कोई एक चुनें। |
| ग्राहक को व्हाट्सऐप मैसेज नहीं मिला | स्टेटस मैसेज सादे टेक्स्ट होते हैं। जिन ग्राहकों ने पिछले 24 घंटों में आपको मैसेज नहीं किया, उन्हें व्हाट्सऐप सादा टेक्स्ट भेजने नहीं देता। | व्हाट्सऐप इनबॉक्स से मंज़ूर टेम्प्लेट के ज़रिए ग्राहक से संपर्क करें। |
| **No appointments yet** | कोई बुकिंग नहीं हुई है। | बुकिंग फ़्लो जोड़ें। देखें [व्हाट्सऐप पर बुकिंग लें](take-bookings-on-whatsapp.md)। |
| कोई पुरानी बुकिंग नहीं दिख रही | पेज सिर्फ़ ताज़ा बुकिंग लोड करता है [LIMIT]। | उसे **Schedule** → **Appointments** व्यू में खोजें। देखें [शेड्यूल](../schedule/index.md)। |
