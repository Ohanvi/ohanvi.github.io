# भेजने के लॉग पढ़ें { #read-the-send-logs }

Send Logs में दिखता है कि कैंपेन के हर पाने वाले के साथ क्या हुआ। इससे आप देख सकते हैं कि किसे ईमेल मिला, किसने खोला और क्लिक किया, और कुछ ईमेल क्यों फ़ेल हुए। आख़िर में आप पूरा लॉग एक्सपोर्ट कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपने कम से कम 1 कैंपेन भेजा हो। इसके लिए [ईमेल कैंपेन भेजें](send-email-campaign.md) देखें।
- आपको **Email** पैनल में **Manage** दिखता हो। न दिखे तो अपने एडमिन से पूछें।

## स्टेप { #steps }

### किसी कैंपेन का लॉग खोलें { #open-the-log-for-a-campaign }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।
2. **Send Logs** चुनें।
3. **Campaign** में कैंपेन चुनें। जब तक आप कैंपेन नहीं चुनते, पेज पर **Select a campaign** लिखा रहता है।
4. टेबल पढ़ें। इसमें हर व्यक्ति के लिए **Recipient**, **Status**, **Sent**, **Opened**, **Clicked**, **Unsubscribed** और **Error** दिखते हैं।

### फ़िल्टर और खोज { #filter-and-search }

1. लिस्ट को छोटा करने के लिए किसी फ़िल्टर पर क्लिक करें: **All**, **Queued**, **Failed**, **Opened**, **Not Opened**, **Clicked**, **Bounced**, **Complained** या **Unsubscribed**।
2. किसी एक व्यक्ति को खोजने के लिए **Search recipient email** में टाइप करें।

### एक पाने वाले का हाल पढ़ें { #read-one-recipient }

1. किसी लाइन पर क्लिक करें। उसकी **Activity Timeline** खुलेगी।
2. उस व्यक्ति को खोलने के लिए **View Contact** पर क्लिक करें। उन्हें जो ईमेल मिला, वह देखने के लिए **View Template** पर क्लिक करें।

### लॉग एक्सपोर्ट करें { #export-the-log }

1. **Export** पर क्लिक करें।
2. हर लाइन के लिए **Export Excel (full log)** पर क्लिक करें। सिर्फ़ स्क्रीन पर दिख रही लाइनों के लिए **Export CSV (current page)** पर क्लिक करें।

### हर स्टेटस का मतलब { #what-each-status-means }

| स्टेटस | मतलब |
| --- | --- |
| **Queued** | भेजे जाने का इंतज़ार कर रहा है। |
| **Sent** | भेजने वाले सर्वर को दे दिया गया है। |
| **Delivered** | पाने वाले के इनबॉक्स प्रोवाइडर ने ईमेल ले लिया है। |
| **Bounced** | वह पता ईमेल पा नहीं सका। |
| **Complained** | पाने वाले ने इसे स्पैम बताया। |
| **Failed** | ईमेल भेजना पूरा नहीं हुआ। **Error** कॉलम में वजह लिखी होती है। |
| **Skipped suppressed** | ईमेल नहीं भेजा गया, क्योंकि पता सप्रेशन लिस्ट में है। |

टेस्ट ईमेल Send Logs में नहीं दिखता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Select a campaign** | कोई कैंपेन चुना नहीं गया है। | **Campaign** में एक कैंपेन चुनें। |
| **No send logs yet** | कैंपेन अभी किसी को भेजा नहीं गया है। | **Campaigns** पर उसका स्टेटस देखें। |
| कई लाइनों में **Failed** दिख रहा है। | भेजने वाला वेरिफ़ाई नहीं है, या आपके अपने प्रोवाइडर ने कनेक्शन मना कर दिया। | **Error** कॉलम पढ़ें। **Sender Identities** और **Email Sending Server** जाँचें। |
| ओपन कम दिख रहे हैं। | कुछ इनबॉक्स ट्रैकिंग इमेज को ब्लॉक कर देते हैं। | ओपन के साथ क्लिक की भी तुलना करें। |
