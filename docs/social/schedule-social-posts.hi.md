# पोस्ट शेड्यूल करें और कतार प्रबंधित करें { #schedule-posts-and-manage-the-queue }

पोस्ट के लिए आने वाली तारीख और समय चुनें, फिर उसके जाने तक **Publish** स्क्रीन पर उसे ट्रैक करें। आप पोस्ट को कैलेंडर पर खिसका सकते हैं, किसी को पहले पब्लिश कर सकते हैं, शेड्यूल रद्द कर सकते हैं, और कुछ नेटवर्क पर फ़ेल हुई पोस्ट को दोबारा आज़मा सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Social** दिखता हो, और उसके पैनल में **Publish**।
- कम से कम एक नेटवर्क कनेक्ट हो। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
- आपको कंपोज़र में पोस्ट लिखना आता हो। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## चरण { #steps }

### पोस्ट शेड्यूल करें { #schedule-a-post }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. **New Post** पर क्लिक करें और अपनी पोस्ट लिखें।
3. कंपोज़र के नीचे **Schedule** पर क्लिक करें।
4. तारीख चुनें, फिर समय। फ़ुटर में **Publishes** और उसके बाद आपकी तारीख और समय दिखता है।
5. **Schedule Post** पर क्लिक करें। संदेश **Post scheduled for …** दिखता है, और पोस्ट **Queue** टैब में दिखती है।

सेव करने से पहले समय हटाने के लिए तारीख के बगल में **Clear schedule** पर क्लिक करें। उसे बदलने के लिए **Reschedule** पर क्लिक करें।

!!! note "ध्यान दें"
    **Facebook** अभी से 10 मिनट से 6 महीने के बीच का समय ही मानता है। बाकी नेटवर्क 2 साल आगे तक मानते हैं। अगर आप ऐसा नेटवर्क चुनते हैं जो आपकी तारीख नहीं मानता, तो Ohanvi उसे हटा देता है और **Cleared the schedule — … does not accept that date.** दिखाता है।

### Publish स्क्रीन पढ़ें { #read-the-publish-screen }

**Publish** स्क्रीन पर 4 टैब हैं:

- **Queue**: जाने का इंतज़ार करती पोस्ट: **Scheduled**, **Queued** और **Publishing**।
- **Drafts**: जो पोस्ट अभी शेड्यूल नहीं हुईं।
- **Approvals**: समीक्षा का इंतज़ार करती पोस्ट। देखें [पब्लिश होने से पहले पोस्ट की समीक्षा करें](approve-social-posts.md)।
- **Sent**: **Published**, **Partial**, **Failed** और **Cancelled** पोस्ट।

व्यू बदलने के लिए **List** या **Calendar** पर क्लिक करें। **Channels** से छाँटने के लिए **Filters** पर क्लिक करें। दाईं ओर का **Publishing Overview** पैनल इस हफ़्ते की **Queued**, **Drafts**, **Published** और **Failed** पोस्ट गिनता है।

समय आपके डिवाइस के टाइम ज़ोन में दिखता है।

### कैलेंडर का इस्तेमाल करें { #use-the-calendar }

1. **Calendar** पर क्लिक करें।
2. **Day**, **Week** या **Month** चुनें। मौजूदा तारीख पर लौटने के लिए **Today** पर क्लिक करें।
3. शेड्यूल की हुई पोस्ट को खिसकाने के लिए उसे नए स्लॉट पर खींचें। संदेश **Post rescheduled to …** दिखता है। **Month** व्यू में पोस्ट का दिन का समय वही रहता है।
4. नई पोस्ट की योजना बनाने के लिए किसी खाली स्लॉट पर क्लिक करें। कंपोज़र उस तारीख के लिए खुलता है।
5. **Undated drafts**, यानी जिन ड्राफ़्ट की अभी कोई तारीख नहीं है, उन्हें देखने के लिए **No Date** पर क्लिक करें।

जो पोस्ट **Published**, **Partial**, **Publishing** या **Cancelled** हैं, उन्हें आप खींच नहीं सकते।

### ड्राफ़्ट या कतार की पोस्ट अभी पब्लिश करें { #publish-a-draft-or-a-queued-post-now }

1. **Drafts** टैब में पोस्ट पर **Publish** पर क्लिक करें। **Queue** टैब में **⋯** मेनू पर क्लिक करें, फिर **Publish Now**।
2. **Publish to** विंडो में आपके कनेक्टेड अकाउंट दिखते हैं। जिन पर पोस्ट करनी है उन पर टिक करें।
3. **Publish Now** पर क्लिक करें। पोस्ट टिक किए गए अकाउंट पर तुरंत लाइव हो जाती है।

### शेड्यूल की हुई पोस्ट रद्द करें { #cancel-a-scheduled-post }

1. **Queue** टैब में पोस्ट के **⋯** मेनू पर क्लिक करें, फिर **Cancel schedule** पर क्लिक करें।
2. **Cancel this scheduled post?** विंडो खुलती है। पक्का करने के लिए **Cancel schedule** पर क्लिक करें।

पोस्ट **Sent** टैब में **Cancelled** में चली जाती है। आप उसे अब भी एडिट या रीशेड्यूल कर सकते हैं।

### फ़ेल हुई पोस्ट दोबारा आज़माएँ { #retry-a-failed-post }

Ohanvi पोस्ट को **Failed** मार्क करने से पहले हर नेटवर्क पर ज़्यादा से ज़्यादा 5 बार कोशिश करता है।

1. **Sent** टैब खोलें।
2. **Failed** या **Partial** पोस्ट पर **Retry** पर क्लिक करें। सिर्फ़ वही नेटवर्क दोबारा आज़माए जाते हैं जिन पर वह फ़ेल हुई थी। जिन नेटवर्क पर पोस्ट जा चुकी है, उन्हें जैसा है वैसा छोड़ दिया जाता है।
3. कौन-सा नेटवर्क फ़ेल हुआ और क्यों, यह देखने के लिए **⋯** मेनू पर क्लिक करें, फिर **Post Details**।

### पोस्ट डिलीट करें { #delete-a-post }

1. पोस्ट पर **Delete** आइकन या मेनू आइटम पर क्लिक करें। **Delete this post?** विंडो खुलती है।
2. **Delete** पर क्लिक करें।

!!! warning "डिलीट करने से पोस्ट अनपब्लिश नहीं होती"
    Delete सिर्फ़ **Publish** से पोस्ट हटाता है। जो पहले ही किसी नेटवर्क पर भेजा जा चुका है, वह वहाँ लाइव रहता है।

## पोस्ट के स्टेटस { #post-statuses }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | सेव है, शेड्यूल या पब्लिश नहीं हुई। |
| **Scheduled** | पब्लिश होने का समय तय है। |
| **Queued** | इसके पब्लिश जॉब चलने का इंतज़ार कर रहे हैं। |
| **Publishing** | कम से कम एक नेटवर्क पर अभी पोस्ट हो रही है। |
| **Published** | चुने हुए हर नेटवर्क पर चली गई। |
| **Partial** | कुछ नेटवर्क पर चली गई और बाकी पर फ़ेल हुई। |
| **Failed** | हर नेटवर्क पर फ़ेल हुई। |
| **Cancelled** | पब्लिश होने से पहले शेड्यूल रद्द कर दिया गया। |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **scheduledAt must be in the future** | चुना हुआ समय बीत चुका है। | बाद का समय चुनें। |
| **Channel account is disconnected: …** | पोस्ट लिखने के बाद नेटवर्क डिस्कनेक्ट हो गया। | **Connect** → **Social Connections** में उसे दोबारा कनेक्ट करें, फिर कोशिश करें। |
| **Post is awaiting approval and cannot be scheduled until approved** | पोस्ट समीक्षा के लिए जमा की गई थी। | किसी अप्रूवर से **Approvals** टैब में उसे मंज़ूर करवाएँ। |
| **No channel is connected yet — posts cannot be published until at least one network is connected.** | कोई नेटवर्क कनेक्ट नहीं है। | **Connect** पर क्लिक करें और एक नेटवर्क कनेक्ट करें। |
| पोस्ट **Partial** या **Failed** दिखती है | किसी नेटवर्क ने पोस्ट ठुकरा दी, या उसका एक्सेस खत्म हो गया। | वजह पढ़ने के लिए **Post Details** खोलें, उसे ठीक करें, फिर **Retry** पर क्लिक करें। |
