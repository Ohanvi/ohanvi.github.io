# क्लास शेड्यूल करें { #schedule-a-class }

क्लास में एक इंस्ट्रक्टर होता है, एक समय होता है, और उसमें कई लोग बुक होते हैं। जैसे योगा का बैच या कोचिंग सेशन। एक-से-एक अपॉइंटमेंट में एक ग्राहक एक स्लॉट लेता है। क्लास में कई ग्राहक एक ही स्लॉट शेयर करते हैं। आखिर में आपकी हफ़्ते की लिस्ट में क्लास दिखेंगी, और हर क्लास पर दिखेगा कि कितनी सीटें भर चुकी हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Appts** दिखे। **Classes** न दिखे, तो अपने एडमिन से Appointments क्लास का एक्सेस माँगें।
- क्लास के लिए आपके पास एक सर्विस हो, जैसे `Morning Yoga`। देखें [बुक होने वाली सर्विस जोड़ें](add-services.md)।
- इंस्ट्रक्टर चुनना हो, तो पहले उन्हें प्रोवाइडर के रूप में जोड़ लें। देखें [प्रोवाइडर और काम के घंटे जोड़ें](add-providers.md)।

## स्टेप { #steps }

### क्लास शेड्यूल करें { #schedule-a-class_1 }

1. लेफ़्ट रेल में **Appts** खोलें, फिर **Classes** चुनें। **Classes** पेज इसी हफ़्ते के साथ खुलता है।
2. **Schedule a class** पर क्लिक करें। **Schedule a class** डायलॉग खुलता है।
3. **Class** में सर्विस चुनें। डायलॉग में लिखा दिखता है: **Everyone booked into a class shares the instructor and the time — that is what makes it different from an appointment.**
4. **Instructor** में कोई प्रोवाइडर चुनें। या **Not assigned** ही रहने दें।
5. **Starts** बॉक्स पर क्लिक करें। पहले तारीख चुनें, फिर समय। यहाँ पहले से कल सुबह 7:00 AM भरा होता है।
6. **Lasts** में क्लास कितनी देर चलेगी, यह चुनें: 30, 45, 60, 75, 90 या 120 मिनट।
7. **Places** में लिखें कि कितने लोग जुड़ सकते हैं। यहाँ पहले से `20` भरा होता है।
8. **Schedule class** पर क्लिक करें। **Saved** मैसेज आता है और क्लास लिस्ट में दिखने लगती है।

### खाली क्लास लिस्ट का मतलब { #read-an-empty-class-list }

1. उस हफ़्ते में कोई क्लास न हो, तो पेज पर **No classes in this week** और **Schedule one to let several people book the same time.** दिखता है। वहीं **Schedule a class** पर क्लिक करें, या **Next week** पर जाएँ।
2. पेज के सबटाइटल में लिखा होता है **One instructor, one time, several people booked in.**

### देखें कि क्लास कितनी भरी है { #check-how-full-a-class-is }

1. **Classes** पेज पर हफ़्ता बदलने के लिए **Previous week** और **Next week** दबाएँ।
2. हर क्लास पर कुल सीटों में से भरी सीटें दिखती हैं, जैसे **12/20**। 2 या उससे कम सीटें बचने पर बैज का रंग एम्बर हो जाता है। एक भी सीट न बचे तो **Full** दिखता है।
3. हर बुक हुए ग्राहक का फ़ोन नंबर और स्टेटस देखने के लिए लिस्ट आइकन (**Who is booked**) पर क्लिक करें। यह आइकन तब दिखता है जब कम से कम 1 सीट भर चुकी हो। किसी ने बुक न किया हो, तो लिस्ट में **Nobody booked yet** और **Places taken will be listed here.** दिखता है।

### क्लास एडिट करें { #edit-a-class }

1. क्लास पर पेंसिल आइकन (**Edit**) पर क्लिक करें। **Edit class** डायलॉग खुलता है।
2. इंस्ट्रक्टर, समय, अवधि या सीटें बदलें।
3. **Save class** पर क्लिक करें।

**Places** को पहले से बुक हुए लोगों की संख्या से कम नहीं किया जा सकता। **Places** के नीचे एक हिंट दिखता है कि कितने लोग बुक हैं, जैसे **5 already booked — cannot go below that**।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Add a service first — a class is a service booked by several people.** | आपके पास कोई सर्विस नहीं है। | **Appts** → **Services** में एक सर्विस जोड़ें। देखें [बुक होने वाली सर्विस जोड़ें](add-services.md)। |
| **Class** के नीचे **Required** | सर्विस नहीं चुनी गई। | **Class** में सर्विस चुनें। |
| **Places** के नीचे **At least 1** | **Places** खाली है, 0 है, या कोई नंबर नहीं है। | 1 या उससे बड़ा नंबर लिखें। |
| **Places** के नीचे **At least 5 are already booked** | आपने पहले से बुक हुए लोगों से कम सीटें रखने की कोशिश की। | **Places** को बुक हुए लोगों की संख्या के बराबर या उससे ज़्यादा रखें। |
| **No classes in this week** | इस हफ़्ते में कुछ भी शेड्यूल नहीं है। | **Next week** पर क्लिक करें, या **Schedule a class** पर क्लिक करें। |
| **Could not save the class** | सर्वर ने क्लास नहीं ली। जैसे इसलिए कि खत्म होने का समय शुरू होने के समय के बाद नहीं था। | **Starts** और **Lasts** देखें, फिर दोबारा कोशिश करें। |
