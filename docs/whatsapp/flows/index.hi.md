# फ़्लो { #flows }

फ़्लो अपने-आप चलने वाली चैट हैं। चैटबॉट फ़्लो आपकी तरफ़ से ग्राहकों को जवाब देता है और सवाल पूछता है। ज़रूरत पड़ने पर वह बातचीत किसी इंसान को सौंप देता है। इन गाइड में बिल्डर का हर ब्लॉक समझाया गया है, और यह भी कि क्या भरना है।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।

![Flows स्क्रीन। इसमें फ़्लो की लिस्ट और चुने हुए फ़्लो का ओवरव्यू दिख रहा है](../../assets/screenshots/whatsapp-flows-0-overview.png)

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट हो। देखें [अपना नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस मिला हो। स्क्रीन न दिखे, तो अपने एडमिन से पूछें।
