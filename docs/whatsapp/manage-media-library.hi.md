# WhatsApp मीडिया लाइब्रेरी मैनेज करें { #manage-the-whatsapp-media-library }

देखें कि आपका WhatsApp मीडिया कितना क्लाउड स्टोरेज लेता है, और जो फ़ाइलें अब काम की नहीं हैं, उन्हें डिलीट करें। आख़िर में आपको अपनी स्टोरेज लिमिट पता होगी और बेकार फ़ाइलें हटने से जगह खाली हो जाएगी। इसमें करीब 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट होना चाहिए। देखें [अपना WhatsApp नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आप **Media Library** पेज खोल पाते हों। [VERIFY: यूज़र इसे कैसे खोलते हैं, और इसके लिए कौन-सी रोल अनुमति चाहिए]
- आपको पता हो कि कौन-सी फ़ाइलें डिलीट करनी हैं। डिलीट की हुई फ़ाइल वापस नहीं आती।

## मीडिया लाइब्रेरी में क्या होता है { #what-the-media-library-holds }

**Media Library** में वे फ़ाइलें दिखती हैं जो आप WhatsApp पर भेजते और पाते हैं, जैसे इमेज, वीडियो, ऑडियो और PDF फ़ाइलें। यहाँ आप देख सकते हैं कि ये फ़ाइलें आपके क्लाउड स्टोरेज में कितनी जगह लेती हैं।

हर रो में फ़ाइल का नाम, फ़ाइल का टाइप और साइज़ दिखता है। लिस्ट के ऊपर **Cloud storage** कार्ड में इस्तेमाल हुई जगह और आपकी लिमिट दिखती है।

!!! note "मीडिया लाइब्रेरी कैसे खोलें"
    अभी **WhatsApp** पैनल में **Media Library** का कोई आइटम नहीं है। [VERIFY: यूज़र इसे कैसे खोलते हैं। मेन्यू की एंट्री छिपी है, और डैशबोर्ड पर **Manage storage** बिलिंग खोलता है, यह पेज नहीं]

## स्टेप { #steps }

### अपना स्टोरेज देखें { #check-your-storage }

1. **Media Library** पेज खोलें। इसका टाइटल **Media Library** है, और उसके नीचे लिखा है **Stored media and the cloud storage it uses.**
2. **Cloud storage** कार्ड देखें। इसमें इस्तेमाल हुई जगह और आपकी लिमिट इस तरह दिखती है: इस्तेमाल / लिमिट।
3. उसके नीचे का बार देखें। स्टोरेज 80% भरते ही बार का रंग बदल जाता है, और पूरा भरने पर बार लाल हो जाता है।
4. स्टोरेज भर जाए, तो कार्ड पर लिखा आता है **Storage full — delete media below to free space, or upgrade your plan.**
5. लिस्ट और आँकड़े दोबारा लोड करने के लिए **Refresh** पर क्लिक करें।

### डिलीट करने के लिए फ़ाइल ढूँढें { #find-a-file-to-delete }

1. **Cloud storage** कार्ड के नीचे लिस्ट को स्क्रॉल करें।
2. हर रो देखें। रो में फ़ाइल का नाम दिखता है, और उसके नीचे फ़ाइल का टाइप और साइज़ लिखा होता है, जैसे `image/jpeg · 240 KB`।
3. जो फ़ाइलें सबसे ज़्यादा जगह लेती हैं, या जो अब काम की नहीं हैं, उन्हें चुनें।

### फ़ाइल डिलीट करें { #delete-a-file }

1. उस रो में **Delete** पर क्लिक करें। इसका आइकन कूड़ेदान जैसा है।
2. **Delete media?** विंडो में फ़ाइल का नाम और साइज़ देख लें।
3. **Delete** पर क्लिक करें। **Media deleted** मैसेज आएगा और वह रो लिस्ट से हट जाएगी।
4. **Refresh** पर क्लिक करें। **Cloud storage** कार्ड में आपकी खाली की हुई जगह दिख जाएगी।

!!! warning "डिलीट करने के बाद वापस नहीं मिलता"
    फ़ाइल डिलीट करते ही उसकी जगह हमेशा के लिए खाली हो जाती है। पक्का न हो, तो विंडो कैंसिल कर दें।

### डैशबोर्ड पर स्टोरेज अलर्ट आए तो { #respond-to-the-dashboard-storage-alert }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Dashboard** चुनें।
2. अलर्ट देखें: **Cloud storage is full.** या **Cloud storage is** के बाद प्रतिशत और **full.** यह तब आता है जब स्टोरेज 80% या उससे ज़्यादा भर जाए।
3. मैसेज पढ़ें। इसमें WhatsApp मीडिया से इस्तेमाल हुई जगह और आपकी लिमिट लिखी होती है।
4. **Manage storage** पर क्लिक करें। [VERIFY: यह Billing & Usage खोलता है, Media Library नहीं]

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No media stored yet** | WhatsApp पर अभी तक कोई फ़ाइल भेजी या पाई नहीं गई है। | कुछ करने की ज़रूरत नहीं। मीडिया भेजने या पाने के बाद फ़ाइलें यहाँ दिखने लगेंगी। |
| लिस्ट में लाल एरर दिखता है। | लिस्ट लोड नहीं हो पाई। | **Refresh** पर क्लिक करें। फिर भी न खुले, तो पेज रीलोड करें। |
| **Failed to delete media** | फ़ाइल हट नहीं पाई। | **Delete** पर दोबारा क्लिक करें। दो बार फ़ेल हो जाए, तो पेज रीलोड करके एक बार और कोशिश करें। |
| **Cloud storage** कार्ड नहीं दिख रहा। | आपके अकाउंट में कोई स्टोरेज लिमिट सेट नहीं है। [VERIFY] | अपने एडमिन से पूछें। |
| डैशबोर्ड पर **Cloud storage is full.** | आपके WhatsApp मीडिया ने पूरा स्टोरेज भर दिया है। | यहाँ से पुरानी फ़ाइलें डिलीट करें, या अपना प्लान अपग्रेड करें। |
