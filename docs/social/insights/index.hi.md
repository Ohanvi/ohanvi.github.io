# इनसाइट्स { #insights }

Insights में आपके सभी चैनलों के रिएक्शन, कमेंट, फ़ॉलोअर और पोस्ट दिखते हैं। किसी एक चैनल को खोलकर आप उसकी पोस्ट और मेट्रिक्स भी देख सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Social** खोलें, फिर **Insights** चुनें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [सोशल इनसाइट्स पढ़ें](../view-social-insights.md) | आप कुल आँकड़े, टॉप पोस्ट और हर पोस्ट की टेबल देखना चाहते हैं। |
| [इनसाइट्स के चार्ट और एक चैनल देखें](../explore-insights-charts.md) | आप फ़ॉलोअर और पोस्ट के चार्ट, मेट्रिक्स टैब और फ़िल्टर देखना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- कम से कम एक नेटवर्क कनेक्ट हो और उस पर पोस्ट पब्लिश हो चुकी हों।
