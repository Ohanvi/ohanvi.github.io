# CRM Automations मैनेज करें { #manage-crm-automations }

आपकी Leads और Deals पर चलने वाले हर बैकग्राउंड रूल को देखें। जैसे, जवाब देना बंद कर चुकी Lead को याद दिलाना। साथ ही जाँचें कि हर रूल चल रहा है या नहीं। आपको पता चल जाएगा कि कौन-से रूल **Active** हैं, कौन-से रुके हुए हैं या अभी ड्राफ़्ट हैं, और हर रूल आख़िरी बार कब चला।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **CRM** दिखना चाहिए, और उसके पैनल में **Automations** भी। इसके लिए ऑटोमेशन फ़्लो का एक्सेस ज़रूरी है। न दिखे, तो अपने एडमिन से पूछें।

## स्टेप { #steps }

### अपने रूल जाँचें { #check-your-rules }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Automations** चुनें।
2. हर रूल का कार्ड पढ़ें। उसमें दिखता है कि रूल किससे शुरू होता है (**When**), कोई शर्त हो तो वह (**And**), और रूल क्या करता है (**Then**)।
3. नाम के नीचे की स्टेटस लाइन पढ़ें:
    - **Draft — not running yet** — रूल अभी पब्लिश नहीं हुआ है।
    - **Paused — not running** — रूल बंद है।
    - **Active · has not run yet** — रूल चालू है और पहले इवेंट का इंतज़ार कर रहा है।
    - **Active · last run …** — रूल चालू है। साथ में उसके आख़िरी रन का नतीजा दिखता है।

चैटबॉट और जर्नी यहाँ नहीं दिखते। उन्हें **WhatsApp** और **Email** में ढूँढें।

### रूल को रोकें या फिर से चालू करें { #pause-or-resume-a-rule }

1. रूल के कार्ड पर **Active** स्विच पर क्लिक करें। **Pause "…"?** विंडो खुलती है।
2. चेतावनी पढ़ें: जो रन पहले से चल रहा है, वह पूरा होगा। जो मैसेज आधा भेजा जा चुका है, वह भी पूरा भेजा जाएगा।
3. **Pause** पर क्लिक करें। स्विच पर अब **Paused** दिखता है।
4. फिर से चालू करना हो, तो **Paused** स्विच पर क्लिक करें। रूल दोबारा **Active** हो जाता है।

### रूल बनाएँ या एडिट करें { #create-or-edit-a-rule }

1. नया रूल बनाने के लिए **New automation** पर क्लिक करें। **Automation flows** स्क्रीन खुलती है, जहाँ आप रूल बनाते हैं।
2. रूल एडिट करने के लिए उसके कार्ड पर क्लिक करें। वह ऑटोमेशन बिल्डर में खुल जाता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not change that automation.** | रोकना या फिर से चालू करना सेव नहीं हुआ। | पेज रीफ़्रेश करें और फिर कोशिश करें। |
| **Could not load your automations** | लिस्ट लोड नहीं हुई। अधूरी लिस्ट दिखाने के बजाय कुछ नहीं दिखता। | पेज रीफ़्रेश करें। बार-बार यही हो, तो अपने एडमिन से कहें कि वे आपका ऑटोमेशन फ़्लो एक्सेस जाँच लें। |
| **No steps yet — this rule does nothing until it has one.** | रूल में ट्रिगर है, लेकिन कोई एक्शन नहीं। | कार्ड पर क्लिक करें और बिल्डर में एक स्टेप जोड़ें। |
| रूल रोकने के बाद भी एक मैसेज चला गया | रोकने से सिर्फ़ नए रन बंद होते हैं। जो रन शुरू हो चुका था, वह पूरा होता है। | रन के पूरा होने का इंतज़ार करें। अगली बार पहले रोकें। |
| **No automations yet** | अभी तक कोई रूल नहीं बना है। | **New automation** पर क्लिक करें। |
