# All schedules

All schedules is the main Schedule screen. It shows every scheduled item from every module in one calendar or list, so you can see the whole plan at once and change any item from here.

**Where to find it:** open **Schedule** in the left rail, then select **All schedules**.


## Guides

| Guide | Use it when |
| --- | --- |
| [View everything scheduled](../view-schedule.md) | You want to see the calendar or list, filter it and read statuses. |
| [Reschedule, cancel or delete a scheduled item](../reschedule-cancel-delete.md) | Plans changed and an item needs to move or stop. |

## Before you start

- You can see **Schedule** in the left rail. By default only the workspace's Super Admin role has it.
- Something is scheduled in at least one module.
