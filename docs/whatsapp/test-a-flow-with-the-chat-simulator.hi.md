# चैट सिम्युलेटर से चैटबॉट फ़्लो टेस्ट करें { #test-a-chatbot-flow-with-the-chat-simulator }

ग्राहकों से पहले बिल्डर से ही अपने चैटबॉट से बात करें। आख़िर में आप अपने फ़ोन पर पूरा फ़्लो चला चुके होंगे, हर जवाब पढ़ चुके होंगे, और जान जाएँगे कि पुराने वर्शन पर कैसे लौटना है।

## शुरू करने से पहले { #before-you-start }

- आपका चैटबॉट फ़्लो सेव और पब्लिश हो। सिम्युलेटर को शुरू होने के लिए लाइव वर्शन चाहिए।
- आपके पास टेस्ट करने लायक व्हाट्सऐप नंबर हो। ऐसा नंबर इस्तेमाल करें जो **Inbox** में किसी एजेंट को असाइन न हो।
- आपने पढ़ा हो कि कीवर्ड की जाँच कैसे काम करती है। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)।

## Test टैब कैसे काम करता है { #how-the-test-tab-works }

चैटबॉट के लिए दाएँ पैनल के **Test** टैब में ऊपर से नीचे 3 टूल होते हैं।

| टूल | यह क्या करता है |
| --- | --- |
| **Would this run?** | कीवर्ड जाँचता है। यह किसी को कुछ नहीं भेजता। |
| **Test on WhatsApp** | चैट सिम्युलेटर। यह लाइव बॉट चलाता है और आपके टेस्ट नंबर पर असली मैसेज भेजता है। |
| **Run published** | पब्लिश किए वर्शन को असली डेटा पर एक बार चलाता है। |

!!! warning "सिम्युलेटर नकली नहीं है"
    यह लाइव बॉट चलाता है। मैसेज व्हाट्सऐप के ज़रिए आपके डाले नंबर पर जाते हैं। अपना ही नंबर इस्तेमाल करें।

## चरण { #steps }

### टेस्ट चैट शुरू करें { #start-a-test-chat }

1. बिल्डर में अपना फ़्लो खोलें।

    ![फ़्लो बिल्डर, जिसमें ऊपर टूलबार में Test बटन और नीचे दाएँ Run test बटन है](../assets/screenshots/whatsapp-chatbot-1-builder.png)

2. टूलबार में **Test** पर क्लिक करें। **Test** टैब खुलता है।
3. **Test on WhatsApp** तक स्क्रॉल करें।
4. **WhatsApp number to test with** में देश कोड के साथ अपना नंबर लिखें, जैसे `9198…`।
5. **Enter** दबाएँ। सिम्युलेटर नंबर याद रख लेता है।
6. **Start from the top** पर क्लिक करें। पहला मैसेज आपके फ़ोन पर जाता है।
7. थोड़ा रुकें। बॉट के जवाब चैट बॉक्स में दिखते हैं।

जब तक फ़्लो का कोई लाइव वर्शन नहीं है, बटनों के नीचे का टेक्स्ट यह कहता है: **The simulator runs the live bot. Save, then publish, and the first message goes to the number above.** पब्लिश करने तक **Start from the top** बंद रहता है।

### ग्राहक बनकर जवाब दें { #reply-as-the-customer }

1. चैट बॉक्स में बॉट का आख़िरी मैसेज पढ़ें।
2. अगर बॉट ने बटन दिए हैं, तो चैट बॉक्स के नीचे किसी एक पर क्लिक करें। हर बटन दबाने लायक चिप है।
3. टाइप करना हो, तो **Message to send as the customer** में टेक्स्ट लिखें। हिंट में **Type as the customer…** लिखा होता है।
4. **Send** पर क्लिक करें, या **Enter** दबाएँ।
5. देर से आए जवाब लोड करने के लिए रिफ़्रेश आइकन (**Refresh**) पर क्लिक करें।

### नतीजा पढ़ें { #read-the-result }

1. चैट बॉक्स ऊपर से नीचे पढ़ें। बॉट के मैसेज बाईं ओर होते हैं। आपके जवाब दाईं ओर।
2. मैसेज के ऊपर **Template · [name]** वाली लाइन का मतलब है कि बॉट ने वह टेम्प्लेट भेजा।
3. जिस मैसेज पर **(no text)** दिखे, उसमें टेक्स्ट नहीं है, जैसे बिना कैप्शन वाला मीडिया ब्लॉक।
4. ग्रे मैसेज का मतलब है कि वह अभी भेजा जा रहा है।
5. वही बातचीत देखने के लिए **WhatsApp** → **Inbox** खोलें। बॉट का हर मैसेज **Bot** से चिह्नित होता है।

अगर चैट बॉक्स में **No messages yet. Start from the top, or say hi.** लिखा है, तो कुछ भेजा नहीं गया है। अगर **Enter a number to see the conversation here.** लिखा है, तो आपने नंबर सेव नहीं किया है।

### बिना भेजे कीवर्ड जाँचें { #check-a-keyword-without-sending }

1. **Test** टैब में **Would this run?** खोजें। उसके नीचे की लाइन में **Sends nothing to anyone.** लिखा है।
2. **A message a customer might send** के नीचे कोई मैसेज लिखें, जैसे `hi`।
3. वैकल्पिक: **From (phone, optional)** के नीचे फ़ोन नंबर लिखें।
4. **Check** पर क्लिक करें। काम होते समय बटन पर **Checking…** दिखता है।
5. नतीजा और उसके नीचे की जाँचें पढ़ें। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)।

### पब्लिश किया वर्शन एक बार चलाएँ { #run-the-published-version-once }

1. **Test** टैब में सबसे नीचे स्क्रॉल करें।
2. **Run published** पर क्लिक करें। अगर आपके बदलाव सेव नहीं हैं, तो बटन पर होवर करके पढ़ें कि वह क्या चलाता है।
3. बटन के नीचे हर चरण की स्थिति पढ़ें। अपडेट करने के लिए **Refresh** पर क्लिक करें।

हर स्थिति का मतलब जानने के लिए देखें [फ़्लो टेस्ट करें और फ़ेल रन ठीक करें](../flows/test-and-monitor-flows.md)।

!!! note "Run published लाइव वर्शन चलाता है"
    यह आपकी स्क्रीन का ड्राफ़्ट नहीं चलाता। टूलटिप **Publish first — there is no live version to run.** पब्लिश करने तक दिखता रहता है।

### किसी बदलाव को अनडू और रीडू करें { #undo-and-redo-an-edit }

1. कैनवास पर कोई बदलाव करें, जैसे गलती से कोई कार्ड डिलीट कर दें।
2. एक बदलाव पीछे जाने के लिए टूलबार में **Undo** पर क्लिक करें।
3. बदलाव वापस लाने के लिए **Redo** पर क्लिक करें।

जब अनडू या रीडू करने को कुछ न हो, तो बटन ग्रे रहते हैं।

### पुराने वर्शन पर लौटें { #go-back-to-an-earlier-version }

1. टूलबार में वर्शन चिप देखें। यह फ़्लो की स्थिति दिखाता है, जैसे **Live** या **Draft**।
2. चिप पर क्लिक करें। **Versions** सूची खुलती है। यह तभी खुलती है जब फ़्लो के 1 से ज़्यादा वर्शन हों।
3. शीर्षक पढ़ें। **This flow** में ऑटोमेशन वर्शन हैं। **Conversation: [name]** में चैट वर्शन हैं।
4. एक वर्शन चुनें। चुनें कि उसे देखना है, एडिट करना है या लाइव करना है। [VERIFY: the exact names of the three actions]
5. **Save** पर क्लिक करें, और अगर आपने बदलाव किया है तो फिर **Publish** पर।

आप बिल्डर के बाहर भी वर्शन देख सकते हैं। **Flows** सूची में फ़्लो की पंक्ति पर क्लिक करें, फिर **Versions** टैब खोलें।

हर पंक्ति में वर्शन नंबर, जैसे `v3`, और एक बैज दिखता है: **Live**, **Published**, **Being edited** या **Draft**। उसमें समय के साथ **Published**, या **Not published** भी दिखता है। उस वर्शन को खोलने के लिए **Open** पर क्लिक करें।

!!! note "पब्लिश किए वर्शन कभी नहीं बदलते"
    पब्लिश किया वर्शन लॉक रहता है। उसे एडिट करने पर नया ड्राफ़्ट बनता है। जो रन पहले से चल रहे हैं वे उसी वर्शन पर रहते हैं जिससे शुरू हुए थे।

अगर सूची में **No versions yet.** लिखा है, तो फ़्लो को एक बार सेव और पब्लिश करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Start from the top** ग्रे है। | फ़्लो का कोई लाइव वर्शन नहीं है, या कोई नंबर सेव नहीं है। | फ़्लो पब्लिश करें, फिर अपना नंबर डालकर **Enter** दबाएँ। |
| बॉट आपके टेस्ट नंबर को जवाब नहीं देता। | नंबर किसी एजेंट को असाइन है या **Requesting** में है। | **Inbox** में बातचीत को resolve करें, फिर दोबारा शुरू करें। |
| शुरू करने के बाद भी चैट बॉक्स खाली रहता है। | जवाब अभी आए नहीं हैं। | **Refresh** पर क्लिक करें। फिर भी खाली रहे, तो जाँचें कि फ़्लो **Active** है। |
| आपका बदलाव टेस्ट में नहीं दिखता। | सिम्युलेटर पब्लिश किया वर्शन चलाता है। | **Save** पर क्लिक करें, फिर **Publish**, फिर दोबारा शुरू करें। |
| सिम्युलेटर बटनों के नीचे लाल रंग में एरर दिखाता है। | भेजना फ़ेल हुआ, जैसे आपका नंबर व्हाट्सऐप पर नहीं है। | नंबर ठीक करें, या **WhatsApp** → **Manage** में अपना व्हाट्सऐप कनेक्शन जाँचें। |
| **Undo** ग्रे है। | अनडू करने को कुछ नहीं है, या फ़्लो अभी-अभी खोला गया है। | पहले कोई बदलाव करें। अनडू सिर्फ़ इस सेशन को कवर करता है। [VERIFY: whether undo survives a save] |
| **Versions** सूची नहीं खुलती। | फ़्लो का सिर्फ़ 1 वर्शन है। | एक बार और एडिट और पब्लिश करें, ताकि दूसरा वर्शन बने। |
