# तैयार संदेश बनाएँ { #create-canned-messages }

ऐसे जवाब सेव करें जिन्हें आपकी टीम इनबॉक्स में **/** और शॉर्टकट टाइप करके डाल सके। अंत में आपका शॉर्टकट कंपोज़र पिकर में दिखेगा, और संदेश भेजने के लिए तैयार होगा। इसमें लगभग 3 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट है। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आपको **WhatsApp** पैनल में **Manage** दिखता है। अगर नहीं, तो अपने एडमिन से कहें कि आपके रोल को एक्सेस दें। देखें [रोल और अनुमतियाँ](../settings/roles-and-permissions.md)।
- आपका रोल तैयार संदेश बना और एडिट कर सकता है। इसके बिना **New quick reply** ग्रे रहता है।
- इमेज, वीडियो या दस्तावेज़ वाले जवाब के लिए फ़ाइल आपके पास तैयार है।

## तैयार संदेश क्या है { #what-a-canned-message-is }

तैयार संदेश (canned message) एक सेव किया हुआ जवाब है। आपकी टीम उसे चैट में **/** और उसके शॉर्टकट से डालती है। ऐप इसे **quick reply** भी कहता है।

हर तैयार संदेश में एक **Shortcut**, एक **Message** और एक **Type** होता है। टाइप **Text**, **Image**, **Video** या **Document** होता है। मीडिया वाला जवाब फ़ाइल को संदेश के साथ, उसके कैप्शन के रूप में भेजता है।

### वेरिएबल { #variables }

वेरिएबल `{{name}}` जैसा प्लेसहोल्डर है। **INSERT VARIABLE** के नीचे के चिप से उसे डालें। जब आप जवाब को चैट में डालते हैं, Ohanvi हर वेरिएबल में उस ग्राहक की वैल्यू भर देता है।

| वेरिएबल | क्या भरता है |
| --- | --- |
| `{{name}}` | ग्राहक का नाम। |
| `{{first_name}}` | ग्राहक का पहला नाम। |
| `{{phone}}` | ग्राहक का फ़ोन नंबर। |
| `{{company}}` | ग्राहक की कंपनी। यह अभी चैट में नहीं भरा जाता, इसलिए जैसा लिखा है वैसा ही रहता है। इसे हाथ से बदलें। |
| `{{agent}}` | जवाब भेजने वाले एजेंट का नाम। |

## चरण { #steps }

### Canned Messages खोलें { #open-canned-messages }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Manage** चुनें।
2. **Canned Messages** चुनें। सूची खुलती है, जिसमें लाइन है **Saved quick-replies your team inserts with "/" in the Live Chat composer.**

    ![Canned Messages, जिसमें Refresh और New quick reply बटन, सर्च बॉक्स, सूची में एक सेव किया हुआ quick reply और उसके Edit, Copy message, Copy shortcut और Delete बटन हैं](../assets/screenshots/whatsapp-canned-messages-1-list.png)

3. **Canned Messages** कार्ड पढ़ें। यह आपके सेव किए जवाबों की गिनती बताता है।

### तैयार संदेश बनाएँ { #create-a-canned-message }

1. **New quick reply** पर क्लिक करें। अगर सूची खाली है, तो इसकी जगह **New Canned Message** पर क्लिक करें। **New Canned Message** फ़ॉर्म खुलता है।

    ![New Canned Message, जिसमें Shortcut, Message, Type, Star this reply, वेरिएबल चिप और Preview हैं](../assets/screenshots/whatsapp-inbox-6-canned-message.png)

2. **Shortcut** में वह शब्द लिखें जिसे आपकी टीम **/** के बाद टाइप करेगी, जैसे `greeting`। स्लैश मत लिखें।
3. **Message** में जवाब लिखें, जैसे `Hi {{name}}, thanks for reaching out! How can we help today?`
4. वेरिएबल जोड़ने के लिए कर्सर को वहाँ रखें जहाँ वह जाना है। **INSERT VARIABLE** के नीचे के किसी चिप पर क्लिक करें, जैसे `{{name}}`।
5. **Type** के नीचे **Text**, **Image**, **Video** या **Document** चुनें।
6. **Image**, **Video** या **Document** के लिए **Attachment** में जाकर फ़ाइल जोड़ें। फ़ाइल आपके लिए अपलोड हो जाती है।
7. वैकल्पिक: **Star this reply** चालू करें। स्टार किया हुआ जवाब कंपोज़र पिकर में सबसे पहले दिखता है।
8. **Preview** देखें। यह नमूने की वैल्यू दिखाता है, पर इनबॉक्स उन्हें नहीं भरता।
9. **Create** पर क्लिक करें। जवाब सूची में आ जाता है।

**Shortcut** और **Message**, दोनों ज़रूरी हैं। मीडिया टाइप के लिए उसकी फ़ाइल भी चाहिए।

### तैयार संदेश पढ़ें { #read-a-canned-message }

1. जवाब को उसके शॉर्टकट या शब्दों से खोजने के लिए **Search shortcut or text…** में टाइप करें।
2. सूची में जवाब पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है।
3. **Shortcut**, **Variables**, **Organization**, **Created** और **Message ID** पंक्तियाँ पढ़ें।

अगर कुछ खुला नहीं है, तो पैनल पर **Select a canned message** लिखा होता है। उसके साथ **Pick a quick reply from the list to read it here.** भी जुड़ता है।

### तैयार संदेश एडिट करें { #edit-a-canned-message }

1. सूची में जवाब पर क्लिक करें।
2. **Edit** पर क्लिक करें। **Edit Canned Message** फ़ॉर्म खुलता है।
3. **Shortcut**, **Message**, **Type** या **Attachment** बदलें। **Star this reply** चालू या बंद करें।
4. **Save Changes** पर क्लिक करें।

### संदेश या उसका शॉर्टकट कॉपी करें { #copy-a-message-or-its-shortcut }

1. सूची में जवाब पर क्लिक करें।
2. संदेश कॉपी करने के लिए **Copy message text** पर क्लिक करें। डिटेल पैनल में इस बटन का नाम **Copy message** है।
3. शॉर्टकट कॉपी करने के लिए **Copy shortcut** पर क्लिक करें।

### तैयार संदेश डिलीट करें { #delete-a-canned-message }

1. सूची में जवाब पर क्लिक करें।
2. **Delete** पर क्लिक करें। **Delete canned message?** विंडो खुलती है। उसमें शॉर्टकट दिखता है।
3. **Delete** पर क्लिक करें। जवाब सूची से हट जाता है।

रखने के लिए **Cancel** पर क्लिक करें।

### अपने कस्टम एट्रिब्यूट इस्तेमाल करें { #use-your-custom-attributes }

संपर्कों के लिए आपके बनाए कस्टम एट्रिब्यूट भी **INSERT VARIABLE** के नीचे चिप के रूप में दिखते हैं। वे `{{attribute.Name}}` की तरह जुड़ते हैं, जैसे `{{attribute.City}}`।

1. तैयार संदेश खोलें और एट्रिब्यूट के चिप पर क्लिक करें, जैसे `{{attribute.City}}`।
2. फ़ॉलबैक तय करने के लिए उसे बार (|) के बाद लिखें: `{{attribute.City|there}}`। जब ग्राहक के पास कोई वैल्यू न हो, तब फ़ॉलबैक दिखता है।
3. जवाब को चैट में डालें। संपर्क की प्रोफ़ाइल से एट्रिब्यूट की वैल्यू भर जाती है। अगर वैल्यू और फ़ॉलबैक दोनों न हों, तो प्लेसहोल्डर जैसा लिखा है वैसा ही रहता है।

### इनबॉक्स में तैयार संदेश डालें { #insert-a-canned-message-in-the-inbox }

1. **WhatsApp** → **Inbox** खोलें, फिर कोई चैट खोलें।
2. कंपोज़र में **/** टाइप करें। **Canned messages** सूची खुलती है।
3. सूची छोटी करने के लिए शॉर्टकट का कुछ हिस्सा टाइप करें।
4. **All**, **Starred**, **Text**, **Image**, **Video** या **Doc** से फ़िल्टर करें।
5. किसी जवाब पर क्लिक करें। वह कंपोज़र में आ जाता है।
6. संदेश पढ़ें, फिर भेजें। वेरिएबल में इस ग्राहक की वैल्यू दिखती हैं। जिस वेरिएबल की कोई वैल्यू नहीं है वह जैसा लिखा है वैसा ही रहता है, इसलिए उसे हाथ से बदलें।

24 घंटे की विंडो और कंपोज़र की बाकी बातों के लिए देखें [व्हाट्सऐप इनबॉक्स का इस्तेमाल करें](use-whatsapp-inbox.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Shortcut is required** | **Shortcut** बॉक्स खाली है। | शॉर्टकट लिखें, फिर **Create** पर क्लिक करें। |
| **Message is required** | **Message** बॉक्स खाली है। | जवाब लिखें। |
| **A file link is required for this type** | आपने **Image**, **Video** या **Document** चुना और कोई फ़ाइल नहीं जोड़ी। | **Attachment** में फ़ाइल जोड़ें, या **Text** चुनें। |
| **Unable to save canned message.** | सेव नहीं हो पाया। | फिर से **Create** या **Save Changes** पर क्लिक करें। |
| **New quick reply** ग्रे है। | आपका रोल तैयार संदेश नहीं बना सकता। | अपने एडमिन से कहें। देखें [रोल और अनुमतियाँ](../settings/roles-and-permissions.md)। |
| **/** टाइप करने के बाद शॉर्टकट नहीं दिखता। | फ़िल्टर उसे छिपा रहा है, या शॉर्टकट की स्पेलिंग अलग है। | **All** चुनें, फिर शॉर्टकट के कम अक्षर टाइप करें। |
