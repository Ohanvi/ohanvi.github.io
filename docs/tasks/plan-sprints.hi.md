# स्प्रिंट में काम की योजना बनाएँ { #plan-work-in-sprints }

अपनी टीम का काम स्प्रिंट में प्लान करें। स्प्रिंट तय समय का एक दौर होता है, आमतौर पर 1 से 4 हफ़्ते का। इस गाइड के बाद आपके पास लक्ष्य और टास्क वाला एक स्प्रिंट होगा, जो चल रहा होगा। स्प्रिंट खत्म होने पर अधूरा काम अगले स्प्रिंट में या वापस बैकलॉग में चला जाएगा।

## शुरू करने से पहले { #before-you-start }

- आपके प्रोजेक्ट में टास्क हों। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।
- आपके बोर्ड का आखिरी कॉलम आपका "पूरा हुआ" कॉलम हो। स्प्रिंट पूरा करते समय आखिरी कॉलम के टास्क पूरे माने जाते हैं।

## स्टेप { #steps }

### स्प्रिंट बनाएँ { #create-a-sprint }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें, फिर **Board** पर क्लिक करें।
2. **Backlog** व्यू पर क्लिक करें। **Backlog** सेक्शन में वे सारे टास्क दिखते हैं जो किसी स्प्रिंट में नहीं हैं।
3. **Create sprint** पर क्लिक करें। **Create sprint** डायलॉग खुलेगा।
4. **Sprint name** में कोई नाम लिखें, जैसे "Sprint 12"।
5. **Start date** और **End date** सेट करें।
6. चाहें तो **Sprint goal** में लिखें कि इस स्प्रिंट में क्या हासिल करना है।
7. **Create** पर क्लिक करें। स्प्रिंट बैकलॉग के ऊपर दिखने लगेगा।

### स्प्रिंट में टास्क जोड़ें { #add-tasks-to-a-sprint }

1. **Backlog** व्यू में किसी टास्क को **Backlog** से खींचकर स्प्रिंट में डालें।
2. इस स्प्रिंट में जितने टास्क पूरे करने हैं, उन सबके लिए यही दोहराएँ।

किसी टास्क को स्प्रिंट से निकालना हो, तो उसे वापस **Backlog** में खींचें। टास्क के अंदर जाकर भी **Sprint** फ़ील्ड सेट कर सकते हैं। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)।

### स्प्रिंट शुरू करें { #start-a-sprint }

एक प्रोजेक्ट में एक समय पर सिर्फ़ 1 चालू स्प्रिंट हो सकता है।

1. जिस स्प्रिंट को चलाना है, उस पर **Start sprint** पर क्लिक करें। **Start another sprint** डायलॉग खुलेगा।
2. **Sprint name** जाँचें।
3. **1 week** से **4 weeks** के बीच **Duration** चुनें, और **Start date** सेट करें। **End date** अवधि के हिसाब से अपने-आप तय हो जाती है।
4. चाहें तो **Sprint goal** बदलें।
5. **Start** पर क्लिक करें। स्प्रिंट पर **ACTIVE** का निशान लग जाएगा।

### स्प्रिंट पूरा करें { #complete-a-sprint }

1. चालू स्प्रिंट पर **Complete sprint** पर क्लिक करें। डायलॉग में दिखता है कि कितने वर्क आइटम पूरे हैं और कितने खुले हैं।
2. **Move open work items to** में कोई प्लान किया हुआ स्प्रिंट या **Backlog** चुनें।
3. **Complete sprint** पर क्लिक करें। खुले टास्क आपकी चुनी हुई जगह पर चले जाएँगे।

पूरे वर्क आइटम वे हैं जो बोर्ड के आखिरी कॉलम में हैं। बाकी सभी कॉलम के आइटम खुले माने जाते हैं।

### स्प्रिंट एडिट या डिलीट करें { #edit-or-delete-a-sprint }

1. स्प्रिंट पर **More actions** पर क्लिक करें।
2. उसका नाम, तारीख़ें या लक्ष्य बदलने के लिए **Edit sprint** पर क्लिक करें, फिर **Update** पर क्लिक करें।

!!! warning "स्प्रिंट डिलीट करने के बाद वापस नहीं आता"
    **Delete sprint** से स्प्रिंट हमेशा के लिए हट जाता है। अगर आप उसके टास्क का प्लान बनाए रखना चाहते हैं, तो पहले उन्हें बैकलॉग में ले जाएँ।

3. स्प्रिंट को एडिट करने की जगह डिलीट करना हो, तो **Delete sprint** पर क्लिक करें, फिर **Delete sprint?** डायलॉग में **Delete** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not start sprint.** | प्रोजेक्ट में पहले से एक स्प्रिंट चल रहा है, या सेव नहीं हो पाया। | पहले चल रहा स्प्रिंट पूरा करें, फिर अगला शुरू करें। |
| **Could not create sprint.** | कोई ज़रूरी फ़ील्ड खाली है, या सेव नहीं हो पाया। | **Sprint name**, **Start date** और **End date** भरें, फिर **Create** पर दोबारा क्लिक करें। |
| **Could not move ticket to sprint.** | स्प्रिंट पूरा हो चुका है, या टास्क का मूव सेव नहीं हुआ। | टास्क को किसी प्लान किए हुए या चालू स्प्रिंट में खींचें। |
| **Could not complete sprint.** | सेव करने की रिक्वेस्ट सर्वर तक नहीं पहुँची। | **Complete sprint** पर दोबारा क्लिक करें। |
| **Sprint completed but refresh failed.** | स्प्रिंट बंद हो गया, लेकिन व्यू रीलोड नहीं हुआ। | बोर्ड पर **Refresh** पर क्लिक करें। |
| **Your backlog is empty.** | हर टास्क पहले से किसी स्प्रिंट में है, या अभी कोई टास्क है ही नहीं। | टास्क बनाएँ, या किसी स्प्रिंट से एक टास्क बाहर खींच लें। |
