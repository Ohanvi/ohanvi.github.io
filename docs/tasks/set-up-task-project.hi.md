# टास्क प्रोजेक्ट सेट करें { #set-up-a-task-project }

पहले वह प्रोजेक्ट बनाएँ जिसमें आपके टास्क रहेंगे। फिर उसका बोर्ड खोलें और उन टीम मेंबर को जोड़ें जो उस पर काम करेंगे। इसके बाद आपकी टीम के पास एक साझा बोर्ड होगा, जिस पर आप जोड़े गए किसी भी व्यक्ति को टास्क असाइन कर सकते हैं। हर टास्क को प्रोजेक्ट की key से बनी एक key मिलेगी, जैसे OHANVI-1।

## शुरू करने से पहले { #before-you-start }

- दाईं ओर की रेल में, नोटिफ़िकेशन की घंटी के पास, **Tasks** आइकन (टिक वाला बॉक्स) दिखना चाहिए। न दिखे तो अपने एडमिन से कहें कि आपके रोल को Task का एक्सेस दें। देखें [सेटिंग्स का अवलोकन](../settings/index.md)।
- आपकी टीम के लोगों के पास पहले से Ohanvi लॉगिन हो। आप सिर्फ़ उन्हीं को जोड़ सकते हैं जो आपके वर्कस्पेस में यूज़र हैं।

## स्टेप { #steps }

### Tasks पैनल से अपना पहला प्रोजेक्ट बनाएँ { #create-your-first-project-from-the-tasks-panel }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें। पेज के बगल में **Tasks** पैनल खुलेगा।
2. अगर आपके वर्कस्पेस में अभी कोई प्रोजेक्ट नहीं है, तो पैनल में **Set up your tasks** दिखेगा। बॉक्स में प्रोजेक्ट का नाम लिखें, जैसे अपनी कंपनी का नाम।
3. **Create project** पर क्लिक करें। पैनल में आपकी टास्क लिस्ट आ जाएगी, जिसके ऊपर **Create** और **Board** होंगे।

Ohanvi नाम के अक्षरों से प्रोजेक्ट की key बनाता है। वह अक्षरों को बड़ा करता है और 6 अक्षर पर रोक देता है। जैसे "Ohanvi" से OHANVI बनता है। अगर नाम में कोई अक्षर ही न हो, तो key TASK बनती है।

### बोर्ड से दूसरा प्रोजेक्ट बनाएँ { #create-another-project-from-the-board }

1. **Tasks** पैनल में **Board** पर क्लिक करें। पूरा टास्क बोर्ड खुलेगा।
2. बाएँ पैनल में **Task** के नीचे **Create project** पर क्लिक करें। **Create ticket project** डायलॉग खुलेगा।
3. **Uniq key** में प्रोजेक्ट की छोटी key लिखें, जैसे SALES। key ज़्यादा से ज़्यादा 10 अक्षर की हो सकती है।
4. **Name** में प्रोजेक्ट का नाम लिखें, जो स्क्रीन पर दिखेगा।
5. चाहें तो **Description** में लिखें कि प्रोजेक्ट किस काम का है।
6. **Create project** पर क्लिक करें। नया प्रोजेक्ट बोर्ड पर खुल जाएगा।

प्रोजेक्ट बदलने के लिए बाएँ पैनल में **Task** के नीचे किसी प्रोजेक्ट के नाम पर क्लिक करें। हर प्रोजेक्ट की पंक्ति में उसका नाम और key दिखती है।

### अपने पहले कॉलम जोड़ें { #add-your-first-columns }

नए प्रोजेक्ट के बोर्ड पर शुरू में कोई कॉलम नहीं होता। कॉलम यानी वे स्टेटस जिनसे टास्क गुज़रता है, जैसे To Do, In Progress और Done।

1. बोर्ड के दाएँ सिरे पर **+** बटन (टूलटिप **Add column**) पर क्लिक करें।
2. **Column name** में कॉलम का नाम लिखें, फिर **Save** (टिक) पर क्लिक करें।
3. जितने स्टेटस चाहिए, उतनी बार यही दोहराएँ। कॉलम बाएँ से दाएँ उसी क्रम में दिखते हैं जिस क्रम में आप उन्हें जोड़ते हैं।

कॉलम का नाम बदलना, क्रम बदलना या कॉलम हटाना बाद में सीखने के लिए देखें [बोर्ड पर टास्क इधर-उधर करें](move-tasks-on-board.md)।

### प्रोजेक्ट में मेंबर जोड़ें { #add-members-to-the-project }

असाइनी की लिस्ट में सिर्फ़ प्रोजेक्ट के मेंबर दिखते हैं। इसलिए उन सबको जोड़ें जिन्हें टास्क मिलेंगे।

1. बोर्ड के टूलबार में **Add members** पर क्लिक करें। **Add people** डायलॉग खुलेगा।
2. **Available people** के नीचे **Search by name…** में नाम टाइप करें और जिन्हें जोड़ना है उन पर टिक करें।
3. **Selected Members & Roles** के नीचे हर व्यक्ति का रोल चुनें: **Admin**, **Member** या **Viewer**। नए लोग **Member** रोल से शुरू होते हैं।
4. **Add** पर क्लिक करें। **Members added successfully.** मैसेज दिखेगा।

किसी को हटाना हो, तो **Add members** दोबारा खोलें। **Selected Members & Roles** के नीचे उनके नाम के पास लाल बिन आइकन पर क्लिक करें। **Member removed successfully.** मैसेज दिखेगा।

### प्रोजेक्ट एडिट करें { #edit-the-project }

1. बोर्ड पर **Edit project** पर क्लिक करें। **Edit ticket project** डायलॉग खुलेगा।
2. **Name** या **Description** बदलें। **Project key** बनने के बाद बदली नहीं जा सकती।
3. **Update project** पर क्लिक करें।

### प्रोजेक्ट डिलीट करें { #delete-the-project }

!!! warning "प्रोजेक्ट डिलीट करने के बाद वापस नहीं आता"
    **Delete project** से प्रोजेक्ट बोर्ड से हमेशा के लिए हट जाता है। डिलीट करने से पहले अपनी टीम से पूछ लें।

1. बोर्ड पर **Edit project** पर क्लिक करें।
2. **Delete project** पर क्लिक करें। **Delete ticket project?** डायलॉग खुलेगा।
3. **Delete** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |

| दाईं ओर की रेल में **Tasks** आइकन नहीं है | आपके रोल को Task मॉड्यूल का एक्सेस नहीं मिला है। | अपने एडमिन से कहें कि आपके रोल को Task का एक्सेस दें। |
| **Enter a project name.** | आपने नाम खाली छोड़कर **Create project** पर क्लिक किया। | नाम लिखें, फिर **Create project** पर दोबारा क्लिक करें। |
| पैनल में **Could not create the project. Please try again.** | इस नाम से बनी key कोई और प्रोजेक्ट पहले से इस्तेमाल कर रहा है, या नेटवर्क चला गया। | कोई दूसरा नाम आज़माएँ, या बोर्ड से अपनी **Uniq key** डालकर प्रोजेक्ट बनाएँ। |
| बोर्ड डायलॉग में **Could not create ticket project.** | **Uniq key** पहले से इस्तेमाल में है, या 10 अक्षर से लंबी है। | ऐसी छोटी key डालें जो किसी और प्रोजेक्ट में इस्तेमाल न हो। |
| **Add people** में **No people found** | वह व्यक्ति आपके वर्कस्पेस में यूज़र नहीं है, या सर्च में नाम मेल नहीं खा रहा। | स्पेलिंग जाँचें, या अपने एडमिन से कहें कि पहले उस व्यक्ति को यूज़र बनाएँ। |
| **Failed to add members.** | सेव करने की रिक्वेस्ट सर्वर तक नहीं पहुँची। | **Add** पर दोबारा क्लिक करें। फिर भी फ़ेल हो तो पेज रीफ़्रेश करके दोबारा कोशिश करें। |
