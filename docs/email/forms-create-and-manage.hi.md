# फ़ॉर्म बनाएँ और संभालें { #create-and-manage-forms }

फ़ॉर्म से आप ग्राहकों के जवाब इकट्ठा करते हैं, चाहे चैट में, वेब पर या शेयर किए गए लिंक से। इस गाइड के अंत में आपके पास ऐसा फ़ॉर्म होगा जिसे आप ढूँढ सकते हैं, पब्लिश कर सकते हैं और सही से संभाल सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Forms** दिखता हो। अगर नहीं दिखता, तो अपने एडमिन से पूछें।

## स्टेप { #steps }

### अपने फ़ॉर्म खोलें { #open-your-forms }

1. लेफ़्ट रेल में **Forms** खोलें, फिर **Forms** चुनें।
2. टाइटल के नीचे की लाइन पढ़ें: **Whatever your customers fill in — chat, web, or a shared link.**
3. **All**, **Draft**, **Active** या **Archived** पर क्लिक करें। हर एक के साथ उसकी गिनती दिखती है।
4. फ़ॉर्म कहाँ से आया, यह छाँटने के लिए **Any source** पिकर इस्तेमाल करें। नाम खोजने के लिए सर्च बॉक्स इस्तेमाल करें।

### नया फ़ॉर्म शुरू करें { #start-a-new-form }

1. **New form** पर क्लिक करें। **Start a new form** खुलेगा।
2. अपने बिज़नेस के हिसाब से कोई टेम्प्लेट चिप चुनें, या **Start blank** पर क्लिक करें।
3. फ़ॉर्म बिल्डर खुलेगा। इसके लिए [फ़ॉर्म बनाएँ](forms-build-a-form.md) देखें।

### फ़ॉर्म की लाइन पढ़ें { #read-a-form-row }

1. **From <source>** बैज बताता है कि फ़ॉर्म कहाँ से आया।
2. **Live in chat** का मतलब है कि कोई चैटबॉट उसे इस्तेमाल कर रहा है।
3. **Public link** का मतलब है कि लिंक वाला कोई भी उसे खोल सकता है।
4. उसे बिल्डर में खोलने के लिए लाइन पर क्लिक करें।

### लाइन का मेन्यू इस्तेमाल करें { #use-the-row-menu }

1. लाइन में **⋮** मेन्यू खोलें।
2. जवाब पढ़ने के लिए **Responses** चुनें। इसके लिए [फ़ॉर्म के जवाब पढ़ें](forms-read-responses.md) देखें।
3. **Share link and QR** चुनें। इसके लिए [फ़ॉर्म का प्रीव्यू देखें और शेयर करें](forms-share-and-preview.md) देखें।
4. **Publish to WhatsApp** चुनें। बदलाव करने के बाद **Republish to WhatsApp** चुनें।
5. **Duplicate** चुनें। इसमें **Duplicated as a draft** लिखकर आएगा।
6. **Pause** चुनें। इसमें **Paused — the link no longer opens** लिखकर आएगा।
7. फ़ॉर्म को डिलीट किए बिना छिपाने के लिए **Archive** चुनें।
8. **Delete** चुनें। **Delete <name>?** में हाँ करके पक्का करें। जो सबमिशन पहले आ चुके हैं, वे बने रहेंगे।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No forms yet** | आपने अभी कोई फ़ॉर्म नहीं बनाया। | **New form** पर क्लिक करें। |
| **No forms match** | कोई फ़िल्टर या सर्च फ़ॉर्म को छिपा रहा है। | **Clear filters** पर क्लिक करें। |
| पब्लिक लिंक नहीं खुलता। | फ़ॉर्म पॉज़ है या अभी ड्राफ़्ट है। | स्टेटस **Active** करें। |
