# फ़ॉर्म का प्रीव्यू देखें और शेयर करें { #preview-and-share-a-form }

प्रीव्यू में आपको वही दिखता है जो ग्राहक देखेगा। शेयर करने से फ़ॉर्म लोगों तक पहुँचता है। इस गाइड के अंत में लोग आपका फ़ॉर्म खोल सकेंगे और सबमिट कर सकेंगे।

## शुरू करने से पहले { #before-you-start }

- आपके फ़ॉर्म में कम से कम 1 सवाल हो। इसके लिए [फ़ॉर्म बनाएँ](forms-build-a-form.md) देखें।

## स्टेप { #steps }

### प्रीव्यू { #preview }

1. फ़ॉर्म खोलें और **Preview** पर क्लिक करें।
2. फ़ॉर्म भरें। पेज पर लिखा होता है **Preview only — submitting here records nothing**।
3. फिर से शुरू करने के लिए **Preview again** पर क्लिक करें। ज़रूरी सवालों पर **\* Indicates required question** का निशान होता है।

### लिंक या QR से शेयर करें { #share-by-link-or-qr }

1. **Share link and QR** पर क्लिक करें। **Share this form** खुलेगा।
2. लिंक कॉपी करें, या **Download QR** पर क्लिक करें।
3. जब तक फ़ॉर्म **Active** है, इस लिंक वाला कोई भी व्यक्ति उसे खोलकर सबमिट कर सकता है।
4. जल्दी कॉपी करने के लिए टॉप बार में **Copy link** पर क्लिक करें।

### एम्बेड करें या चैट में इस्तेमाल करें { #embed-or-use-in-chat }

1. **More** मेन्यू खोलें।
2. **Embed HTML** पर क्लिक करें। **Embed snippet copied** दिखेगा। इसे अपने पेज में पेस्ट करें।
3. चैटबॉट Flow के अंदर यह फ़ॉर्म पूछने के लिए **Use in your flow** पर क्लिक करें।
4. **Publish to WhatsApp** पर क्लिक करें। एडिट करने के बाद **Republish to WhatsApp** पर क्लिक करें।

### फ़ॉर्म को रोकें या बंद करें { #pause-or-retire-a-form }

1. **More** में, लिंक का खुलना रोकने के लिए **Pause** पर क्लिक करें।
2. फ़ॉर्म छिपाने के लिए **Archive** पर क्लिक करें। हटाने के लिए **Delete** पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| लिंक कहता है कि फ़ॉर्म बंद है। | फ़ॉर्म रोका हुआ है या ड्राफ़्ट है। | **Status** को **Active** करें। |
| प्रीव्यू के जवाब Responses में नहीं हैं। | प्रीव्यू कुछ भी रिकॉर्ड नहीं करता। | टेस्ट के लिए असली लिंक से सबमिट करें। |
