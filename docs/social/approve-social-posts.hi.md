# पब्लिश होने से पहले पोस्ट की समीक्षा करें { #review-posts-before-they-publish }

ड्राफ़्ट को लाइव होने से पहले समीक्षा के लिए अपने किसी साथी को भेजें। समीक्षक उसे मंज़ूर करता है या बदलाव माँगता है। मंज़ूर होने के बाद आप उसे शेड्यूल या पब्लिश कर सकते हैं। समीक्षा वैकल्पिक है: जिस ड्राफ़्ट को आप कभी सबमिट नहीं करते, उसे सीधे पब्लिश किया जा सकता है।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखता है, जिसके पैनल में **Publish** है।
- पोस्ट ड्राफ़्ट के रूप में सेव है। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।
- पोस्ट मंज़ूर करने के लिए आपके रोल को सोशल पोस्ट की मंज़ूरी का एक्सेस मिला हो। अगर **Approve** पर एरर आए, तो अपने एडमिन से कहें। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।

## चरण { #steps }

### ड्राफ़्ट को समीक्षा के लिए भेजें { #submit-a-draft-for-review }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. **Drafts** टैब पर क्लिक करें।
3. पोस्ट पर **Submit** पर क्लिक करें। **Post submitted for approval.** संदेश दिखता है।

पोस्ट **Approvals** टैब में स्टेटस **Pending approval** के साथ चली जाती है। आपके वर्कस्पेस के एडमिन को **Approval requested** नोटिफ़िकेशन मिलता है।

### पोस्ट मंज़ूर करें { #approve-a-post }

1. **Social** → **Publish** खोलें, फिर **Approvals** टैब पर क्लिक करें।
2. पोस्ट पढ़ें। कार्ड पर **Submitted by** और भेजने वाले का नाम दिखता है।
3. **Approve** पर क्लिक करें। **Post approved — it can now be scheduled.** संदेश दिखता है।

पोस्ट बनाने वाले को **Post approved** नोटिफ़िकेशन मिलता है और अब वह पोस्ट को शेड्यूल या पब्लिश कर सकता है।

### बदलाव माँगें { #request-changes }

1. **Approvals** टैब में पोस्ट पर **Request Changes** पर क्लिक करें। **Request changes?** विंडो खुलती है।
2. **What needs changing?** में अपना फ़ीडबैक लिखें। यह वैकल्पिक है।
3. **Request Changes** पर क्लिक करें। **Changes requested — the post went back to the creator.** संदेश दिखता है।

### बदलाव के बाद दोबारा भेजें { #resubmit-after-changes }

1. **Drafts** टैब में **Changes requested** वाली पोस्ट खोजें। समीक्षक का नोट उसके नीचे दिखता है।
2. **Edit** आइकन पर क्लिक करें, बदलाव करें और **Save Changes** पर क्लिक करें।
3. **Resubmit** पर क्लिक करें।

!!! note "ध्यान दें"
    अगर आप पोस्ट मंज़ूर होने के बाद उसे एडिट करते हैं, तो वह वापस **Pending approval** में चली जाती है। पब्लिश करने से पहले उसकी नई समीक्षा ज़रूरी है।

## मंज़ूरी के स्टेटस { #approval-statuses }

| स्टेटस | मतलब |
| --- | --- |
| **Pending approval** | समीक्षक का इंतज़ार है। इसे अभी शेड्यूल या पब्लिश नहीं किया जा सकता। |
| **Approved** | समीक्षक ने मंज़ूरी दे दी। आप इसे शेड्यूल या पब्लिश कर सकते हैं। |
| **Changes requested** | समीक्षक ने इसे वापस भेज दिया। इसे एडिट करें और **Resubmit** पर क्लिक करें। |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **You cannot approve your own post** | पोस्ट बनाने वाला अपनी ही पोस्ट मंज़ूर नहीं कर सकता। | किसी दूसरे साथी से मंज़ूर करवाएँ। |
| **Post is awaiting approval and cannot be published until approved** | पोस्ट की समीक्षा अभी बाकी है। | मंज़ूरी का इंतज़ार करें, या किसी समीक्षक से कहें। |
| **Changes were requested; edit and resubmit for approval before publishing** | समीक्षक ने बदलाव माँगे हैं। | पोस्ट एडिट करें, फिर **Resubmit** पर क्लिक करें। |
| **Only draft posts can be submitted for approval; current status is …** | पोस्ट पहले ही शेड्यूल या भेजी जा चुकी है। | सिर्फ़ ड्राफ़्ट समीक्षा के लिए जा सकते हैं। |
