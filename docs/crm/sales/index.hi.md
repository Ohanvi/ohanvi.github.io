# CRM { #crm }

**CRM** में आप अपने कॉन्टैक्ट से जुड़ी कंपनियाँ, डील्स और सेल्स का काम ट्रैक करते हैं। यह बताता है कि आज क्या करना है और महीना कैसा चल रहा है। पाइपलाइन सेट करने, डील्स पर काम करने और अपने आँकड़े पढ़ने के लिए ये गाइड देखें।

**कहाँ मिलेगा:** लेफ़्ट रेल में **CRM** खोलें।

## गाइड { #guides }

| टैब | गाइड | कब देखें |
| --- | --- | --- |
| **Dashboard** | [CRM डैशबोर्ड पढ़ें](../track-sales-performance.md) | आप अपनी खुली पाइपलाइन, जीती हुई डील्स और ठंडी पड़ती डील्स देखना चाहते हैं। |
| **Deals** | [डील्स बनाएँ और मैनेज करें](../manage-deals.md) | आप डील जोड़ना, उसे स्टेज में आगे बढ़ाना और बंद करना चाहते हैं। |
| **Accounts** | [अकाउंट्स जोड़ें और मैनेज करें](../manage-accounts.md) | आप उन कंपनियों को ट्रैक करना चाहते हैं जिन्हें आप बेचते हैं। |
| Activities, Calendar, Notes | [एक्टिविटी और नोट्स दर्ज करें](../log-activities-and-notes.md) | आप कॉल और मीटिंग प्लान करना या नोट्स लिखना चाहते हैं। |
| **Campaigns** | [कैंपेन और कैंपेन Template ट्रैक करें](../track-campaigns.md) | आप कोई कैंपेन और उसके नतीजे दर्ज करना चाहते हैं। |
| **Automations** | [CRM ऑटोमेशन मैनेज करें](../manage-automations.md) | आप नियम रोकना, दोबारा चालू करना या नए नियम बनाना चाहते हैं। |
| **Funnel** | [फ़नल पढ़ें और बोर्ड पर लीड्स आगे बढ़ाएँ](../read-the-funnel.md) | आप देखना चाहते हैं कि लीड्स कहाँ छूट रही हैं। |
| **Forecast** | [सेल्स फ़ोरकास्ट पढ़ें](../read-the-forecast.md) | आप पाइपलाइन को अपने टारगेट से मिलाना चाहते हैं। |
| Sales reports | [सेल्स रिपोर्ट निकालें](../run-sales-reports.md) | आपको Excel या PDF फ़ाइल में रिपोर्ट चाहिए। |
| Pipelines, Products, Lead Sources, Sales Quotas | [CRM कॉन्फ़िगर करें](../configure/index.md) | आप वे चीज़ें सेट करना चाहते हैं जिनसे आपका CRM नापा जाता है। |

कुछ स्क्रीन पैनल में नहीं दिखतीं: **Deal Board**, **Campaign Templates**, **Activities**, **Activity Calendar**, **Notes**, **Sales reports**, **Pipelines**, **Products**, **Sales Quotas** और **Lead Sources**। इन्हें कैसे खोलना है, यह हर गाइड में लिखा है।

## कॉन्फ़िगर करें { #configure }

सेटअप की स्क्रीन **Settings** → **CRM** में हैं। ये सिर्फ़ एडमिन के लिए हैं। देखें [CRM कॉन्फ़िगर करें](../configure/index.md)।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में CRM मॉड्यूल होना चाहिए, और आपके रोल को CRM का एक्सेस मिला होना चाहिए। नहीं तो **CRM** आइकन नहीं दिखता। अपने एडमिन से पूछें।
- **Dashboard**, **Funnel**, **Forecast** और **Sales reports** के लिए CRM रिपोर्ट का एक्सेस चाहिए। **Automations** के लिए ऑटोमेशन का एक्सेस चाहिए।
