# सेल्स रिपोर्ट चलाएँ { #run-the-sales-reports }

अपने फ़नल, पाइपलाइन, जीत और हार, लीड के स्रोत, गतिविधि, कैंपेन के रिटर्न या कोटा की प्रगति पर रिपोर्ट चलाएँ। अंत में आपके पास एक फ़ाइल होगी जिसे आप शेयर कर सकते हैं। एक रिपोर्ट में लगभग 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपके पास CRM रिपोर्ट का एक्सेस है। अगर नहीं, तो अपने एडमिन से कहें।
- **Sales reports** **CRM** पैनल में नहीं दिखता। इसे आप सर्च बॉक्स से खोलते हैं।

## चरण { #steps }

### Sales reports खोलें { #open-sales-reports }

1. **Ctrl K** दबाएँ (Mac पर **⌘K**), या ऊपर सर्च बॉक्स पर क्लिक करें।
2. **Sales reports** टाइप करें।
3. **Sales reports** चुनें। स्क्रीन खुल जाती है।

### रिपोर्ट चुनें { #pick-a-report }

1. 7 रिपोर्ट में से किसी एक पर क्लिक करें:
    - **Sales Funnel**
    - **Pipeline Value**
    - **Win / Loss**
    - **Lead Sources**
    - **Activity Productivity**
    - **Campaign ROI**
    - **Forecast vs Quota**
2. रिपोर्ट लोड होने का इंतज़ार करें।

### अवधि चुनें { #choose-the-period }

1. तारीख की सीमा वाले बटन पर क्लिक करें।
2. मनचाही अवधि चुनें। रिपोर्ट दोबारा लोड होती है।

अगर रिपोर्ट **Nothing in this period** दिखाए, तो तारीख की सीमा बढ़ाएँ।

### रिपोर्ट डाउनलोड करें { #download-the-report }

1. स्प्रेडशीट के लिए **Export Excel** पर क्लिक करें।
2. या प्रिंट करने या भेजने लायक दस्तावेज़ के लिए **Export PDF** पर क्लिक करें।

### कॉमर्स स्ट्रिप देखें { #check-the-commerce-strip }

1. **Sales reports** के ऊपर **Commerce Leads** स्ट्रिप ढूँढें।
2. छोड़ी गई कार्ट खोलने के लिए उस पर क्लिक करें। देखें [Commerce लीड्स से छोड़ी गई कार्ट वापस पाएँ](recover-abandoned-carts.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| सर्च में **Sales reports** नहीं दिखता | आपके रोल के पास CRM रिपोर्ट का एक्सेस नहीं है। | अपने एडमिन से कहें। |
| **Nothing in this period** | तारीख की सीमा में कोई डेटा नहीं है। | तारीख की सीमा बढ़ाएँ। |
| **Forecast vs Quota** पूरी टीम को दिखाता है | रिपोर्ट अभी ओनर के हिसाब से फ़िल्टर नहीं कर सकती। | **Dashboard** पर **Won by owner** से मिलान करें। |
