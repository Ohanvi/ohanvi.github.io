# चैटबॉट में टेक्स्ट और लिस्ट मैसेज भेजें { #send-text-and-list-messages-in-a-chatbot }

**Text** और **List / Buttons** सबसे ज़्यादा काम आने वाले दो ब्लॉक हैं। **Text** सादा मैसेज भेजता है, जिसमें 3 तक रिप्लाई बटन लग सकते हैं। **List / Buttons** ऐसा मैसेज भेजता है जिसमें 10 तक विकल्पों वाला मेन्यू होता है। मैसेज लिखने, विकल्प जोड़ने और उन्हें अगले स्टेप से जोड़ने के लिए यह पेज देखें।

## शुरू करने से पहले { #before-you-start }

- आपने बिल्डर में कोई फ़्लो खोला हो। देखें [फ़्लो बिल्डर को समझें](understand-the-flow-builder.md)।
- आपको पता हो कि फ़्लो कहाँ से शुरू होता है। देखें [चुनें कि फ़्लो कैसे शुरू हो](chatbot-flow-start-and-triggers.md)।

## कौन सा ब्लॉक इस्तेमाल करें { #which-block-to-use }

| ब्लॉक | ग्राहक को क्या दिखता है | विकल्प | कब इस्तेमाल करें |
| --- | --- | --- | --- |
| **Text** | सादा मैसेज। चाहें तो उसके नीचे बटन भी। | 3 तक रिप्लाई बटन। | नमस्ते, जवाब, छोटे मेन्यू। |
| **List / Buttons** | ऐसा मैसेज जिसमें एक बटन दबाने पर मेन्यू खुलता है। | 10 तक लिस्ट पंक्तियाँ। | लंबे मेन्यू, जैसे विभाग या प्रोडक्ट। |

ये दोनों ब्लॉक **Step** पैनल के **Message types** ग्रुप में मिलते हैं।

## स्टेप { #steps }

### टेक्स्ट मैसेज भेजें { #send-a-text-message }

1. जिस स्टेप के बाद मैसेज भेजना है, उसके आगे **+** पर क्लिक करें। **Add a step after** मेन्यू खुलेगा।
2. **All steps** पर क्लिक करें।
3. **Message types** में **Text** पर क्लिक करें। एक कार्ड आएगा, जिसमें **Message** ब्लॉक होगा।
4. ब्लॉक पर क्लिक करें। उसकी सेटिंग्स **Step** पैनल में खुलेंगी।
5. जिस बॉक्स में **Type message...** लिखा है, उस पर क्लिक करें और मैसेज लिखें, जैसे `Hi! How can I help you today?`। इसमें 1,024 अक्षर तक लिख सकते हैं।
6. सेव किया हुआ जवाब दिखाना हो, तो बॉक्स के नीचे किसी चिप पर क्लिक करें, जैसे **{Name}**। इससे `{{name}}` अपने आप लग जाता है।

!!! tip "डबल कर्ली ब्रैकेट और छोटे अक्षर ही लिखें"
    वेरिएबल ख़ुद लिख रहे हैं, तो `{{name}}` लिखें। अगर बड़ा अक्षर लिखा, जैसे `{{Name}}`, तो ग्राहक को वही सादे टेक्स्ट की तरह दिखेगा।

### टेक्स्ट मैसेज में रिप्लाई बटन जोड़ें { #add-reply-buttons-to-a-text-message }

1. मैसेज ब्लॉक के नीचे **+ Add Button** पर क्लिक करें। **New button** नाम का एक बटन आएगा।
2. बटन पर क्लिक करें और उसका लेबल लिखें, जैसे `Fees`।
3. हर बटन के लिए यही दोहराएँ। एक टेक्स्ट मैसेज में 3 तक बटन लग सकते हैं।
4. किसी बटन पर अलग जवाब भेजना हो, तो उस बटन के दाईं ओर बने **+** पर क्लिक करें और अगला स्टेप चुनें।

बटन की सीमाएँ:

- एक मैसेज पर 3 तक बटन।
- बटन के लेबल में 20 अक्षर तक लिख सकते हैं। इससे लंबा लेबल कट जाता है।
- जिस बटन को आप किसी स्टेप से नहीं जोड़ते, वह उसी कार्ड के अगले ब्लॉक पर चला जाता है।

### टेक्स्ट मैसेज में डिले या टाइमआउट सेट करें { #set-a-delay-or-a-timeout-on-a-text-message }

1. ब्लॉक के नीचे ग्रे रंग का टाइमिंग वाला हिस्सा ढूँढें।
2. **Set Delay** चालू करें और **Type delay in seconds...** में सेकंड लिखें, जैसे `3`। मैसेज उतनी देर रुककर जाएगा।
3. **Set Timeout** चालू करें और **Timeout after (minutes)** में मिनट लिखें, जैसे `30`। कार्ड पर **Timed out** एग्ज़िट आ जाएगा।
4. **Timed out** को किसी फ़ॉलो-अप स्टेप से जोड़ें, जैसे रिमाइंडर।

### लिस्ट मैसेज भेजें { #send-a-list-message }

1. जिस स्टेप के बाद मेन्यू भेजना है, उसके आगे **+** पर क्लिक करें, फिर **All steps** पर क्लिक करें।
2. **Message types** में **List / Buttons** पर क्लिक करें। **List** ब्लॉक आ जाएगा।
3. **Header** में छोटा टाइटल लिखें, जैसे `Our services`। इसमें 20 अक्षर तक लिख सकते हैं। यह बॉक्स भरना ज़रूरी नहीं है।
4. **Body** में मैसेज लिखें, जैसे `Choose a service`। इसमें 4,096 अक्षर तक लिख सकते हैं।
5. **Footer** में एक छोटी लाइन लिखें, जैसे `Reply any time`। इसमें 60 अक्षर तक लिख सकते हैं। यह बॉक्स भरना ज़रूरी नहीं है।
6. **Button label** में उस बटन के शब्द लिखें जिससे मेन्यू खुलता है, जैसे `View services`। इसमें 20 अक्षर तक लिख सकते हैं।

### लिस्ट की पंक्तियाँ जोड़ें { #add-the-list-rows }

1. पहली पंक्ति में **Item one** हटाकर विकल्प का नाम लिखें, जैसे `Haircut`। इसमें 24 अक्षर तक लिख सकते हैं।
2. **Describe it** में नाम के नीचे की एक लाइन लिखें, जैसे `30 minutes`। इसमें 72 अक्षर तक लिख सकते हैं।
3. एक और पंक्ति जोड़ने के लिए **+ Add Section** पर क्लिक करें। लिस्ट में बटन पर **+ Add Section** ही लिखा होता है, लेकिन वह **New item** नाम की पंक्ति जोड़ता है।
4. हर विकल्प के लिए यही दोहराएँ। एक लिस्ट में 10 पंक्तियाँ तक हो सकती हैं।
5. कोई पंक्ति हटानी हो, तो उसके नाम के पास बने छोटे **x** पर क्लिक करें।
6. नई पंक्ति का नाम **New item** और लाइन **Describe it** होती है। **Multi product** ब्लॉक में पहली पंक्ति **Section one** होती है और नई पंक्ति **New section**। **Buttons** ब्लॉक में नया विकल्प **New button** होता है। हर डिफ़ॉल्ट नाम बदल दें।

### हर विकल्प को अगले स्टेप से जोड़ें { #wire-each-choice }

1. किसी पंक्ति या बटन के दाईं ओर बने **+** पर क्लिक करें।
2. वह स्टेप चुनें जो ग्राहक के उस विकल्प पर टैप करने पर चलेगा, जैसे कीमतों की लिस्ट वाला **Text**।
3. हर विकल्प के लिए यही दोहराएँ।

बाद में किसी जवाब के हिसाब से आगे बढ़ना हो, तो **Condition** ब्लॉक इस्तेमाल करें। देखें [नाम, फ़ोन, ईमेल और पता पूछें](chatbot-ask-details-blocks.md)।

### लिस्ट में टाइमआउट सेट करें { #set-a-timeout-on-a-list }

1. लिस्ट के नीचे टाइमिंग वाले हिस्से में **Set Timeout** चालू करें।
2. **Timeout after (minutes)** में मिनट लिखें।
3. **Timed out** एग्ज़िट को रिमाइंडर स्टेप से जोड़ें।

लिस्ट में **Set Delay** नहीं होता। सवाल को देर से नहीं भेजा जाता।

### मैसेज जाँचें { #check-the-message }

1. **Save** पर क्लिक करें।
2. **Test** पर क्लिक करें। मैसेज पढ़ें और हर विकल्प पर टैप करके देखें। देखें [चैट सिम्युलेटर से चैटबॉट फ़्लो टेस्ट करें](test-a-flow-with-the-chat-simulator.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **+ Add Button** नहीं दिख रहा | ब्लॉक में पहले से 3 बटन हैं, या यह लिस्ट है। | कोई बटन हटाएँ, या **List / Buttons** ब्लॉक इस्तेमाल करें। |
| **Body** में और टेक्स्ट नहीं लिखा जा रहा | **Text** में 1,024 अक्षर पूरे हो गए, या लिस्ट में 4,096। | मैसेज छोटा करें। |
| किसी पंक्ति में और टेक्स्ट नहीं लिखा जा रहा | पंक्ति के नाम में 24 अक्षर लिखे जा सकते हैं और डिस्क्रिप्शन में 72। | टेक्स्ट छोटा करें। |
| ग्राहक को `{{Name}}` दिख रहा है | वेरिएबल में बड़ा अक्षर है। | `{{name}}` लिखें, या बॉक्स के नीचे वाली चिप इस्तेमाल करें। |
| टैप करने पर विकल्प कुछ नहीं करता | विकल्प किसी स्टेप से जुड़ा नहीं है। | विकल्प के **+** पर क्लिक करें और एक स्टेप जोड़ें। |
