# फ़्लो के वर्शन देखें { #review-a-flows-versions }

फ़्लो की हिस्ट्री उसके पैनल में देखें। इससे आपको पता चलेगा कि अभी कौन सा वर्शन चल रहा है, आप कौन सा ड्राफ़्ट एडिट कर रहे हैं, और हर वर्शन कब और किसने पब्लिश किया।

## शुरू करने से पहले { #before-you-start }

- फ़्लो कम से कम एक बार सेव हो चुका हो।
- **WhatsApp** पैनल में आपको **Flows** दिखता हो। बिल्डर में पुराना वर्शन खोलना हो, तो आपके रोल के पास फ़्लो सेव करने का एक्सेस भी होना चाहिए।

## वर्शन कैसे काम करते हैं { #how-versions-work }

- पब्लिश हो चुका वर्शन कभी नहीं बदलता। पब्लिश किए हुए फ़्लो को एडिट करेंगे, तो नया ड्राफ़्ट बनता है।
- जो रन पहले से चल रहे हैं, वे उसी वर्शन पर चलते रहते हैं जिससे शुरू हुए थे। नए रन लाइव वर्शन से चलते हैं।
- फ़्लो की दो तरह की हिस्ट्री हो सकती है। **THIS FLOW** में फ़्लो के अपने वर्शन होते हैं। **CONVERSATION:** के बाद नाम लिखा हो, तो उसमें उस चैटबॉट कन्वर्सेशन के वर्शन होते हैं जिसे फ़्लो इस्तेमाल करता है।

## स्टेप { #steps }

### Versions टैब खोलें { #open-the-versions-tab }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।
2. फ़्लो की लाइन पर क्लिक करें। लिस्ट के बगल में पैनल खुलता है।
3. **Versions** टैब पर क्लिक करें। पहली बार लिस्ट आने तक लोडर घूमता दिखता है।
4. ऊपर का नोट पढ़ें: **A published version never changes — editing one starts a draft, and runs already going stay on the version they started with.**

### वर्शन की लाइन पढ़ें { #read-a-version-row }

हर लाइन में एक वर्शन दिखता है।

1. वर्शन नंबर पढ़ें, जैसे **v3**।
2. उसके बगल का चिप पढ़ें।
    - **Running now** ऑटोमेशन का लाइव वर्शन है।
    - **Live** चैटबॉट कन्वर्सेशन का लाइव वर्शन है।
    - **Published** वह वर्शन है जो पहले लाइव था और अब बदल चुका है।
    - **Being edited** वह ड्राफ़्ट है जिस पर आप काम कर रहे हैं।
    - **Draft** वह ड्राफ़्ट है जिसे अभी एडिट नहीं किया जा रहा।
3. उसके नीचे की लाइन पढ़ें। इसमें स्टेप की गिनती दिखती है, जैसे **3 steps**। फिर **Published** के साथ समय और पब्लिश करने वाले का नाम आता है, या **Not published** लिखा होता है। बदलाव का नोट सेव हुआ हो, तो वह आखिर में दिखता है।

फ़्लो का कोई वर्शन न हो, तो टैब में **No versions yet.** लिखा आता है।

### पुराना वर्शन खोलें { #open-an-older-version }

1. जो लाइन लाइव नहीं है, उस पर **Open** पर क्लिक करें। बिल्डर खुल जाता है।
2. पुराने वर्शन को लाइव करना हो, या उससे नया ड्राफ़्ट शुरू करना हो, तो बिल्डर में **Versions** बटन का इस्तेमाल करें। देखें [फ़्लो बिल्डर को समझें](../whatsapp/understand-the-flow-builder.md)।

**Open** बटन तीन जगह नहीं दिखता। लाइव वर्शन पर, चैटबॉट कन्वर्सेशन के वर्शन पर, और तब जब आपका रोल फ़्लो नहीं बदल सकता।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No versions yet.** | फ़्लो कभी सेव नहीं हुआ। | बिल्डर खोलें, एक स्टेप जोड़ें और **Save** पर क्लिक करें। |
| लाइन में **Open** बटन नहीं है | वर्शन लाइव है, वह कन्वर्सेशन का वर्शन है, या आपका रोल फ़्लो नहीं बदल सकता। | अपने एडमिन से फ़्लो सेव करने का एक्सेस माँगें। |
| वर्शन की दो लिस्ट दिख रही हैं | फ़्लो के अपने वर्शन हैं और चैटबॉट कन्वर्सेशन के अपने। दोनों की गिनती अलग चलती है। | हर लिस्ट को उसके हेडिंग के नीचे पढ़ें। |
| ड्राफ़्ट **Being edited** की जगह **Draft** दिखता है | यह वह ड्राफ़्ट नहीं है जो फ़्लो अभी इस्तेमाल कर रहा है। | बिल्डर खोलें और देखें कि कौन सा ड्राफ़्ट खुला है। |
