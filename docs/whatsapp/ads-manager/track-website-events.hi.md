# वेबसाइट इवेंट ट्रैक करें { #track-website-events }

**Ads Manager** में एक डेटासेट बनाएँ, उसकी इवेंट स्क्रिप्ट अपनी वेबसाइट पर कॉपी करें, और जाँचें कि Meta को इवेंट मिल रहे हैं। आप ऑफ़लाइन हुई बिक्री भी अपलोड कर सकते हैं। अंत में Meta इन इवेंट की मदद से आपके विज्ञापनों के लिए खरीदार ढूँढ सकता है। इसमें करीब 10 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका Facebook अकाउंट, पेज और विज्ञापन अकाउंट **Setup** में कनेक्ट हैं। देखें [Click-to-WhatsApp विज्ञापन चलाएँ](../click-to-whatsapp-ads.md)।
- आप अपनी वेबसाइट का कोड एडिट कर सकते हैं, या आपको पता है कि कौन कर सकता है।
- ऑफ़लाइन बिक्री के लिए, आपके पास एक CSV फ़ाइल है जिसमें हर बिक्री के लिए फ़ोन नंबर या ईमेल है।

## डेटासेट क्या है { #what-a-dataset-is }

डेटासेट Meta में वह जगह है जहाँ आपकी वेबसाइट के इवेंट इकट्ठा होते हैं। इवेंट वे एक्शन हैं जैसे **PageView**, **AddToCart** और **Purchase**। Meta डेटासेट को पिक्सेल भी कहता है। आपकी वेबसाइट और व्हाट्सऐप, दोनों के इवेंट डेटासेट में जाते हैं। Meta आपके विज्ञापनों को उन्हीं के हिसाब से ऑप्टिमाइज़ करता है।

**Events** टैब में बाईं ओर डेटासेट की सूची और दाईं ओर चुना हुआ डेटासेट होता है।

| डेटासेट के बगल का बिंदु | इसका मतलब |
|----------------------|---------------|
| हरा | Meta को उससे कम से कम 1 इवेंट मिल चुका है। |
| स्लेटी | अभी तक कोई इवेंट नहीं आया है। |

## चरण { #steps }

### डेटासेट बनाएँ { #create-a-dataset }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Ads Manager** चुनें।
2. **Events** पर क्लिक करें।

    ![Events टैब, जिसमें बाईं ओर डेटासेट की सूची है और दाईं ओर चुने हुए डेटासेट के Overview, Setup और Offline sales टैब हैं](../../assets/screenshots/whatsapp-ads-events-1-datasets.png)

3. **New Dataset** पर क्लिक करें। **Create Dataset** विंडो खुलती है।

    

4. **Dataset name \*** लिखें, जैसे `Website Event Data`।
5. **Create** पर क्लिक करें। डेटासेट Meta Events Manager में आपके विज्ञापन अकाउंट पर बन जाता है। इवेंट स्क्रिप्ट बनने के बाद **Setup** के नीचे दिखती है।

!!! note "पहले Setup पूरा होना चाहिए"
    अगर Setup पूरा नहीं है, तो **New Dataset** आपको **Setup** पर ले जाता है।

### डेटासेट खोजें { #find-a-dataset }

1. **Events** पर क्लिक करें। बाईं ओर डेटासेट की सूची खुलती है।
2. सूची के ऊपर **Search by event name** में नाम या ID लिखें।
3. डेटासेट पर क्लिक करें। दाईं ओर उसके टैब खुलते हैं।
4. सूची को रीलोड करने के लिए **Refresh** पर क्लिक करें। हर डेटासेट के बगल का बिंदु अपडेट हो जाता है।

### Overview पढ़ें { #read-the-overview }

1. कोई डेटासेट चुनें, फिर **Overview** खोलें।
2. **Status** पढ़ें। यह डेटासेट का स्टेटस दिखाता है, जैसे **Active**।
3. **Dataset ID** पढ़ें। यह वह नंबर है जिससे Meta डेटासेट को पहचानता है। इसे कॉपी करने के लिए कॉपी आइकन (**Copy ID**) पर क्लिक करें।
4. **Last activity** पढ़ें। यह आखिरी इवेंट की तारीख़ दिखाता है, या जब तक कोई इवेंट नहीं आता तब तक **No events received yet**।
5. **Owned by** पढ़ें। यह उस बिज़नेस को दिखाता है जो डेटासेट का मालिक है। यह तभी दिखता है जब Meta इसे देता है।
6. **Created** पढ़ें। यह डेटासेट बनने की तारीख़ दिखाता है।

### इवेंट स्क्रिप्ट इंस्टॉल करें { #install-the-event-script }

1. डेटासेट चुनें, फिर **Setup** पर क्लिक करें।
2. **Copy the Event Script** खोलें।
3. **Event Code** बॉक्स के कॉपी बटन पर क्लिक करें। संदेश **Event script copied** दिखता है।
4. **Install on Your Website** खोलें।
5. कोड को अपनी वेबसाइट के **हर पेज** पर बंद होने वाले `</head>` टैग से ठीक पहले पेस्ट करें।

    

6. अपनी वेबसाइट पर बदलाव सेव करें और पब्लिश करें।

पैनल में दिया उदाहरण ऐसा दिखता है:

```html
<head>
  <!-- Your existing head content -->
  <!-- Paste your event code here -->
</head>
```

### इंस्टॉलेशन जाँचें { #verify-the-installation }

1. **Setup** में **Verify the Installation** खोलें।
2. अपनी वेबसाइट पर जाएँ और कोई भी पेज खोलें। इससे पहला **PageView** इवेंट जाता है।
3. Meta Events Manager में **Test Events** टूल खोलें। पक्का करें कि इवेंट एक्टिव है और डेटा आ रहा है।
4. **Events** पर वापस आएँ और **Refresh** पर क्लिक करें। Meta को पहला इवेंट मिलते ही डेटासेट के बगल का बिंदु हरा हो जाता है।

!!! tip "सुझाव"
    किसी डेटासेट को नाम या ID से खोजने के लिए सूची के ऊपर **Search by event name** का इस्तेमाल करें।

### ऑफ़लाइन बिक्री भेजें { #send-offline-sales }

जो बिक्री आपकी वेबसाइट पर नहीं हुई, उसके लिए **Offline sales** का इस्तेमाल करें। उदाहरण हैं दुकान के काउंटर की बिक्री, फ़ोन पर मिले ऑर्डर और बाद में पैसे मिलने वाला कैश ऑन डिलीवरी। Meta उन विज्ञापनों को श्रेय देता है जो इन खरीदारों को लाए।

1. डेटासेट चुनें, फिर **Offline sales** पर क्लिक करें।
2. एक CSV फ़ाइल तैयार करें। कॉलम किसी भी क्रम में हो सकते हैं। नीचे की तालिका के कॉलम इस्तेमाल करें।
3. पक्का करें कि हर पंक्ति में ईमेल या फ़ोन नंबर हो।
4. **Choose CSV** पर क्लिक करें और अपनी फ़ाइल चुनें। इसके बाद बटन पर **Choose another** लिखा आता है।
5. वह लाइन पढ़ें जो बताती है कि कितनी बिक्री भेजने के लिए तैयार है, जैसे **120 sales ready to send**। **3 rows skipped: no email or phone** जैसी लाइनें बताती हैं कि क्या छूट गया।
6. **Send to Meta** पर क्लिक करें।
7. **Sending… 40 of 120** के पूरा होने का इंतज़ार करें। संदेश **Meta received 120 sales. They show in Events Manager under this dataset within about an hour.** दिखता है।

**CSV के कॉलम**

| कॉलम | इस्तेमाल |
|--------|-----|
| `email` | खरीदार का ईमेल। |
| `phone` | खरीदार का फ़ोन नंबर। |
| `date` | बिक्री की तारीख़। `2026-10-02` या `02/10/2026` इस्तेमाल करें। |
| `value` | बिक्री की रकम। |
| `currency` | मुद्रा, जैसे INR। खाली होने पर INR माना जाता है। |
| `order_id` | ऑर्डर नंबर। |
| `first_name`, `last_name` | खरीदार का नाम। |
| `city`, `state`, `pincode`, `country` | खरीदार की जगह। |

सीमाएँ और नियम:

- हर पंक्ति में ईमेल या फ़ोन नंबर होना ज़रूरी है।
- इवेंट **Purchase** होता है, जब तक फ़ाइल में `event` कॉलम न हो।
- Meta 62 दिन तक पुरानी बिक्री स्वीकार करता है। 62 दिन से पुरानी पंक्ति कारण **date outside the last 62 days** के साथ छोड़ दी जाती है।

!!! tip "सुझाव"
    हर पंक्ति में एक `order_id` जोड़ें। तब वही फ़ाइल दोबारा भेजने पर हर बिक्री एक ही बार गिनी जाती है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
|-------|-------|-----|
| **Set up now** बटन के साथ **Connect your Meta ad account** | Setup पूरा नहीं हुआ है। | **Set up now** पर क्लिक करें और **Setup** पूरा करें। |
| **No datasets yet** | विज्ञापन अकाउंट पर कोई डेटासेट नहीं है। | **Create Dataset** पर क्लिक करें। |
| **Could not load datasets** | सूची लोड नहीं हुई। | **Retry** पर क्लिक करें। |
| **Could not create the dataset — is Facebook connected?** | Facebook डिस्कनेक्ट है, या Meta ने अनुरोध ठुकरा दिया। | **Setup** जाँचें, Facebook दोबारा कनेक्ट करें और डेटासेट फिर से बनाएँ। |
| डेटासेट के बगल का बिंदु स्लेटी बना रहता है | Meta तक कोई इवेंट नहीं पहुँचा। | जाँचें कि कोड हर पेज पर है, अपनी साइट पर जाएँ और **Refresh** पर क्लिक करें। पक्का करने के लिए Meta का **Test Events** टूल इस्तेमाल करें। |
| **Last activity** में **No events received yet** दिखता है | स्क्रिप्ट इंस्टॉल नहीं है या ब्लॉक हो रही है। | स्क्रिप्ट दोबारा इंस्टॉल करें। अगर ऐड ब्लॉकर चालू है, तो साफ़ ब्राउज़र में टेस्ट करें। बेहतर ट्रैकिंग के लिए देखें [सर्वर ट्रैकिंग सेट करें](set-up-server-tracking.md)। |
| **Upload failed.** | Meta ने बिक्री ठुकरा दी, या कनेक्शन टूट गया। | CSV के कॉलम और तारीख़ें जाँचें। **Send to Meta** पर फिर से क्लिक करें। |
| **rows skipped: no email or phone** | किसी पंक्ति में न ईमेल है न फ़ोन नंबर। | हर पंक्ति में इनमें से एक जोड़ें और फ़ाइल फिर से चुनें। |
