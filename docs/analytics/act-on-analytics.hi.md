# अपने एनालिटिक्स पर कार्रवाई करें { #act-on-your-analytics }

**Analytics** में जो दिखता है, उसे अपने अगले कदम में बदलें। इस गाइड के अंत तक आप फ़ेल हुए संपर्क साफ़ कर चुके होंगे, अपना सबसे अच्छा कैंपेन दोबारा इस्तेमाल कर चुके होंगे, अपने टेम्प्लेट या कार्ट-रिकवरी जर्नी को सुधार चुके होंगे, और अपना अगला ब्रॉडकास्ट उस घंटे में रखेंगे जब आपके ग्राहक सबसे ज़्यादा ऑर्डर करते हैं।

## शुरू करने से पहले { #before-you-start }

- आपने किसी ऐसी अवधि के लिए [मार्केटिंग एनालिटिक्स](read-marketing-analytics.md) या [स्टोर एनालिटिक्स](read-store-analytics.md) पढ़ लिया है जिसमें डेटा है।
- आपका रोल **WhatsApp** → **Campaign** और **Template** खोल सकता है।

## चरण { #steps }

### Do this next का कोई सुझाव अपनाएँ { #follow-a-do-this-next-suggestion }

**Marketing Analytics** पर **Do this next** में ज़्यादा से ज़्यादा 4 सुझाव दिखते हैं, सबसे ज़रूरी पहले। हर सुझाव तभी दिखता है जब उस अवधि के आँकड़े उसकी माँग करते हैं।

| सुझाव | कब दिखता है | बटन कहाँ खोलता है |
| --- | --- | --- |
| **Clean out … contacts that failed to deliver** | फ़ेल हुए मैसेज भेजे गए मैसेज के 2% या उससे ज़्यादा हैं। | **Review failures** — **Delivery Logs**। |
| **Segment your sends — …% read rate is low** | रीड रेट 55% से कम है। | **Pick a segment** — **Campaign**। |
| **Sharpen the offer — only …% of readers acted** | क्लिक और जवाब, खोले गए मैसेज के 8% से कम हैं। | **See templates** — **Template**। |
| **Repeat what worked — "…" read best** | कम से कम 1 कैंपेन का रीड रेट 0% से ऊपर है। | **Open campaign** — **Campaign**। |
| **Connect a store to see revenue per campaign** | कोई स्टोर कनेक्ट नहीं है। | **Connect store** — **WhatsApp** → **Manage**। |

1. लेफ़्ट रेल में **Analytics** खोलें, फिर **Marketing Analytics** चुनें।
2. **Do this next** के नीचे सुझाव और उसकी वजह पढ़ें।
3. सुझाव के बटन पर क्लिक करें। जुड़ी हुई स्क्रीन खुल जाती है।
4. वहाँ बदलाव करें, जैसे फ़ेल हुए नंबर हटाएँ या छोटी ऑडियंस चुनें।

### अपना सबसे अच्छा कैंपेन दोबारा इस्तेमाल करें { #reuse-your-best-campaign }

1. **Best campaigns** के नीचे सबसे ऊपर वाला कैंपेन देखें।
2. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।
3. उसी टेम्प्लेट और मिलते-जुलते भेजने के समय के साथ नया ब्रॉडकास्ट बनाएँ।

### कार्ट रिकवरी को बेहतर बनाएँ { #tune-cart-recovery }

1. लेफ़्ट रेल में **Analytics** खोलें, फिर **Store Analytics** चुनें।
2. **Abandoned carts** में **Recovery rate** देखें।
3. **Tune the cart-recovery journey** पर क्लिक करें। **Flows** स्क्रीन खुल जाती है।
4. कार्ट-रिकवरी जर्नी खोलें और उसके मैसेज या समय में बदलाव करें।

### टॉप ग्राहकों से संपर्क करें { #follow-up-with-top-customers }

1. **Top customers** में हरे रंग में दिख रहे किसी नाम पर क्लिक करें। **Inbox** खुल जाता है।
2. ग्राहक के नाम के नीचे दिए गए नंबर से उसे खोजें।
3. धन्यवाद का या दोबारा ऑर्डर करने का मैसेज भेजें।

### अपने अगले ब्रॉडकास्ट का समय तय करें { #time-your-next-broadcast }

1. **When orders come in** में कैप्शन में लिखा पीक घंटा देखें।
2. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।
3. अपना अगला ब्रॉडकास्ट उस घंटे से थोड़ा पहले शेड्यूल करें। ब्रॉडकास्ट फ़ॉर्म में **When** के नीचे **Schedule** चुनें।
