# CRM सेट अप करें { #configure-the-crm }

इन्हें एक बार सेट करें, फिर ज़्यादातर वैसे ही रहने दें। हर Deal, बोर्ड, फ़नल और फ़ोरकास्ट इन्हीं पर चलता है। ये स्क्रीन सिर्फ़ एडमिन के लिए हैं।

**कहाँ मिलेगा:** नीचे बाईं ओर अपने नाम के शुरुआती अक्षरों पर क्लिक करें, **Settings** चुनें, फिर **CRM**।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [Pipeline सेट करें](../set-up-pipelines.md) | जब आप वे स्टेज बनाना चाहें जिनसे होकर Deal आगे बढ़ती है। |
| [Lead के सोर्स मैनेज करें और देखें कि कौन से कन्वर्ट होते हैं](../manage-lead-sources.md) | जब आप वे चैनल जोड़ना चाहें जहाँ से आपकी Leads आती हैं। |
| [प्रोडक्ट्स जोड़ें](../add-products.md) | जब आप जो बेचते हैं उसे जोड़ना चाहें, ताकि Deal में प्रोडक्ट लाइनें लग सकें। |
| [सेल्स कोटा तय करें](../set-sales-quotas.md) | जब आप हर सेल्सपर्सन को महीने का टारगेट देना चाहें। |

## शुरू करने से पहले { #before-you-start }

- आप एडमिन हों। CRM सेटिंग्स पेज पर लिखा होता है **Configure how your CRM works — admin only**।
- आपके वर्कस्पेस में CRM मॉड्यूल हो।
