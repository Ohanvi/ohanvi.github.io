# बोर्ड का Summary पढ़ें { #read-the-board-summary }

**Summary** व्यू बताता है कि हर टास्क खोले बिना आपका प्रोजेक्ट कैसा चल रहा है। पहले पिछले 7 दिनों की चार गिनतियाँ पढ़ें। फिर स्टेटस, प्रायोरिटी, टाइप और व्यक्ति के हिसाब से चार्ट देखें। मिलते-जुलते टास्क देखने के लिए किसी कार्ड या बार पर क्लिक करें।

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल पाते हों। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- प्रोजेक्ट में कम से कम 1 टास्क हो। खाली प्रोजेक्ट में चार्ट खाली दिखते हैं।

## Summary क्या दिखाता है { #what-the-summary-shows }

| सेक्शन | यह क्या बताता है |
| --- | --- |
| चार गिनती वाले कार्ड | पिछले 7 दिनों में कितने टास्क पूरे हुए, अपडेट हुए और बने, और कितने जल्दी ही ड्यू होने वाले हैं। |
| **Status overview** | सारे टास्क का स्टेटस के हिसाब से डोनट चार्ट। बीच में कुल संख्या लिखी होती है। |
| **Recent activity** | हाल में बने या अपडेट हुए टास्क, साथ में यह कि किसने किया और कब। |
| **Priority breakdown** | हर प्रायोरिटी के लिए एक बार, **Highest** से **Lowest** तक। |
| **Types of work** | प्रोजेक्ट में हर टाइप के कितने टास्क हैं। |
| **Team workload** | हर व्यक्ति के पास कितने टास्क हैं, **Unassigned** मिलाकर। |
| **Epic progress** | हर Epic कितना आगे बढ़ा है। |

## स्टेप { #steps }

### Summary खोलें { #open-the-summary }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें।
2. **Board** पर क्लिक करें। पूरा टास्क बोर्ड खुलेगा।
3. ऊपर के व्यू स्विचर में **Summary** पर क्लिक करें।
4. ताज़ा संख्याएँ पाने के लिए व्यू को दोबारा खोलें। टच स्क्रीन पर पेज को नीचे की ओर खींचें।

### चार गिनती वाले कार्ड पढ़ें { #read-the-four-count-cards }

1. पेज के ऊपर कार्ड की कतार देखें।
2. **completed**, **updated** और **created** पढ़ें। हर कार्ड के अंत में **in the last 7 days** लिखा होता है।
3. **due soon** पढ़ें। इसके अंत में **in the next 7 days** लिखा होता है। यह लेबल पहले से तय टेक्स्ट है, इसलिए **due soon** की संख्या हमेशा 0 दिखती है।
4. किसी कार्ड पर क्लिक करें। **List** व्यू खुलेगा। उसमें वही टास्क दिखेंगे जिनसे वह संख्या बनी है।

### Status overview पढ़ें { #read-the-status-overview }

1. **Status overview** ढूँढें। उसकी लाइन में लिखा होता है **Get a snapshot of the status of your work items.**
2. **Total work items** के नीचे की संख्या पढ़ें। यह प्रोजेक्ट के सारे टास्क की संख्या है।
3. हर टुकड़े को उसके स्टेटस के नाम से मिलाएँ। Done, closed और resolved वाले टुकड़े हरे होते हैं। To do और open वाले स्लेटी होते हैं। In progress और in dev वाले गहरे रंग के होते हैं। बाकी स्टेटस के अपने रंग होते हैं।
4. अगर चार्ट में **No data** लिखा है, तो प्रोजेक्ट में अभी कोई टास्क नहीं है।

### Recent activity पढ़ें { #read-recent-activity }

1. **Status overview** के बगल में **Recent activity** ढूँढें।
2. हर पंक्ति पढ़ें। उसमें टास्क की key, टाइटल, स्टेटस और असाइनी दिखता है। जिस टास्क का कोई असाइनी नहीं है, उस पर **Unassigned** लिखा होता है।
3. टाइटल के नीचे की लाइन पढ़ें। उसमें **created this work item** या **updated this work item** लिखा होता है, साथ में यह कि किसने किया और कब।
4. समय पढ़ें। यह पहले **just now** दिखता है, फिर मिनट (**5m ago**), घंटे (**3h ago**), दिन (**2d ago**) और हफ़्ते (**1w ago**) में। पुराने बदलावों पर तारीख़ दिखती है।
5. उस टास्क को खोलने के लिए किसी पंक्ति पर क्लिक करें।
6. अगर हाल में कुछ नहीं बदला है, तो पैनल में **No recent activity** लिखा होता है।

### Priority breakdown पढ़ें { #read-the-priority-breakdown }

1. **Priority breakdown** ढूँढें। उसकी लाइन में लिखा होता है **Get a holistic view of how work is being prioritized.**
2. पाँच बार पढ़ें: **Highest**, **High**, **Medium**, **Low** और **Lowest**।
3. मदद का लिंक खोलने के लिए **How to manage priorities for spaces** पर क्लिक करें।

### Types of work पढ़ें { #read-types-of-work }

1. **Types of work** ढूँढें। उसकी लाइन में लिखा होता है **Get a breakdown of work items by their types.**
2. हर टाइप की गिनती पढ़ें, जैसे Story, Task, Epic और Sub-task।
3. किसी टाइप पर क्लिक करें। **List** व्यू खुलेगा, जिसमें सिर्फ़ वही टाइप दिखेगा।
4. सारे टाइप देखने के लिए **View all items** पर क्लिक करें।

### Team workload पढ़ें { #read-team-workload }

1. **Team workload** ढूँढें। उसकी लाइन में लिखा होता है **Monitor the capacity of your team.**
2. **Work distribution** के बार पढ़ें। हर बार बताता है कि सारे टास्क में एक व्यक्ति का कितना हिस्सा है।
3. जिन टास्क का कोई ओनर नहीं है, उन्हें देखने के लिए **Unassigned** ढूँढें।
4. किसी व्यक्ति के नाम पर क्लिक करें। **List** व्यू खुलेगा, जिसमें सिर्फ़ उसके टास्क दिखेंगे।

### Epic progress पढ़ें { #read-epic-progress }

1. **Epic progress** ढूँढें। उसकी लाइन में लिखा होता है **See how your epics are progressing at a glance.**
2. हर Epic का बार पढ़ें। जिस प्रोजेक्ट में कोई Epic नहीं है, वहाँ कोई बार नहीं दिखता।
3. किसी Epic पर क्लिक करें। बोर्ड उसी Epic के हिसाब से फ़िल्टर हो जाएगा और **Filtered by epic** दिखेगा।

!!! tip "बिना ओनर वाले टास्क जल्दी ढूँढें"
    जिन टास्क का कोई ओनर नहीं है, उनकी लिस्ट देखने के लिए **Team workload** के नीचे **Unassigned** पर क्लिक करें। फिर उन्हें **List** व्यू से असाइन करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| चार्ट खाली हैं। | प्रोजेक्ट में कोई टास्क नहीं है, या अभी लोड हो रहा है। | कोई टास्क बनाएँ, या व्यू को दोबारा खोलकर रीलोड करें। देखें [टास्क बनाएँ और असाइन करें](create-and-assign-tasks.md)। |
| **Epic progress** में कोई बार नहीं दिखता। | प्रोजेक्ट में कोई Epic नहीं है। | Epic टाइप का टास्क बनाएँ, फिर उसके नीचे टास्क जोड़ें। |
| कोई कार्ड ऐसी **List** खोलता है जिसमें पंक्तियाँ उसकी संख्या से कम हैं। | **List** में बोर्ड पर लगाए आपके फ़िल्टर भी लागू रहते हैं। | बोर्ड के टूलबार पर फ़िल्टर हटाएँ। देखें [टास्क खोजें, फ़िल्टर करें और देखें](find-and-filter-tasks.md)। |
| **No recent activity** | प्रोजेक्ट में हाल में कुछ नहीं बदला। | कोई टास्क बनाएँ या अपडेट करें। |
