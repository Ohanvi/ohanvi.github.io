# अपने शेड्यूल किए ईमेल कैंपेन देखें { #see-your-scheduled-email-campaigns }

**Email** व्यू से हर शेड्यूल किया ईमेल कैंपेन एक कैलेंडर या सूची में देखें। अंत में आप जाँच सकते हैं कि हर कैंपेन कब जाएगा, और उसके जाने से पहले उसे आगे-पीछे या बंद कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Schedule** दिखता है। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। न दिखे तो अपने एडमिन से पूछें।
- कैंपेन का कोई शेड्यूल किया हुआ समय हो। देखें [ईमेल कैंपेन भेजें](../email/send-email-campaign.md)।

## चरण { #steps }

### Email शेड्यूल खोलें { #open-the-email-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Email** चुनें। पेज का शीर्षक **Email schedule** दिखता है।
2. पेज मौजूदा महीने के **Calendar** व्यू में खुलता है। चैनल चिप छिपे होते हैं, क्योंकि पेज पहले से सिर्फ़ Email तक सीमित है।
3. किसी दिन पर क्लिक करके उसके आइटम देखें। उन्हें दिन के शीर्षकों के नीचे समय के हिसाब से देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### जानें कि हर टाइप का क्या मतलब है { #read-what-each-type-means }

**Type** बताता है कि आइटम किस तरह का है।

| टाइप | यह क्या है |
| --- | --- |
| **Regular** | आपका लिखा और भेजा हुआ सामान्य कैंपेन। |
| **Rss** | RSS फ़ीड से बना कैंपेन। |

**Audience / with** लाइन कैंपेन की ऑडियंस दिखाती है। **Channel** फ़ील्ड वह ईमेल चैनल दिखाती है जिससे वह भेजा जाता है।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | कैंपेन **Draft**, **Pending review** या **Rejected** है। |
| **Scheduled** | कैंपेन **Approved** या **Scheduled** है और अपने समय का इंतज़ार कर रहा है। |
| **Live** | कैंपेन अभी भेजा जा रहा है। |
| **Sent** | कैंपेन भेजा जा चुका है। |
| **Failed** | सेंड पूरा नहीं हुआ। |
| **Cancelled** | रद्द कर दिया गया। यह नहीं भेजा जाएगा। |

### किसी आइटम को बदलें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [शेड्यूल किए गए आइटम को रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।
2. Email कैंपेन स्क्रीन खोलने के लिए **Edit** पर क्लिक करें। देखें [ईमेल कैंपेन भेजें](../email/send-email-campaign.md)।
3. उसे रद्द करने के लिए **Cancel** पर क्लिक करें। कैंपेन रद्द हो जाता है और नहीं भेजा जाता।
4. Email से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छोटा करें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in Email** चुनें। Ohanvi Email कैंपेन स्क्रीन खोलता है, जहाँ आप आइटम बनाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | किसी कैंपेन का शेड्यूल किया समय नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | Email में कैंपेन खोलें और भेजने का समय तय करें। |
| कोई कैंपेन नहीं दिख रहा | जिस कैंपेन का शेड्यूल किया समय नहीं है वह Schedule में नहीं दिखता। | उसे भेजने का समय दें। |
| **Could not cancel.** | कैंपेन पहले ही भेजा जा चुका है या आपका रोल उसे बदल नहीं सकता। | स्टेटस देखें। अपने एडमिन से Email एक्सेस माँगें। |
