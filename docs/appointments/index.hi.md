# अपॉइंटमेंट { #appointments }

Appointments से ग्राहक व्हाट्सऐप पर आपकी सर्विस बुक कर सकते हैं, और आपकी टीम को इन बुकिंग को कन्फ़र्म करने, आगे-पीछे करने और बंद करने की एक ही जगह मिलती है।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Appts** खोलें (होवर करने पर नाम **Appointments** दिखता है)। पैनल में **Appointments**, **Services**, **Classes** और **Providers** की सूची दिखती है।

बुकिंग के नियम और रिमाइंडर पैनल में नहीं हैं: नीचे बाईं ओर अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** → **Appointments** → **Booking Rules** चुनें।

## शुरू करने से पहले { #before-you-start }

- आपके रोल के पास Appointments का एक्सेस हो।
- आपका व्हाट्सऐप नंबर कनेक्ट हो। बुकिंग, काम के घंटे, रिमाइंडर और ग्राहकों के संदेश, सब इसी नंबर से जाते हैं।
- आपके पास कम से कम 1 सर्विस और 1 प्रोवाइडर हो। दोनों बनने तक कोई समय ऑफ़र नहीं किया जा सकता।
