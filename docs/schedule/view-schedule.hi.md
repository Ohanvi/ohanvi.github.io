# जो कुछ भी शेड्यूल है, सब देखें { #view-everything-scheduled }

आपके वर्कस्पेस में WhatsApp, CRM, Email, Social और Appointments में जो कुछ भी कतार में है, वह सब **Schedule** सेक्शन में दिखता है। आखिर में आपके पास एक कैलेंडर या लिस्ट होगी, जिसमें सिर्फ़ वही दिन, चैनल, ओनर और स्टेटस दिखेंगे जो आपको चाहिए।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। अगर नहीं दिखता, तो अपने एडमिन से कहें कि वे आपके रोल को शेड्यूल का एक्सेस दें। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। देखें [सेटिंग्स](../settings/index.md)।
- कम से कम एक मॉड्यूल में कुछ पहले से शेड्यूल हो, जैसे WhatsApp ब्रॉडकास्ट या ईमेल कैंपेन। Schedule सेक्शन सिर्फ़ आइटम दिखाता है। आइटम आप उनके अपने मॉड्यूल में ही बनाते हैं।

## स्टेप { #steps }

### Schedule खोलें { #open-the-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **All schedules** चुनें। **My Schedule** पेज इस महीने के **Calendar** व्यू में खुलता है।
2. पिछले या अगले महीने में जाने के लिए महीने के नाम के बगल वाले तीर दबाएँ। इस महीने पर वापस आने के लिए **Today** पर क्लिक करें।
3. हर आइटम एक रंगीन चिप के रूप में अपने समय और टाइटल के साथ दिखता है। रंग से पता चलता है कि यह कौन-सा चैनल है।
4. किसी दिन पर क्लिक करें। उस दिन जो कुछ शेड्यूल है, उसकी लिस्ट खुल जाती है, जैसे **Today · 4 scheduled**। किसी आइटम की जानकारी देखने के लिए उस पर क्लिक करें।
5. अगर किसी दिन में इतने आइटम हैं कि डिब्बे में नहीं समाते, तो डिब्बे में **+N more** दिखता है, जैसे **+3 more**। सारे आइटम देखने के लिए उस दिन पर क्लिक करें।

### कैलेंडर और लिस्ट के बीच बदलें { #switch-between-calendar-and-list }

1. पेज के ऊपर **List** पर क्लिक करें। आइटम समय के हिसाब से लिस्ट में दिखते हैं, दिन के हेडिंग के नीचे। हेडिंग **Yesterday**, **Today**, **Tomorrow** होती हैं, उसके बाद **Fri, 3 Oct** जैसी तारीख।
2. लिस्ट में किसी आइटम पर क्लिक करें। उसकी जानकारी दाईं तरफ़ खुलती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।
3. महीने के व्यू में वापस जाने के लिए **Calendar** पर क्लिक करें।

!!! note "ध्यान दें"
    जानकारी वाला पैनल तभी दिखता है जब विंडो काफ़ी चौड़ी हो, जैसे लैपटॉप या टैबलेट पर। छोटी विंडो में सिर्फ़ लिस्ट दिखती है।

### बने-बनाए व्यू खोलें { #open-a-ready-made-view }

पैनल का हर आइटम यही पेज खोलता है, बस एक फ़िल्टर पहले से लगा होता है:

| पैनल आइटम | यह क्या दिखाता है |
| --- | --- |
| **All schedules** | सब कुछ, कैलेंडर व्यू में। |
| **Today** | आज के लिए शेड्यूल किए आइटम, लिस्ट व्यू में। |
| **Upcoming** | आज से आगे के वे आइटम जो **Scheduled** या **Live** हैं, लिस्ट व्यू में। |
| **Drafts** | वे आइटम जो अभी **Draft** में हैं, लिस्ट व्यू में। |
| **WhatsApp**, **CRM**, **Email**, **Social**, **Appointments** | सिर्फ़ एक चैनल। पेज का टाइटल बदल जाता है, जैसे **WhatsApp schedule**। |
| **Recurring** | वे आइटम जो बार-बार दोहराए जाते हैं। देखें [बार-बार चलने वाले शेड्यूल मैनेज करें](manage-recurring-schedules.md)। |

### व्यू को फ़िल्टर करें { #filter-the-view }

1. **All schedules** पर किसी चैनल चिप पर क्लिक करें: **WhatsApp**, **CRM**, **Email**, **Social** या **Appointments**। पहले क्लिक पर सिर्फ़ वही चैनल दिखता है। दूसरे चैनल वापस जोड़ने के लिए और चिप्स पर क्लिक करें।
2. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
3. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें। **Scheduled** में वे आइटम भी आते हैं जो **Live** या **Paused** हैं।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | सेव है, पर अभी भेजने के लिए शेड्यूल नहीं हुआ। |
| **Scheduled** | दिखाए गए समय पर जाने के लिए कतार में है। |
| **Live** | अभी चल रहा है, जैसे बार-बार चलने वाली सीरीज़। |
| **Sent** | जा चुका है। |
| **Paused** | अपने मॉड्यूल में रोका हुआ है। |
| **Cancelled** | कैंसिल कर दिया गया। रिकॉर्ड बना रहता है। |
| **Failed** | भेजा नहीं जा सका। वजह जानने के लिए आइटम को उसके मॉड्यूल में खोलें। |

### कुछ नया शेड्यूल करें { #schedule-something-new }

1. **New schedule** पर क्लिक करें। **New schedule — pick a channel** शीट खुलेगी।
2. **New in WhatsApp**, **New in CRM**, **New in Email**, **New in Social** या **New in Appointments** चुनें। Ohanvi उस मॉड्यूल की अपनी स्क्रीन खोल देगा। नया आइटम आप वहीं बनाएँगे।

## समस्या का समाधान { #troubleshooting }

| समस्या | वजह | हल |
| --- | --- | --- |
| **Nothing scheduled here**, साथ में मैसेज **No schedules match these filters. Try another channel or clear the status filter.** | कोई भी आइटम चैनल, ओनर या स्टेटस फ़िल्टर से मेल नहीं खाता। | दूसरे चैनल चिप पर क्लिक करें, **Everyone's schedule** चुनें, या स्टेटस को वापस **Any status** करें। |
| **Could not load your schedule.** | पेज सर्वर तक नहीं पहुँच सका। | मैसेज पर दिए रीट्राई बटन पर क्लिक करें। फिर भी न चले, तो साइन आउट करके दोबारा साइन इन करें। |
| लेफ़्ट रेल में **Schedule** नहीं है | आपके रोल में शेड्यूल का एक्सेस नहीं है। | अपने एडमिन से कहें कि वे इसे आपके रोल में जोड़ दें। |
| आपका बनाया आइटम नहीं दिख रहा | जिस आइटम में तारीख और समय नहीं है, वह Schedule में नहीं दिखता। | आइटम को उसके मॉड्यूल में खोलें और उसमें शेड्यूल का समय डालें। |
| **List** व्यू में जानकारी वाला पैनल या एक्शन बटन नहीं हैं | जानकारी वाले पैनल के लिए विंडो बहुत छोटी है। | ब्राउज़र की विंडो चौड़ी करें, या लैपटॉप या टैबलेट इस्तेमाल करें। |
