# व्हाट्सऐप पर TallyPrime इनवॉइस भेजें { #send-tallyprime-invoices-on-whatsapp }

TallyPrime से इनवॉइस PDF एक फ़ोल्डर में एक्सपोर्ट करें, और एक Windows स्क्रिप्ट उसे टेम्प्लेट मैसेज के रूप में ग्राहक के व्हाट्सऐप नंबर पर भेज देती है। भेजी गई फ़ाइलें **Processed** में चली जाती हैं, और फ़ेल होने वाली फ़ाइलें कारण के साथ लॉग में दर्ज होकर **Failed** में चली जाती हैं।

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट हो। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आपके पास Developer API key हो। देखें [Developer API से व्हाट्सऐप संदेश भेजें](../settings/developer-apis.md)।
- आपके पास **Document** हेडर वाला Approved **Utility** टेम्प्लेट हो, जैसे `Hello {{1}}, your invoice {{2}} dated {{3}} is attached.` देखें [व्हाट्सऐप मैसेज टेम्प्लेट बनाएँ](create-message-template.md)।
- कंप्यूटर Windows 10 या 11 पर चलता हो और ऑनलाइन हो। स्क्रिप्ट `curl.exe` और PowerShell इस्तेमाल करती हैं, जो Windows में पहले से होते हैं।
- TallyPrime में हर ग्राहक के लेजर में 10 अंकों का मोबाइल नंबर हो।

## यह कैसे काम करता है { #how-it-works }

| चरण | क्या होता है |
| --- | --- |
| 1 | आप TallyPrime से इनवॉइस को PDF के रूप में **Incoming** फ़ोल्डर में एक्सपोर्ट करते हैं। |
| 2 | एक स्क्रिप्ट फ़ाइल के नाम से ग्राहक का नाम, मोबाइल नंबर, इनवॉइस नंबर और तारीख पढ़ती है। |
| 3 | स्क्रिप्ट PDF को आपकी API key के साथ Ohanvi को भेजती है। Ohanvi उसे टेम्प्लेट के **Document** हेडर में भेजता है। |
| 4 | जब व्हाट्सऐप संदेश स्वीकार कर लेता है, तो फ़ाइल **Processed** में चली जाती है। अगर नाम ग़लत है या भेजना नामंज़ूर हो जाता है, तो वह **Failed** में चली जाती है। |

टेम्प्लेट PDF को साथ ले जाता है, इसलिए यह उन ग्राहकों तक भी पहुँचता है जिन्होंने पिछले 24 घंटे में आपको संदेश नहीं भेजा।

## चरण { #steps }

### PDF का नाम रखें { #name-the-pdf }

1. TallyPrime में सेव किया हुआ इनवॉइस खोलें।
2. **Ctrl+P** (Print) दबाएँ और **Save as PDF** चुनें [VERIFY: exact label in your TallyPrime version]।
3. फ़ाइल का नाम `ClientName_Mobile_InvoiceNo_DD-MM-YYYY.pdf` के रूप में लिखें, जैसे `Sanjay_9416388827_2026-27-045_13-10-2026.pdf`।
4. अपना **Incoming** फ़ोल्डर चुनें और सेव करें।

नाम के लिए ये नियम मानें:

- हर हिस्से में अक्षर, अंक और हाइफ़न इस्तेमाल करें। कोई स्पेस नहीं।
- मोबाइल नंबर 10 अंकों का हो और 6, 7, 8 या 9 से शुरू हो।
- इनवॉइस नंबर में `/` की जगह `-` लिखें, जैसे `INV-186`।
- तारीख `DD-MM-YYYY` के रूप में लिखें।

TallyPrime यह नाम अपने-आप नहीं बनाता। PDF सेव करते समय इसे खुद लिखें, और मोबाइल नंबर पार्टी के लेजर से भरें।

### स्क्रिप्ट डाउनलोड करें { #download-the-scripts }

1. Ohanvi में अपने नाम पर क्लिक करें, फिर **Developer** के नीचे **Developer APIs** खोलें।
2. **Docs** टैब खोलें और **Tally scripts** पर क्लिक करें। `Ohanvi-Tally-WhatsApp-Scripts.zip` नाम की फ़ाइल डाउनलोड होती है।
3. उसे Windows कंप्यूटर पर किसी फ़ोल्डर में एक्सट्रैक्ट करें, जैसे `C:\TallyWhatsApp\`।

ज़िप में 2 फ़ाइलें हैं:

| फ़ाइल | इस्तेमाल |
| --- | --- |
| `tally_run_now.bat` | **Incoming** में मौजूद सब कुछ अभी भेजने के लिए डबल-क्लिक करें। विंडो खुली रहती है और नतीजा दिखाती है। |
| `tally_send_invoices.bat` | शेड्यूल पर चलती है, हर 2 मिनट में। |

डाउनलोड सिर्फ़ वेब ऐप में काम करते हैं।

### सेटिंग्स भरें { #fill-in-the-settings }

1. हर फ़ाइल पर राइट-क्लिक करें, **Edit** पर क्लिक करें, और **SETTINGS** के नीचे की लाइनें सेट करें। दोनों फ़ाइलों में एक जैसी वैल्यू इस्तेमाल करें।
2. फ़ाइल सेव करें।

| सेटिंग | क्या लिखना है |
| --- | --- |
| `API_BASE_URL` | पहले से आपके Ohanvi पते से भरा है। |
| `API_KEY` | आपकी Developer API key, जो `wak_` से शुरू होती है। |
| `TEMPLATE_NAME` | आपके Approved टेम्प्लेट का सही नाम। |
| `TEMPLATE_LANG` | टेम्प्लेट की भाषा का कोड, जैसे `en`। |
| `VAR_ORDER` | फ़ाइल के नाम के कौन-से हिस्से क्रम से `{{1}}`, `{{2}}` और `{{3}}` भरते हैं। `CLIENT`, `MOBILE`, `INVOICE`, `DATE` में से चुनें। डिफ़ॉल्ट `CLIENT INVOICE DATE` है। गिनती टेम्प्लेट की बॉडी के वेरिएबल से मेल खानी चाहिए। |
| `COUNTRY_CODE` | 10 अंकों के नंबर से पहले जुड़ता है, जैसे `91`। |
| `ROOT` | मुख्य फ़ोल्डर। स्क्रिप्ट उसके अंदर **Incoming**, **Processed**, **Failed** और **Logs** बनाती हैं। डिफ़ॉल्ट `D:\TallyInvoices` है। |
| `CHECK_DELIVERY` | `1` हर संदेश की पुष्टि के लिए व्हाट्सऐप का इंतज़ार करता है। `0` Ohanvi के स्वीकार करते ही रुक जाता है। |

### माँगने पर भेजें { #send-on-demand }

1. **Incoming** में 2 टेस्ट PDF रखें: एक सही नाम वाली, आपके अपने मोबाइल नंबर के साथ, और एक ग़लत नाम वाली।
2. `tally_run_now.bat` पर डबल-क्लिक करें।
3. विंडो में नतीजा पढ़ें। सही फ़ाइल **Processed** में चली जाती है और PDF आपके व्हाट्सऐप पर आ जाती है। ग़लत फ़ाइल **Failed** में चली जाती है।

### हर 2 मिनट में भेजें { #send-every-2-minutes }

1. **Start** पर क्लिक करें, `cmd` टाइप करें, **Command Prompt** पर राइट-क्लिक करें और **Run as administrator** पर क्लिक करें।
2. यह कमांड चलाएँ। पाथ को उस जगह के अनुसार बदलें जहाँ आपने फ़ाइलें एक्सट्रैक्ट की हैं।

    ```
    schtasks /Create /TN "Tally WhatsApp Invoices" /TR "C:\TallyWhatsApp\tally_send_invoices.bat" /SC MINUTE /MO 2 /RU SYSTEM
    ```

3. इसे रोकने के लिए `schtasks /Delete /TN "Tally WhatsApp Invoices" /F` चलाएँ।

दो रन कभी आपस में नहीं टकराते। जिस फ़ाइल को TallyPrime अभी लिख रहा है, उसे छोड़ दिया जाता है और अगले रन में उठाया जाता है। अगर कंप्यूटर ऑफ़लाइन है, तो फ़ाइलें **Incoming** में रहती हैं और अगले रन में भेजी जाती हैं।

!!! note "ध्यान दें"
    लैपटॉप के स्लीप में रहने पर टास्क नहीं चलता। इसे बैटरी पर चलाने के लिए **Task Scheduler** में टास्क खोलें और **Conditions** टैब पर **Start the task only if the computer is on AC power** को हटा दें।

### फ़ेल हुई फ़ाइल ठीक करें { #fix-a-failed-file }

1. मुख्य फ़ोल्डर में `Logs\api_log.txt` खोलें और फ़ाइल की लाइन खोजें।
2. कारण ठीक करें, और अगर नाम ग़लत था तो फ़ाइल का नाम बदलें।
3. फ़ाइल को **Failed** से वापस **Incoming** में ले जाएँ। अगला रन उसे फिर से भेजता है।

हर फ़ाइल के लिए Ohanvi ने जो जवाब दिया, वह `Logs\responses` में सेव रहता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| लॉग कहता है कि फ़ाइल का नाम `ClientName_Mobile_...` होना चाहिए | नाम पैटर्न से मेल नहीं खाता। | फ़ाइल का नाम बदलकर `ClientName_Mobile_InvoiceNo_DD-MM-YYYY.pdf` करें। |
| लॉग में HTTP 400 है और टेम्प्लेट का ज़िक्र है | टेम्प्लेट का नाम ग़लत है, Approved नहीं है, या उसमें **Document** हेडर नहीं है। | `TEMPLATE_NAME` और टेम्प्लेट का स्टेटस व हेडर जाँचें। |
| लॉग कहता है कि `{{n}}` के लिए वैल्यू चाहिए | `VAR_ORDER` में उतनी वैल्यू नहीं हैं जितने वेरिएबल टेम्प्लेट की बॉडी में हैं। | हर वेरिएबल के लिए `CLIENT`, `MOBILE`, `INVOICE` या `DATE` में से एक हिस्सा लिखें। |
| लॉग में HTTP 401 या 403 है | API key ग़लत, रद्द की हुई या एक्सपायर है। | नई key बनाएँ और उसे दोनों स्क्रिप्ट में पेस्ट करें। |
| लॉग में HTTP 402 है | Pay as you go ने अपने महीने के API संदेश इस्तेमाल कर लिए हैं। | ज़्यादा भेजने के लिए कोई प्लान चुनें। |
| लॉग कहता है कि व्हाट्सऐप ने नामंज़ूर किया | व्हाट्सऐप ने संदेश ठुकरा दिया, जैसे नंबर व्हाट्सऐप पर नहीं है। | लॉग की लाइन में कारण पढ़ें और नंबर ठीक करें। |
| लॉग कहता है कि API तक पहुँच नहीं हो पा रही | कंप्यूटर ऑफ़लाइन है या `API_BASE_URL` ग़लत है। | इंटरनेट कनेक्शन जाँचें। फ़ाइलें **Incoming** में रहती हैं और दोबारा कोशिश होती है। |
| **Tally scripts** कोई फ़ाइल डाउनलोड नहीं करता | डाउनलोड सिर्फ़ वेब ऐप में काम करते हैं। | Ohanvi को ब्राउज़र में खोलें। |
