# कैंपेन { #campaigns }

ईमेल कैंपेन बनाएँ, शेड्यूल करें और भेजें। फिर उसके नतीजे देखें।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Email** खोलें, फिर **Campaigns** चुनें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [ईमेल कैंपेन भेजें](../send-email-campaign.md) | जब आप कैंपेन बनाकर भेजना चाहते हों। |
| [नतीजे ट्रैक करें और अनसब्सक्राइब संभालें](../track-email-results.md) | जब आप ओपन, क्लिक और बाउंस देखना चाहते हों। |

## शुरू करने से पहले { #before-you-start }

- एक वेरिफ़ाइड सेंडर और सब्सक्राइब किए हुए कॉन्टैक्ट की एक लिस्ट।
