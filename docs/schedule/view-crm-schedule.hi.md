# अपनी शेड्यूल की हुई CRM एक्टिविटी देखें { #see-your-scheduled-crm-activities }

CRM में प्लान की गई हर एक्टिविटी एक कैलेंडर या लिस्ट में देखने के लिए **CRM** व्यू खोलें। यहाँ आप देख सकते हैं कि आपकी टीम को क्या काम कब करना है। आप किसी भी एक्टिविटी का समय बदल सकते हैं या उसे कैंसिल कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखना चाहिए। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल को मिलता है। अगर यह नहीं दिख रहा, तो अपने एडमिन से कहें।
- CRM में तारीख और समय वाली एक्टिविटी हों। देखें [एक्टिविटी और नोट्स लॉग करें](../crm/log-activities-and-notes.md)।

## स्टेप { #steps }

### CRM शेड्यूल खोलें { #open-the-crm-schedule }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **CRM** चुनें। पेज का टाइटल **CRM schedule** दिखेगा।
2. पेज इस महीने के **Calendar** व्यू में खुलता है। चैनल चिप्स यहाँ नहीं दिखते, क्योंकि यह पेज पहले से सिर्फ़ CRM दिखाता है।
3. किसी दिन के आइटम देखने के लिए उस दिन पर क्लिक करें। समय के हिसाब से, दिन के हेडिंग के नीचे आइटम देखने के लिए **List** पर क्लिक करें।
4. किसी आइटम पर क्लिक करें। उसकी जानकारी दाईं तरफ़ खुलती है: **When**, **Recurrence**, **Audience / with**, **Owner**, **Channel** और **Type**।

### हर Type का मतलब समझें { #read-what-each-type-means }

**Type** बताता है कि यह आइटम किस तरह का है।

| Type | यह क्या है |
| --- | --- |
| **Task** | करने वाला काम। जिस टास्क का कोई और Type नहीं होता, वह **Task** दिखता है। |
| **Call** | प्लान की गई फ़ोन कॉल। |
| **Meeting** | प्लान की गई मीटिंग। |
| **Email** | प्लान किया गया ईमेल फ़ॉलो-अप। |
| **Whatsapp** | प्लान किया गया WhatsApp फ़ॉलो-अप। |
| **Whatsapp call** | प्लान की गई WhatsApp कॉल। |

**Audience / with** लाइन में उस Lead, कॉन्टैक्ट या Deal का नाम दिखता है, जिससे यह एक्टिविटी जुड़ी है।

### स्टेटस पढ़ें { #read-the-status }

| स्टेटस | मतलब |
| --- | --- |
| **Scheduled** | प्लान की गई है, अभी शुरू नहीं हुई। |
| **Live** | चल रही है। |
| **Sent** | पूरी हो गई। |
| **Cancelled** | कैंसिल कर दी गई। रिकॉर्ड बना रहता है। |

### किसी आइटम में बदलाव करें { #change-an-item }

1. नई तारीख और समय चुनने के लिए **Reschedule** पर क्लिक करें। देखें [रीशेड्यूल, कैंसिल या डिलीट करें](reschedule-cancel-delete.md)।
2. CRM एक्टिविटी की स्क्रीन खोलने के लिए **Edit** पर क्लिक करें। देखें [एक्टिविटी और नोट्स लॉग करें](../crm/log-activities-and-notes.md)।
3. एक्टिविटी कैंसिल करने के लिए **Cancel** पर क्लिक करें। उसका स्टेटस कैंसिल हो जाता है।
4. आइटम को CRM से हटाने के लिए **Delete** पर क्लिक करें।

### व्यू को छाँटें { #narrow-the-view }

1. सिर्फ़ अपने आइटम देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।
2. **Any status** पर क्लिक करें और **Scheduled**, **Draft**, **Sent** या **Cancelled** चुनें।

### कुछ नया जोड़ें { #add-something-new }

1. **New schedule** पर क्लिक करें, फिर **New in CRM** चुनें। Ohanvi CRM एक्टिविटी की स्क्रीन खोल देगा। नया आइटम आप वहीं बनाएँगे।

## समस्या का समाधान { #troubleshooting }

| समस्या | वजह | हल |
| --- | --- | --- |
| **Nothing scheduled here** | किसी CRM एक्टिविटी में तारीख और समय नहीं है, या कोई फ़िल्टर उसे छिपा रहा है। | CRM में एक्टिविटी का due समय डालें। **Any status** चुनें। |
| पूरी हो चुकी एक्टिविटी **Sent** दिखती है | Schedule में पूरी हुई एक्टिविटी **Sent** नाम से दिखती है। | कुछ करने की ज़रूरत नहीं। |
| **Could not cancel.** | एक्टिविटी पहले ही पूरी या कैंसिल हो चुकी है, या आपका रोल CRM में उसे नहीं बदल सकता। | स्टेटस देखें। CRM एक्सेस के लिए अपने एडमिन से कहें। |
