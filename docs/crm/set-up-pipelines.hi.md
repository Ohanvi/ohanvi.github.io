# पाइपलाइन सेट करें { #set-up-pipelines }

वह पाइपलाइन सेट करें जिसमें आपकी डील्स आगे बढ़ती हैं, उसके चरणों और हर चरण पर जीतने की संभावना के साथ। एक बार बनने के बाद हर डील, बोर्ड, फ़नल और फ़ोरकास्ट इसी का इस्तेमाल करता है। लीड के स्रोत और प्रोडक्ट्स के अपने अलग पेज हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **CRM** दिखता है। अगर नहीं दिखता, तो अपने एडमिन से कहें कि आपके रोल को CRM का एक्सेस दें। आपके वर्कस्पेस के लिए CRM चालू भी होना चाहिए।
- आप एडमिन हैं। CRM सेटिंग्स पेज पर लिखा है **Configure how your CRM works — admin only**।

## चरण { #steps }

### CRM सेटिंग्स खोलें { #open-the-crm-settings }

1. नीचे-बाएँ कोने में अपने इनिशियल पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **CRM** चुनें। इसमें **Pipelines**, **Lead Sources**, **Products** और **Funnel Stages** की सूची है।
3. जिस पंक्ति को सेट करना है उस पर क्लिक करें। उसकी स्क्रीन खुलती है।

आप **Ctrl K** (Mac पर **⌘K**) दबाकर **Pipelines**, **Lead Sources** या **Products** टाइप करके भी स्क्रीन चुन सकते हैं।

### डिफ़ॉल्ट चरणों से शुरू करें { #start-with-the-default-stages }

अगर अभी आपकी कोई पाइपलाइन नहीं है, तो **Pipelines** टैब में **No pipelines yet** दिखता है।

1. **Use the default 10 stages** पर क्लिक करें।
2. Ohanvi **Sales Pipeline** नाम की पाइपलाइन बनाता है और **Default funnel stages created.** दिखाता है।

डिफ़ॉल्ट चरण और उन पर जीतने की संभावना ये हैं:

| चरण | प्रॉबेबिलिटी | श्रेणी |
| --- | --- | --- |
| New Lead | 5% | Open |
| Contacted | 10% | Open |
| Qualified | 25% | Open |
| Meeting Scheduled | 40% | Open |
| Needs Analysis | 50% | Open |
| Proposal Sent | 65% | Open |
| Negotiation | 80% | Open |
| Nurture | 15% | Open |
| Lost | 0% | Lost |
| Won | 100% | Won |

!!! note "ध्यान दें"
    अगर आप पाइपलाइन सेट करने से पहले डील बनाते हैं, तो Ohanvi खुद यह डिफ़ॉल्ट पाइपलाइन बना देता है और डील को उसके पहले चरण में रख देता है।

### पाइपलाइन बनाएँ { #create-a-pipeline }

1. **Pipelines** पर **New pipeline** पर क्लिक करें। **Add Pipeline** फ़ॉर्म खुलता है।
2. **Pipeline Name** में कोई नाम लिखें, जैसे `Enterprise Sales`।
3. वैकल्पिक: **Description** जोड़ें।
4. अगर नई डील्स इसी पाइपलाइन में शुरू होनी चाहिए, तो **Default Pipeline** पर टिक करें।
5. **Stages (top to bottom = board order)** में हर पंक्ति भरें:
    - **Stage Name** — चरण का नाम।
    - **Prob %** — इस चरण की डील के बंद होने की संभावना, 0 से 100 तक।
    - **Category** — काम वाले चरण के लिए **OPEN**, जीत वाले चरण के लिए **WON**, हार वाले चरण के लिए **LOST**।
6. और पंक्तियों के लिए **Add Stage** पर क्लिक करें। पंक्ति डिलीट करने के लिए हटाने वाले आइकन (**Remove stage**) पर क्लिक करें।
7. **Submit** पर क्लिक करें। **Pipeline created** संदेश दिखता है और पाइपलाइन एक कार्ड के रूप में आ जाती है।

हर पाइपलाइन में ठीक 1 **WON** चरण और 1 **LOST** चरण रखें। डील पर **Mark Won** और **Mark Lost** इन्हीं को ढूँढते हैं।

### मौजूदा पाइपलाइन में चरण जोड़ें { #add-a-stage-to-an-existing-pipeline }

1. पाइपलाइन के कार्ड पर **+ Stage** पर क्लिक करें। **Add stage** विंडो खुलती है।
2. **Stage name** में नाम लिखें, जैसे `Proposal sent`।
3. **Add stage** पर क्लिक करें। **Stage added.** संदेश दिखता है।

इस तरह जोड़ा गया चरण पाइपलाइन के अंत में 0% प्रॉबेबिलिटी और **OPEN** श्रेणी के साथ जाता है।

पाइपलाइन की डील्स खोलने के लिए उसके कार्ड पर **Open board →** पर क्लिक करें।

### फ़नल के चरण बदलें { #change-funnel-stages }

**Funnel Stages** टैब केवल पढ़ने के लिए है। उस पर **Sysadmin only** लिखा है, और केवल प्लेटफ़ॉर्म सिसएडमिन ही **Funnel** → **Edit stages** से चरणों के नाम बदल सकता है, उनका क्रम बदल सकता है या उन्हें छिपा सकता है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Pipeline 'Sales' already exists.** | किसी दूसरी पाइपलाइन का यही नाम है। | कोई दूसरा **Pipeline Name** इस्तेमाल करें। |
| **Stage probability must be between 0 and 100.** | कोई **Prob %** 0 से कम या 100 से ज़्यादा है। | 0 से 100 के बीच की संख्या डालें। |
| **Pipeline has active deals in stage '…'. Move or delete them first.** | आपने ऐसी पाइपलाइन डिलीट करने की कोशिश की जिसमें अभी डील्स हैं। | उन डील्स को किसी दूसरी पाइपलाइन के चरण में ले जाएँ, या डिलीट करें, फिर दोबारा कोशिश करें। |
| डील को जीता हुआ मार्क करते समय **No WON stage configured for this deal's pipeline** | पाइपलाइन में **WON** श्रेणी वाला कोई चरण नहीं है (या हार के लिए कोई **LOST** चरण नहीं है)। | पाइपलाइन एडिट करें और एक चरण की **Category** **WON** (और एक की **LOST**) करें। |
| आप पाइपलाइन कार्ड से किसी मौजूदा चरण की प्रॉबेबिलिटी या क्रम नहीं बदल सकते | चौड़ा कार्ड व्यू केवल अंत में चरण जोड़ता है। | **Pipelines** को छोटी विंडो में खोलें, जहाँ हर पाइपलाइन पंक्ति में पूरे चरण एडिटर वाला **Edit** विकल्प होता है [VERIFY: edit path on desktop]। |
