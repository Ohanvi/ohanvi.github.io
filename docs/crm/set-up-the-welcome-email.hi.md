# वेलकम ईमेल और अपने ब्रोशर सेट करें { #set-up-the-welcome-email-and-your-brochures }

वेलकम मैसेज एक बार सेट करें। अपने ब्रोशर भी एक ही लाइब्रेरी में रखें, ताकि पूरी टीम उन्हें अटैच कर सके। इसके बाद **Send Welcome Email** आपके अपने लिखे मैसेज के साथ खुलेगा, और आपकी फ़ाइलें अटैच करने के लिए तैयार मिलेंगी। सेटअप में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Contacts** दिखे, और उसके पैनल में **All contacts**।
- आपके पास फ़ाइलें तैयार हों, जैसे कोई बुकलेट या प्राइस लिस्ट।
- आपकी टीम में कोई भी आपके अपलोड किए ब्रोशर इस्तेमाल कर सकता है। इसलिए निजी फ़ाइलें अपलोड न करें।

## स्टेप { #steps }

### सेटअप विंडो खोलें { #open-the-setup-window }

1. लेफ़्ट रेल में **Contacts** खोलें, फिर **All contacts** चुनें।
2. ऊपर की बार में **Welcome Email Setup (message + brochures)** आइकन पर क्लिक करें। **Welcome Email Setup** विंडो खुलती है।

### डिफ़ॉल्ट मैसेज सेव करें { #save-the-default-message }

1. **Message** के नीचे लिखा नोट पढ़ें। उसमें बताया है कि **Send Welcome Email** पर क्लिक करने पर यही सब्जेक्ट और बॉडी अपने-आप आती है। भेजते समय आप इसे हर बार बदल भी सकते हैं।
2. **Subject** लिखें।
3. **Body** लिखें। बॉक्स बड़ा है, इसलिए आप कई लाइनें लिख सकते हैं।
4. **Save** पर क्लिक करें। **Welcome message saved** मैसेज आता है।

दोनों बॉक्स खाली हों, तो विंडो में **Add a subject or message before saving** दिखता है। सेव न हो पाए, तो **Could not save. Please retry.** दिखता है।

### ब्रोशर अपलोड करें { #upload-a-brochure }

1. **Brochures** के नीचे लिखा नोट पढ़ें। उसमें बताया है कि बुकलेट या प्राइस लिस्ट एक बार अपलोड करें और जब चाहें अटैच करें। यह आपकी पूरी टीम में शेयर होता है।
2. **Upload brochure** पर क्लिक करें।
3. अपने कंप्यूटर से फ़ाइल चुनें। अपलोड पूरा होने तक बटन पर **Uploading…** लिखा रहता है।
4. **Brochure uploaded** मैसेज आने तक रुकें। फ़ाइल अपने साइज़ के साथ लिस्ट में दिखने लगती है।

ब्रोशर के नियम:

- फ़ाइल 25 MB तक की हो सकती है। इससे बड़ी फ़ाइल पर **File exceeds the 25 MB limit** दिखता है।
- PDF, PNG, JPG, DOC, DOCX, PPT या PPTX फ़ाइलें इस्तेमाल करें। तब वे कॉन्टैक्ट के मेल ऐप में खुल जाएँगी।

अभी कोई ब्रोशर न हो, तो लिस्ट में **No brochures yet. Upload a booklet or price list to attach it to emails.** दिखता है।

### ब्रोशर डिलीट करें { #delete-a-brochure }

1. लिस्ट में वह फ़ाइल ढूँढें।
2. उसके बगल में **Delete** आइकन पर क्लिक करें। **Delete brochure?** विंडो पूछती है: **Remove "name" from the library?**
3. **Delete** पर क्लिक करें। **Brochure deleted** मैसेज आता है।

फ़ाइल सबके लिए हट जाती है। जो ईमेल पहले भेजे जा चुके हैं, उनमें फ़ाइल की कॉपी बनी रहती है।

### ब्रोशर अलग से मैनेज करें { #manage-brochures-on-their-own }

1. **Send Welcome Email** विंडो में **Attach brochures** के बगल में **Manage** पर क्लिक करें।
2. **Manage Brochures** विंडो में वही लाइब्रेरी दिखती है। उसमें **Upload brochure** है और हर लाइन पर **Delete**।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Could not read the selected file** | फ़ाइल खुल नहीं पाई। | उसे जिस प्रोग्राम में बनाया था, उसी से दोबारा सेव करें और फिर अपलोड करें। |
| **Upload failed. Please retry.** | अपलोड पूरा नहीं हुआ। | **Upload brochure** पर फिर से क्लिक करें। |
| **Could not delete the brochure** | डिलीट की रिक्वेस्ट सर्वर तक नहीं पहुँची। | थोड़ी देर बाद फिर कोशिश करें। |
| नया डिफ़ॉल्ट मैसेज इस्तेमाल नहीं हो रहा | विंडो बिना सेव किए बंद हो गई थी। | **Welcome Email Setup** दोबारा खोलें और **Save** पर क्लिक करें। |
