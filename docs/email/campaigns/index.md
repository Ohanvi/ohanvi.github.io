# Campaigns

Create, schedule and send email campaigns, then read the results.

## Where to find it

Open **Email** in the left rail, then select **Campaigns**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Send an email campaign](../send-email-campaign.md) | You want to build and send a campaign. |
| [Track results and handle unsubscribes](../track-email-results.md) | You want opens, clicks and bounces. |

## Before you start

- A verified sender and a list of subscribed contacts.
