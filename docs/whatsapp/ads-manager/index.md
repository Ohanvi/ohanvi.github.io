# Ads Manager

**Ads Manager** runs Facebook and Instagram ads from inside Ohanvi. Use it to connect Meta, create ads, track results, and send website events back to Meta. Each page below covers one part of the module.

## Guides

| Guide | Use it when |
| --- | --- |
| [Set up Ads Manager](set-up-ads-manager.md) | You connect Facebook, your Page, ad account and WhatsApp number for the first time. |
| [Create an ad](create-an-ad.md) | You launch an ad and need to know what each field means. |
| [Manage your ads](manage-your-ads.md) | You check status, spend and results, or pause and edit an ad. |
| [Use ad creatives](use-ad-creatives.md) | You compare pictures, videos and ad copy. |
| [Automate your ads](automate-your-ads.md) | You set rules that change or pause ads for you. |
| [Manage ad leads](manage-ad-leads.md) | You see who messaged you from an ad. |
| [Manage lead forms](manage-lead-forms.md) | You use lead form ads and check their forms. |
| [Build ad audiences](build-ad-audiences.md) | You make custom, website or lookalike audiences. |
| [Track website events](track-website-events.md) | You send purchases and other website actions to Meta. |
| [Set up server tracking](set-up-server-tracking.md) | You send events from the server and check tracking health. |
| [Read the performance report](read-the-performance-report.md) | You want spend, leads and message results per ad. |
| [Read the business dashboard](read-the-business-dashboard.md) | You want one overview across your ads. |
| [Run an account audit](run-an-account-audit.md) | You want a health check of the ad account. |

## Before you start

- Your WhatsApp number is connected to Ohanvi. See [Connect your WhatsApp number](../connect-whatsapp-number.md).
- You manage a Facebook Page and a Meta ad account.
- You can see **Ads Manager** in the **WhatsApp** panel. If not, ask your admin.
