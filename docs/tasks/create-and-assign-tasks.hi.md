# टास्क बनाएँ और असाइन करें { #create-and-assign-tasks }

टास्क बनाएँ, हर टास्क को एक मालिक, एक प्रायोरिटी और एक देय तारीख दें, और बड़े काम को सबटास्क में बाँटें। आख़िर में हर टास्क बोर्ड के एक कॉलम में OHANVI-12 जैसी key के साथ दिखता है, और असाइनी उसे अपनी **Assigned to me** सूची में देखता है।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में कम से कम 1 बोर्ड कॉलम वाला टास्क प्रोजेक्ट हो। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- जिन लोगों को आप असाइन करना चाहते हैं, वे प्रोजेक्ट के सदस्य हों। असाइनी की सूची में सिर्फ़ प्रोजेक्ट के सदस्य दिखते हैं।

## चरण { #steps }

### Tasks पैनल से टास्क बनाएँ { #create-a-task-from-the-tasks-panel }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें। **Tasks** पैनल खुलता है।
2. पैनल के ऊपर **Create** पर क्लिक करें। टास्क डायलॉग खुलता है।
3. **Add a summary** पर क्लिक करें और लिखें कि क्या करना है। सारांश ही अकेली ज़रूरी फ़ील्ड है।
4. वैकल्पिक: **Description** में ब्योरा जोड़ें। सूची शुरू करने के लिए `- ` या `1. ` टाइप करें, और इमेज या फ़ाइलें सीधे पेस्ट करें।
5. वैकल्पिक: दाईं ओर के पैनल में फ़ील्ड सेट करें, जैसा [टास्क का ब्योरा सेट करें](#set-the-task-details) में बताया है।
6. **Create** पर क्लिक करें। टास्क बोर्ड में जुड़ जाता है।

### बोर्ड पर टास्क बनाएँ { #create-a-task-on-the-board }

1. बोर्ड पर पेज के ऊपर **Create** पर क्लिक करें। वही टास्क डायलॉग खुलता है, जिसमें पहला कॉलम उसका स्टेटस होता है।
2. टास्क को ऊपर के चरण 3–6 की तरह भरें।

### सीधे किसी कॉलम में टास्क जोड़ें { #add-a-task-straight-into-a-column }

इसे तेज़ टास्क के लिए इस्तेमाल करें, जब आपको सिर्फ़ सारांश, प्रकार और असाइनी चाहिए।

1. बोर्ड पर किसी कॉलम पर माउस ले जाएँ और उसके कार्ड के नीचे **Create** पर क्लिक करें।
2. **What needs to be done?** में सारांश लिखें।
3. वैकल्पिक: टाइप आइकन (टूलटिप **Work type**) पर क्लिक करें और **Epic**, **Story**, **Task**, **Bug** या **Sub-task** चुनें।
4. वैकल्पिक: व्यक्ति वाले आइकन पर क्लिक करें और असाइनी चुनें।
5. Enter दबाएँ, या टिक (टूलटिप **Create**) पर क्लिक करें। टास्क उसी कॉलम में दिखता है।

### टास्क का ब्योरा सेट करें { #set-the-task-details }

टास्क डायलॉग के दाईं ओर के पैनल में टास्क का ब्योरा रहता है। अगर **Details** बंद है तो उसे खोलें।

| फ़ील्ड | यह क्या करती है |
| --- | --- |
| Status (पैनल के ऊपर) | वह कॉलम जिसमें टास्क रहता है। नए टास्क के लिए यह वही कॉलम होता है जहाँ से आपने शुरू किया। |
| **Assignee** | प्रोजेक्ट का वह सदस्य जो टास्क का मालिक है। खुद लेने के लिए **Assign to me** पर क्लिक करें। |
| **Labels** | संबंधित टास्क को समूह में रखने के लिए खुले टेक्स्ट वाले टैग। |
| **Priority** | **Highest**, **High**, **Medium**, **Low** या **Lowest**। नए टास्क का डिफ़ॉल्ट **Medium** होता है। |
| **Parent** | वह एपिक या स्टोरी जिससे यह टास्क जुड़ा है। |
| **Team** | वह टीम जिसका यह टास्क है। |
| **Sprint** | वह स्प्रिंट जिसके लिए टास्क प्लान किया गया है। देखें [स्प्रिंट में काम की योजना बनाएँ](plan-sprints.md)। |
| **Story point estimate** | काम के आकार का अनुमान। |
| **Start date** / **Due date** | काम कब शुरू होता है और कब तक देना है। देय तारीख से **Due today** और **Overdue** टैग तय होते हैं। |
| **Original estimate** / **Remaining estimate** | समय का अनुमान। w, d, h और m इस्तेमाल करें, जैसे `2h 30m` या `1d`। |
| **Reporter** | वह व्यक्ति जिसने टास्क उठाया। इसमें आपका नाम भरा होता है। |

### असाइनी या दूसरा ब्योरा बाद में बदलें { #change-the-assignee-or-other-details-later }

1. बोर्ड पर किसी टास्क कार्ड पर, या **Tasks** पैनल में किसी टास्क की पंक्ति पर क्लिक करें। टास्क डायलॉग खुलता है।
2. **Assignee**, **Priority**, **Due date** या कोई और फ़ील्ड बदलें।
3. **Save** पर क्लिक करें।

आप टास्क खोले बिना बोर्ड से भी असाइनी बदल सकते हैं: कार्ड पर अवतार पर क्लिक करें और किसी व्यक्ति को चुनें।

### टास्क को सबटास्क में बाँटें { #break-a-task-into-subtasks }

1. कोई ऐसा टास्क खोलें जो पहले से सेव है।
2. **Subtasks** के नीचे **Add subtask** पर क्लिक करें।
3. **Name this subtask** में सबटास्क का सारांश लिखें।
4. Enter दबाएँ, या टिक (टूलटिप **Create**) पर क्लिक करें। सबटास्क **Subtasks** टेबल में उसकी **Priority**, **Assignee** और **Status** के साथ दिखता है।

### टास्क की कॉपी बनाएँ { #copy-a-task }

1. बोर्ड पर किसी टास्क कार्ड पर माउस ले जाएँ और उसके **…** मेन्यू पर क्लिक करें।
2. **Clone** पर क्लिक करें। संदेश **Ticket cloned.** दिखता है और कॉपी बोर्ड में जुड़ जाती है।

एक बार बनने के बाद टास्क डिलीट नहीं किए जा सकते। किसी टास्क को सक्रिय बोर्ड से हटाने के लिए उसे done या cancelled कॉलम में ले जाएँ।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Create** कुछ नहीं करता और सारांश वाला बॉक्स खुल जाता है | सारांश खाली है। | सारांश लिखें, फिर दोबारा **Create** पर क्लिक करें। |
| **No ticket project is loaded.** | बोर्ड ने प्रोजेक्ट लोड करना पूरा नहीं किया, या कोई प्रोजेक्ट मौजूद नहीं है। | थोड़ा रुकें, या पहले प्रोजेक्ट बनाएँ। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)। |
| जिस व्यक्ति को आप चाहते हैं वह **Assignee** सूची में नहीं है | वह इस प्रोजेक्ट का सदस्य नहीं है। | बोर्ड पर **Add members** पर क्लिक करें और उसे जोड़ें। |
| **Save this work item before adding subtasks.** | टास्क अभी बना नहीं है। | पहले **Create** पर क्लिक करें, फिर टास्क खोलकर सबटास्क जोड़ें। |
| **Could not create ticket. Please try again.** | सेव सर्वर तक नहीं पहुँचा। | अपना कनेक्शन जाँचें और दोबारा **Create** पर क्लिक करें। |
| **Could not update assignee.** | बदलाव सेव नहीं हुआ। | बोर्ड रिफ़्रेश करें और असाइनी दोबारा चुनें। |
