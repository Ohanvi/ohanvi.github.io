# लीड फ़ॉर्म प्रबंधित करें { #manage-lead-forms }

अपने पेज से जुड़े Meta लीड फ़ॉर्म देखने के लिए **Forms** टैब खोलें। आखिर में आपकी फ़ॉर्म सूची Meta से सिंक हो जाती है, आप उसमें खोज सकते हैं, और हर फ़ॉर्म का स्टेटस, सवाल और लीड्स पढ़ सकते हैं। आप **Lead form** विज्ञापन के साथ नया फ़ॉर्म भी बना सकते हैं। इसमें करीब 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका Facebook अकाउंट, पेज और विज्ञापन अकाउंट **Setup** में कनेक्ट हों। देखें [Click-to-WhatsApp विज्ञापन चलाएँ](../click-to-whatsapp-ads.md)।
- आपने **Setup** में **Terms of Service for Lead Form Ads** स्वीकार किए हों।
- आपने कम से कम 1 **Lead form** विज्ञापन लॉन्च किया हो, या आपके पेज पर पहले से कोई लीड फ़ॉर्म हो। देखें [विज्ञापन बनाएँ](create-an-ad.md)।

## लीड फ़ॉर्म क्या है { #what-a-lead-form-is }

जब कोई आपके विज्ञापन पर टैप करता है, तो लीड फ़ॉर्म Facebook या Instagram के अंदर ही खुलता है। व्यक्ति ऐप छोड़े बिना नाम और फ़ोन जैसी जानकारी भरता है। उनके जवाब **Leads** में आते हैं। आप व्हाट्सऐप पर फ़ॉलो-अप करते हैं।

**Forms** टैब सिर्फ़ फ़ॉर्म की सूची दिखाता है और सिंक करता है। फ़ॉर्म आप तब बनाते हैं जब **Lead form** विज्ञापन बना रहे होते हैं।

| कॉलम | यह क्या दिखाता है |
|--------|---------------|
| **FORM NAME** | फ़ॉर्म का नाम। |
| **STATUS** | फ़ॉर्म का स्टेटस, जैसे **ACTIVE**। |
| **CREATED** | फ़ॉर्म बनने की तारीख। |
| **QUESTIONS** | फ़ॉर्म कितने सवाल पूछता है। |
| **LEADS** | फ़ॉर्म से कितनी लीड्स इकट्ठा हुईं। |

## चरण { #steps }

### सूची खोलें { #open-the-list }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Ads Manager** चुनें।
2. **Forms** पर क्लिक करें। फ़ॉर्म सूची खुलती है, एक बार में 25 पंक्तियाँ।

    

### Meta से ताज़ा फ़ॉर्म लाएँ { #pull-the-latest-forms-from-meta }

1. ऊपर की बार में **Sync** पर क्लिक करें। जिस पेज पर ऊपर की बार नहीं है, वहाँ बटन पर **Sync from Meta** लिखा होता है।
2. जब तक बटन पर **Syncing…** लिखा है, इंतज़ार करें।
3. टेबल जाँचें। Meta पर बनाए गए फ़ॉर्म सूची में दिखते हैं।

**Sync** पर माउस ले जाकर उसका टूलटिप देखें: **Pull the latest lead forms from the Meta ad account**।

### कोई फ़ॉर्म खोजें { #find-a-form }

1. **Search forms** बॉक्स पर क्लिक करें।
2. फ़ॉर्म के नाम का कुछ हिस्सा लिखें। आप जैसे-जैसे लिखते हैं, टेबल फ़िल्टर होती जाती है।
3. सारे फ़ॉर्म फिर से देखने के लिए बॉक्स खाली करें।

### किसी फ़ॉर्म के नतीजे जाँचें { #check-a-forms-results }

1. टेबल में फ़ॉर्म ढूँढें।
2. **STATUS** पढ़ें। **ACTIVE** का मतलब है कि फ़ॉर्म इस्तेमाल में है।
3. **QUESTIONS** पढ़ें, ताकि पता चले कि वह कितने सवाल पूछता है।
4. **LEADS** पढ़ें, ताकि पता चले कि कितने लोगों ने उसे सबमिट किया।
5. लोगों को देखने के लिए **Leads** खोलें। देखें [विज्ञापन से आई लीड्स प्रबंधित करें](manage-ad-leads.md)।

### लीड फ़ॉर्म बनाएँ { #create-a-lead-form }

1. **Create Ad** पर क्लिक करें।
2. **Ad type** के नीचे **Lead form** चुनें।
3. **Use an existing form** के नीचे **Create a new form** चुनें।
4. **What to ask for** के नीचे वह जानकारी टिक करें जो इकट्ठा करनी है। आमतौर पर नाम और फ़ोन चुने जाते हैं।
5. वैकल्पिक: **Custom survey question (optional)** लिखें, जैसे `Which course are you interested in?`।
6. अपना **Privacy policy URL** लिखें। Meta हर लीड फ़ॉर्म पर एक माँगता है।
7. विज्ञापन के बाकी सेक्शन पूरे करें।
8. **Launch Ad** पर क्लिक करें।
9. **Forms** पर लौटें और **Sync** पर क्लिक करें। नया फ़ॉर्म दिखने लगता है।

    

!!! tip "सुझाव"
    किसी फ़ॉर्म को नए विज्ञापन पर दोबारा इस्तेमाल करने के लिए, उसे **Create Ad** में **Use an existing form** के नीचे चुनें। तब लीड्स एक ही फ़ॉर्म में साथ रहती हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
|-------|-------|-----|
| **Set up now** बटन के साथ **Connect your Meta ad account** | Setup पूरा नहीं हुआ है। | **Set up now** पर क्लिक करें और **Setup** पूरा करें। |
| **No lead forms yet** | पेज पर कोई लीड फ़ॉर्म नहीं है, या सूची सिंक नहीं हुई। | **Sync** पर क्लिक करें। अगर सूची फिर भी खाली है, तो **Launch Lead Form Ad** पर क्लिक करें और एक बनाएँ। |
| **Could not load lead forms** | सूची लोड नहीं हुई। | **Retry** पर क्लिक करें। |
| **Add your privacy policy URL — Meta requires one on every lead form.** | नए फ़ॉर्म में प्राइवेसी पॉलिसी का लिंक नहीं है। | **Privacy policy URL** में किसी चालू https पेज का लिंक भरें। |
| नया फ़ॉर्म सूची में नहीं है | सूची तब लोड हुई थी जब फ़ॉर्म Meta पर था ही नहीं। | **Sync** पर क्लिक करें। |
| **LEADS** में 0 दिख रहा है | अभी तक किसी ने फ़ॉर्म सबमिट नहीं किया, या विज्ञापन अभी रिव्यू में है। | **Ads Manager** में विज्ञापन का स्टेटस जाँचें। Meta विज्ञापनों की समीक्षा करता है, आमतौर पर 24 घंटे के अंदर। |
