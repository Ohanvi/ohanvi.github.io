# Write in the task editor

The same editor sits behind a task's description and its comments. Use it to write clear tasks: headings, lists, checklists, tables, pictures and more. Press `/` to add a block, or dictate with your voice in a supported browser.

## Before you start

- You can open a task. See [Create and assign tasks](create-and-assign-tasks.md).
- To dictate, use a browser that supports speech recognition, such as Chrome. The **Voice to text** button only shows when your browser supports it.

## Where the editor appears

| Place | What you write |
| --- | --- |
| The task description | The box that reads **Add a description...** |
| A comment | The box under the task, and the **Write a reply…** box on a comment. |
| An edited comment | The box that reads **Edit comment… Enter to save · Shift + Enter for a new line.** |

## Steps

### Format text

1. Select the words you want to change.
2. Click a button on the toolbar above the box. You can also use a shortcut: `Cmd` on a Mac, or `Ctrl` on Windows and Linux.
3. Use these shortcuts:

    | Shortcut | What it does |
    | --- | --- |
    | `Cmd` or `Ctrl` + B | **Bold** |
    | `Cmd` or `Ctrl` + I | **Italic** |
    | `Cmd` or `Ctrl` + U | **Underline** |
    | `Cmd` or `Ctrl` + Shift + S | **Strikethrough** |
    | `Cmd` or `Ctrl` + `` ` `` | **Inline code** |
    | `Cmd` or `Ctrl` + K | **Insert link** |
    | `Cmd` or `Ctrl` + Z | **Undo** |
    | `Cmd` or `Ctrl` + Y | **Redo** |
    | `Cmd` or `Ctrl` + M | **Indent** |
    | `Cmd` or `Ctrl` + Shift + M | **Outdent** |

4. To remove formatting, select the text and click the clear-format button on the toolbar.

### Make a list or a checklist

1. Type `- ` and press Space to start a bullet list.
2. Type `1. ` and press Space to start a numbered list.
3. Press Enter to add the next item. The list continues on the next line.
4. To switch a line, use `Cmd` or `Ctrl` + Shift + L for a bullet list, + Shift + O for a numbered list, or + Shift + C for a checklist.
5. For a heading, type `# ` and press Space.
6. For a quote, use `Cmd` or `Ctrl` + Shift + B.
7. For a code block, use `Cmd` or `Ctrl` + Shift + `~`.

### Add a block with the plus button or a slash

1. Click the **+** button on the toolbar. Its tooltip is **Insert block  ( / )**. You can also type `/` at the start of a line.
2. Type a few letters to narrow the list. If nothing fits, it reads **No matching blocks**.
3. Pick a block:

    | Block | What it adds |
    | --- | --- |
    | **Text** | A plain paragraph. |
    | **Heading 1** | A large section heading. |
    | **Heading 2** | A medium section heading. |
    | **Heading 3** | A small section heading. |
    | **Bulleted list** | An unordered list. |
    | **Numbered list** | An ordered list. |
    | **Task list** | A checklist with checkboxes. |
    | **Quote** | A block quote. |
    | **Code block** | Monospace code. |
    | **Panel** | An info or warning callout box. |

### Add a coloured panel

1. Add a **Panel** block. A box appears that reads **Empty panel — tap to edit**.
2. Click the box. A window opens.
3. Pick the type: **Info**, **Success**, **Warning** or **Error**.
4. Type the text, then save.

### Insert a table

1. Click the grid button on the toolbar. Its tooltip is **Insert Grid**. The window **Insert Grid (Table)** opens.
2. Drag the **Columns** slider. You can pick from 1 to 10.
3. Drag the **Rows** slider. You can pick from 1 to 15.
4. Click **Insert**. A 3 by 3 table is the starting size.
5. Click the table to change it. The window **Edit Grid** opens.
6. Type in the cells. The top row holds the headers.
7. Click **Add Row**, **Remove Row**, **Add Column** or **Remove Column** to change its size.
8. Click **Delete Table** to remove it, **Cancel** to leave it, or **Save** to keep your changes.

### Mention a person

1. Click the **@** button, tooltip **Mention**, or type `@`.
2. Type a name. If nobody fits, it reads **No matching people**.
3. Pick the person. They are notified. See [Comment, mention and attach files](collaborate-on-tasks.md).

### Add an emoji

1. Click the smile button. Its tooltip is **Emoji**.
2. Click an emoji in the grid. It lands at your cursor.

### Add a picture

1. To paste, copy an image, click in the box, and press `Cmd` or `Ctrl` + V. The picture lands in the text. If you paste a document instead, it becomes an attachment.
2. To pick a file, click the image button on the toolbar and choose a picture.
3. Click the picture. It opens full size, with **Copy** and **Download**.
4. Press and hold the picture, or right-click it, to open a menu: **Open preview**, **Copy image**, **Download** and **Delete Image**.
5. After **Copy image**, the message **Image copied — paste it anywhere** appears.

### Dictate with your voice

1. Click in the box where you want the text.
2. Click the microphone button. Its tooltip is **Voice to text**. Allow the microphone if your browser asks.
3. Speak a sentence. The text appears at your cursor. Dictation listens for English (US).
4. Click the button again to stop. While it listens, the tooltip reads **Stop dictation** and the icon turns red.

### Show more or fewer tools

1. If the toolbar is crowded, click **More tools** to show every row.
2. Click **Fewer tools** to fold it back.

### Save, and see every shortcut

1. Press `Cmd` or `Ctrl` + Enter to save.
2. Press `Cmd` or `Ctrl` + `/`, or click the keyboard button, to open **Editor shortcuts**.
3. Read the groups: **Text formatting**, **Lists and blocks**, **Editing** and **Files and saving**.
4. Click **Close**.

!!! tip "Comments save differently"
    In a comment you are editing, press Enter to save. Press Shift + Enter for a new line.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| There is no microphone button. | Your browser does not support speech recognition. | Use a recent Chrome, or type instead. |
| Dictation types nothing. | The microphone is blocked, or you spoke before it started. | Allow the microphone, then click the button and speak. |
| **No matching blocks** | Your letters match no block. | Delete a letter, or clear the text after `/`. |
| **No matching people** | Nobody on the project matches. | Check the spelling, or add the person to the project. |
| The table shows **Invalid grid data**. | The table data could not be read. | Delete the table and insert it again. |
| A picture does not paste. | The browser would not give the image to the page. | Use the image button instead. |
