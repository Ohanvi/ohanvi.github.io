# सब्सक्रिप्शन विषय (टॉपिक) बनाएँ { #create-subscription-topics }

टॉपिक ईमेल की एक श्रेणी है, जैसे **Weekly offers** या **Product news**। लोग पूरी लिस्ट छोड़े बिना किसी एक टॉपिक से ऑप्ट-आउट कर सकते हैं। आख़िर में आपके पास ऐसे टॉपिक होंगे जिन्हें कैंपेन इस्तेमाल कर सकते हैं और संपर्क जिनसे ऑप्ट-आउट कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको **Email** पैनल में **Manage** दिखता हो। न दिखे तो अपने एडमिन से पूछें।
- आप जानते हों कि आप किस तरह के ईमेल भेजते हैं, जैसे ऑफ़र, खबरें और रसीदें।

## चरण { #steps }

### टॉपिक की सूची खोलें { #open-the-topic-list }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Manage** चुनें।
2. **Topics** चुनें। पेज का शीर्षक **Topics** होता है।
3. अगर कोई टॉपिक नहीं है, तो पेज पर लिखा होता है: **Subscription categories contacts can opt out of individually on your preference centre.** नहीं तो वह आपके टॉपिक गिनकर दिखाता है।
4. **Topic Name**, **Description**, **Created On** और **Status** कॉलम पढ़ें।

### टॉपिक बनाएँ { #create-a-topic }

1. **Add** पर क्लिक करें। जोड़ने का फ़ॉर्म खुलता है।
2. **Topic Name** में एक छोटा नाम लिखें जिसे लोग पहचानें, जैसे `Weekly offers`। यह ज़रूरी है।
3. वैकल्पिक: **Description** में बताएँ कि यह टॉपिक क्या भेजता है।
4. फ़ॉर्म सेव करें। टॉपिक सूची में दिखने लगता है।

### देखें कि टॉपिक कहाँ इस्तेमाल हुआ है { #see-where-a-topic-is-used }

1. किसी टॉपिक की पंक्ति पर **View Details** पर क्लिक करें। **Topic Details** डायलॉग खुलता है। उसे बड़ा करने के लिए मैक्सिमाइज़ बटन पर क्लिक करें, और छोटा करने के लिए **Restore** पर।
2. **Record Status**, **Used In** और **Opted Out** पढ़ें। **Used In** उन कैंपेन की सूची देता है जो इस टॉपिक का इस्तेमाल करते हैं। अगर कोई नहीं करता, तो लिखा आता है **Not used by any campaign yet.**
3. इसे किसने और कब बनाया, यह जानने के लिए **Record Info** पढ़ें।
4. पहले के बदलाव देखने के लिए **History** खोलें। अगर कोई नहीं है, तो लिखा आता है **No revision history available.**

### टॉपिक इस्तेमाल करें { #use-a-topic }

1. कैंपेन बनाते समय उसे टॉपिक से टैग करें। जिस संपर्क ने किसी टॉपिक से ऑप्ट-आउट नहीं किया है, वह डिफ़ॉल्ट रूप से उसका सब्सक्राइबर होता है।
2. किसी लिस्ट को डिफ़ॉल्ट रूप से टॉपिक देने के लिए, लिस्ट खोलें और **Default Topic** सेट करें। देखें [ईमेल ग्रुप का इस्तेमाल करें](use-email-groups.md)।

### टॉपिक एडिट या डिलीट करें { #edit-or-delete-a-topic }

1. पंक्ति पर **Edit** पर क्लिक करें, नाम या विवरण बदलें और सेव करें।
2. टॉपिक हटाने के लिए **Delete** पर क्लिक करें और पुष्टि करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Used In** में गड़बड़ी दिखती है। | कैंपेन लोड नहीं हो सके। | डायलॉग बंद करें और दोबारा खोलें। |
| ऑप्ट-आउट करने के बाद भी लोगों को टॉपिक मिल रहा है। | कैंपेन को उस टॉपिक से टैग नहीं किया गया था। | भेजने से पहले कैंपेन को टॉपिक से टैग करें। |
| आपको **Topics** नहीं मिल रहा। | यह मुख्य पैनल में नहीं, **Manage** के अंदर होता है। | पहले **Manage** खोलें। |
