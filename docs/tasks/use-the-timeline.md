# Use the Timeline

The **Timeline** shows your tasks as bars on a calendar, from start date to due date. Use it to see what overlaps, what is late and how parent tasks and their children line up. You read it here and edit tasks elsewhere.

## Before you start

- You can open the task board. See [Set up a task project](set-up-task-project.md).
- Your tasks have a start date or a due date. A task with neither does not appear. See [Create and assign tasks](create-and-assign-tasks.md).

## Steps

### Open the Timeline

1. Click **Tasks** in the right-hand rail, then click **Board**.
2. In the view switcher at the top, click **Timeline**.
3. If the page reads **No work items yet. Create tickets (and set a start / due date)**, add dates to your tasks first.
4. If it reads **No project selected**, pick a project from the board header.

### Change the time scale

1. Look at the buttons at the top right of the Timeline.
2. Click **Weeks**, **Months** or **Quarters**. The header and the bars redraw.
3. Click **Today** to scroll to today's date. Today is marked in the date header.

### Read a row

1. Read the **Work** column on the left. Each row is one task.
2. Find the bar on the right. It runs from the task's start date to its due date.
3. Read the bar colour. It changes with the task's status.
4. Hover a bar to see its start and end dates.
5. On a parent row, read the count, for example **Done: 2 of 5**. It shows how many child tasks are finished.

### Expand and collapse parent tasks

1. Find a row that has children. It has an arrow.
2. Click the arrow to show its child tasks under it. The arrow shows the tooltip **Expand**.
3. Click the arrow again to hide them. The tooltip reads **Collapse**.

### Select rows

1. Tick the box at the start of a row to select that task.
2. Notice that its children are ticked too, and their boxes are locked.
3. Untick the parent to clear the whole group.

### Widen the Work column

1. Move your pointer over the line between the **Work** column and the calendar.
2. When the pointer changes to a left-right arrow, drag the line.
3. Release when the column is the width you want. The width stays between 200 and 800 pixels.

### Start a child task from a row

1. Hover a top-level task row. Two small buttons appear at its right.
2. Click the **+** button. Its tooltip is **Create child work item**. A new row opens under the task.
3. Click the type button, tooltip **Select issue type**, to pick the type. The default is a story.
4. Type the title in **What needs to be done?**.
5. Pick an assignee with the person button at the end of the row.
6. The row has no save button, and **Enter** does not create the task. Create child tasks from the board for now.

### Open the More actions menu

1. Hover a row and click the **...** button. Its tooltip is **More actions**.
2. Read the menu: **Create work item**, **Move work item**, **Change work item color**, **Edit dates** and **Edit dependencies**.
3. Choosing an item does nothing yet. Change dates and parents from the task's details instead.

!!! note "The Timeline is for reading"
    You cannot drag a bar to change dates. Open the task and change **Start date** and **Due date** there.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **No work items yet. Create tickets (and set a start / due date)** | No task has a start or due date. | Open a task and set its dates. |
| **No project selected** | No project is open on the board. | Pick a project in the board header. |
| **Failed to load timeline** | The Timeline could not load. | Switch to another view and back, or reload the page. |
| A task is missing from the Timeline. | It has no start date and no due date. | Add a date to the task. |
| The **More actions** menu does nothing. | The menu items are not active yet. | Edit the task from its details window. |
