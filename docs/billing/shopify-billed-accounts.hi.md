# Shopify से बिल होने वाला प्लान मैनेज करें { #manage-a-plan-billed-through-shopify }

अगर आपने Ohanvi को Shopify से इंस्टॉल किया है, तो आपके प्लान का बिल Ohanvi नहीं, Shopify बनाता है। प्लान बदलना या कैंसिल करना Shopify में ही होता है। क्रेडिट और इस्तेमाल Ohanvi में पहले की तरह चलते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका वर्कस्पेस Shopify App Store से बना है।
- आप अपने Shopify एडमिन में साइन इन कर सकते हैं। इसके लिए आप स्टोर ओनर हों, या ऐसे स्टाफ़ मेंबर हों जो ऐप्स मैनेज कर सकता है।

## क्या बदल जाता है { #what-changes }

| पेज | Shopify से बिल होने वाले अकाउंट में दिखता है? |
| --- | --- |
| **Plans & Pricing** | नहीं |
| **Billing** | नहीं |
| **Invoice Details** | नहीं |
| **Credits** | हाँ |
| **Current Usage** | हाँ |

## स्टेप { #steps }

### अपना प्लान बदलें या कैंसिल करें { #change-or-cancel-your-plan }

1. Ohanvi में प्लान पेज खोलें और **Manage plan in Shopify** पर क्लिक करें। Shopify खुलेगा।
2. अगर Shopify नहीं खुलता, तो मैसेज में लिखा आता है कि आपके प्लान का बिल Shopify बनाता है और प्लान पेज नहीं खुल सका। मैसेज में जो रास्ता दिया है, उस पर जाएँ: **Settings → Apps and sales channels → Ohanvi**।
3. Shopify में प्लान बदलें या कैंसिल करें।

### क्रेडिट रीचार्ज करें { #recharge-credits }

1. Ohanvi में **Credits** खोलें और पहले की तरह रीचार्ज करें। देखें [अपने अकाउंट में पैसे जोड़ें](../add-funds.md)।
