# अपॉइंटमेंट { #appointments }

Appointments से आपके ग्राहक WhatsApp पर आपकी सर्विस बुक कर सकते हैं। आपकी टीम इन बुकिंग को कन्फ़र्म करने, आगे-पीछे करने और बंद करने का सारा काम एक ही जगह से करती है।

## यह कहाँ मिलेगा { #where-to-find-it }

लेफ़्ट रेल में **Appts** खोलें। उस पर माउस ले जाने से नाम **Appointments** दिखता है। पैनल में **Appointments**, **Services**, **Classes** और **Providers** की लिस्ट मिलती है।

बुकिंग के नियम और रिमाइंडर इस पैनल में नहीं हैं। नीचे बाईं ओर अपने नाम के पहले अक्षर पर क्लिक करें, फिर **Settings** → **Appointments** → **Booking Rules** चुनें।

## शुरू करने से पहले { #before-you-start }

- आपके रोल को Appointments का एक्सेस मिला हो।
- आपका WhatsApp नंबर कनेक्ट हो। बुकिंग, काम के घंटे, रिमाइंडर और ग्राहकों के मैसेज, सब इसी नंबर से चलते हैं।
- आपके पास कम से कम 1 सर्विस और 1 प्रोवाइडर हो। जब तक दोनों नहीं बनते, ग्राहकों को कोई समय नहीं दिखेगा।
