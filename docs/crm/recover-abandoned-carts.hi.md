# Commerce leads से छोड़ी गई कार्ट वापस पाएँ { #recover-abandoned-carts-with-commerce-leads }

वे सभी खरीदार देखें जो आपके ऑनलाइन स्टोर से बिना भुगतान किए चले गए, और हर एक को उसकी कार्ट का लिंक देकर व्हाट्सऐप रिमाइंडर भेजें। आखिर में आपके पास हफ़्ते भर में वापस पाई गई कार्ट की गिनती और वापस जीती गई रकम होती है। पहली कार्ट पर आज़माने के लिए 10 मिनट रखें।

## शुरू करने से पहले { #before-you-start }

- **Connect** → **Store Connections** में Shopify या WooCommerce स्टोर कनेक्ट हो। जब तक नहीं है, स्क्रीन पर **No store connected** लिखा आता है।
- आपका व्हाट्सऐप नंबर कनेक्ट हो। देखें [अपना व्हाट्सऐप नंबर कनेक्ट करें](../whatsapp/connect-whatsapp-number.md)।
- आपके पास CRM लीड्स का एक्सेस हो। कॉमर्स लीड एक सामान्य लीड ही है, जिसका सोर्स कोई स्टोर होता है।

## स्क्रीन पर क्या दिखता है { #what-the-screen-shows }

| टाइल | क्या गिनती है |
| --- | --- |
| **Abandoned Carts** | पिछले 7 दिनों में छोड़ी गई कार्ट। |
| **Potential Revenue** | उन कार्ट की कुल कीमत, अगर हर एक वापस मिल जाए। |
| **Recovered This Week** | इस हफ़्ते जो कार्ट बिक्री में बदलीं, और वापस जीती गई रकम। |
| **Recovery Rate** | व्हाट्सऐप रिमाइंडर से वापस मिली कार्ट का हिस्सा। जिस हफ़्ते कोई कार्ट नहीं होती, यह **—** दिखाता है। |

## चरण { #steps }

### Commerce Leads स्क्रीन खोलें { #open-the-commerce-leads-screen }

1. लेफ़्ट रेल में **Home** खोलें और **Workspace** में **Abandoned Carts** कार्ड ढूँढें।
2. **Work the carts** पर क्लिक करें। **Commerce Leads** स्क्रीन खुलती है। इसका सबटाइटल है **Abandoned carts from your WooCommerce/Shopify store — recover them on WhatsApp**।

आप इसे **Sales reports** से भी खोल सकते हैं। **Ctrl K** दबाएँ (Mac पर **⌘K**), **Sales reports** लिखें, उसे चुनें, और ऊपर की **Commerce Leads** पट्टी पर क्लिक करें। यह पट्टी छोड़ी गई कार्ट, संभावित रेवेन्यू और आज की रिकवरी दिखाती है।

अगर कोई कार्ट नहीं है, तो स्क्रीन पर **No abandoned carts yet** लिखा आता है। खरीदारों के बिना चेकआउट किए जाते ही कार्ट सिंक होकर आ जाती हैं।

### कार्ट पढ़ें { #read-a-cart }

1. सूची में खरीदार को ढूँढें। हर पंक्ति में खरीदार, स्टोर का प्लेटफ़ॉर्म, कार्ट की कीमत, प्राथमिकता और कार्ट छोड़े हुए कितना समय हुआ, यह दिखता है।
2. पंक्ति पर क्लिक करें। खरीदार की विंडो 3 टैब के साथ खुलती है: **Overview**, **Cart** और **Notes & Activities**।
3. कार्ट के प्रोडक्ट देखने के लिए **Cart** खोलें।
4. इस खरीदार की कार्ट खोलने वाला लिंक कॉपी करने के लिए **Copy resume-cart link** पर क्लिक करें। संदेश **Resume-cart link copied** दिखता है।

### एक रिमाइंडर भेजें { #send-one-reminder }

1. पंक्ति में **Nudge** पर क्लिक करें।
2. व्हाट्सऐप खुलता है, जिसमें यह संदेश भरा होता है: **Hi! You left something in your cart — here's your link to finish up:** और खरीदार का लिंक।
3. व्हाट्सऐप में भेजें दबाएँ। Ohanvi में संदेश **Recovery message to …** दिखता है।

अगर कार्ट में फ़ोन नंबर नहीं है, तो संदेश **No phone number on this cart to nudge.** दिखता है। अगर व्हाट्सऐप नहीं खुलता, तो **Couldn't open WhatsApp.** दिखता है।

### सबको रिमाइंडर भेजें { #send-reminders-to-everyone }

1. ऊपर **Recover all** पर क्लिक करें। जब कोई कार्ट खुली न हो, तो यह बटन बंद रहता है।
2. व्हाट्सऐप ब्रॉडकास्ट कंपोज़र खुलता है। वहाँ अपनी ऑडियंस और एक Approved टेम्प्लेट चुनें। देखें [ब्रॉडकास्ट कैंपेन भेजें](../whatsapp/send-broadcast-campaign.md)।

### कार्ट एक्सपोर्ट करें { #export-the-carts }

1. **Export** पर क्लिक करें।
2. Ohanvi स्टोर लीड्स की Excel फ़ाइल डाउनलोड करता है। संदेश **Exported.** दिखता है।

### कार्ट को किसी भी दूसरी लीड की तरह संभालें { #work-a-cart-like-any-other-lead }

1. कॉल या नोट दर्ज करने के लिए कार्ट का **Notes & Activities** टैब खोलें।
2. ग्रिड व्यू में पंक्ति पर **Move Status** और **Convert** वैसे ही इस्तेमाल करें जैसे बाकी लीड्स पर करते हैं। देखें [लीड्स के साथ काम करें](leads.md)।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No store connected** | कोई Shopify या WooCommerce स्टोर जुड़ा नहीं है। | **Connect** → **Store Connections** में एक स्टोर कनेक्ट करें। |
| **No abandoned carts yet** | आपका स्टोर कनेक्ट है, पर अभी किसी ने कार्ट नहीं छोड़ी। | इंतज़ार करें। खरीदारों के जाते ही कार्ट दिखने लगती हैं। |
| **Couldn't load commerce leads** | सूची लोड नहीं हुई। | रीफ़्रेश करें, और जाँचें कि स्टोर कनेक्शन ठीक चल रहा है। |
| **No phone number on this cart to nudge.** | खरीदार ने फ़ोन नंबर नहीं छोड़ा। | कार्ट खोलें और इसके बजाय ईमेल इस्तेमाल करें। |
