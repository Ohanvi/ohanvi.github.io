# Publish के फ़िल्टर, ओवरव्यू और पोस्ट का ब्योरा { #use-publish-filters-overview-and-post-details }

यह पेज **Publish** के छोटे हिस्सों के बारे में है: चैनल फ़िल्टर, साइड पैनल, हर पोस्ट के मेन्यू और ब्योरे वाली विंडो। आप कोई भी पोस्ट खोज सकते हैं, नेटवर्क पर उसका लिंक कॉपी कर सकते हैं, देख सकते हैं कि कौन-सा चैनल फ़ेल हुआ, और किसी पोस्ट की कॉपी बनाकर दोबारा इस्तेमाल कर सकते हैं। इसमें करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखता हो, और उसके पैनल में **Publish** हो।
- कम से कम एक नेटवर्क कनेक्ट हो, और आपने कम से कम एक पोस्ट बनाई हो। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## चरण { #steps }

### टैब और गिनती पढ़ें { #read-the-tabs-and-counts }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. टैब देखें: **Queue**, **Drafts**, **Approvals** और **Sent**। हर टैब दिखाता है कि उसमें कितनी पोस्ट हैं।
3. व्यू बदलने के लिए **List** या **Calendar** पर क्लिक करें। कैलेंडर के लिए देखें [पोस्ट शेड्यूल करें और क्यू संभालें](schedule-social-posts.md)।
4. अगर कोई टैब खाली है, तो उसमें **No … posts yet.** लिखा होता है।
5. पोस्ट दोबारा लोड करने के लिए रिफ़्रेश आइकन पर क्लिक करें।

### पहली बार शुरू करें { #start-for-the-first-time }

अगर कोई चैनल कनेक्ट नहीं है, तो **Publish** में **Welcome to Publish** दिखता है।

1. अपना पहला नेटवर्क कनेक्ट करने के लिए **Connect a Channel** पर क्लिक करें। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
2. या पहले टीम के सदस्यों को जोड़ने के लिए **Invite your Team** पर क्लिक करें।

### चैनल के हिसाब से फ़िल्टर करें { #filter-by-channel }

1. फ़िल्टर वाली पंक्ति में **Channels** पर क्लिक करें। छोटी स्क्रीन पर पहले **Filters** पर क्लिक करें।
2. कोई चैनल खोजने के लिए **Search channels** में टाइप करें।
3. जो चैनल चाहिए उन पर टिक लगाएँ। हर चैनल पर टिक लगाने के लिए **Select all** पर क्लिक करें।
4. अगर कोई चैनल मेल नहीं खाता, तो सूची में **No channels found** लिखा आता है। एक जोड़ने के लिए **Connect a Channel** पर क्लिक करें।
5. अब सूची और गिनती सिर्फ़ उन्हीं चैनलों की दिखती है।

### Tags और Timezone फ़िल्टर देखें { #check-the-tags-and-timezone-filters }

1. **Tags** पर क्लिक करें। उसमें **No tags** और **Use tags to organise your content** लिखा है। टैग अभी चुनने के लिए उपलब्ध नहीं हैं।
2. **Timezone** पर क्लिक करें। उसमें **Based on this device — per-user timezones are coming soon.** लिखा है। पोस्ट का समय आपके डिवाइस के हिसाब से चलता है।

### बिना तारीख वाले ड्राफ़्ट खोजें { #find-drafts-with-no-date }

1. **Calendar** व्यू में **No Date** पर क्लिक करें।
2. **Undated drafts** पढ़ें। इसमें वे ड्राफ़्ट और अप्रूवल दिखते हैं जिनकी कोई शेड्यूल तारीख नहीं है।
3. अगर कोई नहीं है, तो **No Undated Drafts** लिखा आता है।

### Publishing Overview पढ़ें { #read-the-publishing-overview }

1. **Publish** के दाईं ओर का पैनल देखें।
2. **Publishing Overview** के नीचे **This Week** पढ़ें। यह **Queued**, **Drafts**, **Published** और **Failed** गिनता है।
3. वह लाइन पढ़ें जो बताती है कि इस हफ़्ते आपकी कितने प्रतिशत पोस्ट सफलतापूर्वक पब्लिश हुईं।

### Quick Actions इस्तेमाल करें { #use-quick-actions }

1. उसी पैनल में **Quick Actions** खोजें।
2. कंपोज़र खोलने के लिए **Create Post** पर क्लिक करें।
3. **Templates** खोलने के लिए **Create from Template** पर क्लिक करें। देखें [पोस्ट टेम्प्लेट का इस्तेमाल करें](use-post-templates.md)।
4. कैलेंडर पर जाने के लिए **View Calendar** पर क्लिक करें।
5. **Bulk Schedule** और **Media Library** एक संदेश दिखाते हैं कि वे जल्द आ रहे हैं।

### पोस्ट का मेन्यू इस्तेमाल करें { #use-the-menu-on-a-post }

1. किसी पोस्ट पर **⋯** मेन्यू पर क्लिक करें।
2. **Queue** की पोस्ट पर आप **Publish Now** या **Cancel schedule** पर क्लिक कर सकते हैं।
3. किसी भी पोस्ट पर, ऐसी कॉपी बनाने के लिए **Duplicate** पर क्लिक करें जिसे आप एडिट करके दोबारा भेज सकें।
4. उसे हटाने के लिए **Delete** पर क्लिक करें।
5. **Sent** पोस्ट पर आप **Post Details** या **Copy link** पर भी क्लिक कर सकते हैं।
6. नेटवर्क पर पोस्ट का लिंक कॉपी करने के लिए **Copy link** पर क्लिक करें। संदेश **Link copied.** दिखता है। अगर पोस्ट का अभी कोई लिंक नहीं है, तो **No published link available yet.** लिखा आता है।

### पोस्ट का ब्योरा खोलें { #open-the-post-details }

1. **Sent** पोस्ट पर **⋯** पर क्लिक करें, फिर **Post Details** पर।
2. टाइटल में **Published on** और तारीख लिखी होती है।
3. चैनल और पोस्ट का टेक्स्ट पढ़ें। मीडिया नीचे एक पट्टी में दिखता है।
4. **Channels** के नीचे पढ़ें कि किस नेटवर्क पर पब्लिश हुआ और किस पर फ़ेल। फ़ेल हुए नेटवर्क के साथ उसकी एरर दिखती है।
5. पोस्ट के आँकड़ों की पंक्ति पढ़ें।
6. नेटवर्क पर पोस्ट खोलने के लिए **Go to post** पर क्लिक करें। अगर अभी कोई लिंक नहीं है, तो **No published link available yet.** लिखा आता है।

### एक पोस्ट का एनालिटिक्स देखें { #see-the-analytics-of-one-post }

1. जो **Sent** पोस्ट फ़ेल नहीं हुई, उस पर **View Analytics** पर क्लिक करें। फ़ेल हुई पोस्ट पर इसकी जगह **Retry** दिखता है।
2. **Post Analytics** विंडो खुलती है, जिसमें हर नेटवर्क की एक पंक्ति होती है।
3. अगर अभी कोई आँकड़े नहीं हैं, तो **No published targets for this post yet.** लिखा आता है।
4. काम पूरा होने पर **Close** पर क्लिक करें।

### शेड्यूल की गई पोस्ट रद्द करें { #cancel-a-scheduled-post }

1. **Queue** की पोस्ट पर **⋯** पर क्लिक करें, फिर **Cancel schedule** पर।
2. **Cancel this scheduled post?** में पक्का करने के लिए **Cancel schedule** पर क्लिक करें, या उसे जैसा है वैसा रखने के लिए **Keep scheduled** पर।

### फ़ीडबैक भेजें { #send-feedback }

1. **Publish** के ऊपर **Share Feedback** पर क्लिक करें।
2. अपने विचार लिखें और **Submit** पर क्लिक करें, या बाहर निकलने के लिए **Close** पर।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Welcome to Publish** दिखता है | कोई चैनल कनेक्ट नहीं है। | **Connect a Channel** पर क्लिक करें। |
| **No channels found** | आपकी खोज से कुछ मेल नहीं खाता, या कुछ भी कनेक्ट नहीं है। | खोज साफ़ करें, या कोई चैनल कनेक्ट करें। |
| **No published link available yet.** | नेटवर्क ने अभी लिंक वापस नहीं भेजा। | एक मिनट रुकें और फिर कोशिश करें। |
| **Bulk Schedule** या **Media Library** सिर्फ़ एक संदेश दिखाते हैं | वे अभी बने नहीं हैं। | पोस्ट एक-एक करके शेड्यूल करें। |
| **Tags** में **No tags** लिखा है | अभी टैग जोड़े नहीं जा सकते। | कोई समाधान नहीं। |
