# Create and send an email campaign

Build a campaign, select a segment, test the message, and track opens and clicks.

## Steps

1. Open **Email Marketing**.
2. Choose **New campaign**.
3. Add subject, sender name, preview text, and campaign tags.
4. Select a template or start with a blank email.
5. Choose an audience segment and suppression list.
6. Send a test email.
7. Review all links and dynamic fields.
8. Schedule the campaign or send it now.

## Pre-send checks

- All links open correctly.
- Unsubscribe footer is present.
- Sender domain authentication is healthy.
- Preview text is clear on mobile.
- The selected audience segment is correct.
