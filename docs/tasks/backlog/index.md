# Backlog

The **Backlog** view lists tasks that are not in a sprint yet, with your sprints above them. Use it to add and tidy tasks, then plan them into sprints.

**Where to find it:** click **Tasks** in the right-hand rail, click **Board**, then click **Backlog** in the view switcher.

## Guides

| Guide | Use it when |
| --- | --- |
| [Work with items in the Backlog](../work-with-the-backlog.md) | You want to add, rename, reassign or drag tasks. |
| [Plan work in sprints](../plan-sprints.md) | You want to create, start and complete sprints. |

## Before you start

- You can open the task board. See [Set up a task project](../set-up-task-project.md).
- Your project has at least 1 board column.
