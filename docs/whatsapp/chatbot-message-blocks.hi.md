# चैटबॉट में मीडिया, कैटलॉग, प्रोडक्ट, टेम्प्लेट और फ़ॉर्म ब्लॉक जोड़ें { #add-media-catalogue-product-template-and-form-blocks-to-a-chatbot }

चैटबॉट फ़्लो में सादे टेक्स्ट से आगे के मैसेज ब्लॉक जोड़ें। अंत में आपका बॉट फ़ाइल, आपका कैटलॉग, एक प्रोडक्ट, प्रोडक्ट्स का समूह, approved टेम्प्लेट या व्हाट्सऐप के अंदर खुलने वाला फ़ॉर्म भेज सकेगा।

## शुरू करने से पहले { #before-you-start }

- बिल्डर में आपका एक चैटबॉट फ़्लो खुला है। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)।
- **Catalogue**, **Single product** और **Multi product** के लिए आपके नंबर से एक प्रोडक्ट कैटलॉग कनेक्ट है। देखें [अपना व्हाट्सऐप कैटलॉग सेट करें](set-up-whatsapp-catalog.md)।
- **Template** के लिए आपके पास स्टेटस **Approved** वाला कम से कम 1 टेम्प्लेट है। देखें [व्हाट्सऐप मैसेज टेम्प्लेट बनाएँ](create-message-template.md)।
- **WhatsApp Form** के लिए आपके पास एक पब्लिश किया हुआ फ़ॉर्म है।

## मैसेज ब्लॉक कैसे काम करते हैं { #how-message-blocks-work }

फ़्लो कार्ड में एक या ज़्यादा ब्लॉक होते हैं। हर ब्लॉक बॉट का भेजा हुआ एक मैसेज है। नीचे के सभी ब्लॉक चरणों की सूची के **Message types** समूह में हैं।

| ब्लॉक | ग्राहक को क्या मिलता है |
| --- | --- |
| **Text** | सादा मैसेज, जिसमें 3 तक रिप्लाई बटन हो सकते हैं। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)। |
| **List / Buttons** | टैप करने के विकल्पों वाला मैसेज। देखें [व्हाट्सऐप चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)। |
| **Media** | इमेज, वीडियो, डॉक्यूमेंट या ऑडियो फ़ाइल, कैप्शन और 3 तक बटन के साथ। |
| **Catalogue** | आपका पूरा कैटलॉग। |
| **Single product** | आपके कैटलॉग का एक प्रोडक्ट। |
| **Multi product** | सेक्शन में बँटे प्रोडक्ट्स का एक सेट। |
| **Template** | एक approved टेम्प्लेट। |
| **WhatsApp Form** | एक फ़ॉर्म जिसे ग्राहक चैट छोड़े बिना भरता है। |

## चरण { #steps }

### कार्ड में ब्लॉक जोड़ें { #add-a-block-to-a-card }

1. बिल्डर में अपना फ़्लो खोलें।

    ![फ़्लो बिल्डर, जिसमें बाईं ओर कैनवास और दाईं ओर Step पैनल है, और Add a step, Triggers और Message types दिख रहे हैं](../assets/screenshots/whatsapp-chatbot-1-builder.png)

2. किसी चरण के बगल में **+** पर क्लिक करें, या कार्ड के नीचे **+ Add Content** पर क्लिक करें।
3. **All steps** चुनें।
4. **Message types** के नीचे अपनी पसंद का ब्लॉक चुनें।

    ![Step पैनल, जिसमें List / Buttons, Catalogue, Single product, Multi product, Template और WhatsApp Form मैसेज प्रकार और Ask the customer समूह दिख रहे हैं](../assets/screenshots/whatsapp-chatbot-2-message-and-ask-blocks.png)

5. कार्ड में ब्लॉक पर क्लिक करें ताकि उसके फ़ील्ड दाईं ओर के पैनल में खुलें।

!!! note "मैसेज ब्लॉक पर कीवर्ड"
    ज़्यादातर मैसेज ब्लॉक में सबसे पहले **Type, press enter to add AI keyword** फ़ील्ड होती है। शब्द लिखें और जोड़ने के लिए **Enter** दबाएँ। [VERIFY: what AI keywords change in the flow]

### मीडिया भेजें { #send-media }

1. **Media** ब्लॉक जोड़ें।
2. **Select media type** के नीचे पंक्ति पर क्लिक करके **IMAGE**, **VIDEO**, **DOCUMENT** और **AUDIO** के बीच बदलें।
3. अपलोड बॉक्स में फ़ाइल ब्राउज़ करें, या पेस्ट करें। वेब पर पेस्ट करने के लिए **Ctrl+V** दबाएँ।
4. प्रीव्यू दिखने तक रुकें। Ohanvi फ़ाइल आपके लिए सेव कर लेता है।
5. **Caption...** लिखें। इसमें 1,024 अक्षर तक आ सकते हैं।
6. वैकल्पिक: **+ Add Button** पर क्लिक करें और हर रिप्लाई बटन का लेबल लिखें।
7. वैकल्पिक: **Set Delay** और **Set Timeout** सेट करें। देखें [डिले और टाइमआउट](#set-a-delay-and-a-timeout)।

बटन की सीमाएँ:

- **Media** ब्लॉक पर 3 तक बटन।
- बटन के लेबल 20 अक्षर तक।
- 3 बटन होने पर **+ Add Button** वाली पंक्ति गायब हो जाती है।

!!! tip "फ़ाइल क्यों सेव की जाती है"
    बिल्डर आपकी फ़ाइल की अपनी एक कॉपी रखता है। जो बातचीत इस चरण तक कई दिन बाद पहुँचती है, उसे भी फ़ाइल भेज दी जाती है।

### अपना पूरा कैटलॉग भेजें { #send-your-whole-catalogue }

1. **Catalogue** ब्लॉक जोड़ें।
2. **Body** लिखें। इसमें 1,024 अक्षर तक आ सकते हैं।
3. वैकल्पिक: **Footer** लिखें, 60 अक्षर तक।

### एक प्रोडक्ट भेजें { #send-one-product }

1. **Single product** ब्लॉक जोड़ें।
2. **+ Add Product** पर क्लिक करें। **Choose a product** सूची खुलती है।
3. सूची से कोई प्रोडक्ट चुनें।
4. **Body** लिखें, 1,024 अक्षर तक।
5. वैकल्पिक: **Footer** लिखें, 60 अक्षर तक।

अगर सूची में **No product catalogue is connected.** दिखता है, तो पहले कैटलॉग कनेक्ट करें।

### प्रोडक्ट्स का समूह भेजें { #send-a-group-of-products }

1. **Multi product** ब्लॉक जोड़ें।
2. **Header** लिखें। इसमें 20 अक्षर तक आ सकते हैं।
3. **Body** लिखें। इसमें 1,024 अक्षर तक आ सकते हैं।
4. वैकल्पिक: **Footer** लिखें, 60 अक्षर तक।
5. प्रोडक्ट्स का समूह जोड़ने के लिए **+ Add Section** पर क्लिक करें। [VERIFY: how products are chosen inside each section]
6. कार्ड पर **View Items** बटन दिखता है। इसके शब्द व्हाट्सऐप तय करता है, इसलिए आप उसे बदल नहीं सकते।

एक मल्टी-प्रोडक्ट मैसेज में 10 तक आइटम हो सकते हैं।

### approved टेम्प्लेट भेजें { #send-an-approved-template }

1. **Template** ब्लॉक जोड़ें।
2. **Select Template** पर क्लिक करें। **Choose a template** सूची खुलती है।
3. कोई टेम्प्लेट चुनें। सिर्फ़ approved टेम्प्लेट दिखते हैं।
4. अगर टेम्प्लेट में तस्वीर, वीडियो या डॉक्यूमेंट हेडर है, तो **Header media, shown by Meta** खोजें।
5. हेडर का प्रकार चुनने के लिए पंक्ति पर क्लिक करें। डिफ़ॉल्ट **Image** है।
6. हेडर के लिए फ़ाइल अपलोड करें।

ब्लॉक से चीज़ें हटाने के लिए:

- टेम्प्लेट हटाने के लिए टेम्प्लेट के नाम पर बिन आइकन पर क्लिक करें। अगर हेडर फ़ाइल जुड़ी है, तो टूलटिप में **Remove template and its media** लिखा होता है।
- सिर्फ़ फ़ाइल हटाने के लिए **Header media, shown by Meta** के बगल के क्रॉस पर क्लिक करें। टूलटिप में **Remove media only, keep the template** लिखा होता है।
- टेम्प्लेट बदलकर दूसरा लगाने के लिए टेम्प्लेट के नाम पर क्लिक करें।

अगर सूची में **No approved templates yet.** दिखता है, तो पहले टेम्प्लेट बनाकर सबमिट करें।

### व्हाट्सऐप फ़ॉर्म भेजें { #send-a-whatsapp-form }

1. **WhatsApp Form** ब्लॉक जोड़ें।
2. **Message above the form** के नीचे मैसेज लिखें, जैसे `Please fill in your details`।
3. **Form** के नीचे **Choose a form** पर क्लिक करें और कोई पब्लिश किया हुआ फ़ॉर्म चुनें।
4. **Button label** के नीचे उस बटन के शब्द लिखें जो फ़ॉर्म खोलता है, जैसे `Open form`।
5. **Save answers as** के नीचे सेव किए गए जवाबों का नाम लिखें, जैसे `form`।

अगर सूची में **No forms published yet.** दिखता है, तो पहले कोई फ़ॉर्म पब्लिश करें।

### डिले और टाइमआउट सेट करें { #set-a-delay-and-a-timeout }

कुछ ब्लॉक में कार्ड के नीचे समय की सेटिंग्स होती हैं।

1. ब्लॉक के नीचे ग्रे रंग का समय वाला हिस्सा खोजें।
2. **Set Delay** के लिए **Type delay in seconds...** में इंतज़ार के सेकंड लिखें। डिले सिर्फ़ **Media**, **Text** और **AI reply** ब्लॉक में होता है।
3. **Set Timeout** के लिए उसे चालू करें, फिर **Timeout after (minutes)** में मिनट लिखें।
4. कार्ड पर एक नया **Timed out** निकास दिखता है। उसे उस चरण से जोड़ें जो ग्राहक के जवाब न देने पर चलेगा।

टाइमआउट **Media** और **WhatsApp Form** ब्लॉक पर, और लिस्ट व Ask ब्लॉक पर उपलब्ध है। सिर्फ़ जानकारी देने वाले मैसेज में डिले नहीं होता।

| **No forms published yet.** | फ़ॉर्म की सूची खाली है। | कोई फ़ॉर्म पब्लिश करें, फिर ब्लॉक दोबारा खोलें। |
