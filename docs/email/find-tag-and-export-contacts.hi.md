# कॉन्टैक्ट खोजें, टैग करें और एक्सपोर्ट करें { #find-tag-and-export-contacts }

Audience में **Emails** टैब आपके सभी ईमेल कॉन्टैक्ट की लिस्ट दिखाता है। इससे आप लोगों को खोज सकते हैं, टैग कर सकते हैं, उनका स्टेटस बदल सकते हैं और अपनी ऑडियंस एक्सपोर्ट कर सकते हैं। आख़िर में आपके कॉन्टैक्ट पर लेबल लग जाएँगे, ताकि आप उन्हें टारगेट कर सकें।

## शुरू करने से पहले { #before-you-start }

- आपको **Email** पैनल में **Audience** दिखता हो। न दिखे तो अपने एडमिन से पूछें।
- आपके पास कॉन्टैक्ट हों। इसके लिए [कॉन्टैक्ट, लिस्ट और सेगमेंट जोड़ें](manage-email-contacts.md) देखें।

## स्टेप { #steps }

### कॉन्टैक्ट खोजें { #find-contacts }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Audience** चुनें।
2. **Emails** टैब खोलें।
3. **All Contacts**, **Subscribed Contacts** और **Unsubscribed Contacts** के बीच बदलने के लिए **All**, **Subscribed** या **Unsubscribed** पर क्लिक करें।
4. फ़िल्टर से लिस्ट छोटी करें: **Status**, **Filter by Owner**, **Filter by Tags** और **Active in last N days** (Last 7, 30 या 90 days, या **Any time**)।
5. सारे फ़िल्टर हटाने के लिए **Clear all** पर क्लिक करें।

### कॉन्टैक्ट को टैग करें { #tag-contacts }

1. किसी कॉन्टैक्ट के टैग खोलकर **Manage tags** पर जाएँ। **Add or remove tags** के नीचे **Search or create a tag** में लिखें।
2. नया टैग बनाने के लिए **Create** पर क्लिक करें। पुराना टैग दोबारा इस्तेमाल करने के लिए **Popular tags** में से चुनें।
3. **Add tags** या **Remove tags** पर क्लिक करें।
4. कई लोगों को टैग करने के लिए उनके पते **Bulk Tag by Email** में पेस्ट करें, या **Upload File** इस्तेमाल करें। पूछने पर टैग का नाम दें: **What should we name this tag?**
5. या **Manage audience** पर क्लिक करें, फिर **Bulk select & actions** चुनें। **Select All** इस्तेमाल करें, फिर **Tag Contacts** या **Delete Selected Contacts** चुनें।

### कॉन्टैक्ट का स्टेटस बदलें { #change-a-contacts-status }

1. लाइन में **More actions** मेन्यू पर क्लिक करें।
2. उन्हें फिर से **Subscribed** करने के लिए **Reactivate** चुनें। मार्केटिंग ईमेल रोकने के लिए **Unsubscribe** चुनें।
3. उन्हें किसी लिस्ट में जोड़ने के लिए **Copy to List** चुनें।

### अपनी ऑडियंस एक्सपोर्ट करें { #export-your-audience }

1. **Export** पर क्लिक करें। **Export Contacts** डायलॉग खुलेगा।
2. **Export Type**, **File Name**, **Format** और **Fields to Include** सेट करें।
3. चाहें तो **Filters** और **Date Range** सेट करें। फिर एक्सपोर्ट करें।

### Manage audience के अंदर के दूसरे टूल { #other-tools-under-manage-audience }

1. **Import history**, **Export audience**, **Find duplicates**, **Copy to list** और **Bulk select & actions** खोलने के लिए **Manage audience** पर क्लिक करें।

### डेटा रिक्वेस्ट संभालें { #handle-a-data-request }

1. उस व्यक्ति के पास जो भी डेटा है, उसे एक्सपोर्ट करने के लिए लाइन में **GDPR Data Export** पर क्लिक करें।
2. उनका डेटा मिटाने के लिए **GDPR Erase** पर क्लिक करें। इसे वापस नहीं किया जा सकता।
3. डेटा रिक्वेस्ट के बिना कॉन्टैक्ट हटाना हो, तो **Delete Contact** पर क्लिक करें।

!!! warning "चेतावनी"
    **GDPR Erase** हमेशा के लिए होता है। अगर आपको रिकॉर्ड की ज़रूरत पड़ सकती है, तो पहले एक्सपोर्ट कर लें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| कोई कॉन्टैक्ट नहीं दिख रहा। | कोई फ़िल्टर उसे छिपा रहा है। | **Clear all** पर क्लिक करें। |
| बल्क टैग में कुछ लाइनें छूट गईं। | वह पता **Contacts** में नहीं है। | पहले कॉन्टैक्ट जोड़ें, फिर दोबारा टैग करें। |
| बाउंस के लिए **Reactivate** कुछ नहीं करता। | हार्ड बाउंस और शिकायतें हमेशा के लिए होती हैं। | [सप्रेशन लिस्ट से पते ब्लॉक करें](use-the-suppression-list.md) देखें। |
