# विज्ञापन कैंपेन प्लान करें और उसे जाँचें { #plan-and-review-an-advertisement-campaign }

कैंपेन के नोट्स बनाएँ, क्रिएटिव जोड़ें, बजट तय करें और देखें कि कैंपेन कैसा चल रहा है।

## स्टेप { #steps }

1. **Advertisements** खोलें।
2. **New campaign** चुनें।
3. मकसद, टारगेट ऑडियंस, तारीख़ें और बजट जोड़ें।
4. क्रिएटिव अपलोड करें, या कैंपेन के असेट के लिंक पेस्ट करें।
5. कैंपेन को लीड कैप्चर या रिपोर्टिंग वर्कफ़्लो से जोड़ें।
6. खर्च, लीड, कन्वर्ज़न रेट और कैंपेन के नोट्स देखें।

## इन मेट्रिक का मतलब { #metrics-to-explain }

| मेट्रिक | मतलब |
| --- | --- |
| खर्च | कैंपेन के बजट में से जितनी रकम लग चुकी है। |
| लीड | कैंपेन से कितने कॉन्टैक्ट मिले। |
| प्रति लीड लागत | खर्च को लीड की संख्या से भाग दें, तो एक लीड की लागत निकलती है। |
| कन्वर्ज़न रेट | कितनी लीड जवाब, बुकिंग, ऑर्डर या ग्राहक में बदलीं। |
