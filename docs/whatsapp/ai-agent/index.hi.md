# AI एजेंट { #ai-agent }

AI एजेंट आपके बिज़नेस के बारे में जो आप उसे सिखाते हैं, उसी के आधार पर WhatsApp पर ग्राहकों के सवालों के जवाब देता है। पहले उसे टेस्ट करें। जब आप तैयार हों, तब पब्लिश करें।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **AI Agent** चुनें।

![AI Agent स्क्रीन। बाईं ओर उसके सेक्शन हैं और दाईं ओर Test your Agent पैनल है](../../assets/screenshots/whatsapp-ai-agent-0-overview.png)

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |

| [AI एजेंट सेट करें](../set-up-ai-agent.md) | जब आप अपना एजेंट बनाकर पब्लिश कर रहे हों। |
| [AI के जवाब देखें और सुधारें](../review-and-correct-ai-agent-answers.md) | जब आप जानना चाहें कि एजेंट ने ऐसा जवाब क्यों दिया, और उसे ठीक करना चाहें। |

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट होना चाहिए। देखें [अपना नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस होना चाहिए। अगर यह स्क्रीन न दिखे, तो अपने एडमिन से पूछें।
