# ड्राफ़्ट खोजें और पूरे करें { #find-and-finish-drafts }

जो आइटम सेव हैं पर भेजने के लिए तैयार नहीं हैं, उन्हें खोजने के लिए **Drafts** व्यू का इस्तेमाल करें। आखिर में आपने हर ड्राफ़्ट खोज लिया होगा, उसे उसके अपने मॉड्यूल में खोल लिया होगा, और या तो पूरा कर लिया होगा या हटा दिया होगा।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **Schedule** दिखता हो। डिफ़ॉल्ट रूप से यह सिर्फ़ वर्कस्पेस के Super Admin रोल के पास होता है। अगर यह नहीं दिख रहा, तो अपने एडमिन से पूछें।
- आपने Email या Social में तारीख और समय के साथ कोई ड्राफ़्ट सेव किया हो। बिना तारीख और समय का ड्राफ़्ट Schedule में नहीं दिखता।

## चरण { #steps }

### Drafts खोलें { #open-drafts }

1. लेफ़्ट रेल में **Schedule** खोलें, फिर **Drafts** चुनें। पेज का टाइटल **Drafts** होता है और पेज **List** व्यू में खुलता है।
2. सूची पढ़ें। हर पंक्ति में टाइटल, चैनल और एक **Draft** पिल दिखती है।
3. किसी पंक्ति पर क्लिक करें। उसका ब्योरा दाईं ओर खुलता है।

### जानें कि ड्राफ़्ट कहाँ से आते हैं { #know-where-drafts-come-from }

| चैनल | ड्राफ़्ट के रूप में क्या दिखता है |
| --- | --- |
| **Email** | ऐसा कैंपेन जो **Draft**, **Pending review** या **Rejected** है और जिसका शेड्यूल किया हुआ समय है। |
| **Social** | ऐसी पोस्ट जो शेड्यूल किए हुए समय के साथ ड्राफ़्ट के रूप में सेव है। |

व्हाट्सऐप, CRM और अपॉइंटमेंट के आइटम कभी ड्राफ़्ट नहीं होते। वे बनते ही **Scheduled** हो जाते हैं।

### ड्राफ़्ट पूरा करें { #finish-a-draft }

1. ड्राफ़्ट पर क्लिक करें।
2. **Edit** पर क्लिक करें। **Opening Email…** या **Opening Social…** मैसेज आता है।
3. Ohanvi वह मॉड्यूल खोलता है जिसका ड्राफ़्ट है। वहाँ ड्राफ़्ट ढूँढें और उसे पूरा करें। देखें [ईमेल कैंपेन भेजें](../email/send-email-campaign.md) या [पोस्ट शेड्यूल करें और क्यू प्रबंधित करें](../social/schedule-social-posts.md)।
4. **Drafts** पर वापस आएँ। पूरा हो चुका आइटम **Upcoming** में चला जाता है।

### ड्राफ़्ट हटाएँ { #remove-a-draft }

1. ड्राफ़्ट पर क्लिक करें।
2. रिकॉर्ड रखकर उसे रद्द करने के लिए **Cancel** पर क्लिक करें, या उसके मॉड्यूल से हटाने के लिए **Delete** पर क्लिक करें। देखें [शेड्यूल किए गए आइटम को रीशेड्यूल, रद्द या डिलीट करें](reschedule-cancel-delete.md)।

### सूची को छोटा करें { #narrow-the-list }

1. सिर्फ़ **Email** या **Social** के ड्राफ़्ट दिखाने के लिए किसी चैनल चिप पर क्लिक करें।
2. सिर्फ़ अपने ड्राफ़्ट देखने के लिए **Everyone's schedule** पर क्लिक करें और **My schedule** चुनें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Nothing scheduled here** | कोई ड्राफ़्ट नहीं है, या किसी में तारीख और समय नहीं है। | ड्राफ़्ट को उसके मॉड्यूल में खोलें और उसे शेड्यूल का समय दें। |
| एक **Rejected** ईमेल कैंपेन ड्राफ़्ट के रूप में दिखता है | **Rejected** कैंपेन को ड्राफ़्ट के साथ गिना जाता है। | उसे **Edit** से खोलें, जो रिजेक्ट हुआ था उसे ठीक करें और फिर रिव्यू के लिए भेजें। |
| ड्राफ़्ट **Upcoming** में नहीं है | **Upcoming** सिर्फ़ **Scheduled** और **Live** आइटम दिखाता है। | पहले ड्राफ़्ट पूरा करें। |
