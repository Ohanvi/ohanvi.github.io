# Call many contacts in a row with Auto Calling

Pick a group of contacts and call them one after another without going back to the list each time. At the end, every call has a review, and you can stop and pick up again later. A run of 10 calls takes as long as the calls themselves.

## Before you start

- You can see **Contacts** in the left rail with **All contacts** in its panel.
- The contacts you pick have a **Mobile** or **Phone** number.
- You know how the call review works. See [Call contacts and review your calls](call-contacts-and-review-calls.md).

## Steps

### Start a run

1. Open **Contacts** in the left rail, then select **All contacts**.
2. Click the **Auto Calling** icon in the top bar.
3. In **Search contacts…**, type a name to narrow the list.
4. Optional: click **Today's follow-ups only** to list only the contacts due today.
5. Tick each contact you want to call. The line **N selected** counts them.
6. Click **Start Auto Calling**.

The window title changes to **Auto Calling — 1 of N**. It shows the first contact's name and number.

### Make each call

1. Read the contact's name and number in the window.
2. The call starts on your device. If it does not, click **Call Again**.
3. Talk to the contact.
4. When the call ends, come back to Ohanvi. The line **Waiting for the call to finish — the Call Review dialog will open automatically once you return to the app.** disappears and the **Call Review** window opens.
5. Fill in the review and click **Save**. See [Call contacts and review your calls](call-contacts-and-review-calls.md).
6. Auto Calling moves to the next contact. The title counts up, for example **Auto Calling — 2 of 10**.

When the last call is done, the window says **All calls completed.** Click **Done**.

### Stop a run

1. Click **Stop Auto Calling** at any time.
2. Your progress is saved on this device.

### Resume a run

1. Click the **Auto Calling** icon again.
2. Read the message **You have an unfinished Auto Calling run.** It shows how many are done, for example **4 of 10 done — 6 remaining.**
3. Click **Resume (6)** to carry on, or **Start New** to throw the old run away and pick again.

!!! note
    An unfinished run is kept on the device where you started it, and only for about a day. Open Auto Calling on the same device to resume.

## Troubleshooting

| Issue | Cause | Fix |
| --- | --- | --- |
| **No contacts match this view.** | The search or the follow-up filter matches nobody. | Clear the search, or switch off **Today's follow-ups only**. |
| The window waits and nothing happens | The call did not start. | Click **Call Again**. |
| The **Resume** option is missing | The old run is a day old, or it was on another device. | Click **Start Auto Calling** and pick again. |
