# ईमेल टेम्प्लेट बनाएँ { #create-an-email-template }

वह ईमेल डिज़ाइन करें जो आप भेजेंगे: सब्जेक्ट लाइन, प्रीव्यू टेक्स्ट और बॉडी। बॉडी ब्लॉक से या आपके अपने HTML से बनती है। आख़िर में टेम्प्लेट **My Library** में सेव होगा, अप्रूव होगा, और कैंपेन या ऑटोमेशन में चुनने के लिए तैयार रहेगा।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Email** दिखे और उसके पैनल में **Email Templates**। न दिखे तो अपने एडमिन से एक्सेस माँगें।
- अपना लोगो और इमेज ऑनलाइन रखें। इमेज ब्लॉक में इमेज का URL डाला जाता है।

## स्टेप { #steps }

### नया ईमेल शुरू करें { #start-a-new-email }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Email Templates** चुनें।
2. **Create template** पर क्लिक करें। **Create an email** डायलॉग खुलेगा।
3. **Internal email name** में ऐसा नाम लिखें जो सिर्फ़ आपकी टीम देखे, जैसे `Newsletter - May`। इसमें 80 अक्षर तक लिख सकते हैं।
4. **How do you want to design it?** के तहत शुरुआत का तरीका चुनें:
    - **From scratch** — खाली कैनवास।
    - **Basic layout** — एक हेडिंग, एक मैसेज और एक बटन, जिन्हें आप एडिट कर सकते हैं।
    - **Fully designed template** — पहले से बना कोई डिज़ाइन चुनें।
    - **Saved templates** — अपने ही किसी टेम्प्लेट से शुरू करें।
    - **Recently sent** — पहले भेजे जा चुके किसी कैंपेन का ईमेल दोबारा इस्तेमाल करें।
    - **Code your own** — अपना HTML पेस्ट या अपलोड करें।
5. ईमेल बिल्डर खुलेगा।

आप चाहें तो पहले पहले से बने डिज़ाइन देख सकते हैं। **Gallery** पर क्लिक करें। **Email purpose**, **Style** या **Industry** से फ़िल्टर करें। देखने के लिए **Preview** पर क्लिक करें। एडिटर में उसकी कॉपी खोलने के लिए **Use** पर क्लिक करें।

### ईमेल डिज़ाइन करें { #design-the-email }

1. **STYLES** के तहत **Subject line** लिखें। लोग अपने इनबॉक्स में यही देखते हैं।
2. **Preview text** लिखें। ज़्यादातर इनबॉक्स में यह सब्जेक्ट लाइन के बगल में दिखता है।
3. **BLOCKS** से ब्लॉक खींचकर ईमेल पर रखें: **Heading**, **Paragraph**, **Button**, **Image**, **Logo**, **Divider**, **Spacer**, **Video**, **Social** या **Code**।
4. किसी ब्लॉक पर क्लिक करके उसका टेक्स्ट, लिंक, रंग और स्पेसिंग एडिट करें।
5. डेस्कटॉप और मोबाइल पर ईमेल देखने के लिए **Preview** पर क्लिक करें।

टेक्स्ट का ड्राफ़्ट अपने-आप बनवाने के लिए **Write with AI** पर क्लिक करें और **What is this email about?** भरें। अगर ईमेल में पहले से कंटेंट है, तो **Add draft** पर क्लिक करें। ड्राफ़्ट सब्जेक्ट और प्रीव्यू टेक्स्ट की जगह ले लेता है, और आख़िर में नए ब्लॉक के रूप में जुड़ जाता है।

### पर्सनलाइज़ करें और अनसब्सक्राइब लिंक जोड़ें { #personalize-and-add-an-unsubscribe-link }

ईमेल भेजते समय मर्ज टैग की जगह हर पाने वाले की जानकारी आ जाती है:

| मर्ज टैग | इसकी जगह क्या आता है |
| --- | --- |
| `{{firstName}}` | पहला नाम |
| `{{lastName}}` | सरनेम |
| `{{fullName}}` | पूरा नाम |
| `{{email}}` | ईमेल पता |
| `{{phone}}` | फ़ोन |
| `{{attributes.x}}` | कोई कस्टम फ़ील्ड, जहाँ `x` फ़ील्ड का नाम है, जैसे `{{attributes.company}}` |

टैग को सब्जेक्ट या किसी भी टेक्स्ट ब्लॉक में लिखें, जैसे `Hi {{firstName}},`।

!!! warning "अनसब्सक्राइब लिंक जोड़ें"
    फ़ुटर के किसी टेक्स्ट, जैसे `Unsubscribe`, पर `{{unsubscribeUrl}}` का लिंक लगाएँ। Ohanvi उसे हर व्यक्ति के अपने अनसब्सक्राइब लिंक से बदल देता है। इसके बिना इनबॉक्स प्रोवाइडर आपके ईमेल को स्पैम मार्क कर सकते हैं। HTML एडिटर में खोले गए टेम्प्लेट में यह **Check Spam Score** के तहत दिखता है।

### टेम्प्लेट सेव करें { #save-the-template }

1. **Save and exit** पर क्लिक करें। टेम्प्लेट **My Library** में दिखने लगेगा।
2. नए नाम से कॉपी रखने के लिए **Save and exit** के बगल के तीर पर क्लिक करें, फिर **Save as a template** पर क्लिक करें।

### टेम्प्लेट को रिव्यू के लिए भेजें { #send-the-template-for-review }

कैंपेन आपका अपना टेम्प्लेट तभी भेज सकता है जब वह अप्रूव हो चुका हो। **Gallery** के पहले से बने डिज़ाइन पहले से अप्रूव होते हैं।

1. **Email Templates** पर अपने टेम्प्लेट के **⋮** (**More actions**) पर क्लिक करें, फिर **Send for review** पर क्लिक करें।
2. **Send for Review** में **Send for Review** पर क्लिक करें। **Review Status** में **Pending review** दिखेगा।
3. रिव्यू करने वाला व्यक्ति **⋮** → **Review (approve / reject)** पर क्लिक करता है, **Remarks (optional)** जोड़ता है, और **Approve** या **Reject** पर क्लिक करता है।

!!! note "ध्यान दें"
    अप्रूव हो चुके टेम्प्लेट को एडिट करने पर वह वापस **Draft** हो जाता है। हर बदलाव के बाद उसे दोबारा रिव्यू के लिए भेजें।
