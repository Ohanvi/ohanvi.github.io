# अपनी Google Business Profile मैनेज करें { #manage-your-google-business-profile }

अपनी Google लिस्टिंग अपडेट रखें और रिव्यू का जवाब भी Ohanvi से ही दें। आप अपने बिज़नेस का नाम, कॉन्टैक्ट की जानकारी, पता, कैटेगरी और खुलने का समय बदल सकते हैं। आप बुकिंग या ऑर्डर के लिंक जोड़ सकते हैं, और रिव्यू का पब्लिक जवाब भी दे सकते हैं।

## शुरू करने से पहले { #before-you-start }

- Google Business कनेक्ट हो, और उसमें कम से कम एक लोकेशन हो। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
- लेफ़्ट रेल में **Social** दिखना चाहिए, और उसके पैनल में **Business Info**। न दिखे, तो अपने एडमिन से कहें कि आपके रोल को एक्सेस दें। देखें [सेटिंग्स का ओवरव्यू](../settings/index.md)।

अपनी Google लिस्टिंग पर पोस्ट करने के लिए कंपोज़र इस्तेमाल करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## स्टेप { #steps }

### अपनी बिज़नेस जानकारी बदलें { #edit-your-business-info }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Business Info** चुनें।
2. आपकी एक से ज़्यादा लिस्टिंग हों, तो **Location** में सही लिस्टिंग चुनें।
3. **Profile** में **Business name**, **Description**, **Phone number** और **Website** बदलें। फ़ोन नंबर देश के कोड के साथ लिखें, जैसे `+911234567890`।
4. **Address** में **Address line**, **City / locality**, **State / region** और **Postal code** बदलें।
5. **Categories** में **Primary category** बदलें। **Additional categories** में हर कैटेगरी को कॉमा से अलग करें।
6. **Regular hours** में हर दिन को **Open** या **Closed** चुनें, और खुलने व बंद होने का समय लिखें।
7. **Save changes** पर क्लिक करें। **Business info saved.** मैसेज आता है।

Google कुछ बदलावों को लाइव करने से पहले जाँचता है। तब तक पेज पर यह दिखता है: **Your last edit is still pending review by Google — the values shown may not be live yet.**

Business name में ज़्यादा से ज़्यादा 300 अक्षर हो सकते हैं। Description में ज़्यादा से ज़्यादा 750 अक्षर हो सकते हैं।

### बुकिंग या ऑर्डर का लिंक जोड़ें { #add-a-booking-or-order-link }

यह हिस्सा तभी दिखता है जब आपका वर्कस्पेस इसे सपोर्ट करता है।

1. **Booking / order links** में **Add link** पर क्लिक करें। **Add booking / order link** विंडो खुलती है।
2. **Action type** में लिंक किस काम का है, यह लिखें, जैसे `BOOK`।
3. **URL** में लिंक पेस्ट करें।
4. **Add** पर क्लिक करें। **Link added** मैसेज आता है।

लिंक हटाने के लिए उसके बगल के डिलीट आइकन पर क्लिक करें।

### अपनी लिस्टिंग वेरिफ़ाई करें { #verify-your-listing }

1. **Business Info** पर सबसे ऊपर की **Verification** लाइन देखें।
2. लिस्टिंग वेरिफ़ाई न हो, तो **Start verification** पर क्लिक करें।
3. **Method** में `PHONE_CALL` रहने दें, या Google आपकी लिस्टिंग के लिए जो दूसरा तरीका देता है, वह लिखें।
4. **Start** पर क्लिक करें। **Verification started — check for a PIN** मैसेज आता है। Google PIN उसी तरीके से भेजता है जो आपने चुना।

### Google रिव्यू का जवाब दें { #reply-to-google-reviews }

रिव्यू के लिए अलग पेज है। देखें [Google रिव्यू का जवाब दें](reply-to-google-reviews.md)। उसमें फ़िल्टर, जवाब, फ़्लैग और नोट्स की जानकारी है।
