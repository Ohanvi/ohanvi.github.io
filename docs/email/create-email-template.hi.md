# ईमेल टेम्प्लेट बनाएँ { #create-an-email-template }

वह ईमेल डिज़ाइन करें जो आप भेजेंगे: सब्जेक्ट लाइन, प्रीव्यू टेक्स्ट और बॉडी, जो ब्लॉक या आपके अपने HTML से बनती है। अंत में टेम्प्लेट **My Library** में सेव होता है, मंज़ूर होता है, और कैंपेन या ऑटोमेशन में चुनने के लिए तैयार रहता है।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Email** दिखता है और उसके पैनल में **Email Templates**। न दिखे तो अपने एडमिन से एक्सेस माँगें।
- अपना लोगो और इमेज ऑनलाइन रखें। इमेज ब्लॉक में इमेज का URL डाला जाता है।

## चरण { #steps }

### नया ईमेल शुरू करें { #start-a-new-email }

1. लेफ़्ट रेल में **Email** खोलें, फिर **Email Templates** चुनें।
2. **Create template** पर क्लिक करें। **Create an email** डायलॉग खुलता है।
3. **Internal email name** में ऐसा नाम लिखें जो सिर्फ़ आपकी टीम देखे, जैसे `Newsletter - May`। इसमें 80 अक्षर तक आ सकते हैं।
4. **How do you want to design it?** के तहत शुरुआत का तरीका चुनें:
    - **From scratch** — खाली कैनवास।
    - **Basic layout** — एक हेडिंग, एक संदेश और एक बटन, एडिट करने के लिए तैयार।
    - **Fully designed template** — पहले से बना कोई डिज़ाइन चुनें।
    - **Saved templates** — अपने ही किसी टेम्प्लेट से शुरू करें।
    - **Recently sent** — पहले भेजे जा चुके किसी कैंपेन का ईमेल दोबारा इस्तेमाल करें।
    - **Code your own** — अपना HTML पेस्ट या अपलोड करें।
5. ईमेल बिल्डर खुलता है।

आप पहले पहले से बने डिज़ाइन भी देख सकते हैं। **Gallery** पर क्लिक करें, **Email purpose**, **Style** या **Industry** से फ़िल्टर करें, देखने के लिए **Preview** पर क्लिक करें, और एडिटर में उसकी कॉपी खोलने के लिए **Use** पर क्लिक करें।

### ईमेल डिज़ाइन करें { #design-the-email }

1. **STYLES** के तहत **Subject line** लिखें। लोग अपने इनबॉक्स में यही देखते हैं।
2. **Preview text** लिखें। ज़्यादातर इनबॉक्स में यह सब्जेक्ट लाइन के बगल में दिखता है।
3. **BLOCKS** से ब्लॉक खींचकर ईमेल पर रखें: **Heading**, **Paragraph**, **Button**, **Image**, **Logo**, **Divider**, **Spacer**, **Video**, **Social** या **Code**।
4. किसी ब्लॉक पर क्लिक करके उसका टेक्स्ट, लिंक, रंग और स्पेसिंग एडिट करें।
5. डेस्कटॉप और मोबाइल पर ईमेल जाँचने के लिए **Preview** पर क्लिक करें।

टेक्स्ट का ड्राफ़्ट अपने-आप बनवाने के लिए **Write with AI** पर क्लिक करें और **What is this email about?** भरें। अगर ईमेल में पहले से कंटेंट है, तो **Add draft** पर क्लिक करें। ड्राफ़्ट सब्जेक्ट और प्रीव्यू टेक्स्ट की जगह ले लेता है और अंत में नए ब्लॉक के रूप में जुड़ जाता है।

### पर्सनलाइज़ करें और अनसब्सक्राइब लिंक जोड़ें { #personalize-and-add-an-unsubscribe-link }

ईमेल भेजे जाते समय मर्ज टैग हर पाने वाले की जानकारी से बदल जाते हैं:

| मर्ज टैग | इससे भरा जाता है |
| --- | --- |
| `{{firstName}}` | पहला नाम |
| `{{lastName}}` | उपनाम |
| `{{fullName}}` | पूरा नाम |
| `{{email}}` | ईमेल पता |
| `{{phone}}` | फ़ोन |
| `{{attributes.x}}` | कोई कस्टम फ़ील्ड, जहाँ `x` फ़ील्ड का नाम है, जैसे `{{attributes.company}}` |

टैग को सब्जेक्ट या किसी भी टेक्स्ट ब्लॉक में लिखें, जैसे `Hi {{firstName}},`।

!!! warning "अनसब्सक्राइब लिंक जोड़ें"
    फ़ुटर के किसी टेक्स्ट, जैसे `Unsubscribe`, को `{{unsubscribeUrl}}` से लिंक करें। Ohanvi उसे हर व्यक्ति के अपने अनसब्सक्राइब लिंक से बदल देता है। इसके बिना इनबॉक्स प्रोवाइडर आपके ईमेल को स्पैम मार्क करने की ज़्यादा संभावना रखते हैं। HTML एडिटर में खोले गए टेम्प्लेट में यह **Check Spam Score** के तहत दिखता है।

### टेम्प्लेट सेव करें { #save-the-template }

1. **Save and exit** पर क्लिक करें। टेम्प्लेट **My Library** में दिखने लगता है।
2. नए नाम से कॉपी रखने के लिए **Save and exit** के बगल के तीर पर क्लिक करें, फिर **Save as a template** पर क्लिक करें।

### टेम्प्लेट को रिव्यू के लिए भेजें { #send-the-template-for-review }

कैंपेन आपका अपना टेम्प्लेट तभी भेज सकता है जब वह मंज़ूर हो चुका हो। **Gallery** के पहले से बने डिज़ाइन पहले से मंज़ूर होते हैं।

1. **Email Templates** पर अपने टेम्प्लेट के **⋮** (**More actions**) पर क्लिक करें, फिर **Send for review** पर क्लिक करें।
2. **Send for Review** में **Send for Review** पर क्लिक करें। **Review Status** में **Pending review** दिखता है।
3. रिव्यूअर **⋮** → **Review (approve / reject)** पर क्लिक करता है, **Remarks (optional)** जोड़ता है, और **Approve** या **Reject** पर क्लिक करता है।

!!! note "ध्यान दें"
    मंज़ूर टेम्प्लेट को एडिट करने पर वह वापस **Draft** हो जाता है। हर बदलाव के बाद उसे दोबारा रिव्यू के लिए भेजें।
