# Contacts { #contacts }

**Contacts** में वे लोग रहते हैं जिनसे आपका बिज़नेस बात करता है। WhatsApp, ईमेल, कॉमर्स और CRM, सब एक ही रिकॉर्ड देखते हैं। इसलिए यहाँ किया गया बदलाव हर जगह दिखता है। अपने कॉन्टैक्ट जोड़ने, ढूँढने, कॉल और ईमेल करने, ग्रुप में रखने और सुरक्षित रखने के लिए इन गाइड को देखें।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Contacts** खोलें।

## Leads { #leads }

Leads **Contacts** में नहीं हैं। वे **CRM** → **Leads** में हैं। **Contacts** में आप किसी व्यक्ति को जोड़ते हैं, तो वह कॉन्टैक्ट के रूप में जुड़ता है और उसके फ़ॉलो-अप शुरू होते हैं। इम्पोर्ट कॉन्टैक्ट जोड़ता है और कोई फ़ॉलो-अप शुरू नहीं करता। WhatsApp और Email marketing पर इसका असर नहीं पड़ता। देखें [कॉन्टैक्ट मैनेज करें](../manage-contacts.md#what-add-contact-does-with-follow-ups) और [Leads के साथ काम करें](../leads.md)।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में CRM मॉड्यूल हो और आपके रोल को CRM एक्सेस मिला हो। नहीं तो **Contacts** आइकन नहीं दिखेगा। अपने एडमिन से पूछें।
- चैट से कॉन्टैक्ट अपने आप आएँ, इसके लिए आपका WhatsApp नंबर कनेक्ट होना चाहिए।
