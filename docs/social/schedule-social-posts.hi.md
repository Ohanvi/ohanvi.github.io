# पोस्ट शेड्यूल करें और Queue मैनेज करें { #schedule-posts-and-manage-the-queue }

पोस्ट के लिए आगे की कोई तारीख और समय चुनें। पोस्ट जाने तक उसे **Publish** स्क्रीन पर देखते रहें। आप कैलेंडर पर पोस्ट का समय बदल सकते हैं, किसी पोस्ट को पहले पब्लिश कर सकते हैं और शेड्यूल कैंसल कर सकते हैं। जो पोस्ट कुछ नेटवर्क पर फ़ेल हो गई, उसे दोबारा भेज भी सकते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में **Social** दिखना चाहिए, और उसके पैनल में **Publish**।
- कम से कम एक नेटवर्क कनेक्ट होना चाहिए। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)।
- आपको कंपोज़र में पोस्ट लिखना आना चाहिए। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।

## स्टेप { #steps }

### पोस्ट शेड्यूल करें { #schedule-a-post }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
2. **New Post** पर क्लिक करें और अपनी पोस्ट लिखें।
3. कंपोज़र के नीचे **Schedule** पर क्लिक करें।
4. पहले तारीख चुनें, फिर समय। नीचे फ़ुटर में **Publishes** के आगे आपकी चुनी तारीख और समय दिखता है।
5. **Schedule Post** पर क्लिक करें। **Post scheduled for …** मैसेज आएगा, और पोस्ट **Queue** टैब में दिखेगी।

सेव करने से पहले समय हटाना हो, तो तारीख के बगल में **Clear schedule** पर क्लिक करें। समय बदलना हो, तो **Reschedule** पर क्लिक करें।

!!! note "ध्यान दें"
    **Facebook** पर अभी से 10 मिनट से 6 महीने के बीच का ही समय चलता है। बाकी नेटवर्क पर 2 साल आगे तक का समय चलता है। अगर आपने ऐसा नेटवर्क चुना जो आपकी तारीख नहीं लेता, तो Ohanvi वह तारीख हटा देता है और **Cleared the schedule — … does not accept that date.** दिखाता है।

### Publish स्क्रीन समझें { #read-the-publish-screen }

**Publish** स्क्रीन पर 4 टैब हैं:

- **Queue**: जाने का इंतज़ार कर रही पोस्ट। इनमें **Scheduled**, **Queued** और **Publishing** आती हैं।
- **Drafts**: वे पोस्ट जो अभी शेड्यूल नहीं हुईं।
- **Approvals**: रिव्यू के इंतज़ार में पड़ी पोस्ट। देखें [पब्लिश होने से पहले पोस्ट रिव्यू करें](approve-social-posts.md)।
- **Sent**: **Published**, **Partial**, **Failed** और **Cancelled** पोस्ट।

व्यू बदलने के लिए **List** या **Calendar** पर क्लिक करें। **Channels** के हिसाब से देखना हो, तो **Filters** पर क्लिक करें। दाईं तरफ़ के **Publishing Overview** पैनल में इस हफ़्ते की **Queued**, **Drafts**, **Published** और **Failed** पोस्ट की गिनती दिखती है।

समय आपके डिवाइस के टाइम ज़ोन के हिसाब से दिखता है।

### कैलेंडर इस्तेमाल करें { #use-the-calendar }

1. **Calendar** पर क्लिक करें।
2. **Day**, **Week** या **Month** चुनें। आज की तारीख पर लौटने के लिए **Today** पर क्लिक करें।
3. शेड्यूल की हुई पोस्ट का समय बदलना हो, तो उसे खींचकर नए स्लॉट पर छोड़ दें। **Post rescheduled to …** मैसेज आएगा। **Month** व्यू में पोस्ट का समय वही रहता है, सिर्फ़ तारीख बदलती है।
4. नई पोस्ट प्लान करनी हो, तो किसी खाली स्लॉट पर क्लिक करें। कंपोज़र उसी तारीख के लिए खुलेगा।
5. जिन ड्राफ़्ट पर अभी कोई तारीख नहीं है, वे **Undated drafts** में दिखते हैं। उन्हें देखने के लिए **No Date** पर क्लिक करें।

जो पोस्ट **Published**, **Partial**, **Publishing** या **Cancelled** हैं, उन्हें आप खींच नहीं सकते।

### ड्राफ़्ट या Queue की पोस्ट अभी पब्लिश करें { #publish-a-draft-or-a-queued-post-now }

1. **Drafts** टैब में पोस्ट पर **Publish** पर क्लिक करें। **Queue** टैब में **⋯** मेनू पर क्लिक करें, फिर **Publish Now** चुनें।
2. **Publish to** विंडो में आपके कनेक्टेड अकाउंट की लिस्ट दिखती है। जिन पर पोस्ट करनी है, उन पर टिक करें।
3. **Publish Now** पर क्लिक करें। पोस्ट टिक किए हुए अकाउंट पर तुरंत लाइव हो जाएगी।

### शेड्यूल की हुई पोस्ट कैंसल करें { #cancel-a-scheduled-post }

1. **Queue** टैब में पोस्ट के **⋯** मेनू पर क्लिक करें, फिर **Cancel schedule** पर क्लिक करें।
2. **Cancel this scheduled post?** विंडो खुलेगी। पक्का करने के लिए **Cancel schedule** पर क्लिक करें।

पोस्ट **Sent** टैब में **Cancelled** में चली जाती है। आप उसे बाद में भी एडिट या दोबारा शेड्यूल कर सकते हैं।

### फ़ेल हुई पोस्ट दोबारा भेजें { #retry-a-failed-post }

Ohanvi हर नेटवर्क पर ज़्यादा से ज़्यादा 5 बार कोशिश करता है। उसके बाद ही पोस्ट को **Failed** मार्क करता है।

1. **Sent** टैब खोलें।
2. **Failed** या **Partial** पोस्ट पर **Retry** पर क्लिक करें। सिर्फ़ वही नेटवर्क दोबारा आज़माए जाते हैं जहाँ पोस्ट फ़ेल हुई थी। जिन नेटवर्क पर पोस्ट चली गई है, उन्हें छुआ नहीं जाता।
3. कौन-सा नेटवर्क फ़ेल हुआ और क्यों, यह जानने के लिए **⋯** मेनू पर क्लिक करें, फिर **Post Details** चुनें।

### पोस्ट डिलीट करें { #delete-a-post }

1. पोस्ट पर **Delete** आइकन या मेनू आइटम पर क्लिक करें। **Delete this post?** विंडो खुलेगी।
2. **Delete** पर क्लिक करें।

!!! warning "डिलीट करने से पब्लिश हो चुकी पोस्ट नहीं हटती"
    Delete करने पर पोस्ट सिर्फ़ **Publish** स्क्रीन से हटती है। जो पोस्ट किसी नेटवर्क पर पहले ही जा चुकी है, वह वहाँ लाइव रहती है।

## पोस्ट के स्टेटस { #post-statuses }

| स्टेटस | मतलब |
| --- | --- |
| **Draft** | सेव है, पर शेड्यूल या पब्लिश नहीं हुई। |
| **Scheduled** | पब्लिश होने का समय तय है। |
| **Queued** | इसके पब्लिश जॉब चलने का इंतज़ार कर रहे हैं। |
| **Publishing** | कम से कम एक नेटवर्क पर अभी पोस्ट हो रही है। |
| **Published** | चुने हुए हर नेटवर्क पर चली गई। |
| **Partial** | कुछ नेटवर्क पर चली गई और बाकी पर फ़ेल हो गई। |
| **Failed** | हर नेटवर्क पर फ़ेल हो गई। |
| **Cancelled** | पब्लिश होने से पहले शेड्यूल कैंसल कर दिया गया। |

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **scheduledAt must be in the future** | आपका चुना हुआ समय निकल चुका है। | बाद का समय चुनें। |
| **Channel account is disconnected: …** | पोस्ट लिखने के बाद नेटवर्क डिस्कनेक्ट हो गया। | **Connect** → **Social Connections** में उसे दोबारा कनेक्ट करें, फिर कोशिश करें। |
| **Post is awaiting approval and cannot be scheduled until approved** | पोस्ट रिव्यू के लिए भेजी गई थी। | किसी अप्रूवर से **Approvals** टैब में उसे अप्रूव करवाएँ। |
| **No channel is connected yet — posts cannot be published until at least one network is connected.** | कोई नेटवर्क कनेक्ट नहीं है। | **Connect** पर क्लिक करें और एक नेटवर्क कनेक्ट करें। |
| पोस्ट **Partial** या **Failed** दिखती है | किसी नेटवर्क ने पोस्ट नहीं ली, या उसका एक्सेस खत्म हो गया। | वजह पढ़ने के लिए **Post Details** खोलें, उसे ठीक करें, फिर **Retry** पर क्लिक करें। |
