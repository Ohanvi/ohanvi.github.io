# फ़्लो टेस्ट करें और फ़ेल रन ठीक करें { #test-a-flow-and-fix-failed-runs }

पहले टेस्ट रन शुरू करें। फिर पढ़ें कि हर स्टेप ने क्या किया और क्या नतीजा दिया। इससे आपको पता चलेगा कि फ़्लो ठीक चल रहा है या नहीं, कोई रन क्यों फ़ेल हुआ, और रुका हुआ फ़्लो दोबारा कैसे चालू करें।

## शुरू करने से पहले { #before-you-start }

- फ़्लो कम से कम एक बार पब्लिश हो चुका हो। टेस्ट में पब्लिश किया हुआ वर्शन चलता है, आपका बिना सेव किया ड्राफ़्ट नहीं। देखें [ऑटोमेशन फ़्लो बनाएँ](build-automation-flow.md)।
- फ़्लो के पैनल में आपको **Run test** दिखता हो। इसके लिए फ़्लो सेव करने का एक्सेस चाहिए।

## रन कैसे काम करते हैं { #how-runs-work }

- हर ट्रिगर इवेंट एक **रन** शुरू करता है। रन स्टेप को एक के बाद एक चलाता है।
- कोई स्टेप फ़ेल हो जाए, तो थोड़ी देर रुककर वह अपने आप दोबारा चलता है। कुछ स्टेप को दोबारा चलाना सुरक्षित नहीं होता, जैसे कुछ तरह के मैसेज भेजना। ऐसे स्टेप सिर्फ़ एक बार चलते हैं। दोबारा कोशिश के दौरान रन **Running** दिखाता है।
- स्टेप फिर भी फ़ेल रहे, तो रन **Failed** पर खत्म हो जाता है और बाकी स्टेप नहीं चलते।
- रन **Succeeded**, **Filtered** या **Cancelled** पर भी खत्म हो सकता है। **Filtered** का मतलब है कि कंडीशन ने रन रोका, यह फ़ेल होना नहीं है। **Waiting** का मतलब है कि कोई स्टेप टाइमर पर रुका है।

## स्टेप { #steps }

### लिस्ट से टेस्ट चलाएँ { #run-a-test-from-the-list }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Flows** चुनें।
2. फ़्लो की लाइन पर क्लिक करें।
3. **Run test** पर क्लिक करें। रन चलने के दौरान लाइन में उसकी स्थिति दिखती है।
4. मैसेज पढ़ें, जैसे **Test run succeeded.** या **Test run failed:** और उसके बाद वजह।

!!! warning "टेस्ट रन असली रन होता है"
    **Run test** पब्लिश किया हुआ वर्शन असली असर के साथ चलाता है। इससे भेजे गए मैसेज असली लोगों तक जाते हैं, और बने हुए रिकॉर्ड असली होते हैं।

फ़्लो पॉज़ हो, तो **Run a test while paused?** विंडो खुलती है। **Run test** पर क्लिक करें। टेस्ट के बाद भी फ़्लो पॉज़ ही रहता है।

### बिल्डर से टेस्ट चलाएँ { #run-a-test-from-the-builder }

1. फ़्लो खोलें और टूलबार में **Test** पर क्लिक करें। **Step** पैनल में **Test** टैब खुलता है।
2. **Run test** पर क्लिक करें। आपके बदलाव सेव न हों, तो फ़्लो पहले सेव हो जाता है।
3. बटन के नीचे की लिस्ट में हर स्टेप की स्थिति पढ़ें। लिस्ट को ताज़ा करने के लिए **Refresh** पर क्लिक करें।
4. कैनवास के नीचे **Logs** भी खोल सकते हैं और वहाँ से **Run test** पर क्लिक कर सकते हैं।

चैटबॉट में **Test** टैब कीवर्ड जाँचता है। साथ ही आप ग्राहक बनकर चैट करके भी देख सकते हैं। देखें [WhatsApp चैटबॉट फ़्लो बनाएँ](../create-whatsapp-flow.md)।

### रन हिस्ट्री पढ़ें { #read-the-run-history }

1. लिस्ट में फ़्लो की लाइन पर क्लिक करें, फिर **Recent runs** टैब खोलें।
2. हर रन की स्थिति, शुरू होने का समय और लगा हुआ समय पढ़ें। रन के नीचे लाल नोट में एरर दिखता है, जैसे **Step 2 failed:** और उसके बाद वजह।
3. हर स्टेप, उसकी स्थिति और उसका नतीजा देखने के लिए **View details** पर क्लिक करें।
4. रन को **Latest output** टैब में खोलने के लिए **View output** पर क्लिक करें।

### किसी स्टेप का आउटपुट पढ़ें { #read-a-steps-output }

1. **Latest output** टैब खोलें। इसमें सबसे नया रन दिखता है।
2. **Every step** के नीचे किसी स्टेप पर क्लिक करें। उसका आउटपुट और एरर (अगर हो) दिखता है।
3. **Run details** खोलें। यहाँ **Run id**, **Version pinned**, **Started**, **Finished** और **WHAT STARTED THIS RUN** दिखते हैं।
4. आउटपुट सपोर्ट को भेजना हो, तो **Copy JSON** पर क्लिक करके उसे कॉपी करें। सबसे नए रन पर लौटने के लिए **Back to latest** पर क्लिक करें।

बिल्डर में कोई स्टेप चुनें और उसका **Output** टैब खोलें। वहाँ दिखता है कि पिछले रन में उस स्टेप ने क्या बनाया।

### फ़ेल हुआ रन ठीक करें { #fix-a-failed-run }

1. **Recent runs** या **Latest output** में एरर पढ़ें।
2. बिल्डर खोलें, फ़ेल हुआ स्टेप चुनें और उसे ठीक करें। आम गड़बड़ियाँ ये हैं: कोई फ़ील्ड खाली है, टेम्प्लेट का नाम गलत है, या कनेक्शन एक्सपायर हो गया है।
3. **Save** पर क्लिक करें, फिर **Publish** पर क्लिक करें।
4. ठीक किया हुआ फ़्लो जाँचने के लिए **Run test** पर क्लिक करें।

फ़्लो ठीक करने के बाद फ़ेल हुआ रन अपने आप दोबारा नहीं चलता। अगला ट्रिगर इवेंट आने पर नए वर्शन से नया रन शुरू होता है।

### चल रहे रन रोकें { #stop-runs-in-progress }

1. फ़्लो की लाइन पर क्लिक करें, फिर **More** (**…**) खोलें।
2. **Stop runs** पर क्लिक करें। यह विकल्प तभी दिखता है जब कोई रन चल रहा हो।
3. **Stop the runs in progress?** में **Stop runs** पर क्लिक करें। **Runs stopped.** मैसेज दिखता है।

!!! warning "रोके गए रन दोबारा शुरू नहीं हो सकते"
    रोके गए रन cancelled के रूप में दर्ज हो जाते हैं और उनके बचे हुए स्टेप छोड़ दिए जाते हैं। जो स्टेप पहले से चल रहा है, वह पूरा हो जाता है।

### सिस्टम का रोका हुआ फ़्लो दोबारा चालू करें { #restart-a-flow-the-system-stopped }

**When a record appears** ट्रिगर अपने ऐप तक लगातार कई बार नहीं पहुँच पाए (डिफ़ॉल्ट रूप से 10 बार), तो Ohanvi फ़्लो को रोक देता है। फ़्लो के मालिक को आखिरी एरर के साथ **Automation stopped** नोटिफ़िकेशन मिलता है।

1. कनेक्शन ठीक करें। देखें [कोई ऐप कनेक्ट करें और उसे फ़्लो में इस्तेमाल करें](connect-apps-for-flows.md)।
2. फ़्लो खोलें और बिल्डर टूलबार के **Active** स्विच से उसे फिर चालू करें [VERIFY: how a system-stopped flow is labelled in the list and whether the switch turns it back on]।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **This flow is DRAFT. Only an active or paused flow can be tested.** | फ़्लो कभी पब्लिश नहीं हुआ। | **Publish** पर क्लिक करें, फिर **Run test** पर। |
| **This flow has never been published, so there is no version to run.** | अभी कोई पब्लिश किया हुआ वर्शन नहीं है। | पहले फ़्लो पब्लिश करें। |
| **Could not start a run — the flow is at its concurrency limit. Wait for a run to finish and try again.** | इस फ़्लो के बहुत सारे रन एक साथ चल रहे हैं। | किसी रन के खत्म होने का इंतज़ार करें, फिर दोबारा कोशिश करें। |
| **The run stopped at a filter — that is a normal outcome, not a failure.** | **Continue only if…** कंडीशन आपके टेस्ट डेटा से मेल नहीं खाई। | कंडीशन जाँचें, या ऐसे इवेंट से टेस्ट करें जो कंडीशन से मेल खाता हो। |
| लाइन में **Stuck** दिखता है | कोई रन 6 घंटे से ज़्यादा समय से चल रहा है या इंतज़ार में है। | **Recent runs** खोलें। **Wait** स्टेप जानबूझकर किसी रन को कई दिन रोक सकता है। ऐसा न हो, तो रन रोकें और दोबारा टेस्ट करें। |
| **Run test** ग्रे है और क्लिक नहीं होता | फ़्लो में कोई स्टेप नहीं है, कोई टेस्ट पहले से चल रहा है, या स्टोर या WhatsApp कनेक्ट नहीं है। | स्टेप जोड़ें, चल रहे टेस्ट के खत्म होने का इंतज़ार करें, या **Connect store** या **Connect WhatsApp** पर क्लिक करें। |
