# सोशल साइडबार का इस्तेमाल करें { #use-the-social-sidebar }

बाईं ओर के **Social** पैनल में सिर्फ़ मेन्यू की पंक्तियाँ नहीं हैं। उसमें एक **New** बटन और आपके कनेक्ट किए चैनलों की सूची है। आप पोस्ट शुरू कर सकते हैं, किसी एक चैनल के Publish या Insights पर जा सकते हैं, और और नेटवर्क कनेक्ट कर सकते हैं। इसमें करीब 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखता है। न दिखे तो अपने एडमिन से अपने रोल को Social एक्सेस देने को कहें। देखें [सेटिंग्स ओवरव्यू](../settings/index.md)।

## चरण { #steps }

### कुछ नया शुरू करें { #start-something-new }

1. लेफ़्ट रेल में **Social** खोलें।
2. पैनल के ऊपर **New** पर क्लिक करें। एक मेन्यू खुलता है।
3. **Create Post** विंडो खोलने के लिए **Post** पर क्लिक करें। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।
4. **Connect** → **Social Connections** खोलने के लिए **Connect a new channel** पर क्लिक करें।
5. **Idea** ग्रे है। यह अभी बना नहीं है।

### Channels की सूची पढ़ें { #read-the-channels-list }

1. पैनल को **CHANNELS** तक स्क्रॉल करें। हर कनेक्ट किए अकाउंट की एक पंक्ति है, जिसमें उसका आइकन और नाम है।
2. किसी पंक्ति पर क्लिक करके उसे खोलें।
3. उसके नीचे आपको **Publish** और **Insights** दिखते हैं।
4. सिर्फ़ उस चैनल के पोस्ट देखने के लिए **Publish** पर क्लिक करें। देखें [Publish के फ़िल्टर, ओवरव्यू और पोस्ट का ब्योरा इस्तेमाल करें](use-publish-filters-and-extras.md)।
5. सिर्फ़ उस चैनल के नतीजे देखने के लिए **Insights** पर क्लिक करें। देखें [इनसाइट्स के चार्ट और एक चैनल देखें](explore-insights-charts.md)।
6. जो चैनल आपने खोला है वह हाइलाइट रहता है। अगर दो अकाउंट एक ही नेटवर्क के हैं, तो दोनों साथ में सक्रिय दिखते हैं।

### और चैनल कनेक्ट करें { #connect-more-channels }

1. **CHANNELS** के ऊपर दाईं ओर तीन आइकन हैं: सर्च, सेटिंग्स और प्लस का निशान।
2. **Connect** → **Social Connections** खोलने के लिए सेटिंग्स आइकन (**Settings**) पर क्लिक करें।
3. वही स्क्रीन खोलने के लिए प्लस के निशान (**Connect a new channel**) पर क्लिक करें।
4. **Connect more channels** के तहत किसी नेटवर्क के लोगो पर क्लिक करें, उसका कनेक्ट विज़ार्ड खुलता है।
5. सारे नेटवर्क देखने के लिए प्लस टाइल पर क्लिक करें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **CHANNELS** खाली है | कोई अकाउंट कनेक्ट नहीं है। | प्लस के निशान पर क्लिक करें और एक कनेक्ट करें। |
| **Idea** ग्रे है | यह अभी उपलब्ध नहीं है। | इसकी जगह **Post** इस्तेमाल करें। |
| चैनल की पंक्ति नहीं खुलती | पैनल सिकुड़ा हुआ है। | ग्रुप के नाम पर क्लिक करके उसे खोलें। |
