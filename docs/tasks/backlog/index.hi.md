# बैकलॉग { #backlog }

**Backlog** व्यू वे टास्क दिखाता है जो अभी किसी स्प्रिंट में नहीं हैं, और उनके ऊपर आपके स्प्रिंट। इसका इस्तेमाल टास्क जोड़ने और व्यवस्थित करने के लिए करें, फिर उन्हें स्प्रिंट में प्लान करें।

**इसे कहाँ खोलें:** दाईं ओर की रेल में **Tasks** पर क्लिक करें, **Board** पर क्लिक करें, फिर व्यू स्विचर में **Backlog** पर क्लिक करें।

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [बैकलॉग के आइटम के साथ काम करें](../work-with-the-backlog.md) | आप टास्क जोड़ना, नाम बदलना, दूसरे को सौंपना या ड्रैग करना चाहते हैं। |
| [स्प्रिंट में काम की योजना बनाएँ](../plan-sprints.md) | आप स्प्रिंट बनाना, शुरू करना और पूरा करना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आप टास्क बोर्ड खोल सकते हैं। देखें [टास्क प्रोजेक्ट सेट करें](../set-up-task-project.md)।
- आपके प्रोजेक्ट में कम से कम 1 बोर्ड कॉलम है।
