# अपने एनालिटिक्स पर कार्रवाई करें { #act-on-your-analytics }

**Analytics** में जो दिखता है, उसे अपने अगले कदम में बदलें। इस गाइड के आख़िर तक आप फ़ेल हुए कॉन्टैक्ट हटा चुके होंगे और अपना सबसे अच्छा कैंपेन दोबारा चला चुके होंगे। साथ ही आप अपने टेम्प्लेट या कार्ट-रिकवरी जर्नी को सुधार चुके होंगे। अपना अगला ब्रॉडकास्ट भी आप उसी घंटे में रखेंगे जब आपके ग्राहक सबसे ज़्यादा ऑर्डर करते हैं।

## शुरू करने से पहले { #before-you-start }

- आपने ऐसी अवधि का [मार्केटिंग एनालिटिक्स](read-marketing-analytics.md) या [स्टोर एनालिटिक्स](read-store-analytics.md) पढ़ लिया हो, जिसमें डेटा है।
- आपका रोल **WhatsApp** → **Campaign** और **Template** खोल सकता हो।

## स्टेप { #steps }

### Do this next का कोई सुझाव अपनाएँ { #follow-a-do-this-next-suggestion }

**Marketing Analytics** में **Do this next** के तहत ज़्यादा से ज़्यादा 4 सुझाव दिखते हैं। सबसे ज़रूरी सुझाव सबसे पहले आता है। कोई सुझाव तभी दिखता है जब उस अवधि के आँकड़ों में उसकी ज़रूरत हो।

| सुझाव | कब दिखता है | बटन कहाँ ले जाता है |
| --- | --- | --- |
| **Clean out … contacts that failed to deliver** | फ़ेल हुए मैसेज, भेजे गए मैसेज के 2% या उससे ज़्यादा हैं। | **Review failures** — **Delivery Logs**। |
| **Segment your sends — …% read rate is low** | रीड रेट 55% से कम है। | **Pick a segment** — **Campaign**। |
| **Sharpen the offer — only …% of readers acted** | क्लिक और जवाब, खुले हुए मैसेज के 8% से कम हैं। | **See templates** — **Template**। |
| **Repeat what worked — "…" read best** | कम से कम 1 कैंपेन का रीड रेट 0% से ऊपर है। | **Open campaign** — **Campaign**। |
| **Connect a store to see revenue per campaign** | कोई स्टोर कनेक्ट नहीं है। | **Connect store** — **WhatsApp** → **Manage**। |

1. लेफ़्ट रेल में **Analytics** खोलें, फिर **Marketing Analytics** चुनें।
2. **Do this next** के नीचे सुझाव और उसकी वजह पढ़ें।
3. सुझाव के बटन पर क्लिक करें। उससे जुड़ी स्क्रीन खुल जाएगी।
4. वहाँ ज़रूरी बदलाव करें। जैसे फ़ेल हुए नंबर हटाएँ, या छोटी ऑडियंस चुनें।

### अपना सबसे अच्छा कैंपेन दोबारा चलाएँ { #reuse-your-best-campaign }

1. **Best campaigns** में सबसे ऊपर वाला कैंपेन देखें।
2. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।
3. वही टेम्प्लेट और लगभग वही भेजने का समय रखकर नया ब्रॉडकास्ट बनाएँ।

### कार्ट रिकवरी को बेहतर बनाएँ { #tune-cart-recovery }

1. लेफ़्ट रेल में **Analytics** खोलें, फिर **Store Analytics** चुनें।
2. **Abandoned carts** में **Recovery rate** देखें।
3. **Tune the cart-recovery journey** पर क्लिक करें। **Flows** स्क्रीन खुलेगी।
4. कार्ट-रिकवरी जर्नी खोलें और उसके मैसेज या समय में बदलाव करें।

### टॉप ग्राहकों को फ़ॉलो-अप करें { #follow-up-with-top-customers }

1. **Top customers** में हरे रंग का कोई नाम चुनकर उस पर क्लिक करें। **Inbox** खुलेगा।
2. ग्राहक के नाम के नीचे लिखे नंबर से उसे खोजें।
3. उसे धन्यवाद का मैसेज भेजें, या दोबारा ऑर्डर करने के लिए कहें।

### अपना अगला ब्रॉडकास्ट सही समय पर भेजें { #time-your-next-broadcast }

1. **When orders come in** में कैप्शन पढ़कर पीक घंटा देखें।
2. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Campaign** चुनें।
3. अगला ब्रॉडकास्ट उस घंटे से थोड़ा पहले शेड्यूल करें। ब्रॉडकास्ट फ़ॉर्म में **When** के नीचे **Schedule** चुनें।
