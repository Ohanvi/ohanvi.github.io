# विज्ञापन से आई लीड्स प्रबंधित करें { #manage-ad-leads }

अपने किसी विज्ञापन से आपको मैसेज करने वाले हर व्यक्ति को देखने के लिए **Leads** टैब खोलें। आखिर में आप सूची में खोज सकते हैं, जाँच सकते हैं कि आपके मैसेज डिलीवर हुए और पढ़े गए या नहीं, सूची को Excel फ़ाइल में डाउनलोड कर सकते हैं, और **Inbox** से जवाब दे सकते हैं। इसमें करीब 2 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका Facebook अकाउंट, Page, ad account और व्हाट्सऐप नंबर **Setup** में कनेक्ट हैं। देखें [Click-to-WhatsApp विज्ञापन चलाएँ](../click-to-whatsapp-ads.md)।
- कम से कम 1 विज्ञापन लाइव है और किसी ने उस पर टैप किया है। देखें [विज्ञापन बनाएँ](create-an-ad.md)।
- आपको **WhatsApp** पैनल में **Ads Manager** दिखता है। न दिखे तो अपने एडमिन से पूछें।

## Leads टैब क्या दिखाता है { #what-the-leads-tab-shows }

लीड अपने आप आती हैं। आप उन्हें हाथ से नहीं जोड़ते। जैसे ही कोई आपके किसी विज्ञापन से मैसेज करता है, लीड दिख जाती है।

| कॉलम | यह क्या दिखाता है |
|--------|---------------|
| **LEAD** | व्यक्ति का नाम। नाम न हो तो उसकी जगह फ़ोन नंबर दिखता है। |
| **PHONE** | देश का कोड और फ़ोन नंबर। |
| **AD** | उस विज्ञापन का नाम जिस पर व्यक्ति ने टैप किया। |
| **LEAD DATE** | वह तारीख जब व्यक्ति ने आपको मैसेज किया। |
| **ASSIGNED TO** | वह टीम सदस्य जिसे लीड असाइन की गई है। किसी को असाइन न होने पर **—** दिखता है। |
| **SENT** | आपने इस लीड को कितने मैसेज भेजे। |
| **DELIVERED** | उनमें से कितने लीड के फ़ोन तक पहुँचे। |
| **READ** | उनमें से कितने मैसेज लीड ने खोले। |
| **REPLIED** | लीड ने कितनी बार जवाब दिया। |

आखिरी चार कॉलम मैसेज का फ़नल दिखाते हैं: भेजा गया, फिर डिलीवर हुआ, फिर पढ़ा गया, फिर जवाब मिला। जिस लीड का **SENT** ज़्यादा है और **READ** 0 है, उसने आपके मैसेज नहीं खोले हैं।

## चरण { #steps }

### सूची खोलें { #open-the-list }

1. लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Ads Manager** चुनें।
2. **Leads** पर क्लिक करें। लीड की सूची खुलती है, एक बार में 25 पंक्तियाँ।

    ![Leads टैब, जिसमें सर्च बॉक्स, Export बटन और पहली विज्ञापन बातचीत से पहले का संदेश No leads yet दिख रहा है](../../assets/screenshots/whatsapp-ads-leads-1-empty.png)


    

3. सबसे नई लीड लोड करने के लिए **Refresh** पर क्लिक करें।

### लीड खोजें { #find-a-lead }

1. **Search by name, phone or ad** बॉक्स पर क्लिक करें।
2. नाम का कोई हिस्सा, फ़ोन नंबर या विज्ञापन का नाम लिखें। टाइप करते ही तालिका फ़िल्टर होती है।
3. फिर से सारी लीड देखने के लिए बॉक्स खाली करें।

!!! note "ध्यान दें"
    खोज सिर्फ़ उस पेज की पंक्तियों में होती है जिस पर आप हैं। ज़्यादा लीड में खोजने के लिए **Rows per page** बढ़ाएँ या अगले पेज पर जाएँ।

### पेजों के बीच जाएँ { #move-between-pages }

1. तालिका के नीचे देखें। वहाँ **Rows per page:** और **1–25 of 140** जैसी गिनती दिखती है।
2. एक साथ ज़्यादा लीड दिखाने के लिए **Rows per page:** बदलें।
3. अगले या पिछले पेज पर जाने के लिए पेज के तीर इस्तेमाल करें। [VERIFY: exact arrow labels]

### मैसेज की डिलीवरी जाँचें { #check-message-delivery }

1. तालिका में लीड खोजें।
2. आपने कितने मैसेज भेजे, यह देखने के लिए **SENT** पढ़ें।
3. कितने फ़ोन तक पहुँचे, यह देखने के लिए **DELIVERED** पढ़ें।
4. लीड ने कितने खोले, यह देखने के लिए **READ** पढ़ें।
5. लीड ने कितनी बार जवाब दिया, यह देखने के लिए **REPLIED** पढ़ें।

### सूची डाउनलोड करें { #download-the-list }

1. ऊपरी बार में **Export** पर क्लिक करें। जिस पेज पर ऊपरी बार नहीं है, वहाँ बटन पर **Download Report** लिखा होता है।
2. अपने डाउनलोड फ़ोल्डर से फ़ाइल **ad_leads.xlsx** खोलें।

डाउनलोड करने के लिए कोई लीड न हो तो बटन धूसर रहता है।

### लीड को जवाब दें { #reply-to-a-lead }

1. **WhatsApp** पैनल से **Inbox** खोलें।
2. लीड की चैट खोजें। उनका पहला मैसेज वहाँ पहले से मौजूद है।
3. किसी भी दूसरी चैट की तरह जवाब दें।

    

### लीड को टीम सदस्य को असाइन करें { #assign-a-lead-to-a-team-member }

1. **Inbox** में लीड की चैट खोलें।
2. चैट को टीम सदस्य को असाइन करें।
3. **Leads** पर लौटें और **Refresh** पर क्लिक करें। **ASSIGNED TO** में नाम दिखता है।

इस टैब में **ASSIGNED TO** कॉलम सिर्फ़ पढ़ने के लिए है।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
|-------|-------|-----|
| **Set up now** बटन के साथ **Connect your Meta ad account** | सेटअप पूरा नहीं हुआ है और अभी कोई लीड नहीं है। | **Set up now** पर क्लिक करें और **Setup** के 3 चरण पूरे करें। |
| **No leads yet** | अभी तक किसी ने विज्ञापन से आपको मैसेज नहीं किया। | जाँचें कि आपका विज्ञापन **Ads Manager** में **Active** है। किसी के मैसेज करते ही लीड यहाँ आ जाती है। |
| **Could not load leads** | सूची लोड नहीं हुई। | **Retry** पर क्लिक करें। बार-बार फ़ेल हो तो पेज रीलोड करें। |
| **Could not download the leads report.** | Excel फ़ाइल बन नहीं सकी। | **Download Report** पर दोबारा क्लिक करें। दो बार फ़ेल हो तो पहले **Refresh** पर क्लिक करें। |
| **ASSIGNED TO** में **—** दिखता है | लीड को कोई टीम सदस्य असाइन नहीं है। | **Inbox** से चैट असाइन करें। |
| कई लीड के लिए **READ** 0 है | लीड ने आपके मैसेज नहीं खोले हैं, या उनके रीड रिसीट बंद हैं। | **Inbox** में मैसेज जाँचें और छोटा फ़ॉलो-अप भेजें। |
