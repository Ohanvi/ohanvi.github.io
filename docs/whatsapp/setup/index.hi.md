# WhatsApp सेट करें { #set-up-whatsapp }

ये स्क्रीन WhatsApp पैनल में नहीं मिलतीं। नीचे बाएँ में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर Settings → WhatsApp खोलें। यहीं से आप अपना नंबर कनेक्ट करते हैं और उसकी सेटिंग्स बदलते हैं।

**यह कहाँ मिलेगा:** नीचे बाएँ में अपने नाम के पहले अक्षरों पर क्लिक करें, **Settings** चुनें, फिर **WhatsApp**।
