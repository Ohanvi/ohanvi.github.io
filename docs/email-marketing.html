Sample guide

Create and send an email campaign

Build a campaign, select a segment, test the message, and track opens and clicks.

Intermediate12 minutesEmail Marketing

Steps

  1. Open Email Marketing and choose New campaign.
  2. Add subject, sender name, preview text, and campaign tags.
  3. Select a template or start with a blank email.
  4. Choose an audience segment and suppression list.
  5. Send a test email, review links, then schedule or send now.

Pre-send checks

  • All links open correctly.
  • Unsubscribe footer is present.
  • Sender domain authentication is healthy.
