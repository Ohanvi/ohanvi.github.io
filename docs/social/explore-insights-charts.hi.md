# इनसाइट्स के चार्ट और एक चैनल देखें { #explore-insights-charts-and-one-channel }

Insights आपके सभी चैनल एक साथ दिखाता है। किसी एक चैनल पर क्लिक करके उसकी पोस्ट, हफ़्ते की मुख्य बातें और मेट्रिक्स चार्ट देखें। यह पेज **Insights** के हर चार्ट, टॉगल और फ़िल्टर को समझाता है। इसमें लगभग 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आपको लेफ़्ट रेल में **Social** दिखता है, जिसके पैनल में **Insights** है।
- कम से कम एक नेटवर्क कनेक्ट है और उस पर पोस्ट पब्लिश हुई हैं। देखें [सोशल पोस्ट बनाएँ और पब्लिश करें](create-social-post.md)।
- कुल आँकड़ों और टॉप पोस्ट के लिए देखें [सोशल इनसाइट्स पढ़ें](view-social-insights.md)।

## चरण { #steps }

### अवधि और चैनल चुनें { #pick-the-period-and-the-channel }

1. लेफ़्ट रेल में **Social** खोलें, फिर **Insights** चुनें।
2. ऊपर से **7 days**, **30 days** या **Month to date** चुनें। हर आँकड़े की तुलना उससे पिछली अवधि से होती है।
3. **Channels** पर क्लिक करें।
4. **All Channels** चुनें, या कोई एक चैनल। आपके चुनाव पर भरा हुआ बिंदु लगा होता है।
5. अगर कोई चैनल कनेक्ट नहीं है, तो सूची में **No channels connected** लिखा होता है।
6. आँकड़े दोबारा लोड करने के लिए **Refresh** पर क्लिक करें।

### Tags फ़िल्टर इस्तेमाल करें { #use-the-tags-filter }

1. **Tags** पर क्लिक करें।
2. सूची पढ़ें। अभी उसमें **No tags available yet** लिखा है।

!!! note "ध्यान दें"
    टैग पोस्ट पर लगे होते हैं, पर Insights अभी उन्हें जोड़कर नहीं दिखाता। फ़िल्टर मौजूद है, पर उसमें चुनने के लिए कुछ नहीं है।

### सभी चैनलों के लिए Performance टेबल पढ़ें { #read-the-performance-table-for-all-channels }

1. **All Channels** चुनकर **Performance** तक स्क्रॉल करें।
2. हर चैनल के **Posts**, **Reactions**, **Comments** और **Eng. Rate** पढ़ें।
3. किसी चैनल की पंक्ति पर क्लिक करें। Insights उस चैनल पर चला जाता है।
4. अगर किसी चैनल पर कोई पोस्ट नहीं थी, तो टेबल में **No channel activity in this period.** लिखा होता है।

### Followers चार्ट पढ़ें { #read-the-followers-chart }

1. **Followers** तक स्क्रॉल करें।
2. चार्ट के ऊपर दाईं ओर **Bar**, **Line** या **Growth** पर क्लिक करें।
3. **Bar** चैनलों की तुलना करता है। **Line** रुझान दिखाता है। **Growth** दिखाता है कि फ़ॉलोअर कितने बदले।

### Posts चार्ट पढ़ें { #read-the-posts-chart }

1. **Posts** तक स्क्रॉल करें।
2. हर चैनल ने कितनी पोस्ट पब्लिश कीं, इसकी तुलना के लिए **Bar** पर क्लिक करें।
3. चैनलों को एक के ऊपर एक रखने के लिए **Stacked Bar** पर क्लिक करें।

### एक चैनल देखें { #look-at-one-channel }

1. **Channels** में कोई एक चैनल चुनें, या **Performance** में उसकी पंक्ति पर क्लिक करें।
2. सबसे ऊपर **WEEKLY TAKEAWAYS** पढ़ें। उसे समेटने के लिए बगल के तीर पर क्लिक करें।
3. दोनों कार्ड पढ़ें:
    - **Start Building Your Posting Habit** दिखाता है कि इस अवधि में आपने कितनी पोस्ट पब्लिश कीं। **Publish** खोलने के लिए **Create a Post** पर क्लिक करें।
    - **Set a Posting Goal** लक्ष्य तय करने की याद दिलाता है। इसमें अभी कोई बटन नहीं है।
4. **Performance per Post** पढ़ें। इसमें हर पोस्ट उसके **Reactions**, **Comments** और **Eng. Rate** के साथ दिखती है। **Posts · N** लाइन गिनती बताती है।
5. अगर आपने कुछ पब्लिश नहीं किया, तो **No published posts in this period.** लिखा होता है।

### Metrics टैब पढ़ें { #read-the-metrics-tabs }

ये तब दिखते हैं जब कोई एक चैनल चुना हो।

1. **Metrics** तक स्क्रॉल करें।
2. पोस्ट चार्ट देखने के लिए **Content Impact** पर क्लिक करें।
3. फ़ॉलोअर का लाइन चार्ट देखने के लिए **Audience Growth** पर क्लिक करें।
4. **Visibility** पर क्लिक करें। उसमें लिखा है **Impressions and reach are not reported by the connected networks yet.**

### अपनी टॉप पोस्ट को रैंक करें { #rank-your-top-posts }

1. **Top 5 Posts** के नीचे ऊपर दाईं ओर **Reactions** या **Comments** पर क्लिक करें।
2. पाँचों पोस्ट कार्ड उसी क्रम में पढ़ें। हर कार्ड में उसका चैनल, तारीख और टेक्स्ट दिखता है।
3. कार्ड पर **Open post** आइकन अभी ग्रे है। किसी पोस्ट पर काम करने के लिए उसे **Publish** में ढूँढें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| सूची में **No channels connected** | कोई नेटवर्क कनेक्ट नहीं है। | कोई कनेक्ट करें। देखें [सोशल अकाउंट कनेक्ट करें](connect-social-accounts.md)। |
| **No channel activity in this period.** | चैनल ने उस अवधि में कुछ पोस्ट नहीं किया। | लंबी अवधि चुनें। |
| **No published posts in this period.** | इस चैनल के लिए कुछ पब्लिश नहीं हुआ। | लंबी अवधि चुनें, या कोई पोस्ट पब्लिश करें। |
| **No tags available yet** | Insights में अभी टैग का जोड़ा हुआ व्यू नहीं है। | बाकी फ़िल्टर इस्तेमाल करें। |
| **Visibility** खाली है | नेटवर्क अभी इम्प्रेशन या रीच नहीं भेजते। | कोई समाधान नहीं। इसके बजाय **Content Impact** इस्तेमाल करें। |
