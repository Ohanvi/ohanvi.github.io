# Inbox { #inbox }

Inbox में आपकी टीम ग्राहकों से चैट करती है। यहाँ आप जवाब दे सकते हैं, चैट असाइन कर सकते हैं और उन्हें बोर्ड पर आगे बढ़ा सकते हैं। स्टोर के ऑर्डर भी यहीं संभालें और कॉल भी करें।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **Inbox** चुनें।

![All, Requesting और Active टैब और चैट लिस्ट के साथ Inbox](../../assets/screenshots/whatsapp-inbox-1-tabs.png)

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर Ohanvi से कनेक्ट होना चाहिए। देखें [अपना WhatsApp नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस मिला होना चाहिए। स्क्रीन न दिखे, तो अपने एडमिन से पूछें।
