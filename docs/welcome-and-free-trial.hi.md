# अपना फ़्री ट्रायल शुरू करें { #start-your-free-trial }

अकाउंट बनाते ही **Welcome aboard** स्क्रीन आपका 14 दिन का फ़्री ट्रायल शुरू कर देती है। आप चाहें तो अभी प्लान चुन सकते हैं, या छोड़कर बाद में सब्सक्राइब कर सकते हैं। ट्रायल दोनों हालात में चलता रहता है। इसमें करीब 1 मिनट लगता है।

## शुरू करने से पहले { #before-you-start }

- आपने अपना अकाउंट बना लिया हो। देखें [Ohanvi पर साइन अप करें](sign-up.md)।

## चरण { #steps }

### वेलकम स्क्रीन पढ़ें { #read-the-welcome-screen }

1. साइन-अप के बाद **Welcome aboard** स्क्रीन खुलती है।
2. उसके नीचे की पंक्ति पढ़ें। उसमें लिखा होता है कि आपका अकाउंट तैयार है और आपका 14 दिन का फ़्री ट्रायल शुरू हो चुका है।
3. उसके बाद का नोट पढ़ें। आपका ट्रायल दोनों हालात में चलता रहता है। अभी सब्सक्राइब करने का मतलब बस इतना है कि ट्रायल खत्म होने पर आपका काम बिना रुके चलता रहे।

### यूज़र की संख्या चुनें { #choose-how-many-users }

1. **How many people will use it?** के नीचे, माइनस और प्लस बटन से यूज़र की संख्या तय करें।
2. स्क्रीन बताती है कि यह सिर्फ़ इसलिए है कि आपके लिए प्लान की कीमत बताई जा सके। आप इसे कभी भी बदल सकते हैं।
3. **See the plans** पर क्लिक करें।

### प्लान चुनें { #pick-a-plan }

1. प्लान कार्ड पढ़ें। अगर कोई प्लान नहीं है, तो स्क्रीन पर **No plans are available yet.** दिखता है।
2. **Choose** पर क्लिक करें और उस प्लान का नाम देखें। चेकआउट का शीर्षक **Choose a plan for** आपकी चुनी संख्या **users** के साथ दिखता है।
3. भुगतान पूरा करें। देखें [अपना प्लान और यूज़र प्रबंधित करें](billing/manage-plan-and-users.md)।
4. वापस जाने के लिए **Back** पर क्लिक करें।

### छोड़ें और ट्रायल जारी रखें { #skip-and-keep-the-trial }

1. **Continue on the free trial** या **Skip — continue on the free trial** पर क्लिक करें।
2. Ohanvi **Home** खोल देता है। आपका ट्रायल चलता रहता है।
