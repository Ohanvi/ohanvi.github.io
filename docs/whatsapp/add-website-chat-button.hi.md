# अपनी वेबसाइट पर WhatsApp चैट बटन लगाएँ { #add-a-whatsapp-chat-button-to-your-website }

अपनी वेबसाइट पर WhatsApp का एक बटन लगाएँ, जो स्क्रीन पर तैरता रहता है। इससे विज़िटर एक क्लिक में आपको मैसेज कर सकते हैं। आख़िर में आपके पास अपने लेबल, रंग और पहले मैसेज वाला बटन होगा। साथ में एक स्निपेट भी होगा, जिसे आप अपनी साइट में पेस्ट कर सकते हैं।

## शुरू करने से पहले { #before-you-start }

- आपका WhatsApp नंबर कनेक्ट होना चाहिए। देखें [अपना WhatsApp नंबर कनेक्ट करें](connect-whatsapp-number.md)।
- आपको अपनी वेबसाइट का HTML बदलना आता हो, या आपकी टीम में कोई यह कर सकता हो।

## स्टेप { #steps }

### बटन की सेटिंग्स खोलें { #open-the-button-settings }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षर पर क्लिक करें। फिर **Settings** पर क्लिक करें।
2. **WhatsApp** चुनें, फिर **Website Button** चुनें। **Website Chat Button** पेज खुल जाएगा।

आप इसे WhatsApp **Dashboard** से भी खोल सकते हैं। **Quick Actions** में **Website Chat Widget** पर क्लिक करें।

![Website Chat Button की सेटिंग्स। इसमें फ़ोन नंबर, लेबल, जगह, मैसेज, मार्जिन, रंग और बटन का प्रीव्यू दिखता है](../assets/screenshots/whatsapp-website-button-1-settings.png)

### बटन सेट करें { #set-up-the-button }

1. **WhatsApp Phone Number** देख लें। इसमें आपका कनेक्ट किया हुआ नंबर पहले से भरा होता है।
2. **Button Label** में बटन पर दिखने वाला टेक्स्ट लिखें। यहाँ पहले से **Chat with us** लिखा होता है।
3. **Position** में **Right** या **Left** चुनें।
4. **Pre-filled Message** में वह पहला मैसेज लिखें, जो विज़िटर आपको भेजेगा। यहाँ पहले से **Hi, I have a question** लिखा होता है।
5. बटन की जगह और शक्ल तय करने के लिए **Margin Bottom (px)**, **Margin Side (px)** और **Border Radius (px)** भरें। ये पहले से **30**, **30** और **24** होते हैं।
6. **Button Color** चुनें।
7. ज़रूरी नहीं, पर आप चाहें तो **Chat Widget** चालू करें। तब सादे आइकन की जगह बटन के ऊपर लेबल वाला पैनल दिखेगा।
8. ज़रूरी नहीं, पर आप चाहें तो **URL Personalisation** चालू करें। तब विज़िटर जो पेज देख रहा है, उसके हिसाब से उसे अलग स्वागत मैसेज दिखेगा।

नीचे दाएँ कोने में प्रीव्यू बटन दिखता है। उसमें देख लें कि आपका बटन कैसा लगेगा।

### बटन को अपनी वेबसाइट में जोड़ें { #add-the-button-to-your-website }

1. **Generate Snippet** पर क्लिक करें।
2. स्निपेट को अपनी वेबसाइट के HTML में पेस्ट करें। उसे बंद करने वाले `</body>` टैग से ठीक पहले रखें।
