# Set up a WhatsApp broadcast campaign

Create an approved template, select contacts, schedule the broadcast, and review delivery results.

!!! info "Sample guide"
    This page is a documentation sample. Replace labels and screenshots with the exact Ohanvi portal screens.

## Before you start

- Your WhatsApp Business account is connected to Ohanvi.
- Your message template is approved by Meta.
- Your contact list has valid opt-in status.

## Steps

1. Open **WhatsApp Marketing** from the Ohanvi sidebar.
2. Select **Broadcasts**, then choose **Create broadcast**.
3. Pick an approved template.
4. Map dynamic fields such as customer name, offer code, appointment date, or order number.
5. Select a saved audience or upload a CSV contact list.
6. Review the preview for sample contacts.
7. Choose **Send now** or schedule a future date and time.
8. Publish the broadcast.

## Troubleshooting

| Issue | Fix |
| --- | --- |
| Template unavailable | Confirm Meta approved it for the connected business number. |
| Contacts skipped | Check opt-in status and phone number format. |
| Low delivery | Review failed reasons in the delivery report. |
