# Forms

Forms collect answers by chat, web or link.

## Where to find it

Open **Forms** in the left rail. It has **Forms** and **Submissions**.

## Guides

| Guide | Use it when |
| --- | --- |
| [Create and manage forms](../forms-create-and-manage.md) | You start or tidy forms. |
| [Build a form](../forms-build-a-form.md) | You add questions and settings. |
| [Preview and share a form](../forms-share-and-preview.md) | You send it out. |
| [Read form responses](../forms-read-responses.md) | You want a summary. |
| [Read form submissions](../forms-read-submissions.md) | You fix unprocessed answers. |
| [Signup and popup forms](../collect-signups-with-forms.md) | You collect email signups. |

## Before you start

- Access to **Forms** in the left rail.
