# रेफ़र करें और कमाएँ { #refer-and-earn }

बिज़नेस को Ohanvi पर बुलाएँ और हर बिज़नेस जितने महीने भुगतान करता रहे, उतने महीने उसके भुगतान का एक हिस्सा कमाएँ। आपका कमीशन पहले आपके अपने प्लान को कवर करता है। उससे ज़्यादा जो बचे, उसे आप निकाल सकते हैं। पेआउट सेट करने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- आप एडमिन के रूप में साइन इन हैं।
- पैसे निकालने के लिए आपके पास अपने नाम का बैंक अकाउंट या UPI ID हो।

## चरण { #steps }

### रेफ़र करें और कमाएँ खोलें { #open-refer-and-earn }

1. नीचे बाएँ कोने में अपने नाम के पहले अक्षरों पर क्लिक करें, फिर **Settings** पर क्लिक करें।
2. **Billing & credits** के नीचे **Refer & Earn** पर क्लिक करें। **Refer & earn** पेज खुलता है।
3. **How it works** पैनल पढ़ें। कोई बिज़नेस आपके कोड से साइन अप करता है और अपना पहला इनवॉइस चुकाता है, फिर वह जितने महीने भुगतान करता रहे, आप उसके प्लान का एक हिस्सा कमाते हैं।

### अपना कोड शेयर करें { #share-your-code }

1. **YOUR REFERRAL CODE** खोजें।
2. **Copy code** पर क्लिक करें। **Referral code copied** संदेश दिखता है।
3. या **Copy invite link** पर क्लिक करें। **Invite link copied** संदेश दिखता है। इसे उस बिज़नेस को भेजें।
4. बिज़नेस साइन अप करते समय **Have a referral code?** में आपका कोड भी लिख सकता है। देखें [Ohanvi पर साइन अप करें](../sign-up.md)।

### अपनी कमाई पढ़ें { #read-your-earnings }

1. **Total referred**, **Lifetime earned**, **This month** और **Monthly commission** पढ़ें।
2. **Your plan this month** पढ़ें। जब आपका कमीशन आपके प्लान को कवर कर देता है, तो **Commission covering your plan** दिखता है, और बाकी रकम **Balance beyond your next invoice** के रूप में दिखती है।
3. **Referred businesses** में हर बिज़नेस का स्टेटस देखें: **Signed up, not paid**, **Active & paying** या **Stopped paying**।

### पेआउट की जानकारी जोड़ें { #add-payout-details }

1. **Add payout details** पर क्लिक करें। अगर आपकी जानकारी पहले से है, तो **Update payout details** या **Change** पर क्लिक करें।
2. **Bank** या **UPI ID** चुनें।
3. बैंक के लिए **Account holder name**, **Bank name**, **Account number** और **IFSC** भरें, जैसे `HDFC0001234`। UPI के लिए अपनी **UPI ID** लिखें, जैसे `name@okhdfcbank`।
4. **Save** पर क्लिक करें। जानकारी एन्क्रिप्ट होकर सेव होती है और दोबारा पूरी नहीं दिखाई जाती। सेव करने पर पुरानी जानकारी बदल जाती है।

### कमाई निकालें { #withdraw-earnings }

1. **Withdrawable** के नीचे अपना बैलेंस देखें।
2. **Withdraw** या **Request withdrawal** पर क्लिक करें। **Withdraw earnings** विंडो खुलती है।
3. **Amount** लिखें। यह दिखाई गई न्यूनतम रकम से कम और आपके बैलेंस से ज़्यादा नहीं होनी चाहिए।
4. **Request withdrawal** पर क्लिक करें। **Withdrawal requested — we will review it shortly** संदेश दिखता है।
5. इसे **Withdrawals** में ट्रैक करें। स्टेटस **Requested** से **Approved** और फिर **Paid** हो जाता है, या **Declined** दिखता है। **Paid** वाली पंक्ति में UTR दिखता है।
6. पैसे 3–5 कार्य दिवसों में आपके अकाउंट में पहुँच जाते हैं।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **No payout account yet — add one to withdraw.** | कोई पेआउट जानकारी सेव नहीं है। | **Add payout details** पर क्लिक करें। |
| **Enter a valid IFSC, e.g. HDFC0001234** | IFSC का फ़ॉर्मैट गलत है। | कोड जाँचें और दोबारा लिखें। |
| **Enter a valid UPI ID, e.g. name@okhdfcbank** | UPI ID का फ़ॉर्मैट गलत है। | उसे जाँचें और दोबारा लिखें। |
| **Minimum withdrawal is** और एक रकम | आपकी रकम बहुत कम है। | कम से कम न्यूनतम रकम लिखें। |
| **Could not request the withdrawal.** | अनुरोध फ़ेल हो गया। | दोबारा कोशिश करें। |
