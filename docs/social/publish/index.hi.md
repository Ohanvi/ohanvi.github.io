# पब्लिश करें { #publish }

Publish वह जगह है जहाँ पोस्ट बनाई और प्रबंधित की जाती हैं। आप पोस्ट लिख सकते हैं, उसे शेड्यूल कर सकते हैं, समीक्षा के लिए भेज सकते हैं, और पब्लिश होने के बाद उसे ट्रैक कर सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **Social** खोलें, फिर **Publish** चुनें।
