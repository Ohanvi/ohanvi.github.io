# सेल्स फ़ोरकास्ट पढ़ें { #read-the-sales-forecast }

देखें कि आपकी खुली डील से कितनी कमाई होने की संभावना है, और वह आपके टारगेट से कितनी मेल खाती है। आखिर में आप एक ही स्क्रीन से बता सकते हैं कि "क्या हम इस महीने का टारगेट पूरा करेंगे?" फ़ोरकास्ट पढ़ने में करीब 5 मिनट लगते हैं।

## शुरू करने से पहले { #before-you-start }

- लेफ़्ट रेल में आपको **CRM** दिखे और उसके पैनल में **Forecast** हो। इसके लिए CRM रिपोर्ट का एक्सेस चाहिए। अगर यह नहीं दिखता, तो अपने एडमिन से कहें।
- आपकी डील में स्टेज, रकम और अनुमानित बंद होने की तारीख भरी हो। आँकड़े इन्हीं से आते हैं। देखें [डील बनाएँ और प्रबंधित करें](manage-deals.md)।
- कोटा के आँकड़ों के लिए पहले कोटा सेट करें। देखें [सेल्स कोटा सेट करें](set-sales-quotas.md)।

## चरण { #steps }

### फ़ोरकास्ट खोलें { #open-the-forecast }

1. लेफ़्ट रेल में **CRM** खोलें, फिर **Forecast** चुनें।

### तीनों आँकड़े पढ़ें { #read-the-three-figures }

1. **Weighted forecast** पढ़ें। यह हर खुली डील की कीमत को उसके जीतने की संभावना से गुणा करके बनता है।
2. **Open pipeline** पढ़ें। यह वह सबसे अच्छी स्थिति है जब हर खुली डील बंद हो जाए।
3. **Committed** पढ़ें। यह 80% या उससे ऊपर वाले स्टेज की डील की वेटेड कीमत है।

### चार्ट पढ़ें { #read-the-charts }

1. **Weighted pipeline by stage** पढ़कर देखें कि पैसा किस स्टेज में अटका है।
2. **Quota attainment** पढ़कर देखें कि महीने के कोटा में कितनी प्रगति हुई।
3. **3-month forecast** पढ़ें। इस चार्ट में **Committed** वह है जो पहले ही जीता जा चुका है, और **Upside** खुली डील की वेटेड कीमत है।

### फ़ोरकास्ट डाउनलोड करें { #download-the-forecast }

1. **Export** पर क्लिक करें।
2. Ohanvi फ़ोरकास्ट की फ़ाइल डाउनलोड करता है।

### कोटा खोलें { #open-the-quotas }

1. **Manage quotas** पर क्लिक करें। **Sales Quotas** की सूची खुलती है।
2. नया टारगेट जोड़ने के लिए [सेल्स कोटा सेट करें](set-sales-quotas.md) देखें।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| आँकड़े 0 हैं | आपकी खुली डील में रकम या बंद होने की तारीख नहीं है। | अपनी डील में **Amount** और **Expected close** भरें। |
| **Quota attainment** खाली है | इस अवधि के लिए कोई कोटा सेट नहीं है। | कोटा जोड़ें। देखें [सेल्स कोटा सेट करें](set-sales-quotas.md)। |
| **CRM** पैनल में **Forecast** नहीं है | आपके रोल के पास CRM रिपोर्ट का एक्सेस नहीं है। | अपने एडमिन से कहें। |
