# टास्क बनाएँ और असाइन करें { #create-and-assign-tasks }

टास्क बनाएँ और हर टास्क को एक ओनर, एक प्रायोरिटी और एक ड्यू डेट दें। बड़े काम को सबटास्क में बाँट दें। इसके बाद हर टास्क बोर्ड के किसी कॉलम में OHANVI-12 जैसी key के साथ दिखेगा, और असाइनी उसे अपनी **Assigned to me** लिस्ट में देखेगा।

## शुरू करने से पहले { #before-you-start }

- आपके वर्कस्पेस में कम से कम 1 बोर्ड कॉलम वाला टास्क प्रोजेक्ट हो। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)।
- जिन लोगों को आप टास्क देना चाहते हैं, वे प्रोजेक्ट के मेंबर हों। असाइनी की लिस्ट में सिर्फ़ प्रोजेक्ट के मेंबर दिखते हैं।

## स्टेप { #steps }

### Tasks पैनल से टास्क बनाएँ { #create-a-task-from-the-tasks-panel }

1. दाईं ओर की रेल में **Tasks** पर क्लिक करें। **Tasks** पैनल खुलेगा।
2. पैनल के ऊपर **Create** पर क्लिक करें। टास्क डायलॉग खुलेगा।
3. **Add a summary** पर क्लिक करें और लिखें कि क्या करना है। सिर्फ़ यही फ़ील्ड भरना ज़रूरी है।
4. चाहें तो **Description** में पूरी जानकारी लिखें। लिस्ट शुरू करने के लिए `- ` या `1. ` टाइप करें। इमेज या फ़ाइलें सीधे पेस्ट भी कर सकते हैं।
5. चाहें तो दाईं ओर के पैनल में फ़ील्ड सेट करें, जैसा [टास्क की जानकारी सेट करें](#set-the-task-details) में बताया है।
6. **Create** पर क्लिक करें। टास्क बोर्ड में जुड़ जाएगा।

### बोर्ड पर टास्क बनाएँ { #create-a-task-on-the-board }

1. बोर्ड पर पेज के ऊपर **Create** पर क्लिक करें। वही टास्क डायलॉग खुलेगा। उसका स्टेटस पहला कॉलम होगा।
2. ऊपर के स्टेप 3 से 6 की तरह टास्क भरें।

### सीधे किसी कॉलम में टास्क जोड़ें { #add-a-task-straight-into-a-column }

जल्दी में टास्क जोड़ना हो और सिर्फ़ समरी, टाइप और असाइनी चाहिए, तो यह तरीका अपनाएँ।

1. बोर्ड पर किसी कॉलम पर माउस ले जाएँ और उसके कार्ड के नीचे **Create** पर क्लिक करें।
2. **What needs to be done?** में समरी लिखें।
3. चाहें तो टाइप आइकन (टूलटिप **Work type**) पर क्लिक करें और **Epic**, **Story**, **Task**, **Bug** या **Sub-task** चुनें।
4. चाहें तो व्यक्ति वाले आइकन पर क्लिक करें और असाइनी चुनें।
5. Enter दबाएँ, या टिक (टूलटिप **Create**) पर क्लिक करें। टास्क उसी कॉलम में दिखेगा।

### टास्क की जानकारी सेट करें { #set-the-task-details }

टास्क डायलॉग के दाईं ओर के पैनल में टास्क की जानकारी होती है। अगर **Details** बंद है, तो उसे खोलें।

| फ़ील्ड | यह क्या करती है |
| --- | --- |
| Status (पैनल के ऊपर) | वह कॉलम जिसमें टास्क रहता है। नए टास्क में यह वही कॉलम होता है जहाँ से आपने शुरू किया था। |
| **Assignee** | प्रोजेक्ट का वह मेंबर जो टास्क का ओनर है। खुद लेने के लिए **Assign to me** पर क्लिक करें। |
| **Labels** | मिलते-जुलते टास्क को एक ग्रुप में रखने के लिए टैग। इनमें आप कुछ भी लिख सकते हैं। |
| **Priority** | **Highest**, **High**, **Medium**, **Low** या **Lowest**। नए टास्क में **Medium** पहले से चुना रहता है। |
| **Parent** | वह Epic या Story जिससे यह टास्क जुड़ा है। |
| **Team** | वह टीम जिसका यह टास्क है। |
| **Sprint** | वह स्प्रिंट जिसमें यह टास्क प्लान किया गया है। देखें [स्प्रिंट में काम की योजना बनाएँ](plan-sprints.md)। |
| **Story point estimate** | काम कितना बड़ा है, इसका अंदाज़ा। |
| **Start date** / **Due date** | काम कब शुरू होगा और कब तक पूरा करना है। ड्यू डेट से ही तय होता है कि टास्क पर **Due today** या **Overdue** टैग लगेगा। |
| **Original estimate** / **Remaining estimate** | काम में लगने वाले समय का अंदाज़ा। w, d, h और m इस्तेमाल करें, जैसे `2h 30m` या `1d`। |
| **Reporter** | जिसने टास्क उठाया। इसमें आपका नाम पहले से भरा होता है। |

### असाइनी या बाकी जानकारी बाद में बदलें { #change-the-assignee-or-other-details-later }

1. बोर्ड पर किसी टास्क कार्ड पर, या **Tasks** पैनल में किसी टास्क की पंक्ति पर क्लिक करें। टास्क डायलॉग खुलेगा।
2. **Assignee**, **Priority**, **Due date** या कोई और फ़ील्ड बदलें।
3. **Save** पर क्लिक करें।

टास्क खोले बिना भी बोर्ड से असाइनी बदल सकते हैं। कार्ड पर अवतार पर क्लिक करें और किसी को चुनें।

### टास्क को सबटास्क में बाँटें { #break-a-task-into-subtasks }

1. कोई ऐसा टास्क खोलें जो पहले से सेव है।
2. **Subtasks** के नीचे **Add subtask** पर क्लिक करें।
3. **Name this subtask** में सबटास्क की समरी लिखें।
4. Enter दबाएँ, या टिक (टूलटिप **Create**) पर क्लिक करें। सबटास्क **Subtasks** टेबल में उसकी **Priority**, **Assignee** और **Status** के साथ दिखेगा।

### टास्क की कॉपी बनाएँ { #copy-a-task }

1. बोर्ड पर किसी टास्क कार्ड पर माउस ले जाएँ और उसके **…** मेन्यू पर क्लिक करें।
2. **Clone** पर क्लिक करें। **Ticket cloned.** मैसेज दिखेगा और कॉपी बोर्ड में जुड़ जाएगी।

टास्क एक बार बनने के बाद डिलीट नहीं हो सकता। किसी टास्क को चालू बोर्ड से हटाना हो, तो उसे done या cancelled कॉलम में ले जाएँ।

## समस्या का समाधान { #troubleshooting }

| समस्या | कारण | समाधान |
| --- | --- | --- |
| **Create** पर क्लिक करने पर कुछ नहीं होता और समरी वाला बॉक्स खुल जाता है | समरी खाली है। | समरी लिखें, फिर दोबारा **Create** पर क्लिक करें। |
| **No ticket project is loaded.** | बोर्ड पर प्रोजेक्ट अभी लोड नहीं हुआ, या कोई प्रोजेक्ट है ही नहीं। | थोड़ा रुकें, या पहले प्रोजेक्ट बनाएँ। देखें [टास्क प्रोजेक्ट सेट करें](set-up-task-project.md)। |
| जिसे आप असाइन करना चाहते हैं, वह **Assignee** लिस्ट में नहीं है | वह इस प्रोजेक्ट का मेंबर नहीं है। | बोर्ड पर **Add members** पर क्लिक करें और उसे जोड़ें। |
| **Save this work item before adding subtasks.** | टास्क अभी बना नहीं है। | पहले **Create** पर क्लिक करें, फिर टास्क खोलकर सबटास्क जोड़ें। |
| **Could not create ticket. Please try again.** | सेव करने की रिक्वेस्ट सर्वर तक नहीं पहुँची। | अपना कनेक्शन जाँचें और दोबारा **Create** पर क्लिक करें। |
| **Could not update assignee.** | बदलाव सेव नहीं हुआ। | बोर्ड रिफ़्रेश करें और असाइनी दोबारा चुनें। |
