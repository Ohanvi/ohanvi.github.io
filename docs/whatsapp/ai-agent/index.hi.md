# AI एजेंट { #ai-agent }

AI एजेंट आपके बिज़नेस के बारे में आपके सिखाए हुए ज्ञान से व्हाट्सऐप पर ग्राहकों के सवालों के जवाब देता है। आप उसे टेस्ट कर सकते हैं और तैयार होने पर पब्लिश कर सकते हैं।

**यह कहाँ मिलेगा:** लेफ़्ट रेल में **WhatsApp** खोलें, फिर **AI Agent** चुनें।

![AI Agent स्क्रीन, जिसमें बाईं ओर उसके सेक्शन और दाईं ओर Test your Agent पैनल है](../../assets/screenshots/whatsapp-ai-agent-0-overview.png)

## गाइड { #guides }

| गाइड | कब इस्तेमाल करें |
| --- | --- |
| [AI एजेंट सेट करें](../set-up-ai-agent.md) | आप अपना एजेंट बना रहे हैं और पब्लिश कर रहे हैं। |
| [AI के जवाबों की समीक्षा करें और उन्हें सुधारें](../review-and-correct-ai-agent-answers.md) | आप देखना चाहते हैं कि एजेंट ने किसी तरह जवाब क्यों दिया और उसे ठीक करना चाहते हैं। |

## शुरू करने से पहले { #before-you-start }

- आपका व्हाट्सऐप नंबर Ohanvi से कनेक्ट हो। देखें [अपना नंबर कनेक्ट करें](../connect-whatsapp-number.md)।
- आपके रोल को इस स्क्रीन का एक्सेस हो। अगर यह न दिखे, तो अपने एडमिन से पूछें।
