# Tasks panel

The **Tasks** panel is the quickest way to see your own work and add a new task. It lists tasks under **Today**, **Assigned to me** and **Created by me**. The guides below cover creating, writing and finding tasks.

**Where to find it:** click **Tasks** in the right-hand rail, next to the notification bell.

## Guides

| Guide | Use it when |
| --- | --- |
| [Create and assign tasks](../create-and-assign-tasks.md) | You want to add work and give it an owner, a priority and a due date. |
| [Write in the task editor](../write-in-the-task-editor.md) | You want headings, lists, tables, pictures or voice in a description or comment. |
| [Comment, mention and attach files](../collaborate-on-tasks.md) | You want to discuss a task, share files or log time. |
| [Find, filter and view tasks](../find-and-filter-tasks.md) | You want to see only your work, or switch the board's view. |

## Before you start

- Your role has Task access. Without it, the **Tasks** icon is hidden.
- Your workspace has a task project. See [Set up a task project](../set-up-task-project.md).
